# 参考譜面コーパス（設計・2026-09-07）

自動譜面制作をさらに賢くするための「参考譜面コーパス」方式の設計メモ。
**まだ実装していない**。いまの生成器（`tools/mode/rhythm-chart-v3-*`）は、統計ではなく
規則と点数（`rankShapes`）で形を選んでいる。曲が十分に増え、人が耳と指で確かめた譜面が
たまってから、ここに書いた形で統計を足す。

## 目的

よその作品の譜面をコピーすることではない。**人が作って良いと確かめた譜面**に見られる
「自然な譜面文法」（どの音にどの形が来やすいか・どの形のあとにどの形が来やすいか）を
統計として持ち、生成器の点数付けへ足す。

## 何を貯めるか

譜面1つにつき、かたまり（フレーズ）ごとに1行。生成器が `shapes` ログへ残している項目が、
そのまま土台になる。

| 項目 | いまの出どころ | 使いみち |
| --- | --- | --- |
| `patternId` / `patternLength` / `mirrored` | `shapes[]` | 形の出現率 |
| `difficulty` / BPM帯（120以下・〜150・〜180・180超） | 譜面のメタ | 難易度・速さごとの語彙 |
| `role`（intro / body / climax / outro） | `shapes[].role` | 場面ごとの語彙 |
| `motifKey`（刻み＋音の上下） | `shapes[].motifKey` | 「この音形にはこの形」 |
| 直前の形・直後の形 | `shapes[]` の並び | 形の遷移（bigram） |
| レーンの動き（起点・向き・跳び） | `shapes[].lanes` | つなぎの自然さ |
| 手の負荷（strained・指の移動） | `rhythm-hand-simulate.js` の割り当て | 押しやすさの実績 |
| 休符の長さ・難所の長さ | `rhythm-chart-quality-report.js` | 緩急の実績 |
| 同時押しの形（幅・間隔）・SLIDEの形（直線・折り返し・スイープ） | 品質レポートの `chordShapes` / `slideShapes` | 見せ場の使いかた |

すべて **`tools/mode/authoring/<曲>-v3-fixed-*.json` と `<曲>-v3-quality.json` から機械で取れる**。
新しく手で書く項目は無い。

## どう使うか

1. 人が「良い」と確かめた譜面だけをコーパスに入れる（`status:'approved'` のような印を譜面JSONへ持たせる）
2. 形の出現率 P(pattern | motifKey, role, difficulty) と遷移 P(next | prev, difficulty) を数える
3. `rankShapes` の点数へ「コーパスでの起こりやすさ」を1項目として足す（重みは小さく始める）
4. 音との合いかた（`shapeCandidatesFor` の順位）は**コーパスより優先**する。統計は同じくらい合う候補の中でしか効かない

## 機械学習について

曲が十数曲・かたまりが数千のうちは、モデルを足しても学べるものが無い。
まずは上の**数え上げ（確率表）**で足りるかを見る。大きなライブラリは足さない。

## やらないこと

- よその作品の譜面データを取り込むこと
- 特定の曲でしか効かない規則をコーパスから「学んだ」として入れること
- コーパスが無い曲で生成が止まること（コーパスは点数の1項目であって、無くても作れる）
