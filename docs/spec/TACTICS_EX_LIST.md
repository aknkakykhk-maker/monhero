# タクティクスバトル EXスキル 一覧と仕様（決定分）

更新: 2026-10-03

**いま実際にゲームへ入っているEXスキルと、その仕様のまとめ。** 数字はすべて `monster-hero/src/parts/32-tactics-units.jsx` の
`TACTICS_EX_SKILLS` から読み出したもの。実装の細かい置き場所は [TACTICS_EX_SKILLS.md](TACTICS_EX_SKILLS.md)（実装メモ）。
EXはタクティクスバトル専用で、クラシック系のモードには出ない。β版のお試しなので、数字は今後変わりうる。

- 実装済み: **20体**（モノリス・モッチー・ミタラシ・エイキ・ザン・アーク・イブリース・ゴーレム・剣士モッチー・ユグドラシル・メルホイップ・**ピクシー・ミーア・スネグーラチカ・ウンディーネ・ヤオビクニ・パンドラ・ライガー・プラント・オボロゲソウ**）。ピクシー・ミーア・スネグーラチカ・ウンディーネ・パンドラは**数字が仮**（§3-2）
- 実装の途中: **パンドラの染色**（本体・悪魔・天使の3枚の染色。§4。悪魔・天使の2体表示は実装済み）
- 案が未決: **スエゾー・ハム**（§5）

## 1. 共通ルール（どのEXも同じ）

| 項目 | 決まり |
| --- | --- |
| 使い方 | 距離枠をタップして詳細を開き、「EXスキルを使用」を押す。タップで開くだけでは発動しない |
| 回数 | **1ランごと**。WAVEが変わっても戻らず、新しいランで初期値に戻る（回数が「無制限」のEXもある） |
| 使えるタイミング | その子が立っているとき・行動中でないとき・AUTO中でないとき。**同じ子は1ターンに1回まで** |
| カードとの併用 | 併用できるEXは、使ったターンもその子が通常カードを使える。**併用不可のEXは、使ったターンだけ「使った子」がカードを使えない**（ほかの子・緊急回復は使える） |
| 効果の長さ | 発動したターンだけ / 発動したWAVEの終わりまで / 切り替え式 / 使ったターンから◯ターン（**WAVEが変わると切れる**）のどれか |
| カード枠 | EXはカードの枚数制限とは別。通常カードの上限を食わない |
| 表示 | 距離枠の札に「EX」・効いている間は「あとNターン」「◯◯中」。回数が尽きる・条件を満たさないときは詳細に理由が出る |
| 効果が切れたとき | 数字（上がった上限・増えた連撃の数など）は元に戻る。もう一度使うと0から数え直す |

「◯ターン」は**使ったターンを1ターン目として数える**（5ターンなら使ったターン＋あと4ターン）。

## 3. 1体ずつの仕様

### モノリス「みんなをかばう」
- 1ラン10回・併用できる・発動したターンだけ。
- 敵の攻撃を、**単体・全体・連撃まで**全部モノリスが引き受ける。当たる回数はそのままで、当たり先をモノリスへ集める。
- 使った子（モノリス）以外は、いつもどおりカードを使える。

### モッチー「ガッツ全開っちー」
- 1ラン3回・併用できる・使ったターンから5ターン（同じWAVEの中だけ）。
- **力・丈夫さ・ライフの上限・ガッツの上限が30%上がる**（力と丈夫さは切り捨て）。
- **ターンの終わりの自動回復に、ライフとガッツそれぞれ上限の30%を上乗せ**（倍率ではなく固定値で足す。倒れた子の10%の戻りには乗せない）。
- 使った瞬間に、**上がった上限まで**ライフとガッツを満タンにする。
- 効果が切れたら上限は元に戻り、いまのライフ・ガッツは元の上限で頭打ち。

### ミタラシ「ドラゴンだっちー」
- ガッツ全開っちーの、上がるステータスが違う版。1ラン3回・併用できる・5ターン。
- 力とガッツの上限が**+40%**、丈夫さとライフの上限が**+20%**。
- ターンの終わりの自動回復に、ガッツは上限の40%・ライフは上限の20%を上乗せ。
- 使った瞬間に、上がった上限まで満タン。

### エイキ「緋桜瞬歩」
- 1ラン3回・**併用できない**（使ったターンはエイキだけカードを使えない）・3ターン。
- 効いているあいだ、攻撃の**距離補正がどの距離にいても×1.7**。ふだんは敵との距離の差で×1.5（同じ）/×1.3/×1.1/×0.9。間合い適性は変えない。
- エイキが**敵と同じ距離の枠にいるとき**、狙われたら**抽選なしで完全に回避**する（ほかの子が狙われたときは関係ない）。

### ザン「血踊」
- 1ラン5回・併用できる・5ターン。
- ザンが**敵と同じ距離の枠にいるとき**、狙われたら完全に回避する（エイキと同じ判定）。
- **回避するたびに、ザンの攻撃へ与ダメ10%の連撃が1回ずつ増える**（2回避ければ10%の連撃が2回）。
- 敵の連撃でも、1回の敵の攻撃につき1回と数える。効果が切れる・WAVEが変わる・もう一度使うと0に戻る。

### アーク「抗えぬ宿命を追え」
- 1ラン5回・併用できる（指定が無かったので「できる」にした）・5ターン。
- 与ダメージ**+30%**（最終ダメージにかける乗算）。
- 攻撃に**与ダメ10%の連撃を1回**追加。
- アークが受けるダメージ**−20%**（ほかの軽減と掛け算で重なる）。

### イブリース「堕天の烙印」
- 1ラン5回・併用できる（指定が無かったので「できる」にした）・5ターン。
- **使うとき、最大ライフの30%を払う。** ライフがその量より多く残っているときだけ使える（払って倒れることはない。ライフが足りないと詳細に理由が出る）。
- 攻撃に**与ダメ5%の連撃を5回**追加。
- **会心率×1.5**・**会心ダメージ×1.3**（どちらも、ほかの強化を足したあとの値にかける乗算）。
- 丈夫さ**+30%**。

### ゴーレム「捨て身」
- 1ラン3回・**併用できない**・発動したWAVEの終わりまで。**効果が続いているあいだは使えない**。
- 丈夫さを0にし、**0にした丈夫さの50%を力へ加える**。

### 剣士モッチー「ソード・コンバージョン」
- 1ラン5回・併用できる（2026-10-04 変更。それまでは無制限・併用不可）・切り替え式（もう一度使って選び直すまで続く）。いまのスタイルは選べない。
- スタイルは3つ。はじめは**片手剣**。
  - **片手剣**: いつもの戦い方。固有技でソードスキルも出る。
  - **片手盾**: 力と同じ数値を丈夫さへ足す。固有技を使ってもソードスキルは出ない。
  - **二刀流**: 丈夫さが半分になる代わりに、連撃がすべて2回ぶん入る（メインのダメージは1回のまま）。
- 切り替えは、いつも**元のステータス**から数え直す（積み重ならない）。
- **勇者モンに選んだときだけ**、配置の画面で最初のスタイルを選べる。

### ユグドラシル「世界樹の守り」
- 1ラン5回・併用できる・使ったターンから3ターン。
- **味方全員**の受けるダメージ−30%（ほかの軽減と重なる）。
- ターンの終わりに、立っている味方全員のライフを**上限の20%ずつ**回復。

### メルホイップ「スイーツパラダイス」
- 1ラン3回・併用できる・発動したターンだけ。
- そのターンのメルホイップの攻撃に、**与ダメ30%の連撃を4回**追加（連撃ダメージ補正も乗る）。

## 3-2. 2026-10-03 に実装した3体（**数字は仮・あとで調整する**）

ユーザーの案（「これで決め打ちしないで細かい数値とか調整したい」）をもとに、数字は私が仮に置いた。

### ピクシー「お気に入りの魔法」（回数3・併用できる・3ターン）
- 毎ターン、ピクシーの**固有技カードが手札に必ず出る**（使ったターンも出す。手札がいっぱいで、いちばん後ろのカードを選んでいるときは次のターンから）。
- どの距離にいても距離補正が**×1.5**（敵と同じ距離のときと同じ）。
- 固有技の「使うと次のターン、使用ガッツ0」はタクティクスではその子の枠だけに効くので、連発できる。

### ミーア「オン・ステージ！」（回数3・併用できる・4ターン）
- 1ターンに使えるカード枚数が**+1**（盤面ぜんぶ・ミーア自身。上限5は変えない）。
- 味方がカードを1枚使うたびに**ボルテージ+1**（最大10。ターン終わりにまとめて数える）。1段階ごとに味方全員の**与ダメ+3%・回復カードの回復量+5%・ターン終わりのガッツ自動回復+2%・ライフ自動回復+3%**。
- 終わるとボルテージは0に戻る。詳細の「いまの状態」にボルテージが出る。

### スネグーラチカ「クリスマスプレゼント」（各WAVE1回・併用できる・持続は2ターン）
- 必ず全員のガッツが**上限の20%**戻る。
- さらにランダムで1つ: **与ダメ+20%／被ダメ−20%／連撃（与ダメ10%×2回）／ライフ上限の20%回復／ガッツ上限の20%追加回復／会心率×1.3**。
- **10%で大当たり**（6つ全部）。中身は使った直後にログと詳細に出る。
- 回数はWAVEが変わると戻る。

### ウンディーネ「生命の泉」（回数5・併用できる・3ターン・2026-10-03実装・数字は仮）
- **味方1体を選んで使う**（自分も選べる）。
- 選んだ子が**ダウン中**: すぐ立ち上がって**ライフ満タン**。
- 選んだ子が**立っている**: **ライフ上限+30%（3ターン）**のうえ**ライフ満タン**（上がった上限まで）。
- どちらも**ガッツが上限の30%**戻る。詳細の「いまの状態」にだれに使ったかが出る。

### オボロゲソウ「おぼろ返し」（回数5・併用できる・3ターン・2026-10-05実装・数字は仮）
- 3ターンのあいだ、**味方が敵の攻撃で受けたダメージの50%を、受けた子のライフへすぐ回復**し、ガッツも受けたダメージの**5%**ぶん回復する。倒れた子には回復しない。使った子が倒れても効果は続く。WAVEが変わると切れる。

### プラント「緑のめぐみ」（回数5・併用できる・5ターン・2026-10-05実装・数字はユーザー指定）
- 5ターンのあいだ、**味方全員**のちから・丈夫さが+10%（切り捨て）、ターン終わりの**ライフ・ガッツの自動回復が上限の10%ぶん多くなる**。使った子が倒れても効果は続く。WAVEが変わると切れる。

### ライガー「雷狼影」（回数5・併用できる・合計6ターン・2026-10-05実装・数字はユーザー指定）
- 使ったターンから**前半3ターンは「ためる」**: ライガーへ置いたカードを使う（行動する）たびに**雷+1**（ガード・アシストカードも数える。ききの効果でカードが増えたぶんも数える。上限なし）。
- 3ターン目の終わりに**「雷纏」が始まり**、**後半3ターン**、雷1つにつき ライガーに次の強化が付く:
  与ダメージ+30%／会心率+10%（足し算）／与ダメージ10%の連撃が1回／敵の攻撃を回避する確率+5%（上限90%）／ターン終わりのライフ自動回復+5%・ガッツ自動回復+5%。
- 雷纏に入ったあとは雷は増えない。効いているあいだ（ため・雷纏とも）は、もう一度使えない。WAVEが変わると切れる。距離枠の札に「雷◯」「雷纏◯」が出る。

### パンドラ「パンドラの箱」（回数3・併用できる・3ターン・2026-10-03実装・数字は仮）
- 天使側と悪魔側に分かれて3ターン戦う（システム上は1体）。**箱が効いているあいだ、パンドラの枠に悪魔と天使の2体が並び**、カードを切る間は1枚目=悪魔・2枚目以降=天使が前に出る（もう片方は暗くなる。染色は本体だけ・3枚染色は未実装）。
- **1・2ターン目の終わりに最大ライフの30%を払う**（ほかに立っている味方がいないときは倒れない）。パンドラが使えるカード+1。
- **1枚目**は悪魔側: 与ダメ×1.5・与ダメ30%の連撃×1。**2枚目**は天使側: 味方全員のライフ・ガッツ上限の10%回復。
- **3ターン生き残ると「最後の希望」**: パンドラ自身はダウン／ダウン中の味方は復活／全員ライフ満タン／ガッツ上限の50%。助ける味方がいなければダウンしない。
- **途中で倒れると**、倒れたときのパンドラのガッツを、生きている味方へ均等に分ける（最後の希望は起きない）。

### ヤオビクニ「悠久の刻」（回数2・併用できる・発動ターンだけ・2026-10-03実装）
- 時間を止める。使ったターンは**敵が行動しない**。そのターンは**WAVEの20ターンの数にも入らない**（ターンの数字が進まない）。
- ターン終わりの自動回復は入る。止めたあとの同じターンの数字では、もう一度使えない。

## 5. こちらで決めたこと（見直してよい）

指定が無かったので、こちらの判断で決めた点。違っていたら直す。

- アーク・イブリース・ザンのカード併用は「**できる**」にした（自己強化なので、使ったターンも殴れないと意味が薄いため）。
- イブリースのライフ消費は「**最大ライフの30%**」（ユーザー指示）。足りないときは**使えない**ようにした（払って倒れるのは避けた）。
- 「○ターン」は同じWAVEの中だけ数える（WAVEが変わると切れる。ユーザー指示「WAVE跨ぎはなし」）。
- 数字の「乗算」と書いたものは、ほかの強化を足したあとの値にかける（足し算ではない）。

## 6. 更新履歴の書き方（EX）

実装前に何度か調整したEXは、更新履歴へ**最終の中身だけを書いた1件**にする（「強くなりました」の項目は作らない。ユーザー指示）。
すでに公開したEXの数字を変えたときだけ、変更の項目を足す。
