# モンサクの画面の決まり(MONSUC_UI)

2026-11-14 社長「画面の使い方が下手」「こういう細かいところの統一感がないんだよな」
(止め絵: `docs/progress/player-raise/president-notes-2026-11-14/`)。
1画面ずつ直さず、この1枚に合わせて**モンサク(モンヒロサクセス)の全部の画面**をそろえる。
新しい画面を作るとき・直すときは、先にここを読む。参考の実物は `docs/reference/line-mf/REF-MAP.md` から引く。

手本にする画面: **章の終わり・NEXT のはしご**(`MsxKiShow`)/**イッサ博士**(`MsxIssa`)/**イベント図鑑**(`MsxDex`)/
参考 v4 180〜186秒(育成グレード)・te-37(リザルト)・te-40(章の終わり)。

## 1. 画面の使い方(いちばん大事)

縦画面(390×844)は「上の帯 → 場面 → 札 → ボタンの列」の4段。

| 段 | 部品 | 決まり |
| --- | --- | --- |
| 上の帯 | `MsxBand`(育成中)/ `.v-h` の見出し(育成の外) | どの画面も同じ位置・同じ高さ |
| 場面 | `.v-scene`(景色+子の絵) | **残りの高さを全部もらう**(`flex: 1 1 0`)。主役(子)は場面の高さの半分以上 |
| 札 | 結果・数字の札(下の 3・4) | 場面の下か、場面の上に重ねる。札だけで画面を埋めない |
| ボタンの列 | `.v-ft` | いちばん下。主なボタン(`.go`)は1つ |

- **下に大きな空きを残さない。** 中身のいちばん下とボタンの列のあいだは **48px まで**。
  空いたら札を増やすのではなく、**場面(子の絵)を伸ばして埋める**。
  `<div style={{ flex: 1 }}/>` で押し下げて空きを作るのは禁止(見張りが止める)
- 場面の絵が無い画面(一覧・設定のような画面)は、一覧の枠を `flex:1` で伸ばしてスクロールさせる
- 横画面(844×390)は左に場面・右に札とボタン。上に 50px 以上の空きを作らない

> **例外(2026-11-15 社長 r1115-166): ストーリー選択(`MsxScenarioSelect`)は、参考の「ストーリー選択」どおりの全面の絵の専用画面として残す。** 上の帯・下のボタンの列を共通の部品にそろえない(絵の迫力を優先)。ほかの画面にこの例外を広げない

## 2. 数字のそろえ方

| 数字の種類 | そろえ方 | 部品 |
| --- | --- | --- |
| **見せ場の数字**(総合力・獲得賞金・評価・残りポイントなど、結果として見せる数字) | **真ん中そろえ**。小さな見出し → 大きな数字 → すぐ右に差(+616)を小さく。3つを1かたまりで真ん中 | `.v-num`(下の形) |
| 能力6つ | 升目ごとに真ん中(値・棒・差) | `MsxStRow`(`ups` で差) |
| 動いた数字(体力・ストレス・親密度・人気・忠誠度など) | 札ごとに真ん中 | `.v-gains` の札 |
| 説明の表(「残りポイント: 40」のような名前と値の行) | 名前を左・値をその右に続ける。**見せ場の数字には使わない** | `.v-kv` |

- 右寄せの数字(表の右端に値だけ寄せる形)は使わない
- 数字は3けたごとに「,」(`msxFmt`)。差は `+12` / `−12`(全角のマイナス)。増えた差は黄、減った差は赤

```
<div class="v-num"><small>獲得賞金</small><b>7,700<small>G</small><em>+6,600G</em></b></div>
```

## 3. 結果の出し方(1つの形)

何かをした結果(トレーニング・休む・遊ぶ・通院・イベントの選択・大会・修行・アイテム)は、全部この形:

1. **場面**: 子の絵+大きな判子の字(`.v-stamp`。「大成功」「通院」など)
2. **動いた数字の札**: 能力は `MsxStRow ups`、それ以外は `.v-gains`(「❤️体力 +30」「💢ストレス −10」)。
   動いた物は**全部**札にする。何も動かなかったときも「変化なし」と書く(黙らない)
3. **ひとこと**(`.v-log` の白い箱): 何がどう変わったかを**名前で**書く。
   「ようすが治った」「能力が上がった」のようなまとめ言葉で済ませない →「サボりグセが治った」「ちから +12・かしこさ +4」
4. 助手の吹き出し(`MsxSay`)は最後に1つだけ

## 4. 札・見出し・ボタンの形と大きさ

| 部品 | 形 |
| --- | --- |
| 見出し `.v-h` | 15px 太字。下に説明 10.5px を1行。絵文字1つを前に |
| 札 `.v-card` | 背景 #1e1a36・ふち 1px #3b3566・角 14px・中の余白 8px。選んでいる札だけ黄のふち(`.sel`) |
| 見せ場の札 | 札と同じ形で、ふちだけ金(#fde047)。1画面に1つまで |
| 小さな印 `.v-chip` | 丸い角・10.5px。状態(ようす・ピーク)を出すだけ。数字の変化には使わない(それは `.v-gains`) |
| ボタンの列 `.v-ft` | 高さ 48px 以上・押せる物は 44px 以上。左に戻る系(暗い)、右に主なボタン `.go`(桃→橙)。主なボタンの字は「つぎへ ▶」「これで決める ▶」のように ▶ で終える |
| 字の大きさ | 本文 11〜12.5px・小さい説明 10px より下にしない |
| 文の折り返し | **ボタン・選択肢・札の文は言葉の途中で折らない**(2026-11-14 社長「文字列が悪い」。「気合いを入/れる」「ライセン/ス」が NG)。1行に収まる長さを基本にし、2行になるときは言葉の切れ目で折る(`jaWrap` と `JA_LABEL_STYLE` を使う)。土台として `.msx` のボタン・選択肢・吹き出し・白い箱には `word-break: auto-phrase` も付けてある。見張りは `success-shoot.js` の「ボタン・選択肢の文が言葉の途中で折れない」(全7サイズ) |

## 4b. ボタンの中の文字・記号は真ん中にそろえる(2026-11-15 社長「そういうの多すぎる・表示方法にセンスがない」)

- ボタン・チップの中の文字や記号(＋ − ✕ ⇄ 決定 元に戻す 戻る など)は、**上下左右ともボタンの真ん中**。左寄せ・上寄せのまま放っておかない
- 作り方: ボタンは `display:flex; align-items:center; justify-content:center; text-align:center`(`.chip` と `.msx-md-alt` は付けてある)。
  記号だけのボタンで、見た目の丸を角に寄せたいときは、丸の位置でなく**ボタンの位置**を動かす(丸をボタンの真ん中に置く)
- 例外は、絵・ゲージ・染め色の見本を含む札と、長い選択肢の行(左寄せが決まりの行)だけ。行ボタンでどうしても左寄せなら `data-msx-left` を付ける
- 見張り: `tools/success/msx-ui-rules.js` の `offBtn`(文字の箱の中心とボタンの中心の差が 3px 以上で NG)。`success-shoot.js`・`success-r3-shoot.js` の「ボタンの文字・記号が上下左右とも真ん中」

## 5. 余白

- 画面の左右 10px・札と札のあいだ 6px・札の中 8px
- 場面の絵の中の札は、場面のふちから 10px

## 7. 選ぶ画面の検索・並び替えと効果の詳細(2026-11-17 モンサク改善)

- モンスターを選ぶ画面(育成開始・編成・フレンド・マスモンボックス・合体の親選び)は、共通の道具 `MsxPickTools`(56-monsuc-teampick.jsx)でそろえる: **検索(名前・種族)・並び替え・逆順・候補の件数**。
  検索の比べ方は NFKC 正規化+小文字(全角・半角の違いを吸収)。件数は「候補 / 全体」で出し、所持総数と混同しない
- 検索・並び替えは**表示だけ**の操作。選択は個体の id で持ち、検索で隠れた個体の選択・編成は外さない。元の並び・保存データは並べ替えない(写しを並べ替える)
- 空の出方は2つに分ける: 「所持していない(まだいない)」と「検索に当てはまるモンスターがいません」
- 並び替えの項目は画面の既存の物に合わせる(育成開始=標準・名前・種族 / 編成=総合力・Lv・名前・種族・入手 / フレンド=総合力・Lv・名前 / ボックス=既存の `msxMmSorted` と保存される表示設定をそのまま使う)
- 編成の候補の「効果・詳細」ボタンは、選んでいる候補があるときだけ、画面の下の操作の列(フッター)に置く(全候補に全幅のボタンを置くと一覧の密度が下がるため。2026-11-17 点検15件 低-4 で変更。置き場所は 2026-11-18 社長の実機報告でカードの下からフッターへ変更)。カードのタップは選ぶだけにし、詳細はボタンから開く(長押しでは開けない。2026-11-18 社長)。フレンドの行には借りる前の確認として常時置く。詳細は `MsxMonDetail` を再利用し、保存済みアシストを `AT.fromSaved` / `AT.describe` で出す(効果量・条件・重なるときの扱い・上限の注記まで表の文のまま。説明のために別の計算式を作らない)
- **「選択中」の意味色は黄色い光るふち(#fde047)に全画面で統一する**(編成の候補・フレンドの行・大会の札・技の升など)。ピンクはテーマ色として選択中以外にだけ使う。決定・進行のボタンは橙(2026-11-17 点検15件 中-1)
- メモリアルモンスターの一覧と合体の親選びにも検索・並び替えを置く(並び替えはボックスと同じ `msxMmSorted` / `MSX_MM_SORTS`。メモリアルの検索・並び替えの状態はボックス一覧と混ざらないよう別に持つ)
- 詳細の手前にはサポート情報(親密度・友情タッグの強さ・得意率・主な能力の集合率と伸び)を**基本値**として出す。数え方は芯の `memberOf` / `gatherChanceOf` のまま。「実際の効果は発動条件などで変わります」を添える
- 狭い縦画面では検索・並び替えの操作は折り返してよい。タッチ領域は 44px 目安、検索欄の文字は 16px 目安(入力時の拡大防止も兼ねる)。長い効果説明は行を分けて全文読めるようにする。高さの短い画面では編成の帯を詰め、選んでいる編成が見えるままにする

## 8. モンスターの札の型(r1119-017・2026-11-20 社長「全てにサイズ感とか統一感がない」)

モンスターを出す所(マスモンボックス・メモモン・育成の 1/6 と 2/6・編成の候補・合体の親えらび・アシモン・詳細)は、**全部この1つの形**で出す。
画面ごとに丸い顔・点線の箱・全身の小さい絵を別々に作らない。部品は `src/parts/56-monsuc-moncard.jsx` の `MonsucMonCard`(並べるときは `MonsucCardGrid`)。
参考: `docs/reference/line-mf/` の assist-hensei・deck-select・assist-card-8-detail(絵の大きい縦長のカード・左上に能力の印・右上に段・下の帯に Lv)。
見本の止め絵: `docs/progress/hq/r1119-monsuc-fix/shots-moncard/`(`node tools/success/monsuc-moncard-shoot.js` が撮り、重なり・縦横比・字の大きさを見張る)

### 形(どの大きさでも同じ)

| 場所 | 置く物 | 決まり |
| --- | --- | --- |
| 札 | 縦長 3:4 | ふちの色は評価の頭の字(S 金・A 赤・B 桃・C 緑・D 水色・E 青・F 紫・G 灰・M 紫)。点線は使わない |
| 絵 | 全身・下合わせ | 札の上 6%〜下の帯の上まで。顔だけに切らない(染色が出ない)。帯と重ねない |
| 左上 | 得意な能力の印 | 能力のアイコン(❤️🏋️📖🎯👣🛡️)を縦に。小は1つ・中と大は2つまで |
| 右上 | 評価 | 「A2」の形(保存した `grade`。無ければ `rank`) |
| 下の帯 | 名前(と Lv) | 名前は1行。長い名前は字を縮めて収め、9px より小さくしない。Lv は中・大だけ |
| 札の下 | 役の帯 か 数字 | 役の帯は「マスモン 青・メモモン 紫・ベースモン 灰・フレンド 赤」。一覧は総合力の数字 |
| 選んだ印 | 右下の桃の丸 ✓ と桃のふち | 名前の帯には重ねない |
| 選べない理由 | 絵の真ん中の帯(「育成中」など) | 絵を薄くする。名前は読めるまま |
| 空き枠 | 茶色の札に「+」 | 点線にしない |

### 大きさは3つだけ

| 大きさ | 使う所 | 並べ方 |
| --- | --- | --- |
| 小 `size="s"` | 一覧(ボックス・メモモン・候補・合体の親えらび) | 縦5列・横7列(`MonsucCardGrid size="s"`) |
| 中 `size="m"` | 編成の6枠・アシモンの札 | 縦3列・横6列(`MonsucCardGrid size="m"`) |
| 大 `size="l"` | 詳細の1体 | 詳細の左の欄の幅 |

札の中の字と印の大きさは札の幅で決まる(`cqw`)。画面ごとに字の大きさを足さない。

### タブ・検索の段・下のボタンの段

| 部品 | 形 |
| --- | --- |
| タブ | 高さ 36px・同じ幅で横に並べる(2〜4つ)。選んだタブだけ桃→橙 |
| 検索・並べ替えの段 | 高さ 36px の1行(`MsxPickTools`)。得意で絞るなどを足すときも1行に収め、2段にしない |
| 下のボタンの段 | §4 の `.v-ft`。高さ 48px。主なボタンは1つだけ(`.go`)、ほかのボタンは同じ高さ・同じ形。縦に積まない |

### 作り直す順(④)

段1 メモモン(#6891 で中身の直し済み。升目をこの型の小へ)→ 段2 育成の 2/6 編成・枠を選ぶ画面・効果一覧・アシモン → ⑥⑦の画面(合体の窓・1/6)は、それぞれの会話がこの型に載せる。
