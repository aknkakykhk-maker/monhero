# モンサクの画面の決まり(MONSUC_UI)

2026-11-14 社長「画面の使い方が下手」「こういう細かいところの統一感がないんだよな」
(止め絵: `docs/progress/player-raise/president-notes-2026-11-14/`)。
1画面ずつ直さず、この1枚に合わせて**モンサク(モンヒロサクセス)の全部の画面**をそろえる。
新しい画面を作るとき・直すときは、先にここを読む。参考の実物は `docs/reference/line-mf/REF-MAP.md` から引く。

手本にする画面: **章の終わり・NEXT のはしご**(`MsxKiShow`)/**イッサ博士**(`MsxIssa`)/**イベント図鑑**(`MsxDex`)/
参考 v4 180〜186秒(育成グレード)・te-37(リザルト)・te-40(章の終わり)。

## 1. 画面の使い方(いちばん大事)

縦画面(390×844)は「上の帯 → 場面 → 札 → ボタンの列」の4段。

| 段 | 部品 | 決まり |
| --- | --- | --- |
| 上の帯 | `MsxBand`(育成中)/ `.v-h` の見出し(育成の外) | どの画面も同じ位置・同じ高さ |
| 場面 | `.v-scene`(景色+子の絵) | **残りの高さを全部もらう**(`flex: 1 1 0`)。主役(子)は場面の高さの半分以上 |
| 札 | 結果・数字の札(下の 3・4) | 場面の下か、場面の上に重ねる。札だけで画面を埋めない |
| ボタンの列 | `.v-ft` | いちばん下。主なボタン(`.go`)は1つ |

- **下に大きな空きを残さない。** 中身のいちばん下とボタンの列のあいだは **48px まで**。
  空いたら札を増やすのではなく、**場面(子の絵)を伸ばして埋める**。
  `<div style={{ flex: 1 }}/>` で押し下げて空きを作るのは禁止(見張りが止める)
- 場面の絵が無い画面(一覧・設定のような画面)は、一覧の枠を `flex:1` で伸ばしてスクロールさせる
- 横画面(844×390)は左に場面・右に札とボタン。上に 50px 以上の空きを作らない

## 2. 数字のそろえ方

| 数字の種類 | そろえ方 | 部品 |
| --- | --- | --- |
| **見せ場の数字**(総合力・獲得賞金・評価・残りポイントなど、結果として見せる数字) | **真ん中そろえ**。小さな見出し → 大きな数字 → すぐ右に差(+616)を小さく。3つを1かたまりで真ん中 | `.v-num`(下の形) |
| 能力6つ | 升目ごとに真ん中(値・棒・差) | `MsxStRow`(`ups` で差) |
| 動いた数字(体力・ストレス・親密度・人気・忠誠度など) | 札ごとに真ん中 | `.v-gains` の札 |
| 説明の表(「残りポイント: 40」のような名前と値の行) | 名前を左・値をその右に続ける。**見せ場の数字には使わない** | `.v-kv` |

- 右寄せの数字(表の右端に値だけ寄せる形)は使わない
- 数字は3けたごとに「,」(`msxFmt`)。差は `+12` / `−12`(全角のマイナス)。増えた差は黄、減った差は赤

```
<div class="v-num"><small>獲得賞金</small><b>7,700<small>G</small><em>+6,600G</em></b></div>
```

## 3. 結果の出し方(1つの形)

何かをした結果(トレーニング・休む・遊ぶ・通院・イベントの選択・大会・修行・アイテム)は、全部この形:

1. **場面**: 子の絵+大きな判子の字(`.v-stamp`。「大成功」「通院」など)
2. **動いた数字の札**: 能力は `MsxStRow ups`、それ以外は `.v-gains`(「❤️体力 +30」「💢ストレス −10」)。
   動いた物は**全部**札にする。何も動かなかったときも「変化なし」と書く(黙らない)
3. **ひとこと**(`.v-log` の白い箱): 何がどう変わったかを**名前で**書く。
   「ようすが治った」「能力が上がった」のようなまとめ言葉で済ませない →「サボりグセが治った」「ちから +12・かしこさ +4」
4. 助手の吹き出し(`MsxSay`)は最後に1つだけ

## 4. 札・見出し・ボタンの形と大きさ

| 部品 | 形 |
| --- | --- |
| 見出し `.v-h` | 15px 太字。下に説明 10.5px を1行。絵文字1つを前に |
| 札 `.v-card` | 背景 #1e1a36・ふち 1px #3b3566・角 14px・中の余白 8px。選んでいる札だけ黄のふち(`.sel`) |
| 見せ場の札 | 札と同じ形で、ふちだけ金(#fde047)。1画面に1つまで |
| 小さな印 `.v-chip` | 丸い角・10.5px。状態(ようす・ピーク)を出すだけ。数字の変化には使わない(それは `.v-gains`) |
| ボタンの列 `.v-ft` | 高さ 48px 以上・押せる物は 44px 以上。左に戻る系(暗い)、右に主なボタン `.go`(桃→橙)。主なボタンの字は「つぎへ ▶」「これで決める ▶」のように ▶ で終える |
| 字の大きさ | 本文 11〜12.5px・小さい説明 10px より下にしない |
| 文の折り返し | **言葉の途中で折らない**(2026-11-14 社長「文字列が悪い」。「気合いを入/れる」が NG)。ボタン・選択肢は1行に収まる長さが基本。折るなら文の区切り(読点・「」の切れ目)で。`.msx` のボタン・選択肢・吹き出し・白い箱には `word-break: auto-phrase`(文節で折る)を共通で付けてある。直した画面は縦390・横844・幅320・大きい文字で確かめる |

## 5. 余白

- 画面の左右 10px・札と札のあいだ 6px・札の中 8px
- 場面の絵の中の札は、場面のふちから 10px

## 6. 機械の見張り

`tools/success/success-shoot.js`(育成中の画面)と `tools/success/success-r3-shoot.js`(大会・修行・引退)が止める:

- **下の空き**: 中身のいちばん下とボタンの列のあいだが 48px を超えたら NG(縦 390×844)
- **見せ場の数字**: `.v-num` の数字が札の真ん中から 6px 以上ずれたら NG

試合の画面(`MonsucArena` ほか・バトル部)にも同じ決まりを使う(場面=試合の場を残りの高さいっぱいに)。
