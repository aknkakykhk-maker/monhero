## 決まったこと(ユーザーの回答)

| 項目 | 決定 |
| --- | --- |
| 何でダメージを出すか | **難易度**と**判定**(ジャストマーベラスなど)と**最大コンボ数** |
| 上限 | **どんなに高くても30万** |
| ジャストマーベラスの扱い | **最大基準(1.0)**。ジャスト = MARVELOUS のうち、ズレが±20ms以内のもの |
| ジャストとふつうのマーベラスの差 | **ふつうのマーベラスは 0.95**(ジャストの95%) |
| ジャスト以外の判定の割合 | **エクセレント 0.70 / グレート 0.50 / グッド 0.25**(2026-10-06 に 0.85 / 0.65 / 0.35 から変更) |
| 物差し | 「**ジャストマーベラス1000個で100万**」は、**割合の物差しを決めるための基準**(この数字そのものが、出るダメージではない。30万の上限とは別の話として扱う) |
| 難易度の補正 | **MASTER を基準(1.0)**に、それより低い難易度は**下げる補正**を掛ける。補正の比は 200 : 240 : 280 : 320 : 340(EASY 0.589 / NORMAL 0.708 / HARD 0.822 / EXPERT 0.941 / MASTER 1.0) |
| バッド以下 | **マイナス補正**。バッド -0.15 / ミス -0.30。**合計は0で止まり、マイナスにはならない** |
| 最大コンボ | **割合ではなく、数そのものを使う**。判定の合計に **(1 + 最大コンボ数 × 係数)** を掛ける |
| 係数 | **100コンボで +5%**(= 1コンボあたり +0.05%) |
| かんたんな曲 | 同じ難易度なら、ノーツ(叩く数)が少ない曲ほどダメージが少ない(叩いた数がそのまま効く) |
| アシストモード | ダメージにならない(0) |
| 回数・送る先・演出 | 実装済みのとおり(バトルと同じ回数・同じ表・共有ライフから引く・貢献ランキングに足す) |

## 式

```
判定の合計 = max(0, Σ(判定の数 × 判定の割合))
ダメージ   = floor( 判定の合計 × MASTERのジャスト1個の基準 × 難易度の補正 × (1 + 最大コンボ数 × 0.0005) )、ただし 300,000 まで
```

- **判定の割合**: ジャスト **1.00** / マーベラス **0.95** / エクセレント **0.70** / グレート **0.50** / グッド **0.25** / バッド **-0.15** / ミス **-0.30**。
- **難易度の補正**(MASTER 基準・低い難易度ほど下げる): EASY **0.589** / NORMAL **0.708** / HARD **0.822** / EXPERT **0.941** / MASTER **1.0**。
- **MASTER のジャスト1個の基準 = 236**。公開中の曲で最大のノーツ数(MASTER 882)を全部ジャストでフルコンボしたとき、
  最大コンボの補正で増えるぶん(+44%)を見込んで、ほぼ30万になる値。曲が増えて最大が変わったら見直す。
  (「ジャスト1000個で100万」は割合の物差しの話で、基準は上のとおり30万に合わせている。ユーザー回答「基準で出しただけだから無視」)
- スコアは使わない(判定の数・ジャストの数・最大コンボ数・難易度で決まる)。

## まだ決まっていないこと(ユーザーに確認する)

1. **難易度の補正の値**(いまは 0.589 / 0.708 / 0.822 / 0.941 / 1.0。比は 200 : 240 : 280 : 320 : 340 のまま)。「マイナス補正」の下げ幅は、これで良いか。
2. **バッド・ミスの重さ**(いまは -0.15 / -0.30。「いまのまま」と回答済みだが、ほかの割合を変えたので、釣り合いを見直すか)。
3. **最大コンボの補正の効き**。100コンボで+5%だと、MASTER の最大(882コンボ)で +44%、ふつう(531コンボ)で +27%。
   これで良いか(強すぎるなら、係数を下げて基準を上げる)。
4. **曲が増えたとき**: 最大のノーツ数が変わると、30万に収まるかが変わる。基準の見直しを、新曲を足す手順に入れるか。
5. 演奏を**途中でやめたとき**は、ダメージ0・回数は戻らない(実装済みのまま)で良いか。
