## 決まったこと(ユーザーの回答)

| 項目 | 決定 |
| --- | --- |
| 何でダメージを出すか | **難易度**と**判定**(ジャストマーベラスなど)と**最大コンボ数** |
| 上限 | **どんなに高くても30万** |
| ジャストマーベラスの扱い | **最大基準(1.0)**。ジャスト = MARVELOUS のうち、ズレが±20ms以内のもの |
| ジャストとふつうのマーベラスの差 | **ふつうのマーベラスは 0.95**(ジャストの95%) |
| バッド以下 | **マイナス補正**。バッド -0.15 / ミス -0.30。**合計は0で止まり、マイナスにはならない** |
| 最大コンボ | **割合ではなく、数そのものを使う**。判定の合計に **(1 + 最大コンボ数 × 係数)** を掛ける |
| 係数 | **100コンボで +5%**(= 1コンボあたり +0.05%) |
| かんたんな曲 | 同じ難易度なら、ノーツ(叩く数)が少ない曲ほどダメージが少ない(叩いた数がそのまま効く) |
| アシストモード | ダメージにならない(0) |
| 回数・送る先・演出 | 実装済みのとおり(バトルと同じ回数・同じ表・共有ライフから引く・貢献ランキングに足す) |

## 式

```
判定の合計 = max(0, Σ(判定の数 × 難易度ごとの判定1個あたりのダメージ))
ダメージ   = floor( 判定の合計 × (1 + 最大コンボ数 × 0.0005) )、ただし 300,000 まで
```

- **判定1個あたりのダメージ = 難易度ごとの基準 × 判定の割合**。判定の割合は下の表。
- 判定の割合: **ジャスト 1.0 / マーベラス 0.95 / エクセレント 0.85 / グレート 0.65 / グッド 0.35 / バッド -0.15 / ミス -0.30**
  (ジャスト以外は、いま決めた「土台」。ユーザーが調整する)。
- スコアは使わない(判定の数・ジャストの数・最大コンボ数・難易度で決まる)。

## まだ決まっていないこと(ユーザーに確認する)

1. **難易度どうしの基準の差**(いまは 200 : 240 : 280 : 320 : 340 の比のまま)。EASY をもっと低く/高くしたいか。
2. **判定の割合**(ジャスト以外)。いまの値で良いか(例: グッド 0.35・バッド -0.15)。
3. **最大コンボの補正の効き**。100コンボで+5%だと、MASTER の最大(882コンボ)で +44%、ふつう(531コンボ)で +27%。
   これで良いか(強すぎるなら、係数を下げて基準を上げる)。
4. **曲が増えたとき**: 最大のノーツ数が変わると、30万に収まるかが変わる。基準の見直しを、新曲を足す手順に入れるか。
5. 演奏を**途中でやめたとき**は、ダメージ0・回数は戻らない(実装済みのまま)で良いか。
