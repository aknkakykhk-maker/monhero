## 式

```
判定の合計 = max(0, Σ(判定の数 × 判定の割合))
ダメージ   = floor( 判定の合計 × 1000(MASTERのジャスト1個の基準) × 難易度の補正 × (1 + 最大コンボ数 × 0.0005) × 達成の補正 )
達成の補正 = 何もなし 0.5 / フルコンボ 0.7 / オールエクセレント 0.9 / オールマーベラス 1.0(複数あてはまるときは大きいほう)
```

- **判定の割合**: ジャスト **1.00** / マーベラス **0.95** / エクセレント **0.70** / グレート **0.50** / グッド **0.25** / バッド **-0.15** / ミス **-0.30**。
- **難易度の補正**(MASTER 基準・低い難易度ほど大きく下げる): EASY **0.25** / NORMAL **0.40** / HARD **0.55** / EXPERT **0.75** / MASTER **1.0**。
- **基準 = 1000**: MASTER でジャストを1000個叩くと、判定の合計は 1000 × 1000 = **1,000,000**。最大コンボの補正は、これに掛ける
  (1000コンボなら ×1.5 → 1,500,000)。
- **上限は、いまは設けない**(30万の上限は一旦はずしている。数字を見てから決め直す)。実装では、上限の値を1か所の定数にしておき、
  「なし」と「決めた値」を切り替えられるようにする。
- スコアは使わない(判定の数・ジャストの数・最大コンボ数・難易度で決まる)。

## 確認の状況(2026-10-06)

ユーザーは上の案を見て「これでおーけー」と回答した。**上限は、いまは設けない**(30万の上限は一旦はずした)まま、数字を見てから決め直す。以下は、回答の時点で残していた確認事項(今後の調整の候補)。

1. **上限**: 30万の上限を一旦はずしている。上のとおり、MASTER は、ふつうに遊んでも数十万〜60万、最大で約127万になる。上限を置くか、置くならいくつか(共有ライフとの釣り合いも見る)。
2. **難易度の補正の値**(いまは EASY 0.25 / NORMAL 0.40 / HARD 0.55 / EXPERT 0.75 / MASTER 1.0)。下げ幅は、これで良いか。
3. **バッド・ミスの重さ**(いまは -0.15 / -0.30。「いまのまま」と回答済みだが、ほかの割合を変えたので、釣り合いを見直すか)。
4. **最大コンボの補正の効き**。100コンボで+5%だと、MASTER の最大(882コンボ)で +44%、ふつう(531コンボ)で +27%。
   これで良いか(強すぎるなら、係数を下げて基準を上げる)。
5. **曲が増えたとき**: 最大のノーツ数が変わると、ダメージの最大も変わる。上限を置く場合は、見直しを新曲を足す手順に入れるか。
6. 演奏を**途中でやめたとき**は、ダメージ0・回数は戻らない(実装済みのまま)で良いか。
