## 勇者特性(スタックを貯める形)

決めごとは `src/parts/22-enemy-and-bond-entries.jsx` の `SWEET_STACK_TRAITS` から始まる区画(純関数)。
状態は `60-app.jsx` の `sweetStackRef`(`bySlot: { 'party' | '<枠>': 数 }`)。

- 上限10。**ランのあいだ持ち越す**(WAVEでは消えない)。ランの片付けは `resetTacticsJoinCatchUp` の1か所
- 既存5モードは勇者モンが持っているとき(パーティに1つ・キー `'party'`)、タクティクスは持っている子それぞれ(枠ごと)
- 貯まるのは**本人の行動だけ**(`sweetStackGainOf(ownerId, actorId, card, hit)` が ownerId と actorId の一致を見る)
- 保存はしない(ランの途中を保存していないため。新しい `mh_*` キーは作っていない)

### メロディー「メロディの手作りクッキー」

- メロディー本人が、枠を決めてカードを1枚使うたびにクッキー+1(アシストカードは数えない)
- 段階(味方全体): 2個〜 毎ターンのライフ回復+5% / 4個〜 ガッツ回復+5% / 7個〜 被ダメージ−15% / 10個 与ダメージ+15%
- タクティクスは立っているメロディーのうち、いちばん多く持っている子の数で効く

### クロミー「クロミノート」

- クロミー本人の攻撃が当たるたびに黒音符+1(固有技なら+2)
- 段階(クロミー本人の攻撃だけ): 1個ごとに与ダメージ+3% / 5個〜 会心率+10%(足し算) / 10個 与ダメージ15%の連撃が1本

### 内部の印(2026-10-08)

- 2体には本体のデータに内部の印 `collab:'sanrio'` を付けた(ユーザー指示。**画面の文言には出さない**)。判定は
  `22-enemy-and-bond-entries.jsx` の `collabOfMonster` / `isSanrioCollabSkill`(技の出自で見る)の2つだけを通す
- 「合体で受け継いだ2体の固有技を使ったら、場の本人にもクッキー・黒音符が貯まる」は**作らない**(ユーザー判断「元キャラのクッキーとか溜まっても意味なくない？」)
- 受け継いだ側で起きる固有技の効果は、ほかの継承固有技と同じく技の出自で決まる(ピンク音符の加護のクッキー+1はメロディー本人が使ったときだけ)

## タクティクスのEXスキル

定義は `32-tactics-units.jsx` の `TACTICS_EX_SKILLS.Melody` / `.Kuromy`(`stackSpend` に1個あたりの数字)。
どちらも1ラン5回・カードと併用できる・使ったターンから3ターン・スタックが1個以上あるときだけ使える(条件 `hasStack`)。
使うとスタックは0に戻る。

| | おねがい♪メロディボックス(メロディー) | 悪夢全開！メロディ・キー(クロミー) |
|---|---|---|
| 使った瞬間 | 味方全員(立っている子)のライフ 個数×5%・ガッツ 個数×4% 回復 | — |
| 効いているあいだ | 味方全員の与ダメ+個数×2%・被ダメ−個数×2% | クロミーの与ダメ+個数×4%・会心率+個数×3%、敵の被ダメ+個数×2% |
| 10個で使うと | 効果が5ターンに伸びる | クロミーの攻撃へ与ダメ30%の連撃×2 |

メロディーの「配る」とクロミーの「叩き込む」が対になる設計。メロディーは「クッキーを持ち続けて常時の支援を保つか、
全部配って一気に立て直すか」を選ぶ。
