# ジャックのストーリー台本(初稿)

確認用の文書。直したい台詞は、番号(例: 「1-5」)で伝えてください。確定したら `assistants.js` の `EVENT_REPLAYS` にデータとして移します。
設計の正本は [`RAID_BOSS_JACK.md`](RAID_BOSS_JACK.md)「ストーリーと『大王のあと』」。

## 決めごと

- 出す順番: 段階を倒したあと、全員が初めて開いたときに1本ずつ(未視聴は古い順)。回想からいつでも見返せる
- 登場: みゅあ・きき・もも・ドラ(ハロウィン・ナイトと同じ)と、**ジャック**。ジャックの台詞は爵位ごとに話し方が違う
- ぱんぷきんは別の存在(本編の小さなかぼちゃ)。ジャックは「カボチャの大王」。ここでは混ぜない
- 口調: みゅあ=明るい口語 / きき=語尾「〜でつ」 / もも=「〜だよ♡」 / ドラ=「〜だ」「〜だな」

### ジャックの話し方(爵位ごと)

| 爵位 | 話し方 | 例 |
| --- | --- | --- |
| 男爵 | 威張るが小物。「吾輩」「〜であるぞ！」。すぐ弱気になる | 「吾輩は男爵であるぞ！ ひ、ひれ伏すがよい！」 |
| 子爵 | 気取った丁寧語。「わたくし」「〜ですぞ」「〜ではありませんか」 | 「わたくしを止められるとお思いですかな？」 |
| 伯爵 | 優雅で芝居がかっている。「余」「〜かね」「フフフ」 | 「ほう、よくぞここまで。余興としては上々だ、フフフ」 |
| 公爵 | 威厳があって短い。「我」「〜である」「〜せよ」 | 「我が前にひざまずけ。夜は我のものである」 |
| 大王 | 豪快。「ワシ」「〜じゃ」「ガハハ」 | 「ガハハ！ ワシが大王じゃ！ かかってこい！」 |
| 素(最後) | 爵位を脱いだ素直な話し方。「ボク」。子どもっぽい | 「……ボク、みんなと遊びたかっただけなんだ」 |
