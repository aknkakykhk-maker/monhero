## 決めごと

- **ジャック＝ぱんぷきんが暴走した姿**。さびしさと、奪ったビートの力が暴走して、爵位が上がるたびに大きくなる。大王を倒すと、元の小さなぱんぷきんに戻る
- 第1部(10/4から配信中)は変えない。ここに書くのは、第2部から終章まで
- 解放: 第2部以降は、**段階を倒したあと**に1本ずつ(未視聴は古い順)。終章は期間終了後。回想からいつでも見返せる
- 登場: みゅあ・きき・もも・ドラ、そして**ジャック(ぱんぷきん)**
- 口調: みゅあ=明るい口語 / きき=語尾「〜でつ」 / もも=「〜だよ♡」 / ドラ=「〜だ」「〜だな」(ドラは自分を「おで」と言う)
- 既存の台本(絵本・ドラの気持ち・ビートを重ねる場面)の台詞を、できるだけ活かした
- 第1部のあとの状況: ぱんぷきんは街の音(ビート)を瓶に詰めて逃げた。みんなは「ただのいたずらじゃなさそう」と思っている
