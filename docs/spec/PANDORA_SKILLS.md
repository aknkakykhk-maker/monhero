# パンドラの技の動き(参考資料)

2026-10-02 にユーザーが送ってくれた設定資料(「パンドラ 専用技・戦闘解説 PAGE 3」)の、固有技2つの動きを書き写したもの。
**2026-10-02 に実装した**(ユーザー指示「パンドラの技モーション変更」)。

| 技(固有技の段階) | 設定資料の流れ | 動きの組み合わせ(`24-battle-fx.jsx` の `SKILL_MOTION_SETS.Pandora.unique`) |
| --- | --- | --- |
| エクリプスノヴァ(8番目・`Pandora-u7`) | ①魔力集束(白オーラ「アストラルレイ」と黒オーラ「コズミックパン」を同時に発動。光と闇を強引に融合) → ②相反爆発(反発で生じた膨大なエネルギーを一気に解放) | `skm('gather', { fx:orbit の orb ×12(紫と金の交互), over:'eclipse', burst:'star', hit:600 })`。本体が左に紫・右に金のオーラをまとって溜め、600ms で反動。敵の位置に黒い核・白い輪・白いトゲが広がる |
| ダイスキライライ(9番目・`Pandora-u8`) | ①分裂(腹部の鍵穴へ魔力を注ぎ、光と闇の二人へ分かれる) → ②手を取り合う(元へ戻ろうと互いの手を取る) → ③反発雷撃(相反する魔力が反発し、雷撃となって相手を襲う) | `skm('split', { twin:true, line:'bolt', over:'twinThunder', burst:'spark', hit:700 })`。本体が薄くなり、闇(左)と光(右)の2体が左右へ分かれ、中央で手を取り合って弾かれる。700ms に紫と金の雷が敵の位置へ交差して落ちる |

- 足した部品: 本体の動き `gather` / `split`、敵に重ねる絵 `eclipse` / `twinThunder`、分身を描く `twin: true`(`SkillFxMotion` が同じ絵を闇と光の2枚足す。CSS は `.skfx-twin--dark` / `--light`)
- 分身の左右の動きは、本体の絵の幅に対する割合(%)で書いてある(バトルの小さい枠でも図鑑の大きい絵でも、同じ見え方になる)
- 尺は `skillFxSpecOf` が決める(エクリプスノヴァ 1140ms・ダイスキライライ 1200ms。1.2秒を超えない)
- 固有技の1番目(デュアルバン)は見せ場の動き(`pandoraDualThunder`)のまま。ほかの段階は変えていない
- 見張る検査: `node tools/battle/skill-motion-check.js`(2つの技の割り当てとCSS) / `node tools/battle/attack-preview-parity-check.js`(バトルと図鑑の尺)
