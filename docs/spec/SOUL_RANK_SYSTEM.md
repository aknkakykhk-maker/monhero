# 魂格システム 正式仕様

- ステータス: **確定仕様 / 未実装**
- 基準main: `2afd6faa11c23272e897900979029055934975b4`
- 対象: マスモンの超越後育成、魂格進化、魂格P、魂格特性、勇者の証、関連UI・合体・ランキング・保存
- 正本優先順位: 実装時は最新mainを確認し、本書と現行実装が競合した場合は、ユーザーの最新指示 > 本書 > 現行コードの順に扱う
- 注意: 本書は未実装の確定仕様であり、現時点のゲーム挙動を説明する文書ではない

---

## 1. 目的

現行の超越Lv500の先に、Lv1000までの長期育成を追加する。

単純にLv上限だけを伸ばすのではなく、

- 魂格進化で100Lvずつ上限を解放する
- Lv501以降の初到達で「魂格P」を得る
- 魂格Pを個体固有の「魂格特性」に振り分ける
- Lv帯が上がるほど超越Pの獲得量も増やす
- 転生による繰り返し育成と、初到達による一度きり育成を共存させる

ことを目的とする。

---

## 2. 用語

| 用語 | 意味 |
|---|---|
| 魂格進化 | 超越後にLv上限を100ずつ解放する進化 |
| 魂格 | 魂格進化の段階。Ⅰ〜Ⅴ |
| 魂格P | Lv501以降の初到達で1Lvにつき1P得る、一度きりの個体育成ポイント |
| 魂格特性 | 魂格Pで習得・強化する個体固有の戦闘効果 |
| 勇者の証 | 魂格進化の必要素材。高難度クリアで反復入手 |
| 魂格再編の書 | 魂格特性の振り分けを全リセットし、使用済み魂格Pを未使用へ戻すアイテム |

既存の「超越」「超越P」「転生」「限界突破」「勇者特性」は別システムとして残す。
既存の勇者特性そのものを魂格特性へ置き換えたり、名称変更したりしない。

## 3. 魂格進化

### 3.1 段階

既存の超越でLv上限500になった個体が対象。

| 段階 | 進化前の必要Lv | 進化後上限 | ダイヤ | 勇者の証 |
|---|---:|---:|---:|---:|
| 魂格進化Ⅰ | 500 | 600 | 5,000,000 | 20 |
| 魂格進化Ⅱ | 600 | 700 | 10,000,000 | 30 |
| 魂格進化Ⅲ | 700 | 800 | 15,000,000 | 40 |
| 魂格進化Ⅳ | 800 | 900 | 20,000,000 | 50 |
| 魂格進化Ⅴ | 900 | 1000 | 25,000,000 | 60 |

Ⅰ〜Ⅴ合計:
- ダイヤ 75,000,000
- 勇者の証 200

### 3.2 通常の進化条件

神殿から行う。

- 現在の魂格段階に対応したLv上限まで実Lvが到達していること
- 必要ダイヤを所持していること
- 必要な勇者の証を所持していること
- 前段階を順番に解放していること

進化時にLvそのものは上がらない。

例:
- Lv500で魂格進化Ⅰ
- 進化直後もLv500
- Lv上限だけ600へ解放
- その後XPを稼いでLv501へ進む

魂格段階と解放済みLv上限は転生しても維持する。

### 3.3 神殿UI

神殿では、今の個体が次に進化できる**次の1段階だけ**を大きく表示する。

常に表示するもの:
- 現在の魂格
- 次の魂格進化
- 必要Lv
- 現在Lv / 必要Lv
- 所持ダイヤ / 必要ダイヤ
- 所持勇者の証 / 必要勇者の証
- 進化後Lv上限

条件不足でも次の条件は隠さない。

Lv上限へ到達した場合は、リザルトや育成画面で
**「魂格進化できます」**
を目立つ形で案内する。

上限到達中に獲得した余剰XPは貯めず、従来どおり切り捨てる。

## 5. 魂格P

### 5.1 獲得

Lv501以降、**その個体が初めて到達したLvごとに魂格P+1**。

- Lv500→501初回: +1
- Lv501→502初回: +1
- …
- Lv999→1000初回: +1

Lv501〜1000の総獲得可能量は**500P**。

### 5.2 再取得禁止

魂格Pは初回到達のみ。

転生や再育成で、すでに一度到達したLvへ戻っても魂格Pは増えない。

例:
- 以前Lv650まで到達済み
- 転生してLv551
- 551→650の再育成では魂格P+0
- 初めてLv651へ到達した時点から再び+1

### 5.3 保存の正本

魂格Pを「副モンから移す資産」として扱わない。

個体ごとに**魂格P対象Lvの最高初到達Lv**を保持し、
総獲得魂格Pはそこから導出する。

推奨保存項目:
- `soulRankStage`: 0〜5
- `soulPointMaxReachedLevel`: 500〜1000
- `soulTraitLevels`: 特性ID→強化段階

導出:
```text
獲得済み魂格P
= clamp(soulPointMaxReachedLevel - 500, 0, 500)

使用済み魂格P
= 魂格特性の振り分けから計算

未使用魂格P
= 獲得済み魂格P - 使用済み魂格P
```

魂格P自体を複数フィールドへ重複保存して、互いにズレる構造は作らない。

未使用魂格Pの所持上限は設けない。

### 5.4 レベルアップ表示

初到達で複数Lv上がった場合はまとめて表示する。

例:
```text
Lv500 → Lv505
魂格P +5
超越P +10
```

再到達分は魂格P表示に含めない。

## 6. Lv401以降の超越P

既存の超越Pは残す。

Lv501以降は、魂格Pとは別に**超越Pも同時獲得**する。

超越P獲得量は「現在の魂格段階」ではなく、**実際に上がったLv帯**で決める。

| 実Lv帯 | 超越P / 1Lv |
|---|---:|
| 401〜500 | 1 |
| 501〜600 | 2 |
| 601〜700 | 3 |
| 701〜800 | 4 |
| 801〜900 | 5 |
| 901〜1000 | 6 |

転生後の再育成でも、超越Pは現行同様に再取得できる。

例:
- 魂格Ⅴを維持したまま転生しLv850へ下がる
- 851〜900の再育成: 5P / Lv
- 901以降: 6P / Lv

魂格Ⅴだから低Lv帯でも6Pになる、という計算にはしない。

通常強化Pは現行どおりLv400まで。
Lv401以降へ通常強化Pを追加しない。

## 7. 転生との関係

転生では以下を維持する。

- 魂格段階
- 解放済みLv上限
- 魂格P対象の最高初到達Lv
- 未使用魂格P
- 振り分け済み魂格特性
- 既存の超越状態・超越P・超越強化

転生によるLv低下は現行仕様を維持する。

魂格Pは再取得不可、超越PはLv帯に応じて再取得可能。

### 7.1 転生オーラ廃止

現在の「転生回数で色が変わるオーラ」は廃止する。

転生回数そのもの、および「転生×N」の回数表示は残す。

オーラの表示条件・色は魂格段階だけで決める。

## 8. 合体との関係

### 8.1 基本原則

魂格Pは副モンから直接移さない。

合体後に残る**主モンの魂格段階・解放Lv上限・実際の到達Lv**を正本とする。

### 8.2 魂格継承の選択肢

副モンの魂格段階が主モンより高い場合だけ、
合体確認画面に**「魂格を引き継いで合体」**を表示する。

同じ段階以下なら魂格継承の選択肢は出さない。

通常合体も残す。

### 8.3 通常合体

魂格継承を選ばない場合:

- 主モンの魂格段階はそのまま
- 主モンのLv上限もそのまま
- 副モン側の魂格段階は引き継がない
- 副モン側の魂格P対象最高Lvは引き継がない
- 副モン側の魂格特性は引き継がない
- 上限を超える合体XPは従来どおり切り捨て

### 8.4 魂格を引き継いで合体

副モンの方が上位魂格の場合、
主モンが足りない魂格進化段階の**通常進化コストをすべて合算して支払う**。

例:
- 主: 魂格Ⅱ
- 副: 魂格Ⅳ

必要:
- 魂格進化Ⅲ: 15,000,000 + 勇者の証40
- 魂格進化Ⅳ: 20,000,000 + 勇者の証50
- 合計: **35,000,000ダイヤ + 勇者の証90**

魂格継承合体は、通常の神殿進化と違い、
副モンがその魂格段階を持つことを根拠に主モンへ上限を継承するため、
主モンが途中の通常進化必要Lvへ現在到達していなくても選択可能とする。

支払い後:
1. 主モンの魂格段階を副モン側の高い段階まで解放
2. 主モンのLv上限を更新
3. 従来どおり副モンの合体XPを主へ加算
4. その結果、主モンが自身の過去最高初到達Lvを超えた分だけ魂格Pを新規獲得

副モンが持っていた魂格P数や最高到達Lvそのものをコピーしない。

### 8.5 主モンの既存振り分け

魂格継承合体をしても、
主モンがすでに振っている魂格特性は維持する。

新しく実Lvが上がって得た魂格Pだけが未使用Pとして増える。

副モン側の魂格特性振り分けは持ち込まない。

### 8.6 合体確認UI

魂格継承が可能な場合、確認画面へ以下をまとめて表示する。

- 現在の魂格 → 合体後の魂格
- 現在Lv上限 → 合体後Lv上限
- 必要ダイヤ
- 必要勇者の証
- 通常合体 / 魂格継承あり の違い
- 受け取れるXPと上限超過の扱い

素材不足・保存失敗・キャンセルでは、
主副・ダイヤ・勇者の証のどれも中途半端に変更しない。

## 10. 魂格特性

### 10.1 基本ルール

魂格Ⅰになった時点で全種類を最初から解放する。

魂格Ⅱ〜Ⅴで特性の種類を追加解放しない。

- 個体固有の育成
- 勇者モンでも供モンでも、実際にバトルへ参加中の個体だけ発動
- 編成外の所持個体は発動しない
- 複数種類へ自由に振り分け可能
- 1種類への極振りも可能
- %系は原則1段階ごとに+1%
- pt系確率は1段階ごとに+1pt
- 基本的に特性単体の任意上限は設けない
- ただし会心100%、特殊防御75%、カード5枚などゲームシステム側の物理上限は守る
- ライフ・ちから・丈夫さ・最大ガッツの直接上昇特性は作らない

## 11. 攻撃系魂格特性の計算

### 11.1 個体単位

攻撃系魂格特性は、**その特性を持つ本人の攻撃だけ**へ適用する。

パーティ4体の闘魂を足して全員の火力へ配る、という扱いにはしない。

### 11.2 対象

- 闘魂: 本人のカード・攻撃行動から生じる攻撃ダメージ全般
- 奥義: 本人が使用した固有技カードから生じるダメージ
- 武技: 本人が使用した通常技 / 距離技カードから生じるダメージ
- 距離の極意: 本人の攻撃が割り当てられた零 / 近 / 中 / 遠のスロットに応じて適用
- 連撃強化: メインヒット以外の連撃・追撃ダメージに適用

反射ダメージは本人の攻撃カード由来ではないため、闘魂等の攻撃魂格では増やさない。

### 11.3 連撃強化

既存の `comboDmgPct` に+1%ずつ足す方式にはしない。

`comboDmgPct` はヒットごとの元割合自体を増やし、
多段キャラほど効果量が膨らむため、魂格特性の+1%と意味が変わる。

魂格の「連撃強化」は別枠の**最終連撃ダメージ倍率**として扱う。

例:
```text
既存処理で連撃ヒットを計算
→ 会心等を既存どおり解決
→ 魂格 連撃強化倍率を適用
```

1%なら、その本人の連撃・追撃の最終合計が約1%増える意味を維持する。

### 11.4 会心

現行の会心判定方式をそのまま使う。

- メインヒットと各連撃は現在どおり独立会心判定
- 会心眼は本人の既存会心率へ+1pt
- 会心極は本人の既存会心ダメージ補正へ+1%

会心率は実効100%を超えて意味がないため、
UIのMAXは100%を超える無駄振りを選ばない。

## 12. 防御系の合成

### 12.1 鉄壁

複数個体の被ダメ軽減は加算せず、**残りダメージへ乗算**する。

各軽減率を `r1, r2, ...` とした場合:

```text
最終被ダメ倍率 = Π(1 - ri)
最終軽減率 = 1 - 最終被ダメ倍率
```

既存のモッチー / ミタラシ等の被ダメ軽減も同じ考えで合成する。

例:
- 25%軽減×4体
- `1 - 0.75^4 ≒ 68.36%`

既存20%軽減も同時なら:
- `1 - 0.8 * 0.75^4 ≒ 74.68%`

### 12.2 回避・反射・吸収の統一特殊防御

現行の
反射 → 吸収 → 回避
という別々の独立判定は、魂格導入時に統一する。

#### 同種の合成

回避E、反射R、吸収Aは、
それぞれ同種の全ソースを乗算合成する。

同種確率 `p1,p2,...`:

```text
合成確率 = 1 - Π(1 - pi)
```

ここへ既存勇者特性も含める。

#### 特殊防御の発動率

```text
特殊防御発動率 = min(75%, max(E, R, A))
```

絶対上限は75%。

#### 発動したときの結果

特殊防御が発動したら、
E:R:A の比率で結果を1つ選ぶ。

```text
回避の比率 = E / (E + R + A)
反射の比率 = R / (E + R + A)
吸収の比率 = A / (E + R + A)
```

例:
- E=50%
- R=30%
- A=20%

なら
- 特殊防御発動率50%
- 発動時の内訳 50:30:20

特殊防御が発動しなかった場合だけ、通常の被弾処理へ進む。

回避・反射・吸収以外の既存防御ルールやガードは、
この3種統合以外では勝手に変更しない。

#### 各結果

回避:
- 受けるダメージ0
- 追加効果なし

反射:
- 受けるダメージ0
- 本来受けるはずだったダメージと同値を敵へ返す
- 魂格の攻撃ダメージ補正は反射へ乗せない

吸収:
- 受けるダメージ0
- 本来受けるはずだったダメージ分ライフ回復
- 現行吸収と同じくガッツ+10%

### 12.3 威圧

威圧は特殊防御へ含めない。

敵が行動する前の「行動不能」判定として別に扱う。

既存スエゾー40%等と、魂格威圧を同種の乗算方式で合成する。

4体が各20%まで振り、既存スエゾー40%がある場合:
- 魂格のみ: `1 - 0.8^4 = 59.04%`
- スエゾー込み: `1 - 0.6 * 0.8^4 ≒ 75.42%`

専用75%上限は設けないが、確率は当然100%を超えない。

## 13. 自動ガッツ回復強化

高難度のマイナス補正と魂格倍率を混ぜて、
負の回復量がさらに悪化する挙動を作らない。

計算順:

1. 現行の自動回復式をそのまま計算
2. NIGHTMARE / GOD / RAGNAROK等の既存難易度補正もすべて適用
3. その結果の実回復率を0未満なら0へクランプ
4. 正の回復量にだけ魂格倍率を掛ける

```text
currentRate = 現行システムが出した最終回復率
safeRate = max(0, currentRate)

soulMultiplier = Π(1 + 各参加個体の魂格回復強化率)

finalRate = safeRate * soulMultiplier
```

例:
- 2体が+20%ずつ
- `×1.2 ×1.2 = ×1.44`

元の実回復率が0以下なら、魂格だけで正回復へ反転させない。

## 14. 省気

本人のカード消費ガッツだけを軽減する。

既存のカード基礎コスト・現在倍率・高難度ガッツ倍率等を壊さず、
最終的なコスト計算へ魂格の軽減倍率を組み込む。

途中で複数回丸めず、可能な限り既存倍率と魂格倍率をまとめて最後に丸める。

他個体のカードコストは軽減しない。

### 15.1 効果

200魂格Pで1回だけ習得。

- 魂格Ⅰ以上で「超」バッジを置換
- 転生回数でオーラ色が変わらない
- 魂格0でオーラなし
- 5画像参照が厳密な大文字小文字で一致
- 5画像が実アルファ透過
- 画像の白背景・チェッカー焼き込みなし
- reduced-motionを維持

### ランキング・保存
- ランキングは記録時の魂格ビルドを保持
- 再編後も過去記録は変わらない
- 未使用Pはランキングへ保存しない
- 旧ランキングで落ちない
- 旧セーブで落ちない
- バックアップ往復で魂格情報保持
