## このゲームへの当てはめ(案・まだ決まっていない)

このゲームの技は、1種族につき**通常技9段階**(`HERO_ATK_NAMES`)と**固有技9段階**(`unique.names`)で、合わせて18。
共通技は17なので、**1つ足りない**(ユグドラシルはちょうど18あった)。

ゴースト種は「ちから」の技が4つしかないため、ユグドラシルのように技種で通常技・固有技を分けられない。
案は、17技を★と消費ガッツの順に並べて、前の9つを通常技、後ろの8つを固有技にし、足りない1つを固有技の最後に足す形。
