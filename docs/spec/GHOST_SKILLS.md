## このゲームへの当てはめ(2026-10-05 ユーザーと決めた並び)

このゲームの技は、1種族につき**通常技9段階**(`HERO_ATK_NAMES`)と**固有技9段階**(`unique.names`)で、合わせて18。
共通技は17なので、**1つ足りない**(ユグドラシルはちょうど18あった)。

- **通常技** … 「ちから」の技4つ(ピコピコハンマー・体当たり・大パンチ・コンビネーション)に、軽い「かしこさ」の技5つ
  (★1〜2のソウルビーム・ハトのおとしもの・びっくり・カード・すてきステッキ)を足し、★と消費ガッツの順に並べた
  (ユーザーの選択「ちから技を通常技に寄せる」)
- **固有技** … 残りの「かしこさ」の技8つを★と消費ガッツの順に並べ、最後に**作り足した「グランドイリュージョン」**を置いた
  (ユーザーの選択「新しい名前を作る」。手品師のゴーストの大仕掛けで締める。名前はあとで差し替えてよい)
- **スプーキー** … メルホイップと同じく同じ並びで、通常技の「カード」を「カード・クラブ」に、
  「コンビネーション」を「グリンネーション」に置き換える。スプーキーが持っていないハトのおとしもの・びっくりドクロは
  共通技のまま残す

## 勇者特性と固有技の効果(2026-10-05 ユーザーと決めた中身)

参考元の能力(上の節)を、このゲームの仕組みへ置き換えた。参考元にある移動速度・命中・回避・敵の会心・敵のガッツは
このゲームに無いので使っていない。固有技の倍率・消費ガッツは2体とも2.4倍・48の案のまま。

### 勇者特性「トリックスタート」(2体とも)

勇者モンに選んだときだけ効く。

- 各WAVEの1ターン目と、そこから**3ターンごと**に抽選する。次の3つを**それぞれ50%**で当て、当たったものを付ける
  - ちから+20%
  - 丈夫さ+20%
  - 毎ターン、最大ライフの5%を回復
- **重複あり。** すでに付いている効果がまた当たったら重なる(ちから+40%・毎ターン10%回復のように増える)。上限なし
- 重なった効果は**そのWAVEのあいだ**残る。WAVEが変わると消え、ターン数も数え直す(生命の源と同じ数え方)
- **抽選とは別に常に:** 攻撃が当たったとき、その技の消費ガッツの半分のガッツを回復する
- 参考元からの置き換え: 攻撃ステータス → ちから / 移動速度 → 丈夫さ / ガッツ回復速度 → 毎ターンのライフ回復

### ゴーストの固有技「運命のコイン」

固有技を使うたびにコインを投げる(表・裏 50%ずつ)。

| | このときの固有技 | ずっと残る効果(バトル中ずっと・出るたびに重なる・上限なし) |
|---|---|---|
| 表 | ダメージ4倍 | この子の連撃+10% |
| 裏 | ダメージ0.5倍 | 固有技の消費ガッツ+20% |

- 連撃は、ききの全体連撃と同じ仕組み(各攻撃に「元ダメージ×連撃率」の追加ヒットが1本)で、**この子の攻撃だけ**に付く
- 「バトル中ずっと」はききの全体連撃と同じく、ランが終わるまで残る

### スプーキーの固有技「運命の輪」

固有技を当てるたびに、次の6つから1つがランダムで出る(**外れなし**。ユーザー選択「攻め寄り」)。

### 固有技の倍率・モンヒロビートの能力・公開のしかた(2026-10-05 ユーザーと決めた)

- **固有技の倍率と消費ガッツ**(消費は倍率×20の決まりどおり)
