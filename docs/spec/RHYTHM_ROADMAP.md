# 音ゲー 最新ロードマップ

更新日: 2026-09-03
確認main: `abea669a18052ec2e0718515edb3a87d5838081b`（PR #1009 マージ後）

この文書は、Monster Hero 音ゲーモードの「ここから何を進めるか」を短く確認するためのロードマップ。
現行挙動・数値・保存形式は常に最新 `main` と `docs/spec/RHYTHM_MODE.md` を正本とし、この文書は開発順序と公開段階を整理する。
ユーザーが現在の会話で新しく確定した内容は本書へ反映し、未確定事項を実装時に勝手に補完しない。

## 1. 現在地

2026-09-03 時点で、正式譜面制作へ入るための基礎はかなり揃っている。

主な実装済み項目:

- 5メインレーン / 10サブレーン
- TAP / HOLD / FLICK / SLIDE
- 可変幅ノーツ
- 0.5レーン刻みSLIDE、可変幅SLIDE
- HOLD / SLIDE途中追従判定
- ポーズ / 再開 / リスタート / リザルト
- 端末内BEST保存
- 音ゲー専用オプション
  - BGM音量
  - タップ音量
  - ノーツ速度
  - ノーツサイズ
  - 判定タイミング調整
  - FAST/SLOW、判定文字、発光、演出量、振動、軽量モード等
- 数値設定の `− / ＋` ボタン操作
- 最大4体のマスモン設定
- モンスターノーツ
- 元気 / 無敵 / 我慢 / 根性
- 元気の回復量 `+500`
- モンスターノーツの枠なし・背景なし表示
- 能力発動時の「モンスター名なし・能力名のみ」表示
- 縦 / 横のレスポンシブ基盤
- プレイ画面HUDの中央上部を覆っていた黒帯の撤去

現時点では、基礎システムを増やし続けるより、実機で土台を固定して実際の譜面を完成させる段階へ移る。

## 2. 直近の優先順

### STEP 1: iPhoneで現在のプレイ土台を最終固定

最新mainをiPhone Safariでまとめて確認する。

確認対象:

- 中央上部の黒帯が消えている
- レーン / ノーツ / 判定ライン / 入力位置のズレがない
- TAP / HOLD / FLICK / SLIDEが正常
- ポーズ / 再開 / リスタート / 完走リザルトが正常
- 音ゲーオプションが保存後runtimeへ反映される
- モンスターノーツが枠なし・中央寄せで自然に見える
- 能力発動表示が能力名のみになっている
- 元気 `+500`
- 無敵 / 我慢 / 根性の効果が正常

ここで大きな問題がなければ、レーンgeometry・判定位置・入力感覚・HUDを一旦固定する。
譜面制作中に「なんとなく」で基礎を再調整しない。

### STEP 2: 60秒DEBUGで性能を一度だけ実測

`あつ杯テーマ DEBUG 60s` を総合回帰テストとして使い、iPhone実機で負荷を確認する。

確認対象:

- 通常TAP
- HOLD
- FLICK
- SLIDE
- 複合操作
- モンスターノーツ
- 長いSLIDE / 多point
- 16.7ms超フレームや明確なカクつき

問題がなければ、性能改善目的だけの追加リファクタリングは行わない。
問題が確認できた場合のみ、計測結果を根拠に対象を絞って直す。

## 3. 譜面制作ルールの追加方針

今後の正式譜面では、同時刻に横へ隣接し、見た目として1つに繋がるTAPを複数の別ノーツとして置かない。

例:

- 隣接する幅1 TAPが2個 → 幅2相当の1つの可変幅TAPとして制作
- 隣接する幅1 TAPが3個 → 幅3相当の1つの可変幅TAPとして制作
- 幅2 + 幅1が隙間なく連続する場合 → 可能なら連続範囲を1つの可変幅TAPとして制作

間に空白がある本当の同時押しは別ノーツのままにする。

この方針はruntimeで自動結合する仕様ではなく、**譜面を作るときの制作ルール**とする。
既存のデバッグ譜面を今すぐ一括修正する必要はなく、正式譜面の制作・調整時に適用する。

# 4. 先行公開する「音ゲー体験版」

正式版の完成を待たず、基礎がある程度固まった段階で、**1曲だけ遊べる音ゲー体験版を先行公開する**。

## 4.1 体験版の曲

先行公開曲は **Monster Hero** とする。

既存BGM登録:

- trackId: `monster_hero_theme`
- 表示名: `MonsterHero`
- 音源: `monster-hero/audio/bgm-monster-hero-theme.mp3`

既存音源を再利用し、体験版のために同じ音源を複製しない。

`あつ杯テーマ DEBUG 60s` は引き続き開発・総合回帰確認用とし、先行公開曲にはしない。

## 4.2 体験版の難易度

体験版では **3難易度** を遊べるようにする。

1. EASY
2. NORMAL
3. HARD

EXPERT / MASTER は体験版のプレイ対象外。
体験版UIで非表示にするか、将来難易度として非活性表示するかは現時点では未確定なので、実装時に勝手に決めない。

## 4.3 3難易度の役割

### EASY

- 初めて音ゲーへ触る人向け
- TAP中心
- HOLDは少なめ
- 激しい左右移動や複雑な同時押しを避ける
- モンスターノーツは意識して狙える位置へ置く

### NORMAL

- 標準的な遊び方を見せる
- TAP / HOLD / FLICK
- 可変幅ノーツを自然に使用
- EASYより密度・左右移動を増やす

### HARD

- 現在の音ゲーシステムの広さをある程度体験できる難易度
- TAP / HOLD / FLICK / SLIDE
- 0.5レーンや可変幅SLIDE、複合操作を必要な範囲で使用
- DEBUG譜面のような機能詰め込みではなく、曲として気持ちよく遊べることを優先する

## 5. Monster Hero 体験版譜面の制作順

### STEP 3: Monster Hero EASYを完成

最初にEASYをフル尺で完成させる。

- 曲を聴きながら拍・小節・フレーズ・キメへ合わせる
- 自動解析だけで完成扱いにしない
- 隣接同時TAPは上記の可変幅1ノーツ化ルールを適用
- モンスターノーツをフレーズと操作密度に合わせて配置
- 全尺をiPhoneで実プレイする

### STEP 4: Monster Hero NORMALを完成

EASYで確定した音取り・譜面制作ルールを土台に、HOLD / FLICK / 可変幅を増やす。

### STEP 5: Monster Hero HARDを完成

SLIDEや複合操作を追加しつつ、操作しにくいだけの配置は避ける。
「難しい」ことと「押しにくい」ことを分けて設計する。

### STEP 6: 3難易度を通しで実機調整

- 難易度差が自然か
- 同時押しに無理がないか
- モンスターノーツが攻略要素として機能するか
- LIFE / DOWN / 能力バランス
- オプションを変えたときも遊べるか
- iPhoneでカクつきや誤入力がないか

をまとめて確認する。

デバッグ画面をそのまま一般ユーザーへ公開しない。

最低限必要なもの:

- 音ゲー体験版への入口

- EASY / NORMAL / HARD の難易度選択
- 自己BEST表示

- 音ゲーオプション

- リザルト
- もう一度プレイ / 戻る導線

正式音ゲーHOMEの最終デザインをこの段階で全部完成させる必要はない。
体験版で再利用できる最小構成を先に作り、フィードバックを正式HOMEへ反映する。

# 10. 体験版後の正式版ロードマップ

### STEP 10: Monster Heroを5難易度へ拡張

体験版の3難易度を土台に、EXPERT / MASTERを制作する。

### STEP 11: 正式HOMEを完成

- 楽曲選択
- 5難易度選択
- 自己ハイスコア
- クリア / 達成状況
- オプション
- マスモン設定
- プレイ / リザルト導線

を正式版として整理する。

### STEP 12: マスモン連携の残りを検討・実装

現行設計で残っている候補:

- 曲 / BPMに合わせたマスモン演出
- 音ゲープレイでマスモンへ経験値を入れる仕組み

経験値量は本編育成バランスへ影響するため、実装前に最新mainの育成効率と比較して決める。

### STEP 13: 2曲目・3曲目の正式譜面を制作

Monster Heroで確立した譜面制作ルールを再利用し、正式曲を増やす。
各曲は公開対象にする難易度を完成させ、デバッグ譜面を正式譜面扱いにしない。

### STEP 14: 永続全国ランキング

既存設計に従い正式ランキングを実装する。
モンスターノーツ能力込みのプレイは正式攻略要素として扱い、能力使用有無で別部門には分けない方針を維持する。

### STEP 15: 正式曲3曲以上で週間システム

週間システムは**正式譜面が完成している曲が3曲以上揃ってから**進める。

想定:

- 毎週3曲
- 各曲ランキング3部門
- 週間総合1部門
- 週間ミッション
- 順位報酬
- 参加報酬
- リセット / 受取 / 同点処理

3曲揃う前に週間システムを一般公開しない。

### STEP 16: 最終仕上げ

- 演出
- SE
- コンボ演出
- マスモン演出
- 横画面
- 軽量モード
- 長時間プレイ
- 各種端末回帰
- ヘルプ / 更新履歴

### STEP 17: 音ゲー正式公開

正式公開は、必要な正式曲・HOME・ランキング・保存・実機回帰が揃ったあと、ユーザーの明示許可を受けて行う。

## 11. 公開段階の整理

| 段階 | 公開範囲 |
| --- | --- |
| 開発中 | デバッグ画面のみ |
| 先行体験版 | Monster Hero 1曲 / EASY・NORMAL・HARD |
| 正式版 | 正式HOME・5難易度・複数曲へ拡張 |
| 週間システム | 正式譜面完成曲が3曲以上揃ってから |

体験版と正式版を混同しない。
体験版の公開を、音ゲー全体の正式公開許可として扱わない。

## 12. 引き継ぎ

今後 Claude / Codex / ChatGPT で音ゲー開発を続ける場合:

1. 最新 `main` を確認する。
2. `AGENTS.md` / `DEVELOPMENT.md` / `docs/spec/RHYTHM_MODE.md` / 本書を確認する。
3. 現在実装されている事実は最新mainを優先する。
4. 未実装だが確定したロードマップは本書を参照する。
5. ユーザーのその時点の明示指示を最優先する。
6. 自動検査とiPhone実機確認を混同しない。
7. 体験版公開と正式公開を別の公開段階として扱う。
