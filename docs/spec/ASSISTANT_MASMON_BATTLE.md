## 入力と出力

```js
const catalog = ASSISTANT_MASMON_BATTLE.buildCatalog({ ALL_PLAYER_MONSTERS, HERO_ATK_NAMES,
  BASE_ATK_EVOLUTION, RANGE_EVOLUTION, GUARD_EVOLUTION });     // 技データの写し(JSON にできる)
ASSISTANT_MASMON_BATTLE.simulate({ seed, catalog, teamA, teamB, roundLimit?, trace? })
// team = { assistantId:'mua'…'erubin', tactics:0〜100(戦術経験), members:[1体, …](1〜3体) }
// 1体 = { species, name, lv:1〜99, stats:{ life, pow, wise, hit, eva, tough }(0〜999) }  ※ stats の代わりに st でもよい
// → { winner:'A'|'B'|'draw', reason:'wipe'|'judge', rounds, log:[1手ずつ], final, digest }
```

- 育成(キズナ4・`mh_assistant_masmon_grow_v1`)からは `unitFromGrow(row, amgEntryOf(…))` で1体を作る
  (row = `assistantMasmonRowsOf` の行。入れ物が無ければ行の Lv・能力は既定値 100)
- 疲労・ストレス・好き嫌い・型(攻撃型など)は**入力に取らない**(強さに効かせない)
- `trace:true` で、各手に AI が付けた点(`cands`)が記録に付く(観戦で「なぜその手か」を見せる用)

## きまり

- **距離** 零・近・中・遠(0〜3)。種で 近・中 のどちらかから始まる(「零が得意」「遠が得意」に片寄らせない)。場の2体で1つの距離を共有し、移動は1歩
- **技**(既存のデータだけ。段は Lv から 0〜8、名前と会心率に効く)

  | 技 | 元のデータ | 撃つ能力 | 届く距離 | 威力(通常=1) | ガッツ |
  | --- | --- | --- | --- | --- | --- |
  | 通常攻撃 | `BASE_ATK_EVOLUTION`・名前は `HERO_ATK_NAMES` | ちから | 零・近 | 1 | 16 |
  | 距離撃 | `RANGE_EVOLUTION` | かしこさ | 中・遠 | 距離撃÷通常(1.4〜1.18) | 20 |
  | 固有技 | `unique`(`baseMult`・`baseGuts`・`names`) | ちから・かしこさの高い方 | 距離の得意(`distAptitude`)がいちばん高い所 | `baseMult` | `baseGuts` |
  | ガード | `GUARD_EVOLUTION`(名前) | — | どこでも | 次の手番まで受けるダメージ −35〜60%(丈夫さで増える) | 0(+4) |

- その距離の得意(`distAptitude`)で威力が変わる: C=1.0、1段ごとに ±5%(0.8〜1.25)
- **命中** = 75% +(命中−回避)÷999×50% + 技の補正(通常 +5%・距離撃 −3%・固有技 −10%)+ ガッツ(撃つ前のガッツ 0→−5%・50→0・100→+5%)、15〜97%。会心は ×1.5
- **ダメージ** = 威力 ×(20 + 撃つ能力×0.6)× 距離の得意 × ガッツ(撃つ前 0→×0.9・100→×1.1)× 300÷(300 + 丈夫さ×0.9)× 0.9〜1.1
- **ライフ** = 100 + ライフ×1.5
- **ガッツ** 0〜100。始め 50・毎ラウンド +9〜11(種ごと。モンヒロバトルの基礎ガッツ `baseGuts` が大きい種ほど速い)・移動とガード +4・ためる +22・交代/倒れて出たとき最低 40
- **順番** 毎ラウンド、場の2体が1手ずつ。先に動くのは「回避 + 命中÷2 + 種の揺れ」が高い方
- **交代** 手番を使う。出てきてから自分の手番2回は交代しない(行ったり来たりを防ぐ)。倒れたら相性の良い1体が出る
- **決着** 全滅で負け。150 ラウンドで決まらなければ判定(残りライフの割合)。同じなら引き分け

## 助手の AI

候補(技・移動・ガード・ためる・交代)に点を付けて一番高いものを選ぶ。点は 期待ダメージ(命中×威力×会心)・倒しきれるか・
ガッツの節約・残りライフ・反撃の怖さ・距離の得・交代の相性 から。**性格**(§7)で重みを、**戦術経験**で読み(ゆらぎの小ささ・反撃と交代をどれだけ見るか)を変える。

| 助手 | 型 | 傾き |
| --- | --- | --- |
| みゅあ | 積極型 | 攻め↑・守り↓・大技好き |
| きき | 分析型 | 読み +15・間合い↑ |
| ももすけ | 安定型 | 守り↑・ガッツ節約↑ |
| ドラ | 大胆型 | 攻め↑↑・守り↓↓・大技↑↑・交代↓ |
| あつ | バランス型 | 全部ふつう |
| きゅうこ | 研究型 | 読み +10・間合い↑・交代↑ |
| ソラシド | 柔軟型 | 交代↑↑・間合い↑↑ |
| えるびん | 防御型 | 守り↑↑・攻め↓ |

**最低限の判断**(戦術経験 0 でも): 当たれば必ず倒せる技があれば撃つ/届かない技・ガッツの足りない技は候補に入れない/満タンでためない/続けて動くほど点を下げる。

## 端末とサーバで同じにする

- 乱数は種(文字列)から作る(`makeRng`)。計算は + − × ÷ と floor/round/min/max/sqrt だけ
- サーバ(第④段階)では、`buildCatalog` の結果を JSON にして本体と一緒に関数へ持っていく(検査①で JSON を通しても同じ結果を見ている)。
  MFバトルカードの `card-tournament-run` が `game.js` を写して持つのと同じ形
- `digest` は記録の指紋。端末の見返し(リプレイ)とサーバの結果の突き合わせに使う

## MF との対応(2026-11-11 社長「モンスターファームの計算方法を調べて参考にして」)

**数字の考え方だけを参考にした。文章・画像は写していない。** 式を解説した海外のファンの研究サイト LegendCup(legendcup.com)と
公式の取扱説明書(www.gamecity.ne.jp)は、この環境の通信で開けなかった(式は未確認)。開けたのは appmedia の MF2 の攻略ページだけで、
そこにある技の性能の表から、数字の**幅**を読み取った。

出どころ: [技を習得する方法・技一覧](https://appmedia.jp/mf2/5361316)・[モンスター図鑑](https://appmedia.jp/mf2/5370460)・
種ごとの技の表(例 [ケンタウロス種](https://appmedia.jp/mf2/5393029)・[ラッキー種](https://appmedia.jp/mf2/5393041)・[ガリ種](https://appmedia.jp/mf2/5393068))

| 項目 | MF2(appmedia の表から読み取れた幅・役割) | モンヒロの計算 |
| --- | --- | --- |
| 能力の役割 | ちから=ちから技の威力・かしこさ=かしこさ技の威力・命中=当てる・回避=避ける・丈夫さ=受けるダメージを減らす・ライフ=体力(上限999) | 同じ役割。上限999 |
| 技の種類 | 技ごとに「ちから」か「かしこさ」 | 通常攻撃=ちから・距離撃=かしこさ・固有技=高い方 |
| 距離 | 4段(超近・近・中・遠)。技ごとに届く距離 | 4段(零・近・中・遠)。技ごとに届く距離+距離の得意 |
| 消費ガッツ | 10〜55(ふつうの技 10〜30台・大技 40〜55) | 16(通常)・20(距離撃)・40〜68(固有技)=既存の技データのまま |
| 命中の補正 | −25〜+22。重い技ほど低い | +5%(通常)・−3%(距離撃)・−10%(固有技) |
| クリティカル | 5〜30 | 10〜30%(既存の `crit`。Lv の段で上がる) |
| ガッツの効き | ガッツの量が当たり・ダメージに効く(LegendCup の計算ツールの説明より・式は未確認) | 撃つ前のガッツで 命中 ±5%・ダメージ ×0.9〜1.1 |
| ガッツの回復 | 種ごとに違う(図鑑の「G回」7〜19) | 種ごとに 9〜11(既存の `baseGuts` から。差は小さめ) |
| ガッツダウン | 技ごとに 5〜45 | **入れていない**(既存の技データに無い。未実装の技・効果は足さない)。入れるなら社長に聞く |

## 集計(2026-11-11・MF を参考にしたあと・各 2000 戦)

`node tools/masmon-battle/masmon-battle-sim.js` の要点:

- 先後: A 50.7% / B 49.3%。判定 0%。3対3 の平均 22 ラウンド(最長 96)、1対1 は平均 6
- 性格の勝率(同じ編成を入れ替えて総当たり): 46〜55%(きゅうこ・ソラシド・ききがやや上、みゅあ・ももすけがやや下)
- 能力の合計が多い側: +5% → 60% / +10% → 76% / +20% → 90% / +30% → 98%
- 戦術経験 100 対 0: 56%(読みの差は効くが、能力の差ほどではない)
- 種だけの差(6能力を同じにして1対1): 36〜60%(上 アーク・クロミー・エイキ/下 プラント・ピクシー・ゴーレム。距離の得意の片寄りが大きい種が下)
- 手の内わけ(3対3): 技 63%・移動 24%・ためる 7%・交代 4%・ガード 2%

数字(ガッツ・ダメージ式・性格の重み)はどれも仮。観戦の画面を作るときに見ながら直す。
