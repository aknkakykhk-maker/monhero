# マスモンを呼ぶ・ビートLv(モンヒロビートのマルチに呼べる、自分のマスモン)

> 2026-10-07 ユーザー指示で、画面に出す名前を変えた: 「相棒」という呼び名は使わない。
> 部屋のボタンは「マスモンを呼ぶ」、育ちは「ビートLv」、券は「セッション券」(id `session_ticket`)、
> 育ち具合の画面は「M/B管理」の「マスモン一覧(モンヒロビート)」(gameState `RHYTHM_MASU_BEAT`。名前を `RHYTHM_` で始めるのは、モンヒロビートの中の画面として扱い、裏で周回しているクイックの∞をバトル画面へ切り替えないため。2026-10-07 に `MASU_BEAT` だった名前を直した)。
> これまでの「マスモン一覧」は「マスモン一覧(バトル)」。コードの名前(rhythmBuddy…・保存キー mh_rhythm_buddy_v1)は作りはじめのまま。
> 以下の本文の「相棒」は、呼んだマスモンのこと。

2026-10-07 にユーザーと詰めた仕様。実装の正本はこの文書。進み具合は末尾の「進捗」に書く。

## 1. あらまし

- モンヒロビートのマルチ(フリーマッチ・プライベートルーム)の部屋の中で「相棒を呼ぶ」を押し、
  **手持ちのマスモンから1体**を選ぶと、5人までの1枠に CPU として入る。
- 名前と見た目はそのマスモンのまま(名前・種類・染色)。自分で名前やアイコンを設定する画面は作らない。
- 呼んだ人が部屋にいるあいだは何曲でも一緒に遊ぶ。呼んだ人が抜けると相棒も抜ける(1回ぶんを使い切る)。
- **空きがあるだけ1人で何体でも**(2026-10-07・ユーザー指示「セッション券と無料枠さえ数分あればそれだけマスモン入れられる」。その前は1人1体)。1体につき無料1回か券1枚。同じマスモンは2体呼べない。フリーマッチでもプライベートルームでも呼べる。部屋は全部で5人まで。
- 報酬の人数ボーナス: 人は1人+50%のまま、呼んだマスモンは1体につき+5%(`RHYTHM_MULTI_CPU_REWARD_STEPS`)。
- 人が優先: 呼んだマスモンは並びで人のうしろ。5人を超えたら、うしろのマスモンが席をゆずって帰り、呼んだ人へ回数・券を返す(`cpuBrain.refund`)。
- フリーマッチの待ち人数・部屋さがしの人数には、呼んだマスモンを数えない(マスモンで埋まった部屋にも人が入れる)。
- 画面に出す呼び名は「相棒」。

## 2. 回数

- **マスモン全体で**1日3回は無料(朝5:00で戻る)。使い切ったら「セッション券」を1枚使う。
- セッション券(`session_ticket`・所持数は `mh_owned_items`)の入手:
  - ビートP交換所 1枚150P(`RHYTHM_EVENT_POINT_SHOP_OFFERS`)
  - ログインボーナス7日目 2枚(`LOGIN_BONUS_REWARDS`・`gameItem` 報酬)
  - デイリーコンプリート1枚 / ウィークリーコンプリート3枚 / マンスリーコンプリート10枚

## 3. 部屋の中でのふるまい

- 通信はマルチと同じ Broadcast。呼んだ人の端末が、相棒のぶんの知らせ(hb・res)も代わりに出す。
  `hb` に `cpu:1`・`owner`(呼んだ人の id)・`mb`(マスモンの種類)・`mc`(染色の色)を載せる。
  古い端末はこの項目を捨てるだけで、ふつうのメンバーとして見える。
- 待機(マッチング・選曲・準備)と結果のカードは、染色した姿(`DyedMonsterImage`)で出す。
- 相棒の `joinedAt` は呼んだ時刻(呼んだ人より必ず後)なので、部屋主にはならない。
- 選曲: 相棒の得意な曲を選ぶ(抽選は人の選んだ曲だけから引く。相棒の選曲はシャッフル画面の演出だけで、本番の曲には使わない。自分が途中でやめたライブでは相棒も育たない)。
- 準備: すぐ準備完了。難易度は呼んだ人と同じ。
- 演奏: ノーツは叩かない。呼んだ人の演奏が終わったとき(やめたときも)に、相棒のスコアを作って知らせる。
- ひとりでも始められる: 相棒と2人そろえば、フリーマッチは15秒で始まる。プライベートは「メンバー確定」が押せる。
- MVPも取れる(2026-10-07・ユーザー指示)。名前の横に CPU のしるし。
- 報酬(周回・ビートP)の人数ボーナス: はじめは人と同じ +50% だったが、何体でも呼べるようにしたとき(2026-10-07)に、1体目+30%・2体目+20%・3体目と4体目+10% にした。さらに強すぎたため、1体につき+5% にした(2026-10-07)。
- 自分の「記録」(`mh_rhythm_multi_record_v1`)には、相棒と遊んだ回もふつうに入る。
- 相棒のスコアは、既存の全国ランキング(rankings)・自己ベストへ送らない(送るのは自分の演奏だけ。今の作りのまま)。
  マスモンの順位は、別の表のマスモンランキング(§5.1)で見せる。

## 4. 成長(マスモン1体ごと)

- 育ち具合は、一度でも相棒として呼んだマスモンだけが持つ。マスモン本体の保存データには触れない。
- 合体・寄付などでいなくなったマスモンの育ち具合は残す(消さない)が、呼べない。
- バトル側の強さ(絆など)はつなげない。**種類ごとに、なりやすい性格の傾向だけ**がある。

### レベル
- 一緒にライブをするたびに経験値。難しい難易度・高いチームランクほど多め。上限 Lv.100(2026-10-07・ユーザー指示)。必要な経験値は「うまくなるデメリットは無いので早く」(同日)で1/10にした:
  Lv.50 まで約1,800(約37ライブ)、Lv.100 まで約6,500(約130ライブ。1日15ライブなら9日ほど)。
- Lv が上がるほど、うまさ(判定の良さ)が上がる。

### 曲のなじみ
- 同じ曲を一緒に遊ぶたびにたまる。5段階(星)。高いほどスコアが上がりミスが減る。
- 相棒の画面に「得意な曲」ベスト5。

### 難易度の熟練
- EASY〜MASTER ごと。よく遊ぶ難易度ほど上がる。慣れていない高い難易度ではスコアが落ちる。

### 譜面の難しさの補正(2026-10-07・ユーザー指示「曲の難易度補正」→ Lv.＋ノーツの密度)
- 相棒の育ち具合から「無理なく叩ける譜面のLv.」を決める(相棒Lv.1 で譜面Lv.14 前後、Lv.50 で Lv.39 前後、Lv.100 で Lv.54。はじめのうちほど大きく伸びる。
  よく遊んだ曲は最大 +5)。それを超えた譜面は1つごとに落ちる。下回る譜面は少しだけ楽。
- 密度(1秒あたりのノーツ数)が、Lv.の割に詰まっている譜面はさらに少し落ちる(平均は「1 + Lv.÷10」)。一発型は影響が半分。
- 難易度の種類ごとの慣れは、譜面のLv.と役目が重なるので効き目を小さくした。

### その日の調子(1体ごと。朝5:00で変わる。その日のうちは同じ)
| 調子 | 出やすさ | 効き方 |
| --- | --- | --- |
| 超ご機嫌 | 10% | 大きく上がる・ブレ小 |
| ご機嫌 | 25% | 少し上がる |
| 普通 | 35% | そのまま |
| 不機嫌 | 20% | 少し下がる |
| 超不機嫌 | 10% | 大きく下がる・ブレ大 |
- 前の日に一緒に遊んでいると、不機嫌・超不機嫌が少し出にくい。

### 性格(Lv.30 で決まる。それまでは「まだ見えない」。育つのが早くなったので、育て方が見えるだけ遊んでから決める)
2026-10-07 ユーザー指示「性格一覧に各効果を設定して」(他作品の性格一覧の画像を受け取った)で、4つから9つにした。
はじめの4つで決まっていた子は、読み込むときに置き換える(安定型→真面目・一発型→ひょうきん・粘り型→のんびり屋・職人型→インテリ。`RHYTHM_BUDDY_OLD_TRAITS`)。

| 性格(id) | なりやすい育て方(点数) | 効き目 |
| --- | --- | --- |
| ひょうきん(jester) | EXPERT・MASTER の割合 ×0.9 | ブレ大。8%で大きく当て(+0.06)、8%で大きく外す(-0.06) |
| 勇敢(brave) | 自分の叩けるLv.を超える譜面の割合 ×1.2(`hardLives`) | 叩けるLv.を超えた分の落ち方が7割 |
| 甘えん坊(clingy) | 毎日続けて呼んだいちばん長い日数÷10 ×0.9(`bestStreakDays`) | 前の日にも遊ぶとご機嫌になりやすい。3日以上あくと不機嫌になりやすい(調子の出やすさの表を差し替え) |
| インテリ(smart) | 遊んだ曲の種類÷ライブ数×1.5 ×0.8 | 曲の得意が1.5倍の速さでたまる |
| 真面目(serious) | EASY〜HARD の割合 ×0.8 | ブレ小。調子の効き目が半分 |
| プライドが高い(proud) | 人3人以上の部屋の割合 ×1.1(`crowdLives`) | 部屋の人(呼んだマスモンを除く)1人ふえるごとに +0.012(上限+0.04)。ひとりだと -0.01 |
| 心配性(worrier) | 調子の悪い日に遊んだ割合 ×2(`badMoodLives`) | MISS・BAD が少なく GOOD・GREAT が多い。最高判定は1割弱少ない |
| 頑固(stubborn) | いちばん遊んだ難易度の割合が6割を超えたぶん | 難易度の慣れの効き目が2倍(慣れていないとかなり落ちる) |
| のんびり屋(easygoing) | 長い曲の割合 ×1.4 | 長い曲 +0.025・短い曲 -0.01。Lv.の割に詰まった譜面は1.5倍落ちる |

- 種類ごとに出発点の傾向がある(育て方で上書きできる)。能力値のいちばん抜けたもので、丈夫さ→真面目・ちから→勇敢・ライフ→のんびり屋・ガッツ→ひょうきん。
- 決まったあとも、育て方を大きく変えればゆっくり変わる。
- 性格は上限を上げない(得意・不得意の形を変えるだけ)。

### 上限とブレ(2026-10-07・ユーザー指示「マックス100万だからそこを限界にして、うまさでブレ幅を出す」)
- 上限はその難易度の満点(MASTER なら100万)。育ちきって得意な曲なら、たまに満点も出る。
- ブレはうまくなるほど小さい(育てはじめは日によって大きく外す)。性格・調子でも変わる。
- 遊んだ曲ほど得意になる(回数でなだらかに増える。インテリは速い)。
- 目安(普通の調子・MASTER Lv.26 の譜面・初めての曲): 相棒Lv.1 約62万 / Lv.25 約78万 / Lv.50 約83万 / Lv.100 約94万。
  20回遊んだ曲ならそれぞれ +3〜6万。Lv.75 を超えると、よく遊んだ曲でときどき満点、Lv.100 では半分ほど満点。
- うまくなるデメリットは無いので、はじめのうちから早く伸びる(2026-10-07・ユーザー指示)。

## 5. 見せ方

- 相棒の画面(モードえらびから): マスモンの一覧(Lv・調子・性格)、1体の詳しい画面
  (Lv・経験値、調子、性格、難易度ごとの熟練、得意な曲、一緒に遊んだ回数)、今日の残り回数・セッション券の枚数。
- 結果画面: 「なじみ+1」「Lv.UP!」など。

### 5.1 マスモンランキング(2026-10-07・ユーザー指示)

- 見る場所: モードえらびの「ランキング」タイル → 下のタブ「全国ランキング」(いつもの画面)/「マスモンランキング」。
  「ランキング」はマルチの公開(`RELEASE_FLAGS.rhythmMulti`)と同じ旗で出し入れする。
- 順位は2本: 「ビートLv」(同じLvは経験値が多い方が上)と、難易度ごとの「最高スコア」(EASY〜MASTER)。上位50。
- マスモン1体が1行。**血統は関係なく、そのマスモンの名前と見た目(染色つき)で出す**(絆Lvランキングは血統の名前だが、こちらは違う)。
- 中身: Supabase の新しい表 `rhythm_buddy_ranks`(主キー `(user_name, individual_id)`・SQLは `docs/sql/rhythm-buddy-ranks/`)。
  既存の `rankings`・`bond_levels` には書かない。削除は誰にも許可しない。表が無い環境は画面に「準備中」と出し、以後は通信しない。
- 送る行(`39-rhythm-buddy-rank-api.jsx` の `rhythmBuddyRankRows`): 遊んだことのあるマスモンだけ。
  マスモンの育ち・名前・アイコン・フレームが変わったら、4秒落ち着いてから変わった行だけ上書きする(絆Lvのリアルタイム更新と同じ作り。
  最小の間隔20秒。送った行の指紋は新しいキー `mh_rhythm_buddy_rank_sync_v1` へ。送れなかった行は次の機会に送り直す)。
- 難易度ごとの最高スコアは、育ちの保存(`mh_rhythm_buddy_v1`)へ項目 `best` を足して持つ(`{ EASY:{score,songId}… }`)。
  無い人は、残っている最近のスコア(30件)から拾い直す。ここより前の最高は拾えない。
- 改名で同じ個体が2行になったら、ブリーダーID(無ければ名前)が同じものを新しい方だけ見せる。
- 検査: `node tools/mode/rhythm-buddy-rank-check.js`

### 5.2 モードえらびの並び(2026-10-07)

「ソロライブ」「フリーマッチ」「プライベート」「ランキング」の2×2のタイル。
プライベートは、押すと出るシート(「部屋をつくる」/ 合言葉を入れて「入室する」)へ移した。
ハロウィンのテーマで cyan・indigo・slate が橙に置き換わっているので、この画面の新しい色は sky・blue・violet・purple・lime・emerald・teal を使う。
