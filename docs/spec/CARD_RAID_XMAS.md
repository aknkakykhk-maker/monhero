### 1戦の決まり

- ボスは3体(仮: ジョーカー・ゴースト・ゴーレム。黒い服の子)。ボスの3体だけ**ライフに段階の倍率**をかける(レイドのボスなので1戦では倒しきりにくい)
- ルールはふだんの対戦と同じ(勝ち負けの決まりも同じ。ターンの上限は置かない)
- 考え方: 段階ごとの難易度(先読み・気まぐれ・雑さはふだんの EASY〜MASTER の表のまま)+ボスのくせ。
  くせは「贈り物を奪う」ので**手札・ガッツをいじる札をいちばん好む**(攻め 1.2・守りを残す 0.8・ガッツをためる 0.8・大技 1.0・手札/ガッツいじり 1.7・全体攻撃 1.3・弱った子を狙う 1.3)。戦術カードは持たない
- デッキ: 3体が使える札と全モンスター・ブリーダーの札から、くせで点を付けて組む(全部の弾から・守り14枚が目安・重い技8枚まで・先に「大鎌」)。段階ごとに毎回同じデッキ
- ボスは助手ではないので、助手の記録・カードのランキング・ビートP・クイック周回・ミッション・助手のひとこと・投了の印は**通らない**(保存は何も足さない)

### 与ダメージの換算(`raidXmasCardDamageOf` = `cardRaidDamage`)

```
レイドへ足すダメージ = floor( (与えたダメージ × 1点 + 倒した数 × 倒した1体 + 勝ち ? 勝ち : 0) × 段階の補正 )
```

- 与えたダメージ = ボスの3体が減ったライフの合計(倒した子の削りすぎは数えない・回復されたぶんは引かれる)
- 投了しても、それまでに与えたぶんは足す(勝ちの上乗せは付かない)。途中で閉じた(結果が出なかった)ときは 0(回数は使ったまま。ビート挑戦と同じ)
- 上限は1か所の定数(`CARD_RAID_DAMAGE.cap`。いまは無し)

### 試しの対戦の結果(仮の値・`node tools/card/card-raid-check.js --table --games 40`)

プレイヤー役はくせの無い考え方(スターターは NORMAL・組んだデッキは MASTER の読み)。人が遊ぶと、もう少し上下に散る。

| 段階 | プレイヤー役 | 勝率 | 与えたダメージ(ボスのライフ) | 換算の中央 | 下1割〜上1割 |
| --- | --- | ---: | ---: | ---: | ---: |
| 1 | スターター(3つの平均) | 6% | 26(42) | 約26万 | 13万〜37万 |
| 1 | 組んだデッキ(上手) | 10% | 29(42) | 32万 | 20万〜46万 |
| 3 | スターター(3つの平均) | 15% | 20(54) | 約29万 | 15万〜46万 |
| 3 | 組んだデッキ(上手) | 10% | 23(54) | 36万 | 25万〜53万 |
| 5 | スターター(3つの平均) | 13% | 18(63) | 約31万 | 14万〜58万 |
| 5 | 組んだデッキ(上手) | 3% | 20(63) | 32万 | 21万〜61万 |

- くらべる物: モンヒロビート挑戦(ジャックの式)は ふつうの長さの曲で 2万〜65万(難易度とフルコンボで大きく変わる)。カードは1回 **20万〜40万前後**に収まるように置いた
- 段階が上がるとボスが強く・硬くなるぶん与ダメージは減るが、段階の補正で1回の値はほぼ横ばい〜少し上がる
- 選び方の案: ①このまま / ②1点を上げてカードを得意な入口にする(例 1点 12,000 で約1.4倍) / ③段階の補正を無くして、上の段階ほど稼ぎにくくする

## つなぐ口(レイド画面 → カード → レイド)

`CardBattleScreen` に `raidChallenge` を渡すと、デッキえらびから始まる(渡すたびに新しい物にする)。

```js
raidChallenge = {
  tierIndex,                 // 0 始まり
  tierName, bossName,        // 画面に出す名前(RAID_XMAS_EVENT.name・raidXmasTierAt('a', i).name)
  onStart: async () => bool, // デッキを選んで始める直前。中で raidXmasUseTry() を呼び、ok を返す(false なら始めない)
  onResult: async (r) => ({ ok }), // 1戦が終わった直後。r = { dealt, kos, lifeMax, outcome:'win'|'lose'|'resign', tierIndex, damage, turns, ... }
                             //   中で raidXmasAddDamage({ source:'card', kind:'a', tierIndex, damage:r.damage, hitId, eventId, detail:{ won, turns, ko } })
  onClose: (why) => {},      // 結果の画面の「レイドへ戻る」・デッキえらびの「戻る」・回数が無い。中で openRaidXmasResult(res) かレイド画面へ
}
```

App の `startRaidXmasCard(tierIndex)` は、上を作って MFバトルカードの画面(`CARD_TOP`)を開くだけ。バトル部の `raidXmasUseTry` / `raidXmasAddDamage` / `openRaidXmasResult` ができたらカード部がつなぐ。
デバッグでは、MFバトルカードのトップ(デバッグから開いたとき)の「ボス1〜5」で、回数を使わず・送らずに試せる。
