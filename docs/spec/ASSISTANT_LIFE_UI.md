## 1. 型(どの画面も同じ)

```
┌ 上の帯 48px ─────────────────────┐
│ [← 戻る]        題        15:00 昼 │
│                          次に動く 16:00 │
├───────────────────────────┤
│ head(家なら「💗 次のごほうびまで あと ◯」) │
│ 場面の絵(高さは画面の3割まで)         │
│ 主なボタン(1つ)                       │
│ 中身(札・行)                          │
├ 下のタブ 56px ─────────────────────┤
│ 🏡家 │ 🗺町 │ 🤝友情 │ 🏠フレンド │ 🐾マスモン │
└───────────────────────────┘
```

| 部品 | 決まり | 部品の名前 |
| --- | --- | --- |
| 上の帯 | 高さ 48px。左「← 戻る」・まん中に題(16px)・右に時刻「15:00 昼」と「次に動く 16:00」。**時刻の話はここだけ**(帯ごと・札ごとに「あと約3時間」を書かない) | `AluTopBar` |
| 下のタブ | 5つ: 🏡 家・🗺 町・🤝 友情・🏠 フレンド・🐾 マスモン。どの画面でも同じ並び・同じ位置(町も下)。選んでいるタブは桃→橙 | `AluTabBar`・`ALU_TABS` |
| 型 | 上の帯・中身(縦に流れる)・下のタブ。器は `position:absolute; inset:0`(画面の器の中に置く) | `AluFrame` |
| 主なボタン | **1画面に1つ**。高さ 52px・幅は中身いっぱい(120px 以上)・字 16px・桃→橙 | `AluGo` |
| ほかのボタン | 白地・紺の字・高さ 44px 以上・字 13px。どれも同じ形 | `AluBtn` |
| 行 | 左に絵(44px の丸)・中に1行(13px)と注(11px)・右にボタン1つ。高さ 56px 以上 | `AluRow` |
| 札 | 地 #1e1a36・ふち #3b3566・角 14px。「次のごほうび」だけ金のふち(1画面に1つ) | `.alu-card`・`AluNextReward` |
| 小さな印 | 状態だけ(🌡 調子・予定の ◎○△)。11px | `AluCond`・`AluEase` |
| 今日の目標 | 「今日の目標 1/3」と4つ(見る・話す・贈る・誘う)の升。済んだ升は緑。下に注1行 | `AluGoalCard`(段5の `assistantLifeGoalView`) |

## 2. 字は4段だけ

| 段 | 大きさ | 使う所 |
| --- | --- | --- |
| 見出し | 16px | 上の帯の題・窓の題・札の見出し・主なボタン |
| 本文 | 13px | 行の1行・ほかのボタン・時刻 |
| 注 | 11px | 行の注・窓の「上がる物」・下のタブ・小さな印 |
| 数字 | 20px | 「あと 120」・結果の「+5」・「1/3」の1 |

- この4つのほかの大きさは使わない(10px 未満は絶対に使わない)。絵文字も同じ段に乗せる(行の絵は 20px)
- 文は言葉の途中で折らない(`.alu` に `word-break: auto-phrase`)

## 3. 窓

- 地は**不透明**(#1e1a36)。うしろは暗く透ける幕。幕を押すと閉じる
- 右上に ✕(44×44px)。下の大きい「閉じる」は置かない
- 題の下に1行「上がる物: 💗 仲良し度 · 🤝 友情」(何が上がるかをいつも書く)
- 説明は「?」に畳む(押すと開く)。黄色い「分かった」の札は使わない
- 縦は下からの1枚(幅いっぱい)、PC・横は真ん中の1枚(幅 560px まで)
- 選ぶだけの窓(行ごとにボタン)は主なボタンが無くてよい。置くなら1つ

部品: `AluSheet({ title, gain, help, onClose })`

## 4. 結果の1枚

見る・話す・贈る・誘うの**後に必ず出す**。形は窓と同じ。

1. 何が起きたか1行(13px)
2. 上がった物を数字の札で(`💗 仲良し度 +5`・`🤝 友情 +3`。数字は 20px)
3. 拾い物があれば1行(「🧺 拾い物: 星のかけら」)
4. 「次にすること」を主なボタン1つで(例「💬 あつと話す」)

部品: `AluResult({ title, line, gains:[{ icon, label, v }], finds, next:{ label, onClick } })`

## 5. 大きさごとの形

| 大きさ | 形 |
| --- | --- |
| 縦(390×844)・幅320(320×568) | 1段。head → 場面の絵(画面の高さの3割まで・140px 以上)→ 主なボタン → 中身。小さい画面でも主なボタンが最初から見える |
| 横(844×390)・PC(1280×800) | 2段組。左に場面の絵(残りの高さいっぱい)、右に head → 主なボタン → 中身(幅 560px まで)。真ん中に細く寄せない |

- 2段組かどうかは**器の幅**で決める(幅 700px 以上で、横長)。🔄横で回した中でも器の大きさで決まる
- 下の空きは画面の20%まで(中身が少ない画面は、畳んである物を開いたまま出してよい)

## 6. 機械の見張り(`tools/assistant/life-ui-shoot.js`)

見本 `AssistantLifeUiSample`(家・窓・結果の1枚)を 縦・幅320・横・PC で撮り、次を測る。1つでも外れたら NG。

| # | 測る物 | 基準 |
| --- | --- | --- |
| ① | 見えている字の大きさ | 11・13・16・20px だけ・10px 未満なし |
| ② | 上に見えている主なボタン | ちょうど1つ(選ぶだけの窓は1つまで)・120×44px 以上・字 13px 以上 |
| ③ | 上の帯・下のタブ | 帯は高さ 48px で上の端・タブは5つで下の端 |
| ④ | 横のはみ出し・字の切れ | 器の外に出る物・切れる字なし |
| ⑤ | 下の空き | 画面の20%まで |
| ⑥ | 窓 | 地が不透明・右上に 44px 以上の ✕ |
| ⑦ | 段組み | PC・横は2段組・縦は1段 |

段7〜 で画面を型に載せたら、その画面の撮影(`tools/browser/visual-life-shoot.js`・`life-walkthrough.js`)にも同じ決まりを足す。

## 7. 段7〜 での使い方

```jsx
<AluFrame title="家" onBack={close} tab={tab} onTab={setTab}
  head={<AluNextReward rest={rest} text={nextText} />}
  scene={<家の絵 />}
  overlay={giftOpen ? <AluSheet …>…</AluSheet> : result ? <AluResult … /> : null}>
  <AluGo onClick={watch}>👀 見る — {a}と{b}の話</AluGo>
  <AluGoalCard />
  …
</AluFrame>
```

- 下のタブのキーは今のタブと同じ(`house`・`where`・`friends`・`visit`)に `masmon` を足した5つ
- 旧UI(`mh_assistant_life_ui_v2` が偽の人)は段13 まで今のまま
