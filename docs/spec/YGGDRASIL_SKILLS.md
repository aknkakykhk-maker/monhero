## 技ごとの動き(2026-09-29)

ユグドラシル種は、技の名前ごとに別の動きを持つ(ほかの種族は種族ごとに1つ)。
技の名前 → 型は `23-rpg-debug.jsx` の `SKILL_ATTACK_THEMES`、尺は `THEMED_ATTACK_MS`、
見た目の組み合わせは `24-battle-fx.jsx` の `SKILL_FX_SPECS`、動きは `70-bootstrap.jsx` の `.skfx-◯◯`。
バトルは技名(`hit.skillName`)を演出へ渡して型を選ぶ。デバッグ「新モンスター確認」→ 攻撃アクションで技を1つずつ再生できる。
検査: `tools/battle/skill-motion-check.js`(つながり・実ブラウザ)と `tools/battle/attack-preview-parity-check.js`(尺と技名)。

通常技(ちから)は体ごとぶつかる・飛びかかる動き、固有技(かしこさ)はその場で力をためて放つ動き。

## 能力値と勇者特性(2026-09-29 ユーザーと決めた値)

正式実装のとき `ALL_PLAYER_MONSTERS` へ入れる値。ユーザー指示「どっちもライフ、丈夫さ型」「どっちも力を丈夫さよりに」
「ユグのほうがメルホイップより丈夫さ型で、メルホイップのほうが少し攻撃型のステにして」。
間合いはユグドラシルが参考画像の適性(遠A・中E・近D・零B)、メルホイップは最初の案(零D・近C・中B・遠B)から
「ゼロを下げて中距離をAに」。供モン加算は「このバランス見て決めて」(重い型の子の加算320〜645の中ほど)。

| | ライフ | ガッツ | ちから | 丈夫さ | 合計 | 間合い(零/近/中/遠) | 供モン加算(ライフ/ガッツ/ちから/丈夫さ) |
|---|---|---|---|---|---|---|---|
| ユグドラシル | 800 | 115 | 100 | 180 | 1195 | B/D/E/A | 380/5/10/80 |
| メルホイップ | 780 | 120 | 130 | 150 | 1180 | E/C/A/B | 350/10/30/50 |

```js
// ALL_PLAYER_MONSTERS へ入れるときの形(固有技の倍率・消費・効果はまだ決まっていない)
baseHp:800, baseGuts:115, baseAtk:100, baseDef:180, plusStats:{hp:380,atk:10,def:80,guts:5},  distAptitude:['B','D','E','A'], // ユグドラシル
baseHp:780, baseGuts:120, baseAtk:130, baseDef:150, plusStats:{hp:350,atk:30,def:50,guts:10}, distAptitude:['E','C','A','B'], // メルホイップ
```

### 勇者特性「生命の源」(2体とも)

> 生命の源:勇者モン選択時:1〜5ターンの間、被ダメージ30%軽減。6ターン目以降、3ターンごとにガッツを30%回復

- ターンは **WAVEごとに1から数え直す**(中二病の回数と同じ)
- 回復するのは **最大ガッツの30%**
- 回復するのは **6・9・12・15…ターン目**(6ターン目に1回目、以後3ターンごと)
- 効き目は本体の分岐で作る(`trait` と `traitDesc` は説明文だけ)。実装先の候補は、被ダメージの軽減が
  もち肌(モッチー・ミタラシ)、ターン開始時のガッツ回復が氷海の支配者(自動ガッツ回復)の分岐の近く

### 固有技の中身(2026-09-29 決めた値・2体とも)

- 倍率 **×3.2**・消費ガッツ **64**(消費=倍率×20 の決まりどおり。ゴーレム×3.2・消費68と並ぶ重い一撃)
- 効果: **使ったターンから2ターン、被ダメージ30%軽減。さらに最大ガッツの20%を回復**
  (ユーザー指示「使ったターンから2ターン被ダメ30減、最大ガッツの20%回復」)
- `effectDesc` の案: `"大樹の加護：使ったターンから2ターン、被ダメージ30%軽減＋最大ガッツの20%回復"`(名前は仮)
- 撃てる早さ: 開始ガッツは最大の半分なので、ユグドラシル(最大115・開始57)は3ターン目ごろ、
  メルホイップ(最大120・開始60)は2ターン目ごろに初めて撃てる
- 被ダメージの軽減はほかの軽減と**掛け算で重なる**(`applyTurnDamageReduction` がターンのバフを掛け合わせる作り)。
  1〜5ターン目に「生命の源」と重なると 0.7×0.7=0.49、つまり51%軽減になる

```js
unique:{ name:"スターボム", icon:YGGDRASIL_ICON, monId:"Yggdrasil", baseMult:3.2, baseGuts:64, evoLevel:0,
  names:[...draftUniqueNames], effectDesc:"大樹の加護：使ったターンから2ターン、被ダメージ30%軽減＋最大ガッツの20%回復" }
```
