# モンヒロビート iPhone実機チェックリスト

自動検査（`tools/mode/rhythm-input-scenario-check.js` など）は本番の関数を Node 上で動かして
「入力→対象ノーツ→判定」の筋道を確かめるが、**指の感触・遅延感・見えかた**は実機でしか分からない。
公開後に本番URL（`https://aknkakykhk-maker.github.io/monhero/`）で、iPhone Safari（縦画面）を主に確認する。
Android Chrome・PC Chrome も、可能なら同じ表で見る。

各項目は「○ 違和感なし / △ 気になる（何が） / × 不具合（何が）」で記録する。
△・× は、曲名・難易度・おおよその時刻（秒）を添える。

## 譜面（難易度ごと）

| # | 確認すること | 見るところ |
| --- | --- | --- |
| 1 | EASY を1曲通す | 初見で読める。TAP/HOLD中心。同時押しは左右の端。同じ形の繰り返しになっていない |
| 2 | NORMAL を1曲通す | FLICK が混ざる。EASY で見た形がそのまま出てくる |
| 3 | HARD を1曲通す | 16分・SLIDE が入る。忙しい区間は短く、あとに間がある |
| 4 | EXPERT を1曲通す | 押さえながら叩く・同時押しの連なり・端まで走る SLIDE。物量ではなく複合で難しい |
| 5 | MASTER を1曲通す | 高密度でも「押せない」と感じる場所が無い。クロス（押さえている指の外側）が取れる |
