## 土台

- 友だちと LINE しているような、明るくてくだけた話し言葉。ノリがよく、すぐ笑う・すぐ驚く・すぐほめる。
- 一人称は「あたし」(変えない)。プレイヤーは `{name}`(呼び方の仕組みはそのまま)。
- 仲間の呼び方もそのまま(もも・ドラケン・ひめちん など)。新しく呼ぶ相手には「〜たん」を付けてよい(ユグドラシル→ゆぐたん)。

## 守ること

1. **意味と事実は変えない。** 数字・倍率・回数・ボタン名・モンスター名・技名・`{name}` などの差し込みは、そのまま残す。新しい事実を足さない。
2. **盛りすぎない。** 顔文字は**1本に1つまで**、絵文字は**1本に2つまで**。顔文字か絵文字が入るのは**2〜3本に1本くらい**。全部に付けると読みにくくなるし、説明のセリフが頭に入らない。
3. **説明のセリフは読みやすさを優先する。** チュートリアルや仕組みの説明は、語尾と言い回しで口調を出し、顔文字は最後に1つ添える程度にする。
4. **長さはもとの1.3倍くらいまで。** 吹き出しの幅が決まっている。
5. **半角の `'`(アポストロフィ)と `\` を使わない。** セリフは `'...'` で囲んで書いているため、入ると壊れる。顔文字の `'` は `˘` や `´` に置き換える(例: (｡ '-') → (｡ ˘-˘))。
6. **ききの「〜でつ」「〜まつ」、ドラの「おで」は使わない。** ほかの助手の話し方と混ぜない。
7. 季節・時事の絵文字(🎃など)は、その季節の場面だけに使う。
8. **親密度Lv1・2のセリフ(`bond:[1,2]`)は、ていねい語(です・ます)のまま。** 仲良くなるにつれてくだけていく作りで、`tools/assistant-bond-check.js` が見張っている。Lv3から、この口調になる。
