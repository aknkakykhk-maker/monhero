# あつ杯テーマ EASY 耳確認プラン

基準: `atsu-cup-theme-easy-formal-candidate-v1.json` / candidate v1

この文書は、正式EASY完成前に残っている `earReviewGrids` 22点を、あとで実機確認しやすい順番へまとめた作業用プラン。

重要:

- ここでは採用・移動・不採用を決めない
- `reviewRequired:true` / `runtimeConnected:false` を維持する
- 数値監査だけで正式完成扱いにしない
- 最終判断は曲を聴き、必要ならiPhone実機で行う

## まとめ方

- BPM 169
- `beatZeroMs` 40ms
- 16分グリッド
- 近接候補の間隔が24グリッド以内なら同じ確認区間へまとめる
- 各区間は最初/最後の候補から前後8グリッド余白を取る

この条件で22点を16区間へまとめられる。

## 実機確認時の判断単位

各候補は次のどれかを耳で決める。

1. 現在のグリッドを採用
2. 近傍の16分グリッドへ移動
3. EASYでは不採用
4. TAPではなくHOLD等へ変更した方が自然なら種類変更候補として保留

判断後に正式候補v2を作る。全22点の確認と全尺プレイが終わるまでは正式runtimeへ接続しない。

## 自動検査

`node tools/mode/rhythm-easy-ear-review-plan.js`

この検査は以下を固定する。

- 現行の耳確認候補が22点
- 時刻順・重複なし
- 22点を16確認区間へまとめられる
- 各候補が対応区間内に収まる
- `reviewRequired:true`
- `runtimeConnected:false`

候補データが変わった場合は、このプランも再確認する。
