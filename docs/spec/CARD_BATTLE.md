### 1-3. モンヒロ版のルール本文

**準備**
1. モンスターカード3枚と技カード50枚でデッキを作る。同じ技カードは3枚まで。
2. 先攻・後攻はコンピューター戦では毎回ランダム、対人戦は部屋の抽選で決める。
3. 山札を切って5枚引く。後攻は始める前に、手札から**2枚まで**ガッツにできる。
4. 引き直し(マリガン)は無し(元にも無い)。★ただし「手札に自分のモンスターが使える攻撃カードが1枚も無い」ときだけ、1回引き直せる案もある(初心者向け。社長が決める)。

**ターンの流れ**(自分のターン)
1. **ドロー**: 1枚引く(先攻の1ターン目は飛ばす)。手札がすでに5枚なら、引いたカードをそのままガッツにする。
   引くカードが無ければ、そのプレイヤーの負け。
2. **ガッツ**: 手札から**1枚まで**伏せてガッツにできる。★(元で確かめられなかった所。後攻の特例が「2枚まで」なので、ふだんは1枚とした)
3. **攻撃**: 生きている自分のモンスターごとに1回、攻撃カードを使える。
   - そのモンスターが使えるカードだけ(1-4)。カードに書いたガッツを払う(新しく置いたガッツから捨て札へ)。
   - 攻撃先は、相手の生きているモンスターから選ぶ。
   - 攻撃を受けた側は、そのつど防御カードを何枚でも重ねて出せる(ガッツが足りる限り)。対人戦は15秒で打ち切り。
   - 使い終わったカードは捨て札へ。
4. **終わり**: 「ターン終了」を押す。手札の上限は5枚(ドローで超えないので捨てる場面は無い)。

**ダメージ**
- 攻撃カードに書いたダメージがそのまま入る。ライフが0以下でそのモンスターは倒れる(戻らない)。
- 防御カードは、受けたモンスターが使えるものか「全体」のものだけ。

**攻撃と守りの相性**★
| 守り | ちから | かしこさ | 特殊 |
| --- | --- | --- | --- |
| 回避(なくす) | カードに書いた種類だけ | カードに書いた種類だけ | × |
| 防御(減らす) | ○ | ○ | × |
| はね返す | カードに書いた種類だけ。ダメージをそのまま攻撃したモンスターへ返す(返されたダメージは守れない) | 同左 | × |

特殊の攻撃(ダメージが小さい代わりに、ガッツを捨てさせる・手札を1枚捨てさせる など)は守れない。

**勝ち負け**
- 相手のモンスター3体を全員倒す → 勝ち
- 相手が引くときに山札が無い → 勝ち
- 対人戦で相手が抜けた・持ち時間を3回続けて使い切った → 勝ち
- 同時に決まる(はね返しで最後の1体同士が倒れる など)ときは、ターンを持っていたほうの負け(攻めて自滅した扱い)★

**持ち時間**(対人戦): 自分のターン60秒・守り15秒。過ぎると、そのターンは終了/守りはしない。

## 2. カードの作り方

### 2-1. カードの種類

| 種類 | 色 | だれが使えるか | 中身 |
| --- | --- | --- | --- |
| モンスターカード | — | 場に置く3体 | 種族・ライフ・ちから/かしこさの得意(表示だけ)・系統 |
| 攻撃カード(技) | 赤 | **その種族だけ** | ちから/かしこさ/特殊・消費ガッツ・ダメージ・効果 |
| 固有技カード | 赤(金ふち) | その種族だけ | 種族の固有技。重い・強い・効果つき |
| 防御カード(系統) | 青 | **その系統のモンスター** | 回避・防御・はね返す |
| 防御カード(全体) | 青 | だれでも | 回避・防御(弱め) |

- 攻撃カードを種族ごとにしたのは、同じ「もんた」でも モッチーとミタラシで強さが違うため(育てた強さを持ち込まない代わりに、**種族の強さをカードの数字に焼き込む**)。
- 防御カードの「系統」は、ゲームの血統(`data/lineages.js` の主血統)を使う。14系統:
  モッチー系(モッチー・ミタラシ・剣士モッチー)/ピクシー系(ピクシー・ミーア・パンドラ)/
  ウンディーネ系(ウンディーネ・スネグーラチカ・ヤオビクニ)/ユグドラシル系(ユグドラシル・メルホイップ・メロディー・クロミー)/
  プラント系(プラント・オボロゲソウ)/アーク系(アーク・イブリース)/ザン系(ザン・エイキ)/ゴースト系(ゴースト・スプーキー)/
  イルミネ系(イルミネ・ドリーミィ)/スエゾー/ゴーレム/ライガー/ハム/モノリス(1種の系統)。

### 2-2. モンスターカードの式

ゲームの基礎値(`ALL_PLAYER_MONSTERS` の `baseHp`・`baseDef`・`baseAtk`・`baseGuts`)から作る。供モン加算・個体差・育成は入れない。

- **ライフ** = 10の位に丸め( 150 + ライフ × 0.25 + 丈夫さ × 0.5 )
  丈夫さをライフへ足したのは、元のカードに「丈夫さ」の欄が無く、硬さはライフで表すため。
- **ちから係数** = ちから ÷ 135(0.75〜1.35 に収める)
- **かしこさ係数** = ガッツ ÷ 135(0.75〜1.35 に収める)
  モンヒロには「かしこさ」が無いので、ガッツの多さで代える(ピクシー・ミーア・ウンディーネのように魔法らしい子ほどガッツが多いので、見た目とも合う)。

### 2-3. 攻撃カードの式

各種族の9つの技(`HERO_ATK_NAMES`)を、並びの順(弱い→強い)にそのまま1枚ずつカードにする。

| 段(技の並び) | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 | 固有技 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 消費ガッツ | 1 | 1 | 2 | 2 | 3 | 3 | 4 | 4 | 5 | 6(ゲームの消費が60以上の種族は7) |
| 基本ダメージ | 20 | 25 | 30 | 35 | 45 | 50 | 60 | 65 | 75 | 60 + 15 × 固有技の倍率 |
| レア度 | C | C | C | C | UC | UC | UC | R | R | SR |

- **ダメージ** = 5の位に丸め( 基本ダメージ × 係数 )。係数は、ちからの技ならちから係数、かしこさの技ならかしこさ係数。
  固有技は2つの係数の大きいほう。
- **ちから/かしこさ/特殊の分け方**: 技の名前と、元のゲームの技種(ユグドラシル種などは仕様書に元の技種がある)で1つずつ決める。
  例: 「レイ」「サンダー」「アイスアロー」はかしこさ、「パンチ」「たいあたり」はちから、「びっくり」「おなら」「なげキッス」は特殊。
  28種×9技=252枚の分け表は、実装の最初に表(画像)にして社長に見せる。
- **特殊**: ダメージは基本ダメージの半分。代わりに効果1つ(相手のガッツを1〜2捨て札へ/相手の手札をランダムに1枚捨て札へ/自分が1枚引く/次の相手ターン、相手の1体は攻撃できない)。
- **固有技の効果**: 勇者特性・固有効果を1文に縮めたもの。例: ゴーレム「合掌」=次の自分のターンのはじめ、山札の上1枚をガッツにする(闘志)/ハム「おなら」=当たった相手は次のターン防御カードを使えない/ゴースト「連続カード」=当たったらもう1回、同じダメージの半分。
- **同じ名前の技**(プラントとオボロゲソウの「ビンタ」など)は、別のカード(数字も違う)。カードには種族名を小さく入れる。

### 2-5. 防御カードの式

| 種類 | 消費ガッツ | 中身 | レア度 |
| --- | --- | --- | --- |
| 全体・防御 | 1 | ダメージ −20 | C |
| 全体・回避 | 3 | ちから(または、かしこさ)の攻撃をなくす | UC |
| 系統・防御 | 1 | ダメージ −30 | C |
| 系統・回避 | 2 | ちから(または、かしこさ)の攻撃をなくす | UC |
| 系統・はね返す | 3 | ちから(または、かしこさ)の攻撃をそのまま返す | R |

- 系統ごとに防御・回避・はね返すを1枚ずつ(14系統×3=42枚)。ちから・かしこさのどちらを守るかは、その系統の得意な間合いと技の色で決める
  (ピクシー系の回避は「かしこさ」、ゴーレムの回避は「ちから」など)。
- 名前は系統の雰囲気から作る(「もちもちガード」「ひらりステップ」など)。元のカードの名前(カウンター・魔法反射 など)は使わない。

### 2-6. カードの見た目

**並べ方は、元のカードの配置を参考にする**(2026-10-24 社長が元のカードの画面写しを見せてくれた。窓口から)。
元のゲームの絵・名前・ロゴは使わない。立ち絵と技の絵はモンヒロのものから作る。

**モンスターカード**
```
┌───────────────────┐
│               (系)│ ← 右上: 丸い印(元は「地上」などのタイプ)。モンヒロ版は系統の印(例「モチ」)
│                   │
│   立ち絵(大きく)  │ ← 真ん中: ゲームの立ち絵
│                   │
│モッチー      400  │ ← 左下: 名前 / 右下: ライフの数字(大きく)
│No.001             │ ← カード番号
└───────────────────┘
  枠の色で系統が見分けられる(モッチー系=桜色・ピクシー系=紫 など14色)
```

**技カード**
```
┌───────────────────┐
│ちから 45  ガッチャー│ ← 左上: 技の種類(ちから/かしこさ/特殊)とダメージの数字 / 上: 技名
│                   │
│     技の絵        │ ← 真ん中: その技の攻撃の動き(ゲームの技アクション)を1こま切り出した絵
│                   │
│   モッチー        │ ← 絵の下: 使えるモンスターの名前(防御カードは系統名・全体)
│③  回避されても    │ ← 左下: 消費ガッツの数字 / 右下: 効果の文
│   半分のダメージ  │
└───────────────────┘
  赤い枠(攻撃)/青い枠(防御)。R 以上は金色の枠。SR(固有技)は金の枠に光
```

- 効果の文は短く1〜2行(例「回避されても半分のダメージ」「回避されなかったら自分も10ダメージ」)。
  こうした「当たり方で変わる効果」も、段5以上の攻撃カードに少しずつ入れる(2-3 の特殊の効果とは別)。
- 技の絵は、技ごとの攻撃アクション(`SKILL_ATTACK_THEMES` など、すでに動きのある技)から1こまを画像に書き出して使う。
  動きの無い技は、顔アイコン＋技の色の背景で代える。書き出した絵は `images/CLAUDE.md` どおり軽くしてから入れる。
- 枠・数字・文字は CSS で組む(カードごとの画像は作らない)。画像ファイルが増えるのは技の絵の切り出しだけ。
- 番号は「モンスター → その子の技 段1〜9 → 固有技 → 系統の防御 → 全体」の順に振る(図鑑の並びと同じ)。

## 4. パックと専用通貨

### 4-1. 専用通貨

名前の案(社長が選ぶ): **「カードコイン」**(推し・意味がすぐ分かる) / 「バトルメダル」 / 「ガッツコイン」。
以下「コイン」と書く。ほかの通貨(ダイヤ・ブリーダーP・ビートP)とは交換しない(カードバトルの中だけで回す)。

| 手に入り方 | コイン |
| --- | --- |
| はじめて遊んだとき(スターターといっしょに) | 300(パック3つぶん) |
| CPU戦 勝ち(よわい/ふつう/つよい) | 30 / 45 / 60 |
| CPU戦 負け | 10 |
| 対人戦 勝ち | 60 |
| 対人戦 負け(最後まで戦った) | 20 |
| 対人戦 途中で抜けた | 0 |
| その日はじめての勝ち(CPU・対人どちらでも) | +50 |
| 4枚目以降のだぶったカード(自動でコインへ) | C 5 / UC 10 / R 30 / SR 80 / モンスター 50 |

CPU戦のコインは1日 600 まで(放置で増やしすぎない)。対人戦は上限なし。
目安: CPU「ふつう」で勝ち2回+その日の初勝利で、だいたいパック1〜2つ。

### 4-2. パックの種類と値段

1パック **8枚・100コイン**(5パックまとめて 450)。

| パック | 出る種族 | いつ |
| --- | --- | --- |
| はじまりのパック | 公開中の全種族 | いつも |
| もりのめぐみパック | ユグドラシル系・プラント系・モッチー系・モノリス | いつも(テーマパック) |
| まほうのひかりパック | ピクシー系・ウンディーネ系・アーク系・スエゾー | いつも |
| つわものパック | ゴーレム・ライガー・ザン系・ハム | いつも |
| よるのかげパック | ゴースト系・イルミネ系 | イルミネ・ドリーミィの公開後 |

(パックの名前は仮。テーマパックは「その系統の防御カードも出る」ので、デッキの系統をそろえたい人が買う)

### 4-3. 中身の出方(1パック8枚)

| 枠 | 枚数 | 出るもの |
| --- | --- | --- |
| C 枠 | 5 | C(攻撃 段1〜4・防御) |
| UC 枠 | 2 | UC(攻撃 段5〜7・回避) |
| レア枠 | 1 | R 72% / モンスターカード 18% / SR(固有技) 10% |

- **天井**: SR が出ないまま10パック開けたら、11パック目のレア枠は SR。数は新しい保存キーに持つ(6.)。
- 持っていないモンスターカードが出やすいように、モンスター枠は「まだ持っていない子」を2倍の重みで引く。
- 確率はパックの画面に「出る確率」として出す(だれでも見られる)。

## 5. 画面の流れ

```
HOME の「カードバトル」(バトルの入口のとなりに1つ。HOME の配置は home-layout-check を通す)
 └ はじめて: ルールのお話(助手が3場面で説明)→ スターターを1つ選ぶ → 練習試合(CPU よわい・手順の案内つき)
 └ カードバトルのトップ CARD_TOP
     ├ CPU と戦う   … 相手のデッキ(よわい/ふつう/つよい)を選ぶ → 対戦 CARD_BATTLE → 結果(コイン)
     ├ みんなで対戦 … フリーマッチ / 部屋をつくる / 合言葉で入る / フレンドを誘う → 対戦 → 結果
     ├ デッキ       … デッキ一覧(5つまで)→ デッキを組む CARD_DECK_EDIT
     ├ パック       … パック一覧(確率つき)→ 買う → パックを開ける CARD_PACK_OPEN
     ├ カード図鑑   … 持っている/持っていない・枚数
     └ ルール       … いつでも読める(ヘルプにも同じ節)
```

**デッキを組む**: 上にモンスター3体の枠、下に持っているカード。「使える子で絞る」「赤/青で絞る」。
50枚そろうまで「保存」はできても「対戦に使う」はできない(足りない枚数を出す)。「おまかせで組む」ボタン(3体を選ぶと残りを自動で)。

**対戦**: 上が相手・下が自分。各側に モンスター3体(ライフのバー)・ガッツの数・山札の数・捨て札。手札5枚は一番下。
攻撃は「カードを自分のモンスターへドラッグ→相手のモンスターをタップ」(タップだけでもできる)。
守りの番は画面の真ん中に「守る?」と使える青いカードだけを出し、15秒の輪を出す。
縦画面を基本にし、横画面でも崩れないようにする(既存の layout 系の検査に入れる)。

**パックを開ける**: 袋を横になでると切れる → 8枚が裏で並ぶ → タップでめくる(レア枠は最後・光る)。「全部めくる」あり。

## 6. 保存データと対人戦の作り

### 6-1. 新しい保存キー(既存の `mh_*` は1つも変えない)

| キー | 中身 | 無い・壊れているとき |
| --- | --- | --- |
| `mh_card_collection_v1` | `{ カードid: 枚数 }` | `{}`。枚数は `Number.isFinite` で確かめ 0〜99 に収める。知らない id は残す(消さない) |
| `mh_card_decks_v1` | `{ active: デッキid, decks:[{ id, name, monsters:[3], cards:[50] }] }`(5つまで) | 空。持っていないカードが入っていたら、そのデッキは「足りない」と出すだけで消さない |
| `mh_card_coin_v1` | 数(コイン) | 0。マイナス・数でない値は0 |
| `mh_card_starter_v1` | `{ kit:'A'|'B'|'C', at }` 一度きりの印 | 無ければスターター選びを出す。**ある人には二度と配らない**(二重付与を防ぐ) |
| `mh_card_pack_pity_v1` | `{ パックid: SRなしで開けた数 }` | `{}` |
| `mh_card_daily_v1` | `{ day:'YYYY-MM-DD', cpuCoin, firstWin }` | 今日の0 |
| `mh_card_record_v1` | `{ cpu:{win,lose}, pvp:{win,lose}, recent:[…30件] }` | 0 |
| `mh_card_settings_v1` | 演出の速さ・守りの自動パス など | 既定値(`normalizeCardSettings` を通す) |

- 引き継ぎ(`data/mhsave-backup.js`)は `mh_` で始まるキーをまとめて運ぶので、何もしなくても入る。
- [`SAVE_DATA.md`](SAVE_DATA.md) に8行足す。
- 既存のランキング・勇者モン・マスモン・ダイヤには一切さわらない(カードバトルの勝ち負けは、いまのランキングに入れない)。

### 6-2. 対人戦の作り(いまの「みんなで対戦」の仕組みが使える)

いまの「みんなで対戦」([`RHYTHM_MULTI.md`](RHYTHM_MULTI.md))は **Supabase Realtime の Broadcast だけ**で、表も SQL も使っていない。
カードバトルは1対1・ターン制なので、演奏より通信はずっと少なく、同じやり方がそのまま使える。

| いまの仕組み | カードバトルでの使い方 |
| --- | --- |
| 部屋のチャンネル `realtime:mhb-room-<コード>` | 別の名前 `realtime:mhc-room-<コード>`(混ざらない) |
| 受付 `realtime:mhb-lobby-free` | `realtime:mhc-lobby-free`(2人そろったら部屋へ) |
| ホスト=先に入った人 | 同じ。ホストが先攻・後攻の抽選と、山札を切る「種」を配る |
| `hb`(2秒ごと) | 同じ(名前・アイコン・フレーム・生きているか) |
| 受け取った知らせは掃除してから使う | 同じ(`cardMultiCleanMessage`) |
| フレンドの招待・合言葉 | そのまま使う([`FRIENDS.md`](FRIENDS.md)) |
| `bye` | 同じ。抜けたら相手の勝ち |

**知らせ(案)**: `ready`(使うデッキ: モンスター3体とカード50枚の id)/ `draw`(引いた枚数だけ。中身は送らない)/
`guts`(伏せた枚数)/ `atk`(使ったカード・攻めた子・狙った子)/ `def`(使ったカード。パスも)/ `end`(ターン終了)/ `chat`(定型文)/ `bye`。

- **手札は相手に送らない**。使ったカードだけ送る。ダメージは両方の端末で同じ式で計算し、食い違ったらホストの値に合わせる。
- 山札の順は自分の端末だけが知る。ズル(持っていないカードを使う)は、`ready` のデッキに無いカード・3枚を超える使い方を相手の端末がはねる。
- 対人戦の勝ち負けをランキングにするときだけ表が要る。**最初は表を作らない**(いまの対戦と同じ)。

**のちにランキングを作るときの表の案**(4段目。そのとき改めて相談):
```
card_battle_results(id, at, winner_breeder_id, loser_breeder_id, winner_deck_monsters, loser_deck_monsters, turns, end_reason)
card_battle_ratings(breeder_id 主キー, rating, wins, loses, updated_at)
```
新しい表だけで、既存の表(`rankings` など)は読みも書きもしない。
