# MFバトルカード 元のルール(社長が確かめてきたもの)

2026-10-24 に社長が送ってくれた、元の実物カードゲームのルールの整理。**設計書 `CARD_BATTLE.md` のルールはこれを正本にする。**
カード固有の効果・版の違い・細かい裁定は、カードの文と社長の決め(`docs/rules/PRESIDENT_DECISIONS.md`)で補う。

## 1. 基本構成
- 2人対戦のターン制カードゲーム。各プレイヤーはモンスター3体を使う
- 同じモンスターカードは重ねて入れられない。同じ種族の別の派生モンスターは入れてよい
- 技カード・全モンスター用カード・ブリーダーカードを合わせて50枚でデッキを組む。モンスター3枚は別枠
- 同じ名前の技カードは、原則3枚まで
- 相手のモンスター3体をすべてKOすれば勝ち

## 2. ゲーム開始
1. 互いにモンスター3体を場に出す
2. デッキをシャッフルする
3. 先攻・後攻を決める
4. 互いに手札を5枚引く
5. 後攻は、手札から最大2枚をガッツにできる
6. 先攻のターンから始める

## 3. ターンの進み方
ドロー → 攻撃(必要に応じて相手の守り) → ガッツ → ターン終了

## 4. ドロー
- 手札が5枚になるまで山札から補う。先攻の1ターン目は引かない
- 手札がすでに5枚以上なら、山札の上から1枚をそのままガッツにする
- 山札から必要な枚数を引けなければ、原則負け

## 5. 攻撃
- 各モンスターは、同じターンに原則1枚だけ攻撃用の技カードを使える。ちから技・かしこさ技・特殊技は、この1回に含まれる
- 3体がそれぞれ1枚ずつ使うことはできる。攻撃の順はプレイヤーが選ぶ。攻撃しないモンスターがいてもよい
- ガッツが足りない技は使えない。KOされたモンスターは原則技を使えない
- 同じモンスターが攻撃技を使ったあと、別の攻撃技や特殊技を続けて使うことは原則できない
- カード固有の効果があれば、その指示を確かめる

## 6. ブリーダーカード
- モンスターとは別に、ブリーダーが使うカード。原則1ターンに1枚まで。カードのコストと効果に従う

## 7. 攻撃の処理
1. 攻撃するモンスターを選ぶ 2. 技カードを選ぶ 3. ガッツを払う 4. 攻撃先を決める
5. 守る側に守りのカードを使う機会を与える 6. 防御・回避などの効果を解く 7. 最終ダメージを決める
8. 狙われたモンスターのライフを減らす 9. ライフが0以下ならKO 10. 使ったカードを捨て札にする

## 8. 防御・回避
- 守る側は、攻撃に応じた守りのカードを使える。条件を満たせば、同じターンに何枚でも使える。同じ攻撃に複数枚使ってもよい
- 守るには、使えるカードと要るガッツが必要
- 防御はダメージを減らす。回避は条件に合う攻撃をよけ、基本的にダメージを0にする
- カード固有の効果で、回避できない・追加の処理がある、などが起きることがある
- 特殊技は、原則として通常の防御・回避では守れない
- 防御や回避をしても、そのモンスターの次の自分のターンの攻撃権はなくならない

## 9. ガッツ
- 技カードを使うための共通のコスト。置いたカード1枚につき1ガッツ。手札のカードを裏向きで置く
- 技を使うときに要る枚数を払う。払ったガッツは捨て札へ。コスト0の技はガッツが無くても使える
- ガッツの枚数は相手にも見える。ガッツはモンスターごとではなく、プレイヤーごとに持つ

## 10. ガッツの番
- 攻撃のあとに行う。手札から好きな枚数をガッツにできる
- ガッツにしたカードは、ふつう技カードとして使い直せない。終わったら相手のターンへ

## 11. 技カードの種類
- ちから技・かしこさ技: 攻撃用。書かれたダメージを与える
- 特殊技: ダメージ以外の効果が中心。通常の守りでは防げない
- 防御: 相手の攻撃のダメージを減らす守りのカード
- 回避: 条件に合う攻撃をよける守りのカード
- 全体: 場に残り、続けて効果を出すカード。場全体で原則1枚だけ。新しい全体カードが出たら、前のものと置き換わる

## 12. モンスターと技の対応
- モンスターには種族がある。原則、使える種族の技だけを使える
- 派生モンスターは、MAIN 種族の攻撃・特殊技と、SUB 種族の防御・回避技を使える場合がある
- カード固有の条件や例外を優先する

## 13. KO
- ライフが0以下になったモンスターはKO。KOしたモンスターカードは裏向きにする。以後、原則技を使えない

## 14. 勝ち負け
1. 相手のモンスター3体をすべてKOする 2. 相手が必要なドローなどをできず山札切れになる 3. 相手が投了する
- 特別な同時KOなどは、個別の裁定に従う(→ 社長の決め: 攻撃した側の勝ち。台帳 #3389)

## 15. 攻撃回数の例(自分のモンスターが A・B・C)
- Aが攻撃技1を使う → できる。続けて攻撃技2 → 原則できない。攻撃技のあとに特殊技 → 原則できない
- B・Cがそれぞれ攻撃技を使う → できる
- Aが相手のターンに防御・回避を何回もする → 条件を満たせばできる
- Aが次の自分のターンにまた攻撃する → できる

## 16. 戦い方の特徴
- 攻撃の回数はモンスター単位で決まる。守りの回数は原則無制限だが、カードとガッツを使う
- ガッツを攻撃で使い切ると、相手のターンに守りにくい。ガッツをためすぎると山札が減り、山札切れの危険がある
- 同じ敵を複数の味方で集中攻撃できる。攻撃技と特殊技のどちらを使うかが大事な選び
