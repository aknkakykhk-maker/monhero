# タクティクスバトル EXスキル 暫定仕様

更新: 2026-09-23

## 0. この文書の位置づけ

タクティクスバトル専用の「EXスキル」について、ユーザーと相談して**現時点で決まった内容だけ**を記録する仮仕様書。

- 未実装。
- 未確定部分は推測で補わない。
- 今後、対象モンスター・効果・回数・名称・UI詳細などを追加・変更する前提。
- タクティクスバトル本体の現行仕様は [BATTLE_NEW_MODE_PLAN.md](BATTLE_NEW_MODE_PLAN.md) と最新コードを正本とする。
- クラシックバトル等へEXスキルを追加する仕様ではない。

## 1. EXスキル共通ルール

### 1.1 モンスター固有

- EXスキルはモンスターごとに設定する。
- 使用できる回数もモンスターごとに異なる。
- 使用回数は原則として**1ラン中の回数**として管理する。
- モンスターによっては使用回数無制限のEXも存在する。

### 1.2 通常カードとは別枠

- EXスキルは原則として通常のカード使用枚数に含めない。
- EXスキルを使用したターンでも、通常ルールの範囲内で他のカードを使用できる。
- ただしEXごとの個別ルールとして「使用したターンは他カード使用不可」などを設定できる。
- ハムや剣士モッチー等の同時使用可能枚数増加とは別枠として扱う。

### 1.3 使用UI

- タクティクスバトル中、**モンスターの距離枠をタップ**することでEXスキルの確認UIを開く。
- 距離枠をタップしただけでは即発動しない。
- 確認UIでは少なくとも以下を確認できるようにする。
  - EXスキル名
  - 効果
  - 残り使用回数 / 最大使用回数（無制限の場合はその旨）
  - 他カードとの併用可否
  - 個別の発動条件・効果時間がある場合はその内容
  - EXスキルを使用する操作
- 距離枠上で残り回数を常時表示するか等の細部は未確定。

## 2. 個別EXスキル

### 2.1 モノリス

**名称（仮）:** みんなをかばう

- 使用回数: **1ラン中3回**
- 効果時間: **発動ターン**
- 他カード: **併用可能**
- 効果:
  - そのターンの敵の攻撃をすべてモノリスへ向ける。
  - 単体攻撃だけでなく、**全体攻撃・連撃もまとめてモノリスが引き受ける**。
- 既存の攻撃種別そのものの性質は変更しない方針。
  - 例: 貫通攻撃を引き受けても、既存の「ガード無視」という性質まで消す仕様ではない。
- 全体攻撃・連撃を集約した際の各ヒットの処理順やガード消費等、実装上の詳細は実装前に現行戦闘処理と照合して確定する。

### 2.2 ゴーレム

**名称:** 捨て身

- 使用回数: **1ラン中3回**
- 効果時間: **発動したWAVE内**
- 発動ターン: **行動不可（他カード使用不可）**
- 効果:
  - 発動時のゴーレムの丈夫さを0にする。
  - **0にした丈夫さの数値の50%を、力へ加算する。**
  - 効果はそのWAVE終了まで継続する。
- WAVE終了後はEXによるステータス変更を解除し、EX発動前の育成結果を保持する。
- 効果中の再使用については、現状では実質的な意味がないが、UI上で使用不可にするか等は未確定。

例（基礎値の場合）:

- 力 220 / 丈夫さ 150
- 捨て身発動後: **力 295 / 丈夫さ 0**

※WAVE中の育成・バフ等を含め「どの時点の丈夫さを発動値として参照するか」の厳密な計算順は、実装前に現行ステータス計算と照合して確定する。

### 2.3 剣士モッチー

**名称:** ソード・コンバージョン

- 使用回数: **無制限**
- 効果時間: **永続（再度使用して切り替えるまで）**
- 発動ターン: **行動不可（他カード使用不可）**
- 効果:
  - **二刀流 ⇄ 片手持ち**を切り替える。

#### 二刀流

- 現在の剣士モッチーの通常状態。
- 現行の二刀流・ソードスキル関連効果を使用する。

#### 片手持ち

- 力の値は減らさず、そのまま維持する。
- **現在の力と同じ数値を丈夫さへ加算する。**
- 固有技自体は使用可能。
- ただし片手持ち中に固有技を使用しても、**ソードスキルの効果は発生しない**。
- 再度「ソード・コンバージョン」を使用すると二刀流へ戻る。

基礎値の場合:

- 二刀流: 力 185 / 丈夫さ 25
- 片手持ち: **力 185 / 丈夫さ 210**

※片手持ち中に停止する「二刀流」由来効果の厳密な範囲、および切替時の永続連撃成長値等の保持方法は、既存の二刀流・ソードスキル実装を確認したうえで実装前に確定する。現時点ではユーザーが明示した「片手持ち中は固有技を使ってもソードスキルの効果なし」を確定事項とする。
