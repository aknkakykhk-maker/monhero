### 1.1 どこで見られるか（動作確認の入口）

`TACTICS_EX_SKILLS_RELEASE` が false のあいだは、**デバッグ設定の「⚔️ バトルモード」から始めたタクティクス**だけに出る。

- HOME の「設定」→「ヘルプ」→ いちばん下の 💊 → 「⚔️ バトルモード」→ タクティクスバトル → タクティクスプロ
- 勇者モンを **ゴーレム / モノリス / 剣士モッチー** にすると、WAVE1 からその子の距離枠に「EX」の印が出る
- ふだんの入口（β版のタクティクスプロ）では、距離枠をタップしても何も開かない（いままでどおり）
- 練習（バトルのれんしゅう）でも出さない

> ⚠️ デバッグの「⚔️ バトルモード」から始めた戦いは、難易度を決めた時点で `debugBattle` が false へ戻る
> （ふだんの周回と同じく記録する側へ寄せる既存の作り）。入口から来たことは `debugMonsterPreviewRef`
> だけが覚えているので、EXの先行表示はそちらも見ている。**保存・スコア・ランキングの判定には使っていない。**
> STEP1 のEXは効果が無いので、使っても戦いが有利にはならない。**STEP2 で効果を入れたまま公開前に
> 先行表示する場合は、そのランをランキングへ送らない扱いを先に決めること。**

## 2. データの形

定義は `monster-hero/src/parts/32-tactics-units.jsx` の `TACTICS_EX_SKILLS`（キーはモンスターのid）。
**モンスターごとの if を本体へ書かない。** 1体足すときは、ここへ1行足すだけで画面・回数・併用が動く。

| 項目 | 意味 |
| --- | --- |
| `id` | EXスキルのid（あとから変えない） |
| `name` / `desc` | 画面に出す名前と説明 |
| `maxUses` | 1ランで使える回数 |
| `unlimited` | `true` なら回数を数えない（画面は「無制限」） |
| `withCards` | 同じターンに通常カードも使えるか。`false` なら「使ったターンは他のカードを使えない」。**書き忘れは false に倒す** |
| `duration` | `'turn'`（発動ターン）/ `'wave'`（発動WAVEの終わりまで）/ `'toggle'`（もう一度使うまで） |
| `toggleLabels` | `'toggle'` のときの呼び名 `[切り替える前, 切り替えたあと]` |
| `conditions` | 追加の使用条件。`TACTICS_EX_CONDITIONS` のキーを並べる（例 `'notActive'`＝効果中は使えない） |
| `conditionText` | 条件を詳細に出すときの文（任意） |
| `effect` | 効果の種類。`TACTICS_EX_IMPLEMENTED_EFFECTS` に入っているものだけが「実装済み」 |

いま入っている3体（効果はまだ無い）:

| モンスター | EX | 回数 | カード | 効果時間 | effect |
| --- | --- | --- | --- | --- | --- |
| モノリス（`Monol`） | みんなをかばう | ラン3回 | 併用できる | 発動ターン | `coverAll` |
| ゴーレム（`Golem`） | 捨て身 | ラン3回 | 使ったターンは不可 | 発動WAVE | `allIn` |
| 剣士モッチー（`KenshiMocchi`） | 武器チェンジ | 無制限 | 使ったターンは不可 | 再使用まで（二刀流⇄片手持ち） | `weaponChange` |

## 3. ラン中の状態

`60-app.jsx` の `tacticsExState`（ref でも持つ）。中身は純関数 `createTacticsExState` の形で、**枠（スロット）ごと**に持つ。

```
uses[slot]    = { monId, count }                           1ランで使った回数
effects[slot] = { monId, exId, duration, wave, turn, on }  いま載っている効果
lastUse[slot] = { wave, turn }                             同じ子は1ターンに1回まで
turnUsed      = { wave, turn }                             このターンにだれかがEXを使った
cardLock      = { wave, turn }                             このターンは他のカードを使えない
```

- **枠で数えてよい理由**: 配置はラン中に変わらない（倒れた子の代わりも入らない）。念のため `monId` も持ち、枠の子が違えば0回として数える
- **ランの片付けは `resetTacticsJoinCatchUp` の1か所**（ランを作り直すところが必ず通す関数）。ここで `createTacticsExState()` に戻す
- **WAVE の切り替わりでは何もしない**。回数は戻らず、効果の長さは `isTacticsExEffectActive(state, slot, monId, {wave, turn})` が**見るたびに数え直す**（`'wave'` は WAVE 番号が同じあいだだけ真）。WAVE の変わり目で消す処理を持たないので、消し忘れが起きない
- **保存はしない。** 現行のタクティクスはランの途中を保存していない（中断・再開の保存が無い）ので、それに合わせた。新しい `mh_*` キーは作っていない

## 4. 操作の流れ

1. **距離枠をタップ** → そのモンスターが EX を持っていれば詳細（`data-tactics-ex-panel`）が開く。**発動はしない**
   - カードの置き先を選んでいる途中のタップは、いままでどおりカードの置き場所の操作（EXは開かない）
2. 詳細には「モンスター名・EX名・説明・残り回数／最大（無制限なら『無制限』）・カードとの併用・効果時間・条件・いまの状態（切り替え式）・開発中」を出す
3. **「EXスキルを使用」** だけが発動の入口（`activateTacticsEx`）。使えないときは押せず、理由を1行出す
   - 倒れている（カードと同じく使えない）／回数が残っていない／このターンはもう使った／
     併用できないEXなのにカードを選んでいる／行動中・AUTO中／定義の追加条件
4. 使うと回数が減り（無制限は減らない）、バトルログへ1行残る
5. **併用できないEXを使ったターン**
   - 手札はすべて「EX使用」の理由つきで灰色になり、タップ・スワイプ・ACTION・AUTO のどれからも使えない
   - 緊急回復も押せない（行動不可）
   - ACTION の場所が **「ターンを進める」** に変わり、押すと敵の番へ進む（中身は緊急回復の「回復のあと」と同じ）
6. **併用できるEXを使ったターン** はカードをいつもどおり選べる。カードを1枚も選ばなければ「ターンを進める」で送れる

**EXはカードではない。** 1ターンに選べる枚数（`cardLimit`・👑ハム／剣士モッチーの+1）には一切数えない。

## 5. STEP2 で効果を入れるときの手順

1. 効果の中身を戦闘の計算側へ入れる。**モンスターの id ではなく、`isTacticsExEffectActive(tacticsExStateRef.current, slot, monId, {wave, turn})` を見る**
   - 攻撃の引き受け（モノリス）: 敵の攻撃の狙いを決めるところ（`tacticsIntentTargets` / `handleEnemyTurn` の新モード分岐）
   - ステータスの一時変更（ゴーレム）: 盤面の値そのものを書き換えず、読むときに上乗せする形にすると、WAVE が変わった瞬間に自然に元へ戻る（「EX発動前の育成結果を保持」を満たしやすい）
   - 戦闘スタイル切替・固有技の追加効果の無効化（剣士モッチー）: `'toggle'` の `on` を見る
2. 使った瞬間に1度だけ起こすもの（演出・ログ）があれば、`60-app.jsx` の `TACTICS_EX_ON_USE` へ **effect 名で** 足す
3. `TACTICS_EX_IMPLEMENTED_EFFECTS` へ effect 名を足す（詳細の「開発中」が消える）
4. `tools/mode/tactics-ex-skills-check.js` に効果の検査を足す
5. 3体そろったら `TACTICS_EX_SKILLS_RELEASE` を立てる。**このとき更新履歴・ヘルプ・助手の告知・画面の中の使い方案内**を同じ PR で入れる（CLAUDE.md ⑤）

### まだ決まっていないこと（仮仕様 §3 のまま）

- 距離枠へ残り回数を常時出すか（いまは小さい「EX」の印だけ）
- 演出・SE（いまはカードを選んだときと同じ音）
- ゴーレムの効果中の再使用を止めるか（止めるなら定義へ `conditions:['notActive']` を足すだけ）
- 倒れている子の効果（例: 剣士モッチーが片手持ちのまま倒れたとき）をどう扱うか
