## 2. データの形

定義は `monster-hero/src/parts/32-tactics-units.jsx` の `TACTICS_EX_SKILLS`（キーはモンスターのid）。
**モンスターごとの if を本体へ書かない。** 1体足すときは、ここへ1行足すだけで画面・回数・併用が動く。

| 項目 | 意味 |
| --- | --- |
| `id` | EXスキルのid（あとから変えない） |
| `name` / `desc` | 画面に出す名前と説明 |
| `maxUses` | 1ランで使える回数 |
| `unlimited` | `true` なら回数を数えない（画面は「無制限」） |
| `withCards` | 同じターンにその子が通常カードも使えるか。`false` なら「使ったターン、その子はカードを使えない」（ほかの子は使える）。**書き忘れは false に倒す** |
| `duration` | `'turn'`（発動ターン）/ `'wave'`（発動WAVEの終わりまで）/ `'style'`（もう一度使って選び直すまで）/ `'turns'`（使ったターンから `turns` ターン。WAVEが変わると切れる） |
| `turns` / `statRate` / `fullRecover` | `'turns'` のターン数／効いているあいだ力と丈夫さを何割上げるか／使った瞬間にライフとガッツを満タンにするか |
| `styles` / `defaultStyle` | `'style'` のときの選択肢 `[{id,label,desc}]` と、はじめのスタイル。使うたびに1つ選ぶ（いまのものは選べない） |
| `heroInitialStyle` | `true` なら、勇者モンにしたときだけ配置の画面（`PickSlotScreen`）で初期スタイルを選べる |
| `conditions` | 追加の使用条件。`TACTICS_EX_CONDITIONS` のキーを並べる（例 `'notActive'`＝効果中は使えない） |
| `conditionText` | 条件を詳細に出すときの文（任意） |
| `effect` | 効果の種類。`TACTICS_EX_IMPLEMENTED_EFFECTS` に入っているものだけが「実装済み」 |

いま入っている3体:

| モンスター | EX | 回数 | カード | 効果時間 | effect |
| --- | --- | --- | --- | --- | --- |
| モノリス（`Monol`） | みんなをかばう | ラン10回 | 併用できる | 発動ターン | `coverAll` |
| モッチー（`Mocchi`） | ガッツ全開っちー | ラン3回 | 併用できる | 使ったターンから5ターン（WAVEが変わると切れる） | `statBoost` |
| ゴーレム（`Golem`） | 捨て身 | ラン3回 | 使ったターンはその子だけ不可 | 発動WAVE | `allIn` |
| 剣士モッチー（`KenshiMocchi`） | ソード・コンバージョン | 無制限 | 使ったターンはその子だけ不可 | 再使用まで（片手剣・片手盾・二刀流の3択。既定は片手剣） | `weaponChange` |

## 3. ラン中の状態

`60-app.jsx` の `tacticsExState`（ref でも持つ）。中身は純関数 `createTacticsExState` の形で、**枠（スロット）ごと**に持つ。

```
uses[slot]    = { monId, count }                           1ランで使った回数
effects[slot] = { monId, exId, effect, duration, wave, turn, on, snapshot }  いま載っている効果（snapshot は使った瞬間の力・丈夫さ）
lastUse[slot] = { wave, turn }                             同じ子は1ターンに1回まで
turnUsed      = { wave, turn }                             このターンにだれかがEXを使った
cardLock[slot]= { wave, turn }                             このターン、その子はカードを使えない（使った子だけ）
```

- **枠で数えてよい理由**: 配置はラン中に変わらない（倒れた子の代わりも入らない）。念のため `monId` も持ち、枠の子が違えば0回として数える
- **ランの片付けは `resetTacticsJoinCatchUp` の1か所**（ランを作り直すところが必ず通す関数）。ここで `createTacticsExState()` に戻す
- **WAVE の切り替わりでは何もしない**。回数は戻らず、効果の長さは `isTacticsExEffectActive(state, slot, monId, {wave, turn})` が**見るたびに数え直す**（`'wave'` は WAVE 番号が同じあいだだけ真）。WAVE の変わり目で消す処理を持たないので、消し忘れが起きない
- **保存はしない。** 現行のタクティクスはランの途中を保存していない（中断・再開の保存が無い）ので、それに合わせた。新しい `mh_*` キーは作っていない

## 4. 操作の流れ

1. **距離枠をタップ** → そのモンスターが EX を持っていれば詳細（`data-tactics-ex-panel`）が開く。**発動はしない**
   - カードの置き先を選んでいる途中のタップは、いままでどおりカードの置き場所の操作（EXは開かない）
2. 詳細には「モンスター名・EX名・説明・残り回数／最大（無制限なら『無制限』）・カードとの併用・効果時間・条件・いまの状態（切り替え式）・いまの力／丈夫さ」を出す（効果が未実装のEXには「開発中」も出す）
3. **「EXスキルを使用」** だけが発動の入口（`activateTacticsEx`）。使えないときは押せず、理由を1行出す
   - 倒れている（カードと同じく使えない）／回数が残っていない／このターンはもう使った／
     併用できないEXなのにカードを選んでいる／行動中・AUTO中／定義の追加条件
4. 使うと回数が減り（無制限は減らない）、バトルログへ1行残る
5. **併用できないEXを使ったターン**（2026-09-23 ユーザー指示「EXで他行動禁止はそのモンスターだけ」）
   - **使った子だけ**、置ける子の一覧（`tacticsUsableSlots`）から外れる。タップ・スワイプ・枠のタップ・ACTION・AUTO のどれからもその子へは置けない
   - ほかの子はいつもどおりカードを使える。緊急回復も使える
   - 使った子しかカードを出せないカードは「EX使用」の理由つきで灰色になる
   - カードを1枚も選んでいなければ ACTION の場所が **「ターンを進める」** に変わり、押すと敵の番へ進む（中身は緊急回復の「回復のあと」と同じ）
6. **併用できるEXを使ったターン** はカードをいつもどおり選べる。カードを1枚も選ばなければ「ターンを進める」で送れる

**EXはカードではない。** 1ターンに選べる枚数（`cardLimit`・👑ハム／剣士モッチーの+1）には一切数えない。

## 5. 効果（お試しで入れた形）

効き目は戦闘の計算側で **効果の種類（`effect`）** を見て決める。モンスターのidでは分けない。

| effect | どこで効くか | 中身 |
| --- | --- | --- |
| `coverAll`（みんなをかばう） | 敵の攻撃の当たり先 `tacticsTargetsNow` → `coverTacticsTargets` | 使ったターン、狙いをモノリスへ集める。**当たる回数はそのまま**（全体攻撃で3体に当たるはずなら3回受ける）。貫通撃はガード無視のまま。回避・反射・吸収の抽選もモノリスで引く。予告の🎯・予定ダメージも同じ関数で付け替える。モノリスが倒れていたら、かばわない |
| `allIn`（捨て身） | 1体ぶんの読み取り `tacticsBattleUnit` → `applyTacticsExStats` | **使ったときの丈夫さ**（盤面の値。丈夫さ%のバフはかける前）を控え、丈夫さ0・力＋その50%。盤面の値は書き換えず読むときに乗せるので、次のWAVEで何もしなくても元に戻る。効果中は再使用不可（`conditions:['notActive']`） |
| `statBoost`（ガッツ全開っちー） | 1体ぶんの読み取り `tacticsBattleUnit` → `applyTacticsExStats`＋使った瞬間の回復 | 2026-09-25 ユーザー指示。使った瞬間に、その子のライフとガッツの上限を×(1+`statRate`)（ユニットの `exMaxRate` に入れて `scaleTacticsUnitMaxHp` 系で上限を数え直す）にしてから、上がった上限まで満タン（`fullRecover`。2026-09-25 ユーザー指示「上限も上げてさらに全回復」）。使ったターンから `turns`（5）ターンのあいだ、力と丈夫さ×(1+`statRate`)（30%・切り捨て。はじめ20%、2026-09-25 ユーザー指示で30%）。同じあいだ、ターン終わりの自動回復（`tacticsRegen`）で、その子だけ上限の `regenRate`（0.3）ぶんを `rateHealTacticsAt` で上乗せする（倍率ではなく固定値。ユーザー指示「1.3倍じゃなくて30%固定値でプラス」）（`tacticsExRegenRateAt`。倒れた子の10%の戻りには乗せない。2026-09-25 ユーザー指示「効果中ライフとガッツの自動回復を30%上昇」）。**WAVEはまたがない**（ユーザー指示「WAVE跨ぎはなし」。`duration:'turns'` は同じWAVEの中だけ数える）。効果が切れたら `expireTacticsExMaxRates` が `exMaxRate` を0へ戻し、上限を元に戻す（今のライフ・ガッツは元の上限で頭打ち）。カードとの併用は指定が無かったので制限なし |
| `weaponChange`（ソード・コンバージョン） | 1体ぶんの読み取り＋ヒット列＋固有技の処理 | 2026-09-25 ユーザー指示で3択。**片手剣**＝いつもどおり。**片手盾**＝丈夫さ＋いまの力、本人の固有技でソードスキル（20%×2・連撃+3%・連撃パワー）が出ない（`swordSkill:false`）。**二刀流**＝丈夫さ半分（切り捨て）、本人の攻撃の**連撃だけ**がもう1回ぶん入る。メインのダメージは1回のまま（2026-09-25 ユーザー指示「二刀流はメインダメじゃなくて、連撃分のみね」。`buildAttackHits` の `hitRepeat:2`。2回目は同じ値のまま連撃として足す）。どれも盤面の元の値から数え直すので積み重ならない。勇者モンなら配置の画面で初期スタイルを選べ、置いた瞬間に `setTacticsExInitialStyle` で記録へ書く（回数も「このターン」も数えない） |

- 読み取り口は **被ダメ（`getIncomingDamageBeforeTurnReduction`）・ガード（`guardDefFor`）・与ダメ（`getDmg`）** の3か所。
  これらは `useCallback` で古い描画の関数が残ることがあるので、EXの「いま」と有効かどうかは `tacticsExLiveRef` から読む
- 使った瞬間の演出は、吹き出し（「EX 名前！」）＋カットイン（2026-09-26 ユーザー指示「EXスキルが演出もなくて寂しい」）。
  `24-battle-fx.jsx` の `TacticsExCutin`（暗転・斜めの帯に立ち絵とEX名・効果ごとの模様、1600ms、body へ portal）と、使った子の距離枠の光（`.ex-aura`）。
  色と模様は `TACTICS_EX_CUTIN_THEME` を **effect 名** で引く（モンスターごとに分けない。新しい effect は1行足す。無ければ既定の紫）。
  見た目だけで、進行は待たない（`showTacticsExCutin` が時間で片付ける）。個別の処理が要るなら `TACTICS_EX_ON_USE` へ effect 名で足す

### お試しのあいだ決めていないこと（あとで変えてよい）

- ガードの段階（いちばん硬い子で決まる）とパーティの力・丈夫さの平均には、EXの上乗せを入れていない。ステータス画面（Hero Scan）の数字も盤面の値のまま（EXの詳細に「力／丈夫さ」を出している）
- 片手盾で止めるのはソードスキルだけ。勇者特性「二刀流」（通常攻撃の50%+50%・固有技の10%×3・カード+1）と、すでに貯まった永久連撃はどのスタイルでもそのまま
- 剣士モッチーの基礎値は 2026-09-25 に ちから185→135 / 丈夫さ25→75（種の基礎値なので全モード・既存の個体にも効く。個体差は差分で持っているので保存データは変わらない）
- 距離枠への残り回数の常時表示、効果ごとの専用のSE
- 倒れている子の効果（片手盾・二刀流のまま倒れてもそのまま）

### EXを足すとき

1. `TACTICS_EX_SKILLS` へ1行（効果が既存の種類なら、これだけで動く）
2. 新しい効果なら、戦闘の計算側で `tacticsExEffectAt(slot)` / `applyTacticsExStats` を見る形で足し、`TACTICS_EX_IMPLEMENTED_EFFECTS` へ名前を足す
3. ヘルプの表は自動で増える。ヘルプの説明（note）と更新履歴は手で書く
4. `tools/mode/tactics-ex-skills-check.js` に効果の検査を足す
