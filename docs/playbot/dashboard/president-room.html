    Tier の決め方

    ステータスだけでは決めません。次の6つを ◎○△ で見て、理由に「どれが効いてその Tier なのか」を書きます(— はまだ数えていない)。

    項目見るもの
    攻め頭割り比(その回のダメージ ÷ 味方の平均。1.0 で人並み)。◎ 1.3 以上・○ 0.8 以上
    守り打たれ強さ(ライフ×丈夫さ。全員の中で上・中・下)。守り役は、その子が入った回の届いた WAVE
    勇者特性勇者モンにした回の届いた WAVE(難易度の平均との差)。◎ +1 以上・○ −1 以上。記録欄に特性の文が出た回数も数える
    固有技1回の戦いで撃った回数。◎ 3回以上・○ 1回以上
    EX1回の戦いで使った回数。◎ 2回以上・○ 1回以上・未 = 一度も使えていない → Tier を付けず「保留」
    間合い間合い適性(零・近・中・遠。立っている枠で A +10%・G −20%)。数えた回があれば、撃ったときの「適性の補正 × 距離の倍率(敵との距離の差で ×1.5 / 1.3 / 1.1 / 0.9)」の平均。◎ 1.4 以上・○ 1.2 以上

    点(並べる順と S〜D の線引き): 攻め役は頭割り比と勇者の伸び、守り・支え役は入った回の伸びと勇者の伸び。

    S ≥ 0.45 > A ≥ 0.15 > B ≥ −0.15 > C ≥ −0.45 > D。勇者モンにした回が3回より少ないうちは、勇者の伸びを軽く見ます。
