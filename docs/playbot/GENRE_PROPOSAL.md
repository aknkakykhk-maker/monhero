# モンヒロビート 全曲のジャンル分けの案(社長に聞くための下ごしらえ)

2026-10-11 ビート部 カゲ。台帳 `REQUESTS.md` の「ジャンルタブがあるから余裕あるときに全曲設定したいね」(r2610111259genre)。
**まだ曲には付けていない。** 社長が返事できるときに、窓口が下の「聞き方」で選択式に聞く。決まったら、
`RHYTHM_GENRES` へタブを足し、`RHYTHM_SONG_GENRE_TAGS` へ曲ごとの印を書く(画面 `29-rhythm-screens.jsx` は書き換えない)。

## いまの状態

- タブは **ALL・イベント・お気に入り** の3つだけ(`13-bgm-and-rhythm-settings.jsx` の `RHYTHM_GENRES`)。曲に付けた印は0件
- 曲を見分ける印の仕組み(`tag`)は用意済み。印の無い曲は `original` 扱い
- 保存値の id は名前を変えない。`original`(オリジナル)・`collab`(コラボ)は 2026-09-26 に半日だけ出していたので、
  使うなら**同じ id・同じ意味**で足し直す(別の意味で使い回さない)
- 2026-09-26 のユーザー指示は「オール、オリジナル、コラボ、イベント、お気に入り。あとはこれから追加できる仕組みを」
- 公開曲は40曲(`RHYTHM_DEMO_SONG_IDS`)。版のある曲(原曲・remix・short ver.)は曲えらびで1行にまとまるので、同じ曲の版は同じジャンルにそろえる

## 案(どれも推測を入れず、データにあるものだけで分けた)

| 案 | タブ | 分け方 | 良いところ | 気になるところ |
| --- | --- | --- | --- | --- |
| **A 出どころ(推奨)** | オリジナル / コラボ | BGM の作者の欄(`creator`)に名前がある曲をコラボ、それ以外をオリジナル | 2026-09-26 の指示どおり。過去の id をそのまま使える。新曲は作者の欄を書くだけで決まる | 作者の欄は、作者が分からない曲も「オリジナル」になっている。下の ※ 22曲は**社長に確かめる** |
| B テンポ | ゆったり / ふつう / はやい | 解析した BPM(140未満 / 140〜170未満 / 170以上) | 数字で決まるので迷わない。新曲も自動で決まる | 曲の雰囲気とは合わないことがある(テンポが速くても落ち着いた曲など) |
| C 歯ごたえ | やさしめ / ふつう / 激ムズ | MASTER の Lv.(24以下 / 25〜32 / 33以上) | 腕前に合う曲を探しやすい | 難易度はすでに曲ごとに選べるので、ジャンルと役目が重なる。譜面を作り直すと分類が動く |
| D いまのまま | (足さない) | — | 手間が無い | 曲が増えるほど探しにくい |

### 案A の ※(社長に確かめたいこと)

作者の欄が「オリジナル」で、BGM の id が `melo_`(モンヒロビート用に足した曲)の22曲。オリジナル曲か、よその作品(コラボ)かの記録がリポジトリに無い。
とくに、曲名がよく知られた曲と同じもの(例: crossing field・only my railgun・Rising Hope・ハルカ・FREEDOM DiVE↓・ビッグブリッヂの死闘)は、
**コラボ(または別の扱い)にするかを社長に決めてもらう**。こちらで作者名を推測して書くことはしない。

## 聞き方(窓口が AskUserQuestion で使う形)

**質問1**「曲えらびのジャンルのタブを、どの分け方で足しますか?」
1. 出どころ(オリジナル / コラボ)(推奨) — 2026-09-26 の指示どおり。作者の分からない22曲は、続けてどちらにするか聞く
2. テンポ(ゆったり / ふつう / はやい) — BPM で自動で決まる
3. 歯ごたえ(やさしめ / ふつう / 激ムズ) — MASTER の Lv. で決まる
4. いまのまま(足さない)

**質問2(1 を選んだときだけ)**「作者の欄が空の22曲(下の表の ※)は、どう分けますか?」
1. 全部オリジナル(推奨・いまの見え方と同じ)
2. 曲名がよく知られた曲と同じものだけコラボにする(社長が曲を指定)
3. 1曲ずつ決める(表を見ながら)

**質問3(どれでも)** 「ほかの分け方も一緒に足しますか?」(複数選択可)… テンポ・歯ごたえ・足さない
