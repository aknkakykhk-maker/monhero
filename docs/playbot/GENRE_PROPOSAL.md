# モンヒロビート 全曲のジャンル分けの案(社長に聞くための下ごしらえ)

2026-10-11 ビート部 カゲが作り、**2026-10-26 にいまの公開曲50曲へ合わせて書き直した**(部長テンポくんの依頼)。
台帳 `REQUESTS.md` の「ジャンルタブがあるから余裕あるときに全曲設定したいね」(r2610111259genre)。
**まだ曲には付けていない。ゲームのデータも触っていない。** 決まったら `RHYTHM_GENRES` へタブを足し、
`RHYTHM_SONG_GENRE_TAGS` へ曲ごとの印を書く(画面 `29-rhythm-screens.jsx` は書き換えない)。

## いまの状態

- タブは **ALL・イベント・お気に入り** の3つだけ(`13-bgm-and-rhythm-settings.jsx` の `RHYTHM_GENRES`)。曲に付けた印は0件
- 曲を見分ける印の仕組み(`tag`)は用意済み。印の無い曲は `original` 扱い
- 保存値の id は名前を変えない。`original`(オリジナル)・`collab`(コラボ)は 2026-09-26 に半日だけ出していたので、
  使うなら**同じ id・同じ意味**で足し直す(別の意味で使い回さない)
- 2026-09-26 のユーザー指示は「オール、オリジナル、コラボ、イベント、お気に入り。あとはこれから追加できる仕組みを」
- 公開曲は **50曲**(`RHYTHM_DEMO_SONG_IDS`)。版のある曲(原曲・remix・short ver.・フル)は曲えらびで1行にまとまるので、同じ曲の版は同じジャンルにそろえる
- 10/11 の案のあとに増えた曲は、BGM の表の作者の欄(`creator`)にアーティスト名が入っている(DECO*27・Team Grimoire・HANA・Roselia など11曲)

## 画面のどこで使うか

1. **曲えらびのジャンルのタブ**(いまの ALL・イベント・お気に入りの並び)。仕組みは用意済みなので、タブを足して曲に印を付けるだけ。いちばん手間が少ない
2. (足すなら)曲えらびの1行に、小さなジャンルの札。タブで絞らなくても、どの種類の曲か分かる
3. (足すなら)マルチの部屋の「おまかせ」で、ジャンルを選んでからおまかせ

まずは 1 だけを推す。2・3 は 1 を見てから決める。

| D いまのまま | (足さない) | — | — | 手間が無い | 曲が増えるほど探しにくい |

### 案A で社長に決めてもらうこと

- **他の作品(アーティスト名のある11曲)を、どのタブに入れるか**: 「コラボ」(`collab`)に入れる/新しいタブ(例「カバー」「アーティスト」・新しい id)を作る。
  2026-09-26 の「コラボ」は、よその人と組んだ曲(例: ドラの「もう一つの世界へ」)の意味だったので、同じ id に別の意味を足すかどうかは社長が決める
- **※の24曲**(作者の欄が「オリジナル」で BGM の id が `melo_`): オリジナル曲か、よその作品かの記録がリポジトリに無い。
  よく知られた曲名と同じ物(crossing field・only my railgun・Rising Hope・ハルカ・FREEDOM DiVE↓・ビッグブリッヂの死闘 など)を含む。
  こちらで作者名を推測して書くことはしない

## 聞き方(窓口が AskUserQuestion で使う形)

**質問1**「曲えらびのジャンルのタブを、どの分け方で足しますか?」
1. 出どころ(オリジナル / コラボ / 他の作品)(推奨) — 2026-09-26 の指示どおり。続けて下の2つを聞く
2. テンポ(ゆったり / ふつう / はやい) — BPM で自動で決まる
3. 歯ごたえ(やさしめ / ふつう / 激ムズ) — MASTER の Lv. で決まる
4. いまのまま(足さない)

**質問2(1 を選んだとき)**「アーティスト名のある11曲は、どのタブに入れますか?」
1. 新しいタブ「カバー」を作る(推奨・「コラボ」の意味を変えない)
2. 「コラボ」に入れる
3. 「オリジナル」に入れる

**質問3(1 を選んだとき)**「作者の欄が『オリジナル』の※24曲は、どう分けますか?」
1. いまの作者の欄どおり全部オリジナル(推奨・いまの見え方と同じ)
2. よく知られた曲と同じ物だけ別のタブへ(社長が曲を指定)
3. 1曲ずつ決める(下の表を見ながら)

**質問4(どれでも)** 「ほかの分け方も一緒に足しますか?」(複数選択可)… テンポ・歯ごたえ・足さない
