# 参考動画を活かす決まり(2026-10-11・社長の指示)

社長「せっかく参考動画も上げてるんだから、もっとそれを解析して活かすようにしてほしい」。
Sheriruth では「止まる間もレーンの上にノーツがある」を見落とした。Grievous Lady では「動く演出の最中はノーツが来ない」を窓口が答えられなかった。
どちらも、動画を見れば分かることを、作る前に読み取っていなかったのが原因。

## 作る前に、動画から次を読み取って表にする(全部の項目に「参考ではこう」を書く)

| 項目 | 読み取ること |
| --- | --- |
| ノーツ | 叩く時刻・レーン・地上/空中・ホールド・スライドの通り道(`tools/mode/rhythm-ref-capture.js`) |
| 流れの速さ | 止まる・前へ飛ぶ・後ろへ戻る・速くなる区間の時刻と量(`tools/mode/rhythm-ref-flow.js`) |
| 演出中のノーツ | 速さが変わる最中に判定線へ来るノーツの数(0 か、どの拍に何個か)(同上) |
| 待っているノーツ | 止まる・戻る間に、レーンの上のどこにノーツが見えているか(道の何%か)(同上) |
| 見た目 | 地上と空中の見分け方(色・形・高さ)・押した時の光・判定線・影 |
| 手 | 左右の手の分け方・同時押し・交差 |
| 密度 | 区間ごとの叩く数・休み(音の休みと譜面の休みが合っているか) |

読み取れなかった項目は「読み取れなかった」と書く。推測で埋めない。

## 寄せても変えない前提: 横持ち・親指2本

参考動画のプレイヤーは指を何本も使うことがある。こちらは**スマホ横持ち・親指2本で遊ぶのが前提**(2026-10-10 社長の決定)。
参考に寄せた譜面も、親指2本のモデル(`tools/mode/rhythm-hand-model.js`)で「押せない・指の交差・届きにくい」が**0**になるまで直してから出す。
「参考どおり」は、流れ・演出・密度の形・見た目を寄せるという意味で、多指でしか押せない配置まで写すことではない。

## 社長に見せる前に

- 参考と、こちらの絵を**同じ曲の時刻**で並べたコマの一覧と、上の表の「参考/こちら」の数字を出す
- 食い違いは、直すか、なぜ違うかを書く。窓口はこの表がないものを社長へ回さない
- 写し(参考の譜面の一覧・コマ)は `ref-work/` など、公開リポジトリの外にだけ置く

## 道具の使い方(2026-10-11・オンプくん)

```
# 流れの速さ・演出中のノーツ・待っているノーツ(表を出し、ref-work/<曲>/flow[-name].json と軌跡図を書く)
node tools/mode/rhythm-ref-flow.js --track <曲id> --video <参考動画> --profile <約束の表の名前> --offset <秒> [--from 80 --to 90] [--sheet] [--name stop60]
# 参考のコマと演奏画面を同じ曲の時刻で並べる(ref-work/<曲>/compare/compare-sheet.png)
node tools/mode/rhythm-ref-compare.js --track <曲id> --video <参考動画> --offset <秒> --song "<曲名>" --diff MASTER --times 82.1,82.6,83.0
```

- 新しい撮り方の動画は、`tools/mode/rhythm-ref-profiles.json` に `flow`(消失点 vp・奥の端 farY・判定線 judgeY・左右 x0/x1・白さの読み方・外す四角 masks)を足す
- ずれ(`--offset`)は「参考の時刻 = 曲の時刻 + ずれ」。2秒を超えるずれは自動では測れないので手で入れる
- 待っているノーツは「奥行き%/見た目%」の2つで出る。手測り(画面の高さで測ったもの)と比べるのは見た目%
- 白いノーツが読めないコマ(アークだけ・半透明の場面)は「読めない」になる。そこは推測で埋めず、表に「読み取れなかった」と書く
