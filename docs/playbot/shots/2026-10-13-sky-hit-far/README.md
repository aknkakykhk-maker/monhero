# HELL: 空中を叩いた柱の光「奥まで」と、待機中の空中のレーンの光(2026-10-13)

社長の報告(Android・本番): ①「空中を叩いた柱の光」を「奥まで」にしても短いまま ② 曲が始まる前の待機中、地上のレーンは光るのに空中のレーンは光らない。

## 撮り方

2つの道で撮った。デバッグの道(デバッグ設定 → モンヒロビート → 全解放の曲えらび → 風がそよぐ場所 HELL)は `before-*` / `after-*`・`compare.webp`。
通常の曲えらび(ソロライブ → Sheriruth → HELL)は `select-before-*` / `select-after-*`・`select-compare.webp`(std・minimal・light の3通り)。844×390。
描き方は2つの道で共通で、前も後も同じ絵になった(道による違いは無い)。地上(左のレーン)と空中(右のレーン)を**同じ瞬間に**指2本で押して撮る。

- `*-hit` … 演奏中(0.6秒・ノーツの無い所)に2本で押し、同じ瞬間に地上と空中の「叩いた光」をゲームの関数(`rhythmSpawnHitEffect`)で出して約0.11秒後
- `*-wait` … 待機中(READY→3→2→1)に2本で押したところ

描き方・軽さの4通り: `std`(既定: 描画方式「自動」・演出量「標準」) / `minimal`(演出量「最小」= 見た目のおまかせ「軽さ優先」) /
`light`(軽量モード) / `webgl`(描画方式「軽い」)。`compare.webp` は 行=4通り、列=叩いた直後の前・後、待機中の前・後。

## 原因

| どこ | 前 | 原因 |
| --- | --- | --- |
| ① 演出量「最小」・軽量モード | 空中の柱の光がまるごと出ず、押している間の短い光だけが見えていた | canvas の `pushHit` が演出量「最小」・軽量モードの光を全部捨てていた(空中の柱も)。「奥まで」の設定はそこまで届いていなかった |
| ① 既定・描画方式「軽い」 | 奥まで出ている | — |
| ② 待機中 | 地上は光る・空中は光らない | 地上のレーンの光は画面の要素、空中は canvas に描く。canvas を描く毎フレームの処理は READY→3→2→1 のあとに動き出すので、待機中は空中の光を描く機会が無かった |

## 直したこと

- ① 演出量「最小」・軽量モードでも、空中の柱の光(設定どおり 奥まで/短い)だけは出す。中心の光・粒・星は今までどおり出さない(地上の光も今までどおり出さない)
- ② 曲が始まる前の待機中は、指の出入りのたびに空中の押した光だけを canvas へ1回描く(ポーズ中は描かない)
- 「奥まで」の既定・3択・保存キー(`mh_hell_sky_hit_proto`)・譜面は変えていない
