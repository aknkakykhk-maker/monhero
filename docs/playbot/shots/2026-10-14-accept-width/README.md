# HELL: 地上と空中の「受け付ける範囲の広さ」(2026-10-14)

社長「地上と空中の判定ラインは決まった範囲だけど、狭くする方はオプションでできるようにできない?」。

## 作ったもの

- オプション「演奏」→「判定ラインの位置」の地上の行・空中の行それぞれに「受け付ける範囲の広さ」(100%〜50%・5%刻み・「−/＋」とスライダー)
- 保存は新しいキー `mh_rhythm_ground_accept_pct_v1` / `mh_rhythm_sky_accept_pct_v1`。既定100(今の広さ・上限)。壊れていたら100
- 狭める向きは「地上と空中の境目の側」だけ。空中は線より下へのはみ出し、地上は線より上へのはみ出しを縮める
  (押し間違いが起きるのは地上と空中が重なる境目のあたり。空中の線より上・地上の線より下には取り合う相手がいないので縮めない)
- 下限50%: 縦の画面で、境目の側の受け付けが空中は線の下 約53px、地上は線の上 約34px 残る。人の指の押す位置のばらつき(ボットの指のくせ σ=28px)より広く残し、線をねらえば空振りしない幅
- 案A(押すくせで空中の境目が自動で下がる)は、空中の範囲を狭めたときは狭めた下の端より外へは広げない
- 見本の色の帯も同じ式で細くなり、両方を受け付ける所(しま)も狭まる。狭めると、間にどちらも取らない所ができる
- 押す時刻・スコア・ランキングは変えない
