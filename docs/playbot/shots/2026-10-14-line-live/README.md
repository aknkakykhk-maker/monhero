# 判定ラインの位置を、実際の演奏画面で合わせる(2026-10-14)

社長「判定ラインの調整見づらいから実際の画面に切り替わって調整できるようにして」「空中ラインと地上ラインの調整範囲もっと広げないと意味ない」、
空中の受付範囲に「上の端」を作る(社長の決定)。

## 作ったもの

- オプション「演奏」→「判定ラインの位置」の「🎯 実際の画面で合わせる」。押すと演奏画面(本番と同じ `RhythmTapTest`・同じ描き方)に切り替わる
  - 曲は「判定ライン合わせ」(地上と空中のタップを2拍ごとに交互)。練習と同じ扱いで、ライフ・記録・ランキングに何も残さない
  - 左上(縦は上)に操作: 地上の判定ライン/地上の受付の広さ/空中の判定ライン/空中の受付の広さ(下側)/空中の受付の上の端。どれも「−/＋」とスライダー
  - 受け付ける範囲の帯(地上=水色・空中=桃色・両方=しま)を演奏エリアに重ねる。範囲は演奏と同じ式(`rhythmSkyAcceptLimit` / `rhythmSkyAcceptTop` / `rhythmGroundAcceptFrom`)
  - 動かすとすぐ効く(保存はまだ)。「保存して戻る」でこれまでと同じキーへ書く。「やめる」・途中で抜けたときは元へ戻す
- 動かせる幅を広げた: 地上 4〜50%(上は50まで。判定ラインは画面の上半分より下に置く作り)。空中は画面に収まるところまで
  (空中の線は地上の線より10%以上上・画面の上から3%より下)。空中の線を下げても、空中の受け付けの下の端は既定の位置より下へは行かない
- 空中の受付の上の端: 空中の線から上へ画面の高さの20%×広さ(50〜300%・既定100・新しいキー `mh_rhythm_sky_accept_top_pct_v1`)。
  空中から始まるスライドの押し始めも同じ上の端を使う

## 確かめたこと(Chromium・横 844×390 と 縦 390×844)

- 両端まで動かしたとき(横): 地上50%・空中+7%で 地上 y=193・空中 y=14 / 地上4%・空中−29%で 地上 y=372・空中 y=333。地上と空中の光の道は、それぞれの線から出る
- 保存して戻る: `mh_rhythm_sky_line_offset_v1` などへ書かれ、オプションへ戻る
- 古い版で開く: 空中のずらし30は8に丸めて読む。地上の50は範囲外なので既定の20%として読む。どちらも壊れず遊べる
- HELL 4曲を人の指のくせのボット(親指・seed 3)で遊ばせた MISS: 前 3 → 後 2(Grievous Lady で1つ増えた 121.383秒は地上のホールドで、上の端とは関係ない揺れ)

## 絵

`live-start` / `live-moved`(横・動かす前と後)、`live-max-landscape` / `live-min-landscape`(横・両端)、`live-max-portrait`(縦・上の端)
