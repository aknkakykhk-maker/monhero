## 押せるか
- 寸法は実際の演奏画面(横持ち 844×390)から測った: 空中の線は地上の線より約2.6cm上、1レーン約1.9cm(画面幅14.3cmとして)
- 交差する瞬間は、親指の先どうしが上下に約2.6cm離れているので**先どうしはぶつからない**
- ぶつかるのは**くぐったあと**。空中を押さえている右の親指は、先から右下の付け根へ斜めに寝ている。その右下へ左の親指が入るので、右の親指の腹に当たる
  (親指の太さ1.8cm・付け根は左下/右下の端と仮定した見積もりで、①③ 約1.0cm 重なる/② 約0.8cm 重なる)
- 逃げ道: 空中の受け付けは「地上と空中の線の真ん中より上」で上限が無いので、右の親指を空中の線よりずっと上で押さえれば当たらない。ただし画面からは分からない

## 直し方の案(まだ譜面は変えていない)
- **案1 交差を浅く**(①③): 地上スライドの行き先を 5.5→5.0(レーン5→4.5)。演出の形はそのまま、横の間 1.5→1.0レーン(②と同じ)。重なりは 約1.0→0.55cm に減るが0にはならない。手の決まりは0件のまま
  - `1-before.png`/`1-after.png`・`3-before.png`/`3-after.png`・`2-before.png`(②はもともと1.0レーン)
- **案2 上下を入れ替える**: 動いて越える方を空中、止まっている方を地上にする(上の指が越える)。上の親指は付け根が左下へ向かうので、越えた先の右下の指に当たりにくい。
  同じ位置の見積もりで ① 約-0.03cm(ほぼ当たらない)、横の間を1.0レーンにすると +0.2cm(当たらない)。そのかわり前後の空中⇔地上の切り替えを作り直す
