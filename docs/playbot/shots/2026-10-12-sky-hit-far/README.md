# 空中を叩いたときの柱の光「奥まで」と、空中の押さえの光の位置(2026-10-12)

## 部品だけで描いたもの(1〜3・compare.jpg)

横持ち 844×390(倍率2)・叩いてから 60ms の同じ瞬間。左下が地上を叩いた光、右が空中を叩いた光(HELL の空中のノーツだけ)。
道・ノーツは描いていない。

- `1-off.png` … 柱の光 切
- `2-short.png` … 短い柱(それまでの「入」)
- `3-far.png` … 奥まで(既定)。空中の線から空中のレーンの奥まで、レーンの形(奥ほど細い)に沿って伸ばす
- `compare.jpg` … 3枚を左から並べたもの

重さ(光8つ・1コマあたり・GPU が描き終えるまで・この入れ物の SwiftShader・3回):
地上の光 0.17〜0.56ms / 空中・柱なし 0.47〜0.99ms / 短い柱 0.56〜1.94ms / 奥まで 0.63〜1.80ms。
奥まで は短い柱と同じくらい(地上の光より1コマ 0.5〜1ms ほど重い。光が8つ同時に出たとき)。

## 実際の演奏画面(4・5・play-compare.jpg)

iPhone 横持ち相当 844×390(倍率3)・Sheriruth HELL 0:57 ごろ。左はしのレーンを空中の高さで押したまま(押さえの青い光)。
右上は右はしのレーンで空中を叩いた直後。時刻はおおよそ同じだが、自動演奏なので判定の文字やノーツは少し違う。

- `4-play-before.jpg` … いまの本番と同じ(短い柱)。左の押さえの光は、空中の線より手前の部分が空中の段の壁の外(左)へ斜めにはみ出している
- `5-play-after.jpg` … 直したあと(奥まで)。押さえの光の手前の部分は壁のふちで止まる。右はしの柱の光は空中の段の面に沿って奥へ伸びる
- `play-compare.jpg` … 前(左)と後(右)を並べたもの

押さえの光の空中の線より奥の部分(斜めに伸びる青い帯)は、空中の段の面(灰色)のふちに沿っていて、位置は合っている。
空中の段は地上の判定ラインの道幅のまま持ち上げた形なので、その奥は地上の道より外側に見える。
