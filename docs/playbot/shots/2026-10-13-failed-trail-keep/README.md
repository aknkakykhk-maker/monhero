# 取り損ねたホールド・スライドを、消さずに薄い灰色で終わりまで流す(2026-10-13)

社長「スライドとホールドのノーツが消えるやつ、まだ直ってない」「消すなんてルール決めたことない」。
10/13 午前(#2902)の「取り損ねた残りは約0.3秒で消す(全難易度)」は社長の言葉の受け取り違いだったので、その前の「薄く残る」見え方へ戻した。

## 直したこと

- 取り損ねた HOLD / SLIDE の残り(帯と終わりの棒)は、消さずに薄い灰色(濃さ0.34)で帯の終わりまで流す。地上・空中・全難易度・ひとりもマルチも同じ(描き方は1つ)
- 灰色は #2954 でそろえた濃さ(`RHYTHM_FAILED_SLIDE_FILL`)のまま
- #2954 の「空中で切れたスライドだけ元の色で流す」例外(`_rhythmSkyCut`)は、全部が同じ灰色で流れるようになったので外した
- 判定・スコア・ライフ・コンボは変えていない
- 検査 `rhythm-failed-hold-trail-check` / `rhythm-perf-check` を「終わりまで薄く残る」を見張る形へ直した
