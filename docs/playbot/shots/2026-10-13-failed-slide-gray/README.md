# 取り損ねたスライドの灰色を、地上のホールドと同じ濃さに(2026-10-13)

社長「空中のスライドが、途中で外れたりして MISS 判定になったときに消える」(iPhone)。

## 調べたこと(Chromium・Sheriruth HELL・横 844×390)

外れの描き方が始まったコマと、その1つ前・0.15秒後のノーツの canvas を、そのコマのうちに写し取って比べた(画面写しは遅れて撮れるため)。

- 外し方: 頭を見送る(`pass-*`)/頭を押さえて0.3秒後に切れる(`cut-*`。空中のスライドが指から外れて猶予を超えたときと同じく、MISS を付けて終わりの時刻をいまへ寄せる)
- 描き方: 既定(2D)・軽さ優先・軽量・描画方式「軽い」(WebGL・GPU の帯)
- 結果: 空中も地上のスライドも、外れた瞬間に灰色へ変わって元の位置に残り、0.3秒で消える(10/12 に決めた消え方)。空中だけ描かれない道は Chromium では見つからなかった
- ただ、スライドの外れた灰色(`rgba(120,120,135,.48)`)は地上のホールド(灰色の段 .9→.7)の約6割の濃さで、色のついた帯が急に暗い灰色へ変わり、道の上ではほとんど見えなかった

この環境には WebKit が無いので、Safari そのものでは撮れていない。

## 直したこと

取り損ねたスライドの灰色を `RHYTHM_FAILED_SLIDE_FILL`(`rgba(135,145,160,.8)`)にし、2D と GPU の帯の両方で使う。地上も空中も同じ。判定・スコア・消えるまでの時間(0.3秒)は変えていない。

## 絵

`compare.webp` … 行は 上から 空中を途中で外す / 地上のスライドを途中で外す / 空中を見送る / 地上のスライドを見送る / 地上のホールドを見送る(比べる相手)。
列は 左から 外れる1コマ前 / 前: 外れた直後 / 前: 0.15秒後 / 後: 外れた直後 / 後: 0.15秒後。0.3秒後はどれも消え切っている(前も後も同じ)。
`before-*` / `after-*` はそれぞれの1枚。
