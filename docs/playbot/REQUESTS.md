# 頼みごとの台帳

ユーザーが窓口(モンヒロくん1号)へ投げた頼みごとの一覧。決めごとは `tools/playbot/ROUTINE.md`「頼みごとの流れ」。

- 新しいものを上に足す。受けたら窓口が1行足し、班は始めたとき・終わったときに「いま」「見込み」を書き換える(PR に含める)
- 「いま」は `受けた` / `班で作業中` / `ユーザーの判断待ち` / `公開済み` / `取りやめ` のどれか
- 時刻は日本時間

| 10-08 11:50 | モンヒロバトルの入口(バトルのモードえらび)を、モンヒロビートのモードえらびのような見た目にする | バトル班 | 公開済み | 12:30ごろ公開。入口を舞台+立ち絵+大きな3枚の札に作り替え(行き先・ランキングは変更なし) |
