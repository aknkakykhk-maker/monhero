# AIコピー: 4人そろった盤で気づきにくい件の見本(2026-10-28・レフェリーくん)

社長の頼み「参考画像作って」(ジン部長経由)。タクティクス/レイドで空いたマスが無いと、AIコピーは元の子のマスに重なり、小さな札しか出ないので気づきにくい。案A の2つを見本の絵にした。**本体は直していない(見本だけ)。**

## 撮り方

- タクティクスプロ(Beginner)のバトルを開き、写真用にだけ次を足した。どれもローカルの一時的な書きかえで、コミットしていない
  - 盤の4人: モッチー(本物)・ゴーレム・ライガー・ピクシー(写真用に埋めた)
  - コピー: ゴーレムのコピー(近のマスに重なる・ライフ600・次に使う札「でこぴん」・あと4ターン)
- レイドのグランドスラムは開催中でないと開けないため、4人そろったタクティクスの盤で撮った

## 見て気づいたこと

- ア: 縦は盤の右に細い5列目(4人の枠が少し細くなる)、横は盤の下に1本の帯。どちらも「5人目がいる」とすぐ分かる。重なる小さな札は出さない(札が2か所に出ないように)
  - 札の顔はいまの5つの遊びの札と同じソラシドの顔。ゴーレムの顔にするかは決めどころ
- イ: 縦はゴーレムの絵の上に札が乗るが、名前・ライフ・GUTS の行にはかからない。**横は札が3行になって、ゴーレムのライフの行にかかる**(本番にするなら横だけ1行に詰めるなどの手直しが要る)
- イは元の子の絵の一部を隠すので、ア のほうが元の子もコピーも両方見やすい
