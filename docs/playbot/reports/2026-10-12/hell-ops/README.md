# HELL の操作のしやすさの洗い出し(2026-10-12 ビート部 テンポくん)

社長の頼み(10/12 6時台)「HELL の視覚性・操作性をもっと改良して」のうち、操作のしやすさ(見やすさはマクアケくん)。
対象: Sheriruth HELL(`sheriruth_hell_debug`)・Grievous Lady HELL(`grievous_lady_hell`)。HELL はデバッグ専用のまま(公開の印は偽)。

## 測り方
- 横の取れる幅: `tools/mode/rhythm-note-reach-scan.js --song <曲>`(判定の関数そのもので、全ノーツを 0.05 サブレーンずつ)
- 描いた位置と取れる位置: `docs/playbot/reports/2026-10-12/tap-position/`(8画面)
- 人の指: `tools/playbot/rhythm-cross-swap-bot.js --entry proto --persona thumb|lean|normal --seed N`(横持ち 844x390・親指2本・人のずれ入り)。
  今回足した引数: `--persona`・`--seed`・`--sigma`(人の指のくせ)/`--travel 0.5`(同じ側の指が250ms以内に高さを変えるとき、空中の高さの半分しか上げ下げしない)/`--sky-adapt`(下の案Aを入にする)
- 比べ: 地上の MASTER(公開曲)を同じ指・同じ種で

## 問題なし
- 横の取れる幅: 2曲全ノーツで「取れない・真ん中で取れない・和音で取れない」0。描いた位置と取れる位置のずれ 0
- 交差の長押し(Sheriruth の4本): 4本とも MARVELOUS・帯が暗くなった時間 0
- 空中の長押しの持ち続け: 高さでは切れない(スライドは横だけで追う)。ボットの途中切れ 0
- 地上のノーツの MISS は地上の MASTER と同じくらい(HELL で増えていない)
- 判定の時間の窓・スライドの追い方(許容・猶予 120ms)は MASTER と同じ

## 問題1: 親指が空中へ届ききらないと、空中が取れない
- 境目(横持ち 844x390): 地上の線 310px・空中の線 158px。空中のノーツは「地上の線の14px上より上」でだけ受ける(固定)。地上のノーツは「地上の線の76px上まで」受ける
- 親指の人は地上を線の60〜80px下で押す。そのまま空中へ半分だけ上げると、線のすぐ上で押すことになり、空中が断られる(空中→地上は落ちない)
- 案A(作った・既定は切): その人の構えに合わせて境目を下げる。地上のノーツを取れた押下の、線より下の深さを直近16回ぶん覚え、その中央値ぶん下げる(上限は画面の高さの20%)。
  真ん中を押す人は今と同じ。デバッグの「空中の受け付けを構えに合わせる」(`mh_sky_reach_adapt_proto`)で入。見張り: `tools/mode/rhythm-sky-reach-adapt-check.js`
- 案B(作っていない): 近くで地上のノーツと取り合わない空中ノーツは高さを問わない。変わるのは Sheriruth 251中196・Grievous Lady 206中178。10/10 の社長「位置を合わせなくても勝手に判定オッケーになってない?」と逆向き
- 案C(作っていない): 境目を固定で下げる。真ん中を押す人には、地上を押したつもりで空中が取れる所が増える

## 問題2: 同じ側の手で、短い間に高さを変える所(譜面の側)
- 同じ側の手(レーンの真ん中で左右に分けた)で地上⇔空中を切り替える押し始め(時間差・同時押しを除く):
  Sheriruth HELL 100ms以内 5(どれも81ms: 5.41・5.50・17.41・44.42・71.90秒)・200ms以内 18 / Grievous Lady HELL 100ms以内 1(137.03秒・72ms)・200ms以内 4
  (はじめの中間報告の「Sheriruth 20・Grievous Lady 2」は同時押しを数えていた誤り。点には HOLD/SLIDE の終わりも入れている)
- HELL の作り方(`tools/mode/rhythm-hell-mix.js`)の直しは、窓口からオンプくんへ頼んだ(数え方はオンプくんとそろえる)

## 残っていること
- 案Aを既定にするかは社長に聞く(HELL を公開するときに一緒に決める形でよい)
- ボットは指を一瞬で動かす(届ききらないくせは足したが、動かす時間は入れていない)。実機の手ざわりは社長の試しで確かめる
