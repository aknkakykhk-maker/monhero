# 鍵つきフレームの札に、買える条件を短く書く(2026-10-20・改善部の指摘 L3)

社長の決定: 「条件を達成すると買えます」の代わりに、条件を短く書く(2行まで・言葉の切れ目で折る・390/320 で収まる)。

- `profileFrameConditionShort(frame, shop)`(data/breeder.js): `unlock.condition` の中身(種類・モンスター・難易度・回数・Lv.)から、2つの区切りの短い文を作る。`condition.text` は書き写さない
- 札はその区切りで折り、いちばん長い区切りが1行に入る字の大きさ(最大10px・最小7px)
- 読めない条件のときは、これまでの「条件を達成すると買えます」

| 枠 | 札 |
| --- | --- |
| モッチー | モッチー種を / 限界突破 |
| ムー | Masterを / クリア |
| スエゾービート | モンヒロビートを / 10回クリア |
| スエゾー・ゴーレム・ライガー・ハム・ピクシー・ミーア | ◯◯を / 転生(ブリーダーP交換所だけ。ビートP交換所は条件なし) |
| ラグナロク | ラグナロクを / クリア(ブリーダーP交換所だけ) |
| ハロウィン・恐 | ジャックを倒すか / イベント終了で |
| ザン・エイキ | ザン・エイキ / ビートLv50 |
| ウンディーネ3姉妹 | ウンディーネ3姉妹 / ビートLv50 |

実ブラウザで 390・320 の幅、両方の交換所の全カードの名前と札を1文字ずつ測り、区切り以外で行が変わった所 0・札はすべて2行以内。
