# マーケットの鍵つきカードで「条件を達成すると買えます」がはみ出す(2026-10-20)

窓口「鍵つきのカードの帯がカードの幅からはみ出している(文字の頭がカードの左の外から始まり、隣のカードへかかって見える)」。前からの崩れ。

- 原因: 商品カード(`MarketProductCard`)の「買えない予告の札」が `whitespace-nowrap` で1行に固定されていて、3列の細いカードでは幅に収まらなかった
- 直し: 札をカードの幅で折り返す(中央そろえ・行間を詰める・角を丸めた四角)。値段の行はそのまま
- 実ブラウザで、札がカードの左右の外へ出ていないかを測った(フレームの全カード・ブリーダーP交換所とビートP交換所)
