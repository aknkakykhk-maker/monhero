# 枚数・回数を直接打ち込む(2026-10-20)

社長「クイックでのスキップチケットも直接入力できるようにして。個数系のやつは基本的に直接入力があったほうがいいね」。iPhone の幅(390)で撮影。

| ファイル | 中身 |
| --- | --- |
| `before-1-skip.png` | 変更前。スキップの使う枚数は表示だけ(−/＋/全部) |
| `after-1-skip.png` | 変更後。使う枚数が打ち込める欄になった |
| `after-2-skip-typed-12.png` | 「12」と打ったところ(所持37枚) |

数を打ち込める欄(`CountInput`)にそろえた所: マーケットの確認の窓 / トレーニングチケットを使う枚数 / スキップチケットの使う枚数 /
お布施の上げるレベル・転生する回数 / 転生(1体ずつ)の回数 / まとめて転生の1体あたりの回数。
もとから数字の欄があった所(お布施のダイヤの量・自動限界突破の残す量)はそのまま。強化ポイントの振り分け(1ずつ振る操作)は対象外。
検査: `tools/boot/count-input-check.js`(MAX/全部/最大のそばに欄があるか・部品の動き)
