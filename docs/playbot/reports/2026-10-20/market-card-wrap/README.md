# マーケットのカードで、札と商品名を言葉の切れ目で折る(2026-10-20)

窓口「折り返しの位置が不自然」(#3199 のあと)。札「条件を達成 / すると買え / ます」、商品名「モッチーのフ / レーム」「ウンディーネ / 3姉妹のフレ / ーム」など。

- 商品名: 折ってよい位置の印(`marketNameForWrap`)に「フレーム」「ビート」の前・「・」の後ろ・カタカナのあとに数字が続く所を足した
- 札: 「すると」の後ろだけで折る(`marketLabelNodes`)。字の大きさは、いちばん長い語(条件を達成すると)がカードの幅に1行で入る大きさ(最大10px・最小7px・`marketLabelFitSize`)
- 実ブラウザで、全フレームのカード(390・320、ブリーダーP交換所・ビートP交換所)の名前と札を1文字ずつ測り、印の位置以外で行が変わっていないことを確かめた(変な所で折れた数 0)

折れ方(320px): 「モッチーの / フレーム」「スエゾー / ビートの / フレーム」「ザン・ / エイキの / フレーム」「ウンディーネ / 3姉妹の / フレーム」「ハロウィン・ / 恐のフレーム」、札は「条件を達成すると / 買えます」。
390px では名前は「〜の / フレーム」の2行、札は2行。
