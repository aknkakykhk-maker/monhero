## 参考はどうやって地上と空中を見分けさせているか(遊び手の目で)

### 形と透明感
- **地上のノーツは、不透明な白い厚い板。** 床に寝ていて、手前の側面(厚み)が見える。光らない
- **空中のノーツは、半透明のガラスの箱**(01 の左)。厚みのある箱で、向こうが透けて見える。地上の板と色はほぼ同じ白〜薄い水色。**色ではなく「透けているか・厚みがあるか」で分けている**
- アークは、なめらかな半透明の帯(02 の左)。角が無く、曲線でしなる。向こうのノーツが帯を通して見える

### 影と高さの手がかり
- **空中の箱の真下の床に、箱と同じ形・同じ大きさの灰色の影が落ちる**(01 の左・下のほう)。影は輪ではなく、中まで塗った四角。だから「この箱はこの床の真上に浮いている」が一目で分かる
- アークは床から空中へ、また床へと、帯そのものの傾きで高さを見せる。帯の手前の端が床に着く所で指を置く
- 空中の判定ライン(「Sky input」)は、**道の外まで横いっぱいに伸びる、細い1本の光の帯**。道の上の面(台形)や柱は無い
- 空中と地上の判定の高さの差は、画面の高さの**約39%**(01 の左で測った。空中の線 266px・地上の判定の位置 451px・絵の高さ 478px)

### 線の少なさ・色の数
- 道にレーンの区切りの線がほとんど見えない。道は無地の紫で、真ん中にコンボの数が薄く書いてあるだけ
- **プレイの物の色は3つだけ**: ノーツの白(地上も空中も)・アークの青(左手)・アークの桃(右手)。押したときの光は全部同じ桃色
- 背景は曲の絵で明るいが、道は暗い紫一色なので、白い物が浮いて見える

### 押したときの光
- **地上でも空中でも同じ桃色の星形を、指の当たった点そのものに出す**(03 の左。空中の光は、道の外の Sky input の線の上に出ている)
- アークでは、帯の手前の端(指のある点)が星形に光り続ける。光の柱は立たない

### 手(60fps の撮影から)
- 参考の撮影は **iPad を机に置き、両手の何本もの指で遊んでいる**。空中のノーツは手のひらを浮かせて画面の上のほうを押している
- モンヒロビートの目標は「スマホを親指2本」(空中の段は横持ちが主)。参考と同じ動きの量は、親指2本では出せない。見た目だけまねても、社長の「人間の指ではまともにやれる気がしない」は残る

## ピンセットくんへ渡す要点(設計で決めること)

1. **空中を何で分けるか**: 参考は「色」ではなく「透明感+厚み+真下の影」。モンヒロビートの地上の板は色で種類(タップ・ホールド・フリック…)を分けているので、空中も色で分けると色が足りない(10-10 の note-inventory の結論と同じ)
2. **影は塗った同じ形1つ**にする(輪にしない・板より大きくしない)。込み合っても床が埋まらない
3. **空中と地上の高さの差**を、いまの約25% からどこまで広げるか(参考は約39%)。広げるほど見分けやすいが、親指が届くかは手のモデルで別に確かめる
4. **押したときの光**を地上と空中で同じ形にし、当たった点に出す(L6 のずれは直す)
5. **物と色の数を減らす**(L4・L7)。空中の面・柱・字を出すなら、それぞれ何のために要るかを決める
6. 「重い」は見た目の下調べの外。ただ、L2 の大きな半透明の楕円が何枚も重なるのは、描く量が増える所の候補
