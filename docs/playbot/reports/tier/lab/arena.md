## ボットで直したこと

- 2026-10-10 覚え書きの上限を 300 回 → 1000 回(`tactics-brain.js` の `rememberRun`)。174 回の時点で、あと 126 回で古い回から消え、暫定外しの回数が減るところだった

- 2026-10-10 `PLAYBOT_TACTICS_ASSIST_ROTATE=1` を足した(`tactics-brain.js` のアシストカード選び。ハカセくん・改善部の指摘 A3)。
  新規習得のカードのうち、覚え書きで選ばれた回がいちばん少ないアシカ(本人の名前で数える)を選ぶ。同じなら点数の高いほう。強化だけの画面は今までどおり。既定は切。
  入れる前の回数(覚え書き 174 回): あつ 172・ポルツ 80・ももすけ 48・きき 35・メロソ 39・みゅあ 27・かどみうむ 11・ニコラオ 9・ドラ 3

- 2026-10-10 **緊急回復を押すようにした**(ハカセくんの直す順1)。それまで一度も押していなかった。`tactics-brain.js` の `emergencyWhy`・`tactics.js` のターンの始め。
  押すのは「次の攻撃で倒れる子がいて、そのあと立っている子が1体以下・+30% なら持ちこたえる・使える回復カードが無い(倒れそうなのが1体でガードのカードがあり、貫通撃でなければ守りに任せる)」とき。
  `PLAYBOT_TACTICS_EMERGENCY=0` で切れる。覚え書きに `emergency`(押した回数)を足した
- 2026-10-10 **回復・支援のしきい値に自動回復を見込んだ**(ハカセくんの直す順2。`decidePick`)。
  回復カード: 前は「全体のライフが 35% 未満」→「次の攻撃(予告のダメージ)を受けて、ターン終わりの自動回復(上限の10%)が入ったあとで 35% 未満」。メロソも同じ見込みで 55% 未満。
  支援: 前は「いちばん多い子のガッツが6割以上」→「20 払って、ターン終わりのガッツ自動回復(上限の5%)のあとに4割以上」。
  `PLAYBOT_TACTICS_REGEN=0` で前の決め方に戻る。※自動回復の率はアシカ・EX で上がるが、画面から読めないので基本の 10%・5% で見込む
- 2026-10-10 **起こす(復活)を WAVE ごとに考える**(ハカセくんの直す順3。`chooseBetween`)。
  前は `mem.reviveAsked` が1ランで1回きりで、2回目の WAVE からは起こすかどうかを考えていなかった(主力が倒れたまま次の WAVE へ)。
  起こす子: 勇者モン(勇者特性は立っているときだけ効く)→ ダメージの3割以上を出した子(前は35%)→ 半分以上が倒れていれば誰か。起こすとその WAVE は誰も強化できない(仕様)。
  `PLAYBOT_TACTICS_REVIVE_EACH=0` で前の決め方
- 2026-10-10 **トレーニングでドミノ倒し(ちから)も選ぶ**(ハカセくんの直す順4。`chooseBetween`)。前はほぼ全員「丸太うけ+走り込み」でドミノ倒しは0。
  傷んだ子(倒れた・ライフ半分未満)→ 丸太うけ+走り込み(前のまま)/ ダメージを頭割り以上出した子 → ドミノ倒し+走り込み /
  ほかの子 → ガードが4枚に届いていなければ丸太うけ+走り込み、届いていれば走り込み+ドミノ倒し。ガッツの少ない子は2つ目を猛勉強(前のまま)。
  ガードの枚数 = 2 + (いちばん硬い子の丈夫さ÷100)÷2(最大4)。丈夫さは名簿の値 ×1.2(丸太うけ1回ごと)で見積もる。`PLAYBOT_TACTICS_TRAIN_V2=0` で前の決め方

## 見つけたボットの取りこぼし(ハカセくんへ渡す)

- ヤオビクニを勇者にした Hard で、ヤオビクニの EX「悠久の刻」を1回も使わなかった → **ボットの見誤り。直した**。
  W6 T2 でためた必殺技 1,453 がライフ 540 のヤオビクニへ向いていたが、予告の札が「」と読まれて 'single' 扱い。時間停止は「必殺技・貫通撃・全体攻撃」の札のときだけ使う決まりだったので、2回とも残したまま倒れた。
  札が読めなくても「狙われた子が次の攻撃で倒れる見込み」なら使うようにした(`maybeUseEx`)。ヤオビクニの Hard の1回は直す前の版


### ボットが使っていない・気にしていない機能(2026-10-10。社長「自動ライフ回復とか自動ガッツ回復…全て把握した上で」→ ハカセくんの mechanics.md へ)

`tactics-brain.js` を読んで見つけたもの(実戦で効き目を測る前。「ボットのせいで弱く出ているかも」の候補)。

1. **ターン終わりの自動回復(ライフ 10%・ガッツ 5%。アシカ・EX で上がる。60-app.jsx の permaBuffs.autoHpRecovery・tacticsRegen)を見込んでいない**。
   回復は「全体のライフが半分を切ったら」、支援は「いちばん多い子のガッツが6割以上なら」の固定のしきい値で、次のターンに戻る分を勘定に入れていない。
   ガッツを使い切って次のターンの回復を待つ・自動回復が大きいときは回復カードを遅らせる、といった使い方をしない
2. **ポルツ(自動回復アップ)・ももすけ(能力永続アップ)など、効き目が後から積み上がるカード**は、点数が固定(3〜5点)で、ランの残り WAVE 数を見ていない(早い WAVE ほど得なのに、いつでも同じ評価)
3. **トレーニングはほぼ全員「丸太うけ+走り込み」**(ガッツ 90 以下の子だけ猛勉強を1つ)。ドミノ倒し(ちから)はまったく選ばない。
   20 ターンの打ち切りがある WAVE 10(覚醒ムー。ライフ約 13.8 万)で火力不足の負け方をしている子は、ここで損をしている可能性
4. **倒れた子を起こす**のは「ダメージ 35% 以上の子」か「半分以上が倒れている」ときだけ。起こさなかった子のトレーニングの機会・EX の回数がどう失われるかは見ていない
5. **固有技の強化はダメージの多い子から**(上限 12 回)。回復・守り・ガッツの固有技を持つ子(支援役)は強化されにくい
6. **EX は早い WAVE で控える**。回数が限られる EX を最後まで使い切らずに終わる回があるかは、これから実戦の記録(exBy)で確かめる
7. **見ていない機能**(覚え書きに記録が無い): 魂格・WAVE を抜けたときの報酬(ボットに専用の判断が無い。画面に出た分は既定の押し方で通っている)
