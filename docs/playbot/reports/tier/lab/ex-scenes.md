# EX・アシカを使う場面(上手な使い方 best と いまのボット bot・Hard / Expert・各 300 回)

`node tools/playbot/sim/ex-scenes.js` の出力(シミュレーター 4 版目 = トレーニング入り・間合いボーナスを入れる前で回した)。シミュレーター(battle.js)で、同じ seed・同じ供モンのまま、使い方だけ変えて回した。
「差」は best − bot の平均 WAVE(大きいほど、ボットの使い方を直すと伸びる)。場面は勇者モンの EX だけを数えた。
ターンはその WAVE の何ターン目か。予告は使ったターンの敵の予告。ライフ・敵の残りは使う前の割合(EX は使う子のライフ、アシカは立っている子でいちばん細った子のライフ)。
