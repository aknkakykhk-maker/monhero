# アシカ(アシストカード)の Tier(タクティクスプロ)

更新: 2026-10-10 13:20(JST)・シミュレーター: 1マス 100 回(26体 × 使い方2通り。シミュレーター 8 版目(7 版目+緊急回復はボットと同じ「AUTO の条件 → 全滅の手前」・上手な EX はボス戦のぶんを残す))・実戦: 173 回

研究所(シミュレーター: ダイスくん)。各カードを「そのカードを優先して選ぶ」設定にしてシミュレーターで回し、届いた WAVE の差で決めます。強さはスキル込み(EX・勇者特性・固有技を入れたシミュレーター)。**Tier は上手な使い方の数字だけで決めます**(ボットの数字は「ボットの使い方で弱く見えているカード」にだけ使う)。

緊急回復は直したボットと同じ条件(AUTO の条件 → だめなら全滅の手前。EX を使ったターンは押さない)で測った。ガッツの少ない子は押す回数が多く、伸びやすい。

まだ入れていない・一部だけの機能(シミュレーターかボットに無く、この Tier の数字に効いていないもの。効きの大きい順): トレーニングの選び方(一部)・起こす(復活)の判断(一部)・アシカの選び方(一部)・魂格(入っていない)・強化ポイントでガッツ(入っていない)・極限の特別ルール(入っていない)。機能の一覧は docs/playbot/reports/tier/mechanics.md。この表の数字は、シミュレーター 8 版目(7 版目+緊急回復はボットと同じ「AUTO の条件 → 全滅の手前」・上手な EX はボス戦のぶんを残す)で回したもの。

## 総合 Tier

- **A** ももすけのおねだり・みゅあの愛・ニコラオの力(暫定)・ポルツの弁当

- **C** かどみうむの計算・ドラの緑膝(暫定)・みゃるの薬(暫定)

暫定 = 実戦でそのカードを選んだ回が5回以上ある難易度が2つ未満(シミュレーターの数字だけで決めたもの)。

## ひとことの理由

- **ももすけのおねだり**: ガッツのカード。優先すると WAVE +0.6。Expert では S(WAVE +1.0)。自動ガッツ回復(毎ターン5%)を入れたシミュレーターでも、ガッツを補うと伸びる
- **みゅあの愛**: 回復のカード。優先すると WAVE +0.5
- **ニコラオの力**: 火力のカード。優先すると WAVE +0.4。ボットの使い方では弱く見えている
- **ポルツの弁当**: ガッツのカード。優先すると WAVE +0.3
- **あつの挑発**: 優先しても平均なみ(WAVE +0.3)。Master では A(WAVE +0.3)。ボットは必ず最初に選ぶ
- **ききの応援**: 優先しても平均なみ(WAVE +0.1)。Hard では A(WAVE +0.3)
- **メロソの解析**: 優先しても平均なみ(WAVE -0.2)。ボットは使い渋るが、上手に使っても弱い
- **かどみうむの計算**: 優先すると WAVE -0.6。ほかのカードを選んだほうが伸びる
- **ドラの緑膝**: 優先すると WAVE -0.6。ほかのカードを選んだほうが伸びる
- **みゃるの薬**: 優先すると WAVE -0.7。ほかのカードを選んだほうが伸びる。ボットは使い渋るが、上手に使っても弱い

- **ポルツの弁当**: モノリス(+1.2)・モッチー(+1.1)・ユグドラシル(+1.1)

- **ききの応援**: モッチー(+0.5)・メルホイップ(+0.5)・ミタラシ(+0.5)
- **メロソの解析**: 剣士モッチー(+0.4)・パンドラ(+0.2)・スプーキー(+0.2)
- **かどみうむの計算**: 合う子は見つからなかった(いちばん下がりにくいのはザン WAVE -0.3)

## 実戦の記録について

実戦(ブラウザでボットが戦った回)は、ボットがほぼ毎回「あつの挑発」を最初に選ぶため、カードごとの回数がとても偏っています。差は「そのカードを選んだ回の届いた WAVE − その難易度の平均」で、選んだ回が少ないカードは当てになりません。アシカを順番に選ぶ回(ボットの rotate)は回数には数えますが、差の計算には入れていません(勇者モンの強さが混ざるため)。
もう1つの偏り: あとの WAVE で選ぶカード(2枚目・3枚目)は、そこまで届いた回にしか出てきません。そのため実戦の差は、ほとんどのカードで大きくプラスに出ます(生き残りの偏り)。いちばん最初に選ばれる「あつの挑発」だけが 0 前後になるのはこのためです。Tier は実戦の差では決めず、シミュレーターで決めています。

## シミュレーターに入れたアシカの効果

`tools/playbot/sim/battle.js`(3 版目)。式は 60-app.jsx から写したもの。

- **ニコラオの力**(ニコラオの力 → ニコラオの気合 → ニコラオの憤怒): 攻撃 +10〜30%(バトル中ずっと)
- **ドラの緑膝**(ドラの緑膝 → ドラの黒膝臭 → ドラの毒膝地獄): 被ダメージ −3〜10%(バトル中ずっと)
- **かどみうむの計算**(かどみうむの計算 → かどみうむの理論 → かどみうむの叡智): ガッツ自動回復・ライフ/ガッツ上限アップ
- **みゅあの愛**(みゅあの愛 → みゅあの深愛 → みゅあの慈愛): 全体のライフ 50〜90% 回復・上限と攻撃アップ
- **あつの挑発**(あつの挑発 → あつの暴言 → あつの怒号): そのターンの敵の行動を無効にして、×1.5〜4.5 で殴る
- **みゃるの薬**(みゃるの薬 → みゃるの怪薬 → みゃるの禁薬): 飲んだ子の次ターン攻撃 ×2〜3・自傷
- **ききの応援**(ききの応援 → ききの本気 → ききの全力全開): 2〜4ターン、1体ずつの枚数 +1・全体連撃アップ
- **メロソの解析**(メロソの解析 → メロソの予測 → メロソの最適解): ライフ・ガッツ 30% 回復と、使った子のガード
- **ポルツの弁当**(ポルツの弁当 → ポルツの挫折 → ポルツの目覚め): 敵の攻撃を受けるたびにガッツ 20% 回復(1〜3回)
- **ももすけのおねだり**(ももすけのおねだり → ももすけのだだこね → ももすけの独り占め): 全体のガッツ 50〜90% 回復・上限と丈夫さアップ
- 選ぶ流れ: ランの始めに1枚(10 枚から)、WAVE 1・3・5・7・9 のあと(強化できる2枚+持っていないカードで4枚)、供モンが入った WAVE 2・4・6 のあと(MAX でないカードから4枚)。2回目からは強化(Lv.3 まで)
- 入れられなかったもの・近づけたもの:
  - アシカの演出(fireTeachingFx)・ポップアップの文字は数えない(効果だけ)
  - デバッグの「すべて解放」と同じく、10 枚すべてを選べる前提(ふだんのプレイは編成の6枚から)
  - EXTREME などの効果倍率(effMul の難易度ぶん)は無い。同じ子が1ターンに2枚目を使ったときの半分(×0.5)だけを数える
  - アシカのポルツは「味方のだれかが敵の攻撃を受けた・ガードで受け止めた」ターンに1回ぶん消化する(ゲームは handleEnemyTurn の tookEnemyAttack)
  - アシカのみゅあ・かどみうむ・ももすけの上限アップは、そのカードの回復のあとで1体ずつの上限へ掛ける(ゲームは permaBuffs が変わったあとの useEffect で掛ける)
  - アシカを選ぶ画面の並び(Math.random の混ぜ方)は seed 付きの乱数で引く。ボットの「ガッツ不足」の数え方は、ガッツが足りずに置けない攻撃カードがあるターンに、ガッツ35%未満の子を1ずつ数える

## 上手な使い方(best)の中身

- 回復(みゅあ・メロソ・ももすけ): 倒れた子がいる・全体のライフ5割未満・だれかが一撃で倒れる攻撃を予告されたとき。ももすけはガッツ35%未満の子がいるときも
- ずっと続く強化(きき・ニコラオ・ポルツ): 2体以上そろってから、敵のライフが3割より多いうちに1ターン1枚。ドラ・かどみうむは攻撃が置けないときだけ(ボットと同じ)
- みゃるの薬: いちばんダメージを出している子に、ライフ6割以上・次のターン撃てるガッツが残るとき・その子が狙われていないときだけ
- あつの挑発: ためる・貫通の構えのほか、だれかが一撃で倒れそうな攻撃も止める
