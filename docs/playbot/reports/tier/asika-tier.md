研究所(シミュレーター: ダイスくん)。各カードを「そのカードを優先して選ぶ」設定にしてシミュレーターで回し、届いた WAVE の差で決めます。強さはスキル込み(EX・勇者特性・固有技を入れたシミュレーター)。**Tier は上手な使い方の数字だけで決めます**(ボットの数字は「ボットの使い方で弱く見えているカード」にだけ使う)。

## 総合 Tier

- **A** みゅあの愛・ももすけのおねだり・あつの挑発・ニコラオの力

## ひとことの理由

- **みゅあの愛**: 回復のカード。優先すると WAVE +0.7。Expert では S(WAVE +1.1)
- **ももすけのおねだり**: ガッツのカード。優先すると WAVE +0.7。Expert では S(WAVE +1.2)。自動ガッツ回復(毎ターン5%)を入れたシミュレーターでも、ガッツを補うと伸びる
- **あつの挑発**: 止めるのカード。優先すると WAVE +0.4。ボットは必ず最初に選ぶ
- **ニコラオの力**: 火力のカード。優先すると WAVE +0.3。ボットの使い方では弱く見えている
- **ポルツの弁当**: 優先しても平均なみ(WAVE +0.2)。Hard では A(WAVE +0.3)
- **ききの応援**: 優先しても平均なみ(WAVE +0.0)
- **メロソの解析**: 優先しても平均なみ(WAVE +0.0)。ボットの使い方では弱く見えている
- **ドラの緑膝**: 優先すると WAVE -0.5。ほかのカードを選んだほうが伸びる
- **かどみうむの計算**: 優先すると WAVE -0.5。ほかのカードを選んだほうが伸びる
- **みゃるの薬**: 優先すると WAVE -0.6。ほかのカードを選んだほうが伸びる。ボットは使い渋るが、上手に使っても弱い
- **きゅうこの譜面**: 優先すると WAVE -0.7。ほかのカードを選んだほうが伸びる

## 実戦の記録について

実戦(ブラウザでボットが戦った回)は、ボットがほぼ毎回「あつの挑発」を最初に選ぶため、カードごとの回数がとても偏っています。差は「そのカードを選んだ回の届いた WAVE − その難易度の平均」で、選んだ回が少ないカードは当てになりません。アシカを順番に選ぶ回(ボットの rotate)は回数には数えますが、差の計算には入れていません(勇者モンの強さが混ざるため)。
もう1つの偏り: あとの WAVE で選ぶカード(2枚目・3枚目)は、そこまで届いた回にしか出てきません。そのため実戦の差は、ほとんどのカードで大きくプラスに出ます(生き残りの偏り)。いちばん最初に選ばれる「あつの挑発」だけが 0 前後になるのはこのためです。Tier は実戦の差では決めず、シミュレーターで決めています。

- 回復(みゅあ・メロソ・ももすけ): 倒れた子がいる・全体のライフ5割未満・だれかが一撃で倒れる攻撃を予告されたとき。ももすけはガッツ35%未満の子がいるときも
