# 味方モンスターの Tier 表(タクティクスプロ・全体で見る決め方 overall の試し)

**試しの表です。公開中の表(monster-tier.md・tier.html)は変えていません。** 決め方 overall: 供モンとして入った回の働き(攻めは頭割り比、守り・支えは入った回の伸び)と、供モンで入った回の伸びを主にし、勇者モンにした回の伸びは重み 0.3(いまの決め方は 1)。プレイヤーの実戦は混ぜていない(--player-weight で混ぜられる)。

更新: 2026-10-22 04:29(JST)・数えた回: 347回(Beginner 3 / Hard 88 / Expert 162 / Master 94)・戦ったモンスター: 26 / 26体・技と間合いまで数えた回: 347回

研究所:ハカセくんが作る。タクティクスプロはベースモンを使うので、全員が同じ条件です。
「すべて解放してバトル」(デバッグ。記録・ランキング・報酬はつかない)で、勇者モンを入れ替えながら少しずつ集めています。
**総合 Tier は、その難易度で5回以上試したマスが2つ以上そろうまで「暫定」です。** 5回以上のマスが1つも無い子は「回数不足」として総合を付けません。回数が増えると Tier は動きます。

## 総合 Tier

- **S** ゴーレム・メロディー・ピクシー・パンドラ
- **A** モノリス・モッチー・ライガー・ミタラシ・ゴースト・ザン
- **B** ユグドラシル・イブリース(暫定)・スプーキー・クロミー(暫定)・ウンディーネ(暫定)・ミーア・メルホイップ・スエゾー
- **C** ハム・プラント・オボロゲソウ・ヤオビクニ(暫定)
- **D** エイキ・スネグーラチカ・剣士モッチー・アーク

境目(3つの難易度とも5回以上あるのに、決め手がぶれの中。上下どちらの段とも言い切れないので、回数はここで止めて暫定のまま置く): イブリース(B)・クロミー(B)・ウンディーネ(B)・ヤオビクニ(C)

決め方: 難易度ごとの点(下の「Tier の決め方」)を Hard 2・Expert 5・Master 3 の重みで合わせる。Hard はほぼ全員が最後の WAVE まで届くので、クリアしたかどうか(クリアは WAVE 11 と数える)だけで差が付き、重みを軽くしている。
数えるのは、直したボット(勇者モン選び・EX の使い方を直したあと)で戦った回だけ。固有技・EX・勇者特性・間合いを使えた回の成績で見る(EX を一度も使えていない子は保留)。
まだ入れていない・一部だけの機能(シミュレーターかボットに無く、Tier の数字に効いていないもの。効きの大きい順): トレーニングの選び方(一部)・起こす(復活)の判断(一部)・アシカの選び方(一部)・魂格(入っていない)・強化ポイントでガッツ(入っていない)・極限の特別ルール(入っていない)。機能の一覧は docs/playbot/reports/tier/mechanics.md。
ボットの EX の使い方が下手な子(シミュレーターで「上手な使い方 − ボット」が平均 0.2 WAVE 以上)は、直したボット(2026-10-10 から)で勇者モンにした回が 5 回たまるまで「暫定」。
その難易度で5回未満のマスは「*」で、総合には数えない。5回以上のマスが2つ以上ない子は「暫定」、5回以上のマスが1つも無い子は「回数不足」(総合はまだ付けず、* のマスから出した仮の Tier を添える)。回数が増えると Tier は動きます。

## Tier の決め方

ステータスだけでは決めません。次の6つを ◎○△ で見て、理由に「どれが効いてその Tier なのか」を書きます(— はまだ数えていない)。

| 項目 | 見るもの |
| --- | --- |
| 攻め | 頭割り比(その回のダメージ ÷ 味方の平均。1.0 で人並み)。◎ 1.3 以上・○ 0.8 以上 |
| 守り | 打たれ強さ(ライフ×丈夫さ。全員の中で上・中・下)。守り役は、その子が入った回の届いた WAVE |
| 勇者特性 | 勇者モンにした回の届いた WAVE(難易度の平均との差)。◎ +1 以上・○ −1 以上。記録欄に特性の文が出た回数も数える |
| 固有技 | 1回の戦いで撃った回数。◎ 3回以上・○ 1回以上 |
| EX | 1回の戦いで使った回数。◎ 2回以上・○ 1回以上・**未 = 一度も使えていない → Tier を付けず「保留」** |
| 間合い | 間合い適性(零・近・中・遠。立っている枠で A +10%・G −20%)。数えた回があれば、撃ったときの「適性の補正 × 距離の倍率(敵との距離の差で ×1.5 / 1.3 / 1.1 / 0.9)」の平均。◎ 1.4 以上・○ 1.2 以上 |

点(並べる順と S〜D の線引き): 攻め役は頭割り比と勇者の伸び、守り・支え役は入った回の伸びと勇者の伸び。
S ≥ 0.45 > A ≥ 0.15 > B ≥ −0.15 > C ≥ −0.45 > D。勇者モンにした回が3回より少ないうちは、勇者の伸びを軽く見ます。
