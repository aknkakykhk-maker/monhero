# 味方モンスターの Tier 表(タクティクスプロ)

更新: 2026-10-09 16:42(JST)・数えた回: 38回(Hard 1 / Expert 9 / Master 28)・戦ったモンスター: 18 / 26体

研究所:ハカセくんが作る。タクティクスプロはベースモンを使うので、全員が同じ条件です。
「すべて解放してバトル」(デバッグ。記録・ランキング・報酬はつかない)で、勇者モンを入れ替えながら少しずつ集めています。
**試した回数が5回より少ない子は「暫定」です。** 回数が増えると Tier は動きます。

## Tier の決め方

- **攻め役**: 頭割り比(その回のダメージ ÷ 味方の平均。1.0 で人並み)と、勇者モンにしたときの届いた WAVE(難易度の平均との差)
- **守り役・支え役**(EX が かばう・ガード・回復・味方強化など): ダメージでは測れないので、その子が入った回の届いた WAVE と、勇者モンにしたときの WAVE
- S ≥ 0.45 > A ≥ 0.15 > B ≥ −0.15 > C ≥ −0.45 > D(点はこの2つの平均。勇者モンにした回が3回より少ないうちは、勇者の伸びを軽く見る)
