# タクティクスプロ 勝ち負けに効く機能の一覧

研究所:部長ハカセくんの資料(2026-10-10)。ゲームのコード(60-app.jsx・32-tactics-units.jsx・17/18/19/22 の parts・data/)と、シミュレーター `tools/playbot/sim/battle.js`(4版目)・ボット `tools/playbot/scenarios/tactics-brain.js` を読んで作った。研究の対象は Hard・Expert・Master。

- 「シミュ」= シミュレーター、「ボット」= ブラウザのボット(実戦)。ボットは画面の見込みの数字(ダメージ・ガード・予告のダメージ)を読むので、式の中身は数字に乗るぶんだけ判断に入る
- 「Tier」欄: どちらかに入っていれば「入っている(シミュ/実戦/両方)」。両方とも欠けがあれば「一部」。どちらにも無ければ「入っていない」
- 行番号は 2026-10-10 の 60-app.jsx のもの

## 入っていない・一部(勝ち負けへの効きの大きい順)

1. **固有技の強化(一部)** … 3回の加入で合わせて3〜12 Lv。1 Lv で倍率+0.5なので、固有技は2〜3倍になる。シミュレーターは Lv0 のまま
2. **緊急回復(入っていない)** … 全員30%をいつでも何回でも使える(回数の上限が無いのはコードで確か。AUTO もガッツ切れで使う)。全滅の手前で立て直せる。ただし手番を1つ失うので、20ターン上限との引き換え
3. **トレーニングの選び方(一部)** … 1 WAVE に1体2回の複利。ドミノ倒しを選ばないので、火力の伸びを試せていない。丸太うけでガードが最大4枚に増え、攻撃カードを引きにくくなる
4. **起こす(復活)の判断(一部)** … 主力が倒れたまま WAVE をまたぐと火力が半分になる。1ランに1回しか考えない
5. **アシカの選び方(一部)** … 永続のもの(おりょう・ドラ・ポルツ)は早く取るほど効くが、残り WAVE を見ていない。シミュレーターは10枚すべて選べる前提
6. **魂格(入っていない)** … 育てたマスモンでは大きいが、Tier の研究は素のモンスターなので0。実際のプレイヤーとの差になる
7. **強化ポイントでガッツ(入っていない)** … 1ポイントで+10だけ。固有技の強化と取り合うので小さい
8. **極限の特別ルール(入っていない)** … Hard〜Master の Tier には効かない

入れたもの: WAVE 報酬の間合いボーナスと供モンの間合い追いつき(2026-10-10 シミュレーター 5 版目。4 版目までは通常技・距離撃の段階がずっと Lv0 で、与ダメの倍率にも入っていなかった)。

ほかに、Tier では「入っている(実戦)」だが**シミュレーターには欠けがある**もの: 魂格の枚数+1・パンドラの引き継ぎ固有技・剣士モッチーの初期スタイル・供モン選び。
