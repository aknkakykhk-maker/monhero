# 簡易シミュレーター(タクティクスプロ・Hard / Expert / Master・各 300 回・EX の使い方 none / bot / best)

`node tools/playbot/sim/battle.js` の出力(7 版目・スキル・アシカ・トレーニング・間合いボーナス・固有技の強化・緊急回復入り。トレーニング bot・アシカ bot・間合いボーナス on・固有技の強化 on・緊急回復 auto)。式はゲームのコード(60-app.jsx・19-difficulties・22-enemy・32-tactics-units)から写したもの。

**2 版目で入れたもの**(社長の決まり「ステは弱いけどスキル系で調整してるから、そこもちゃんと見て判断して」):

- **EX 26 体ぶん(effect 23 種)**: 発動・持続(ターン数/WAVE/スタイル)・回数(1ラン/1WAVE)・併用できない EX はその子だけカードを使えない、まで 32-tactics-units.jsx の関数で数える
- **固有技の長く続く効果**: モッチー/ミタラシの敵被ダメ+10%(WAVE)・味方被ダメ−3%(永続)、ゴーレムの与ダメ+7.5%(永続)、ザン/エイキ/剣士モッチーの連撃ダメージ+3%(永続)、
  剣士モッチーの連撃パワー、ピクシー/ミーアの次ターン消費0、ライガーの次ターン会心確定・会心率/会心ダメ+2%、モノリスの丈夫さ+3%・敵の攻撃−10%(WAVE)・次ターン反射、
  アーク/イブリースの追撃・次ターン被ダメ半分・消費ガッツ増・倍率+0.1、大樹の加護/ピンク音符/メロディ・ボゥ(被ダメ減2ターン・回復・クッキー・与ダメ+5%積み)、
  パンドラの双極共振(2ターン消費半減)、絶氷の楔(5ターン移動封じ・敵の与ダメ−30%・消費ガッツ−3%積み)、運命のコイン/運命の輪の積み
- **勇者特性すべて**: 連撃(ザン)・桜花連舞(エイキ)・黒の剣士(剣士モッチー)・禁忌解錠(パンドラ。buildAttackHits が heroId で見分ける)、怪力・魔力開放・もち肌・中二病・眼力・
  俊足/反射/吸収・生命の源・氷海の支配者・トリックスタート・メロディの手作りクッキー・クロミノート・連続攻撃(枚数+1)
- **間合い**: 勇者モンはいちばん得意な枠、供モンは空いた枠のうち得意なもの。引き寄せの距離撃はボット(decidePick の pull: いちばんダメージを出した子の距離)に合わせた

**EX の使い方**: `bot` = いまのボットの決め方(tactics-brain.js maybeUseEx と同じ条件)。`best` = 上手な使い方(回避・カウンターは狙われたターンに必ず、
火力・強化は手強い WAVE の始めに、守りは重い攻撃の前に、回復は倒れた子・細った子へ。ザンの血踊は敵が同じ距離にいなければ距離撃で引き寄せる)。
bot と best の差が大きい子ほど「ボットの EX の使い方が下手で負けている」。

**近似したもの・まだ入れていないもの**:

- パンドラの箱の「最後の希望」の反動(次の1ターン動けない)は、ゲームと同じく nextTurnBuffs へ書く(ターン終わりの入れ替えのあとに書くので、実際に止まるのはその次のターン)
- 氷海の支配者(人魚3体の勇者特性)の「敵と同じ距離」は、ターンの始めの敵の距離で見る(ゲームも描き直し前の enemyDist を見る)
- ゲームは1ターンのあいだ permaBuffs・waveBuffs・turnBuffs を「ターンの始めの値」で読む(React の state)。ここもターンの始めに写しを取って読む。ref で持つもの(EX の状態・クッキー・黒音符・運命の輪・運命のコイン/輪の積み)はその場の値
- スネグーラチカのプレゼント・コイン・輪・乱心などの乱数は seed 付きの乱数で引く
- 剣士モッチーの初期スタイルは片手剣(配置の画面で選べる初期スタイルは選ばない)。bot は EX で二刀流へ、best は勇者なら二刀流・供モンなら片手盾へ切り替える
- ボットの「見込みのダメージ」は画面の数字を読むが、ここでは同じ式(getDmg・被ダメージ)で出す
- 魂格は入れていない(Tier の対象外。素のモンスターで比べる)。強化ポイントはすべて固有技へ使う(ガッツ+10 には使わない。ボットと同じ)
- 緊急回復は AUTO と同じ条件(出せるカードが無く、ガッツさえあれば出せるとき)だけ。ブラウザのボットは緊急回復を使わないので、実戦とのずれを見るときは --emergency none も並べる
- トレーニングの選び方はボットと同じ(丸太うけ+走り込み。ガッツの少ない子は丸太うけ+猛勉強。倒れた子を起こすかはランで1回だけ考える)。上手な選び方はまだ無い
- アシカのポルツは「味方のだれかが敵の攻撃を受けた・ガードで受け止めた」ターンに1回ぶん消化する(ゲームは handleEnemyTurn の tookEnemyAttack)
- アシカのみゅあ・かどみうむ・ももすけの上限アップは、そのカードの回復のあとで1体ずつの上限へ掛ける(ゲームは permaBuffs が変わったあとの useEffect で掛ける)
- アシカを選ぶ画面の並び(Math.random の混ぜ方)は seed 付きの乱数で引く。ボットの「ガッツ不足」の数え方は、ガッツが足りずに置けない攻撃カードがあるターンに、ガッツ35%未満の子を1ずつ数える

編成: 勇者モン1体で始め、WAVE 2・4・6 のあとに供モンが1体ずつ加わる(ゲームの POST_WAVE_JOIN_WAVES)。供モンは debugOnly でない子から seed で3体(どの使い方も同じ3体)。
あとから入る子には追いつき補正(残りターン×1%を WAVE ごとに積む)が乗る。敵は編成の総合力で強くなる。
戦い方は tactics-brain.js の decidePick を縮めたもの(とどめ → 予告に合わせた守り → ハムのスタン → ガッツ1あたりの火力で攻撃 → 捨ててガッツを戻す → 余ればガード)。

「届いた WAVE」は負けた WAVE(クリアは 10)。「序盤越え」は WAVE 1〜2(1体の時間)を越えた割合。「EX」は勇者モンが1ランで EX を使った回数の平均。
「ボス戦」は最後の WAVE(覚醒ムー)まで届いた回のうちクリアした割合で、かっこの中は届いた割合。Hard はほぼボス戦で勝ち負けが分かれるので、Hard はここを見る。
「前の版」は 1 版目(スキル無し)の平均 WAVE。

- **いちばん効いたのは間合いボーナス**(Hard −0.66・Expert −0.35 WAVE)。それまでのシミュレーターは素の適性だけで段階を決めていて、素の適性は最高 A(+10%)なので Lv1(15%)に届かず、
  通常技・距離撃がずっと Lv0 だった。しかも間合いボーナスは与ダメの倍率(getDmg 11081)にも掛かる。1ランの例(モッチー Hard): WAVE 4 で最大 +13%・WAVE 6 で +55%・WAVE 10 で +125%
- **ボットと同じ条件(6 版目・EX=bot)では、どの難易度もずれが ±0.2 以内に入った。** EX=best は Expert・Master でシミュレーターのほうが 0.3〜0.5 強い(上手な EX の使い方のぶん。ボットの EX の使い方の差は lab/ex-scenes.md)
- **ボス戦(覚醒ムー)の勝ち率**: Hard でシミュレーター 26%(EX=bot・届いた割合 90%)、実戦 38%(届いた 53 回)。まだシミュレーターのほうが低い。
  ボス戦の残りのずれは、トレーニングの選び方(丸太うけばかりでガードカードが増える)・デッキの組み方(簡略)を疑っている
- **Hard はクリア率で並べる**: 平均 WAVE は全員 9.3〜10.0 に入って差が見えにくい。クリア率は モッチー 46%・ミタラシ 43%・剣士モッチー 36%・スプーキー 34%・ゴーレム 28%(EX=best)が上、イブリース 12%・ザン 13%・オボロゲソウ 14%・ライガー 14%・アーク 15% が下
- **4 版目から順位が大きく動いた子**(EX=best。Hard はクリア率、Expert・Master は平均 WAVE): モノリスが Hard 25 → 11 位・Expert 26 → 15 位・Master 21 → 5 位と大きく上がった
  (わけはまだ確かめていない)。ゴーストは Hard 7 → 17 位、ライガーは Hard 15 → 23 位に下がった。
  ライガーの Hard は、上手な EX(クリア 14%)のほうがボットの EX(22%)より低い。best の「手強い WAVE の始めに雷狼影」は、Hard の後半では合っていない見込み(300 回ずつ。直すのは次)。Expert・Master はモノリスとピクシー(Expert 20 → 25 位)のほかは ±4 位以内
- 子ごとの「実戦 − シミュレーター」は実戦の回数が 1〜4 回の子が多く、ぶれが大きい(下の突き合わせの表)。子ごとの差では式を合わせに行かない
