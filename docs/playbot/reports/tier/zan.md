# ザンの調整案の測り直し(2026-10-10・改善部 Z1〜Z3 を受けて)

研究所:ハカセくん。**案だけ。ゲームの数字は変えていない。** 測ったのはスキル入りシミュレーター(`tools/playbot/sim/battle.js`)で、案ごとにメモリの中だけ数字を置き換えて回した(ゲームのファイルは変えない)。

- 回数: 案ごと・使い方ごと・難易度ごとに **200 回**(供モンは `pickAllies`、乱数の種は同じ)
- 使い方は3通り
  - **ボット**: いまのボットと同じ条件で血踊を使う
  - **上手**: 狙われたターンに必ず使う(敵が別の距離なら引き寄せる)
  - **序盤で使い切る**: WAVE 1〜3 は、血踊が切れていて回数が残っていれば毎ターン使い、あとは「上手」と同じ(改善部 Z2。ザンの弱さは序盤なので)
- 数字は「届く WAVE の平均・WAVE 3 に届いた割合(序盤越え)」

## 読み取り

- **いまの3ターンでは、序盤で使い切っても守りきれない**(2.28・20%)。5ターンなら序盤で使い切る使い方がいちばん効き(3.06・77%)、丈夫さ60(上手 2.98・73%)と同じくらいになる。スキルの作り(よけて殴る)を活かすなら、ステータスより血踊のターンが効く
- **回避の条件を広げる(距離±1)だけでは、ほとんど変わらない**。5ターンと組み合わせると、序盤で使い切る使い方で 3.20・93% まで上がる
- **Master はどの案でも 1.8〜2.0**。ザンだけの問題ではなく、Master の序盤(勇者モン1体)の厳しさが大きい。上げすぎにはならない
- 血踊はもともと社長の指示が「5ターン、ラン5回、併用あり」だった(32-tactics-units.jsx の注釈・更新履歴 2026-10-02 の注釈)。ゲームはいま3ターン。3ターンにしたのが社長の判断だったかの記録は見つかっていない(改善部 Z3)

## 残っていること

- 実戦の裏付け: ザンを勇者モンにした実戦は Expert 1回・Master 1回だけ。ブラウザで Expert を5回ほど足す
- シミュレーターは、まだトレーニング・アシストカードを入れていないぶん、実戦より Expert で平均 +0.9 WAVE 低く出る(案どうしの比べには使えるが、絶対の値は低め)
- 丈夫さの案は、同じく打たれ弱い攻め役のエイキ(ライフ×丈夫さ 8,000)と並べて見るとよい(改善部 Z3)
