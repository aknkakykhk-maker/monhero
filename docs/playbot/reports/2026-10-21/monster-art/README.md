# おしゃべりで味方モンスターの絵を見せる(2026-10-21 開発部)

依頼: 窓口(社長)。「モッチーってどんなモンスター？」のように聞かれたら、答えと一緒にゲームにある公式の絵を見せる。

## 画像(幅 320 / 390)

| 写し | 直す前 | 直したあと |
| --- | --- | --- |
| `*-mocchi-*`「モッチーってどんなモンスター？」 | 字だけ | 答えの下にモッチーの立ち絵 |
| `*-spooky-*`「スプーキーってどんなモンスター？」 | 字だけ | スプーキーと、答えに出たゴーストの立ち絵 |

- 答えの文は写しのために置いた見本の文(本物の答えではない)。直す前と後で同じ文を返している。違いは絵が出るかどうかだけ
- 本物の答えは公開後に Claude アプリで確かめる(この作業の環境からは公開サイトへつながらないため)

## 作り

- 絵: 直前の発言と答えに出た名前から機械で選ぶ(`56-assistant-chat.jsx` の `assistantChatMonsterIds`)。図鑑に並ぶモンスター(debugOnly でないもの)だけ。
  長い名前から照らし(剣士モッチー/モッチー)、前後がカタカナの所は数えない(ハムスター)。多くても3体。
  出すのは `ALL_PLAYER_MONSTERS` の立ち絵(`imgUrl`、無ければ顔アイコン)そのもので、染色はしない。立ち絵の小さな版は無いので、M/B管理などと同じ絵を読み込みを遅らせて出す
- 知識: 図鑑の説明・血統(区分)・タイプ(公開の印 tacticsHate が立っているときだけ)・固有技の名前を、ゲームのデータから機械で作って毎回渡す部分へ入れた(`tools/build-assistant-chat-digest.js` の `loadMonsters`)。
  能力の数字・敵のことは入れない。「書いていないことや、表に無いモンスターは作らず、M/B管理のモンスター図鑑を案内する」決まりも足した。中継役の出し直しは不要

## 見張り

- `tools/assistant/assistant-chat-check.js` ㉔: 毎回渡す部分にモンスターの表と決まりがあり、能力の数字が無い/モッチー・剣士モッチーの立ち絵がそのまま出る/「ハムスター」では出ない
