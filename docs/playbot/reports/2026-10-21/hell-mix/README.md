# HELL の地上と空中の入り乱れ・見分けにくさ(2026-10-21)

社長「新しめの曲のフルが普通のノーツで地上と空中が近辺で入り混じってるのがあるけど、これかなり難易度高いから難易度もっと重く見てほしい」
「空中地上は基本は指を離した位置に置くのが基本」「見分けづらいってのが相当難易度高いんだよ」。

## 数え方(見分けにくい所)

`rhythm-chart-hand-rules.js` の `skyConfusable`。押し始めのノーツどうしで、

- 500ms 以内(同時も含む)
- 横に重なって見える(真ん中の差が2つの幅の半分の和以下)
- 高さ(地上・空中)が違う

組を拾う。重さ(score)は 0〜1 で、近いほど・短いほど重い。形が同じ(タップどうしなど)で高さだけが違う組は重く、形が違えば 0.6 倍。
同じ手が離した位置から1レーン以内で高さを変える(指を離した位置へ・自然な形)は数えない。Lv. の式 v3 は1つにつき 10 × 重さを足す。

## 見分けやすくする手当ての案(作っていない)

見分けにくい所の8〜9割は「形が同じで高さだけ違う」組。

1. 空中のノーツの色・縁取りを地上と別の系統にする(形の違う組と同じく、重さ 0.6 倍ぐらいまで軽くなる見込み)
2. 空中のノーツの真下の地上に影を出し、近いレーンに地上のノーツがあるときは影を濃くする(どちらの高さかを位置で読める)
3. 近いレーンに高さ違いが続くときだけ、空中側に光る外枠を付ける(山場の見分けにくい形を残したままにできる)
