# HELL の地上と空中の入り乱れ(2026-10-21)

社長「新しめの曲のフルが普通のノーツで地上と空中が近辺で入り混じってるのがあるけど、これかなり難易度高いから難易度もっと重く見てほしい。
気安くいれていい譜面の形ではない。空中地上は基本は指を離した位置に置くのが基本」。

## 数え方

250ms 以内に高さ(地上⇔空中)が変わるタップを数える(`rhythm-chart-hand-rules.js` の `skyMixedSwitch`)。

| 種類 | 形 | 重さ(v3) |
| --- | --- | --- |
| 近い(near) | 同じ手が、指を離した位置から1レーン以内で持ち上げる・下ろす | 0.6 軽く |
| 遠い(far) | 同じ手が、1レーンより遠い所で高さを変える | +6 |
| 交互(cross) | 1.5レーン以内のすぐ近くで、別の手が高さを変える | +6 |

「入り乱れ」= 遠い + 交互。

## 2. これからの HELL の作り方(道具の改修・公開中の譜面は1バイトも変わらない)

- `rhythm-hell-mix.js` は空中を付けたあと、入り乱れになった空中のタップを地上へ下ろす(指を離した位置への持ち上げ・下ろしが基本)
- 残してよいのは、歯ごたえが最上位の曲(`topTier:true`)の盛り上がり(`mixedWindows`)だけ
- 試し(書き込みなし)で作り直した場合: SAD SONG 入り乱れ 17 → 1・Lv.43 → 38 / Toward the Stars(short) 42 → 2・Lv.67 → 53
