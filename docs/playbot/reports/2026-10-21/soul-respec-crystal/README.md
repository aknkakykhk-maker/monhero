# 魂格再編の書で、使った魂格の結晶が持ち物に戻る

2026-10-21 バトル部:ブレイブくん。社長「結晶で使った分は結晶にもどる仕様にしたい」への答え。

- 再編の書を使うと、振り分けを全部戻し、その子の `soulBonusPoints` の数だけ魂格の結晶を `mh_owned_items` へ戻して、`soulBonusPoints` を消す(0は保存しない)
- 書の消費・結晶の戻り・個体の書き換えは、`mh_masu_mons` と `mh_owned_items` を1つの取引で保存する(`buildSoulTraitRespec`)。ボーナスを消した個体と結晶を足した持ち物を同時に書くので、二重に戻らない
- 壊れた値(数でない・負)は0として扱い、戻さない。ほかの個体・ランキングの送信には触れない
- 結晶を使っていれば、振り分けが0でも書を使える(結晶を取り戻すため)
- 確認の窓に「魂格の結晶◯個が持ち物に戻ります」と、結晶の数・この子の獲得済み魂格Pの変わり方を出す(0個のときは出さない)
