## ハロウィンのかぼちゃの飾りが字にかかる(2026-10-21 窓口の確認)

- どこで: 画面の枠の下の左右の角のかぼちゃ。中身はその上をスクロールして通るので、透ける札や見出しの字がかぼちゃの上に乗っていた
  (プロフィールの一番下の「助手」・ギフトの「受取期限」・ミッション・ダイヤショップなど6画面。`ja-wrap-check` が直す前の main で6件 NG)
- 直し
  - 枠の画面(`.mh-screen-shell`)は、ハロウィンのときだけ下の余白を 30px にし、かぼちゃをその余白の中に収まる大きさ(幅40px・31px)にした。中身は余白より上で止まるので、スクロールしても字に重ならない
  - 枠の無い画面(モンヒロビート・モンヒロバトルの入口など。`.mh-app` の背景)は、下の端までボタンが並ぶので、かぼちゃを置かないことにした(こうもりと夜空は残す)
- 写し: `pumpkin-before-*` → `pumpkin-after-*`(プロフィールは一番下までずらしたところ・ギフト・モンヒロビートの入口。320/390)
- 見張り: `ja-wrap-check`(22画面×320/390。枠の下の余白の角に、見えている字が乗っていないか)・`kaizen2-layout-check`(CSS の形)
