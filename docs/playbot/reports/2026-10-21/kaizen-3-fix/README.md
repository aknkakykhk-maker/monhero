## N5 ダイヤが10桁になると、HOME(320)の財布の数が読めないほど小さい

- 写しのセーブ: ダイヤ 6,736,760,000・ブリーダーP 123,456,790(改善部と同じ)
- 直す前(`before-home-320.jpg`): 字が 5.9px(ダイヤ)・4.0px(ブリーダーP)
- 直したあと(`after-home-320.jpg`): 「67.3億」9px・「1.23億」8.75px。390 は 10px
- 押すと細かい数が小さな札で出る(`after-home-tap-*.jpg`。2.5秒で消える)
- プロフィールの所持数(`*-profile-*.jpg`)と、マーケットの入口の札も同じ縮め方にした。各ショップの中の大きな欄は細かい数のまま
- 縮め方: 8桁まではそのまま。9桁(1億)から「1.23億」「67.3億」「6,736億」、13桁から「兆」。上から3桁ぶんで、端は切り捨てる(持っていない数に見せない)。保存値は変えない
- 部品: `compactCount`・`CompactCount`(`src/parts/41-screen-ui.jsx`)

## M10 ギフトボックス(320)のカボチャ

- 今の main で確かめた(`m10-gift-now-320.jpg`・`m10-gift-now-390.jpg`。カードが左下のかぼちゃにかかる位置までずらして写した)
- **直っている**: カードの地は不透明(rgb(19,22,48)・不透明度1)で、かぼちゃはカードの下に隠れ、字の上には出ない。かぼちゃが見えるのは、カードの外の余白(画面の左下の角)だけ
- 改善部の写しは、カードの外の角に出ているかぼちゃが「受取期限」の行のすぐ横に見えていたもの。字には重なっていない
