# 手札の「技変更」の札が言葉の途中で折れる(窓口からの指摘)

2026-10-21 バトル部:ブレイブくん。#3210 の battle-after-320 で、攻撃カードの「⇄技変更」が「技変 / 更」と折れていた。

- 原因: 「⇄」と「技変更」が別々の並びの部品で、幅43pxに38pxで収まるはずなのに、文字のほうが縮んで折れていた
- 直し: 札を折り返さない(whitespace-nowrap)にし、「技変更」を縮まない部品に包んだ。新しい盤面・古い盤面の両方
- ほかの札(攻撃・守り・単体・支援・全体)は、320・390 とも1行に収まっていることを測って確かめた(幅に対して文字の幅が足りている)
- 検査: card-name-fit-browser-check に「技変更が2行に折れていないか」を足した
