## M2 戦闘(背の低い画面=高さ640以下)
- 「ログ」「ステータス」「解析」を、絵だけの丸いボタン(28px)にして左上の1行に並べる(名前は aria-label に残る)。前は四隅に置いていて、舞台が低いと上下の角でぶつかった
- 右は「次の行動」の欄だけ。背の低い画面では、ダメージの数字を右の列へ移して3行の高さに収める
- 魂格効果のボタン(出るときだけ)は左下
- 敵の絵には重ねない(丸いボタンは絵の外に収まる幅)
- 味方の枠の名前: 右の印(🔥・EX)を名前の後ろに並べ、印のぶんだけ詰める(前は右84pxを常に空けていて、320で「モ…」)
- 390×844 は今までどおり四隅

## M4 モードえらび・難易度えらび(横幅360未満)
- のぞきの余白を11%→4%、カードの幅を82%→90%(モード・難易度・極限の並び4つ)
- 難易度のカードの「全WAVE詳細」「ランキング」は縦に並べる
- 言葉の途中で折らない(word-break:keep-all): モードの説明・特長の行・記録の下の小さな説明・鍵のかかったボタンの文(この2つは「…」で隠れていたので、幅に関係なく2行まで折る)
