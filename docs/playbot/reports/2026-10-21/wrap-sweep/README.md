| `before2-320-プロフィール` → `after2-320-プロフィール`(390 も同じ) | 「ひとこと」が「まだ書い／ていません」。「アイコン」が「えらびな…」と切れて読めない | 「まだ／書いていません」「えらびなおす」。幅360未満はタイルの余白と絵を詰め、値の字を1段小さく(10px) |

検査が見逃した理由: 言葉の切れ目の道具は「まだ|書い|て|い|ませ|ん」と細かく切るので、「書い／て」も切れ目と見ていた。
ja-wrap-check は、ひらがな同士の間(「の」「を」などの助詞のあとを除く)の折れを言葉の途中と数えるようにした。
8字以下の札が「…」で切れて読めないのも NG にした。直す前の画面ではどちらも NG になる。
