### N1 助手の呼び方で、敬称が重なる

- どこで: 助手がブリーダーを呼ぶ所すべて(HOME の吹き出し・お話・プロフィールの「呼び方」)
- 何が: ブリーダー名「モンヒロくん」で、Lv2〜4 は「モンヒロくんさん、聞いて聞いて！」(`call-san-320.jpg`・起動直後のお話)、Lv5 からは「モンヒロくんちん」(`call-chin-390.jpg`・プロフィールの呼び方の欄)
- 根拠: 呼び名は `assistants.js` の `assistantCallName` が段の `call`(`'{name}さん'`・`'{name}ちん'` など)の `{name}` を名前でそのまま置き換えるだけで、名前の終わりの「くん・さん・ちゃん・様」を見ていない。Lv6 からは呼び方を選べるが、選ばない人は既定のまま
- なぜ困るか: 「〜くん」「〜ちゃん」と付けた名前は多い。助手は毎日何度も呼ぶので、そのたびに変に聞こえる。仲良し度 Lv30 の新しいセリフ(10/21)でも同じことが起きる
- 案:
  1. (おすすめ)呼び名を作るとき、名前の終わりが「くん・さん・ちゃん・様・ちん」なら、段の敬称を付けずに名前だけで呼ぶ(「{name}さん」→「モンヒロくん」)。保存値は変えない
  2. 名前の終わりの敬称を外してから段の敬称を付ける(「モンヒロくん」→「モンヒロちん」)
  3. 今のまま(Lv6 で自分で選び直してもらう)
