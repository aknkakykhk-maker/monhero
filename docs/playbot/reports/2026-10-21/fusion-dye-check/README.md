# 合体の演出の「染めた絵が0枚」(masu/fusion-animation-browser-check の NG)

2026-10-21 バトル部:ブレイブくん。窓口「本当に色が出ていないのか、検査が古いだけかを見分けて」への答え。

## 結論: 検査が古いだけ(プレイヤーに見える不具合ではない)
- 合体の演出で、主(モッチー: 青・赤・緑)も副(スエゾー: 赤・青・黄)も、染めた色で出ている(`fusion-normal-slide.jpg`)
- 検査が古くなっていた点は2つ
  1. 2026-10-13 から、染めた絵は裏の作業で作って1枚に焼き、`blob:` のURLで渡す(15-dye-and-art.jsx)。検査は `data:` の画像だけを数えていた → 両方を数えるようにした
  2. 焼き上がるまで 0〜1.8秒かかる。検査はスライドが始まった直後に数えていて、副の分がまだ届いていなかった → 両方の子に届くまで最大4秒待つ。スライド(0.7秒)のあとの「揺れ」の段の絵でも数える
- 左右それぞれに1枚以上あるか(`dyedPerSide`)も見るようにした(前は合計2枚以上だけ)
- 止まったときに、画面の文字と写真を残す処理を足した

## 気づいたこと(直していない)
- スライドが始まった直後のごく短いあいだ(0〜0.5秒ほど)は、焼き上がる前の元の色で出て、そのあと染めた色に変わる。2体とも画面の外からすべり込んでくる途中なので、目立ちにくい
