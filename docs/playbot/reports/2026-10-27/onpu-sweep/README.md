# 全曲・全難易度の「正しく押したのに MISS」洗い出し(2026-10-27・オンプくん)

テンポ部長の依頼。人の指のボット(`tools/playbot/feel.js`)で、公開曲50曲の全難易度を遊ばせた。
判定ラインの ±150ms 以内で押したのに MISS になった所を拾い、「ボットの押し方のせいか、ゲームの判定のせいか」の見立てを付けた。
配信中の譜面は変えていない(⑩-2)。直し方は案だけ書く。

## 回し方

- `node tools/playbot/feel.js --songs <曲> --difficulty <難易度> --mode touch --raw`(種 20261007・2本並べ)
  - `--mode touch`: 押した合図が抜ける形の端末のくせは入れない。ボットがわざと遅らせて届けるタッチ(端末の遅れのまね)は残るので、一覧からは除いた
  - ホールドの一部で受付の端をわざと押す調べ方(`edgeProbe`)で取れなかった分も、「正しく押した」から外して別に数えた
- 版: MASTER・EXPERT は main bacf61e9、HARD は途中まで同じ版。NORMAL 以降と回し直しは ac15560b〜9ffda539(ボットの曲えらびの直し #3751・#3910 と、端押しの向きの直しが入った版)
- 回せなかった曲(版のある曲など7曲の MASTER・EXPERT・HARD)は、曲えらびの直しのあとに回し直した。MASTER〜EASY は 50曲×5難易度 = 250譜面すべて回せた

### FLICK の見立て

- 同じ所では続けて落ちない(9か所とも、種を変えた2回はどちらも MARVELOUS)。向きのあるもの・上へはじくものの両方で出ていて、位置も片寄っていない
- ただし割合は TAP の約20倍(千回あたり 2.25 と 0.10)。ボットのはじき方は、押してから25ms後に「動く・動く・離す」の3つの合図を同じ瞬間にまとめて送る作り(`lib/feel.js`)
- 見立て: 「譜面の置き方のせい」ではない。ボットの合図の送り方とゲームのフリックの判定のどちらかで、まれに取りこぼしている。どちらのせいかは、この記録だけでは決められない
- 次に確かめるなら: ボットの動く合図を、時間をずらして(数フレームに分けて)送る形にして、割合が下がるかを見る。下がればボットの都合、下がらなければゲームのフリックの判定(はじいた距離・速さの数え方)を見る

## 調べてボットのせいと分かったもの(取り下げた見立て)

- ホールド・スライドの押し始めの MISS は、ほぼ全部、ボットが受付の端をわざと押した所(`edgeProbe`)だった。押す向きが「道の真ん中寄り」に決まっていたので、すぐ隣の同時のノーツの内側を押して、隣に結ばれていた(カゲくんが確かめた)。端押しの向きは、隣のノーツを避けるようにカゲくんが直した(main 1ea88f83)
- 「隣り合う2つが同時に来るとホールドの押し始めが落ちる」という最初の見立ては、これで説明がつくので取り下げた

## HELL について(空中のノーツは、このボットでは測れない)

- `feel.js` は空中のノーツも地上の判定ラインで押す。そのため HELL 26譜面では、空中のノーツがほとんど落ちる(取れない1206か所のうち1143か所が空中)。**空中のノーツの取れない数は、このボットでは測れない**
- 地上のノーツの取れない所(端押し・遅れを除く)は114か所。そのうち107か所は、±0.2秒の中に空中のノーツがある。ボットが空中のノーツを地上で押した指に、隣の地上のノーツが取られた巻き添えと見ている
- 残る7か所: 遅め(+57〜87ms)に押した TAP が6か所(the_city_beneath_the_comets 147.74・dullahan_clockwork 40.36・light_player 124.00・monster_hero_another 38.09・six_eternel_beat 61.16・151.44)と、big_bridge_no_shitou 142.13秒の HOLD(+36ms)
- HELL の空中を確かめるときは、空中を押せる `tools/playbot/rhythm-cross-swap-bot.js` を使う。`feel.js` に空中の線を押す処理を足すのは、別の仕事(テンポ部長)

## まとめ

- 譜面の置き方のせいで、正しく押しても続けて落ちる所は、MASTER〜EASY では見つからなかった
- 気になるのは FLICK のまれな取りこぼし(千回あたり 2.25)。ボットとゲームのどちらのせいかを切り分けるのが次の調べ
