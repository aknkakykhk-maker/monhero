「レイドにも(ヘイトを)実装して」

## ① 編成と距離
- 上に零・近・中・遠の4つの枠。光っている枠に、下の一覧で押した子が入る(枠を押すとその距離が光る)
- 最初に置いた子が勇者モン(👑勇者)。ほかの子は「👑にする」で勇者モンに替えられる
- 枠には、置いた子のその距離での適性(%)。一覧の子には、光っている距離での適性(%)
- タクティクスと同じく、その距離に立つ子の適性だけが効く(足し算しない)
- 一覧の各子にメインのタイプ。幅360未満は4列
- 別の配置画面(RAID_JACK_PLACE)は無くした

## ② アシカ
- 「次へ」で選ぶ画面へ。上に編成と距離が残る。「← 編成」で戻れる。ここで「この編成で挑戦する」

## タイプ
- 詳細の窓(どの画面も共通の見出し)の名前の下に、メイン・サブのタイプ

## レイドのヘイト
- `tacticsHateOnFor` を `isTacticsMode(mode)` に(タクティクスの盤面のバトル全部)
- 勇者の下地は、戦闘の始めに写した勇者の id で付ける(レイドは勇者を決めた同じ描画で戦闘が始まるため)
