# マーケットの数を直接打ち込む(2026-10-19)

社長「マーケットのアイテムは直接数値入力で買えるようにしよう！」。iPhone の幅(390)で撮影。

| ファイル | 中身 |
| --- | --- |
| `before-1-sheet.png` | 変更前。真ん中の数は表示だけ(−/＋・MAX で選ぶ) |
| `after-1-sheet.png` | 変更後。真ん中の数が打ち込める欄になった(数字のキーボード・20px) |
| `after-2-typed-25.png` | 「25」と打ったところ。合計2,500ダイヤ・残り47,500ダイヤがすぐ出る |

決まり: 空・0 は1、小数は点より前、買える数より多いと買える数にそろえる。欄を離れるとそろえた数を出す。−/＋・MAX はそのまま。
