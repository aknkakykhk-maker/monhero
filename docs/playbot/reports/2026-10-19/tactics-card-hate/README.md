# 行動カードの🔥(使うと上がる量)

2026-10-19 バトル部:ブレイブくん。社長「各カードにヘイト割合も書いたほうがわかりやすいかもね」への答え。

- カードの下の端の真ん中に、使うと🔥がどれだけ上がるかを 🔥(小)・🔥🔥(中)・🔥🔥🔥(大) で出す
- 基準は `TACTICS_HATE.cardFlames`(15・40)の1か所。子に置くと、その子のタイプ・特性の倍率が入る
- 攻撃は与ダメージの割合で変わるので、半分取ったとみなした目安(`cardDmgShareGuess`)
- EX は詳細の「狙われやすさ」の行に出す
