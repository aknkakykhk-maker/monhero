# 編成の枠を上に固定・勇者モンはあとで選ぶ(ジャック・プロモード)

「プロモードはタクティクスやクラシックもこの仕様のほうが見やすいね」(→ 社長の答え「画面の形だけそろえる」)

## ジャックの編成(RaidJackPrepScreen)
- 「いまの編成と距離」の箱を、一覧の流れる枠の外へ出して上に固定。下の一覧だけが流れる
- ① 距離に置く(好きな枠・どの順でも) → ② 勇者モンをえらぶ(置いた子を押すと👑。選び直せる) → ③ アシカ
- 置いた子が1体だけならその子が勇者モン。勇者モンは party[0] になり、ヘイトの下地・ランキングの記録はその子に付く(送る形は同じ)
- 背の低い端末(高さ640以下)は、説明の行を畳み・案内を1行にし・枠の顔を少し小さくする(320×568 で一覧が札2行ぶん見える)

## プロモードの編成(クラシック・タクティクス共通の ProPartyPicker)
- 上に6つの枠(勇者モン+候補5体ぶん)を固定。好きな枠に好きな順で「枠に入れる」
- 6体そろったら「次へ」で、入れた子から勇者モンをえらぶ → 今までどおり距離の配置 → 候補の確認(この編成で開始)
- 候補がWAVEごとに合流する決まり・記録・保存(mh_pro_pick_prefs_v1 など)の形は変えていない
- この画面では助手の吹き出しを出さない。背の低い端末は、説明の行・血統タブ・詳しい情報の絵と数値を畳む
- チュートリアルは今までの1体えらびのまま(指の案内がその形に合わせてある)

## そろえなかったところ
- タクティクスバトル(チャレンジ・クイック・種族チャレンジなど)の勇者モン選び・配置画面: 上の切り替えと下の詳しい情報がもともと固定で、一覧だけが流れる作り。配置画面は一覧が無い。今回は触っていない
