# マルチの相棒(CPU)の染め色が崩れる(2026-10-19)

窓口経由の社長の指摘: CPU「👑あっち~👑」の剣士モッチーが、メンバーの並び(28px)とチャットのアイコン(32px)で
全身ほぼ赤一色・頭の上だけ緑・剣だけ青っぽく見える。

## 原因(CPU の染め絵の作り元)

CPU の色は `RHYTHM_MULTI.summon` が `getMasuColors(masu)` を部位の順の配列 `mc` にして、
心拍(`hb`)で部屋の全員へ送る。受けた側は `clean` で文字を絞り、`RhythmMultiAvatar` が `DyedMonsterImage` へ渡す。
その途中に2つの崩れがあった(10/13 の焼き直しそのものは正しく動いていた)。

1. 送るとき・受けるときの文字の絞り込み(`[^A-Za-z0-9_#:-]`)が `@` を消していた。
   濃さを付けた色(`green@60`)が `green60` になり、色として読めずその部位が染まらない。
2. 表示で `m.mc.filter(Boolean)` していた。染めていない部位(空)を詰めるので、うしろの色が前の部位へずれる。
   剣士モッチーは5部位(肌・コート・髪・左の剣・右の剣)なので、ずれがいちばん目立つ。

## 直したこと

- `rhythmMultiColorId` を作り、送る側・受ける側とも `@` と `.` を通す
- 表示は `m.mc.map((c) => c || null)` で部位の順のまま渡す
- `tools/mode/rhythm-buddy-check.js` に2項目を足した

## 直す前・後
