# マルチの部屋の上の並びで、自分のアイコンが点の散ったように見える(2026-10-19)

社長「前に指摘したモンビーマルチのマスモンの染色ずれなおってないよ」(Android 折りたたみ・部屋の上の並びの左端「選曲中 ♪みゅあ♪*」)。

- 崩れていたのはマスモンの染色ではなく、**プロフィールのアイコンに付けた絵の枠**(社長は `frame_mua_3`「みゅあ・慈愛」のリース・アイコンは `myua_halloween_crying`)。
  上の並び(28px)とチャット(32px)では、細かい飾りのリースが潰れて、アイコンのまわりに白とピンクの点が散ったように見えていた(`report-crop.jpg`)。
  CPU の枠は染めた全身の絵(`DyedMonsterImage`・10/13 の直し)で、こちらは崩れていない
- 直し: `RhythmMultiAvatar` に `small` を足し、小さいとき(上の帯・チャット)は絵の枠を重ねずアイコンだけにする(色の輪の枠はそのまま)。
  待機・準備の大きいカード・ステータスの窓など大きく出す所は今までどおり枠を付ける
- `before-after.png`: 社長の端末と同じ画素密度(2.6倍)で、28px のアイコンを枠つき(直す前)・枠なし(直した後)で描いたもの
- 検査: `tools/mode/rhythm-multi-small-frame-check.js`
