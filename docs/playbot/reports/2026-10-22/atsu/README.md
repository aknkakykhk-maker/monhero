## 決めたこと(窓口の依頼のとおり)

- 一人称「俺」(勢いのあるときに「オレ」)・モンビー呼び・笑いは全角の「笑」・顔文字なし・下ネタなし・です/ます調にしない
- 上の難易度へ誘う(HELL 推し)。ただし遊ぶ人の腕はけなさない(厳しいのは編成のかたより・準備の話だけ)
- 呼び方: あつ→「みゅあ」「きき」「もも」「ドラちゃん」/みゅあ→「あつくん」/きき→「あっくん」/もも→「あつ」/ドラ→「あっくん」
- 仲良し度の段階(30段): 旅の道連れ → パーティの一員(Lv3)→ 背中を預ける仲間(Lv6)→ ギルドの右腕(Lv12)→ 伝説のパーティ(Lv15)→ 永遠の相棒(Lv20)→ ともに世界を救う勇者(Lv30)。ごほうびはほかの4人と同じ表
- 挑発のカードは「あつの挑発、俺が考えたんだよ笑」とセリフで触れるだけ

## 公開のとき(大きい絵が届いたら)

1. 絵を `images/assistant/atsu_*.PNG` と `face/` に置き、`ASSISTANTS` の `tempImageDir`・`tempImageExt` の2行を消す
2. `RELEASE_FLAGS.assistantAtsu` を真にする
3. `node tools/build-assistant-chat-digest.js` で材料を作り直す(公開前は、ほかの助手が「あつ」の名前を出さないよう材料から外してある)
4. 更新履歴と告知を書く(`changelog-help-update` スキル)

`tools/assistant/atsu-check.js` が、印を真にしたのに仮の絵のまま・材料の作り直し忘れを止める。
