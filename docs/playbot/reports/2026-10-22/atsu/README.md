## 決めたこと(窓口の依頼・社長の決めごと台帳のとおり)

- 呼び方: あつ→「みゅあ」「きき」「もも」「ドラちゃん」/みゅあ→「あつくん」/きき→「あっくん」/もも→「あつ」/ドラ→「あっくん」

- 自分で「リーダー」と言わず、まわりを立てる。セリフの最後には必ず「笑」か記号(！？…)か顔文字(台帳 2026-10-22)
- お話の仲間の呼び方: もも→はるちゃん・ともちゃん・みりちゃん・さえちゃん・デムさん/みゅあ→キラボス・らっせ・ろむちゃん/きき→デロチー・デムさん・はるさん(ききとゲズデロは「そこそこ特別な仲」)

## 公開のとき(社長が全文を読んで OK が出たら)

1. `RELEASE_FLAGS.assistantAtsu` を真にする
2. BGMアレンジの「イベント」に「あつ加入のお話 BGM」の枠を並べる(枠と既定の曲はもう入っている: `atsuJoinStoryEvent`)
3. `node tools/build-assistant-chat-digest.js` で材料を作り直す(公開前は、ほかの助手が「あつ」の名前を出さないよう材料から外してある)
4. 更新履歴と告知を書く(`changelog-help-update` スキル)

`tools/assistant/atsu-check.js` が、材料の作り直し忘れなどを止める。
