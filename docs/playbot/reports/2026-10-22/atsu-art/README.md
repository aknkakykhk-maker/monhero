# あつの顔アイコンと立ち絵の見え方(2026-10-22 開発部)

依頼: 窓口(社長「顔アイコンをもっと近くにしたい。立ち絵のバランスが悪い。王冠も見えない」)。
`before-*` が直す前(main f0be4e63)、`after-*` が直したあと。幅は 390×844(縦)と 844×390(横・`-l`)。

| 写し | 直す前 | 直したあと |
| --- | --- | --- |
| `*-icon-list`(アイコンを選ぶ画面)・`*-profile` | 顔アイコンが頭のてっぺん〜胸まで入り、顔が小さい | 顔が枠の6〜7割。王冠は頭の上に少しのぞく。8表情で顔の位置をそろえた |
| `*-battle-entry-p` / `-l`(モンヒロバトルの入口)・`*-rhythm-entry-p` / `-l`(モンヒロビートのモードえらび) | 頭が枠の上で切れて王冠が見えない・体が右下に寄る | 王冠のてっぺんまで入り、頭の中心を枠の真ん中にそろえた |

- 顔アイコン: `tools/make-assistant-faces.js` の あつの切り出し(0.62・-0.02 → 0.40・0.05、横へ 0.10 ずらす。髪が左へ広がるぶん顔が右に出るため)。
  吹き出しの顔(`images/assistant/face/`)とマーケットの表情アイコン8枚(`images/breeder-icons/atsu_<表情>.png`)は同じ絵
- 立ち絵: `77-screen-rhythm-multi.jsx` の `RHYTHM_MODE_ASSISTANT_FRAMES.atsu`(絵の上端を枠の上から3%・頭の中心=絵の幅の48%を真ん中)。元絵は変えていない
