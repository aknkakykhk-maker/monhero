# 新モンスター イルミネ・ドリーミィ 社長に決めてもらう材料(2026-10-22 開発部)

依頼: 窓口(社長「新モンスター イルミネ(イルミネ×イルミネ) / ドリーミィ(イルミネ×ニャー)」)。
2体はデバッグの「新モンスター確認」にだけ並べてある(案の段階。図鑑・マーケット・ロースターには出ない)。

## もう入れたもの(聞かずに入れてよいもの)

- 立ち絵(余白を切って高さ916px)・顔アイコン(仮に B 案)・図鑑の文(届いた文のまま)
- 待機アニメ: イルミネは体ごとふわふわ・髪の先がゆらゆら / ドリーミィはゆったり息をする・玉の飾りが揺れる(`idle-*.jpg`)
- 円盤石アイコン(絵だけ。マーケットの商品は正式実装のときに足す。いま足すと本番に「近日追加」で見えるため)
- 血統カタログに「イルミネ」「ニャー」(血統アイコンは前から届いていたもの)
- 染色マスク(5部位ずつ・`dye-proposal.png`): 社長「染色マスク イルミネ 5色 ドリーミィ 5色 イメージ見て作ってみて」で開発部が部位を決めた
  - イルミネ: ①黒い体(顔・体・ドレス・脚) ②頭の後ろの黒い髪 ③光る髪とスカートの裏 ④耳と頭の金の飾り ⑤目と体の模様
  - ドリーミィ: ①体の毛(顔・耳・腕・脚・左右の大きな毛) ②雲 ③頭の後ろの縞の帽子 ④玉の飾り ⑤ピンクと水色の飾り(ボタンの目・ハート・服の花・耳のふち)
  - 見本は白・黒・パステル・濃い色。ドリーミィは元が白っぽいので、白で染めるとほぼ変わらない

## 3. 勇者特性(イルミネ種の2体で同じにする案。ゴースト種・ユグドラシル種と同じ形)

- 案A「影潜み」: 勇者モン選択時、被弾時25%の確率で攻撃をかわす。かわした次の攻撃のダメージ+50%
- 案B「月影の護り」: 勇者モン選択時、味方全体の被ダメージ15%軽減。この子のライフが50%以下のあいだは与ダメージ+20%
- 案C「シャドウステップ」: 勇者モン選択時、攻撃後30%の確率で与ダメージ30%の追撃。被弾時15%の確率でかわす

## 4. 固有技(消費ガッツ = 倍率×20)

- イルミネ: ×2.6・消費52。効果の案
  - 案A「ボディーガード」: このターンから2ターン、味方の被ダメージ35%軽減＆被弾するたびにガッツ5%回復
  - 案B「影縫い」: 40%の確率で敵を次のターン行動不能＆敵の与ダメージ−20%(2ターン)
- ドリーミィ: ×2.4・消費48。効果の案
  - 案A「おもちゃの爆弾」: 与ダメージの30%で追撃(爆発)＆敵の被ダメージ+10%(そのWAVEのあいだ・3回まで重なる)
  - 案B「ぬいぐるみの身代わり」: 次の被弾を1回だけ0にする＆最大ガッツの15%回復

## 8. モンヒロビートの能力(血統ごと。能力は主血統で決まる)

- イルミネ血統(2体とも主血統がイルミネなので、2体ともこの能力になる)
  - 案A 新しい能力「影潜み」: 8秒のあいだ、BAD を GREAT に引き上げる(MISS はそのまま)
  - 案B 新しい能力「月明かり」: 10秒のあいだ、ノーツのスコア+20%
  - 案C 既存の「必死」(7秒のあいだ GREAT・EXCELLENT を MARVELOUS へ)と同じにする
- ニャー血統: いまは主血統になる子がいない(ドリーミィの副血統だけ)ので、能力はまだ決めなくてよい。決めるなら既存の「元気」案
