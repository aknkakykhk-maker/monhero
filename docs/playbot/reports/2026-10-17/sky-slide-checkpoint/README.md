# HELL の空中のスライドも、地上と同じくチェックポイントで判定する

社長「スライドとかで外れたらミス判定になるの早くない？」「今までって判定箇所があって、それを何%分外したらその分判定が下がってくとかじゃなかったっけ？」。作: ビート部:部長テンポくん。

- 空中のスライドは、指が外れて120ms でその場で切れて MISS になっていた(2026-10-10〜)。これをやめ、地上のスライドと同じく途中で切らない。
  外れているあいだに通ったチェックポイントを落とし、落とした割合で判定を下げる(`rhythmSlideTrackingFloor`)
- 1本で1ノーツ・1コンボのまま。満点・最大コンボ・譜面・ランキングは変わらない。ホールドは今のまま切れる
- 外れているあいだ帯が暗くなる合図は今までどおり。空中の帯にはチェックポイントの線を描かない(帯がすっきり見えるよう今のまま)

## 自動演奏(Sheriruth HELL・106.77秒始まりの空中のスライド)

| 指の動かし方 | 直す前 | 直したあと |
| --- | --- | --- |
| 108.42秒に外れて、110.0秒に戻る | MISS | GREAT |
| 108.42秒に外れて、戻らない(帯を捨てる) | MISS | BAD |

どちらも外れているあいだは帯が暗くなる(暗かった時間は前後で同じ約1.2秒・5.7秒)。

動画: `sky-slide-checkpoint-yoko.mp4`(上が直す前・下が直したあと・107.5〜115.8秒)。
見た目の差は小さく(どちらも外れているあいだ暗くなる)、違いは最後の判定に出る。
