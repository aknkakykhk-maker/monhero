# ホールド・スライドで線を通るたびに光・音・コンボのはね(案A・2026-10-17)

社長「ホールドとかスライドで、他ゲーはコンボ増えてくけど、あれのほうが爽快感はある」→ 案A(見た目と音だけ足す。数え方は変えない)。作: ビート部:部長テンポくん。

## 何をしたか

- ホールド・スライドを押さえたまま判定の線(チェックポイント)を通るたびに、**小さな光の弾け**(判定ラインの上・帯の幅の薄い光と小さな十字の星・0.2秒)、
  **小さな音**(高い「チッ」・0.07秒)、**コンボの数字の軽いはね**(1.07倍・0.15秒)を出す
- ホールドには線が無いので、スライドの線と同じ間隔(難易度と譜面のレベルで決まる)で出す(`rhythmHoldTickTimes`。終わりの手前30msには置かない)
- 曲がりの多い帯(HELL など)は線が約45msおきに来るので、1本の帯につき0.1秒に1回までにまとめる
- **落とした線では出さない**(指の処理が、落とさずに通った線でだけ印 `note._rhythmTicks` を増やす)
- コンボの数・スコア・判定・ランキング・最大コンボ・譜面は変えない(判定に使う `checkpointPassed` の数え方はそのまま)
- 演出量「最小」と軽量モードでは光とはねを出さない。音はタップ音の設定と「押さえている間の音の大きさ」に従い、0%なら鳴らない。線が詰まっても70ms以内は重ねて鳴らさない
- **画面の部品を足さない**: 光はノーツの canvas の中(叩いた光とは別の6枠を使い回す)、はねは今あるコンボの数字を `animate` で動かすだけ。音は既にある音の作りを使い、新しく起こさない
- ついでに見つけた不具合: 設定を一度も保存していない端末では、効果音の設定の読み込みが既定値を作らず、押さえている間の音(シャラシャラ)が鳴っていなかった。直した(`cachedRaw` を「まだ読んでいない」から始める)
- 検査: `tools/mode/rhythm-hold-tick-check.js`

## 自動演奏での確認

- Sheriruth MASTER 0〜60秒(取りこぼしなしの設定・main と交互に3回ずつ): コンボはどちらも289(main の3回のうち2回は自動演奏のぶれで116で切れた)。スコアの差は main どうしのぶれ(約±300点)と同じ幅
- 0〜60秒で光が265回・音が209回(70ms以内の重なりを除く)
- 指を捨てる動かし方(Sheriruth HELL・106.77秒始まりの空中のスライド・`--abandon`)で、印が付いた線の数:

| 指の動かし方 | 印が付いた線 | 帯が暗かった時間 |
| --- | --- | --- |
| 外さない | 267本 | 0秒 |
| 108.42秒に外れて、110.0秒に戻る | 241本 | 1.2秒 |
| 108.42秒に外れて、戻らない | 179本 | 5.5秒 |

外れていた時間のぶんだけ、光と音が出る線が減る(落とした線では出ない)。
