# 線通過の演出の作り直し(はっきり分かる強さ・2026-10-17)

#3151 への社長の感想「全然わかんないし音もないし」を受けて作り直した。作: ビート部:部長テンポくん。数え方(コンボの数・スコア・判定・ランキング)は変えていない。

## 何を変えたか

| | #3151 | 作り直し |
| --- | --- | --- |
| 音の大きさ | 「押さえている間の音の大きさ」× 基準 `.007`(叩いた音の約5分の1) | **タップ音量**に従う。基準 `.03`(叩いた音 `.035` に近い) |
| 音の形 | 高いサイン波1つ・0.07秒 | 鈴のような2音(G6 と1オクターブ上・スライドは A6)+ごく短い高い「カッ」の雑音。曲の上でも聞き分けられる「チリッ」 |
| 光 | 細い線と小さな星・0.2秒 | 0.3秒。帯の幅の太い線が白く光って帯の色へ消え、真ん中から十字の星と8本の筋が飛ぶ(ホールドは水色・スライドは桃色) |
| 光の位置(スライド) | 帯の終点のレーンに出ていた(ずれ) | いまの時刻に帯がいるレーン(`rhythmSlideExpectedLane`) |
| コンボの数字 | 1.07倍・0.15秒 | 1.28倍に拡大し、明るく光る(帯の色のにじみ)・0.24秒 |
| 演出量「最小」 | 光もはねも出さない | 線と星だけの控えめな光・1.12倍のはね(最小でも分かる合図は残す) |
| 軽量モード | 出さない | 出さない(同じ) |

- 1本の帯につき0.1秒に1回までのまとめ・線が詰まったとき70ms以内は音を重ねない・光はノーツの canvas の中(叩いた光とは別の6枠)・画面の部品を足さない、は #3151 のまま
- **iPhone Safari で鳴る経路**: 叩いた音と同じ音の作り(`RHYTHM_NOTE_SE_RUNTIME` の ctx)・同じ出口(割れ止めを通す `output`)で鳴らす。押さえ始めの1回目のタップで音の作りは解錠されている。
  止まっていたら(`suspended`・iPhone の `interrupted`)起こしてから鳴らす。音の作りを新しく起こすことはしない。
  手元のブラウザでは20秒までに26回中26回鳴った(実機の iPhone では確かめられていない)
