# タクティクスのヘイト(確認待ちの試作)

2026-10-17 バトル部:ブレイブくん。社長「試作する」への答え。数字の根拠は [../tactics-hate-numbers.md](../tactics-hate-numbers.md) の★おすすめ。

## 入れ方

デバッグ設定 → いちばん上の「🧪 確認待ちの試作」 → **⚔️ タクティクスのヘイト(試作)** を入。既定は切(切のときは今までとまったく同じ狙い方)。
タクティクスバトルだけに効く(レイドバトル・既存5モードは変わらない)。保存データには触らない(入/切のキー `mh_tactics_hate_proto_v1` だけ)。

## 中身(数字は `32-tactics-units.jsx` の `TACTICS_HATE` の1か所)

- 与ダメージ: そのターンの味方の与ダメージのうち、その子の割合 × 15
- 通常攻撃 +2・固有技 +4・ガード +25(盾は +31)・強化 +5・弱体 +8
- あつの挑発 +40・みゅあの愛 +15/+31.5/+40.5・ももすけのおねだり +7.5/+31.5/+40.5(段ごと。助手のカードは使った子に付く)
- モノリスのかばう +60。モノリスの特性: 増え方 ×1.5・行動のたび +3
- タイプ(メイン)ごとの倍率: タンク ×1.3(ガード +6)・ヒーラー ×1.2・サポーター ×1.1・アタッカー ×1.0・シャドウ ×0.8。表は `MONSTER_TYPES` / `MONSTER_TYPE_OF` の1か所(ヘイトはここから引く)
- 毎ターン3割へる・上限100・倒れたら0・WAVE が変わったら0・勇者は下地20(炎は下地を引いた値で出す)
- 炎: 名前の横(新しい盤面は EX の印の左)に 🔥(20以上)・🔥🔥(50以上)・🔥🔥🔥(80以上)
- 狙いの重み = 今の重み ×(1 + ヘイト ÷ 25)
