# ホールド・スライドの刻みもノーツとして数える(2026-10-17)

社長の決定(窓口経由)。作: ビート部:部長テンポくん。進め方のメモ: [`PLAN.md`](PLAN.md)。見積もり: [`../combo-estimate-v2.md`](../combo-estimate-v2.md)

## 何が変わったか(切り替えの時刻 `RHYTHM_TICK_SWITCH_AT` 以降に始めた演奏)

- ホールド・スライドを押さえているあいだに「刻み」を通る。刻みも1つのノーツとして数え、押さえて通れば JUST MARVELOUS、外れていれば MISS。コンボも1つずつ増える
  - 間隔: EASY〜HARD は4分音符、EXPERT 以上は8分音符(150ms より詰まる速い曲は1段粗く)。帯の折れ点には必ず置く。1本の帯で100ms に1つまで。始まりと終わりの前後40ms には置かない
  - 譜面のデータは変えない(演奏を始めるときに帯と曲の拍の表から作る・`rhythmComboTickTimes`)。曲えらびは「ノーツ数 + 刻み◯」、Lv. は変えない
- スコア: 刻みの重みはふつうのノーツの半分(`rhythmCalculateScoreTicks`)。全部取れば満点は今のまま。今の計算 `rhythmCalculateScore` は変えていない
- フルコンボ・AE・AM は刻みも落とさないことが条件。取った称号は下げない
- ホールドも外れで切らない(スライドと同じ)。外れていた間の刻みだけ MISS。刻みの MISS でライフは減らない。いたずらは刻みの MISS にも効く
- 光・音・コンボのはねは刻みで出す(判定の線ではなく)
- 自己ベストは新キー `mh_rhythm_best_v2`(v1 は書き換えない。クリア・称号の印だけを重ねて見せる)
- ランキング: 新しい記録は `Rhythm-曲-難易度-2` で送り、データベースに足した `rhythm2_*` が数える。今の順位(旧記録)には混ざらない。ランキング画面の「旧記録」で今までの順位も見られる
  - 週間・イベントは、切り替えの時刻より後に終わる期間を新しい物差しで数える(2026-10-17 社長「切り替えちゃっていいよ」で、今週もすぐ切り替えた)。終わった週は今までの物差しのまま。切り替えより前の今週の記録は「旧記録」で見られる。旧の記録を一緒に送る仕組みはやめた
- レイド: 刻みも判定の数に入れる(取った刻みは JUST MARVELOUS・落とした刻みは MISS)。HELL の補正(今まで無くてダメージ0)を MASTER と同じ 1.0 で足した
- マルチ: 通信路を版で分ける(古い版のアプリとは同じ部屋に入らない)
- 遊んだ記録・端末の記録・異変の報告には刻みを入れない(判定の数 `run.counts` はノーツだけ)
