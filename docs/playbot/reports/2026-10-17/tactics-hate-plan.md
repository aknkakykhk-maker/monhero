# タクティクスバトル: 裏ステータス「ヘイト」の案(作らずに案だけ)

2026-10-17 バトル部:ブレイブくん。社長「タクティクスバトルで、裏ステータスでヘイトを作ろうと思うんだけどどう？」への案。
ゲームの数字・コードはまだ何も変えていない。

## いまの狙いの決め方

- `32-tactics-units.jsx` の `chooseTacticsTarget` / `tacticsTargetWeights`。立っている子ごとに **重み = 1 + 2 × (1 − 残りライフの割合)** で抽選する(`TACTICS_TARGET_LOW_HP_BIAS = 2`)。満タンの子は1、瀕死の子は約3
- 狙いは**予告を作るとき**に決まり(`withTacticsTarget`。60-app.jsx の `aimTacticsIntent` はタクティクスのときだけ通る)、吹き出しに「◯◯を狙う」と出る。全体攻撃は狙いなし。間合い攻撃は、その間合いに立つ子がいればその子
- すでに「狙いをそらす」ものが2つある: モノリスの「みんなをかばう」(当たり先をかばう子へ集める)、あつの「挑発」(技の名前。狙いは変えていない)

## 1. ヘイトの増え方と減り方(子ごと・バトル中だけの数)

| できごと | ヘイト | メモ |
| --- | --- | --- |
| 敵へダメージを与えた | +(与えたダメージ ÷ 敵の最大ライフ)× 100 | 敵の最大ライフの1%で+1。1回の攻撃は上限 +30 |
| 味方を回復した | +回復した量 ÷ 味方の最大ライフ × 50 | 回復役も少し狙われる |
| 強化・弱体を使った | +5 | 支援役が「狙われない置物」にならない程度 |
| ガードを使った(守りのカード) | +3 | 守る子は少しだけ目立つ |
| 挑発の技(新しく足す) | +40(その場で最大に近づける) | 2ターンで元に戻る強さ |
| 毎ターンの終わり | × 0.7(3割減る) | 何もしなければ2〜3ターンでほぼ0 |
| 倒れた | 0 | 起き上がっても0から |
| 上限 | 100 | 1人に張り付きすぎない |

目安: 主役の攻撃役が毎ターン殴ると 25〜40 あたりで落ち着き、支援役は 5〜10、何もしない子は 0。

## 2. 今の「低いライフを狙う」重みとの合わせ方

**重み = (1 + 2 ×(1 − 残りライフの割合)) × (1 + ヘイト ÷ 50)** をおすすめ。

- ヘイト0なら今と同じ(既存の検査・予告の見え方がそのまま通る)
- ヘイト100で重みが3倍。満タンの攻撃役(1×3=3)と、瀕死で何もしていない子(3×1=3)が同じくらい狙われる → 「攻撃役を守るか、弱った子を守るか」の判断が生まれる
- 掛け算にするのは、ヘイトだけで決まると瀕死の子が安全になりすぎるため。足し算(重み + ヘイト)は数字の桁で効き方が変わって調整しにくい
- 予告を作るときに決めるのは今と同じ(予告と実際の当たり先が食い違わない)

## 3. 見せ方

| 案 | よい点 | 気になる点 |
| --- | --- | --- |
| A. 完全に隠す | 画面がそのまま | 「なぜこの子が狙われた?」が分からず、運に見える |
| B. 予告だけ(今のまま) | 作業が少ない | 狙いが出てから気づくので、先回りの手が打てない |
| **C. 炎のアイコン1〜3段でうっすら(おすすめ)** | 「殴りすぎると狙われる」が見て分かり、ガードや挑発を先に置ける | 枠の札が1つ増える(今のマークの段と同じ場所に入れられる) |

おすすめは C。段は ヘイト 0〜19 = なし / 20〜49 = 🔥 / 50〜79 = 🔥🔥 / 80〜 = 🔥🔥🔥。数字は出さない(裏ステータスのまま)。詳細の窓(枠をタップ)に「狙われやすさ」の一行を足す。

## 4. ヘイトを上げ下げする効果を付ける候補

- **モノリス「みんなをかばう」**: 使ったターン、モノリスのヘイトを +60(かばう役がそのまま狙われ役にもなる。今のかばう動きとかみ合う)
- **あつの技「挑発」**: 名前どおり、使った子のヘイトを +40(今は名前だけで、狙いは変わらない)
- **新しいアシストカード「ひそむ」(案)**: 使った子のヘイトを 0 に戻す。弱った主力を逃がす手
- **守りのカードの上の段(金剛不壊など)**: ガードと一緒にヘイト +15。「盾役」の役割をはっきりさせる
- **敵側**: 一部の敵(知恵のある敵・ボス)は「ヘイトを無視して一番弱い子を狙う」予告を混ぜる。いつも同じ解き方にならないように

## 5. 影響

- **保存データ**: 触らない。ヘイトは `tacticsUnits` の各子に持たせるバトル中だけの数(WAVE をまたいで持つか、WAVE ごとに0へ戻すかは決めてほしい。おすすめは WAVE ごとに0)。セーブ・ランキング・送信には何も足さない
- **既存の5モード(クラシック等)**: 狙いの抽選はタクティクスだけ(`isTacticsMode`)なので影響なし
- **Tier 表・おすすめパーティ**: 動く。攻撃役(ゴーレム・ライガー)が狙われやすくなり、盾役(モノリス)・回復役の値打ちが上がる見込み。公開前にタクティクスくんで Hard を数回回して比べる(研究所の対戦は使わずに、点検の回数で見る)
- **ボットの戦い方**: `tactics-brain.js` の「予告に合わせた守り」はそのまま使える。ヘイトの段を読んで先に守る判断を足すとよりよい(研究所へ回す)
- **検査**: `tactics-units-check.js` に「ヘイト0なら今と同じ重み」「倒れたら0」「上限100」「毎ターン3割減る」を足す

| 1 | ヘイトの数と重みの式・毎ターンの減り・倒れたら0・検査 | 小(半日) |

| 3 | モノリス・あつの技にヘイトの効果を付ける | 小 |

いちばん効くのは「攻撃役を守るか、弱った子を守るか」の迷いが生まれること。見せ方は C(炎の段)がないと運に見えるので、1と2はセットで。
