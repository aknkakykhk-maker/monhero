2026-10-17 バトル部:ブレイブくん。社長「途中で変わるのいいね」(候補3)を入れた。**お話そのものはまだ公開しない**(公開の印 `tacticsTypes` が偽。回想にも出ない。デバッグ設定の「全ストーリーを確認」からだけ見られる)。

- 名乗りまで: **イベントBGM 1**(会話イベントの曲 `tacticsTypesEvent` の既定)
- ドラが前に立つ行(5/12「おでは🛡️タンクだな。…」)から: **戦場の疾風**。今の曲を0.8秒で下げてから替わる
- 仕組み: 会話イベントの台本の行に `bgm:'<曲id>'` を書くと、その行から曲が替わる(`eventScriptBgmAt`・`Audio_.fadeToBGM`)。**`bgm:` の無い今までのお話は何も変わらない**
- 音量: どの曲も -14 LUFS にそろっているので手当てなし。BGM の音量設定はそのまま効く
