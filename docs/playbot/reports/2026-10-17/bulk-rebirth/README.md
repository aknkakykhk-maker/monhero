# まとめて転生(2026-10-17)

社長依頼「転生画面にて、転生可能な各キャラにチェックボックス的なものを設置。すべて選択ボタン…まとめて転生」。iPhone の幅(390)で撮影。

| ファイル | 中身 |
| --- | --- |
| `before-1-list.png` | 変更前の転生の一覧。1体ずつ押して転生するだけ |
| `after-1-list.png` | 変更後。転生できる子のカードの左上に□、下に「すべて選択」「選択を外す」「まとめて転生」 |
| `after-2-select-all.png` | 「すべて選択」。編成中(アーク)とお気に入り(ザン🔒)は選ばない。Lvが足りない子(ゴーレム)には□が無い |
| `after-3-confirm.png` | アークを足して4体で確認。一覧(編成中の印)・得られる物・失う物・必要ダイヤ合計・所持・転生後の残り |
| `after-4-animation.png` / `after-5-done.png` | 転生の演出「4体の転生完了！」と、そのあとの一覧 |
| `bulk-rebirth.mp4` | 12秒。すべて選択 → アークを足す → まとめて転生 → 確認 → 転生 |

決まり: 固有技は上げず、1体ごとに固有技ポイント+1(「あとで決める」と同じ)。結果は1体ずつ転生したときと同じ。
途中でダイヤが足りなくなったら、その手前の子までを転生する。個体とダイヤは1回の取引で保存する。
