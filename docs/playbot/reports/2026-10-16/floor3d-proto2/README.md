# 床と空中の見た目・試作2(2026-10-16)

社長「もっと一目見て空中にある感じにするのって難しいのかな？」「スライドも変わってないよね？」「結局色で覚えてるだけな気がする」。
→ 色は今のまま、**色を抜いても高さで見分けられる**ことを狙って作り直した。作: ビート部:部長テンポくん。
デバッグ専用(既定は切・ふつうのプレイには出ない)。判定の位置・時刻・指の扱いと譜面は変えていない。前の試作: [`../floor3d/README.md`](../floor3d/README.md)

- または「🎵 モンヒロビート デバッグ」の「床と空中の見た目（試作）」で「試作2」
- 試作1 と試作2 は同じ切り替え(同じキー `mh_rhythm_floor3d_proto_v1`)。どちらかの「切」で今の見た目に戻る

## 試作2で変えたこと

| | 試作1 | 試作2 |
| --- | --- | --- |
| 空中のタップの影 | 箱と同じ幅の薄い影(判定の線に近づくと消える) | **ノーツの真下の床に濃い影**(黒62%・白い細い縁)。判定の線の手前まで消さない |
| 影と箱のつなぎ | 細い白線(薄い) | **白い導線(2px)**と、影の真ん中の白い点(参考動画の「導線」) |
| 空中の箱 | 床の遠近に沿って奥へ寝た上の面 | **宙に立った箱**(こちらを向いた面+下の暗い厚み)。床に寝た地上の板と形で分かれる |
| 空中スライド | 帯の下の厚み(2D の描き方のときだけ) | **帯の真下の床に濃い影+帯と影のあいだに手の色の薄い幕と縦の導線**(浮いたリボン)。**帯の描き方の設定に関係なく効く**(試作2のときは GPU の帯を使わず 2D で描く) |
| 地上のノーツ | 床にべったり | 同じ |
| 色 | 今のまま | 今のまま |

近づくにつれて影と箱の間が開くのは、今の空中の高さ(手前ほど高く見える)のまま。

## 重さ(前回と同じ物差し: CPU を4倍遅くした条件・Sheriruth HELL 70〜90秒・横持ち)

1コマの時間(プロファイラなし・2回ずつ):

| | 平均 | 95% | 最長 | 50ms 超 |
| --- | --- | --- | --- | --- |
| 今の見た目 | 44.3 / 42.3ms | 83 / 83ms | 150 / 133ms | 110 / 93コマ |
| 試作1 | 39.6 / 44.4ms | 83 / 83ms | 150 / 150ms | 96 / 109コマ |
| 試作2 | 43.7 / 38.5ms | 100 / 67ms | 150 / 133ms | 94 / 81コマ |

関数ごとの時間(1秒あたり ms・1回ずつ): 毎コマの処理 `tick` 333.9 → 337.3(差は1%)。空中スライド `drawSkySlideZ` 29.9 → 47.2(幕と導線のぶん)、
帯の床の影 `drawSkyShadowBand` 17.0 → 10.9、地上の粒 `drawHead` 31.0 → 18.2(光を描かないぶん)、空中の箱 `drawFloatBox` 2.5。
コマの数字は測るたびのゆれの中で、悪くなっていない。

⚠️ 試作2は、iPhone で既定の「GPU の帯」を使わず 2D で帯を描く(帯の描き方に関係なく効かせるため)。手元のブラウザには GPU が無いので、
この差はここでは測れない。実機で重く感じたら知らせてほしい(そのときは GPU の帯の側にも同じ影と幕を足す)。
