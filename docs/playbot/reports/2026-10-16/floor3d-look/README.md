## 参考動画はなぜ見やすく、立体に見えるのか

| 見る所 | 参考ではこう | 今までの試作で外した所 |
| --- | --- | --- |
| 明るさ | 空中のものはどれも**背景より明るい**(白っぽい板・光る帯)。暗い面が無い | 試作3・段階Aは箱の側面・下を暗くした → 色が沈んで重く見えた |
| 透け具合 | 空中の板も帯も**半透明**。後ろの道が透ける。重なると明るくなる | 不透明な箱・管で後ろが隠れ、込み合う所でごちゃついた |
| 光り方 | 帯は**芯が白く、外へ向かって色がにじむ**(光が足し算で重なる) | 影と暗い面で立体を出そうとした |
| 太さ | 帯は細め。空中の板は**薄い**(厚みはほとんど見せない) | 箱を厚くした |
| カメラの角度 | **低く寝かせたカメラ**。道が画面の上のほうまで長く伸び、奥ほど強く縮む | 今の道の遠近のまま |
| 床と空中の高さの差 | 空中の線が地上の線より大きく上(画面の約4割)。高さの差そのもので空中だと分かる | 同じ(今も約39%) |
| 背景との対比 | 背景は**暗く落ち着いた紫**。光るノーツが浮いて見える | 床の上に影・柱・幕を足して、画面が明るく込み合った |

→ 立体感は「暗い面・影」より「**明るさ・透け・光のにじみ・カメラの奥行き**」から来ている。

## 見本(`look-50s.jpg`=空中のタップ・`look-78s.jpg`=空中スライド。左上から 今/案1/案2/案3)

| 案 | 中身 | 見どころ |
| --- | --- | --- |
| 案1 明るく薄い板+光る縁 | 空中のタップを薄い明るい板にし、縁を光らせる(色のにじみを足し算で) | 厚みを見せず、明るさで空中を分ける。参考の空中の板にいちばん近い |
| 案2 半透明で光る管 | 空中スライドを、白っぽい芯+外へにじむ手の色の光の帯にする(半透明・足し算) | 後ろの道が透け、重なっても見やすい。参考の帯にいちばん近い |
| 案3 案1+案2+カメラを寝かせる | 道の遠近を強くして、奥へ長く伸びる道にする | 奥行きが深くなる。**ただし道の遠近は指の当たり判定と同じ式なので、入れるなら判定もそろえる大きな改修**(見本では見た目だけ) |

## おすすめ

**案1+案2 を先に**(どちらも見た目だけで判定に触れない・重さもほぼ増えない)。案3(カメラ)は、案1+案2を見たあとで「もっと奥行きがほしい」となったときに、判定ごと作り直す改修として別に見積もる。
