# 地上は床に貼り付け・空中は立体の見た目(試作)(2026-10-16)

社長「モンビーのスカイノーツの表示だけど、参考動画みたいに地上は床にべったり、空中は立体感ある表示にするとかって可能？」→「試作を作って見る」。
作: ビート部:部長テンポくん。**デバッグの切り替えだけで入る試作**(既定は切・ふつうのプレイには出ない)。判定の位置・時刻・指の扱いは変えていない。配信中の譜面は触っていない。

## 見方(社長の iPhone)

1. デバッグ設定 → 「🎵 モンヒロビート」を開く → 「**🎵 モンヒロビート デバッグ**」
2. 「**床と空中の見た目（試作）**」で「試作」を押す(もどすときは「今の見た目」)
3. そのまま「曲えらび(全解放)」などから曲を始める(次の演奏から効く)
4. 空中スライドの厚みも見たいときは、同じ画面の「スライドの帯の描き方（検証用）」を「今の描き方」にする
   (iPhone は既定で帯を GPU の部品で描いていて、そちらにはまだ厚みを付けていない)

## 参考動画から読み取ったこと(REFERENCE_VIDEO.md の表)

参考: 社長が送った Grievous Lady の動画(2026-10-11・iPad を机に置いて遊ぶ撮影・854×480・30fps)。
動画とコマは公開リポジトリに置かない決まりなので、ここには文字だけを書く(並べた画像は受け渡しのブランチで窓口へ渡す)。
社長が「もっといい参考動画を撮ってくる」とのことなので、**厚み・影・色の細かい決めは新しい動画を見てから**。

| 項目 | 参考ではこう | こちら(試作) |
| --- | --- | --- |
| 地上のノーツの形 | 床に平たく寝た白く細い板。奥ほど細く・薄く、何段も重なって見える(0:19 ごろ) | 床の遠近に合わせた台形(上の辺が狭く真ん中へ寄る)。奥ほど薄く潰れる |
| 地上の厚み | 手前に来ると、手前の側面が細く見える | 下の辺の下に、少し暗い色の側面の帯 |
| 地上の光 | 光らない | 光らせない(今の見た目は板のまわりが光る) |
| 地上の色 | 白(種類は形で分ける) | **今の色のまま**(タップ水色・フリック桃など。色で種類を分けているので変えていない) |
| 空中のノーツの形 | 空中の線(Sky input)の少し上の、半透明の白い箱。上の面が明るく、手前の面が少し暗い。道の傾きに合わせて斜めに傾く(1:05 ごろ) | 上の面(奥へ狭まって真ん中へ寄る台形)・手前の面・真ん中の側の側面の箱。面は半透明で縁は白 |
| 空中の影 | 箱と同じ形・同じ大きさの、塗った灰色の影が真下の床に落ちる(10/11 の hell-look の控え) | 箱と同じ幅の灰色の影を、床に寝かせた台形で真下に落とす。箱と影は細い白い線でつなぐ(今と同じ) |
| 空中スライド | なめらかな半透明の帯。手前の端が床に着く | 帯の下に暗い同じ形を少しずらして塗り、厚みを見せる(2D の描き方のときだけ) |
| 空中のフリックの印 | 読み取れなかった(この動画では空中フリックがはっきり映るコマが無い) | 今の白い三角のまま(箱の上に載る) |
| 高さ | 空中の線は地上の判定の線から画面の高さの約39%上(10/11 の控え) | 変えていない(判定に関わるため) |
