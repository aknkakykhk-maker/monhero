## 2段目: カメラを寝かせる(道の遠近と押す場所を一緒に替える)

見方: 「🧪 確認待ちの試作」→「🎵 空中の見た目(案3+カメラを寝かせる)」(値 `c3b`)。1段目の見た目に加えて、カメラを寝かせる。

- 奥の幅を細く(.07→.04)・遠くのノーツほど小さく遅く、手前で速く近づく(近づき方 .4→.3)。**道の両端はまっすぐのまま**(曲げると、以前やめた「ラッパの形」に戻るため)

- 判定の時刻・譜面・ランキング・セーブデータは変わらない。既定(試作が切)の遠近は今と1つも変わらない
- 検査 `tools/mode/rhythm-camera-deep-check.js`: 既定が今と同じこと・寝かせても描いたノーツの真ん中を押すとそのレーンに当たること(ずれ 4e-15 レーン)・遠近の値を直接読む所が残っていないこと

## 社長の注文で直したこと(2026-10-16)

社長「試作を入れていると、地上のホールドの始まりの粒が平たい板になって消え、線だけに見えた・全体が重い感じ」。
- 地上の粒(ホールド・スライドの始まりも含む)は、案3では今の見た目と大きさのまま(床の板にしない)
- 空中スライドの光の帯は、**iPhone がふだん使う GPU の帯の描き方のまま**描く(1段目は帯を GPU から外していた。2段目でこれも直る)。GPU の帯の塗り・縁・芯を重ねて同じ見た目にした

| --- | --- | --- | --- | --- |
| 今 | 73.6 / 74.1ms | 117 / 117ms | 200 / 167ms | 210 / 211コマ |
| 2段目 | 79.6 / 76.6ms | 117 / 117ms | 183 / 167ms | 216 / 212コマ |

平均で 4〜8% 重い(光の帯の重ね塗りのぶん)。95%・最長は同じ。iPhone の本物の GPU での差は手元では測れない。
