## 試作3で変えたこと

| | 今 | 試作3 |
| --- | --- | --- |
| 空中の層 | 空中の判定の線だけ | **道と同じ遠近の「ガラスの床」**を空中の高さに描く(奥ほど薄い・横の目・両端のレール)。空中のノーツが出た曲だけ |
| 床と空中のつながり | なし | **道の両端に柱**(奥から手前へ4組・手前ほど太い)。道の上が「箱の中の空間」に見える |
| 空中のタップ | 薄い板 | **厚い立方体**(上の面・前の面・真ん中側の側面。前の面は上から下へ明→暗)。真下の床に**はっきりした影**(黒72%)と、影から箱まで立つ**柱** |
| 空中スライド | 半透明の帯 | **厚みのある管**(帯の下に帯の幅の35%の厚い面)と、帯から床の影へ下りる柱。床の影も濃く。帯の描き方の設定に関係なく効く(試作3では GPU の帯を使わず 2D で描く) |
| 地上 | 光る板 | 床に平たく貼り付いた板(試作1と同じ・光らない) |

空中の層の高さ・遠近は、空中のノーツの高さと同じ式(`rhythmSkyLiftPx`)で出しているので、空中のノーツはちょうどガラスの床の上を流れてくる。
