# 見積もりと実際の時間の台帳

部署が出した見積もりと、実際にかかった時間(依頼を受けてからマージまで。社長の返事待ちは除く)を並べる。
統括部長(窓口)が書き足す。決まりは [RULES.md](RULES.md) 21。

- 見積もりは **AI が実際に手を動かす時間** で出す。人の作業時間のつもりで出さない・余裕を足さない
- 延びる見込みが出たら、延びる理由を具体的に添えて先に窓口へ知らせる
- 窓口は届いた見積もりをこの表の実績と照らし、大きすぎれば中身を確かめて部署へ突き返してから社長へ伝える

## 物差し(2026-10-11 時点の実績)

- 譜面の一部を直す・足す(検査込み): 15〜30分
- 会話場面・説明画面の組み込み(静止画込み): 20分前後
- 見た目の値を足すだけの案出し(静止画込み): 20分前後
- 小さな不具合の直し(原因が見えているもの): 5〜15分
