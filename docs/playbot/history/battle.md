# モンヒロくんバトル班の記録

班のセッションが毎晩いちばん上へ1日ぶんを足す(手順は [`tools/playbot/ROUTINE.md`](../../../tools/playbot/ROUTINE.md) の手順8・9)。
書くこと: 結果のひとこと / 不具合と PR の番号(マージ待ちか) / 出した提案と、ユーザーの返事(**却下・保留もそのまま残す**) / 作り手へ回したいこと / 決まったこと

## 2026-10-07

- 担当を足した(作り手): **タクティクス係**(`tactics`)。タクティクスプロを手で6分遊ぶ。予告で狙われた子が危なければ守りを先に選び、2体以上なら置き場所も選ぶ・EX・ガッツ切れは捨てる。報告は「着いたWAVE」と「危ないときに守った回数」。WAVE の合間で「取り消す」「下げる」「選び直す」は押さない
- 決まったこと: アシストカードの「習得する」の二度押しで挑戦回数が2回数えられていたのは #2282 で直した(タクティクス係が見つけた)
- 担当を足した(作り手): **イベント係**(`event`)。開催中のレイド(ジャック)にバトルで1回挑戦し、バトル速度を上げて20ターン戦い切る(約6分)。残り回数が1回分だけ減るか・与えたダメージ(`raid_jack_hits`)が送られるかを見る。開催していなければ何もしない
- 班のセッションを作った。最初のプレイは 10/11(日)2:5x。そのあとは日曜・水曜の週2回(定期メンテナンス点検と同じ日)
