# 紹介動画「HELLの見どころ」第3版 社長の指示(2026-11-24・原文のまま)

Claude Codeへ。モンヒロビートの紹介動画「HELLの見どころ」を、初代と同じ構成で、今の3曲に替えて作り直してください。最優先は3曲のプレイ映像を指定設定で新しく撮ることです。

対象：aknkakykhk-maker/monhero の最新main
完成品：縦720×1280・60fps・2分12秒・タップ音入りのMP4

■ 1. まず3曲を撮り直す

全曲HELL。撮影設定は以下で統一してください。

・ノーツ速度：10.0
・演出量：ゲーム初期設定の「標準」（effectAmount: 'LIGHT'）
・軽量モード：OFF（lightweightMode: false）
・自動軽減：OFF（autoEffectDown: false）
・タップ音：ON、スタンダード
・その他の演出設定：ゲームの初期値

曲順と採用区間（各30秒）：
1. パンドラ「Rebellion ～Beyond the Lock～」／rebellion／曲内 2:59〜3:29
2. みゅあ「BRAND NEW SKY」／brand_new_sky／曲内 1:37〜2:07
3. きき「全部必殺技でつ」／zenbu_hissatsuwaza／曲内 1:29〜1:59

既存の tools/promo/beat-stage-capture.js を利用し、通常のソロライブ画面をゲーム内の自動入力で演奏してください。速度9.5の旧録画が再利用されないよう、新しい撮影フォルダを使ってください。

最初に「BRAND NEW SKY」の曲内1:42付近を短く撮り、左右同時フリックの直後に、判定ラインから左にオレンジ、右に黄緑の炎が出ることを録画で確認してください。炎が出なければ、実際にゲームが読み込んだ設定とフリック判定を調べてください。演出量は「標準」のままにし、編集で炎を後付けするのも避けてください。確認できたら、その設定で3曲を収録してください。

■ 2. 初代と同じ構図で、冒頭の画質を改善する

見本：tools/art-sources/promo/monhero-beat-stage.mov

初代の場面順・構図・尺・文字位置・音のタイミングを基準にしてください。冒頭の画質が悪いので、同じ構図で撮り直して構いません。ゲーム画面は高解像度で再収録し、イラストは公開済みの元画像から配置、文字は完成解像度で描画してください。

特に冒頭の「本オープン」の集合絵は、初代と同じ公開済みの絵を使用してください。前回作った約38秒の別編集版には公開前のステージ絵が入っているため、素材に使わないでください。

■ 3. 1本の紹介動画に編集する

・約0:34に3曲一覧、約0:38にパンドラ、約1:08にみゅあ、約1:38にきき。最後は初代と同じ構成で締める
・演奏パートは、上にジャケット・曲名・HELL・「NOTE SPEED 10.0」、中央に横長の演奏画面を1段、下にその曲の見どころ字幕を配置する
・全編でズームイン／ズームアウトは使わない。冒頭や曲紹介は固定構図のまま、照明・タイトルに走る光・拍に合わせたカットで見せる。演奏中はノーツ、判定ライン、ゲーム内のフリック炎が見えることを優先する
