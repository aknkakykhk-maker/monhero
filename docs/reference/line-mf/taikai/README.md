# 大会の参考資料(社長と友達でまとめたもの)

2026-11-13 社長が送ってきた LINEモンスターファームの大会画面のスクショ。全部保存する。
画像は縦620pxの jpg に縮めて入れた(元は 924×2000 の PNG)。ファイル名の頭の数字は資料の番号(1=資料①・2=資料2・3=資料3)。

**大会と報酬は分けて管理する(社長の指示)。**
- 大会: [TOURNAMENTS.md](TOURNAMENTS.md)(正本 tournaments.json)… 時期・名前・格・賞金・賞品・地形・天気
- 報酬: [REWARDS.md](REWARDS.md)(正本 rewards.json)… 賞品ごとの効果と、もらえる大会
- 新しい資料が来たら、json の2つに足してから `python3 -I build_md.py` で md を作り直す(md は json から作った写し)
- 資料4(4-IMG_0565〜0573): もちものの画面で、デビュー戦の賞品「洋なし」の正体はカララギマンゴーと分かった。アイテムは1ターンに1回まで使える・所持枠99

画面の見方: 1か月を前半・後半に分け、その時期に出られる大会が並ぶ。大会の札 = 格の記章の色(デビュー=緑・銅・銀・金・青緑=地形の大会)・名前・賞金・印3つ(左=会場 中=地形 右=天気)。
地形の印に★が付くもの(海・砂漠・火山)がある(条件か得意の印)。出る前の「大会参加確認」で賞金と賞品が出て、賞品を押すと効果の説明が出る。
