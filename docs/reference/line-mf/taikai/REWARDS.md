# 大会の報酬(賞品)と効果

正本は rewards.json。効果は賞品を押したときの「アイテム詳細」の文。

## 効果がわかっているもの

- オイリーオイル(小瓶): オイリーの実から作った小瓶タイプのオイル。疲労が小回復する(画像 3-IMG_0557)
  - もらえる大会: 1年目7月前半 あらなみ杯、1年目8月後半 あさがお杯
- アルタケーキ(ピース): モンスターが好んで食べるヘルシーなケーキ。忠誠度が少し上がる(画像 2-IMG_0551)
  - もらえる大会: 1年目7月後半 ホップ杯、1年目8月前半 なないろ杯
- スタープルーン: 使用したターンのみ「人気」が上がりやすくなる不思議な実(画像 3-IMG_0559)
  - もらえる大会: 1年目7月後半 ひまわり杯、1年目8月前半 ミス・マーメイド杯、1年目8月後半 デザート杯、1年目8月後半 フォレスト杯、1年目8月後半 コースト杯、1年目8月後半 ブリザード杯、1年目8月後半 マグマ杯
- カチコチソース: 打たれ強さをきたえる効果がある特製ソース。丈夫さと忠誠度が上がる(画像 1-IMG_0550)
  - もらえる大会: 1年目8月前半 雪月花賞(夏)、1年目8月前半 花水木賞(夏)、1年目8月前半 桔梗賞(夏)
- サケールの果実: 使用したターンのみ「回避」が上がりやすくなる不思議な実(画像 1-IMG_0549)
  - もらえる大会: 1年目8月前半 ミス・マーメイド杯
- ホッカイイラブ(半身): 強いニオイを放つ、海外産海ヘビの串焼き。モンスターの忠誠度が少し上がる(画像 3-IMG_0555)
  - もらえる大会: 1年目8月後半 ヴィーナス杯
