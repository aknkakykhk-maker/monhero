# HELL の空中のノーツの色の組(2026-10-12・デバッグの試作)

社長「やっぱ今までの上フリックの色変えると戸惑う人いるだろうからスカイノーツ変えるほうがいいね」への試作。
上フリックはピンクのまま(全難易度で変えない)。空中のタップと右手の空中の長押しの色を、上フリックのピンクから離す。
左手の空中の長押しは青のまま。金はマスモンのノーツ(同日に既定を金の板にした)に使うので使わない。既定は変えていない。
社長の気づき「スカイノーツの白縁が濃すぎるのも見にくい原因かも」を受けて、組1〜3は白い縁を細く・薄くした版にし、「いまの色のまま縁だけ薄く」も足した。

| 組 | 空中のタップ | 右手の空中の長押し |
| --- | --- | --- |
| いま | 明るい赤(248,113,113)・白い縁 2.4px | 桃(244,114,182)=上フリックと同じ色・白い縁 |
| いまの色・縁を薄く | 明るい赤・縁は薄い赤 1px | 桃・白い縁を薄く細く |
| 組1 | 深い赤(200,30,30)・縁は薄い赤 1px | マゼンタ紫(217,70,239)・縁を薄く |
| 組2 | 白銀(226,232,240)・縁 1px | 深い赤(220,38,38)・縁を薄く |
| 組3 | 深い赤(200,30,30)・縁は薄い赤 1px | 白銀(226,232,240)・縁を薄く |

  - いちばん下は上フリック(ピンク)とマスモンのノーツ(金の板)。HELL の譜面には上フリックが無いので、ほかの画面から同じ倍率で切り出した
