# HELL でもオプションが同じように効くか(2026-10-13)

社長「マスター以下と同じ内容のものを同じように変更できるようにしたい。ヘル専用のものはあってもいいと思う」。
オプションの全項目について、HELL(空中のノーツ・空中の判定線・空中の道)でも効くかをコードで追い、怪しいものは実際に撮って確かめた。

## 項目ごと

| 項目 | HELL で | メモ |
| --- | --- | --- |
| ノーツの速さ・タイミング調整 | 効く | 空中も同じ時刻・同じ判定 |
| ノーツサイズ | 効く | 空中の板・空中の帯の幅にもかかる |
| ノーツの出る位置 | 効く | 空中のノーツも同じ位置から出る |
| 判定ラインの高さ | 効く(**直した**) | 空中の判定線も一緒に動くが、空中の面が1回遅れて描き直されていた。測った高さが変わったらすぐ描き直す |
| 道の幅(横向き) | 効く(**直した**) | 空中の面を作るより後に幅を入れていて、1回遅れていた。先に入れる |
| レーンカバー | 効かなかった→**直した** | 地上の道の形で切っていたので、端の空中の板が横からはみ出し、60%では空中の判定線と判定の文字まで隠れた。空中の道の幅にも合わせ、空中の判定線の手前で止める |
| 判定文字表示・FAST/SLOW 表示 | 効く | 空中の判定の文字にもかかる |
| ずれの表示(数字) | 効く | 空中の判定の文字にも数字が出る |
| ずれの表示(メーター) | 一部 | メーターは地上の判定の上に1つだけで、空中のずれもそこに並ぶ(1本で見るほうが分かりやすいので、このまま) |
| 叩いた場所に判定 | 効かなかった→**直した** | 空中の判定も地上の線に出ていた。空中の判定線の高さに出す |
| アシストモード | 効く | 空中のフリックもタップになる。空中の高さの受け付けはゆるめない |
| ミラー譜面 | 効く | 空中のノーツ・帯も左右が入れ替わり、帯の手(左手の青・右手の桃)も入れ替わる |
| レーン発光 | 効く | 空中を押した光にもかかる |
| タップ音のセット・判定で音を変える・音ごとの大きさ | 効く | 空中を叩いたときの「きらっ」だけはセットと関係ない決まった音(判定ごとの大きさの差は効く) |
| 演出量・軽量モード | 一部→**直した** | 叩いた光は止まっていたが、空中の道の流れる光と明滅が止まっていなかった。軽量モード・「最小」で止める |
| ノーツの動き | 一部 | 空中の帯(既定の見た目)には流れる光が出ない(このまま。空中の帯は見た目を軽くしてあるため) |
| 道の演出 | 地上だけ | 空中の道には出ない(このまま) |
| 判定の演出・にじむ光・モンスターノーツの演出・振動 | 効く | |
| コンボ数・フルコンボ表示・自己ベスト比・ライフ・ラッキーラッシュ・ライブ背景・盛り上がりの光・BGM 音量 など | 関係なし | 画面全体の設定 |

- DOM で描くとき(デバッグで描き方を DOM にしたときだけ。プレイヤーのオプションでは選べない)は、空中のノーツが持ち上がらない。プレイヤーには出ないので、このまま
- コンボ数はもともとレーンカバーの奥にある(地上の譜面でも、真ん中のコンボ数はカバーに隠れる)。HELL では幕が空中の道の幅まで広がるので、右に置いたコンボ数もカバーに隠れることがある

## HELL 専用の設定の案(作るのは社長が選んでから)

HELL を開けた人にだけ、「表示」タブの下に小さく「◆ HELL(空中)」のまとまりを出す。いまデバッグにある切り替えのうち、プレイヤーが好みで変えたいものだけ。

| 案 | 出す項目 | 中身 |
| --- | --- | --- |
| 最小(推奨) | 空中を叩いた柱の光 | 切 / 短い / 奥まで(既定) |
| 少し多め | ＋空中の判定の文字の位置 | 線の下(既定)/ 線の上 |
| 多め | ＋空中の道の見え方 | はっきり(既定)/ 控えめ |
