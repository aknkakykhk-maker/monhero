# 上フリックの色・マスモンのノーツの金(2026-10-12・デバッグの試作)

既定は変えていない。

> **上フリックの色は同日の社長の決定でピンクのまま**(「今までの上フリックの色を変えると戸惑う人がいる」)。切り替えは外し、見分けは空中のノーツの色の組([`../sky-note-colors/`](../sky-note-colors/README.md))で付ける。下の上フリックの絵は検討の記録として残す。

(どちらもページを開いたときに1回だけ読むので、切り替えたらページを読み込み直す)。
