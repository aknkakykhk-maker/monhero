## 2. 止まっているあいだの見え方

- **6.866秒のノーツ2つ(地上TAP・スライド1本目の始点)は、止まっている 406ms のあいだずっと判定線の上に乗ったまま。** 止まる直前(6.460秒)に判定線へ届き、
  そこで止まって 6.866秒に叩く形。速度の設定によらない(止まる間は距離が増えないので)
- 画面だけ見て叩く人は、6.460秒に「届いた」と見て 406ms 早く叩く(判定の窓の外)おそれがある
