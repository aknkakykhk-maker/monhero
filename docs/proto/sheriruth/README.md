道具: `build-proto.js`(試作の譜面を組み立てる)・`record.js`(偽の Supabase で自動演奏して録画する。`python3 tools/serve.py 8899` を立ててから)

## 直したこと(2026-10-10 15:40)

比較動画の左右のずれを直した。最初は「参考動画の時刻 = 曲の時刻 + 0.27秒」としていたが、相関の向きを取り違えていた。
正しくは **参考動画の時刻 = ゲームの音源の時刻 − 0.414秒**(オンプくんが6区間で測った値。元の mp4 の音とでは −0.38秒、差の 34ms はゲームの音源の頭の遅れ)。
試作の譜面は、この誤ったずれで動画を読んだので、2本のアークの始まりが参考より約2拍早い(照合の結果は r2610101500sheri の返信)。

## 空中の段の試作(2026-10-10 17時前・社長「今日、小さな試作を作る」)

- `sheriruth-sky-proto-compare.mp4` … 左が参考譜面、右が「空中の段」つきの試作(自動演奏・ミスなし)。ずれは「参考 = 曲 − 0.414秒」
- 空中の判定ライン(SKY)は、プレイエリアの高さの **72%**(地上の判定ラインは88%・差の16%が `RHYTHM_SKY_LIFT_RATIO`)
- 譜面はオンプくんの下書き(参考動画を1コマずつ読み、16分の格子へ寄せたもの)を `build-sky.js` で組み立てた。2本のスライドは「参考どおり交わる版」。
  **下書きの JSON はリポジトリに置かない**(写しは残さない)。ここにあるのは組み立てた試作の譜面だけ
- 地上タップ85・空中タップ37・ホールド5・スライド4(合わせて131)。試作区間の MASTER は Lv.54

### ゲーム側で足したもの(このブランチだけ)

| どこ | 何 |
| --- | --- |
| 譜面の形 | TAP/FLICK の `skyHeight`(0〜1)、SLIDE の `slidePoints[].sky`(0〜1)・`hand`('L'=水色/'R'=ピンク)。書いていないノーツは地上のまま |
| 見た目(Canvas と WebGL の共通の描画) | 空中の粒は高さぶん持ち上げ、地面に影と柱。水色の枠で地上と見分ける。スライドは点ごとに持ち上げ、地面に影の帯 |
| 空中の判定ライン | 空中のノーツがある譜面だけ `[data-rhythm-sky-line]` を出す |
| 入力 | 空中のノーツがある譜面だけ、地上と空中の真ん中(80%)より上を押した指を「空中」とし、判定ラインの高さの横幅でレーンを測る |
| 判定 | 空中のノーツは空中の指で、地上のノーツは地上の指でだけ取れる。スライドは横の位置だけで追う |

まだ無いもの: 画面の部品(DOM)の描き方・横画面・ミラー/アシスト・譜面を作る道具・検査。
