# Sheriruth 試作(MASTER 30秒・公開しない)

台帳 r2610101500sheri。社長「こんなような譜面をモンビーですることは可能？」→「まず試作だけ見せて」。
**このブランチ(`claude/sheriruth-proto`)だけに置く。main へは入れない。**

- `sheriruth-proto-compare.mp4` … 左が参考譜面(Arcaea)、右がモンヒロビートの試作(自動演奏・取りこぼしなし)。曲の 1:44〜2:16 の同じ区間・音つき
- 曲えらびの「Sheriruth 試作 MASTER 30秒」(songId `sheriruth_proto`)で遊べる(このブランチをローカルで開いたときだけ)

## 置き換え

| 参考譜面 | 試作 |
| --- | --- |
| 2本同時のアーク(交差しながら絡む・108.7〜117.5秒) | 2本同時のスライド(0.5レーン刻み・2拍ごとに曲がる・最後に上へはじく) |
| 最後の2本のアーク(両端から寄って合わさる・129.8〜135秒) | 両端から少しずつ寄り、真ん中で隣り合う2本のスライド |
| スカイノーツ(空中の段) | 2拍目・4拍目のタップを上へはじくフリックに(16個) |
| 地上のタップ・ホールド | 自動生成の MASTER のまま |

作り方: `rhythm-chart-v3-pipeline.js` の自動 MASTER(chartIntensity extreme)から区間を切り出し、
2本のアークの区間だけを手で置き換えた(参考動画を0.5秒ごとに見て、判定ラインでのアークの位置をレーンに写した)。

道具: `build-proto.js`(試作の譜面を組み立てる)・`record.js`(偽の Supabase で自動演奏して録画する。`python3 tools/serve.py 8899` を立ててから)

## 直したこと(2026-10-10 15:40)

比較動画の左右のずれを直した。最初は「参考動画の時刻 = 曲の時刻 + 0.27秒」としていたが、相関の向きを取り違えていた。
正しくは **参考動画の時刻 = ゲームの音源の時刻 − 0.414秒**(オンプくんが6区間で測った値。元の mp4 の音とでは −0.38秒、差の 34ms はゲームの音源の頭の遅れ)。
試作の譜面は、この誤ったずれで動画を読んだので、2本のアークの始まりが参考より約2拍早い(照合の結果は r2610101500sheri の返信)。
