## 決めごと(どの子も共通)

- 演出は「マーク×数」(#2851・#2856)の**代わりではなく上乗せ**。数字は枠の絵の左下、演出は絵の上側・右側に置き、重ねない
- 置くのは**その子の枠の絵のまわりだけ**(ライフ・ガッツの字、名前の帯、狙われの札にはかけない)
- 軽量表示・超省エネでは演出を出さない(数字の「マーク×数」だけ残す)。動きは「動きを減らす」設定で止める
- 絵柄は「マーク×数」と同じく1か所の表にまとめ、あとで差し替えやすくする
