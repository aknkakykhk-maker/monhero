# 空中を叩いた柱の光「奥まで」の直し(2026-10-13)

社長の報告「空中タップの道の光を『奥まで』に設定しても、奥まで出ていない(風がそよぐ場所の HELL)」。

## 原因(3つの描き方で撮って確かめた)

| 描き方 | 前 | 原因 |
| --- | --- | --- |
| GPU(WebGL)・2D(canvas) | 道の形の台形は奥の端まであるが、上の半分がほとんど見えない | 色を道の4割までしか残さず、奥の端で透明(0)まで落としていた(`drawFarBeam` の色の段) |
| DOM | 地上と同じ短い四角い柱を持ち上げただけ(道の形でも奥まででもない) | DOM の部品には「奥まで」が作られていなかった |

設定の切り替え(`RHYTHM_HELL_SKY_HIT`)はその場で効いていて、風がそよぐ場所だけ違うこともなかった。

## 直したこと

- GPU・2D: 色を道の7割まで残し、奥の端にも薄い光(14%)を残す。奥の明るさ(画素の明るさ 0〜255)は 105〜124 → 141〜148
- DOM: 柱を道の幅いっぱいに広げ、canvas 版と同じ台形(奥ほど細い)で切り抜いて奥の端まで出す。色は canvas 版の空中の柱と同じ白紫(#e9d5ff)
- 重さ: GPU・2D は描く数・形が同じ(色の段の位置だけ)。DOM は叩いたときに道の高さを1回読むだけ
