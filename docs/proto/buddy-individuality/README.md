# マスモンの個体差(案)

2026-10-13 ビート部 カゲ。社長「モンビーのマスモンで、喋り方は性格で決まると思うけど、その他にも個体差みたいのをつけたりできる?」→「候補作っといて」。
**案だけ。ゲームのコードは変えていない。** 見本の静止画: [`chat-sample.png`](chat-sample.png)(マルチのチャットの形で、同じ「真面目」の3体が違う話し方をしている所)。

## いまの作り(前提)

- 性格は9つ(`33-rhythm-buddy.jsx` の `RHYTHM_BUDDY_TRAITS`)。ビート Lv.30 で決まる
- おしゃべり(`33-rhythm-buddy-talk.jsx`)は、場面ごとに「性格」「その日の調子」「共通」の3つの束から1つ選ぶ。
  場面は 呼ばれた(join)/曲を選んだ(pick)/曲が決まった(song)/結果(mvp・high・mid・low)/席をゆずる(bump)/人への返事(reply◯◯)/ひとりごと(idle)
- **同じ性格の子は同じ束から選ぶので、ほぼ同じ話し方になる。** 調子(その日の機嫌)で少し変わるだけ
- チャットは40文字まで

## 1. 個体差の候補

どれも「性格の束」を置き換えるのではなく、**上に重ねる**。性格の言葉づかい(真面目は丁寧、頑固は「〜ぞ」など)は崩さない。

| 候補 | 値の例(各10前後) | 性格との組み合わせ | どこで出るか |
| --- | --- | --- | --- |
| **A 一人称** | ぼく / わたし / おれ / あたし / うち / わし / オイラ / 自分 / わたくし / 拙者 | 性格ごとに選べる一人称を決める(例: 真面目=わたし・自分・わたくし・ぼく/頑固=おれ・わし・拙者/甘えん坊=あたし・うち・ぼく/インテリ=わたし・わたくし・ぼく) | 新しく足す「{me}」入りのセリフ(呼ばれた・ひとりごと・結果) |
| **B ブリーダーの呼び方** | ◯◯さん / ◯◯くん / ◯◯ちゃん / ◯◯様 / マスター / 相棒 / ボス / ご主人 / 先輩 / 呼び捨て | 真面目・インテリは「さん・様・マスター」から、甘えん坊は「ちゃん・くん・ご主人」から、頑固・勇敢は「相棒・ボス・呼び捨て」から | 呼んでくれた人への返事(replyThanks・replyCall)、呼ばれたとき(join) |
| **C 口ぐせ(前置き・締めの一言)** | 前置き: よーし、/ えっとね、/ ふむ、/ ねえねえ、/ おっ、/ さてと、/ よいしょ、 締め: …なんてね / ♪ / ってわけ! / 〜 / !! | 語尾を作り変えると文が崩れるので、**文の前後に短い一言を足す**だけ。3回に1回くらい。性格に合わないもの(真面目に「…なんてね」など)は外す | どの場面でも(40文字に収まるときだけ) |
| **D 好きな曲・苦手な曲**(遊びから) | 好き = その子と一緒にいちばん多く遊んだ曲 / 苦手 = 3回以上遊んで成績がいちばん低い曲 | 性格には関係なく、記録から決まる。曲が増えたり遊ぶほど変わる | 曲を選んだとき(pick)・曲が決まったとき(song)・結果が悪かったとき(low) |
| **E 叩き方のくせ** | 早押しぎみ / 遅押しぎみ / ぴったり / 波がある / 出だしが固い / 後半に強い / 速い曲が好き / ゆっくりの曲が好き / 長押しが得意 / スライドが得意 | **見た目とセリフだけ。判定・スコアには使わない**(強さは性格と育て方のまま) | 結果(high・mid・low)のひとこと、ひとりごと |
| **F 小さなこだわり**(好物・趣味) | 好物: プリン / おにぎり / カレー / いちご / 焼き魚 / ドーナツ / ラーメン / りんご / チョコ / お団子 趣味: お昼寝 / 歌 / 星を見る / 散歩 / 本 / おしゃれ / 料理 / 掃除 / 釣り / かけっこ | 性格には関係なく選ぶ(どの性格でも自然な言い方で話す) | ひとりごと(idle)、待っている間 |
| **G 誕生日** | 1年のどこか1日 | — | その日だけ、呼ばれたとき・ひとりごとに一言(「今日、誕生日なんだ!」) |

## 2. 決め方

- **基本は個体番号から決める**(マスモンの id を種にして、候補ごとに別の数をまぜて選ぶ)。
  新しい保存キーは要らない。**今いる子にもすぐ付く**。同じ子なら何度開いても同じ。
  性格が決まる前(Lv.30まで)の子にも、A・B・C・F・G はすぐ付く(性格が決まったら、性格に合う候補の中から選び直す)
- **遊び方から決まるのは D(好き・苦手な曲)だけ**。いまある相棒の記録(`mh_rhythm_buddy_v1` の曲ごとの記録)を**読むだけ**で決める。
  保存の形も中身も変えない(CLAUDE.md ⑦)
- E(叩き方のくせ)は、遊びの結果から決めると「判定に効いている」ように見えて誤解を生むので、個体番号から決める(見た目とセリフだけ)
- どの候補も、性格と合わない組み合わせは表で外す(例: 真面目の子が「おれ」「呼び捨て」にならない)

## 3. セリフの例(同じ「真面目」の3体)

| 場面 | モチ(わたし・あつさん・前置き「よーし、」・プリン・早押しぎみ) | ラム(自分・マスター・締め「!!」・散歩・後半に強い) | コテツ(ぼく・あつくん・前置き「えっとね、」・おにぎり・ぴったり) |
| --- | --- | --- | --- |
| 呼ばれた(join) | よーし、あつさん、よろしくお願いします! | マスター、自分も全力で取り組みます!! | えっとね、ぼくも最後までがんばります! |
| 曲を選んだ(pick) | わたし、Monster Hero がいちばん好きなんです | 自分、この曲で後半に巻き返します!! | えっとね、ぼく、この曲なら落ち着いて叩けます |
| 結果がよかった(high) | よーし、早めに入ったぶんうまくいきました! | 後半で追い上げました!! | ぴったり合わせられました。うれしいです |
| 結果が悪かった(low) | Journey はまだ苦手です…次こそ | 前半で出遅れました。次は最初から!! | えっとね、ちょっとずれちゃいました… |
| ありがとう(replyThanks) | あつさん、こちらこそありがとうございます! | マスター、ありがとうございます!! | あつくん、ありがとうございます! |
| ひとりごと(idle) | 終わったらプリンが食べたいです | 散歩みたいに、一歩ずつ練習します!! | えっとね、おにぎり持ってきました |

※ 曲名はその子の記録から(上の例の曲は仮)。ブリーダー名「あつ」は例。

## 5. 作るときの見込み(AI の手の時間)

| 作業 | 見込み |
| --- | --- |
| 個体番号から候補を選ぶ仕組みと、性格との組み合わせの表(A・B・C・E・F・G) | 40分 |
| 好き・苦手な曲を相棒の記録から読む(D・読むだけ) | 20分 |
| セリフの追加({me}・{you}・{like}・{food} 入り。9性格ぶん、場面ごと) | 50分 |
| 検査(40文字・性格と合わない組み合わせが出ない・同じ子は同じ値・保存値を書かない)と見本の確かめ | 30分 |
| 更新履歴・ヘルプ | 10分 |
| **合計** | **約2時間30分** |

一度に全部ではなく、**A・B・F(一人称・呼び方・好物)だけ先に入れる**なら約1時間20分。
