# モンヒロビートのオプションの整理(2026-10-13・案だけ・まだ作っていない)

社長「モンビーのオプションがごちゃつきそうだから、もっと使いやすく見やすくして」。社長が案を選んでから作る。
どの案も **保存キー・値の意味は変えない**(⑦)。並べ替え・見出し・畳み方・説明文だけ。

## いまの項目(`RhythmOptions` 29-rhythm-screens.jsx)

- タブ3つ(ライブ / 音量 / システム)・枠53・保存する設定56キー。縦画面では項目が2列、横画面では3列
- ライブ 25枠(縦画面で約3,450px)/ 音量 9枠(試聴ボタン6つ)/ システム 19枠(見た目のおまかせの絵4枚)
- 公開の印・HELL・デバッグで出し分ける項目は無い。**HELL・空中の設定はオプションではなくデバッグ画面にある**(公開の日にオプションへ移すかは別に決める)
- 同じ設定をほかでも触る所: 曲えらびの「アシスト」「ミラー譜面」、見た目の「試す」、タイミング合わせ、対戦画面の演出の段、モードえらびの立ち絵・コメント

## 案

| | 案1 タブ4つ+よく触るものを上 | 案2 タブ無し・1枚+まとまりを開け閉め |
| --- | --- | --- |
| 形 | 演奏 / 表示 / 音 / 軽さ・演出 の4タブ。どのタブも上に「★よく触る設定」 | 上に「★よく触る設定」5つ(速さ・タイミング・ノーツサイズ・BGM・タップ音)。下に8つのまとまり(判定ラインと道・判定と数字の表示・マスモン・遊び方・音・見た目と演出・軽さと端末・その他)を開け閉め |
| よい所 | いまのタブに慣れた人が迷いにくい。1つのタブが短くなる(ライブ 25枠 → 演奏 約11枠) | 最初の画面で全体が見渡せる。探す場所が1つ。HELL の設定を足すときも、まとまりを1つ足すだけ |
| 気になる所 | タブを行き来しないと全体が見えない | 開け閉めの手間が1回増える。開いた場所は覚えておく(新しい保存キーを1つ足す・既存のキーは触らない) |
| 作る手間 | 約1時間30分 | 約2時間 |
