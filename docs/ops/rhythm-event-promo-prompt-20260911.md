# モンヒロビート ゲリラ開催 告知画像プロンプト

チャッピー（ChatGPT）へ貼って画像を作らせるためのもの。

**使い方**: 下のプロンプトをコピーして、`曲名A / 曲名B / 曲名C` の行だけ、
画面（全国ランキング → イベント）に出ている3曲へ書き換えて貼る。

---

## 正方形（SNS用・1:1）

```
スマホのリズムゲーム「モンヒロビート」のイベント告知バナーを1枚作って。

正方形。黒〜濃紺の背景に、奥から手前へ流れる光るノーツのレーン。
シアンとマゼンタのネオンで、突然始まったお祭りっぽい勢いのある感じ。
文字は白で大きく、背景に埋もれないように。

画像に入れる文字（この日本語のまま、正確に）:
ゲリラ開催中
今週のモンヒロビート
曲名A / 曲名B / 曲名C
9/14(月)朝5:00まで
```

## 横長・縦長にしたいとき

2行目の「正方形。」を書き換えるだけ。

- 横長（Xのタイムライン向け）: `横長16:9。`
- 縦長（ストーリーズ向け）: `縦長9:16。上下は文字を置かず空けて。`

## ゲーム内バナーにしたいとき

曲名の行を消して、2行目を `細長い帯（横長3:1）。` に変える。帯では曲名まで読めない。

---

## うまくいかないとき

| 気になった点 | 追加で投げる一言 |
| --- | --- |
| 日本語が崩れた | 「文字はいっさい入れずに、背景だけで作り直して」→ あとからCanva等で文字を乗せる |
| 文字が小さい | 「見出しをもっと大きく、横幅の8割まで使って」 |
| ごちゃごちゃ | 「背景の光を半分に減らして、文字まわりを暗く落として」 |
| 曲名が読めない | 「曲名の下に半透明の黒い帯を敷いて」 |

---

## 投稿につける文

```
【ゲリラ開催】モンヒロビートの今週のイベント、予告なしで始まりました。
対象は「曲名A」「曲名B」「曲名C」の3曲。
難易度不問・1曲だけでもOK。9/14(月)朝5:00まで。
https://aknkakykhk-maker.github.io/monhero/
```

---

## 告知の中身（画像に足すときの材料）

- 期間: **9/14（月）朝5:00まで**。以後は毎週月曜5:00で対象曲が入れ替わる
- 部門: 対象曲ごとに3つ ＋「総合」の4つ
- 総合: 対象3曲それぞれのその週のベストを合算（満点 3,000,000点）
- 難易度は不問。1曲だけ遊んだ人も総合に載る
- 参加のしかた: モンヒロビート → 全国ランキング → 「イベント」タブ

> 曲名は正式名称のまま出す。音ゲーの名前も「モンヒロビート」で統一する（「モンビー」は
> キャラクターが愛称として呼ぶ会話でだけ使う・CLAUDE.md ⑤）。
