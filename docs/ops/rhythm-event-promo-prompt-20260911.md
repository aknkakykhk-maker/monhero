## 3. バリエーション

### 3-1. 横長（16:9・Xのタイムライン向け）

メインのプロンプトの【用途・サイズ】と【レイアウト】だけを次に差し替える。

```
【用途・サイズ】
- SNS投稿用の横長（16:9、1200×675px 相当）

【レイアウト】
- 左半分：「ゲリラ開催中」のタグ ＋ 大見出し「今週のモンヒロビート」 ＋ 期限「9/14（月）朝5:00まで」
- 右半分：奥へ伸びるノーツレーンと、そこへ重ねた対象3曲のタイトルカード（縦に3枚）
- 左右の境目ははっきり分けず、光でなじませる
```

### 3-2. 縦長（9:16・ストーリーズ向け）

```
【用途・サイズ】
- ストーリーズ投稿用の縦長（9:16、1080×1920px 相当）

【レイアウト】
- 上下それぞれ250px は文字を置かない（UIに隠れるため）
- 上から：「ゲリラ開催中」タグ → 大見出し → 対象3曲のカード（縦積み）→ 期限 → 最下部の案内
- 背景のノーツレーンは画面いっぱいに、下から上へ流れる形で
```

### 3-3. 助手（みゅあ）を入れる版

キャラを添えたいときは、【レイアウト】の最後へ次を足す。
画像生成AIは既存キャラをそのままは描けないので、**特徴を文で伝える**形にしてある。

```
- 右下に、案内役の女の子を胸から上まで小さく配置する（画面の1/4以内）
  ・淡いブロンドの巻き毛のツインテール、白いリボン
  ・金色の装飾が入った白いドレス、背に小さな白い羽
  ・目を細めて楽しそうに笑っている表情
  ・水彩のようにやわらかいアニメ塗り。線は細く、影は薄い
  ・文字の上に重ならないこと
```

### 3-4. ゲーム内バナー（横長の帯）

```
【用途・サイズ】
- アプリ内に貼る横長の帯バナー（1200×300px 相当、3:1弱）

【レイアウト】
- 左に「ゲリラ開催中」の赤タグと大見出し「今週のモンヒロビート」
- 右に期限「9/14（月）朝5:00まで」
- 曲名は入れない（帯では読めないため）。背景に細く光るノーツレーンだけ流す
```

## 5. 日本語が崩れるときの逃げ道

画像生成は漢字を崩しやすい。3回作り直しても直らなければ、**文字なしで作らせて後から乗せる**。

```
（メインのプロンプトの【画像に入れる文字】を、まるごと次に差し替える）

【文字】
- 文字はいっさい入れないでください。背景とレーンと光だけの画像にしてください
- あとから文字を乗せるので、次の場所は暗いまま・模様を置かないでください
  ・上から15%の帯（見出し用）
  ・中央の縦半分（曲名用）
  ・下から20%の帯（期限用）
```

出てきた画像に、Canva・Keynote・PowerPointなどで §4 の文字を乗せる。
フォントは太めのゴシック（源ノ角ゴシック Heavy / ヒラギノ角ゴ W7 など）。

## 8. 作るときの注意

- **曲名は正式名称のまま出す。** 音ゲーの名前も「モンヒロビート」で統一する（「モンビー」はキャラクターが愛称として呼ぶ会話でのみ使う・CLAUDE.md ⑤）
- **対象曲は毎週変わる。** この文書は 2026-09-11〜09-14 の週のもの。次の週（9/14〜）は
  Monster Hero ／ トリコ ／ crossing field になる。使い回すときは §1 の表と §4 の文字を差し替える
- **既存のジャケット画像を生成AIに読ませて「似せて」と頼まない。** 3曲のジャケットは画風がばらばら
  （和風ファンタジー／ゴシック／90年代アニメ）なので、並べるより統一したイベントビジュアルにするほうが締まる
