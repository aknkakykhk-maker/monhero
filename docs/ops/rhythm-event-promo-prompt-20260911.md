# モンヒロビート 初イベント 告知画像プロンプト

チャッピー（ChatGPT）へ貼って画像を作らせるためのもの。

**使い方**: 下のプロンプトをそのままコピーして貼るだけ。

告知する内容（ユーザー指定）。

| | |
| --- | --- |
| 何の告知か | モンヒロビート**初**のイベント開催。**始まる前に出す予告**（「開催中」ではない） |
| 期間 | **2026-09-11（金）15:00 スタート 〜 09-14（月）5:00 まで** |
| 対象曲 | Monster Hero ／ 風がそよぐ場所 ／ Close To Your Heart |

> ゲーム側（期間限定イベントの実装）は別途進行中。この文書は告知画像のプロンプトだけを扱う。

---

## 正方形（SNS用・1:1）

```
スマホのリズムゲーム「モンヒロビート」の、初イベント開催を予告する告知バナーを1枚作って。

正方形。黒〜濃紺の背景に、奥から手前へ流れる光るノーツのレーン。
シアンとマゼンタのネオンで、これから始まるぞという高揚感のある感じ。
まだ始まっていない予告なので、カウントダウン前の静かな緊張感も混ぜて。
文字は白で大きく、背景に埋もれないように。

画像に入れる文字（この日本語のまま、正確に）:
初開催
モンヒロビート イベントランキング
Monster Hero
風がそよぐ場所
Close To Your Heart
9/11(金)15:00 スタート
9/14(月)5:00まで

「初開催」は上部の小さなタグに。
「9/11(金)15:00 スタート」は曲名より目立たせて、いちばん読ませたい文字にする。
「9/14(月)5:00まで」はいちばん小さく、下のほうに。
曲名は3行に分けて、省略はしないで。
```

## 横長・縦長にしたいとき

書き出しの「正方形。」を書き換えるだけ。

- 横長（Xのタイムライン向け）: `横長16:9。`
- 縦長（ストーリーズ向け）: `縦長9:16。上下は文字を置かず空けて。`

## ゲーム内バナーにしたいとき

曲名の3行を消して、「正方形。」を `細長い帯（横長3:1）。` に変える。帯では曲名まで読めない。

---

## うまくいかないとき

| 気になった点 | 追加で投げる一言 |
| --- | --- |
| 日本語が崩れた | 「文字はいっさい入れずに、背景だけで作り直して」→ あとからCanva等で文字を乗せる |
| 文字が小さい | 「見出しをもっと大きく、横幅の8割まで使って」 |
| ごちゃごちゃ | 「背景の光を半分に減らして、文字まわりを暗く落として」 |
| 曲名が読めない | 「曲名の下に半透明の黒い帯を敷いて」 |
| 開始時刻が目立たない | 「9/11(金)15:00 スタート をいちばん大きく、画面の中央に置いて」 |
| 開催中に見える | 「これから始まる予告のデザインにして。『開催中』の雰囲気は消して」 |

## 投稿につける文

```
【初開催】モンヒロビート、はじめてのイベントを本日15:00から開催します。
対象は「Monster Hero」「風がそよぐ場所」「Close To Your Heart」の3曲。
難易度不問・1曲だけでもOK。9/14(月)5:00まで。
https://aknkakykhk-maker.github.io/monhero/
```

## 告知の中身（画像に足すときの材料）

- 画像に載せる3曲（ユーザー指定）
  1. Monster Hero（`monster_hero`）
  2. 風がそよぐ場所（`kaze_ga_soyogu`）
  3. Close To Your Heart（`close_to_your_heart`）
- 期間: **9/11（金）15:00 スタート**、9/14（月）5:00 まで
- モンヒロビート**初**のイベント。開催中ではなく、**始まる前に出す予告**として作る
- 部門: 対象曲ごとに3つ ＋「総合」の4つ
- 総合: 対象3曲それぞれのその週のベストを合算（満点 3,000,000点）
- 難易度は不問。1曲だけ遊んだ人も総合に載る
- 参加のしかた: モンヒロビート → 全国ランキング → 「イベント」タブ

> 曲名は画面の表記をそのまま使う。「Monster Hero」「Close To Your Heart」は英字が正式表記
> （カタカナにしない）。音ゲーの名前も「モンヒロビート」で統一する（「モンビー」は
> キャラクターが愛称として呼ぶ会話でだけ使う・CLAUDE.md ⑤）。
>
> 週間ランキングの対象曲を確かめ直すときは `data/rhythm-event.js` の `rhythmActiveEvent()` を動かす。
