## 何が読みにくいか

- 作る側の略語: 「被ダメ」「与ダメ」「WAVE限定」「永続」「重複可」「消費ガッツ」
- 効く時期を(かっこ)に詰めている: 「(永続/重複可/次のターンから)」
- 「＆」で2つ3つの効き目をつないで1文が長い
