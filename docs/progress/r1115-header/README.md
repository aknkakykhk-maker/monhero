# モンサクのヘッダの題(社長の決め: 「みゅあ編」だけ)

育成中などシナリオ名が付く画面のヘッダは、「🌱 モンヒロサクセスβ」を外して「みゅあ編」だけにした(`MsxHd`・`data-msx-hd-sc`)。
シナリオ名が付かない画面(ホーム・ボックスなど)は、これまでどおり「🌱 モンヒロサクセスβ」。

| 場面 | 止め絵 |
| --- | --- |
| 持ち物(字が大きい・幅320) | `msx-M3-s320big.png` |
| 持ち物(字が大きい・幅390) | `msx-M3-big.png` |
| 修行の入口(字が大きい・幅320 / ふつうの字・幅320) | `msx-Q1-s320big.png` / `msx-Q1-s320.png` |
| ホーム(題が「モンヒロサクセスβ」のまま・字が大きい・幅320) | `msx-H0-s320big.png` |

撮影の見張り「…で切れた文字」は、M3・Q1(big・s320big)で0件になった。
