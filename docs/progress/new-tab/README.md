# 「極限」の上の新しいタブの画面の案(2026-11-01・レフェリーくん)

社長「INFERNOからシールドで少しバトルの感じが変わったから、タブで『極限』の上を作って、そっちに移して一新したい」(ジン部長経由)。
クラシックのチャレンジの難易度選びに、極限とは別の新しいタブを作り、INFERNO と COCYTUS をそちらへ移す案。**まだ作らない(画面の案だけ)。** 保存・ランキングへの影響はセコンドくんの担当。
今の難易度選びの画面を開き、タブ・背景・説明の行だけブラウザで描き足して撮った。タブの名前は仮に「深淵」。カードはまだ解放していないので「???」の形で写っている。
見出し(「極限チャレンジ」)の書きかえは撮影で効かなかったので、本作りで「深淵チャレンジ / ABYSS CHALLENGE · SHIELD LAYERS」などにする。

## 案1: タブを3つ並べる(通常 / 極限 / 深淵)

| ファイル | 中身 |
| --- | --- |
| 案1_タブの並び_極限を開いた所_縦 / _横 | 極限を開いている時。3つ目の「🛡 深淵 2」は水色の縁だけ(まだ選んでいない) |
| 案1_深淵タブ_INFERNO_縦 / _横 | 深淵を開いた所。タブは炎→氷のグラデーション。背景も炎(左下の橙)と氷(右上の水色)に一新。説明の行「シールドの層をまとうボスに挑む、極限の先の段」。点は2つ |
| 案1_深淵タブ_COCYTUS_縦 / _横 | 同じ画面で COCYTUS のカード |

よい所: 入口がひと目で分かる。気になる所: 3つ並ぶとタブの字が少し小さくなる(縦でも読める大きさ)。

## 案2: 極限のタブの中に、2段目の切り替え(極限 / 深淵)

| ファイル | 中身 |
| --- | --- |
| 案2_タブの並び_極限を開いた所_縦 / _横 | 極限のタブを開くと、下に「極限 9 / 🛡 深淵(シールドの世界)2」の切り替え |
| 案2_深淵_INFERNO_縦 / _横 | 深淵に切り替えた所。背景が炎と氷に変わる |

よい所: 一番上のタブは今のまま(通常 / 極限)で、極限の続きだと分かる。気になる所: 2段目は気づかれにくい。

## タブの名前の候補

| 名前 | 英語 | ひとこと |
| --- | --- | --- |
| 深淵 | ABYSS | 極限の「さらに下」。炎(INFERNO)も氷(COCYTUS)も地獄の底のイメージで合う |
| 冥層 | UNDERWORLD LAYERS | 層のシールドと「冥府」の続き |
| 奈落 | NARAKU | 和の言葉で強い。落ちていく感じ |

## 一新できるもの(案)

- **背景**: 炎(橙)と氷(水色)が混ざる暗い背景に、うっすらシールドのひび。カードの後ろの光の筋は弱める
- **タブの色**: 炎→氷のグラデーションに「🛡」
- **カードの枠**: INFERNO は燃える橙の縁、COCYTUS は氷の水色の縁(今の色を枠にも)。カードの右上にシールドの枚数のしるし(「🛡×3〜5」)
- **BGM**: 深淵のタブを開いた時だけ、難易度選びの曲を低く重い版に(新しい曲を足すか、今の曲を遅く低くするか。音源は社長に相談)
- **解放の演出**: ETERNAL をクリアした時、深淵のタブが「ひびが入って割れて開く」演出(シールドが割れる演出と同じ作り)。タブに「NEW」
- **みゅあの言葉**: 深淵を開いた時だけの一言(「ここから先はシールドの世界…」など)
- **バトル**: 深淵の難易度では、バトルの上の段(難易度の札)も炎/氷の色に
