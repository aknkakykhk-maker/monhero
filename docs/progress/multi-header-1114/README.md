# マルチの上の帯: 💬が下の段へ落ちる(r1114-123・2026-11-14・テンポ)

社長「吹き出しのコメントのやつが押し出されて下に来る。ランキングボタンを曲側の方にうつせばいいんじゃない？」

- 原因: 🔄横のマルチは、上の帯に ← / 題字 / WAVE の札 / 呼ぶ / 締め切る / 選曲 / 縦 / 📊 / ⚙ / 🏆 / 💌 / 💬 が並び、幅が足りず、いちばん右の💬が2段目(参加者の列の下)へ落ちていた
- 直し: ①🏆(ランキング)を上の帯から外し、曲の側へ(曲えらび=詳しい欄の下の「🏆 ランキング」・待ち=出る段・準備=ライブする曲の札の右・待機=下の段) ②上の帯のボタンの最低の幅を44→38px・すき間を4pxに(`index.html`)
- 止め絵: 上=直す前・下=直したあと(🔄横は絵を元の向きに戻した)
