## 本作りでしたこと(71 だけ)

- ふつうの敵には左の大きな札を出さない(`enemyShellView(enemy).boss` が true の敵だけ)。ボスはゲージの見出しに「👑 BOSS」、横向き・背の低い画面は名前の横に「BOSS」
- 左の札の見出しを難易度ごとに(INFERNO=🔥 燃える橙 / COCYTUS=❄ 氷の水色)。「次の1枚 +◯%」は難易度の決まり(layerGrowth)から読む
- いちばん派手な演出(最終形態)を「5枚目」の決め打ちから「3連撃になったとき」に変えた(INFERNO の見え方は変わらない)
- 起き上がりの札(EnemyRevivalReveal)に、名前(name)と説明の文(desc)を渡せるようにした。渡さなければ今までどおり

## 復活の演出(氷の3段)の動画

社長の決め: 3段の差の付け方と言葉(FROZEN BREAK!!・ABSOLUTE ZERO!!・真・覚醒)は「これでよい」、そのあとに DEAD RISING の札も出す。
60 から `stage`(durahan / moo1 / moo2)が渡ると、71 が「凍りつく → 砕ける → 蘇る」を3秒出してから札を出す。軽め・最軽量・省エネ表示は帯だけ。
撮るときは、蘇りの合図(stage・名前・文)だけ外から差し替えた。
