## 気づいたこと

- 縦の7枚は、いちばん長い⑦の右端が「解析」ボタンに少しかかる(390幅で約10px)。本作りでは、7枚のときだけ長さの伸び方を小さくする(1枚ごと+7% → +4%)

- 横向き・背の低い画面は細い1本なので、枚数が増えても高さは変わらない(小さな印が7つに増えるだけ)
