# 対戦の場のモンスターの大きさを1体ずつそろえる(r1119-074・止め絵)

社長「バトル中の画面でモンスターのサイズ感が合っていない」「渡した絵はサイズ別にしていないから、実際の絵を見てサイズを合わせてほしい」。開発部 クラフトくん・2026-11-21。**社長の OK まで公開しない。**

## 何をしたか

- 30体の絵を1体ずつ見て、姿から「見た目の大きさ」(ふつう=1)を決めた。小さな生き物 0.72〜0.85・人の背丈くらい 0.9〜1・大きめ 1.05〜1.3・巨体 1.4〜1.45
- 絵の余白の差は、今ある「絵の中身の範囲」の表 `ART_CONTENT_BOXES`(`tools/image/make-art-content-boxes.js` が測る)で消す。足元の余白も詰めて、床に立つようにした
  - 今は、どの子も同じ枠に「全体を収める」形なので、縦長の絵(ミーア・サンリオの子など)ほど大きく、余白の多い絵(スエゾー・イブリース)ほど小さく描かれていた
- 大きさを変えるのは対戦の場(`MsaStage`。モンサクの試合・助手対戦β・修行を見る)だけ。立ち絵・アイコン・図鑑・試合の始まりの対面(`.msa-intro`)・技の窓(`.msa-cut`)は今のまま
- 計算(`SPECIES_TRAITS` の z・避ける・受けるダメージ)は変えていない

## 表の置き場所

`monster-hero/src/parts/16-monster-stage-size.jsx` の `MONSTER_STAGE_SIZE`(1体ずつの値)。引く口は `monsterStageSizeOf(id)`(値)と `monsterStageFit(id, 枠の幅, 枠の高さ)`(余白を詰めた描く大きさ)。場面に依らないので、助手ライフの家など並んで立つ場面でも同じ表を引ける。

- **表に無い子は 1(ふつう)**。絵の中身の範囲が分からない子は、今までどおり枠に収める
- 大きさ1の子の中身の高さ = 枠の高さ × 0.8。横に広い子(アーク・オボロゲソウなど)は、中身の幅が枠の幅の1.5倍で頭打ち

## 止め絵

- `lineup.png` … 全員を小さい順に、名前・大きさ・計算の z つきで並べた一覧
- `golem-mocchi.png` / `monol-ghost.png` / `kuromy-suezo.png` … 大小の差が大きい組み合わせの対戦の場面(縦 390×844・左が今・右が新)

## はみ出し・重なり

3組とも場からはみ出さず、相手とも重ならない(零の間合いのクロミーとスエゾーで 9px 離れる・ゴーレムの頭は体力の帯の下)。横に広い子が零の間合いで並ぶと近づくので、気になる組があれば教えてほしい。
