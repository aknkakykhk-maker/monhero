# 山札切れの必勝法(「1枚ずつガッツ」)の調べと直し案 — 保留(2026-11-04 社長「今は様子見」)

ブランチ `claude/card-mill-fix` だけにある。**main には入れていない。** また頼まれたら、このメモと下の道具ですぐ測り直せる。

## 何が起きたか

- テスターのえるびんさんが組んだ「山札切れを狙う戦術カード」入りの登録デッキを、フリー対戦の「ほかのブリーダー」で AI が動かし、人間が相手をする
- 人間が毎ターン手札を1枚だけガッツにして山札の減りをおさえると、AI のほうが先に山札切れになって負ける

## えるびんさんのデッキの形(本番の登録・2026-11-03。窓口が読むだけの SQL `docs/sql/card-deck-share/CARD_DECK_MILL_READ.sql` で読んだ)

- 名前「オート用」・くせ ソラシド・モンスター C-067V / C-061 / C-047S・切り札 F258 / 304 / 209・登録の対戦 16戦4勝
- 基本カード: 持久型・堅実型
- ブリーダーの行: いつでも→全体カード「大きいダメージを封じる」/いつでも→守りのカードを3枚まで残す/相手の山札10枚以下→全体カード「山札を削る」
- モンスターの行: 受けると倒れる→守る/3ダメージ以上→回避で守る(3体目は守る)/ガッツ◯以上→ガッツを減らす・付けるカード・手札を捨てさせる・山札を削る など/ライフ◯%以下→回復・吸い取る・回避で守る
- デッキと戦術カードの JSON は `tools/elbin.json`

## 再現(今の main)

えるびんさんのデッキ・戦術カードそのまま(賢さ MASTER)。人間はスターター3つ×30試合(打ち方は「プレイヤー役(きゅうこ MASTER)」で、ガッツの番だけ1枚にしぼる)。

| 人間の打ち方 | 人間の勝率 | 決着 |
| --- | --- | --- |
| ふつうに戦う | 6% | AI が人間の山札を先に切らして勝つ(85/90) |
| 毎ターン1枚だけガッツ | 72% | AI の山札切れ(65/90) |

## 原因

- このデッキは守りを固めて、相手の山札切れを待つ作り
- 人間が山札をおさえると、AI のほうがガッツをため(1回 約1枚)、守りの札も使う(1試合 3〜4回)ぶん、先に山札が切れる
- AI は山札の残りを相手と比べずに戦っている(自分の山札が5枚を切るまで、ふだんどおりガッツにする)

## 効いた手(AI の判断だけ・ルールは変えない)

持久型(基本カードの持久型・持久型のくせ)の**登録デッキ**が、山札の残りで「相手より2枚多い」ところまで追いつかれたら、戦術カードの指示より次を先にする:

1. ガッツにするのは1枚まで
2. 倒れない攻撃には守りの札を使わない
3. カードを引く手・山札からガッツにする手を控える

(助手=フリー対戦の相手の打ち方は変えない。`82-card-battle-core.jsx` の `cardAiDeckRaceLosing`・`cardAiMillPlan`)

## 試して、だめだった手

| 試した手 | 結果 |
| --- | --- |
| 全員(助手も)、山札で負けそうならガッツを1枚までにする | 試合が長くなり、助手が弱くなる(1枚ずつガッツへの人間の勝率 MASTER 27→58%) |
| 全員、手札の札を出すのに足りる分だけガッツにする | 同じく助手が弱くなる |
| 負けそうなら攻め・とどめを強め、守りを残すのを弱める | えるびんさんのデッキではむしろ逆効果(35%→39%) |
| 山札で負けていても、山札を削る札を高く見る | 変わらない |
| 負けが決まりそうな場面(山札10枚以下で相手より少ない)だけ切り替える | 遅すぎて効かない(69→71%) |
| 助手のうち持久型のくせ(ソラシド)にも入れる | 低い難易度のソラシドが「1枚ずつガッツ」に弱くなり(NORMAL 18→68%)、助手どうしの長い試合も増えた(50ターン超 0→20) |
| ドラ(守り型の助手)だけ、負けそうなら攻め型へ丸ごと切り替え | 70〜83% までしか下がらない |
