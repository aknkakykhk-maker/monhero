# 助手のデッキを3パターンにして、中身を見せる(案の止め絵・2026-11-08 カード部ツナグ)

社長(本番・縦の「ドラのマスモン」→デッキのタブを見て)「デッキは何パターンかあって中身も見れる方が良さそう。その何パターンかのデッキを対戦で出すみたいな」

- 止め絵: `portrait.jpg`(縦 390×844)・`landscape.jpg`(横 844×390)。カードの画面には🔄横は無いので2つ
- 作ったブランチ: `claude/tsunagu-assistant-decks-mock`(ルールの `claude/card-grow-style` の上。**マージしない**)
- 中身はルールの `cardAssistantDeckPreview(助手, 型, 'normal')` が返す本物の並び。**名前とひとことはドラの分だけ仮で書いた**(AI が付ける予定)

## 案
1. 助手ごとにデッキを3つ(攻め/守り/ふつう)。名前・助手のひとこと・3体・カード50枚
2. (a) デッキのタブ: 上に3つの切りかえ(その助手がいちばん出す型に「よく使う」)→ 名前・ひとこと → 3体 → 切り札(ガッツのいちばん重い技)→ 種類ごとの一覧(技/防御/回避/特殊/場・同じカードは ×3)→ 小さく「AI が 4:00 に組み直しました・対戦では毎回少し入れかわります」
3. (b) カードを押すと、いつもの詳しい窓(`CardDetailModal`)で大きく見る
4. (c) 相手えらびと VS の画面に、型の札「🛡 今日は『のんびり長期戦』(守り)でいくよ」。(d) 結果の画面に「相手のデッキ: 『のんびり長期戦』(守り)」。対戦の記録(リプレイ)にも同じ札を出す予定(止め絵なし)

## 決めてほしいこと
- **VS の画面の名前が2つになる**: 今もある助手のデッキの名前の帯(例「ドラのカチコチねばり腰の砦」)と、型の名前(「のんびり長期戦」)が並ぶ。型の名前に1つにまとめるか、両方残すか
- 「よく使う」の印をどの型に付けるか(止め絵は助手部の `ASSISTANT_MASMON_CARD_STYLE`。ドラは守り)
- 切り札の選び方(止め絵は「技のうちガッツがいちばん重いもの」。全体攻撃を優先するか)
- 今は対戦で出す3体が型ごとのプレビューと同じとは限らない(対戦の3体は毎試合えらび直し)。プレビューどおりの3体で出すか
