- どちらの枠も零・近・中・遠に1技ずつ(その間合いで命中×威力がいちばん大きい技)。押すとその間合いの技の窓(相手のは見るだけ)
- 相手のいまの間合いの枠は光る。危なさ(相手の技の中で、その技の命中×威力がいちばん強い技の何割か)で光を3段に分ける。届く技が無い間合いは光らせない
- 使った技には、そのモンスターが次に技を出すまで白い点線の印
- 実況は場の外(場のすぐ下)、技名の札は場の上(体力の帯の下)。零近中遠の字は場の下のまん中にいつも出す
- 手動の操作は「◀ 後退・前進 ▶・🛡 ガード・💪 ためる」の1段(零では 💨 吹き飛ばしを足す)
- 残り: 小さい横では、技名の札が寄ったときのモンスターの頭に少しかかる。ライフ・ガッツの帯は今の形のまま(社長の見立てどおり参考と大体同じ)
