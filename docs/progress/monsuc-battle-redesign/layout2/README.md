## 1. 技の枠(相手も自分も同じ形)

- **零・近・中・遠の4枠。1枠に1技**(その間合いの代表の技)。枠の中: 間合い・技名・種類(ち=ちから/か=かしこさ)・威力(ランクの字)・命中%・ガッツ。
  効果のある技は効果も1行(吹き飛ばし・ガッツ減など。枠の高さが足りない小さい横では印だけ)。右上の「+2」は同じ間合いのほかの技の数
- **押すと窓が開き、その間合いのほかの技が中身つきで見える**(自分の枠は、窓の中から技を選べる)
- **いまの間合いの枠を光らせる**。相手の枠は赤く光らせ、「危険 大/中/小」を出す(下の決め方の値で3段)。自分の枠は黄色
- **使った技は、次の技が出るまで枠に白い点線の印を残す**(代表でない技を使ったときは、その枠の中身をその技に替えて印を付ける)。
  場の中にも、使った瞬間に技名の札(使った側・種類・威力・命中・ガッツ)を出す
- **代表の技の決め方**: その間合いに届く技のうち、いまのガッツで出せる技の中で「威力 × 命中率」がいちばん大きい技
  (=当たったときにいちばん痛い技)。出せる技が無いときは、ガッツがいちばん少ない技を薄く出し「ガッツ不足」と添える。
  自分の枠も同じ決め方(手動では、助手のおすすめが別の技ならその技に替えて「おすすめ」の印)
- **危険の段**: 相手の代表の技の「威力 × 命中率」を、自分のいまの体力に対する割合で3段(大 ≥ 体力の30%・中 ≥ 15%・小)

- 速さ・オート・一時停止は上の帯の右に小さく寄せる(今は下に1段使っている)

## 3. 場の中の大きさと立ち位置(`plan2-maai-*.jpg`)

- 絵の幅 = min(場の幅×0.25, (場の幅 − 24)÷4)。中心の距離 = 絵の幅 × 零1・近1.6・中2.3・遠3
- 遠でも両端の絵+安全域(12px)が場に収まる。当たりの演出(点線の円 = 絵の幅×1.15)も場の中に収まる
- 縦の場の上半分は、飛ぶ物・大技の寄り(零1.25倍・近1.12倍まで)の余白。足もとは場の高さの74%
- 寄ったときも2体+数字が場に収まる所まで倍率を下げる(段1で作った決まりと同じ)
