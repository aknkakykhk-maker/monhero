## 4. 作り直し案

配置図: `plan-tate.jpg`(縦 390×844)・`plan-yoko.jpg`(横 844×390。小さい横は同じ割り付けを縮める)

```
縦 390×844                                   横 844×390
┌ 上の帯(固定) 自分 体力・ガッツ│R│相手 ┐   ┌ 上の帯(固定) ─────────┐┌ 操作(右1/3) ┐
├ 場 ──────────────────────┤   ├ 場(画面の約2/3)─────────┤│ 自分の技札   │
│ [効果(自分)]      [効果(相手)] │   │[効果]                [効果]││ [相手の技]   │
│               [相手の技の札]   │   │[技の札(使った側)]          ││              │
│   ▢自分     -48     ▢相手     │   │    ▢自分        ▢相手      │├ 速さ・オート ┤
│   └── 中心距離=絵の幅×倍数 ──┘ │   │     零・近・【中】・遠     ││              │
│     零・近・【中】・遠(常に)    │   ├ 実況の帯(場の外)───────┤└──────┘
├ 実況の帯(場の外・1行) ───────┤
├ 操作欄 自分の技札+[相手の技] ──┤
└ 速さ・オート・背景 ──────────┘
```

### 4-1 相手の技の見せ方

- 技を使った瞬間に、**使った側の上の段に「技の札」**を出す(自分=左・相手=右)。中身は 技名・種類(ちから/かしこさ)・効果・命中%・ガッツ。
  形は手動の自分の技札(`MsaDistCards` の札)と同じ部品を使い、色だけ自分/相手で分ける。今の `.msa-plate`(下の端の技名)はやめる
- 決め技(大技)のときだけ札を金にし、使った子を大写しにする(参考も大写しは決め技だけ)
- 効果(上がった・下がった)は**場の上の左右に「効果の行」**として並べる(自分は左・相手は右・残り手番の数つき)
- 「相手の技」ボタンを操作欄に常に置き、押すと**相手の技札の一覧**(同じ形・零近中遠で分けて)を下から出す。
  助手マスモン対戦にある「👀 相手の技」(`ambb-foe-tech`)と同じ口にまとめる

### 4-2 間合い

- 2体の**中心の距離 = 絵の幅 × 倍数**(零 1・近 1.6・中 2.3・遠 3)。零は「触れ合う」で重ならない。今の `MSA_GAP`(場の幅に対する割合)と `gapOf` の三通りの計算をこれ1つに置き換える
- 零近中遠の字(`.msa-dist`)は**技の行でも消さない**(`e.ev !== 'tech'` の条件を外す)。足元の点にもいまの間合いの字を付ける
- **動いた子だけが動く**: 移動の行のあいだカメラは止める(`MSA_PAN_K` の追いは移動中 0)。2体の片寄りは、実況だけの間(技の合間)に 0.4 秒でそっとまん中へ戻す

### 4-3 大きさとカメラ

- 絵の幅 = **min(場の幅 × 0.25, (場の幅 − 安全域×2) ÷ 4, 場の高さ × 0.45 × 0.82)**。最後の2つは「遠(3倍)でも両端の絵が場に収まる」「上の帯・効果の行にかからない」ための上限
  - 目安: 縦 場370 → 絵 約86px(今 136〜225)/ 横 場560 → 約134px / 小さい横 場375 → 約87px
- 縦の場の高さは**オートと手動で同じ**にする(今 359↔520。P3)。大きさは場の大きさだけで決まり、操作の切り替えで絵が変わらない
- 寄りは零 1.25 倍・近 1.12 倍まで(今 最大 1.6 倍)。寄った後の「2体+数字+安全域」が場に収まらないときは寄りを下げる(はみ出しは 0 にする)
- 横は場を画面の約 2/3 に広げ、操作を右の 1/3 に詰める(今は半々で、右に大きな空き)

### 4-4 帯と札の置き場所(重ならない決まった場所)

| もの | 置き場所 | 今 |
| --- | --- | --- |
| 名前・体力・ガッツ | 上の帯(場の外・固定) | 場の上にかぶる帯(寄りで頭がかかる P6) |
| 効果の行 | 場の中の上・左右 | 決まった場所なし |
| 技の札 | 効果の行の下・使った側 | 場の下の端(実況と重なる) |
| ダメージの数字 | 当たった子の頭の上(場の中に収める) | 同じだが寄りで外へ出る |
| 零近中遠 | 場の中の下・常に | 技の行で消える |
| 実況 | **場の外**・場のすぐ下の1行 | 場の中に重ねている(`.msa-say.over`) |

### 4-5 決着の音は1系統

- 試合の部品(`MsaStage`)に「決着の音は親が出す」の口を付け、モンサクでは部品の `msaSe('victory')` を鳴らさない。
  曲を止める処理も部品からは呼ばない
- 決着の音は、**①音の会話が作る「意味で引く表」の『勝ち』『負け』の行**を大会の画面(`SuccessSound`)が1回だけ鳴らす。1.7 秒の無音は無くす
- 助手マスモン対戦は親が無いので、同じ表の行を部品の既定として鳴らす(音の出どころは表1つ)

### 4-6 助手マスモン対戦も同じ部品に載せる

助手マスモン対戦(`56-assistant-masmon-battle-beta.jsx`)と応援(`56-assistant-life-masmon-cheer.jsx`)は `MsaStage` を `fill`(絵 140px 固定)で使っている。
`fill` の固定値をやめて 4-3 の式に乗せ、技の札・効果の行・実況の帯・相手の技の一覧も同じ部品から出す。

### 4-7 作る順番と規模

| 段 | 中身 | 変えるファイル・定数 | 規模の目安 |
| --- | --- | --- | --- |
| 1 大きさ・間合い・カメラ | 4-2・4-3。縦の場の高さをそろえる。横の割り付け 2/3 | `56-monhero-success-arena.jsx`(`MSA_GAP`→`MSA_GAP_X=[1,1.6,2.3,3]`・新 `MSA_FIG_RATIO=0.25`・`bigFh`/`bigFw`/`gapOf`/`MSA_PAN_K`/`sCap`・`.msa-dist`)・手動の場の高さの CSS(同ファイル 297 行付近) | 中(約150行) |
| 2 帯と札・相手の技 | 4-1・4-4。技の札の部品、効果の行、実況を場の外へ、相手の技の一覧 | 同上(`.msa-plate`・`.msa-say.over` を置き換え)・`56-monhero-success-manual.jsx`(`MsaDistCards` を札の部品として使い回す)・`56-assistant-masmon-battle-beta.jsx`(相手の技の口をまとめる) | 中〜大(約300行) |
| 3 決着の音・助手対戦・告知 | 4-5・4-6。①音の表が入ってから | 同上+大会の画面の音。更新履歴・ヘルプ | 小 |

- 各段で PR を分ける。仕上がりは段ごとに**参考と並べた止め絵**を撮って別の目(ミハリ)で確かめる(r1119-001)。作るのは opus(r1119-002)
- **保存データに触らない**: 新しい保存キーは足さない。背景・オート/手動の既存キー(`MSA_BG_KEY`・`MSA_CTL_KEY` など)はそのまま。試合の計算(芯)・ランキングにも触れない。見た目だけ
- **検査で見張るもの**(新しい検査 `tools/battle/msa-layout-check.js` を足し `run-checks.js` から呼ぶ。縦・横・小さい横+助手対戦の4通りで、撮らずに寸法を数える):
  - 絵の幅 ÷ 場の幅 が 0.18〜0.27
  - 中心の距離 ÷ 絵の幅 が 零1・近1.6・中2.3・遠3(±5%)、零で2体が重ならない
  - 絵・数字・技の札が場の外へ出ない(寄りの最大でも)
  - 実況・技の札・効果の行・上の帯・零近中遠の矩形が互いに重ならない
  - 零近中遠の字が技の行でも出ている
  - 決着1回で鳴る勝ち負けの音が1つ(既存の音の記録を使う)

### 4-8 社長に選んでほしい所

- **A 横の画面の場の広さ**: ① 場を画面の約 2/3 に広げ、操作は右の 1/3 に詰める(推奨: 間合いの差が倍近く見える) ② 今の半々のまま(操作の札が大きいまま)
- **B 相手の技の札を出しておく長さ**: ① 演出と同時に出し、次の技が出るまで残す(推奨: 読む時間がある) ② 演出のあいだだけ出す(場がすっきり)
