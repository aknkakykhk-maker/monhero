# モンヒロビートのオプションで、いまの設定での演奏画面を見られるようにする(案)

2026-11-11 ビート部テンポ。社長「モンビーのオプションで、現在の設定での画面が分からないから見れるようにしたい」(窓口経由)。

## 案A(推奨)「▶ 見てみる」→ 本物の演奏画面で見本
- オプションの上に「▶ 見てみる」。押すと演奏画面いっぱいに、**保存前の設定(下書き)のまま**、自動で叩く見本の譜面が数秒〜くり返し流れる
- 本物の演奏画面と同じ描き方なので、見た目の設定(見た目のセット・ノーツの速さ・大きさ・形・色・レーン・判定の文字・コンボ・背景・キラメキが作っている判定の光・コンボの熱・背景の層)がそのまま出る
- 右上の「設定へ戻る」で、下書きのままオプションへ戻る(保存はしない)
- 仕組みは、いまの「判定ラインを合わせる」の「試す」(ノーツをくり返し流す・何も記録しない)を土台にして、自動で叩く見本を足す。譜面・判定・音の同期は変えない
- 音: 鳴らすか(曲・ノーツの音)は社長に聞く。無音でもよい

## 案B 設定画面の上に小さな見本窓
- 設定を変えると、すぐ窓に出る。ただし演奏画面を小さく描き続けるので重く、設定画面の高さを取る(縦で 260px ほど)
- 本物の演奏画面は全画面で描く作りなので、縮めて描くと見え方が本物とずれやすい
