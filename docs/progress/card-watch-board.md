# 観戦を対戦の盤面(84 CardBattleBoard)に切り替える(2026-10-27〜・カード部ナガメ)

社長の決め: 観戦の画面は、実際に遊ぶ対戦の画面と同じ見た目にする(攻撃・アクションの見せ方も同じ)。手札は2人とも裏。
あわせて「投了したら終わったのが分からない」を直す(どちらがいつ投了したか)。部長: ソランド。見返し(93)の所はリプレイくんに見てもらう。

## PR の分け方(部長の決め)
1. 盤面に「観戦の形」を足す(枝 claude/card-watch-board)
2. 観戦(94)をその盤面に切り替える(手が届くたびに step・途中から見る人は quiet で最新へ)。2台+観戦の検査
3. 要れば古い観戦の部品を片づける

## 1本目でやったこと(84)
- `game.watch = { top:{name,icon,frame}, bottom:{name}, attach(h) → はずす関数 }`。h = `{ onState(next, quiet), onEnd(end), onEyes(n) }`
- pvp は watch.top を使う(上の帯の顔)。pvpLive は watch では偽(通信・持ち時間・自動の手・チャットなし)
- 呼び名 `meName`(ふだん「あなた」・観戦は下の人の名前): 番の帯・上の帯「◯◯の番」・技の箱の札・大写しの名前
- 押せない(myTurn 偽)。下の人の手札の欄は裏の札で枚数だけ。下のボタンは「観戦をやめる」(決着後「観戦の一覧へ戻る」)→ onFinish({ outcome: 'watchExit' })
- 決着: WIN/LOSE の演出と結果の画面は出さず、`data-card-watch-over` の帯(「◯◯さんが投了しました」「△△さんの勝ち！」)。押すと消える
- 決着の言葉は 94 の cardWatchEndText(枝 claude/card-watch-end にある)を 2本目で持ってくる
