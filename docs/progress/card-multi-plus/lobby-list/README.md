# マルチ対戦: いま相手を待っている人を見て選ぶ(案)

2026-10-27 社長「マルチで誰かが募集してたりしたらここで見れるようにして。あとおしたらすぐはいらないで誰がいるかも見れるようにしたい」。
カード部 ツナグくんの案。写真は実際の画面に一覧を重ねたもの(名前・強さは例)。

## 案A: 入口の画面に「いま相手を待っている人」の欄 (`A-lobby-list.jpg`)
- マルチ対戦の入口のいちばん上に、いま「だれとでも」で待っている人を並べる(アイコン・名前・強さ・待っている秒数・[対戦する])
- [対戦する] で、その人の部屋に入って始まる
- 「だれとでも」は「だれとでも(自分も待つ)」にして、押すと今までどおり自分も待つ側になる
- 待っている人がいないときは、欄に「いまは、待っている人はいません」
- 入口を開いただけで見える(押す前に分かる)

## 案B: 「だれとでも」を押すと、まず「相手をえらぶ」画面 (`B-pick-screen.jpg`)
- 入口は今のまま。「だれとでも」を押すと、すぐには入らず、待っている人の一覧の画面へ
- 一覧から [対戦する] を選ぶか、[自分も待つ] で今までどおり待つ。[もどる] で入口へ
- 入口が今と変わらず、ボタンが増えない

## どちらも同じ作り
- 一覧に出すのは「だれとでも」で待っている人だけ。合言葉の部屋・フレンドの招待の部屋は出さない(合言葉も出さない)
- 出すもの: アイコン・名前(プロフィールの名前)・強さの点数・待っている秒数。デッキの中身は出さない
- 一覧は、待っている人が2秒おきに出している「待っています」の知らせ(Supabase の Realtime の受付の通り道。いまもある)を、入口の画面で聞くだけで作る。
  知らせに名前・アイコン・強さを足す(古い版の人は名前なしで「ブリーダー」と出す)
- 同じ人を2人が同時に選んだときは、先に入った人と始まり、遅れた人には「ほかの人と始まりました」と出して一覧に戻す
- 自分が待っているあいだも、ほかに待っている人が見えたら、その人を選んで入れる

## Supabase の表
- 足す物はない(表・列・関数とも要らない)。強さの点数は、待っている人が自分の点数を知らせに入れる(いまの点数の表を読むだけ)
