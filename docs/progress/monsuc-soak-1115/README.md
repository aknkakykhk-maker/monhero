## 台本の限り(読むときの注意)

- 戦いは周1〜3・5〜9がオート、周4・10は「手動」(台本は先頭の技を押すだけの雑な手動なので、負けが多いのは台本のせい)
- 修行は「覚えられる技のうち最も高いランクを1つ選ぶ」だけ。熟練の条件つきの技を狙い撃ちしてはいない
- 子の種類・育て方・編成が周ごとに違うので、周どうしの差は「育て方の差」だけではなく「子の差」も含む(同じ子を比べるなら 周1と周8=モッチー、周3と周9=ゴーレム、周4と周10=ライガー)
- 画面の通し検査(はみ出し・文字切れ・真っ白・エラー)は台本が自動で見た。人の目で見たのは止め絵の一部だけ
