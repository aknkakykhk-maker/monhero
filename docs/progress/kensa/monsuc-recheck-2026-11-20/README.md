## 5. 目で見て分かった道具の側のこと

- ランキングの1行を押した詳細・血統を選ぶの縦は、前と同じく押す手順が当たっておらず一覧のまま(空振りとして外した)
- 大会の1試合は「負け…」の後 約4秒で撮るのを止めた。その先に進むかは見ていない(中に下げた)
- メモモンの「1970/1/1」は偽のデータに日付が無いため(中に下げた。日付が無い子に 1970 を出さない直しは要る)
- 大会の1試合は、偽の育成(勝つ設定の `win`)でもオートで戦うと 0 ダメージの判定負けになった。結果だけ見るの勝ちと食い違う。②で確かめてほしい

## 6. 直したあとの確かめ方(窓口から頼まれたら)

1. 直した PR の場面を同じ道具で見る: `node tools/browser/monsuc-visual-pr.js --scenes msx:T1,msx:M1`(名札は表の〔〕の中)。流れの件は、下の撮影で `SHOT_SEQ` を付けて撮り直し、`--only flow` で送る
2. 指摘が消えていたら、表の状態を「確かめ済み」に。消えていなければ「未」に戻して窓口へ

## 7. 道具(この PR で足した物)

| 道具 | 足した物 |
|---|---|
| `tools/success/success-shoot.js`・`success-r3-shoot.js`・`success-arc-shoot.js` | `SHOT_SIZES=base,pc` で PC 1280×800 も撮る。`SHOT_SEQ=<名前>` でその場面を操作のたびに1枚撮る(`<名前>~00.png` …)。流れ用の場面 `SQE`(イベント1つ)・`SQT`(トレーニングの1ターン)・`SQV`(編成の子のイベント)・`SQC`(大会の1試合・オート)。名指ししたときだけ撮るので、ふだんの検査の動きは同じ |
| `tools/browser/visual-api-monsuc.js` | `--sizes tate,pc` で送る大きさを絞る(1本の頼みに18枚まで詰める)。`~NN` の止め絵を1つの流れとして束ね、観点11を中心に見てもらう頼みを作る(`--only flow` で流れだけ) |
| `tools/browser/monsuc-recheck-table.js` | API の結果を部ごとの表(番号・場面・何が悪いか・直し方・優先度・状態)にする。前の点検と比べて「前から」を付ける。`overrides.json` で空振りを外す |

全画面の撮り直し(約40分の撮影 + API 約30分):

```
SHOT_SIZES=base,pc SHOT_DIR=<奥>/msx node tools/success/success-shoot.js > <奥>/msx.log
SHOT_SIZES=base    SHOT_DIR=<奥>/msx SHOT_ONLY=SQE,SQT,SQV SHOT_SEQ=SQE,SQT,SQV node tools/success/success-shoot.js
SHOT_SIZES=base,pc SHOT_DIR=<奥>/r3  node tools/success/success-r3-shoot.js > <奥>/r3.log
SHOT_SIZES=base    SHOT_DIR=<奥>/r3  ONLY=SQC SHOT_SEQ=SQC node tools/success/success-r3-shoot.js
SHOT_SIZES=base,pc SHOT_DIR=<奥>/arc SHOT_SEQ=S6,G4,N2 node tools/success/success-arc-shoot.js > <奥>/arc.log
node tools/browser/visual-shoot.js --only <monsuc- の id を , で> --sizes tate,pc --out <入口>
ANALYSIS_GATEWAY_TOKEN=proxy node tools/browser/visual-api-monsuc.js --home <入口> --deep <奥> --out <置き場> --sizes tate,pc --max-tokens 13000 --effort medium --max-usd 6 --send
ANALYSIS_GATEWAY_TOKEN=proxy node tools/browser/visual-api-monsuc.js --out <置き場> --fetch
node tools/browser/monsuc-recheck-table.js --in <置き場>/api-findings.json --out <この置き場>
```

(撮影は前の3本を同時に回せる。ただし `rm` と同じ行で `&` を付けて並べると、消す前に撮り始めて記録が消える。合言葉は環境のネットワークの秘密で付く。値はどこにも書かない)
