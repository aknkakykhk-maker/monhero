## 譜面の問題一覧(曲ごと・Muse へそのまま渡せる形)

- 44曲・104件(API の答え。数字は [`chart-table.tsv`](chart-table.tsv) と同じ)。「既知」= 11/11 の一覧(beat-chart-fix/ALL.md)に同じ譜面・同じ種類の問題がある物。連打・重なり・音とのずれ・仮想ミスは今回はじめて測ったので既知にしていない
- **配信中の譜面は作り直さない**(tools/mode/CLAUDE.md)。案は「位置だけ直す」「その難易度だけ手で直す」「表示 Lv. だけ直す」「耳で確かめる」のどれか。直すかどうかは社長が決める
- 場所の「小節」は曲の最初のテンポから数えた目安(速さが変わる曲はずれる)。「0:56〜」のような区間は仮想プレイヤーの8秒ごとの区切り
- 「押せない」は横持ちの親指2本の厳しい物差し(3本目の指・持ち替えで押せる所も含む)
- 曲の終わりと譜面の終わり: 最後のノーツのあとの空きは最大 9.5秒(Erfolg)で、どれもフェードアウトの所(強い音が無い)。おかしいずれは無かった
- 3つ以上の同時押しは0。仮想プレイヤーのミス%で、下の段のほうが上の段より高い逆転も0
