# モンヒロビートの音の点検(2026-11-20 23:41 ミハリ)

窓口の依頼(社長の決定 r1119-047「モンヒロビートの点検に音を足す」)。**監査だけ。ゲームのコードは変えていない。API は使っていない(ページの中の記録だけ)。**
基準: main `92da7d86`。フルコンボの音の直し(r1119-047・ビート部)は、この時点でまだ PR が無かった。届いたら同じ台本で確かめる(下の「直ったあとに確かめる」)。

## 結論(3行)

1. **演出量「最小」と軽量モードでは、フルコンボを取っても音が鳴らない**(F1)。大きなお祝いの画面と一緒にしか音を出さない作りのため。r1119-047 で「鳴らす」と決まっていて、ビート部が直している
2. **マルチは、人が部屋に入ったときと結果に、音が無い**(F2・F3)。ソロの結果はランクアップのファンファーレなどが鳴るのに、マルチの結果は無音
3. **結果の経験値の数え上げで、ボタンの音(tap)が0.03秒おきに8回続く**(F4)。ランクアップの「割れる音」と、別の「ごほうびの音」が0.03秒差で重なる(F5)

ボタンの音・ノーツの音(タップ・フリック・ホールドの終わり・モンスターノーツ)・新記録・ランクアップは、鳴るべき所で鳴っていた。効果音 OFF・音量0では、ノーツの音とフルコンボの音が止まる(r1119-047 どおり)。

### 確かめて問題なしとした物

- **ボタンの音**: モード選び・曲えらび・難易度・縦横の切り替え・マスモン設定・マルチの部屋・準備・ポーズのボタンで、`se.tap` が毎回鳴った。カードバトル・HOME と同じ共通の音(モンサクだけボタンが無音なのは前の点検 Q-1-3 の件)
- **ノーツの音**: タップ119・ホールドの終わり13・フリック12・モンスターノーツ1 が、すべて鳴った。ホールドの終わりはタップの音と0.015秒以内に2つ重なる(13回とも)。終わりの音を重ねる作りなら問題なし
- **新記録**: 2回目に記録を更新すると、`playNewRecord` がフルコンボの1.3秒後に鳴った。ほかの音とは重ならない
- **ランクアップ**: 割れる音 → ファンファーレ → もらった物ごとの音、の順で鳴る(カードランクと同じ部品・意図どおり)
- **タップ音 OFF・音量0**: ノーツの音とフルコンボの音は止まった。ボタンの音・結果のランクアップの音は鳴った。r1119-047 の「鳴らさないのはノーツの効果音 OFF・音量0・全体ミュートのとき」と合う
- **コンボの節目**: 音は無い(演出だけ)。指摘には入れない
