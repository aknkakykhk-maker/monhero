## 二重にならないか(保存)

- デビュー戦の結果で閉じる → 開き直す: 勝ちが残り、点・賞金・ビートPは1回分だけ
- ファイナルの負けの画面で閉じる → 開き直す: ファイナルの前のホームへ戻る。もう一度戦うと同じ負け(引き直しはできない)
- 引退の画面で閉じる → 開き直す: 引退の画面から続き、引退後は途中の育成なし・ボックス1体・成績1件・ビートP 320(勝ちの170+引退Bの150)で二重なし
- 別のタブ・古い画面からの保存(#6712)はこの周では試していない
