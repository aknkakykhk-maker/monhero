## 決まりどおりに動いていたこと

- 能力ポイント: デビュー戦(★)+30・金の大会(★)+30・ヒーローズリーグ(★★)+60(#6702)。上限なしで、能力300を超えると「2点で+1」と出る
- 技の熟練: 10点で熟練+1、保存も合う(#6702)
- 振り分け: ちから+1 → 命中+1 → ちから−1 で、ちからだけ戻り命中は残る(r1115-172a)。おまかせは低い能力へ振る
- 結果だけ見る: その大会に勝つまでは押せず「一度優勝すると使えます」と出る(#6649 / r1115-172b)
- 試合の札: 後退(これ以上行けない/遠へ)・吹き飛ばし(零で使える・相手の手のあと遠へ)・前進が出て、吹き飛ばしで相手が遠へ飛ぶ(#6704)。届かない技は押せない
- 修行: 編成の効き「編成のおかげ ×4体/×5体」、超修行(チケット2枚・体力2回分・1つ覚えて1つ外す・外した技は次から +15%)(#6650)
- 中断 → 読み直し → 続きから: 大会当日の前・結果の画面・負けの画面とも、数字は崩れず続けられた(M1 のやり直しは別)

- 合体: 見通しの能力(132/144/169/228/187/148)とできた子が一致、親2体はメモリアルへ。合体の子で2周目を始められた
