## 新しい指摘が来たら

1. [`cases.json`](cases.json) に1件足す: 画面・直す前のコミット(`rev`)・社長の言葉・撮る道具と場面・拾うべき物(`expect.measure` に測る検査の種類、`expect.api` に API の言葉の正規表現)。実機の止め絵しか無いときは `"shots": ["repo:<道>"]`、`"shoot": null`
2. 撮って測る: `node tools/browser/president-eye-calibrate.js --out <置き場> --shoot --only <件>`(助手ライフは1件 約10分。ほかは数十秒)
3. API: `ANALYSIS_GATEWAY_TOKEN=proxy node tools/browser/president-eye-calibrate.js --out <置き場> --api --send --only <件>` → 数分後に `--fetch`(1件 約 $0.1)
4. 拾えなかったら、`ui-measure.js` の物差しか指示書(`prompts/common-balance.md`)を直し、拾えるまで回す。直したら、全部の件を回し直して、前に拾えた件が落ちていないかを見る

## 残り(次に直すとよい所)

- 絵の端の切れ(L4)は API が苦手。測る検査で「画像が、横に `overflow:hidden` の枠で切られている」を測る案がある。ただし、横に流れる一覧の絵も切れるので外れが多い。今回は足していない
- 実機だけの事情(安全な領域)は、ブラウザの撮影では出ない。上の部品が画面の頭から 20px 以内にあるときに、注意として出す案がある
- 助手ライフの撮影は、場面を絞っても全部の道を歩くので1件 約10分かかる
