## 4. 道具の側で分かったこと(直すのは道具)

- playbot の `enterQuickBattle`(tools/playbot/scenarios/battle.js)は、勇者モンの札の探し方(「くわしく見る」を含む札)が今の画面と合わず、一覧で止まる。見た目の点検の道具は自前の手順で進めた。playbot の「バトル」担当も同じところで止まっている見込み
- 横・PC では難易度の札が何枚も並んで見え、選ばれていない札の「この難易度で挑戦」を押すと札を選ぶだけで始まらない。選ばれた札(`article.on`)のボタンを押すようにした
- 前の版との差は、助手の立ち絵と台詞が毎回変わる画面で 45% 前後揺れる。「低」のまま扱う(API の目で「崩れか」を判定する)
