# 横向きのバトルで、手札と敵を同時に見る案(社長に選んでもらう)

ダメダシくんの見回り(クラシック f01・タクティクス g03)で見つかった件: 横向き(844×390)だと、
縦長の1列(幅390)が真ん中に出たままで、敵の舞台が潰れ(高さ16px)、手札が画面の下に隠れる。
「カードを選ぶ」を押しても手札は見えない。

**写真: [`proposals.jpg`](proposals.jpg)**(上がクラシック、下がタクティクス。左から いま・案A・案B。下に案C)

| 案 | 中身 | よいところ | 気になるところ |
| --- | --- | --- | --- |
| A | 横で背の低い画面だけ2列。左に敵・予告・4枠、右に手札とボタン | 敵の絵・予告・4枠・手札が全部いっしょに見える | 敵の「移動しようとしている」吹き出しは、いまの位置だと右の手札にかかる(採用なら置き場所も直す) |
| B | 1列のまま。敵の帯と絵を小さくし、手札を下に重ねる | 組み替えが少ない | 手札を出すと4枠の下半分が隠れる |
| C | 横向きでは「縦にしてね」の案内を出す | いちばん手が少ない | 横で遊びたい人は遊べない |

- ゲームのファイルはまだ変えていない。写真は、本物の戦いの画面に `proposal-*.css` をその場で足して撮った
- タクティクスの4枠は、どの案でもクラシックにそろえて横1列にした(縦画面の2×2は変えない)
- みゅあの説明(盤にかかるのは社長の決めごと)は触っていない。案の写真だけ、カードが見えるよう閉じるボタンで閉じてから撮った
- `proposal-*.css` は試しの物(撮るときに `@media` を付けず全部に効かせた)。採用したら `@media (orientation: landscape) and (max-height: 500px)` の中へ入れ、parts 側で作る
