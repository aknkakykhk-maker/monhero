## 2. 呼び方の仕組み(案)

### 2-1. 3つの入り口

| 入り口 | 流れ | 止め絵 |
| --- | --- | --- |
| ① プレイヤーから「こう呼んで」 | おしゃべりで「あっちゃんって呼んで」→ 助手が口調のまま反応 → 返事の下に**確かめるカード**「これから『あっちゃん』って呼んでいい？[うん、そう呼んで][いまのままで]」→ うんで決まる | 1・3 |
| ② 助手から「なんて呼べばいい？」 | 仲良し度の段が上がって呼び方が変わる所(❶で選ぶ)で、自動で変えずに、次のおしゃべりの最初に助手が聞く。返事の下に**候補のボタン**(その助手の段の呼び方・性別の くん/ちゃん から3つ)と「いまのまま」。送る欄に自由に書いてもよい(書いたら①と同じ確かめ) | 2・4 |
| ③ 会話の流れで自然に | 思い出メモや話の流れから、助手が「ねえ、◯◯って呼んでもいい？」と持ちかける(❹で選ぶ)。同じく確かめるカード。助手ごとに7日に1回まで(端末が数える) | (1 と同じカード) |

決まったあとは、その助手のつぎの吹き出しで1回だけ「あっちゃん、おつかれ♪ 呼び方、ちゃんと覚えてるからね！」+小さな札「みゅあの呼び方：あっちゃん」(止め絵5。3秒で消える。🔄横では回した器の中に出す)。

### 2-2. 助手ごとに別

- 呼び方は助手ごとに持つ(みゅあは「あっちゃん」、ききは「◯◯さん」のまま、など)。決めた助手だけ変わる(カードの下に「みゅあだけ呼び方が変わります」)
- 助手どうしの呼び方は変えない(2026-11-07 社長「呼び方は変えないでいい」のまま)

### 2-3. どこに出るか

`assistantCallName` の中で新しい呼び方を先に見るので、**その助手がプレイヤーを呼ぶ所ぜんぶ**に出る: 吹き出し・おしゃべり・1日1回の AI のひとこと・助手どうしの掛け合いの中でプレイヤーに触れる所・助手ライフ・育つ助手の相談。
出さない所: ランキング・フレンド・フレンドの家の相手・お話(加入のお話など台本で呼び方を決めてある所は今のまま)。

### 2-4. 決まる順(強い順)

1. 新しい呼び方 `mh_assistant_callname_v1`(会話・聞かれて答えた・プロフィールで決めた)
2. 今の Lv6 からの呼び方 `mh_assistant_call_style_<id>`(読むだけ。これまで決めた人はそのまま続く=下地)
3. 段の呼び方(性別の くん/ちゃん 込み。今のまま)

プロフィールの小窓(今の入力欄)は残し、ここで決めたものも 1. へ入れる(❺)。「最後に決めたものが使われる」になる。

### 2-5. AI が「こう呼んで」を読み取る方法

- **API を1回も増やさない。** 今のおしゃべりの返事の形(REPLY_SCHEMA)に、欄を1つ足すだけ:
  `call: { action: 'none' | 'confirm' | 'ask' | 'reset', value: '12字まで' }`
  - `confirm` … プレイヤーが呼び方を頼んだ/助手が持ちかけた。`value` が候補(名前の所は `{name}`)
  - `ask` … 段の所で「なんて呼べばいい？」と聞いた(端末が候補のボタンを出す)
  - `reset` … 「前の呼び方に戻して」
- 決まり文(RULES_TEXT)に足す(キャッシュに乗る): 「はっきり頼まれたときだけ confirm。冗談か分からないときも confirm(すぐ決めない)」「悪口・下品・恋人のような呼び方・本名や個人情報は confirm にせず、やんわり断る」「呼び方が変わっても口調は変えない」
- 中継役(core.js)でも `value` を見張る(長さ・下の禁止の言葉・`looksPersonal`)。通らなければ `none` にして返す
- **AI が読み取れなかったとき・API が止まっているとき**: 端末にも決まった形の読み取りを置く(「◯◯って呼んで」「◯◯と呼んでほしい」「◯◯でいいよ」)。当たったら同じ確かめるカード「◯◯って呼んでいい？」を出す。返事の文は台本(各助手3行ほど)
- **どの道でも、変わるのはカードで「うん」を押したときだけ**(❸で B を選ぶとすぐ変わる)

### 2-6. 元に戻す

- おしゃべりで「前の呼び方に戻して」→ `reset` →カード「◯◯さんに戻していい？」
- プロフィールの助手の呼び方の小窓に「会話で決めた呼び方：あっちゃん [元に戻す]」。戻すと 1. の行を消し、2.→3. の順に戻る(今のキーには触らない)
- 1つ前の呼び方(`prev`)も持っておき、「1つ前に戻す」もできる

### 2-7. 今の「助手Lvで決める」仕組みとのつなぎ

- 段の自動の変化はそのまま残す(決めなかった人・API を使わない人は今と同じ)
- ②で「いまのまま」を選ぶと、**その時の呼び方を 1. に固定**する(つぎの段で自動で変わらない。つぎの聞く所でまた聞く)
- Lv6 の解放の案内「呼び方を決められるようになったよ」は、文を「おしゃべりで『こう呼んで』と言っても決められる」に足す(告知の文は作るときに出す)

## 3. 守り(変な言葉・悪口・個人情報)

3段で弾く。どれか1つで止まる。

| 段 | 見るもの |
| --- | --- |
| AI(Haiku) | 決まり文で判定。悪口・下品・恋人のような呼び方・本名や個人情報は confirm にせず、口調のまま断る(「それはちょっと……別のにしよ？」) |
| 中継役(core.js) | 長さ(12字・名前を入れたあと)・禁止の言葉・`looksPersonal`(電話・メール・住所・郵便番号)・数字4つ以上・URL・`<>` などの記号 |
| 端末(保存の直前) | 同じ見張りをもう一度(古い中継役・台本の読み取りからでも通るので)。通らなければ保存しない |

- 禁止の言葉は短い一覧を端末と中継役で同じものにする(悪口・下ネタ・差別の言葉・「ダーリン」「ハニー」「彼氏」「彼女」「旦那」「嫁」などの恋人呼び・「本名」・「子」で呼ぶ言い回し「この子」「うちの子」)。一覧の中身は作るときに窓口へ出す
- 長さ: テンプレート16字まで(今の `ASSISTANT_CALL_STYLE_MAX_LEN` と同じ)・名前を入れたあと12字まで(吹き出しで切れないため)
- 名前がすでに敬称で終わるとき(「モンヒロくん」)は、今の `assistantFillCallTemplate` で敬称を重ねない(そのまま使う)
- 検査を足す: `tools/assistant/callname-guard-check.js`(禁止の言葉・長さ・個人情報が3段どれでも止まる/通る呼び方は通る/今のキーを書きかえない)

- 呼び出し: **増えない**(おしゃべりの1往復に相乗り)。無料枠 月50万回への影響 0

- 新しい関数・新しい表は作らない

### 4-3. API が止まったとき・上限に届いたとき

- どの道でも「AI」とは出さない

## 11. 助手ライフとつなぐ(案・2026-11-08 社長の追加)

社長「ちなみにこれってこっちからおしゃべりをしないとでない？このおしゃべり自体も助手ライフと連携させてそのへんの流れもうまいこといかないかな？助手に設定してなくても部屋に行ってはなしたときにそういう会話になるとか」

今は、おしゃべりは HOME の「💬 おしゃべり」から、**設定で選んだ1人**とだけ話せる。これを助手ライフの部屋からも、**だれとでも**話せるようにする。

止め絵(案の部品は黄色の点線): `shots/callname-life-1-room-portrait.jpg`・`-2-room-landscape.jpg`(部屋のシートに「💬 おしゃべりする」)/
`shots/callname-life-3-follow-portrait.jpg`・`-4-follow-landscape.jpg`(声をかけたあとの続き)/
`shots/callname-life-5-chat-portrait.jpg`・`-6-chat-landscape.jpg`(部屋から開いた、あつとのおしゃべり。Lv6 の「なんて呼んだらいい？」がその場で出る)。撮り方 `shots/callname-life-shots.js`

### 流れ

1. 助手ライフ → 家 → 部屋を押す → 部屋のシートに **「💬 おしゃべりする」**(起きている助手だけ)
2. 押すと、**その助手との**おしゃべりの窓が開く(設定で選んでいる助手は変わらない)。呼び方の確認カード・Lv6 の「なんて呼んだらいい？」・助手からの持ちかけ・あだ名は、その場で出る(作った仕組みをそのまま使う)
3. **「💬 声をかける」のあと**、掛け合いが終わって部屋に戻ったら、続きのカード「(助手のひとこと)[💬 おしゃべりする][またね]」を1回出す。
   その助手が Lv6 でまだ呼び方を聞いていない/持ちかけてよい日なら、ひとことが呼び方の話になる(「てか、だいぶ仲いいよね笑 呼び方、そろそろ決めない？」)。ほかの日はふつうのひとこと(台本)
4. 閉じると部屋のシートへ戻る

### 決まり

- 回数・費用は今のおしゃべりと**同じ枠**(1人1日100往復・全員1日2,000往復)。増えるのは、選んでいない助手とも話せることだけで、上限は変えない。費用の見積もり(最悪 約$97/月)も変わらない
- 呼び方・あだ名は助手ごとに別で、どこで決めても同じ保存(`mh_assistant_callname_v1` など)に入る
- 思い出メモ・会話の記録は、もともと助手ごとに分けて持っている(`mh_assistant_chat_log_v1`・`mh_assistant_chat_memo_v2`)ので、そのまま使える
- 仲良し度は、**話した助手**のぶんに入る(❿)
- 寝ている助手には出さない(❽)

### 差し込み口(ナカヨシ7とのすり合わせ)

- 本体(60-app.jsx)が、`ASSISTANT_LIFE_LINKS.chatWith = (id, opts) => …` を用意する(今の `beatInvite`・`cardInvite` と同じ形)。開く窓は今の `AssistantChatWindow` で、相手の助手 id を渡せるようにする(ココロが作る)
- 部屋のシート(56-assistant-life-house.jsx・ナカヨシ7の持ち物)は、`typeof ASSISTANT_LIFE_LINKS.chatWith === 'function'` のときだけ「💬 おしゃべりする」を出す。声をかけた掛け合いが終わったら続きのカードを出し、ひとことは `assistantCallnameLifeLine(id)`(ココロが作る。呼び方の話にするか・ふつうのひとことかを返す)から取る
- 公開の印は `assistantCallname` と同じにそろえる(偽のあいだは、部屋に「おしゃべりする」も出さない)

### 社長に選んでもらう所(A がおすすめ)

| | A(おすすめ) | B |

### 更新履歴の文案(この形に合わせて書き直し。社長の「この文で」待ち)

題: 助手とのおしゃべりで、呼び方を決められるようになりました
- おしゃべりで「〇〇って呼んで」と話しかけると、助手が「〇〇って呼んでいい？」と確かめてくれます。「うん」を押すと、その助手はこれからその呼び方で呼んでくれます。
- 助手ライフの部屋からも、その助手とおしゃべりできるようになりました。いっしょに遊ぶ助手に選んでいない助手とも話せます。
- 呼び方は助手ごとに別々に決められます。仲良くなったばかりのうちは、照れて「もう少しあとでね」と言う助手もいます。
- 仲良し度がLv6になると、助手のほうから「なんて呼んだらいい？」と聞いてきます。話の流れで、助手から新しい呼び方を持ちかけてくることもあります。
- 「〇〇って呼んでいい？」と、助手にあだ名を付けることもできます。
- 決めた呼び方とあだ名は、プロフィールの助手の「呼び方」から元に戻せます。
