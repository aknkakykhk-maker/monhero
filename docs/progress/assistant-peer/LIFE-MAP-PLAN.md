## いまのずれ(縦)
- MFバトルカード: 地図は闘技場/HOME は左の中ほどの札(闘技場は「モンヒロバトル」)
- 助手の家: 地図は左下の林/HOME の「助手ライフ」の札は M/B管理とモンヒロビートのあいだ
- モンヒロビート: どちらも左の赤い屋根の家だが、札の高さがちがう
- 図書室・おやつ屋さん・ひなたの丘・中庭: HOME に無い場所を、HOME の建物に後から札を貼ったように見える
- 札と顔の丸が建物に浮いて、助手が「そこにいる」感じが薄い

## A(おすすめ): HOME の画面そのものを地図にする
- 絵・切り抜き・札の位置を HOME と1対1に(HOME の札の部品をそのまま使う)。施設の場所は HOME の札そのもの、助手は札の上に小さな全身で立つ
- 町だけの場所(図書室・おやつ屋さん・ひなたの丘・中庭・広場)は、HOME の札と同じ形の小さめの札で、HOME に札の無い建物・場所へ(図書室=神殿の奥の塔/おやつ屋さん=右上の家/ひなたの丘=滝の上/中庭=泉の下の芝生/広場=方位の印)
- 時間帯の明るさ・🔄横の作りも HOME と同じになる
- 良くなる所: HOME と地図の位置がずれない(同じ部品なので、HOME を直せば地図も直る)。助手が「建物の前にいる」と分かる
- 気をつける所: 横は HOME と同じく、絵が真ん中の細い帯で札が左右に広がる(止め絵の横 A)。全身が重なる人数(4人)は縮める

## B: HOME の絵を使わない、場所ごとのカード一覧
- 11の場所をカードで並べ、いる助手を全身で。HOME に札がある場所は「HOME の札と同じ」の印
- 良くなる所: 位置のずれが起きない・字が大きく読みやすい・横でも崩れにくい
- 気をつける所: 町を歩いている感じは減る

## C: HOME と同じ並びの見取り図(タイル)
- 絵の代わりに、HOME の札と同じ位置関係のタイルを並べ、タイルの中に全身
- 良くなる所: 位置関係は HOME とそろい、絵の上に札を貼った感じは無くなる
- 気をつける所: 見た目が素っ気ない(絵を描き起こすなら別の注文が要る)
