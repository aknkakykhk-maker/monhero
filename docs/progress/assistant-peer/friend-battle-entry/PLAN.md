# フレンドの家から、その助手のマスモンに挑む入口(案・r1115-004)

社長 11/11「フレンドのとこにいったらそこから戦えるようにもするとわかりやすい」。止め絵: `friend-battle-entry-390.png` / `friend-battle-entry-320.png`(元 `mock.html`)

## 案(新しい対戦の仕組みは作らない・サーバ変更なし)
1. **入口**: フレンドの家の部屋シート(`AlfMsRoomLink` の「🐾 ◯◯のマスモン ›」の直下)に、赤い「⚔ ◯◯のマスモンに挑む ›」を1つ足す。
   出す条件は、対戦の印(`ambbPvpOn()`)が真のときだけ。偽のあいだは出さない。
2. **押した後**: 既存の対戦画面(`assistantMasmonBattleOpen`)を開く。開き口に `friendId`(家の主)と `friendAssistantId`(いま見ている部屋の助手)を足し、
   対戦画面は「👥 フレンドの助手」の側で、その相手を選んだ状態で始まる(`AmbbFriendPanel` の `pickF` の初期値)。
   「挑む」「ランキングの区分」「今日あと◯回」は既存のまま。挑むときの登録し直し・サーバでの試合(masmon-pvp)も既存のまま。
3. **戻る**: 対戦画面は上に重なる形なので、閉じるとフレンドの家のその部屋に戻る。
4. **相手が編成を登録していないとき**: 既存の文「フレンドが助手の編成を登録すると、ここに出ます。」。入口は出したまま、押すとその文が見える。
5. **自分にマスモンがいないとき**: 既存の文「対戦に出せるマスモンがいません。助手ライフで、助手がマスモンを迎えると対戦できます。」。
6. 自分の助手は既存どおり(マスモンを持つ助手の先頭)。画面で変えられる。
