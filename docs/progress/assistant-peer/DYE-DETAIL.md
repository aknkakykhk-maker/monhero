## 5体の染め方(役)
1体目は必ず「好きな色が主役」。2〜5体目は助手ごとの候補5つから、プレイヤーごとに4つを選んで並べる。
| 役 | 中身 |
| --- | --- |
| 好きな色が主役 | いちばん広い部位に好きな色、ほかの部位にも好きな色を順に(くせの割合で元の色を残す) |
| 差し色だけ | いちばん小さい部位1〜2か所だけ、はっきりめに |
| 同じ色の濃淡 | 色のある好きな色1つを、広い部位から 深い→そのまま→薄め→淡い の順に |
| 反対色を差す | 広い部位に好きな色、小さい部位に反対色 |
| 元の色に近い | 1か所を薄く(25〜40%) |
| 全部の部位を思い切って | 染められる部位を全部。好きな色と反対色を交互に |
| 思いがけない色 | 好きな色でも苦手でもない色を、広い部位と小さい部位に |
| 季節の色 | 小さい部位に季節の色(春 薄ピンク・薄黄緑・薄黄/夏 空色・シアン・黄/秋 橙・赤・黄/冬 白・薄青・赤) |

## ❷ 部位ごとの決まり(`ASSISTANT_MASMON_DYE_PARTS`・`assistantMasmonPartRule`)
部位の意味と広さは、30体の部位を1つずつ染めて実測した(広さ=体に占める%)。
| 印 | 決まり |
| --- | --- |
| face(顔・目・口) | 染めない(ザンの目・スエゾーの瞳・ミタラシの口元・イルミネの目と模様) |
| skin(顔を含む肌・体の地) | 55%まで。深い版とあざやかな版は使わず薄めに(顔色が悪く見えない) |
| white(白い部位) | 60%まで。黒と深い版は使わない(灰色ににごる) |
| dark(黒っぽい部位) | 70%まで。淡い版・薄め・白は55%まで(白っぽく浮く) |
| clear(透ける・光る部位) | 50%まで(ゴーストの体・イルミネの光る髪・エイキのオーラ など) |
| wide(体の45%以上) | 75%まで(陰影が消えない) |
| 印なし | 90%まで |

## ❹ 変な色の歯止め(`assistantMasmonDyeLimit`)
- 思いがけない色は1体に2か所まで。広い部位では60%まで。主役の色は上書きしない(まだ染めていない部位にだけ差す)
- 暗い部位以外に深い版は65%まで(明るい部位に濃くかけると濁る)
- 染めた広さ×濃さの合計を 0.75(思い切った役は 0.9)までに下げる。元の絵の陰影と輪郭を残す
- あざやかな反対色どうし(色相が150度以上はなれる)を両方80%以上にしない(小さい方を65%)
- 最低20%(見えない染めを作らない)

## ❸ 変化(どれも「前の色は残す」)
保存は `mh_assistant_life_masmon_v1` に新しい項目 `dyes`(助手ごとの記録の列)を足しただけ。`made[].colors`(v1)は書き換えない。
| 記録 | いつ | 何をする | 二度足さない印 |
| --- | --- | --- | --- |
| remake(v2) | 初めて開いたとき | 5体を v2 の設定で染め直す | 同じ版(v:2)の remake があれば足さない |
| season | 季節が変わって最初に開いたとき | 1体だけ(前の季節と別の子)季節の色を差す | 最後の記録と同じ季節なら足さない |
| like | 助手の好きな色の表が変わったとき | 先頭の1体を新しい好きな色で | 最後に記録した好きな色と同じなら足さない |
- いまの色 = 記録の新しい順にその枠を含む最初のもの。無ければ v1 の色
- 記録は助手ごとに40件まで(最初の remake は残す)
- プレイヤーごとの差: 役の選び方・並び・好きな色の順・版・濃さ・色相の少しのずれが、プレイヤーの種(ブリーダーID)で決まる
- 詳しい画面の「染めた色」に部位の名前を出し、下に「🎨 11/08 染め方を見直しました(同じ色の濃淡) 前の色 ●●●」を出す
