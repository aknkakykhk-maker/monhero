# 助手マスモン対戦 β: 作戦・交代の早さの数字の案(ミセカタ2・2026-11-11)

社長の決め「自分で決めるのは 形・3体と順番・作戦・交代の早さ(おまかせと切替)」の、作戦と交代の早さの中身。
計算(`data/assistant-masmon-battle.js`・タタカイ)には手を入れず、`team.style` の上書きだけで作る。

## 形

- 上書きの値 = **その助手の型(`STYLES[助手]`)× 下の倍率**。助手の性格は残したまま、向きだけ寄せる
- 上書きした値は 0.4〜1.8(交代 `swap` だけ 0.3〜2.0)に収める
- 「おまかせ」は上書きなし(いまの計算そのまま)
