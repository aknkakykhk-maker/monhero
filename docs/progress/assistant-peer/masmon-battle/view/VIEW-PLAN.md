# 助手マスモンの対戦の見せ方(案 v1・2026-11-11 ミセカタ)

**まだ何も作っていない。** 社長が選んでから、タタカイの計算(`monster-hero/data/assistant-masmon-battle.js`)の
1戦の記録を再生する画面として作る。計算は触らない。止め絵はこのフォルダ、作りは `mock-view.html`。
止め絵の数字は、本物の計算で回した1戦(きき 対 みゅあ・28ラウンド・惜しい負け)の記録から作った。
技の名前はいまの技データのもの(シュギョウの新しい技表が入れば、札の中身がそのまま入れ替わる。距離撃の札は無くなる)。

社長のことば: 「もっとわかりやすく楽しさをだして」「人が手を加えれば加えるほど強くなる」「最大3VS3で1VS1とかバリエーションあり」
「ランキングも作る」「自分で指定も出来るし任せる事もできる」。

見せ方の決まり(どの案でも):
- **技**: 帯に「💪 ちから技/🧠 かしこさ技・ガッツ −◯」と技の名前。はずれは「はずれ」、ガードで減ったら「ガード!」
- **距離**: 2体の間の広さ+下の「零 近 中 遠」。札の技は、届く=明るい・届くがガッツ不足=白い字・届かない=暗い
- **ガッツ**: ライフの下の黄色い棒(25 ごとの目盛り)。技を出すと減り、ためると増えるのが見える
- **会心**: 数字が大きく・「会心!」・相手が光ってのけぞる。**交代**: 控えの顔が入れ替わり「交代!」
- **とばし**: 「結果へ」でいつでも振り返りへ。速さは次の観戦でも覚える(新しい保存キーを1つ足すだけ)

## 2. 勝敗のあとの振り返り(選ぶ所 ❷・止め絵 `view-3-review.png`)

- **この1戦の数字**: 技が当たった回数・会心・与えたダメージ・いちばん活躍したマスモン
- **🔍 もしも こう育っていたら**: 同じ相手と同じ編成で、能力を1つだけ +80 して計算し直し、勝率がいちばん上がる3つを出す
  (止め絵は本物の数字: いまのまま 24% → ライフ +80 で 44%)。助手がそれを自分の言葉で言い、
  **「💡『◯◯を鍛えて』と提案する」**でそのまま提案(いまの「助手に提案する」の入口)へつなぐ
- **あなたが関わって伸びた分**: 助言・提案で伸びた能力の合計を出す(「何もしなかった場合より +◯」)。育成(キズナ4・シュギョウ)の記録に数があれば出す

| B | 数字と「もしも」だけ(関わった分は育成の画面に任せる) |

## 3. ランキング(選ぶ所 ❸・止め絵 `view-4-ranking.png`)

- タブ2つ: 「💪 育てた強さで」「⚖ 同じ強さで腕くらべ」(PLAN.md の2区分)+形(3 VS 3/2 VS 2/1 VS 1)
- 自分の行をいつも上に固定(順位・勝敗・ポイント・出した3体)。**次の段まであと◯**の棒で、近い目標を見せる
- 上位の行は プレイヤー名+助手の顔+3体。**▶ でその人の最近の1戦を観戦**(記録は種と編成で再現)
- 既存のランキング(チャレンジ・絆 など)とは別の画面・別の表。混ぜない

| | 順位の付け方の見せ方 |
| --- | --- |
| A(推奨) | ポイント順+段(ブロンズ→シルバー→ゴールド…)。週ごとに区切る |
| B | ポイント順だけ(段なし) |
| C | 勝ち数だけ(いちばん単純。たくさん戦った人が上) |

ポイントの計算・表・対戦の回数はタイセン(サーバ)と決める。ここは見せ方だけ。

## 4. 自分で決める/おまかせ(選ぶ所 ❹・止め絵 `view-5-prepare.png`)

- いちばん上のスイッチ「🌸 ◯◯に おまかせ/✍ 自分で決める」
- 自分で決める: 対戦の形・出すマスモンと順番・作戦(ぐいぐい攻める/間合いをとる/じっくり守る/助手の考えで)・交代の早さ
- 決めるたびに助手がひとこと返す(相手を見た助言)。おまかせは、助手が相手を見て全部決め、理由をひとこと言う

| | 指定できる広さ |
| --- | --- |
| A(推奨) | 形・3体と順番・作戦・交代の早さ(止め絵の形) |
| B | 形と3体と順番だけ(作戦は助手) |
| C | A に加えて、マスモンごとに「よく使う技」も指定 |

作戦と交代の早さは、タタカイの計算の入力(性格の重みへの上乗せ)が要る。A・C を選んだらタタカイと形を決める。

## 5. タタカイに頼みたい記録の形(計算の中身は変えない・足すだけ)

1. 技の手に、撃つ前の**命中率**(%)。「命中 72% → 当たり」と出す・振り返りで「運」と「能力不足」を分ける
2. 始まりの記録に、各マスモンの**技の一覧**(名前・種類・ガッツ・届く距離)。札の「いま届く技」に使う(いまは `buildMoves` が外から呼べない)
3. 各手の終わりの**両方のガッツ**(毎ラウンドの回復が記録に無く、再生でずれる)
4. 技の手に、**受けた側の番号**
5. (あれば)選んだ手の理由の種類(「ガッツ不足」「倒しきれる」など)。助手のひとことに使う

「もしも」は端末で同じ計算を回し直すだけ(Node で 2100 戦が約1秒)。保存もサーバも要らない。
