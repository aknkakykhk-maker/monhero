# 助手のマスモンで対戦する(案・2026-11-11 キズナ4)

社長「今後は助手が育てたマスモンを、助手同士やフレンド対戦とかでもできるようにしたい」への案。
**まだ作らない。** 社長が選んでから作る。見本の止め絵はこのフォルダの `mock-s1.jpg`〜`mock-s4.jpg`(作りは `mock.html`)。

## いまの作りで分かったこと

- **モンヒロバトルの戦いは「編成 対 敵のウェーブ」。** 計算(`processTurn`)は画面(App)の中にあり、編成どうしを戦わせたり、画面なしで回したりはできない
- 助手のマスモンには、種類・Lv・育て方(攻撃型など)・技の名前がある。能力のゲージは「基礎値 × Lv × 育て方」でその場で計算している(数字は保存していない)
- フレンドの家には、助手のマスモンの写し(名前・種類・色だけ)が控えの表で渡っている(6000字まで)。Lv と育て方はまだ渡していない
- 前例: MFバトルカードの大会は、デッキの写しをサーバで自動で戦わせ、朝4:00に結果を見せている(`card-tournament-run`)

## 決めてほしいこと

### Q1 戦いの中身(いちばん大事)

| | 中身 | よいところ | 気になるところ |
| --- | --- | --- | --- |
| **A(推奨)** | **新しい「マスモン対戦」**: 勇者モン+3体の4対4。零・近・中・遠に並び、能力(ライフ・攻撃・防御・ガッツ)・育て方・技の名前で、自動で殴り合う。勇者モンが先に倒れた方の負け。同じ種(たね)なら必ず同じ結果になるので、あとから同じ試合を見返せる | 画面なしで一瞬で回せる(端末でもサーバでも)。助手ごとの育て方・提案が勝ち負けに効く | モンヒロバトルとは別の、新しい計算になる |
| B | モンヒロバトルの道を同じ難しさで走らせて、どこまで進めたか(WAVE・スコア)で比べる | いまのバトルの計算をそのまま使える | 計算が画面の中にあるので、外へ取り出す大きな作り直しが要る。相手と直接戦う感じは出ない |

### Q2 助手どうしの対戦(見本 `mock-s1.jpg`・`mock-s2.jpg`)

| | 中身 |
| --- | --- |
| **A(推奨)** | **助手リーグ**: 8人が自分の編成で週ごとに総当たり。毎日1試合、朝4:00に結果。プレイヤーは「どっちが勝つか予想」(当たるとビートP)・「応援」(1日1回・仲良し度が少し上がる)・「作戦を提案」(いまの提案の仕組みで育て方や勇者モンを変える)。試合は ▶ で見返せる |
| B | **練習試合**: 好きな2人を選んで、その場で戦わせて見る(予想・応援なし・ごほうびなし) |
| C | A と B の両方 |

- 戦うのは、そのプレイヤーの端末にいる助手のマスモン(人ごとに顔ぶれが違う)。なので**サーバは使わず、端末の中だけで回る**
- 入口は助手ライフの中(置き場所はナカヨシ9の「助手ライフをもっと見やすく」とすり合わせ中)。各助手の「🐾 マスモン」の画面に戦績を出す

### Q3 フレンド対戦(見本 `mock-s3.jpg`・`mock-s4.jpg`)

| | 中身 |
| --- | --- |
| **A(推奨)** | フレンドの家から「⚔ ◯◯のマスモンに挑む」。**自分の助手**(8人から1人)の編成で、相手の助手の写しと戦う。相手がその場にいなくてよい。1日3回まで。勝ち負けは相手の家の「最近」にも残る(「ききが挑みに来た(ききの勝ち)」) |
| B | A に加えて、**プレイヤー自身のマスモン**(モンヒロバトルの編成)でも挑める。強さの物差しが助手のマスモンと違うので、そろえる計算が要る |

### Q4 勝ち負けで起きること

| | 中身 |
| --- | --- |
| **A(推奨)** | ごほうびは小さく: 予想の当たりでビートP・応援と勝ちで仲良し度が少し。助手が勝ち負けで台詞を言う。負けが続くと、助手が「次は防御型も考えようかな」と育て方の相談をしてくる。**ランキングには入れない** |
| B | A に加えて、助手リーグの優勝回数や、フレンド対戦の勝ち数のランキングを作る |

- B にしない理由: 助手のマスモンの強さは提案で変えられるので、ランキングにすると「強い型に寄せるだけ」の競争になりやすい
