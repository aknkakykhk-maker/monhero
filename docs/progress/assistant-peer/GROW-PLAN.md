## 0. 守ること(全部の案で同じ)

- プレイヤーのスコア・ランキング・セーブ・マスモン・ビートP などの数には効かせない。助手の育ちは**助手の中だけ**
- 助手とのセッションは「スコアと判定は変えない」(2026-11-07 社長の決定)のまま。助手の腕前は見た目・台詞・助手側の表示だけに出す
- 保存は新しいキーで足すだけ(`mh_assistant_life_grow_v1` など)。今のキー(セッション Lv・カード・バトル)は書きかえない
- 呼び方は `{name}`・「子」と呼ばない・えるびんの私生活に触れない・「友情Lv」は助手どうし/「仲良し度」はプレイヤーと助手
- 遊ぶうちに順に開く(助手ライフの決まり)。相談は仲良し度 Lv3 から、マスモンは Lv5 から など

## 7. Claude API を使う所(2026-11-08 社長「APIの使用量がこんなもんだから活用出来そうなら使っていいから」・今月 $0.43/上限 $500)

使うのは「その場で変わる受け答え」だけ。決まったもの(ニックネーム・デッキ名・組んだわけ・好き/苦手のわけ)は、先にコトバ・ツムギが書いた台本(データ)にして、API は使わない(毎回同じでよく、社長が選んだ文を変えないため)。

| 使う所 | 中身 | 1回の量(目安) |
| --- | --- | --- |
| ① 相談の問いかけ | 助手のいまの腕前・得意・最近の出来事(今日あったこと・けんか)から、相談の文と2〜3択を作る | 入力 約3,000(うち決まり文 約2,500はキャッシュ)・出力 約300 |
| ② 相談の答えへの返し | プレイヤーの選んだ答えに、その助手の口調で返す(育ち方の向きは選んだ択で決まる。API は文だけ) | 入力 約3,000(同)・出力 約200 |
| ③ 育った報告のひとこと | 「はじめて HELL を最後まで叩けた」など、掲示板と部屋の吹き出し | 入力 約2,000・出力 約100 |

- 使うモデルは今のおしゃべりと同じ `claude-haiku-5-5`(料金 入力 $0.10・キャッシュ読み $0.01・出力 $0.50/100万トークン。assistant-peer-plan.md と同じ表)
- 1回の費用: ① 約 $0.0002・② 約 $0.00018・③ 約 $0.0001。相談1回(①+②)で 約 $0.0004

### (1) 月の費用の見積もり

| 遊ぶ人 | 1人1日 | 月の呼び出し | 月の費用 |
| --- | --- | --- | --- |
| 毎日100人 | 相談3回(①+②で6回)+報告2回 = 8回・約 $0.0014 | 約 2.4万回 | 約 $4 |
| 毎日1,000人 | 同じ | 約 24万回 → 全員の上限で 約 9万回 | 約 $15(上限で止まる) |
| 上限まで(全員で1日3,000回) | — | 約 9万回 | 約 $15 |

- 全員の1日の上限(例 3,000回)と1人1日の上限(相談は助手ごとに1日1回なので最大8回)を、今のおしゃべりと同じ形で Secrets から下げられるようにする
- 上の表は、今のおしゃべり・AI 版の掛け合い(assistant-peer-plan.md の最悪 約 $265)に足しても、上限 $500 に収まる

### (2) Supabase(Edge Function・送信量)

- 新しい関数は作らず、今の `assistant-chat` に `kind:'grow_consult'`・`'grow_report'` を足す(鍵・上限・記録をまとめて使う)
- 呼び出し: 上限どおりなら月 約9万回(毎日1,000人でも全員の上限で止まる)。無料枠 月50万回のうち、今のおしゃべり・掛け合いの分と合わせて見る。足りなくなりそうなら全員の上限を下げる
- 送信量: 1回 約4KB(往復)。月9万回で 約0.4GB。無料枠(5GB)の1割ほど

### (3) API が止まったとき・上限に届いたとき

- ①②③とも、台本の決まった文で代わりに出す(コトバ・ツムギに注文する相談 96本・返し 96本・報告 48本。GROW-PLAN の 4 の台本)。プレイヤーには違いが見えない(「AI」と出さない)
- 待ちは 3秒まで。間に合わなければ決まった文を出し、あとから届いた API の文は捨てる
- 答えで変わる育ち方(得意・攻め/守り)は、選んだ択で端末の中だけで決める。API の返事に頼らない(止まっても育ちは同じ)
- 鍵はリポジトリに置かない(Supabase の Secrets にある今の鍵を使う)。送るのは助手の id・腕前の★・最近の出来事の短い文だけ(プレイヤーの名前・個人の情報は送らない。呼び方は端末で {name} を置きかえる)
- 返ってきた文は、今のおしゃべりと同じ見張り(80字まで・「子」と呼ばない・「ブリーダー」と直に書かない・悪口なし)を通し、通らなければ決まった文
