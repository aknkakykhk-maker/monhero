## 0. 守ること(全部の案で同じ)

- プレイヤーのスコア・ランキング・セーブ・マスモン・ビートP などの数には効かせない。助手の育ちは**助手の中だけ**
- 助手とのセッションは「スコアと判定は変えない」(2026-11-07 社長の決定)のまま。助手の腕前は見た目・台詞・助手側の表示だけに出す
- 保存は新しいキーで足すだけ(`mh_assistant_life_grow_v1` など)。今のキー(セッション Lv・カード・バトル)は書きかえない
- 呼び方は `{name}`・「子」と呼ばない・えるびんの私生活に触れない・「友情Lv」は助手どうし/「仲良し度」はプレイヤーと助手
- 遊ぶうちに順に開く(助手ライフの決まり)。相談は仲良し度 Lv3 から、マスモンは Lv5 から など

## 6. 助手のマスモン(育成・染色)・好き/苦手・MFバトルカードのデッキ(2026-11-08 社長の追加の指示)

社長「助手のバトルカードやマスモンはちゃんと名前とか考えて作らせて、助手にもマスモン一覧とか編成とかもプレイヤーと同じように存在すると面白い」「各助手のモンスターの好き嫌いは血統単位で3種類ぐらい決めたい」「まだ実装されてないベースモンが入ってる」「マスモンとデッキに組むモンスターはあくまでも別化扱いだよね？あとマスモンにも俺らみたいに成長システムや染色システムもある？好き嫌いはその個体の好き嫌いでいいけど、その血統にも影響させたい。剣士モッチーが好きならモッチー種も好きみたいな」

- 🐾 マスモン(助手が育てている個体): 1人3体・先頭1体・ニックネーム。実装済み(ALL_PLAYER_MONSTERS)だけ

### (2) Supabase(Edge Function・送信量)

- 新しい関数は作らず、今の `assistant-chat` に `kind:'grow_consult'`・`'grow_report'` を足す(鍵・上限・記録をまとめて使う)

### (3) API が止まったとき・上限に届いたとき

- ①②③とも、台本の決まった文で代わりに出す(コトバ・ツムギに注文する相談 96本・返し 96本・報告 48本。GROW-PLAN の 4 の台本)。プレイヤーには違いが見えない(「AI」と出さない)
- 待ちは 3秒まで。間に合わなければ決まった文を出し、あとから届いた API の文は捨てる
- 答えで変わる育ち方(得意・攻め/守り)は、選んだ択で端末の中だけで決める。API の返事に頼らない(止まっても育ちは同じ)
- 鍵はリポジトリに置かない(Supabase の Secrets にある今の鍵を使う)。送るのは助手の id・腕前の★・最近の出来事の短い文だけ(プレイヤーの名前・個人の情報は送らない。呼び方は端末で {name} を置きかえる)
- 返ってきた文は、今のおしゃべりと同じ見張り(80字まで・「子」と呼ばない・「ブリーダー」と直に書かない・悪口なし)を通し、通らなければ決まった文

## 8. 好き嫌いが遊んでいくうちに変わる(2026-11-08 社長「好き嫌いも遊んでいくうちに変わることもある。そういう誘導もできる仕組みも欲しいね」)

### 持ち方
- 今日決めた好き・苦手・好きな色(`masmon-plan.json`)は「はじめの好み」。データに置いたまま変えない
- 「今の好み」は新しいキー `mh_assistant_life_taste_v1` に、はじめとの差分だけを持つ: `{ [助手id]: { mon: { [モンスターid]: 点 }, lin: { [血統]: 点 }, color: { [色の名前]: 点 }, log: [{ day, target, from, to }] } }`
- 点は -100〜+100。はじめの好き +60・苦手 -60・ふつう 0。モンスターの点はその血統へ3割広がる(「剣士モッチーが好き → モッチー種も少し」と同じ)
- 段: +40 以上 = 好き/-39〜+39 = ふつう/-40 以下 = 苦手。段が変わったときだけ知らせる
- 推し(性格の芯)は「芯」の印: みゅあ=モッチー種・きき=ゴーレム・ももすけ=メロディー・ドラ=スエゾー・あつ=モッチー種(特別)・きゅうこ=イルミネ・ソラシド=キュービ・えるびん=アーク

### 知らせ方
- 段が変わった日: その助手のひとこと(「最近{c}…ちょっと好きになってきたかも」など。台本はコトバ・ツムギに注文)・家の掲示板「今日あったこと」に1件・部屋の「💗 好き・苦手」タブに「変化」の印(はじめの好みと並べて見せる)
- 数字(点)は見せない。段と「ちょっと好きになってきた」などの言葉だけ

### 守ること
- スコア・ランキング・強さ・ごほうびには効かせない(反応の台詞・マスモンの選び方だけ)
- はじめの好みは消さない。今の好みを消せばはじめに戻れる(ヘルプにも書かない程度の裏の安全策)
- 苦手→好きは時間がかかる(すぐ変わると性格がぶれて見える)
