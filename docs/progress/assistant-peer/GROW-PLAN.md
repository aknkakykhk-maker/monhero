# 助手が育つ・相談してくる・自分のマスモン(案だけ・作るのは決まってから)

2026-11-08 助手部キズナ。社長の言葉(2026-11-07):

あとはモンスターの再生とかとして助手のマスモンや編成とかもできてそのへんも聞いてきたり一緒に神殿に行こうとか誘ってきたり。
たまにそのマスモンと遊んでたりとかいろいろやれそうだよね」/2026-11-08「先に案だけ作る」

止め絵(見本): `ux/grow-mock.png`(作り方は `ux/grow-mock.html`)。家のどこに入るかは `LIFE-HOUSE-PLAN.md` の 7(段階4・5)。

## 0. 守ること(全部の案で同じ)

- プレイヤーのスコア・ランキング・セーブ・マスモン・ビートP などの数には効かせない。助手の育ちは**助手の中だけ**
- 助手とのセッションは「スコアと判定は変えない」(2026-11-07 社長の決定)のまま。助手の腕前は見た目・台詞・助手側の表示だけに出す
- 保存は新しいキーで足すだけ(`mh_assistant_life_grow_v1` など)。今のキー(セッション Lv・カード・バトル)は書きかえない
- 呼び方は `{name}`・「子」と呼ばない・えるびんの私生活に触れない・「友情Lv」は助手どうし/「仲良し度」はプレイヤーと助手
- 遊ぶうちに順に開く(助手ライフの決まり)。相談は仲良し度 Lv3 から、マスモンは Lv5 から など

## 1. 全体の形

| 柱 | 中身 | 家のどこ | 育つもと |
| --- | --- | --- | --- |
| ① ビートがうまくなる | 助手ごとの「🎵 ビートの腕前」★1〜5 と得意(正確さ/速い曲/スライド) | 部屋の棚(🏆 トロフィー・ヘッドホン)・掲示板「はじめて HELL を最後まで叩けた」 | 助手ライフで練習スタジオ(モンヒロビート)に行った回数・セッションで一緒に遊んだ回数・相談の答え |
| ② デッキを変える | 助手ごとの「🃏 デッキの好み」(攻め⇔守り)。ときどき組みかえる | 部屋の棚(🗃️ デッキ箱)・掲示板「◯◯がデッキを組みかえた」・カードの対戦の相手のデッキ名 | カード部屋に行った回数・カード対戦の勝ち負け・相談の答え |
| ③ 相談してくる | 部屋に「？」。ビート・カード・マスモンの3種類。2〜3択の答え | 部屋の「？」→ 部屋のシート | 1日1回(助手ごと)。答えで「育ち方の向き」と仲良し度 |
| ④ 助手のマスモン | 助手ごとに1体。再生で入れかわる・育つ。中庭や部屋で一緒に遊ぶ姿 | 中庭・部屋 | 神殿・育成場に行った回数・再生 |
| ⑤ 神殿に誘う | 「一緒に神殿に行かない？」のおさそい(1日1回まで) | 家の手紙(今日やれることの札) | 誘いを受けて神殿で戦う |

人間らしい出来事(けんか・ライバル心)ともつなぐ: 腕前が近い2人はライバル心の掛け合いが出やすい/相談に乗る(consult)の中身に「デッキ」「曲」の話を足す。

## 2. 社長に選んでもらう所

| | A(おすすめ) | B |
| --- | --- | --- |
| ❶ 腕前の値 | 新しい「🎵 ビートの腕前」「🃏 デッキの好み」(★で見せる)。セッションLv とは別に、日々の過ごし方で育つ | 今のセッションLv をそのまま「うまさ」として使う(新しい値は作らない) |
| ❷ 相談の答えの効き方 | 答えで「育ち方の向き」(得意・攻め/守り)が変わる+仲良し度 | 仲良し度だけ。育ち方は日々の過ごし方だけで決まる |
| ❸ デッキが変わる範囲 | MFバトルカードで対戦するときの助手のデッキの中身が変わる(強さの段・ごほうびは変えない) | デッキの名前と見た目(部屋の箱・掲示板)だけ |
| ❹ 助手のマスモン | 助手ごとに決まった1体(血統は性格に合わせて社長が選ぶ)。再生で入れかわる(助手の中だけ) | プレイヤーのマスモンを1体「預ける」(預けているあいだは使えない) |
| ❺ 神殿の誘い | 神殿のバトルで横から応援(見た目とひとこと・数字は変えない) | 助手のマスモンが一緒に戦う(1枠。バトル部の調整がいる) |

B の❹は、プレイヤーのマスモン(セーブ)に触るので、おすすめしない。B の❺は、神殿の強さとランキングに関わるのでバトル部の確かめが要る。

## 3. つなぐ部と、どこをつなぐか

| 部 | つなぐ所 | 読むだけ/書く |
| --- | --- | --- |
| ビート部(マモリ) | セッションLv・好みの曲(`33-rhythm-assistant-session.jsx` の `rhythmAssistSessionLevel` ほか)を読んで腕前の元にする。セッションの結果の助手のひとことに「腕前・得意」を足す口。練習スタジオにいた回数は助手ライフ側で数える | ビート部の値は読むだけ。腕前の表示はビート部の画面に口を1つもらう |
| カード部(ソランド) | 助手の CPU デッキ(`82-card-battle-core.jsx` の `CARD_AI_DECKS`)に、助手ごと2〜3の「型」(攻め・守り・ふつう)を持ってもらい、助手ライフがどの型かを渡す口 `assistantLifeCardStyle(id)`。デッキ名(`cardAssistantDeckName`)にも反映。強さの段・カード部屋のごほうび 1.5倍は変えない | 型の中身はカード部が作る。助手ライフは型の名前を渡すだけ |
