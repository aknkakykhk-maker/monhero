  1. HOME に「🏡 助手ライフ」ができました。助手たちが住む家で、8人それぞれの部屋があります。
  2. 部屋にいる助手は顔が見え、出かけている助手の部屋には、行き先と、一緒にいる全員の名前の札が下がります。助手は2人だけでなく、3人・4人で一緒に遊んでいることもあります。部屋を押すと、その助手のいまの様子・仲良し度・友情Lv・今日あったことが見られ、その場で見守る・声をかける・渡すができます。
  3. 見守ったおしゃべりは、その場所の景色と、そこにいる全員の立ち絵で流れます。家を出ずに、続けて遊べます。
  4. 「📋 みんなの居場所」では、町の地図と一覧で、だれがどこにいるかをまとめて見られます。
  5. HOME では、モンヒロビートや MFバトルカードなど、助手が遊んでいる所の下に、小さな顔が出ます。家や町にいる助手は「🏡 助手ライフ」の下です。顔を押すと、その助手の部屋が開きます。
  6. 朝・昼・夕方・夜で、空や窓の外の景色、部屋の灯りが変わります。助手ライフの中では「風がそよぐ場所」が流れます。
  7. 助手それぞれに生活のリズムがあります。夜は家に帰る助手が増え、寝ている部屋には「💤」が出ます。夜ふかしの助手は、深夜もモンヒロビートで練習していたり、部屋で起きていたりします。夜によく誘って遊ぶと、その助手は少しずつ夜型になります(しばらく誘わなければ元に戻ります)。
  8. 言い合いのあとの2人は、部屋に「💢」の印が出ます。声をかけたり引き合わせたりすると、仲直りのきっかけになります。
