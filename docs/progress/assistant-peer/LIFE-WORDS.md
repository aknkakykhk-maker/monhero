### 気分(6)・ひとりの理由(3)・時間(6)— 台本の鍵

- 気分: happy ごきげん / lonely さみしい / restless そわそわ / sulky すねてる / sleepy ねむい / eager やる気
- ひとりの理由: lonely(だれかといたかったのに、だれも来なかった。誘うと喜ぶ)/ mypace(ひとりが好きな時間・自分のペース)/ distance(言い合いのあと距離をおいている)
- 時間: 深夜 0〜5 / 朝 5〜10 / 昼 10〜14 / 午後 14〜18 / 夕方 18〜21 / 夜 21〜24(日本時間)
- 場所の型(ひとりごと): 家 / 好きな場所(下の表。コトバの気持ちの紙の案に合わせた 2026-11-07) / それ以外
