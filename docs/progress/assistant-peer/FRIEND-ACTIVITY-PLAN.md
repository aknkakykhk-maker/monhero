# フレンドの「最近」が見える種類を増やす(案・オトズレ3・2026-11-08)

社長「フレンドで相手の行動見えるバリエーションも増やして」。止め絵(試し画面): `friend/activity-plan.jpg`(左=縦・右=横)。

## 1 見せるもの(何をどこまで)

| 種類 | 例 | 出どころ | 数字・個人の情報 |
| --- | --- | --- | --- |
| 助手の今日 | 朝: みゅあ・ききが居間でおやつ/ドラ・ソラシドが仲直り/ききが寝言 | 今日あったこと(いまも くわしい控えに8つ) | よその人の名前が入る行(行き来)は今までどおり除く |
| 助手が贈られた | みゅあに「くまのぬいぐるみ」を贈った | 今日あったこと(kind=give) | 道具の名前だけ |
| モンヒロビート | 「風がそよぐ」を遊んだ | 遊び終わったとき | 曲名だけ。スコア・ランク・難易度は出さない |
| MFバトルカード | 対戦で勝った | 勝ったとき | 勝ったことだけ。相手の名前・戦績の数は出さない |
| マスモン | 新しいマスモン「ゴーレム」を迎えた | 迎えたとき | 種類の名前だけ。ニックネーム・Lv は出さない |
| お部屋 | ドラの部屋に「くまのぬいぐるみ」を置いた | 置いたとき | 家具の名前だけ |
| 入れない | ランキングの順位・持ち物やお金の数・自由文・おしゃべりの中身・ログインの時刻 | — | — |

## 2 見せ方

- **一覧の札**: 名前の下に「最近」の1行。開くたびに新しい順から1つずつ入れ替わる
- **訪ねた家の居間の掲示板**:「◯◯さんの家の最近」(助手の今日と、遊びの最近を混ぜて新しい順)。種類ごとに色の札
- **訪ねたときの助手の話題**: 台本の「最近の話題」の型(「◯◯さん、さっき『風がそよぐ』遊んでたぞ」)に、最近の1つを差しこむ。AI(friend_scenes)には今日は渡さない(呼び出しを増やさないため。台本で足りなければ次の段で)
- **置き手紙への返事**: いまの「お礼の一言」の後ろに、相手の家の助手のひとことは足さない(今回は見送り。台本が要るため)

## 3 見せたくないとき(設定)

- 「最近の遊びをフレンドに見せる」(見せる側)を足す。切にすると、曲・対戦・マスモン・家具の行は出ない(助手の様子は「家の様子をフレンドに見せる」に従う)
- 既定: A(推奨) 入 / B 切(気づいた人だけ入にする)

## 4 データ・無料枠

- くわしい控え(house_more)に `ac = [{ k: 種類, x: 40字まで, at }]` を6つまで足す。いま約2KB → 約2.5KB(上限 6,000字の内)。**SQL なし**
- 端末の記録は新しいキー `mh_assistant_life_friend_activity_v1`(最近の6つだけ)。遊び終わり・勝ったとき・迎えたとき・置いたときに1行足す
- 一覧の札の1行は、今の控え(houses)に「最近の1つ」だけ足す(約60字)。houses の上限 2,000字の内
- 読む量: 一覧は今と同じ(変わった家だけ)。くわしい控えは訪ねたときだけ。月の転送は前の見積もり(約0.7%)から少し増える程度

## 5 決めてほしいこと

- 「最近の遊び」の既定: A(推奨) 入 / B 切
- モンヒロビートの曲名: C(推奨) 出す / D 「モンヒロビートを遊んだ」だけ(曲名を出さない)
