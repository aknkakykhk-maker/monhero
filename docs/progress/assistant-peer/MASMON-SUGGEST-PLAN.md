# 助手のマスモン・デッキに「提案する」(案・キズナ4・2026-11-08)

社長「助手のマスモンの名前とか染色とかをこっちからアイディア出して誘導できるようもしたい。マスモン自体の変更も誘導できるようにしたい。デッキとかも。色々できるようにしたい」
→ プレイヤーが助手に「こうしてみたら?」と提案し、助手が性格・仲良し度・好き嫌いで「受ける/少し変える/断る」。作るのは社長の答えのあと。
止め絵: `masmon-life/suggest/mock.png`(左=くわしい画面の「💡 提案する」・色のタブ/右=返事3通りと色の記録)

## Q1 提案できるもの(おすすめ: A)
- A(推奨): 段階で出す。①色(部位ごと)と名前 → ②次に迎えるマスモンの希望・勇者モン → ③デッキ(主役・名前・方針)。①を先に出し、②③は様子を見て足す
- B: 5つ(名前・色・迎える・勇者モン・デッキ)を一度に出す
- C: 色と名前だけ
中身: 名前/色(部位ごと・顔まわりは染めない所として選べない)/迎える(次の「？」の枠にこの種類を、と希望。迎えるときの材料に強く足す。苦手とその血統は断る)/入れ替え(迎えたマスモンを外すのは、思い出が消えるのでやらない案。代わりに勇者モンの交代だけ)/勇者モン(迎えたマスモンから選ぶ)/デッキ(推し・好き・素顔のうち1つの「主役」「名前」「方針(攻め・守り・ふつう)」。中身はカード部の組み方のまま、方針だけ渡す)

## Q2 提案のしかた(おすすめ: A)
- A(推奨): 選ぶ式が基本+名前だけ自由に書ける。名前は今の決まり(2〜8字のかな・漢字・言ってはいけない語)を通す。返事は用意した台詞(助手ごと×受ける・少し変える・断る)
- B: Aに加えて、返事を AI に助手の口調で作らせる(1日の上限の中・失敗したら用意した台詞)
- C: 全部自由に書く(AI が読み取って決める)。見張りが重く、思った通りにならないこともある

## Q3 助手の受け方(おすすめ: A)
- A(推奨): 好き嫌いと仲良し度で決める。好きな色・好きなモンスター → 受ける/どちらでもない → 仲良し度 Lv5 以上は受ける・それ未満は「少し変える」(例: 一部の部位だけ)/苦手 → 断る(仲良し度 Lv10 以上なら「今回だけな」と受けることも)。提案は1人1日3回、断られた分は数えない。どの変更も「前に戻してもらう」ができる
- B: 確率で受ける(仲良し度が高いほど受けやすい)。同じ提案でも日によって返事が変わる
- C: いつも受ける(助手らしさが薄い)

## Q4 保存(案は1つ・CLAUDE.md ⑦)
- `mh_assistant_life_masmon_v1` に新しい項目 `asked`(提案の記録: 日付・何を・返事)と `mine`(プレイヤーの提案で決まった名前・色・勇者モン)を足すだけ。draw・pick・dyes は消さない
- 色はいまの「染め直しの記録」(dyes)に why:'ask' として足す。だから「前の色に戻す」は記録から選ぶだけ
- プレイヤーが変えた部位・名前は、そのあとの季節の染め直し・名前の付け直しでは上書きしない(季節の色は、提案で変えていない部位にだけ差す)
- デッキはカード部の保存(mh_card_ai_recipe_v2)へ、カード部の口から渡す(こちらは「何を提案したか」だけ持つ)

## Q5 どこから(おすすめ: A)
- A(推奨): マスモンのくわしい画面の下に「💡 ◯◯に提案する」(名前・色)/編成タブの勇者モンの札に「勇者モンを変えてみたら?」/まだの「？」の枠に「この種類を迎えてみたら?」/デッキのタブに「デッキに提案する」。それぞれの場所で、そのことだけ
- B: 助手の部屋のシートに「💡 提案する」を1つ置き、中でタブを切りかえる(止め絵の左の形)
- C: おしゃべり(AI)の中で言うと、助手が受け取って変える(自由だが、思った通りにならないことがある)
