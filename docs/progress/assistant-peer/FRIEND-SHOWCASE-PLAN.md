# フレンドのプロフィールで、マスモンとデッキをもっと見られるようにする(案)

2026-11-11 オトズレ。社長「フレンドの部屋に行ったときにマスモンとかデッキとか見れないんだっけ？詳細的な」→「自分のと同じぐらい見れるようにして」。

止め絵: `friend/showcase-tate.jpg`(① プロフィールに2行 ② マスモンの一覧 → 詳細 ③ デッキの一覧と中身)/差の表: `friend/showcase-diff.jpg`

## 1. いまの差(要点)

| 項目 | 自分 | フレンド(いま) | 案 |
| --- | --- | --- | --- |
| 手持ちのマスモンの一覧 | 全部 | 数だけ | 一覧を足す |
| マスモン1体ずつの詳細 | 全部 | 好きな1体だけ | どの子もランキングと同じ詳細(`rankingMonsterDetail`) |
| バトルカードのデッキ | 組んだ全部(20組まで) | 登録した1組の札だけ | 組んだ全部の中身 |
| バトル記録の難易度ごと・公式杯 | ○ | モードごとの最高だけ / × | 今回は入れない(次の候補) |
| ダイヤ・ブリーダーP・回想・履歴 | ○ | × | 出さない |

## 2. 何を送るか・大きさ

- **マスモンの一覧**: 1体あたり 顔(種類)・名前・絆Lv・総合力・染め色・超越/転生の印。約90字。**総合力の高い順に200体まで** → 最大約18KB
- **マスモンの詳細**: `rankingMasuDetail` と同じ形(ランキングと同じ詳細画面で開くため)。1体 約0.5〜1.5KB
- **デッキ**: 名前・3体・カード(同じカードは id×枚数にまとめる)・いま使っている印。1組 約0.2〜0.8KB、20組で最大約16KB

いまの `friend_profiles.records`(12000字まで・2分ごとに送る)には入らないので、**新しい表を足す**(足すだけの SQL。既存の表・列は変えない)。

## 3. 案

### 案A(推奨): 1体1行の表 + デッキ1人1行の表。変わったぶんだけ送る

- 表 `friend_showcase_masu`(ブリーダー × マスモンの個体id で1行: 一覧用の小さな JSON・詳細の JSON・更新時刻)
- 表 `friend_showcase_decks`(1人1行: デッキの JSON・更新時刻)
- 送り方: 端末が「前に送った中身の指紋」を新しい保存キー `mh_friend_showcase_sent_v1` に持ち、**変わった子・変わったデッキだけ**送る。
  手放した子の行は消す(自分の写しだけ)。間隔は **起動の1分後と、変わってから最短10分**(プロフィールの2分ごととは別。見えていないあいだは送らない)
- 見る側: 一覧は小さい列だけ読む。1体を押したときに、その1行の詳細だけ読む → 開くのが軽い
- 通信: 初回だけ全員分(200体なら約100〜200KB)、あとは育てた子だけ数KB

### 案B: 1人1行に全部(一覧+詳細)

- 作りは簡単。ただし詳細込みで1回 50〜200KB を、変わるたびに丸ごと送る。見る側も開くたびに全部読む。体数の上限を60体くらいに下げる必要がある

### 案C: 一覧だけ(詳細は好きな1体のまま)+デッキ

- いちばん軽い。社長の「詳細的な」に届かない

## 4. 見せたくない人の切り替え

- 設定(フレンドの画面の「見せる設定」の並び)に「🐾 マスモンを見せる」「🃏 デッキを見せる」を足す(新しい保存キー `mh_friend_show_masu_v1`・`mh_friend_show_decks_v1`)
- 切ったら送らず、表の自分の行を消す。見る側には「この人は見せていません」
- 既定は **入**(推奨。「最近」と同じ。入でないとほとんど誰のも見えない)/ 切 のどちらにするか

## 5. 古い版・壊れない作り

- 表がまだ無い・古い版の相手 → 「この人はまだ見せていません(相手がゲームを開き直すと出ます)」。フレンド本体は止めない(`softMissing` と同じ扱い)
- 受け取った JSON は型を確かめ、知らないモンスター・カードは捨てる。名前は文字として出す
- 既存の保存キー・`friend_profiles` には触らない。「戦う」「借りる」は今までどおり登録した1組だけ

## 6. 決めてほしいこと

1. 送り方: **A 変わったぶんだけ(推奨)** / B 1人1行に全部 / C 一覧だけ
2. 見せる設定の既定: **入(推奨)** / 切
3. マスモンの体数の上限: **総合力の高い順に200体(推奨)** / 100体 / 全部
4. デッキ: **組んだ全部(推奨)** / ★使用中と登録したデッキだけ
