# Monster Hero 助手マスモン育成＆完全オートバトル
## 第1弾仕様書 Ver.1.0

対象：助手ライフ／助手マスモン。企画・基本設計段階。リポジトリ：`aknkakykhk-maker/monhero`。

## 1. 目的・基本方針
助手が独立したブリーダーとして自分のマスモンを育成し、修行・休養・模擬戦・編成見直しを自主的に行う。プレイヤーは相談・助言・観戦で関与する。育成・生活・交流・完全オートバトルを連動させる。

- **寿命なし**：老化・死亡・強制引退なし。長期育成可能。
- **6能力**：ライフ、ちから、かしこさ、命中、回避、丈夫さ。
- 助手1人につき当面3体を所有し、3体編成・先頭1体・個別ニックネームを設定。
- 助手マスモンとMFバトルカードのデッキは別管理。
- プレイヤー用マスモン・セーブ・ランキング・報酬には勝手に影響させない。

## 2. 6能力と戦闘
| 能力 | 役割 |
|---|---|
| ライフ | 最大HP |
| ちから | ちから技の威力 |
| かしこさ | かしこさ技の威力 |
| 命中 | 攻撃の当てやすさ |
| 回避 | 攻撃を避ける能力 |
| 丈夫さ | 被ダメージ軽減 |

各能力上限999は**仮案**。ガッツは戦闘中の独立ゲージ。技には威力・命中補正・ガッツ消費・使用距離・特殊効果・習得条件・熟練度を持たせる。既存技データの再利用を優先する。

## 3. 個体差・成長適性
6能力ごとの血統基本適性＋個体補正＋育成方針＋助手指導能力で成長を決定。早熟・普通・晩成タイプを検討するが、寿命がないため晩成だけが最終的に有利にならないよう調整。同血統でも異なる能力・戦術に育つ。

## 4. トレーニング
| 育成能力 | 軽トレ | 重トレ |
|---|---|---|
| ライフ | 走り込み | 長距離走 |
| ちから | 腕立て | 重量上げ |
| かしこさ | 勉強 | 高度研究 |
| 命中 | 的当て | 高速射撃 |
| 回避 | ステップ | 障害物回避 |
| 丈夫さ | 受け身 | 耐久特訓 |

特殊訓練4種：実戦訓練（複数能力・経験）、合同訓練（助手同士）、集中訓練（特定能力）、弱点克服（苦手能力）。計16種類。

**成長量の仮案**：軽トレ主能力+3〜6・疲労+5、重トレ主能力+7〜12・副能力+1〜3・疲労+14、特殊訓練主能力+4〜9・副能力+2〜5・疲労+10〜18、休養疲労-30。正式数値は後日調整。

## 5. 疲労・ストレス・休養
訓練・修行で疲労、無理な育成・失敗でストレスが増える。休養・遊び・交流で回復。高疲労は育成効率低下、高ストレスは失敗率上昇。助手AIが状態を見て休養を選択。放置による永久的な能力低下や取り返しのつかない育成失敗は原則なし。

## 6. 修行・技熟練
ちから修行、かしこさ修行、命中修行、回避修行、防御修行、実戦修行の6系統。技の習得・熟練・距離判断・交代判断などを育成する。熟練度による命中・ガッツ効率等の小補正は上限付きで検討。未実装技を無断で追加しない。

## 7. 助手のブリーダー能力
育成知識、指導力、観察力、戦術力、信頼構築、育成経験を助手ごとに管理。性格に応じた初期傾向を持たせ、経験によって苦手分野も成長。仮の傾向：みゅあ積極型、きき分析型、ももすけ安定型、ドラ大胆型、あつバランス型、きゅうこ研究型、ソラシド柔軟型、えるびん防御型。

## 8. 自主育成とプレイヤーの関与
助手は6能力、適性、疲労、ストレス、技、試合結果、性格、助言から訓練・修行・休養・遊び・合同訓練・模擬戦・編成見直しを選ぶ。生活リズムと連動し、ログイン時などに経過時間分をまとめて確定する方式を基本案とする。放置が最適解にならないよう1日あたりの成長上限を設定。

プレイヤーには「命中を鍛える／ちからを伸ばす／バランス型／助手に任せる」等の相談を出す。優先能力・修行先・編成・戦術の直接指定範囲は**未確定**。自主育成＋必要に応じた指導を推奨。

## 9. 完全オートバトル
3対3・1体ずつ出場・3体全滅で敗北。零／近／中／遠の距離、技、ガッツ、移動、防御、交代を助手AIが全自動判断。AIは期待ダメージ、命中率、ガッツ消費、残ライフ、反撃リスク、距離、交代価値を比較し、助手の性格・戦術経験を反映する。初心者AIにも最低限の判断能力を保証。

助手同士の自主模擬戦とプレイヤー指定対戦の併用を推奨。試合後に戦術経験、育成方針の見直し、ライバル会話、「今日あったこと」への記録が発生する。

## 10. 将来の非同期PvP
他プレイヤーの助手＋マスモン3体と非同期対戦。登録編成・対戦履歴・リプレイ・リーグ・大会・ランキングを検討。「育成値そのまま」と「能力補正で公平化」の2区分を候補とする。サーバー側で対戦データを検証し、自己申告の勝敗を信用しない。報酬・正式ルールは未確定。

## 11. 助手ライフとの連携
部屋＝育成記録、中庭＝遊び、育成場＝トレーニング、神殿＝修行・再生関連、友情＝合同訓練、ライバル関係＝模擬戦、仲良し度＝相談、掲示板＝育成・対戦日誌、生活リズム＝自主育成時間。染色や好き嫌いは既存構想を継承。好き嫌いは会話・マスモン選択に反映し、直接の戦闘能力補正にはしない。

## 12. 長期やり込み
能力上限後も技熟練、戦術研究、編成研究、戦績・大会実績、染色、助手との特別イベントで楽しめる。能力値の無制限インフレは避ける。

## 13. 保存・互換性
既存`mh_*`キーを改名・削除しない。助手専用データに6能力、適性、コンディション、技熟練、戦績等を後方互換で追加。旧データがあれば安全に正規化・一度きりの移行を行い二重適用を防ぐ。プレイヤー側のマスモン、セーブ、ランキングを保護する。

## 14. 開発段階
1. **育成基盤**：6能力・個体差・訓練・疲労ストレス・自主育成・記録。
2. **修行と助手成長**：技習得・熟練・ブリーダー能力・相談・日常イベント。
3. **助手同士のバトル**：3対3オート・距離・ガッツ・交代・模擬戦・リプレイ。
4. **非同期PvP**：編成登録・サーバー検証・リーグ・大会。
