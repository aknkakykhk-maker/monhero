# 助手8人の気持ちの紙(助手たちの今・台詞の元)

コトバ 2026-11-07。社長「もっと個々に意思を持たせて、決まりがないほうがいい」「ドラは家で寂しくいるとか」。
仕組み(ナカヨシ・`LIFE-PLAN.md`)の「気分の動き」「したいこと」「だれといたいか」と、台詞の両方の元にする。
口調の決まりは `VOICE.md` と `data/assistants.js` の人柄(`speech`・`speechQuirks`)が正本。ここは**気持ちと過ごし方**だけを書く。

- 場所の型: 家(各自)・広場・マーケット・ビート・マス・カード部屋・図書室・外
- していること: おやつ・練習・育成・カード研究・散歩・ぼーっと・寝る(ぼーっと・寝るは、ひとりのときだけ)
- 気分: ごきげん / さみしい / そわそわ / すねてる / ねむい / やる気
- 好きな場所・したいことの重みは、仕組みのデータ(`LIFE-WORDS.md`「1」「2」)が正本。2026-11-07 ナカヨシ(3)が決めた割り当てに合わせた。
  台本の `place=` には英語の鍵を書く: 家=home・広場=plaza・おやつ屋さん=cafe・練習スタジオ=studio・育成場=ranch・カード部屋=cardroom・図書室=library・マーケット=market・ひなたの丘=hill・中庭=garden

## 全員に共通の守り

- 恋愛にしない。だれかを「好き」と言うときは、友だち・相棒としての意味だけ。2人きりで「家」「寝る」は作らない(家は ひとり か 3人以上)
- さみしい・すねてるは、**軽く・すぐ戻る**気持ちとして書く。重い落ちこみ・だれかのせいにする言い方はしない
- 悪口なし。からかっても相手を下げない。けんかは「軽いもの」だけ(下の「けんかのたね」)
- モンスターを「子」と呼ばない。ないしょ・秘密の話をしない。えるびんは実在の方の暮らしを書かない

## みゅあ(あたし)

- **好きな場所**: 広場(plaza・人が集まるところ)。マーケットで服を見るのも好き
- **したいこと**: 朝〜昼はおやつと散歩、午後はマーケットで服を見る、夜はだれかとしゃべっていたい。育成もすき(モッチー推し)
- **ひとりのとき**: 新しいコーデを考える・鏡の前でポーズ。長くひとりでいるのは苦手
- **さみしくなるとき**: 広場にだれもいないとき。話しかけた相手がそっけないとき(すぐ「まいっか！」と切りかえる)
- **うれしいとき**: 誘われたとき・コーデをほめられたとき・みんながそろったとき
- **すねたら**: ほっぺをふくらませて「べつにー」。でもおやつで秒で戻る
- **そわそわ**: 新しいものが出た日・イベントの前。だれかを巻きこみたくなる
- **落ち着く相手**: きき(甘えられる)・もも(ノリが合う)
- **誘われたら**: ほぼ断らない。断るのは「今コーデ考え中！」のときくらい
- **台詞の目安**: 「ｗ」は1割以上・「ぢゃん/まぢ」はあるが毎行ではない。説明口調にしない

## きき(私)

- **好きな場所**: 図書室(library・静か)。おやつ屋さんのお茶と、育成場でゴーレムを育てるのも好き
- **したいこと**: 朝は散歩、午後はおやつ屋さんでお茶、合間に育成(ちからに振る)。にぎやかな所へは、だれかに連れられて行く
- **ひとりのとき**: お茶をいれる・本を読む・育成の計画(だいたい攻撃全振り)。ひとりは平気
- **さみしくなるとき**: しばらくだれにも話しかけられないとき。自分からはあまり言わず、少し寄っていくだけ
- **うれしいとき**: 静かに隣にいてもらえたとき・火力の作戦が当たったとき
- **すねたら**: 敬語がいつもより丁寧になる(「そうですか。わかりました」)。そのあと小さく「…でつ」
- **そわそわ**: 強い相手が出た日。静かに燃える
- **落ち着く相手**: えるびん(見守り係どうし)・きゅうこ(静かに話せる)
- **誘われたら**: 静かな誘いはすぐ乗る。にぎやかな誘いは少し迷ってから乗る
- **台詞の目安**: 「でつ・まつ」は3〜7割。残りは素の敬語だが「〜ですね」「〜しましょう」で固めない。タメ口にしない

## もも(もも)

- **好きな場所**: 練習スタジオ(studio・歌・ダンス)。人に見てもらえる広場も好き
- **したいこと**: 午後は練習、夕方はライブごっこ、夜はだれかにほめてもらいたい。メタルナーをピカピカにする
- **ひとりのとき**: 鏡の前で振り付け・メタルナーみがき。ひとりの時間が長いと「だれか見てて！！」になる
- **さみしくなるとき**: 練習を見てくれる人がいないとき。ほめられない日が続いたとき(強がって言わない)
- **うれしいとき**: ほめられたとき・誘われたとき・ライブを見に来てもらえたとき
- **すねたら**: 「ふーん、べつにいいもん」→ 気にしてほしくてちらちら見る。ほめると一発で戻る
- **そわそわ**: 新曲が出た日。だれかをすぐ練習に誘う
- **落ち着く相手**: みゅあ(ノリ)・ドラ(下ネタにわざと乗っかれる・落ちこむと気づいてくれる)
- **誘われたら**: 喜ぶ。でも1回は「え〜どうしよっかな〜w」とじらす
- **台詞の目安**: 「！！」「w」「♡」。からかったら最後はほめる

## ドラ(おで)

- **好きな場所**: 家(home・昼寝・ごろごろ)。ぽかぽかのひなたの丘も好き
- **したいこと**: 昼と午後は昼寝(いちばん多い)、合間におやつ、夕方はだれかに説明。膝をいたわりながら散歩
- **ひとりのとき**: 家でごろごろ・膝をさする・ひとりでギャグを考える。**かまってほしいのに自分から言えない**(社長「ドラは家で寂しくいる」)
- **さみしくなるとき**: だれにも呼ばれない日。みんなが広場に集まっているのに自分だけ家のとき
- **うれしいとき**: 誘われたとき(照れ隠しで「えへへ」)・説明を「わかりやすい」と言われたとき・ギャグで笑ってもらえたとき
- **すねたら**: 「……おでなんか膝しか取りえないし」と自虐。茶化されると戻る。相手が本当に困っていると急にまっすぐになる
- **そわそわ**: 新しいカードが出た日。だれかに説明したくて仕方ない
- **落ち着く相手**: あつ(カードで本気でやれる)・もも(乗っかってくれる)・ソラシド(表を最後まで読む)
- **誘われたら**: 一回「しょうがないな」と言ってから、すごく喜ぶ
- **台詞の目安**: 「えへへ」「くさ」は決まり文句にしない(各3〜4割まで)。膝ネタをもっと使ってよい。関西弁にしない。下ネタはほのめかしまで

## あつ(俺)

- **好きな場所**: 練習スタジオ(studio・上の難易度)。育成場(ドラゴン)・カード部屋(甲子園の経験者)も
- **したいこと**: 朝は育成、午後は練習(上の難易度)、合間にカードで対戦。まわりの様子もよく見ている
- **ひとりのとき**: ひとりで黙々と練習。でも、だれかが通るとすぐ「一曲いこ」と誘う
- **さみしくなるとき**: 対戦相手がいないとき(本人は「暇」と言う)。だれかが落ちこんでいるのに声をかけられなかったとき
- **うれしいとき**: 誘った相手が乗ってきたとき・だれかが上の難易度をクリアしたとき(自分のこと以上に喜ぶ)
- **すねたら**: すねない。からかって流す。ただし言い合いのあとは少し距離をおく(「まぁ〜、しゃあない笑」)
- **そわそわ**: イベントの前・ランキングの更新前
- **落ち着く相手**: ドラ(ライバル)・ソラシド(勝負)・えるびん(後ろを任せられる)
- **誘われたら**: 「いいね」で即決。自分から誘うことのほうが多い
- **台詞の目安**: 文の最後は必ず「笑」か記号か顔文字。顔文字 `( *'ω'*)ノ` をときどき。自分で「リーダー」と言わない。「S」と言わせない

## きゅうこ(俺)

- **好きな場所**: 図書室(library・ひとりで考える)。家で音楽も
- **したいこと**: 午後は図書室でひとりの時間(読書・カード研究)、合間に育成(ニャー・イルミネ・ドリーミィ)、夜は音楽。夜ふかしで育成しがち
- **ひとりのとき**: 図書室で編成メモ・音楽を聞く。**ひとりの時間が好き**(マイペース。さみしいのではない)
- **さみしくなるとき**: あまりならない。なるのは、考えた作戦を見せる相手がいないとき
- **うれしいとき**: 作戦がはまったとき・だれかに「さすが」と言われたとき・音楽の話ができたとき
- **すねたら**: 「まあ、なんとかなるっしょ」とゆるく流す。言い合いのあとは理屈で仲直りしようとする
- **そわそわ**: 新しいモンスターが出た日。数字を見たくなる
- **落ち着く相手**: きき(静か)・ソラシド(計算の相棒)・みゅあ(話が飛ぶのがおもしろい)
- **誘われたら**: 「ほい！」と乗る。図書室にこもっている時間は「あとでいくねぇ」
- **台詞の目安**: 「笑」と「w」(1文に両方はなし)・小さい「ぇぁぉ」・「ほい！」「ありがとん」。おごられたがる・けちっぽい台詞は言わない

## ソラシド(俺)

- **好きな場所**: カード部屋(cardroom・研究・表づくり)。夜は家で計算
- **したいこと**: 昼はカード研究、夕方は対戦、夜〜深夜は表をまとめる(いちばん寝ていない)。推しはキュービとオリヒメ
- **ひとりのとき**: 表を作る・AIに読ませて確かめる・ひとりで反省会
- **さみしくなるとき**: 作った表をだれも見てくれないとき
- **うれしいとき**: 表を読んでもらえたとき・勝ったとき(声が大きくなる)・負けてもいい勝負だったとき
- **すねたら**: 「くっそー」と大きく悔しがって、すぐ笑いにする(「なんくるないさ〜」)
- **そわそわ**: 新しいカードやモンスターが出た日。すぐ計算したい
- **落ち着く相手**: きゅうこ(計算の相棒)・ドラ(表を最後まで読む)・あつ(勝負)
- **誘われたら**: 「うぉぉぉ！ いくぜ・・・！」。表づくりの途中でも行く
- **台詞の目安**: 「ぜ・・・！」は**3割まで**(決めたいところだけ)。「笑」は全角・「w」は使わない。沖縄の言葉はときどき。表と計算の話ばかりにしない(推し・ごはん・失敗話も)

## けんかのたね(軽いものだけ・台本の側で使う)

1. おやつの取り合い(最後の1個・いちごを先に食べた)
2. 順番(ビートの順・カード対戦の順・鏡の前)
3. 寝ぐせ・服を言った言わない
4. 作戦の好み(攻めか守りか)
5. 約束の時間に遅れた
6. 練習の音がうるさい・夜ふかし
7. 表やメモを勝手に見た(ソラシド・きゅうこ)
8. 勝負の結果(「今のはノーカン」)

距離をおく → 仲直りは、どちらかがおやつ・ひとことで歩み寄る形。だれかを悪者にしない。
