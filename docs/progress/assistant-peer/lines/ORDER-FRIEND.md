## 守ること

- 穴: `{name}`(プレイヤー。「ブリーダー」と直に書かない)・`{h}`(その家のフレンドの呼び名。後ろに「さん」を付ける)・`{f}`(相手の助手の呼び方)。穴は1本に1つまで
- 助手・マスモンを「子」と呼ばない。恋愛・悪口・ないしょ話・体に触れる話(膝・抱っこ・くっつく など)なし。よその家なので、けんか・言い合いも起こさない
- 数字・ゲームの中のモードや難易度の名前・「攻略」の話を書かない。えるびんは実在の方の私生活に触れない
- くせは VOICE.md のとおり(みゅあ「ぢゃん・まぢ」/ききは敬語/あつは文末に笑・記号・顔文字/ドラは関西弁にしない、など)。1行60字まで
