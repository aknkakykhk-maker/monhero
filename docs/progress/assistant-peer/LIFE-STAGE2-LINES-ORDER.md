# 助手ライフ 段階2(二歩目)の台詞の注文(2026-11-08 ナカヨシ7)

社長OK(2026-11-08「二歩目の台詞約240本はコトバ・ツムギへ注文してよい」)。届いたら、各種類から数本ずつの抜き出しを窓口(モンヒロくん)へ送り、社長に見せてから入れる。

## 書く形

`lines/SAMPLE.txt` と同じ1行1本の形(頭の説明・守り・表情・60字まで)。口調は VOICE.md、呼び方は docs/rules/CALL_NAMES.md。
新しい鍵・種類だけ下に足す。

- 場所の鍵 `place=` に **temple(神殿)** を足す。遊び場は今の id のまま: studio(モンヒロビート)・cardroom(MFバトルカード)・ranch(M/B管理)・market(マーケット)・temple(神殿)
- していることの鍵 `doing=` に **temple(お参り)・shopping(お買い物)** を足す
- 新しい種類
  - `visit <人> place=studio` … {name} が券なしで会いに来たとき、その助手が言う1〜2行(喜ぶ・照れる・調子に乗る など性格で)
  - `lure <人> to=song/deck/temple/market` … 助手が {name} を遊びへ誘う1〜2行(「この曲いいよ」→ 曲えらびへ/「このデッキ見て」→ カードへ/「神殿行こう」/「マーケットのぞこ」)。押すとその入口へ飛ぶので、言い切りで終える

## 守ること(社長の決まり)

- プレイヤーは {name}。「ブリーダー」と直に呼ばない
- 助手・モンスターを「子」と呼ばない(助手が特定のマスモンを「この子」と言うのだけはよい)
- 「友情Lv」は助手どうし、「仲良し度」はプレイヤーと助手
- えるびんの私生活に触れない
- 音ゲーの呼び方は台詞なら愛称でよい(みゅあ・ドラ「モンビー」/ももすけ「モンビート」/きき「モンヒロビート」)
- みゅあは「ぢゃん」「まぢ」。あつは文の最後に「笑」か顔文字か記号
- 時間帯の言葉(朝の・寝る前・昼寝・夕方)は入れない(どの時間でも出るため)。ほかの場所の名前も入れない
