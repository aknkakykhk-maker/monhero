🔄横: 訪ねた家はモンヒロビートの外の画面なので、🔄横(モンヒロビートの中で回す)にはならない。HOME へ戻ったときの印は今までどおり検査 ⑦ が見る。

## 1 見られるもの(何を見せて何を見せないか)

| 見せる | 中身 | 控えに足すもの |
| --- | --- | --- |
| 家の絵 | 自分の助手ライフの家と同じ絵(屋根・8部屋・居間・時間帯の空)。名札は「🏡 ◯◯さんの家」 | なし(今の控えで描ける) |
| 助手の様子 | 部屋にいる(何をしているか)・🚶 おでかけ中・💤 おやすみ中を部屋の絵で | なし |
| 部屋の家具 | 天井・壁・床に置いた家具 | `r.<助手>.fu = { c, w, f }`(key だけ) |
| 今日あったこと | 居間の掲示板に新しい3つ | `dy = [{ t, x }]`(40字まで) |
| マスモン | 部屋のシートに先頭の1体(キズナ2の口が入ったら) | `r.<助手>.ms = { mo, c }` |

| 見せない | 理由 |
| --- | --- |
| フレンドとの行き来の行(「◯◯さんの家へ」) | よその人の名前が入る。今日あったことからも外す |
| 自由文・おしゃべりの中身・思い出メモ | 個人の言葉 |
| 仲良し度・友情Lv・持ち物・お金などの数 | 数字は出さない(並び順だけなら出せる → 決めごと C) |
| セッション Lv の札 | 自分の家の札なので、よその家では出さない |

## 2 訪ねたときにできること(下の札・横は右の欄)

- 💬 **話す**: 家にいる助手に話しかける → 返事を3つから選ぶ → 答えてくれる(押す前に「返事を押すと、◯◯が答えてくれます」)
- 👀 **部屋を見る**: どの部屋も押せる。おでかけ中は「部屋は見られます」、おやすみ中は「起こさないように、そっと見るだけ」
- ✉️ **置き手紙**: 一言を選ぶと「◯◯さんに届いて、この家から帰ります(ビートP 50)」。下に1行で、何が届くか・今日はもう残したか
  - いまの画面の食い違い(「今日はもう残せません」と「訪ねたことが置き手紙で届きます」)は、この1行にまとめて解消
- (この先・前に出した案) 自由文の一言・留守の助手あての一言は、この部屋のシートに入れる

## 3 控えの大きさと無料枠

- いま 約480字 → 家具・今日あったこと・マスモンまで全部入れても **約1,730字**(上限 2,000字の内)。表の決まりは変えない・SQL なし
- 読む量: 1軒 約2KB。フレンドの家は「変わった家だけ」を30分に1回まで読む今の作りのまま。100人が1日2回、10軒ずつ読んでも 1日 約4MB(無料枠の転送 5GB/月 の 2〜3%)
- 余裕は約270字。これ以上足すなら、別の表に分ける案(決めごと D)

## 4 一覧の札

- 名前と顔に加えて「🏠 家に5人・🚶 おでかけ2人・💤 1人・🪑 家具5・今日 09:11」
- 「来ないようにする」は、その札の「⋯」を押したときだけ出る作り(押した札だけに出る)。社長の画面で1枚目だけに出ていたのは、1枚目の「⋯」を押したため。どの札も同じ決まり

## 5 決めてほしいこと

- A(推奨) この作り直しで公開する / B いまの画面のまま、家具・今日あったことだけ足す
- C(推奨) 仲良し度は出さない / D 助手の並びで「◯◯さんと仲良し」の順だけ出す(数字なし。60-app から読む口が要る)
- E(推奨) 控えは今の表のまま(2,000字の内) / F 控えを別の表に分けて、もっと載せる(SQL・表を足す)
