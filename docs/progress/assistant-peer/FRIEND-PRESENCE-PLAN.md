# フレンドが「いま何をしているか」を増やす(案・オトズレ3・2026-11-08)

社長「モンビーとかバトルカードとかオート周回中も分かるようにしたい。オート周回はそのまま。モンビーとかは長く放置してたらオート周回にかわるとか」「オート周回のはなしはフレンドからみれる画面のはなしね」。
止め絵(試し画面): `friend/presence-plan.jpg`(左=縦・右=横)。

## 1 今ある仕組み(これを使う・新しい表なし)

- 34-friends-api.jsx の「いまの状態」: 開いているあいだ 2分おき(場所が変わったら15秒あけて)に、friend_profiles の自分の1行へ place を上書きする。5分以内なら「● ◯◯中」、それより前は「◯時間前」
- 表の place に入らない細かい場所は、place='other'+records.pl で送る作りが既にある(MFバトルカード・部屋で待ち中)

## 2 足す状態

| 表示 | いつ | 判定の材料 |
| --- | --- | --- |
| ⚡ オート周回中 | オート周回(∞周回)が回っているあいだ(どの画面にいても) | 60-app の quickRunProgressRef(終わっていない)。バトル部ジンの持ち物 |
| ⚡ オート周回中(長く操作なし) | モンヒロビート・MFバトルカードなどを開いたまま、操作が一定時間ない(演奏中・対戦中は変えない) | 最後に画面に触れた時刻(端末の中だけ)。演奏中=RHYTHM_PLAY 系(テンポ)/対戦中=CARD_BATTLE(ソランド) |
| 🎵 モンヒロビートで演奏中 | 演奏の画面 | gameState(今の rhythm を「曲えらび=遊び中」「演奏=演奏中」に分ける) |
| 🃏 MFバトルカードで対戦中 | 今のまま | — |
| 🏡 助手ライフ | 助手ライフの画面 | 助手ライフの器が開いているか |
| 💤 ◯時間前 | 5分以上知らせが無い | 今のまま |

- 長く操作がないときの下の行: 「モンヒロビートを開いたまま 25分 操作なし」(何を開いたままかだけ。曲名などは出さない)
- 見える所: フレンドの一覧・プロフィール・招待の一覧(今と同じ部品)・訪ねた家の見出し(「◯◯さんはいま ⚡ オート周回中」)

## 3 送る量と無料枠

- 新しい表・Realtime は使わない(Realtime の同時200には影響なし)。今の 2分おきの上書きに、records.pl の値(数文字)と「操作なしの分」(数字1つ)を足すだけ
- 送る回数: 状態が変わったときだけ増える(15秒あけて)。オート周回中・長く操作なしは 2分おきの知らせに乗るので、回数はほぼ今のまま
- 転送: 1回あたり数十バイト増える程度。月の転送の増え方は 0.1% 未満の見込み

## 4 見せたくない人

- 設定「いまの状態をフレンドに見せる」を足す。切にすると、place は 'other'(「ログイン中」)だけを送る
- 既定: 今も場所を見せているので、入のまま

## 5 決めてほしいこと

- 長く操作がないとき、何分で「オート周回中」に変えるか: A(推奨) 10分 / B 5分 / C 20分
- 「長く操作なし」を「オート周回中」と同じ表示にするか: D(推奨・社長の言葉どおり) 同じ「⚡ オート周回中」+下の行に「◯◯を開いたまま ◯分 操作なし」 / E 別の表示「💤 開いたまま」
- 作る担当: 判定の材料はジン(オート周回)・テンポ(演奏中)・ソランド(対戦中)の持ち物。読むだけの口を1つずつ出してもらい、組み立てはオトズレ3
