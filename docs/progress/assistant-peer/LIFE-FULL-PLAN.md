## 3. 入場の演出(④)

1. 題「助手ライフ」が光る(0.3秒)。後ろの空の色は今の時間帯
2. 雲が左右に開いて、町を見下ろしながら寄る(0.5秒)
3. 顔が場所へポンと落ち、選んでいる助手がひとこと(`{name}` で呼ぶ。例「おかえり、テストちん！ いま広場で ひめちんとおやつ中〜」)

その日2回目からは 2→3 だけ(0.4秒)。タップで飛ばせる(❸で選んでもらう)。

## 4. 場面(③・⑧)

- 背景はその場所の絵。お話の背景に昼・夕・夜がある広場・森(丘・中庭)・町並み(マーケット・おやつ屋さん)はそれを使う。
  絵の無い所(スタジオ・カード部屋・図書室・育成場)は、町の地図のその建物を大きく切り抜き、少しぼかして時間帯の色を乗せる(あとで絵を差し替えるだけで入る作り)
- 2〜3人の立ち絵が並び、台本の表情で入れかわる。頭の上に気持ちの印(♪・❗・😉)
- 上に場所の名前と、その組の友情Lv の帯(次の Lv までの残り)
- 掛け合いが終わると「🤝 友情Lv +◯ / 💗 仲良し度 +◯ / 🎉 +◯」が花火の演出で出る(今の演出 44-growth-fx をそのまま使う)
- 下に「この場所の思い出 12/40」「この2人のアルバム 8話」と、🧺 渡す / 💬 誘う / 🗺 町へ
- 台詞は今の台本(ASSISTANT_LIFE_TALKS)をそのまま流す。止め絵の台詞も本物(life-pair-kiki-mua-062・life-pair-erubin-sorashido-040)

## 5. 友情(⑤)と、遊ぶほど開く
