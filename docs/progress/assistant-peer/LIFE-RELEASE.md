## 1. 更新履歴(1件・新しい遊びなので助手の告知つき)

- 題: **助手たちが、それぞれ自分で過ごすようになりました**
- type:'content'・group:'assistant'・releaseFlag:'assistantLife'・assistantNotice:{ id:'update_notice_assistant_life_v1', type:'content' }
- 本文:
  1. 助手はそれぞれ、朝・昼・午後・夕方・夜・深夜の時間ごとに、だれと・どこで・何をするかを自分で決めます。いまの様子は HOME の帯と「助手たちの今」で見られます。
  2. 一緒にいる組を「見守る」と、その場に合ったおしゃべりが流れ、2人の友情Lv と、あなたとの仲良し度が上がります。ひとりでいる助手は「ようすを見る」で、ひとりごとや、あなたへのひとことが聞けます。
  3. さみしそうな助手を「誘う」と、次の時間にだれかのところへ行きます。2人を「引き合わせる」と、次の時間に一緒にすごしやすくなります。どちらも無料です。
  4. その日にモンヒロビート・モンヒロバトル・MFバトルカード・おしゃべりで遊ぶほど「にぎわい」がたまります。にぎやかな日ほど助手どうしの動きが増え、友情Lv も上がりやすくなります。
  5. ときどき言い合いをした2人は、しばらく距離をおきます。引き合わせたり、また一緒になったりすると仲直りします。
  6. 助手どうしの仲良し度は「友情Lv」になりました。Lv3 は「友だち」、Lv4 は「いい友だち」です。今日のペアはなくなり、その日の様子で目立つ2人が変わります。
  7. 差し入れ・友情のしるしは「助手たちの今」で、一緒にいる2人に渡せます。渡す前に、友情Lv と仲良し度がどれだけ上がるかが見られます。

## 2. ヘルプ

新しい項目 `assistant-life`(🏡 助手たちの今・releaseFlag:'assistantLife')を、「助手どうしの仲良し度」(peer-bond)の前に足す。

- 助手のひとこと(みゅあ): 「みんな、それぞれ好きにすごしてるんだよ♪ さみしそうな子がいたら、声かけてあげてね！」
  - ※「子」は助手を指すので守り(モンスターを「子」と呼ばない)には当たらないが、気になるなら「さみしそうな助手がいたら」
- 本文:
  - (p) 助手はそれぞれ、6つの時間(朝5時・昼10時・午後14時・夕方18時・夜21時・深夜0時から)ごとに、気分としたいことで、だれと・どこで・何をするかを決めます。同じ時間のあいだは様子は変わりません。
  - (p) HOME の帯を押すか、プロフィールから「助手たちの今」を開くと、組ごと・ひとりごとの様子が見られます。
  - (list) できること
    - 見守る: その組のおしゃべりが流れます。組のペアの友情Lv と、あなたとの仲良し度が上がります。1日に見守れる数は、にぎわいの段で増えます(静か6・ふつう10・にぎやか16・お祭り24)
    - ようすを見る: ひとりでいる助手のひとりごとや、あなたへのひとことが聞けます(同じ時間に1回)
    - 誘う: さみしそうな助手が、次の時間にだれかのところへ行きます
    - 引き合わせる: 選んだ2人が、次の時間に一緒にすごしやすくなります。言い合いのあとなら仲直りのきっかけになります
    - 渡す: 差し入れ・友情のしるしを、一緒にいる2人に渡します(それぞれ1日1回)
  - (kv) にぎわい: 静か(0〜)・ふつう(20〜)・にぎやか(60〜)・お祭り(120〜)。友情Lv の上がり方 ×1/×1.25/×1.5/×2・1組の1日の上限 20/30/45/60
    - たまり方: モンヒロビート1曲・バトル1回 +2、MFバトルカード1戦 +3、おしゃべり +1、見守る・誘う など +2。続けて遊んだ日は少し上乗せ。朝4時に新しくなります
  - (note) 言い合い: 気分がすぐれない2人は、ときどき言い合いをします。そのあとしばらく距離をおきます。また一緒になると仲直りし、友情Lv が上がります
  - (note) 見た おしゃべりは、しばらく出にくくなります。いろいろな組を見守ると、いろいろなおしゃべりに会えます
- 「助手どうしの仲良し度」(peer-bond)の直し(印が真のとき): 「仲良し度」→「友情Lv」、今日のペアの段落と一覧の行を外す、差し入れ・しるしの渡し場所を「助手たちの今」へ。
  ヘルプは印で文を切り替える作りが無いので、公開と同じ PR で書き直す
