## 2. 全部の場所に意味を持たせる案

**どこへ行っても「体力」か「ストレス」か「ほかの遊びの得」のどれかが動く。** 体を使う場所(得が大きい)は体力を減らし、休む場所は体力・ストレスを戻す → 「得の大きい所へ行かせ続けると疲れる。休ませる所へも行かせる」が予定を組む理由になる。
名前は施設の名前を先に(地図・HOME と同じ)。町だけの場所はそのまま。

| 場所(予定表の名前) | 体力 | ストレス | 得(1行) | つながる遊び |

| 🃏 MFバトルカード(カード部屋) | −5 | +3 | 対戦すると ごほうび1.375倍(今のまま) | MFバトルカード |

- 好きな場所の ❤ は「❤ 好きな場所」と字で書き、そこへ行くとストレスが さらに −5

## 3. 助手の状態(体力・ストレス・気分)

- **体力**(0〜100・社長の言葉。減ると悪い)と **ストレス**(0〜100)を1人ずつ持つ。はじめは体力80・ストレス20
- **気分**は今ある6つ(ごきげん・さみしい・そわそわ・すねてる・ねむい・やる気)をそのまま使い、状態から寄せる: 体力40以下 → ねむいになりやすい/ストレス50以上 → すねてるになりやすい/ひなたの丘・おやつ屋さんのあと → ごきげん
- 線はマスモン(育成ノートの「疲れ・ストレス」)とそろえる: **体力40以下で黄・30以下で赤**(= 疲れ60・70)、**ストレス50で黄・60で赤**

| できごと | 起きる条件(その回の終わり) | 起きやすさ(1回・案) | どうなる | 治し方 |
| --- | --- | --- | --- | --- |
| 💤 サボり | 体力40以下 または ストレス50以上 | (40−体力)% + (ストレス−50)%・最大35% | 行くけれど休んでいる。その回の得なし(体力+5・ストレス−5) | なし(次の回はふつう) |
| 🤕 けが | モンヒロバトル・M/B管理・モンヒロビート・広場の回で、体力30以下 | (30−体力)×1.5%・最大30% | 2日 家で休む。予定に入れられない・得なし | 自然に治る/🏥 病院へ1回 |
| 🤒 病気 | ストレス60以上 | (ストレス−60)%・最大30% | 3日 家で休む | 自然に治る/🏥 病院へ2回 |

- **起きるのは、プレイヤーが予定で決めた回だけ。** おまかせの回は助手が自分で休む(体力45以下・ストレス50以上なら家・ひなたの丘・おやつ屋さんへ寄る。性格で少し違う)ので、予定表を使わない人には何も起きない
- 家出は助手には入れない(ビート・カード・修行の得がまとめて消え、強すぎる)。ストレス80以上は「すねて お願いを聞かない」(聞いてくれる割合 −30%)にとどめる
- けが・病気の間も、アシストカード・バトル・ランキングには何も効かない(助手ライフの得が止まるだけ)
- 決まり方は今の生活と同じ回ごとの決まった乱数(開き直しても変わらない)
- **予定表で管理できること**(止め絵②): 予定表の上に、その助手の体力とストレスの棒(黄・赤の線つき)と、今日の予定どおりなら回ごとにどう動くかの見通し。サボり・けがの起きやすさが上がる回は ⚠ と%。「ここを家にすると」1マス変えたときの差も出す
- **見せる場所**: 予定表(棒と見通し)/部屋の上(小さな棒)/家の断面図・地図の名札(黄・赤のときだけ 💤🤕🤒 の印)

## 4. 病院(助手専用の施設)

- 行き先に 🏥 **病院** を1つ足す(地図では町だけの場所と同じ小さな札。HOME には出さない)
- **助手**: けがは その回の終わりに治る。病気は2回で治る(続けなくてよい・同じ日の中)。けが・病気でなくても行ける(体力+15・健康診断の一言)
- **マスモン**: その助手のマスモンも一緒に診てもらえる。けが・病気の残りが1日短くなり、ストレス −10(看病と同じ量)。看病(1日1回)と同じ日に重ねてよい(1日で最大2日分。残りは0日より短くしない)。家出は病院では戻らない(今のまま「さがしに行ってもらう」だけ)。数字・線は育成ノート第4版と同じ(キズナと合意 2026-11-12)
- **費用**: 基本は無料(予定の1マスを使うのが代償。その回はほかの得が取れない)。案B として「すぐ治す(その場で・ビートP 300)」を足すかは社長に聞く
- けが・病気の助手はおまかせでも自分で病院へ行く(2日・3日待たずに半分ほどで治る)

## 5. 保存と今の仕組みとの関係(CLAUDE.md ⑦)

- **新しいキーを1つ足すだけ**: `mh_assistant_life_body_v1 = { v:1, at: 回の通し番号, s: { [助手id]: { hp, st, cond: { k:'hurt'|'sick', until: 回, visits } | null } }, log: [...] }`。読めない・壊れている → 体力80・ストレス20・何も起きていない
- 進め方は マスモンの育成と同じ「前に進めた回から今の回まで、その回の行き先を順に当てる」。開いていない日が7日を超えたら、それより前は「休んでいた」(体力・ストレスを戻すだけ)
- 公開の回より前の回には当てない(さかのぼって疲れさせない)
- 既存のキーは変えない: `mh_assistant_life_v1`(生活)・`mh_assistant_life_plan_v1`(予定。場所に 'clinic' を足すだけ。古い版では捨てられるだけ)・`mh_assistant_life_perks_v1`(#5493 の場所の得)・`mh_assistant_masmon_ranch_v1`(M/B管理のチケット)・`mh_assistant_masmon_grow_v1`(修行)
- **#5493 の場所の得**: そのまま。けが・病気・サボりの回は得の行を出さない(「🤕 けがで休んでいます」)
- **M/B管理のチケット**: そのまま。けがで休んでいる助手の回は使えない
- **修行**: そのまま。サボった回は修行しない(1日3回の数にも入らない)。おまかせの修行の回数(約3割)は下げない — 作るときに30・90日の試算で確かめる
- 行き先の重みを変えるのは「公開した回から」(今日の今までの居場所・日記は変えない)
- マスモン側(けが・病気の保存 `mh_assistant_masmon_cond_v1`)には書かない。病院の効果は口 `assistantLifeHospitalSlotsOf(aid)`(その助手が病院にいた生活の回 abs の配列)で渡す。育成ノートが typeof で有無を見て各回1度だけ効かせ、効かせた回の印は `mh_assistant_masmon_cond_v1` 側に残す(二重にならない。キズナと合意)
