## 更新履歴の文案(社長の「この文で」待ち)

フレンドの家で、助手のマスモンとデッキが見られるようになりました

- フレンドの家で助手の部屋を開くと「🐾 ◯◯のマスモン」が出ます。押すと、その助手が育てているマスモンの Lv と6つの能力が見られます
- 「デッキ」のタブでは、その助手のMFバトルカードのデッキ3つ(推し・好き・素顔)の中身が見られます
- 自分の助手のマスモンを見せたくないときは、「🏘 フレンド」の設定「助手のマスモンのくわしい中身をフレンドに見せる」を切ってください(はじめは見せる設定です)

## ヘルプの文案(フレンドの家の項に1つ足す)

**フレンドの助手のマスモンを見る**
フレンドの家で助手の部屋を開き、「🐾 ◯◯のマスモン」を押すと、その助手が育てているマスモンの一覧(Lv・種類)と、1体ずつの6つの能力、MFバトルカードのデッキ3つが見られます。見るだけで、育て方を変えたり対戦したりはできません。
見せたくないときは「🏘 フレンド」の設定で「助手のマスモンのくわしい中身をフレンドに見せる」を切ります。
