## b) 忠誠度と人気

### 忠誠度(0〜100・はじめ50・1体ずつ)

言うことを聞くかどうか。**強さそのものには効かせない**(対戦の数字を変えない)。

| 上がる | 下がる |
| --- | --- |
| 成功・大成功を褒める +3 / ズル・サボりを叱る +4 | ズル・サボりを褒める −3(甘やかし) / 成功を叱る −5 |
| 失敗を褒める(はげます)+1 | 失敗を叱る −2(ただし次の回の失敗が少し減る) |
| 看病・さがしに行く +5 / 中庭(ストレス−10)+1 | 家出から戻った −10 / けが・病気のまま重い訓練の計画を入れた −2 |
| 1日の終わりに疲れ・ストレスがどちらも50未満 +1 | 何も関わらない日が7日続く −1/日 |

効くもの(計画の回だけ。おまかせの回は今のまま):
- サボりの起きやすさ: 今の式 ×(1.5 − 忠誠度 ÷ 100)。忠誠100で半分・0で1.5倍
- 家出の起きやすさ: 同じ掛け算
- ズルの起きやすさ(下の c)
- 忠誠80以上: 大成功が少し出やすい(+3%)

### 人気(0〜100・はじめ0・1体ずつ)

まわりから見た人気。**強さとランキングには効かせない**(見た目と小さな得だけ)。

| 上がる | 下がる |
| --- | --- |
| フレンド対戦で勝つ +2(負けても +0.5) | 14日、対戦にも修行を見るにも出ない −1/日 |
| 応援される・修行を見られる +1 | (人気は家出や叱るでは下がらない) |
| フレンドが見る画面で見られた(1日1回・人ごと)+1 | |
| 大成功 +1 | |

効くもの: 人気で名前に印(30 ★・60 ★★・90 ★★★)/応援したときの助手の仲良し度 +5 → 人気60以上で +6/冬眠の一覧で並べる順を選べる。

## c) トレーニング・修行の結果と、叱る・褒める

育成ノートの「計画の回」と、自分で決めた回に結果が出る(おまかせの回は結果だけ記録・叱る/褒めるは出ない)。

| 結果 | 起きやすさ(目安) | 中身 |
| --- | --- | --- |
| 🌟 大成功 | 8%(忠誠80以上 11%) | 伸び ×1.5・ストレス −3 |
| ⭕ 成功 | 残り | 今の伸び |
| ❌ 失敗 | 今の失敗の率のまま | 伸び ×0.3(今と同じ) |
| 🤫 ズル | 忠誠50未満で (50−忠誠)÷5 %・最大10% | 訓練したふり。伸び ×0.2・疲れは増えない |
| 💤 サボり | 今の育成ノートの式 × 忠誠の掛け算 | 伸びなし・疲れ −5・ストレス −5(今と同じ) |

- 結果のあと、その回のうちに1回だけ **「📣 叱る」「👏 褒める」**(しなくてもよい)。合う方を選ぶと忠誠度が上がる(b の表)
- **育成方針が変わる**(聞くこと 4): 同じ能力の訓練を褒めた回数が10回たまると、助手が「この子、◯◯の訓練が好きみたい。◯◯型にしてみる?」と提案する(押すと型が変わる・断れる)
- 叱りすぎ: 1日に3回以上叱るとストレス +5(叱りすぎはよくない)
- 今の「サボるときはある・家出もある・けが・病気」(育成ノート第4版の表)はそのまま。忠誠度はその起きやすさの掛け算として足すだけ

## d) 育ち盛り(年齢のかわり・聞くこと 5)

```
育てた日数(その子が来てから育成が動いた日)で伸びの倍率が変わる。合体でできた子は 0 日に戻る
0〜30日 育ち盛り ×1.2 / 31〜90日 ×1.0 / 91〜180日 ×0.85 / 181日〜 落ち着き ×0.7
```

- くわしい画面に「🌱 育ち盛り(あと12日)」のように出す。冬眠中は日数が進まない
- 合体のやりがい: 長く育てた子は伸びが落ちる → 冬眠させて合体し、Lv1・育ち盛りから、前より高い初期値で育て直す
- 能力は下がらない(引退・寿命は入れない案)
