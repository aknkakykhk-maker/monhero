# 助手のマスモンの「冬眠」(案・第1版・社長に聞く前)

キズナ 2026-11-12。社長「モンスターファームにある冬眠と言う機能をつけて、何体までか保存できるようにしたい」「冬眠も一覧で見れて能力とか詳細も確認できるようにね」

- 止め絵: `mock-sleep.png`(元は `mock-sleep.html`・スマホ縦3画面: 一覧に並ぶ冬眠中の子/冬眠中の子のくわしい画面/眠らせる・起こすの確認)
- 取り入れるのは仕組みの考え方だけ(画面・用語・絵は写さない)。画面の言葉は「冬眠」「眠らせる」「起こす」

## 1. いまの形(調べた結果)

- 助手のマスモンは助手ごとの枠(枠1=勇者モン+迎えた枠)。提案の「入れ替え」をすると、前の子は消さずに `mh_assistant_life_masmon_v1` の `mine.former[枠]` に残る(新しい8体まで)。「前の子に戻す」で、いちばん最近の1体だけ戻せる
- 育成(6能力・Lv・疲れ・ストレス)は `mh_assistant_masmon_grow_v1` に「枠:種類」のキーで残る(助手ごとに新しい64体まで)。修行(技・熟練)は `mh_assistant_masmon_train_v1` に同じキーで残る
- つまり前の子は、育てた中身がほぼ残っているが、見えない・選べない・同じ枠に同じ種類が来ると中身が混ざる

## 2. 案

- **眠らせる**: 育成ノートの一覧で、起きている子の「💤 眠らせる」を押す。その子の中身(名前・色・種類・Lv・型・6能力・Lv・疲れ・ストレス・技と熟練・迎えた日)を冬眠の箱へ写す。空いた枠は、助手がすぐ次の子を迎える(今の「入れ替え」と同じ流れ・候補から選べる)
- **眠っている間**: 育たない・疲れ/ストレスも動かない・けが/病気の残りも止まる・対戦(助手どうし・フレンド対戦)に出ない・計画の子から外れる(予定は消さない)
- **起こす**: 冬眠中の子の「☀ 起こす」→ どの枠に戻すかを選ぶ(その枠にいた子は、かわりに冬眠へ入る=入れ替え)。中身は眠らせたときのまま戻る
- **一覧で見る**(社長の追加): 育成ノートの「一覧」の下に「💤 冬眠中(2/3)」を並べ、押すと起きている子と同じくわしい画面(6能力・Lv・型・技と熟練・名前・色)を、💤の印付きで見られる。ボタンは「起こす」だけ
- **保存できる数**: 下の「聞くこと 1」
- **今の「前にいた子」**: 下の「聞くこと 2」

## 3. 保存(CLAUDE.md ⑦)

- 新しいキー `mh_assistant_masmon_sleep_v1` だけを足す: `{ v:1, beds:[{ id, aid, row:{ monster, nick, lv, grow, colors, why, role, welcome, ai }, grow:{ 育成の1体ぶんの写し }, train:{ 修行の1体ぶんの写し }, at, src:'sleep'|'former' }], done:{ formerMoved_v1 } }`
- 起きている子の保存(`mh_assistant_life_masmon_v1`・育成・修行のキー)は形も意味も変えない。眠らせるときは写すだけで、元のキーの行は消さない(起こしたときは、その枠の今の行を上書きせず、写しから新しい行を足す)
- 起こした子は箱から外す(`beds` から1つ抜く)。二重に起こさないよう `id` で確かめる
- 読めない・壊れているときは「冬眠中の子はいない」。数の上限を下げても、すでに眠っている子は消さない(新しく眠らせられないだけ)

## 4. 聞くこと(おすすめが先頭)

1. **保存できる数**: ①(推奨)はじめ3体、育成ノートの段が上がるごとに+1(段5で7体)・全助手で共通 ②はじめ3体、仲良し度で増える(助手ごと) ③ずっと5体
2. **今の「前にいた子」**: ①(推奨)初めて冬眠を開いたときに1度だけ、冬眠の一覧に「前にいた子」として並べる(数に入れない・起こせる・印で二度しない) ②冬眠の数に入れる(上限を超えた分は古い順に今のまま残す) ③今のまま(冬眠とは別・前の子に戻すだけ)
3. **起こす先**: ①(推奨)眠らせた助手の枠にだけ戻せる ②どの助手の枠にも戻せる(その助手の好き嫌いで、苦手な血統の子は受けない)
4. **勇者モン(枠1)**: ①(推奨)眠らせない(助手の顔なので) ②ほかの子と同じく眠らせられる
