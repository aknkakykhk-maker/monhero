# 冬眠中のマスモンどうしの「合体」(案・第1版・社長に聞く前)

キズナ 2026-11-12。社長(窓口経由)「冬眠中の子どうしで合体できる。モンスターファームの合体の考え方を参考に(画面・用語・絵は写さない)。ただし種類は変わらない(親の片方の種類のまま)。ステータスが少し上がる・技を引き継ぐ・Lvは1に戻る。素材になった子はいなくなる」

- 止め絵: `mock-fuse.png`(元は `mock-fuse.html`・スマホ縦3画面: 2体を選ぶ/できあがりの見通し/いなくなるマスモンの最後の確認)
- 冬眠の本体は main に入っている(`56-assistant-life-masmon-sleep.jsx`・印 `assistantMasmonSleep` は偽)。合体はその上に足す

## 1. 流れ

1. 育成ノートの「💤 冬眠中」の下の「🧬 合体する」から開く
2. **主になるマスモン**(種類・名前・色を残す方)と、**素材になるマスモン**(いなくなる方)を、冬眠中の中から1体ずつ選ぶ
3. できあがりの見通し(6能力の いまの値 → 合体後・引き継ぐ技・Lv 1 に戻ること)を見る
4. 最後の確認: 素材のマスモンの絵・名前・Lv・6能力を赤い枠で出し「このマスモンはいなくなります。元に戻せません」と書く。「合体する」を押すと、もう一度だけ「本当に合体する」を押す(2回押す)
5. できあがったマスモンは冬眠中のまま(起こすのは今の「☀ 起こす」)

## 2. 数字の案

| 項目 | 案(おすすめ) | ほかの案 |
| --- | --- | --- |
| 種類・名前・色 | 主のまま | — |
| 6能力 | 能力ごとに **主の値 + 素材の値 × 10%**(1つの能力で最大+50・999まで)。主より下がらない | B: 2体の平均 + 5%(主より下がることがある) |
| 技 | 主の技は全部残す。素材の技は、**主の種類でも覚えられる技だけ**引き継ぐ(技は種類ごとなので) | — |
| 熟練 | 同じ技は高い方の半分から(Lv 1 からのやり直しに合わせる)。主だけの技も半分 | 熟練はそのまま残す |
| Lv・育成Lv | どちらも 1 に戻る(経験も 0) | — |
| 疲れ・ストレス・けがの残り | 0・なし(生まれ直し) | — |
| 育て方の型 | 主のまま | — |

- 何回合体しても6能力は999で止まる。Lv 1 から育て直すので、すぐ対戦で強くなるわけではない(伸びしろを重ねる仕組み)
- 対戦(フレンド対戦)の見張り `DAILY_GROWTH_CAP`(1日40)は、起こした日に跳ね上がって見えることがある → 起こすときの6能力は「眠らせたときの値」で、合体の上がり分は1つの能力で最大+50。masmon-pvp の見張りに引っかからないかはタイセンに確かめてもらう(聞くこと 4)

## 4. 聞くこと(おすすめが先頭)

1. **どのマスモンどうしで合体できるか**: ①(推奨)同じ助手の冬眠中のマスモンどうしだけ ②助手をまたいでもよい(できあがりは主の助手のもの)
2. **6能力の上がり幅**: ①(推奨)主の値 + 素材の値 × 10%(1つの能力で最大+50) ②2体の平均 + 5% ③主の値 + 素材の値 × 20%(最大+100)
3. **回数**: ①(推奨)1日1回 ②何回でも
4. **フレンド対戦との関係**: ①(推奨)合体した直後のマスモンも今のまま対戦に出られる(上がり幅が小さいので、masmon-pvp の見張りはタイセンに確かめるだけ) ②合体したマスモンは、起こしてから7日はフレンド対戦に出さない
