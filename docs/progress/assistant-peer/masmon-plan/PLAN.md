## 2. 案: 「計画して育てる子」(1体から5体)の、朝・昼・夜×7日の予定を組む

- **計画する子**: プレイヤーが助手のマスモン全体から選ぶ(助手をまたいでよい。いつでも外せる・入れ替えられる)。はじめ1体
- **育成ノートの段**(計画の子が予定で育った日の延べ。下がらない): 段1=1体 → 延べ7日で段2=2体 → 21日で段3=3体 → 42日で段4=4体 → 70日で段5=5体。どの段も「いまの数で約1週間」で次へ届く(最大まで約4週間)
- **計画しない子**: 今の自主育成のまま(相談・修行・応援・チケットもそのまま)
- **予定**: 1日を朝(4:00〜)・昼(12:00〜)・夜(18:00〜)の3回に分け、回ごとに「軽い訓練(6能力)/重い訓練(6能力)/修行/休み/遊び/助手にまかせる」から選ぶ。それを月〜日の7日ぶん(21マス)組み、7日でくり返す
- **かんたん設定**: 「毎日同じ」「平日/休日(平日の1日と休日の1日だけ決める)」「先週と同じ」「この日を写す(ほかの日へ・平日ぜんぶへ)」
- **能力と比べながら組む**(止め絵③): 1日の画面に、6能力の今の値と、その日の予定どおりならどれだけ伸びるか(黄の帯・幅で出す)・伸びやすさ・疲れとストレスの見通しを並べる。週の画面には1週間の見通しを出す
- **安全**: 疲れが70をこえた回・ストレスが50以上の回は、予定より休み・遊びを優先(記録に「疲れていたので休みました」)。体をこわさない
- **休みの見張り**: 予定に休みが0日だと、計画の画面に「ストレスがたまり、伸びが落ちます」と出す(組むことはできる)
- **修行の回**: 助手がその回にモンヒロバトルにいれば修行、いなければ方針の能力の軽い訓練(助手の行き先は動かさない。行き先の予定はナカヨシの「1日のスケジュール」側)

### 伸びの釣り合い(フレンド対戦の見張り 40 に収まる)

- 計画の回は今の「指定」と同じ扱い(指定は計画に一本化): 伸び1.3倍・失敗が半分。1日の上限は **20**(見に来た日と同じ。上限そのものは上げない)
- チケットは今のまま上限の外で最大20 → 合計は最大 **40**。`DAILY_GROWTH_CAP` も masmon-pvp も変えない
- 目安(試算の前の見込み): 計画しない子 1日 約12〜15・計画の子 1日 約18〜20(休みの日は0)。週に1日休むと、計画の子は1週間で約+15〜25%。方向を決められるのがいちばんの得で、数字の差は小さめ
- 作るときに `care-sim` と同じ形で30・90・180日の試算を回し、上限999の届き方を確かめてから数字を決める

### 既存のしくみとの関係

| しくみ | 計画の子 | 計画しない子 |
| --- | --- | --- |
| 自主育成 | 予定が「助手にまかせる」の回だけ | そのまま |
| ✋ 訓練を指定(1日3回) | **計画に一本化してなくす**(1マスだけ変えるのが今の指定の代わり) | なくす(手を入れたい子は計画の子にする) |
| 💬 相談 | 「まかせる」の回に効く | そのまま |
| ⚔ 修行・📣 応援 | そのまま(「修行の日」で寄せやすい) | そのまま |
| 🎫 チケット | そのまま(ページの「チケット」から使える) | そのまま |

### 保存(CLAUDE.md ⑦)

- 新しいキー `mh_assistant_masmon_plan_v1` だけを足す: `{ v:1, picks:[{ aid, slot, monster }], week:{ "<aid>:<slot>": [7日×3回] }, days, done:{ 引き継ぎの印 }, log:[...] }`
- **指定の引き継ぎ**: 今の指定は育成のキーの `plan`(次の回の指定)にある。消さず・書き換えず、育成ノートを初めて開いたときに1度だけ読み、まだ来ていない回の指定を計画の子のその回のマスへ写す(`done.pickMoved_v1` の印で二度しない)。指定の画面とボタンは印が真になったら出さない
- 育成のキー `mh_assistant_masmon_grow_v1` の形・意味は変えない。育成の計算(`amgCatchUp`)は、修行と同じ形で `typeof amgpPlanOf === 'function'` のときだけ予定を読む(印が偽なら今と全く同じ)
- 計画の子が手放された・入れ替わった(slot と種族が合わない)ときは、その子の予定を読まないだけ(消さない)
- 迎えた日にさかのぼって計画を当てない(計画は決めた次の回から)
- 育成ノートの段は同じキーの中に `days`(計画で育てた日数・延べ)を持つ。下がらない

## 3. 専用ページ「育成ノート」(仮の名前)

- **入口**: 家の上の「いま行くと得なこと」の並びに「📒 育成ノート」の札/各助手の部屋の「🐾 マスモン」の行からも同じページへ(その助手の子で絞った形)。下のタブ4つは増やさない
- **中身(上のタブ5つ)**
  - 一覧: 計画中の子(段の数まで)と段の道のりを上に大きく、ほかは助手ごとに絞れる一覧(今日の伸び ◯/15・方針)
  - 計画: 「週」(朝・昼・夜×7日のマス・かんたん設定・1週間の見通し)と「1日」(回ごとに選ぶ・6能力と見通しを並べて比べる)
  - 記録: 7日の能力の変化(いくつ → いくつ)と、自主育成・計画・修行・応援・チケットのできごとを1本に。関わって伸びた分も
  - 修行: 今の修行の窓(技と熟練・応援・修行を見る)をここからも開ける
  - チケット: 今の M/B管理の窓をここからも開ける(使える回は今のまま、助手が M/B管理にいる回だけ)
- 今の詳細画面・地図の窓は残す(近道として)。ページは表示と計画だけで、新しい得は「計画」だけ
- **フレンドから見るだけの形**(オトズレの「フレンドの家で助手マスモンを見る」と同じ部品): 部品に相手の中身(一覧・1体の6能力・デッキ)を渡し、`readOnly` で開く。タブは 一覧・記録・デッキ だけ、計画の中身・修行・チケット・応援のボタンは出さない。自分の保存キーを読まない・書かない(止め絵④)
