## 2. 案: 「計画して育てる子」(1体から5体)の、朝・昼・夜×7日の予定を組む

- **計画する子**: プレイヤーが助手のマスモン全体から選ぶ(助手をまたいでよい。いつでも外せる・入れ替えられる)。はじめ1体
- **育成ノートの段**(計画の子が予定で育った日の延べ。下がらない): 段1=1体 → 延べ7日で段2=2体 → 21日で段3=3体 → 42日で段4=4体 → 70日で段5=5体。どの段も「いまの数で約1週間」で次へ届く(最大まで約4週間)
- **計画しない子**: 今の自主育成のまま(相談・修行・応援・チケットもそのまま)
- **予定**: 1日を朝(4:00〜)・昼(12:00〜)・夜(18:00〜)の3回に分け、回ごとに「軽い訓練(6能力)/重い訓練(6能力)/修行/休み/遊び/助手にまかせる」から選ぶ。それを月〜日の7日ぶん(21マス)組み、7日でくり返す
- **かんたん設定**: 「毎日同じ」「平日/休日(平日の1日と休日の1日だけ決める)」「先週と同じ」「この日を写す(ほかの日へ・平日ぜんぶへ)」
- **能力と比べながら組む**(止め絵③): 1日の画面に、6能力の今の値と、その日の予定どおりならどれだけ伸びるか(黄の帯・幅で出す)・伸びやすさ・回ごとの疲れとストレスの見通し(棒・60と70の線)・その回のサボりとけがの起きやすさを並べる。「夜を休みにすると」のように1マス変えたときの差も出す。週の画面には日ごとの終わりの疲れ/ストレス(60で黄・70で赤)と1週間の見通しを出す
- **疲れ・ストレス**: 計画の子は、疲れ・ストレスがたまっても自動で休みにしない(管理はプレイヤーの役目)。くわしくは次の節
- **修行の回**: 助手がその回にモンヒロバトルにいれば修行、いなければ方針の能力の軽い訓練(助手の行き先は動かさない。行き先の予定はナカヨシの「1日のスケジュール」側)

### 疲れ・ストレスの管理(けが・病気・家出・サボり)

2026-11-12 社長「疲れやストレスで怪我したり病気になったり家出したりもする。そうするとしばらく育成出来なかったりする。だから疲れ、ストレスがたまっても勝手に休む優先しないでしっかり管理できるほうがいい。ただし疲れストレスでサボるときはある。計画段階で疲れストレスの変動も見たい。おまかせの場合は助手の判断でおこなう」

- 疲れ・ストレスは今の育成の値(0〜100)をそのまま使う。訓練ごとの増え方も今のまま(軽 疲れ+5・ス+1/重 +14・+4/修行 +12・+2/休み −30・−5/遊び −10・−15)
- 起きるのは **計画の子の、計画の回だけ**。まかせる回と計画しない子は、今の自主育成のとおり助手が休ませる(疲れ45〜70・ストレス50で休み・遊び。助手の性格で違う)ので起きない
- 起きるかどうかは回ごとに決まった乱数(今の育成と同じ作り)。同じ予定なら端末を開き直しても結果は変わらない

| できごと | 起きる条件(その回の終わりの値で) | 起きやすさ(1回あたり・案) | 育成できない間 | 治し方 |
| --- | --- | --- | --- | --- |
| 💤 サボり | 疲れ60以上 または ストレス50以上 | (疲れ−60)% + (ストレス−50)%・最大35% | その回だけ(伸びなし・疲れ−5・ストレス−5) | なし(次の回はふつう) |
| 🤕 けが | 重い訓練・修行の回で、疲れ70以上 | (疲れ−70)×1.5%・最大30% | 2日(6回) | 自然に治る。助手の「看病」(1日1回)で1日早まる |
| 🤒 病気 | 休み以外の回で、ストレス60以上 | (ストレス−60)%・最大30% | 3日(9回) | 自然に治る。看病で1日早まる。病気の間はストレスが毎回−10 |
| 🏃 家出 | ストレス80以上 | 3% + (ストレス−80)×0.5% | 2日(帰ってくるまで) | 助手に「さがしに行ってもらう」(1日1回)でその日のうちに戻る。戻るとストレス−40 |

- けが・病気・家出の間は、計画のマスは灰色になり訓練しない(疲れ−30・ストレス−5 の休み扱い)。能力は下がらない・技も忘れない(保存した能力を減らさない)
- 対戦(フレンド対戦・助手どうしの対戦)には、けが・病気の間も今のまま出られる案(対戦の仕組みとサーバを変えない)。出られなくするなら窓口へ
- 道具(けがや病気をすぐ治す物)は今回は足さない。交換所に足すかはあとで窓口と
- 試算の見込み: 夜を休みにするなど週に休みを入れていれば、疲れは70に届きにくく、何も起きない。重い訓練を3回続ける日を毎週入れると、月に1回ほどけがをする強さ(作るときに `care-sim` と同じ形で30・90日を回して数字を決める)

### 伸びの釣り合い(フレンド対戦の見張り 40 に収まる)

- 計画の回は今の「指定」と同じ扱い(指定は計画に一本化): 伸び1.3倍・失敗が半分。1日の上限は **20**(見に来た日と同じ。上限そのものは上げない)。サボり・けが・病気・家出は伸びを減らすだけで、増やすことはない
- チケットは今のまま上限の外で最大20 → 合計は最大 **40**。`DAILY_GROWTH_CAP` も masmon-pvp も変えない
- 目安(試算の前の見込み): 計画しない子 1日 約12〜15・計画の子 1日 約18〜20(休みの日は0)。週に1日休むと、計画の子は1週間で約+15〜25%。方向を決められるのがいちばんの得で、数字の差は小さめ
- 作るときに `care-sim` と同じ形で30・90・180日の試算を回し、上限999の届き方を確かめてから数字を決める

### 保存(CLAUDE.md ⑦)

- 新しいキー `mh_assistant_masmon_plan_v1` だけを足す: `{ v:1, picks:[{ aid, slot, monster }], week:{ "<aid>:<slot>": [7日×3回] }, days, done:{ 引き継ぎの印 }, log:[...] }`
- **指定の引き継ぎ**: 今の指定は育成のキーの `plan`(次の回の指定)にある。消さず・書き換えず、育成ノートを初めて開いたときに1度だけ読み、まだ来ていない回の指定を計画の子のその回のマスへ写す(`done.pickMoved_v1` の印で二度しない)。指定の画面とボタンは印が真になったら出さない
- けが・病気・家出は新しいキー `mh_assistant_masmon_cond_v1` に足す: `{ v:1, mons:{ "<aid>:<slot>:<monster>": { k:"hurt"|"sick"|"away", from:回, until:回, care:看病した日 } }, log:[...] }`。疲れ・ストレスは育成のキーの値をそのまま使い、形・意味は変えない。読めない・壊れているときは「何も起きていない」
- 育成のキー `mh_assistant_masmon_grow_v1` の形・意味は変えない。育成の計算(`amgCatchUp`)は、修行と同じ形で `typeof amgpPlanOf === 'function'` のときだけ予定を読む(印が偽なら今と全く同じ)
- 計画の子が手放された・入れ替わった(slot と種族が合わない)ときは、その子の予定を読まないだけ(消さない)
- 迎えた日にさかのぼって計画を当てない(計画は決めた次の回から)
- 育成ノートの段は同じキーの中に `days`(計画で育てた日数・延べ)を持つ。下がらない

## 3. 専用ページ「育成ノート」(仮の名前)

- **入口**: 家の上の「いま行くと得なこと」の並びに「📒 育成ノート」の札/各助手の部屋の「🐾 マスモン」の行からも同じページへ(その助手の子で絞った形)。下のタブ4つは増やさない
- **中身(上のタブ5つ)**
  - 一覧: 計画中の子(段の数まで)と段の道のりを上に大きく、ほかは助手ごとに絞れる一覧(今日の伸び ◯/15・方針)
  - 計画: 「週」(朝・昼・夜×7日のマス・かんたん設定・1週間の見通し)と「1日」(回ごとに選ぶ・6能力と見通しを並べて比べる)
