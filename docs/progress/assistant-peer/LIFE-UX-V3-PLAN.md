### STEP7 旧UIと切替を外す段取り(2026-11-11 社長「いずれは古いのは使わなくなるはず」)
- それまで: 旧UIは「新UIを既定にした後の当面の逃げ道」。**新しい機能は旧UIに足さない・直すのは壊れたときだけ**。今後の改修は新UIだけを前提にする

- 何を消すか: ① 上の「✨新UI/↩旧UI」の切替ボタン ② 部屋・家・居場所の `uiV2 ?` の分かれ道の旧UIの側(旧UIだけのボタンの段・縦の6つのボタン dock など) ③ 旧UIだけを見ている検査の項目(新UIの検査に置き換える)
- 消さないもの: 保存キー `mh_assistant_life_ui_v2` は消さず、読むだけにする(値は見ないで新UIを出す)。ほかの `mh_*` も触らない
- 1つの PR で外し、更新履歴は「助手ライフの画面を新しい形に一本化しました」程度の1行(文案は社長へ)

どれも1つずつ PR・更新履歴とヘルプ。保存キーは足すだけ(施設の得の「その日受け取ったか」だけ新しいキー)。ランキングには効かない。
