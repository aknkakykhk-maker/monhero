## 更新履歴(4行)

- 見出し: M/B管理にいる助手のマスモンに、トレーニングチケットを使ってあげられるようになりました
- 助手がM/B管理にいると「ごろべえのちからを鍛えたいな」のように頼んできます。頼みのままでも、別のマスモン・別の能力を選んでもかまいません
- 助手がM/B管理にいる時間帯ごとに、助手1人につき1枚。同じマスモンには1日1枚までです
- 重トレーニングチケットを使うと大きく上がりますが、ほかの能力が少し下がり、マスモンが少し疲れます。使ったその場で「いくつ → いくつ」が見られます

## ヘルプ(助手のマスモン の節に足す)

- **M/B管理でチケットを使う**: 助手がM/B管理にいるとき、地図のM/B管理の窓か、M/B管理の画面の帯から、助手のマスモンにトレーニングチケット・重トレーニングチケットを使えます。使えるのは、助手がM/B管理にいる時間帯ごとに助手1人につき1枚、同じマスモンには1日1枚までです
- **トレーニングチケット**: 選んだ能力が上がります。伸びやすさ(A〜E)が高い能力ほどよく上がります
- **重トレーニングチケット**: 選んだ能力が大きく上がり、決まった能力も少し上がりますが、かわりに決まった能力が少し下がり、マスモンが少し疲れます。何が上がって何が下がるかは、使う前に表示されます
- **自分のモンスターには入りません**: 助手のマスモンに使ったチケットは、自分のマスモンの絆経験値にはなりません。絆ランキングにも効きません。上がった能力は、助手のマスモンのフレンド対戦にはそのまま入ります
