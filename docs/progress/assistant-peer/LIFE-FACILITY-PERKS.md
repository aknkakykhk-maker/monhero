# 助手ライフ: 助手がいる施設へ行く意味(案) 2026-11-08 ナカヨシ7

社長「モンビーやバトルカード以外にも他の施設にいるときにそこにいく意味を持たせたい」。今あるのは モンヒロビート=券なしでセッション・MFバトルカード=対戦のごほうび1.5倍 の2つ。
控えめに・ランキングに効かない形で、M/B管理・神殿・マーケットに足す。どれも「助手がその施設にいるあいだ」だけ、HOME の顔に「UP」の印、施設の画面の上に「◯◯が来ています」と得の一言を出す。

## 案(施設ごとに A/B から1つ、または「どれもA」「どれもB」でまとめて選ぶ)

| 施設 | A(すぐ得する) | B(1日1回のおまけ) |
| --- | --- | --- |
| 🥚 M/B管理 | 助手がいるあいだ、トレーニングで上がる経験値が1割増える | 助手に話しかけると、その日1回、育成のアドバイスと育成アイテム1個 |
| ✨ 神殿 | 助手がいるあいだ、合体・転生で使ったブリーダーPの5%が戻る | 助手と一緒にお参りすると、その日1回、小さなおまけ(ブリーダーP 少し) |
| 🛍️ マーケット | 助手のおすすめ品が1つ並び、その品だけ1割引き(1日1回) | 助手がいるときに何か買うと、その日1回、おまけが1つ付く |

- 量はどれも小さく、1日の上限を付ける。ランキング(ビート・チャレンジ)の記録には効かない
- A のトレーニング1割増しは、モンスターの育ちが少し早くなるだけ。バトルの数字そのものは変えない
- 助手がその場でひとこと話す(台詞はコトバ・ツムギの遊び場の注文に足す)
- 保存は新しいキー(その日のおまけを受け取ったか)だけ

## 持ち主とのすり合わせ
- M/B管理・神殿: バトル部ジン。マーケット: 持ち主を確かめる(社長が選んだあとで相談)

## 出す時期
段階2の二歩目(遊び場の台詞・神殿とお買い物の遊び場)と一緒に。台詞がそろってから。
