# フレンドの助手ライフの画面を、基本的に自分のと同じに見られるようにする(案・r1115-019)

社長 11/14「フレンドの助手ライフの画面も基本的に自分のと同じように見れるようにしてね これもまえにいったやつだけど」。
前の決めごと: 11/8「極端な話、自分の画面と同じように。そこまではいらない」/ 11/11「フレンドのとこに遊び行っても機能が少なすぎる。もっといろいろ見せれるようにして意味も持たせたい」。今回は「基本的に同じ」まで広げる。
止め絵: `friend-same-view-390.png` / `friend-same-view-320.png`(元 `mock.html`。いまと案の並べ。**手書きの試作**で、実画面ではない)

## 1 案の形(1つ)
フレンドの家を開くと、自分の助手ライフと同じ下のタブ(🏡 家・🗺 町・🤝 きずな・📖 紹介)が出る**見る専用**の画面にする(右上に「👀 見る専用」)。
部品は自分の画面のものをそのまま使い(`readOnly` で操作を止める)、中身だけ相手の写しに差し替える。操作・保存・もらえる物は、いまのフレンドの家の決まり(話す・置き手紙・スタンプ)のまま。

## 3 足す中身と量の見積もり(Supabase 無料枠)
- **足すのは「仲良しの段」だけ**: 助手ごとに0〜2の1けた×8人=約20字。いまの控え `house_more`(上限 6000字・1人1行)の `bd` に入れる。**表・SQL は足さない**(上限の中に収まる見込み。実装前に端末の実際の字数を数えて、足りなければ窓口へ戻す)
- 町・紹介は、いま送っている `houses` の中身だけで作る → **送る量・読む量は増えない**
- 読む量: 「相手の家を開いたときに1回」だけいまと同じ(1軒 約2〜8KB。`house_more` と `alf_masmon_share` は開いた助手の分だけ読む)。町・きずな・紹介のタブを切り替えても読み直さない(端末に持つ)。前の見積もり(FRIEND-VISIT-PLAN.md の 0-2)から**変わらない**(10倍の人数でも送り出し月 約2.8GB=57%・ふつうの遊び方)
- 書き込みは、変わったときだけ(いまの決まりのまま)。`bd` は仲良しの段が変わったときにだけ書き直すので、1人1日 数回以内

## 4 決めてほしいこと
1. 仲良しの「段」を相手に見せてよいか(数ではなく3段階)。見せない場合は、きずなのタブは友情Lv・スタンプだけにする
2. 町の地図で、相手の助手の「今のいる場所」を見せてよいか(いま家の絵でも「おでかけ中◯◯へ」と見えているので新しい情報は増えない)
3. 作る順(推奨): 第1弾 = タブの枠+町+紹介(送る物が増えない) → 第2弾 = きずな(段を足す)

## 5 守ること(変えない)
サーバ(表・権限)・ランキング・保存データは変えない。新しい表は足さない。よその人の名前が入る行・自由文・おしゃべり・仲良し度の数は見せない(11/8)。自分の画面の部品を触るので、自分の助手ライフの見た目が変わらないことを実画面の検査で確かめる。
更新履歴・ヘルプは作ったあとに書く(文案は社長の OK のあと)。
