# 好き・苦手の gift・color をオクリモノに付ける(r1115-035)の案

社長の答え: 「オクリモノに付ける」(2026-11-15)。ナカヨシ(部屋)3 が作る。この紙は窓口に選んでもらうための案。

## 分かったこと
- いまの道具(14種)・家具(20種)には「どのモンスターの物か」「何色か」が無い。そのまま `gift`・`color` を呼べる品は無い
- モンスターの持ち物で全員分あるのは円盤石(15万〜30万)・アイコンだけ。贈る品には向かない
- 助手の好きな色は表にある(`ASSISTANT_MASMON_PLAN[].favColors`。例 みゅあ=淡いピンク・空色・ピンク / ドラ=緑・橙・黒)
- 受け持ち: 贈る窓 `56-assistant-life-gifts.jsx` はオクリモノ部、好みの点 `56-assistant-life-masmon-taste.jsx` はマスモン部。ナカヨシはどちらも持たない

## 案A(推奨): 新しい1人用の品「モンスターのぬいぐるみ」を1つ足す。贈るときにモンスターと包みの色を選ぶ
- 1人に贈る窓の道具の並びに 🧸「モンスターのぬいぐるみ」を足す(買い方は今の道具と同じ・ビートPで1つずつ)
- 贈るときに小窓で ①モンスター(助手のマスモンの種類が先頭・顔アイコンで出す)②リボンの色(染色の色見本から)を選ぶ
- 贈ると `assistantLifeTasteBump(助手, モンスター, 'gift')`。リボンの色が助手の好きな色なら、続けて `'color'` も
- 新しい絵は要らない(ぬいぐるみの枠の上に顔アイコンを丸く載せる・リボンは CSS の色)
- 仲良し度は今の1人用の道具と同じ扱い(好みはそのモンスターの段で 好き/ふつう/苦手 → 台詞も3通り)
- 1日1回(同じ道具は1日1回の決まりのまま)
- 家具は対象にしない(色・モンスターの付いた家具は絵が要る。要るなら案Cで別に)

## 案B: 今の家具・道具に「関係するモンスター・色」を表で付けるだけ
- 例: 🐈ニャーのクッション・🐟金魚鉢 など、合うモンスターがいる物だけ。品は増えない
- 合う物が少なく(数個)、モンスターを選べないので「好みを誘導できる」にならない

## 案C: モンスターごとの家具・道具を新しく作る(絵が要る)
- 例: 「キュービのクッション」「メロディーのレコード」。絵の部・交換所・好み表・台詞がモンスターの数だけ要る。重い
