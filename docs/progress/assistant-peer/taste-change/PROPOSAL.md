正本の案: docs/progress/assistant-peer/GROW-PLAN.md 8(#4951)。社長の答え(❶〜❹ すべて A)のとおり作る。作るのは社長の OK のあと。

## 何を保存するか(新しいキーを足すだけ)
- 新キー `mh_assistant_life_taste_v1`: `{ v:1, by:{ [助手id]: { mon:{[モンスターid]:点}, lin:{[血統]:点}, day:{[日付]:{[対象]:増減}}, log:[{day,target,from,to}] } }`
- 点は -100〜+100。はじめの好き +60・苦手 -60・ふつう 0。はじめの好み(`masmon-plan.json`)は書き換えない・消さない
- 読み込みは壊れていても既定値(差分なし=はじめの好み)を通す。型は `Number.isFinite`/`Array.isArray` で確かめる
- 既存の `mh_*` キーは変えない。移行・補償はなし(二重適用の心配なし)。今の好みを消せばはじめに戻る(裏の安全策)

## 動き方(社長の決定どおり)
- 速さ: ゆっくり。苦手→ふつう約2週間・ふつう→好きがさらに約2週間
- 1日の上限: 1つのモンスターにつき +6・-3。冷めは控えめ(上がり幅の半分まで)
- 推し(性格の芯)は動き方が5分の1・好きの段より下がらない
- 好きになったモンスターは、助手のマスモンの再生のとき入りやすい(助手のマスモンだけ)
- きっかけ: 一緒にバトル/モンヒロビートで勝つ +3 / 会話でほめる +4(1日1回)/ 道具・家具を贈る +5 / 友情Lv5以上の好み +1/日 / 自分のマスモンに育てる +1/日 / 同じ日に3連敗など -2
- スコア・ランキング・強さ・ごほうびには効かせない

## プレイヤーに見えるもの(止め絵 mock-taste-390.png)
- 段が変わった日だけ、助手のひとこと・家の掲示板「今日あったこと」に1件・部屋の「好き・苦手」に「新しく好き」の印と「最近の変化」
