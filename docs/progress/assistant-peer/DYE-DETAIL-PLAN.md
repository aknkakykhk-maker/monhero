# 助手のマスモンの染め方を作り込む(段取り・キズナ3 → 次の担当)

社長の依頼: 「助手の染色はもう少し工夫がほしい。透明度とかも含めて。好きな色は良いんだけど変になりすぎず、かつ変にする人もいるみたいな」
→「好き色はあるけどバリエーションをもっとだしてほしい」→「もっと詳細に設定を作りこんで」(台帳 2026-11-08 の3行)。
窓口(2026-11-08 16:46): このまま始めてよい。仕上がったら公開の前に止め絵(助手ごとの染め上がり)と、更新履歴を付けるならその文案を窓口へ。社長に見せてから公開。

## いまの作り(main #5082 で公開済み)
- 本体: `monster-hero/src/parts/56-assistant-life-masmon.jsx` の `assistantMasmonDyeMake(aid, p, monster, style, rnd)`
  - 5つの型(1 好きな色を濃いめ/2 差し色だけ/3 反対色と秋の色/4 元の色に近い/5 思い切った色)。先頭は型1、残り4体は型2〜5を人ごとに並べ替え
  - 性格は濃さだけ(`ASSISTANT_MASMON_TEMPER`: 控えめ=0.75倍・大胆=1.12倍)。濃さは人ごとに ±5。最大90%
  - 部位の数は `MASU_COLOR_REGION_HUES[monster].length`(3 か 5)。部位の意味は 15-dye-and-art.jsx のコメントにだけある(例: ゴースト ①帽子 ②体 ③リボン)
- 保存: `mh_assistant_life_masmon_v1` の made[助手][].colors(色id か「色id@10〜100」か null)。**一度決めた人の色は変えない**(作り直すなら新しい版の印を足し、前の色は残す。⑦)
- たたき台: `docs/progress/assistant-peer/masmon-life/dye-vary.js`(型の元)・`dye-vary.jpg`(前の止め絵)

## 作り込むこと(引き継ぎで社長の答えに書いてあったもの)
1. 助手ごとの染め方のくせの表(8人): 好きな色/明るい・暗い・くすんだ版の使い方/苦手な色(使わない)/濃さの癖/染めがちな部位(大きい所・差し色だけ等)/グラデーションの有無/元の色を残す割合/つや
2. モンスターの部位の分け方ごとの決まり: 白・黒・半透明の部位・広い部位は濃くしすぎない上限/顔まわり・目は元のまま 等(部位の意味は 15 のコメントから表にする)
3. 変化: プレイヤーごとの差(今の並べ替え+α)/季節やイベントで染め直す/好き嫌いが変わったら色も(どれも「前の色は残す」形で)
4. 変な色にする人(ドラ等)の度合いと歯止め(読めなくならない・汚くならない上限)
5. 止め絵: 8人×5体を「元の色・今の型・作り込んだ設定」で並べた1枚+原寸の拡大3〜4体 → 窓口へ(社長の確認)

## 確かめ方
- `MASMON_SEED=◯◯ MASMON_SHOT_DIR=… MASMON_WHO=◯◯ node tools/assistant/assistant-masmon-browser-check.js --shots` で人ごとの止め絵が撮れる
- 名前は API。`MASMON_REAL_NAMES=1`(縦だけ・本番の関数を1回呼ぶ・約0.2円)
- 既に made を持っている人の色を変える場合は、⑦のとおり新しいキー/版の印で足し、二度適用しない
