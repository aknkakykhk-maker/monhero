2026-11-07 ナカヨシ5。社長の決定「家の絵は新しく描いた断面の1枚に(届くまでは図形の形で出す)」の、描く人向けの注文。
見本(今の仮の形): `ux/life-house-mock-tate.jpg` の②②'、`ux/life-house-mock-yoko.jpg` の⑨。絵が届いたら差し替えるだけで入るよう、部屋の位置はこの表に合わせてゲームを作る。

- 絵は**昼の明るさで1枚**。朝・夕・夜はゲームが色を重ねて作る(下の4)
- **窓のガラスは透明**にする(窓の外の景色はゲームが後ろに置き、時間帯で入れかえる)
- 人(助手)と文字は描かない。顔・名札・札はゲームが上に重ねる

## 4. 1部屋の中の決まり(どの部屋も同じ)

```
┌──────────────────────────────┐
│[名札・🎵Lv の札]      [窓(透明)] │ ← 左上の 4割×3割は空けておく(ゲームが名札を置く)
│                               │    右上に窓(部屋の幅の 25%・高さの 35% くらい)
│        (真ん中: 札を下げる所)   │ ← 真ん中は空ける(出かけているときの札を下げる)
│ [家具]            (顔を置く所)  │ ← 右下の 4割は床だけ(顔の丸を2〜3個置く)
└──────────────────────────────┘
```

- 家具は**左下と壁ぎわ**に寄せる。右下の床は何も置かない
- 灯りの元(天井の照明・机のランプ)は描いてよい。点けた・消したはゲームが明るさで出す
- 部屋ごとの持ち物(今の見本の家具。好みで足してよい):

| 部屋 | 壁の色 | 置くもの |
| --- | --- | --- |
| みゅあ | 桃色 | 鏡台・リボン・ケーキの皿 |
| きき | 薄紫 | 紅茶のポット・本棚・小さなゴーレムの置物 |
| ももすけ | 桃橙 | 鍵盤・ヘッドホン・譜面台 |
| ドラ | 薄緑 | 大きいベッド・おやつ・毛布 |
| あつ | 薄赤 | 太鼓(ドラム)・ドラゴンの置物・トロフィー |
| きゅうこ | 水色 | 本の山・楽譜・カード |
| ソラシド | 薄黄 | カードを並べた机・計算の道具・紙の束 |
| えるびん | 灰青 | 剣と盾の飾り・カード |

- 居間: ソファ・暖炉(夜に火が入る)・左の壁に掲示板(「今日あったこと」をゲームが貼る。幅 500 px ほど空けて板だけ描く)
- 庭: 草・小道・花。あとで助手のマスモンがここで遊ぶ(段階5)ので、真ん中は空ける

## 5. 時間帯の重ね方(ゲーム側でやること・参考)

| 時間 | 空(家の後ろ) | 家の絵 | 部屋 |
| --- | --- | --- | --- |
| 朝 5〜10 | 桃色〜黄色 | 少し明るく黄みを足す | — |
| 昼 10〜14 / 午後 14〜18 | 青空 | そのまま | — |
| 夕方 18〜21 | 紫〜橙 | 橙を重ねる(掛け合わせ) | いる部屋に灯り |
| 夜 21〜 / 深夜 0〜5 | 紺・星 | 暗くする(明るさ 45% くらい) | いる部屋だけ灯り・居間の暖炉 |

- 出かけている部屋は、ゲームが暗い膜を重ねる(灯りが消えた見た目)
- 窓の外: お話の背景の絵(広場・森)を時間帯ごとに後ろに置く
