## 1. 分かりにくい所(初めて触る人の目で)

| # | 分かりにくい所 | どう直すか(案) |
| --- | --- | --- |
| 1 | **同じ「仲良し度」が2つある。** プロフィールでは あなた↔助手 も「仲良し度 Lv」、すぐ下の関係図の 助手↔助手 も「仲良し度 Lv」。ヘルプも同じ | 助手どうしの方の名前を変える。おすすめ「コンビLv」(段の名前に「名コンビ」「最強コンビ」があり合う)。ほか「ふたりの仲」「友情Lv」 |

| 3 | **ペアの行が「Lv4 大のなかよし」と細い棒だけ。** あといくつで何が起きるかが出ない | 行に「あと150で Lv5 → 特別なお話・写真2枚目」(見本①) |
| 4 | **Lv で何が開くかが画面に無い**(ヘルプの中だけ) | アルバムの上に Lv1〜10 の道のり(済み・つぎ・まだ)を出す(見本②) |

**もうひとつ大きいこと: ふつうに遊んでも Lv が上がらない。** 毎日 HOME に12回・ほかの画面に8回入る人で30日まねると、ペアは **Lv2〜3 にしか届かない**(点が全ペアに分かれ、掛け合いは1回 +2・1日 6 まで)。Lv3 からのミニイベント・Lv5 の特別なお話は、ほとんどの人が1か月では見られない。→ 3の「上がり方の見直し」を合わせて決める必要がある。

## 2. 台詞の量

| 種類 | いま(全体) | 1ペアあたり |
| --- | --- | --- |
| ふだんの掛け合い Lv1 | 28本(+ 画面ごと 28本: マーケット3・ビート10・マスモン6・カード9) | 1本(+0〜1) |
| Lv2 / Lv4 / Lv7 / Lv9 | 各28本 | 各1本 |
| 返事を選ぶ | 28本 | 1本 |
| その日の出来事(朝・夜・冬・バトルした日 など9種) | 36本 | 約1.3本 |
| 特別なお話 Lv5 / Lv10 | 各28本 | 各1本 |
| ミニイベント | 12本 | 0.4本(16ペアは0本) |
| 3人の掛け合い | 8組×2本=16本 | — |
| 言い合い→仲直り | 8組 | 0.3組 |
| 差し入れ・しるし・遊んだあと | 8人×3つ=24行 | 決まった1行 |
| 合計 | 掛け合い 約380本・約1,700行 | ふだん出るのは **Lv1〜3 で 約3〜4本** |

**同じ台詞を見る頻度(まねた結果・台本版だけ)**: 1日 約6本出る。会った助手8人で30日 180回出て、ちがう台詞は64本(**7日以内のくり返し 35%**)。助手4人だと34本しかなく **7日以内のくり返し 78%**。最近見たものを避ける仕組みは**ある**(最近30件)が、選べる台詞が少ないので効かない。
今日のペアは3回見る決まりなのに、そのペアの Lv1 の台詞が3本前後なので、同じ日に出つくす。

**増やし方(おすすめ順)**
- **A(おすすめ)**: 1ペアのふだんの掛け合い 約4本 → 約16本(Lv1 6・Lv2 4・Lv3 3・Lv4〜6 3)、返事を選ぶ 1 → 3本、その日の出来事 9種×4 → 9種×8、ミニイベント 1ペア1本(28本)、3人 16 → 32本、言い合い 8 → 16組。**約1,800行**。最近見たものを避ける数を 30 → 150 に。毎日遊ぶ人でも、同じ台詞は 2〜3週間に1回くらい
- B: ふだん 4 → 10本・返事 2本・ミニイベント 28本だけ。約900行。くり返しは 1〜2週間に1回くらい
- C: 台本は少し(約400行)で、AI 版を多く使う(下の4)。AI が使えない日は今と同じ

台詞はコトバと分担(VOICE.md の形でテキスト → 取り込み道具)。ナカヨシは仕組みと検査、コトバは本文。

## 3. 上がり方の見直し(1・2と一緒に決める)

- **おすすめ**: いちばん遊ぶ助手のペアが、2週間で Lv5、2か月で Lv10 に届くくらいに、これからの1回の量を上げる(掛け合い +2 → +5、1日の上限 20 → 40 など)。今の点数は消さない・書き換えない(⑦)
- ほか: 「聞く」ボタン(1の5)と今日のペアの達成を増やすだけにして、量は変えない

## 4. AI 版の掛け合い(peer_talks)

- いま: HOME に入って、その日に作ったものを見終えていたら4本頼む。HOME では6割の確率で台本より先に出る。ほかの画面・アルバムには出ない
- まぜ方の案: (a) 1回の頼みを 4 → 8本にし、今日のペアといまの助手のペアを多めに、(b) ほかの画面でも出す、(c) よかったものをアルバムで見返せるようにする(端末に残すだけ・新しいキー)
- 出ている量を見る SQL(読むだけ):
  `select day, count(*) as players, sum(count) as calls, max(count) as most from public.assistant_peer_talk_usage group by day order by day desc;`
