# モンヒロバトルの場所でできること: 👀 修行を見る・📣 応援する(設計・シュギョウ 2026-11-11)

社長「助手がモンバトにいるときって何をしてるかとかこっちから何かできることってないの？」(台帳 #5350)。
止め絵: `mock-portrait.png`(縦 ①窓 ②修行を見る ③応援した)・`mock-landscape.png`(横 ④窓 ⑤修行を見る)。見本の HTML は `mock.html`(本物の部品ではない)。

## 1. 窓(地図でモンヒロバトルを押したとき)

- 助手の行に「🥋 きょうの修行」を1行足す(どのマスモンが・どの修行・覚えた技・熟練の伸び)。まだなら「きょうはまだ修行していません」
- 行の下に**マスモンのボタンを1列3つ**: `👀 修行を見る` / `📣 応援する 今日 n/3` / `⚔ マスモンで対戦(β)`(⚔ はミセカタ2の口 `assistantMasmonBattleRowInfo`・`Open` のまま)
- 右の `💬 詳細を見る`・`🏡 部屋へ` は今の場所のまま
- 修行の印(`assistantMasmonTrain`)が偽なら、👀・📣 と「きょうの修行」の行は出さない

## 2. 👀 修行を見る

- その助手の**いちばん最近の修行**(今日。無ければ前回)を、練習試合として短く見せる。保存は何もしない(見た印もなし)
- 練習の相手: ①その助手の別のマスモン(手持ち2体以上)/②1体だけなら、同じ時間帯にモンヒロバトルにいるほかの助手のマスモン/③どちらも無ければ相手なしの「型の稽古」(技を順に出す)。架空の練習相手は作らない(βの決めに合わせる)
- 1対1・その日の回の番号を種にして毎回同じ試合(何度見ても同じ)。★見せ場だけで始まる
- 下に「きょうの修行」: 覚えた技(NEW)と、熟練の 前→後 のバー・段(見習い〜極み)
- 観戦の部品は β の `ambwLoadEngine`・`ambwFramesOf`・`ambwIsHighlight`・`AmbwPanel`・`AMBW_CSS` を使い回す(ミセカタ2に相談)

## 3. 📣 応援する(数字の案)

| | いま(1日6回の移動) | 12回の移動のあと(1回ごと約75%) |
| --- | --- | --- |
| 回数 | 移動の1回に1回・助手ごと | 同じ |
| 1回の熟練 | +1 | +1(1より小さくできないので回数で合わせる) |
| 1回の 💗 仲良し度 | +6 | **+5**(6×0.75=4.5 を四捨五入) |
| 1日の上限 | 2回(熟練+2・💗+12) | **3回(熟練+3・💗+15)** = 1日の量は約1.5倍 |

- 熟練が入るのは「その日いちばん最近に修行したマスモン(まだなら先頭のマスモン)」の**いちばん熟練の低い技1つ**。能力(ちから等)・疲れは動かさない(育成の1日の上限・フレンド対戦の見張りに触れない。サーバの見張りは熟練0〜100だけ)
- 💗 は新しい行動 `lifeCheer { amount:5, dailyMax:15 }`(比べ: 神殿 +30/日・フレンドの家 +30/日・助手どうしの掛け合い +10/日)
- 保存は修行のキー `mh_assistant_masmon_train_v1` に項目を足す(`cheer: { [助手]: { d: 日, n: 回数, s: [回の番号] } }`)。同じ回は二度数えない

### 試算(`node tools/assistant/assistant-masmon-train-check.js --sim --rate=0.25 --cheer=回数,量`)

ゴーレム・手持ち2体・モンヒロバトルにいた日は毎回応援した場合。技8つの熟練(低い〜高い)。

| | 90日 | 180日 |
| --- | --- | --- |
| 応援なし(いま) | 27〜56 | 57〜88 |
| 1日2回×1(いまの案) | 32〜69 | 77〜100 |
| **1日3回×1(12回後の案)** | 37〜85 | **84〜100**(極みまで約5か月) |
| 1日3回×1.5(強すぎ) | 41〜91 | 90〜100 |

手持ちが多いほど1体あたりは薄まる(応援は1回に1体だけ)。「極みまで約半年」を「約5か月」に縮める程度。

## 4. 決めてほしいこと

1. 応援の量: 12回のあと「1回 熟練+1・💗+5・1日3回」(推奨)/少なめ 1日2回/多め 1回 熟練+2
2. 練習の相手: 自分の別のマスモン → ほかの助手 → 型の稽古(推奨)/ほかの助手を先に
3. 「修行を見る」に得は付けない(推奨)/見たら育成の「見に来た」(伸び1.1倍)に数える
