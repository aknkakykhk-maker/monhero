# 設計: モンヒロバトルの窓に「👀 修行を見る」「📣 応援する」を足す(シュギョウ・2026-11-11)

社長「助手がモンバトにいるときって何をしてるかとかこっちから何かできることってないの？」への答え。
**まだ作っていない。この1枚と止め絵(`cheer-mock-portrait.png`・`cheer-mock-landscape.png`)に OK をもらってから作る。**

## どこに出すか

地図 → モンヒロバトルの札 → 開いた窓の、**バトルにいる助手の1行ごと**。

いまの1行は、右に縦3つ(⚔ マスモンで対戦(β)/💬 詳細を見る/🏡 部屋へ ›)。ここへ2つ足すと縦5つ(約240px)になり、窓が縦に伸びすぎる。
そこで**名前の下に横並びの帯を1本**足し、新しい2つはそこへ置く(右の縦3つはそのまま)。

```
┌──────────────────────────────────────────────┐
│ (顔) きき                    [⚔ マスモンで対戦(β)] │
│      ⚔ マスモンと修行している     [💬 詳細を見る]      │
│      今日: パンチ 熟練+6・キックを覚えた [🏡 部屋へ ›] │
│ [👀 修行を見る]  [📣 応援する]   ← 新しい帯(横いっぱい) │
└──────────────────────────────────────────────┘
```

- 帯は**マスモンを1体以上迎えている助手だけ**に出す(いなければ帯ごと出さない)。印 `assistantMasmonTrain` が偽でも出さない
- 名前の下の一言を「今日: ◯◯ 熟練+◯・◯◯を覚えた」にする(今日まだなら「今日はこれから修行します」)
- **ボタンの並び**(ナカヨシ11・ミセカタ2と合わせる所): 右の縦は「対戦(β) → 詳細 → 部屋へ」の今のまま。帯は「修行を見る → 応援する」。
  ナカヨシ11が窓の作りを12回化で変えるなら、帯は「助手の1行の中・名前の下」に置く約束だけ守ればよい

## 👀 修行を見る

押すと窓の上に重ねて、**練習試合を短く観戦**する(1ラウンド・「★ 見せ場だけ」の速さで約20秒・飛ばせる)。

- 相手: その助手のマスモンが**2体以上なら2体どうし**、**1体だけなら自分の「影」**(同じ絵を暗くしたもの。新しい絵は要らない)
- 使う技: そのマスモンが**いま覚えている技**と熟練。結果はその日・その時間帯で決まる(何度見ても同じ。保存しない)
- 下に「今日の修行」: 何の修行をしたか・覚えた技・熟練の伸び(段の名前が上がったら「見習い → 一人前!」)
- 観戦の部品は**ミセカタ2の β の観戦の再生(`ambwFramesOf`・`AmbwPanel`・速さ)を使い回す**。計算はタタカイの `data/assistant-masmon-battle.js`。
  使い回しの可否はミセカタ2へ相談(下の「聞くこと」)
- **何も増えない・何も保存しない**(見るだけ)

## 📣 応援する

| | 案A(推奨) | 案B |
| --- | --- | --- |
| 1回で何が起きる | そのマスモン全員の「いま磨いている技」の熟練 **+1〜2** | 次の修行の伸びが **×1.3**(貯まらない) |
| 回数 | 時間帯(12回のうちバトルにいる回)に**1回**・**1日3回まで** | 同じ |
| 仲良し度 | **+8**(1日 +24 まで)。新しい行動 `lifeCheer` | 同じ |
| よいところ | 押した瞬間に数字が動いて分かりやすい | 修行の数字の流れを変えない |

- 量の決め方: 12回化で修行1回の伸びは約75%(熟練 +3〜6)。応援1回はその**約1/3**(+1〜2)。
  バトルにいる回は1日におよそ3回(12回×約25%)なので、**毎回応援すると1日の伸びが約2〜3割増える**(極みまで約半年 → 約4〜5か月)
- 押したあとは「📣 応援済み・◯時から」に変わって押せない。助手のひとことが1行出る(「きき: ありがとう、ごろべえも張り切ってる!」)
- ブリーダー能力の掛け算は**掛けない**(応援はプレイヤーの手柄)

## 保存(CLAUDE.md ⑦)

- 新しいキーは作らず、修行のキー `mh_assistant_masmon_train_v1` に**項目を足す**: `cheer: { [助手id]: [時間帯の番号…] }`(新しい方の30件だけ残す)
- 正規化を通して読む(無い・壊れている → 空)。同じ時間帯の二度押しは番号で止める
- 仲良し度は既存の `addAssistantBond` の口へ `lifeCheer` で入れる(行動を1つ足すだけ。既存の量は変えない)

- 更新履歴(group assistant): 「助手がモンヒロバトルにいるとき、マスモンの修行を見たり応援したりできるようになりました」

## 社長に決めてもらうこと

1. 応援の効き方: **案A(推奨)熟練+1〜2がすぐ** / 案B 次の修行×1.3
2. 応援の回数: **1日3回まで(推奨)** / バトルにいる回は全部(上限なし)
3. 練習試合の相手(1体だけのとき): **自分の影(推奨)** / 観戦なしで「今日の修行」だけ
