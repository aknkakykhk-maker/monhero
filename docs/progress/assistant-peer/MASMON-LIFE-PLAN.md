# 助手のマスモンが助手ライフに登場する(案だけ・作るのは決まってから)

社長「助手のマスモンも部屋にいたりどこかにいたり色々絡んできたら面白いな。顔アイコンと全身絵はあるし」(2026-11-08)。担当: 助手部キズナ2

止め絵(本物の助手ライフの画面に案の部品を重ねた。撮り直し `node docs/progress/assistant-peer/masmon-life/shoot.js`):
- `masmon-life/1-house-tate.jpg`・`1-house-yoko.jpg` … 部屋にマスモン(染めた全身絵)。助手がいれば様子の印(💤♪🍡✨)、助手が出かけていれば半分は「🏠 るすばん」
- `masmon-life/2-map-tate.jpg`・`2-map-yoko.jpg` … 居場所の地図で、助手の顔の下に一緒に出かけたマスモンの顔アイコン
- `masmon-life/3-sheet-tate.jpg` … 部屋のシートに「🐾 いま」(どこで誰のマスモンと遊んでいるか)と、助手のひとこと

## 守ること
- 絵はゲームにあるものだけ(全身絵は DyedMonsterImage で助手の染めた色・顔アイコンは faceIconUrl)。描き下ろさない
- 数字(強さ・スコア・ごほうび)に効かせない。保存は新しいキーだけ(`mh_assistant_life_masmon_v1` に入れる予定)。プレイヤーのマスモン・セーブに触らない
- 実装済みのモンスターだけ。助手やマスモンを「子」と呼ばない
- 助手ライフは🔄横でも回らない。縦・横で崩れないこと(作るときに本物で撮って確かめる)

## 形
1. **部屋にいる**: 助手の部屋の床の右下に、先頭(または当番)のマスモンが小さく。様子は時間帯と助手の様子に合わせる(寝ている助手のそばで 💤・練習帰りに ♪・おやつのあと 🍡)。作るときは行き先の札・顔・吹き出しに重ならない所へ置く(止め絵では右下に重ねただけ)
2. **どこかにいる**: 助手が出かけるとき、マスモンも一緒に行くか留守番するかを、その時間帯の様子(1日6回の区切り)で決める。一緒なら居場所の地図・居場所タブで助手の顔の下に顔アイコン。マスモンだけで中庭・広場にいることもある
3. **絡み**(どれも台詞と印だけ)
   - マスモンどうしの仲: 同じ場所にいた回数で「なかよし」の印(数字は見せない)。部屋のシートの「🐾 いま」と助手のひとことで出る
   - 好き嫌いの台詞: 助手がほかの助手のマスモンを見て反応(好きなモンスターなら喜ぶ・苦手なら少し引く。悪口にしない)。好き嫌いが変わる仕組み(GROW-PLAN 8)のきっかけ「一緒に遊んだ」にもつなげられる
   - プレイヤーのマスモンと会う: {name} の先頭マスモンを部屋に連れて行くと、助手のマスモンと並んでひとこと(読むだけ。プレイヤーのセーブには書かない)
   - フレンドの家: 助手が遊びに行くとき、マスモンの顔アイコンも一緒に写る(オトズレ2とすり合わせ。控えに先頭のマスモンの id・色だけ足す)
   - モンヒロビート: 助手とのセッションで、その助手の先頭マスモンがモンスターノーツとして出る(ビート部とすり合わせ。譜面・スコアは変えない、見た目だけ)

## 部屋のマスモンの大きさ・置き場所(2026-11-08 社長「マスモンのサイズ感ちがくない？」「部屋の中でウロウロしてもいいとはおもう」)
止め絵(見本。札の位置は CSS を上書きしただけ): `masmon-life/size-all.jpg`(A・B・C × 縦・横・🔄横から戻った)・`masmon-life/size-walk.jpg`(歩く案の3コマ)。撮り直し `node docs/progress/assistant-peer/masmon-life/size-shoot.js`
- A(おすすめ): どの部屋も助手の顔の丸と見合う同じ大きさ(縦 約44px・横 約33px)で床の右に立つ。出かけ札は少し左へ
- B: 同じ大きさで床の左(家具の前)に固定。出かけ札は右へ
- C: 全身は出さず、名札の横に顔アイコン
- 歩く(A の大きさに足す): 床の帯で、札・顔・吹き出し・名札に重ならない区間だけを左右に歩く。ときどき止まって様子の印を出す。動きは小さく(助手より目立たせない)。動きを減らす設定(prefers-reduced-motion)の人には止まった形。縦・横・🔄横から戻った で同じ
- 作るとき: 札の位置はナカヨシ8の札の置き場所の直しで決め、マスモンはそれに合わせる。検査で「重ならない」「出かけていない部屋の全部に同じ大きさで出る」を数える(歩く途中のどの位置でも重ならない)
