## C-1 好きな家具を使っている吹き出し(furnuse 24本)

- 8人×好きな家具3つ。例「🛋️ ソファでごろごろ中…」「植物に水やり中でつ」(20字まで・表情なし)
- 出す所: 家の部屋の吹き出し(今の「部屋で ◯◯」の所)
- 出す条件: その助手が自分の部屋にいる・起きている・けんかのあとではない・さみしそうではない、かつ部屋に**置いてある**家具のうち、その助手の好きな家具に台詞がある
  - 押し入れにしまった家具では出さない
  - 好みは贈ったときに分かっているので、吹き出しで隠れた好みがばれることはない
- 社長に選んでもらう所 ❶: どのくらい出すか
  - A: 好きな家具が置いてあれば、部屋にいるあいだはいつもこの吹き出し(推し)
  - B: 時間帯ごとに半分くらい(いつもの「部屋で ◯◯」と入れかわる)

## C-2 遊びに来た助手が家具に触れる(visitfurn 40本)

- 決まった2人と決まった家具の掛け合い(2〜3行)。例: ももすけがみゅあの部屋で「このくま、かわいすぎ！！」→ みゅあ「{name}がくれたの♪」
- 出す条件: 部屋の主とその台詞の相手が2人でその部屋にいる、かつその家具が部屋に置いてある
- 社長に選んでもらう所 ❷: どこで流すか
  - A: 部屋の吹き出しに「🧸 くまの話をしてる」と出し、部屋のシートの「👀 見守る」で流れる(見守る1回に数える・今日あったことに残る)(推し)
  - B: 部屋を開いたときに、その場で自動で流れる(1日1回まで)
- 一度見た掛け合いは思い出アルバムに入る(今の掛け合いと同じ)
