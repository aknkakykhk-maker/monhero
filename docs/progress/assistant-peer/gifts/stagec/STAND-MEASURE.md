# 場面の立ち絵を、実際に見えている体で測った表(2026-11-08 オクリモノ3)

社長「助手の立ち絵サイズのバランスや配置の仕方があんまりよくない」「絵の余白の違いだと絵のサイズで変わるから実際の見た目ではかって」。

- 測り方: 「にこにこ」の絵を、透けていない画素の範囲(見えている体)で切り出し、上を0・下を100として目と顎の高さを読んだ(`stand-measure.png`。赤い線が10ずつ)
- 8人の絵は全身ではなく上半身で、どこで切れているかが絵ごとに違う。見えている範囲の高さをそろえていた前の作りでは、頭の大きさがばらつき(上半身の短い絵ほど頭が大きい)、幅の広い絵(みゅあの羽・ももすけの袖)が隣と大きく重なっていた

## 置き方(56-assistant-life-house.jsx の ASSISTANT_LIFE_STAND_FACE・assistantLifeStandLayout)

- 「目から顎まで」を、その場面の全員で同じ長さにする(頭の大きさがそろう)
- 長さは、人数で決めた場面の高さの割合と、1人の見えている幅が受け持ちの幅(画面の幅を人数で割る)の1.08倍を超えない長さの、小さいほう
- 体の下端を床の線にそろえる(上半身で切れている絵が宙に浮かない。背丈の差はそのまま出る)
- 着替えなど表に無い絵は、ふつうの形(目33・顎47)で見る
- 検査: tools/assistant/assistant-life-scene-stand-browser-check.js(縦390・横844・🔄横667・小さい縦375 × 4組。頭の大きさ・左右の重なり・顔が見出しと台詞の箱に隠れない・下端が床の線)
