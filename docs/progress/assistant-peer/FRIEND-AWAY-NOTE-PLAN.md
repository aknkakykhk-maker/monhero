## A 訪ねた家の助手が全員おでかけ・おやすみのとき

- **A1** 上に案内「みんな出かけたり、寝たりしているみたい。部屋をのぞいたり、留守の助手に一言を残せます」。
  いない・寝ている部屋も押せる(「👀 のぞく」)。いる助手は今までどおり声をかける
- **A2** おでかけ中の部屋をのぞく: その助手の部屋の絵に、置いてある家具(天井・壁・床の3つ)と、助手のマスモン(キズナ2の ms)。
  「📝 ◯◯に一言残す」→ B1 の置き手紙があて先つきで開く
- **A3** おやすみ中: 「💤 すやすや…起こさないように、そっと見るだけ」。部屋と Zzz。一言は残せる
- 控えに足すもの: `r.<助手>.fu = { c, w, f }`(家具の key だけ。今の控えの JSON に項目を足すだけ・新しい SQL なし・読むときは知らない key を捨てる)
- ごほうび・回数は今のまま(置き手紙は1日1軒1回・ビートP 50)。のぞくだけなら回数を使わない

## B 置き手紙の自由文(社長決定)

- **B1** 決まった一言(今の12個)を選んだうえで、「✏️ ひとこと(自由・40字まで・なくてもよい)」。あて先(留守の助手)があれば上に出す
- **B2** 見張り(端末): MFバトルカードのチャットと同じ表(`cardChatClean` で見えない字・改行を消す → `cardChatContact` で連絡先らしいもの〈URL・メール・7けた以上の数字・SNSのID〉は**送れない**(ボタンを押せない・理由を出す)→ `cardChatMask` で悪い言葉は●)。
  個人情報として、住所らしいもの(〒・丁目・番地)と「本名」「学校」も送れなくする(案)
- 見張り(表): 長さ40字・改行なし・player の行だけ・連絡先らしいものをはじく・あとから変えられない(下の SQL)
- **B3** 受け取る側: 置き手紙の下に自由文。「⋯」で「この人の自由文を見ない」(この人の決まった一言は出る)・「来ないようにする」(今の機能)。
  設定に「置き手紙の自由文を見る」(既定は入)。保存は今の設定(行き来の設定オブジェクト)に `noteOff: [id]`・`noteShow: true` を足す(正規化で既定値を補う)。
  受け取る側の表示でも、もう一度 `cardChatContact`・`cardChatMask` を通す
- 通報: **今回は入れない案**(相手は承認済みのフレンドだけ・見ない/来ないようにする・フレンド解除で止められるため)。要るなら次の段で
- 気をつけること: 置き手紙の表は、今も公開の鍵で読める作り(select using true)。自由文も、相手のブリーダーIDを知る人なら読める。
  連絡先・個人情報をはじくのはそのため。気になるなら「自由文は届いた人だけが読む口(関数)」に分ける案もある(SQL が増える)
