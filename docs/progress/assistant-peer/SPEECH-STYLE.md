## 書き方の決まり

1. **取り込むのは話し方の特徴だけ**: 語尾・言い回し・のばし方・顔文字・絵文字・テンポ・提案のしかた
2. **中身は書かない・置かない**: 送られてきた文の内容、私生活、名前、連絡先、ほかの人の話。原文の引用も置かない(特徴の形に言い換えて、短い例を作って添える)
3. えるびんは、実在の方の私生活を書かない(今までどおり)
4. `VOICE.md` の「必ず守ること」とぶつかるときは、`VOICE.md` が先(例: あつの文末の「笑」・記号・顔文字。みゅあの「ぢゃん」「まぢ」)。変えるのは社長が決めたときだけ
5. 1つの特徴は1行。「いつ使うか(多め/ときどき/ここぞで)」を添える。見本が来たら日付を付けて足す
6. 例は自分で作った短い台詞にする({name}・{c} の決まりもそのまま)
