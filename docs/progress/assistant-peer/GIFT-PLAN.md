- 仲良し度: ふつう +80/💗好き +120/💧苦手 +40。その家具をその助手に初めて贈ったときの1回だけ
- 部屋に置けるのは3つ(天井・壁・床)。ほかは「しまう」で部屋の押し入れへ。部屋の「🪄 飾り付け」で入れかえ自由(=前の決定の「飾り付け」)。贈った家具はほかの助手へは移せない
- もとからある家具(🥁🐉 など)はそのまま
- 置き場所の決め方(止め絵で確かめた): 部屋の右側は顔・吹き出し、真ん中は出かけたときの札が使うので、天井=真ん中の上(吊るす)・壁=左の壁(名札の下)・床=真ん中の床(今の家具の右・顔の左)。横の狭い部屋では床の家具が顔に少し寄るので、作るときに大きさを部屋の幅に合わせる
- 描き下ろしの家の絵が来ても使える作り: 置き場所は「部屋の箱に対する割合」で持つ(HOUSE-ART-ORDER.md の部屋の箱と同じ)。絵が来ても同じ所に出る。注文書には「天井の真ん中・左の壁・真ん中の床は空けておく」を足す。家具ごとに絵(透明 PNG)の欄を持ち、届くまでは絵文字
- 好きな家具を置いた部屋では、いるときの吹き出しが変わる(「🛋️ ソファでごろごろ中」)。遊びに来た助手が家具に触れる台詞も(段階C)
