# HELL の精度(作り方と Lv. の測り方)2026-11-11・ジゴク

社長「譜面の作成とその難しさをはかるのがヘルだとかなり難しいからそこをしっかり精度上げてつくってほしい」。
**公開中の譜面・解析・表示の Lv.・既定の測り方は1つも変えていない**(道具と検査と資料だけ)。決まりの本文: [`docs/rules/CHART_ENGINE.md`](../../rules/CHART_ENGINE.md)「HELL の Lv. を手ごとに測る(v4・参考値)と、HELL の作り方の精度の強化」。

## ② 難しさの測り方(新しい式 v4・参考値)

- 今の式(v3)は毎秒の仕事量で測るので、**ノーツは少なめなのに1つ1つの手の段取りが難しい譜面**を低く出していた(10/27 に社長の値で上げた7譜面がそれ)
- 新しい式は、速さ・密度の難しさ S(今の式の値)に、手の段取りの難しさ C(同じ親指の地上⇔空中・片手が押さえている間に残りの親指で叩く・押さえている手の側まで伸ばす・
  押さえている帯と高さが違う・地上と空中の混ざり。**1ノーツあたり**で数える)を合わせる: `Lv. = (S^3 + C^3)^(1/3)`
- 表: [`hell-level-table.png`](hell-level-table.png)(公開中の HELL 56譜面の 表示・今の式・新しい式・いちばん効いた要素・案)

| | 今の式(v3) | 新しい式(v4) |
| --- | ---: | ---: |
| 社長の値の7譜面との外れ(最大) | 13 | 2 |
| 同じ7譜面を1つずつ抜いて合わせたときの外れ(最大) | — | 3.5 |
| ほかの49譜面の表示との差 | 0(表示が式の値) | 0〜+3(29譜面は変わらない・+1 が13・+2 が3・+3 が4) |

### 分かっている限り

- 合わせ先は社長の値の7譜面だけ(どれも「押さえながら」が多い型)。社長が遊んで「この Lv. は合っている/違う」と言った譜面が増えるほど確かになる(`--calibrate` で出し直せる)
- 「連打」(同じ側の速い連打)は今の式のままで、これだけで Lv. を 20 以上動かす譜面がある(ヒューマノイド +25.6・ビッグブリッヂの死闘 +22.8)。ここが合っているかは今回確かめていない
- 前に社長が体感を言った譜面(AMOS の前の譜面 42・Toward the Stars short の前の譜面 57)は、譜面が作り直されていて今の形では比べられない
- 空中を押せるボットでの通しは回していない(重い調査なので、窓口の返事を待つ)

## ① 作り方(`rhythm-hell-mix.js` の `precision:true`。書いた曲の HELL にだけ効く)

点検(`node tools/mode/rhythm-hell-review.js`)で公開中の HELL 56譜面を数えた: 音からの外れ 平均1%・ノーツの量と盛り上がりの合い方 0.52・
**空中の量と盛り上がりの合い方 0.01**(空中の回し方が曲に関係なく順番だった)・同じ親指の速い持ち替え(150ms以内 97・押さえていない手 31・250ms以内の空中 198)。

強化: 空中・地上の回し方を小節の盛り上がりで決める/静かな小節の長いスライドは地上のまま/交差は盛り上がる所から選ぶ/速い持ち替えの空中タップを最後に下ろす/空中の量は元の9割以上に保つ。

作り比べ(5曲・書き出すだけ。ゲームのデータには入れていない。切 → 入):

| 曲 | ノーツ | 空中 | Lv.(v3) | 空中と盛り上がりの合い方 | 速い持ち替え(3種の合計) | 押せない・水平クロス・帯の中・見分けにくい | モンスター |
| --- | ---: | ---: | ---: | ---: | ---: | --- | ---: |
| Evans | 464→466 | 62→55 | 51→49 | −0.06→0.31 | 13→6 | どれも 0→0 | 4→4 |
| ROSE short | 432→434 | 31→34 | 52→51 | −0.13→0.38 | 6→5 | どれも 0→0 | 4→4 |
| SAD SONG short | 296→297 | 33→34 | 42→40 | −0.05→0.50 | 2→2 | どれも 0→0 | 4→4 |
| BLACK SHOUT | 512→514 | 45→43 | 60→60 | −0.31→−0.23 | 1→0 | どれも 0→0 | 4→4 |
| light player short | 678→678 | 54→62 | 52→52 | −0.35→−0.07 | 0→1 | どれも 0→0 | 4→4 |

- 5曲の平均で 合い方 −0.18 → 0.18。ノーツの混んだ曲(BLACK SHOUT・light player short)は、盛り上がる所で段を変える間(1.5拍)が取れず、空中の量を保つために
  回し方を寄せ直すので、効きが小さい
- `precision` を書いていない曲は、強化前と1文字も同じ譜面になる(Evans で前後のワークツリーの出力を突き合わせた)
- 骨組みを作る `rhythm-chart-v3-generate.js --difficulty HELL` は触っていない(音からの外れが無かったため。MHB CHART ENGINE のリビジョンは上げていない)

## 足した道具と検査

| 道具 | 何をする |
| --- | --- |
| `tools/mode/rhythm-hell-level.js` | HELL の Lv. を手ごとに測る(v4)・1譜面の内訳・全譜面の表・重みの合わせ直し |
| `tools/mode/rhythm-hell-review.js` | HELL の作りの点検(速い持ち替え・音からの外れ・盛り上がりとの合い方)・精度の強化の入/切の作り比べ |
| `tools/mode/rhythm-hell-mix.js` | 曲の設定 `precision:true`(`--precision` で試す) |
| `tools/mode/rhythm-hell-level-check.js`・`rhythm-hell-precision-check.js` | 上の決まりの見張り |
