# r1115-157・163 試合の技の演出をランクごとに派手にする

社長「技演出はさっぱりしすぎてるからランク毎にもっと派手にしたい。カットイン付きとか。エフェクトも派手」(r1115-157)
試作を見て「もっと派手に」・短くするのは速さで決める(案A)・ランク5は毎回全画面カットイン(r1115-163)

- 対象: 試合の場(`56-monhero-success-arena.jsx` の `MsaStage`)。モンサクの試合・助手のマスモン対戦・フレンド対戦・練習試合は同じ場を使うので、どれにも出る
- **見た目だけ**。試合の芯(`assistant-masmon-battle.js`)の計算・記録は変えない。ランクは見せる側で技表(`ASSISTANT_MASMON_TECHS` の `rank`)から引く
- 数の表は `MSA_RANK_FX` の1か所(カットインの長さ・当たりの段・揺れ・場の光・背景)
- 止め絵は実際に動かして撮った物(縦390・場の高さ440・モンサクと同じ大きな場)

## ランクごとに出るもの(仕上げ)

| ランク | 撃つ前 | 当たったとき | 場全体の光 | 揺れ |
| --- | --- | --- | --- | --- |
| 1 | いまの構え・光 | 光の玉・輪・火花3つ | なし | 弱 |
| 2 | 同上(中・遠は相手へ走る光の筋) | 大きめの光・輪・火花6つ | 弱 | 弱 |
| 3 | 構えのあいだ攻め手に集中線 | 大きな光・放射の光・破片10個 | 中 | 中 |
| 4 | 帯のカットイン(顔・技名・★・回る集中線・0.9秒)→ 大技の構え | 大爆発・二重の輪・放射の光・地面の衝撃波・破片12個 | 強 | 強 |
| 5 | 全画面カットイン(暗転・集中線・大きな斜めの帯に立ち絵・技名・★5・白い閃光・1.4秒)→ 背景が変わる → 大技の構え | 特大の爆発が2回・三重の輪・光の柱・破片16個(かしこさは魔法陣も) | とても強い | 大揺れ(ランク5だけ) |

- ちから技=橙と赤・四角い破片・ランク5の背景は燃える赤い空 / かしこさ技=水色と紫・星の破片・ランク5の背景は星の夜空
- 相手の技は向きが逆(右から入る・絵が右・字が左)。カットインの絵はいまの立ち絵(染めた子は染めた色)。新しい絵・音は足していない
- ランク5は同じ試合で何回撃っても毎回全画面カットイン(r1115-163)
- ×2: カットインを0.7倍 / ×4(早送り)・端末の「動きを減らす」・ハイライト: カットインなし。新しい設定・保存キーは作らない(r1115-163 案A)
- オートも手動と同じ。重さ: CSS のアニメーションだけ(位置・大きさ・透明度)。絵の読み込みは増えない
