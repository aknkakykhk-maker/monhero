# r1115-157 試合の技の演出をランクごとに派手にする(案)

社長「技演出はさっぱりしすぎてるからランク毎にもっと派手にしたい。カットイン付きとか。エフェクトも派手」

- 対象: 試合の場(`56-monhero-success-arena.jsx` の `MsaStage`)。モンサクの試合・助手のマスモン対戦・フレンド対戦・練習試合は同じ場を使うので、どれにも出る
- **見た目だけ**。試合の芯(`assistant-masmon-battle.js`)の計算・記録は変えない。ランクは見せる側で技表(`ASSISTANT_MASMON_TECHS` の `rank`)から引く
- 止め絵は試作を実際に動かして撮った物(縦390・場の高さ440・モンサクと同じ大きな場)。枝 `claude/craft39-r1115-157-skill-fx`

## ランクごとに出るもの

| ランク | 撃つ前 | 当たったとき | 場の揺れ | 1手の長さ(×1) |
| --- | --- | --- | --- | --- |
| 1 | いまの構え・光 | 小さな光の玉と輪 | いまのまま | いまのまま |
| 2 | いまの構え(中・遠は相手へ走る光の筋) | 光の玉・輪・火花4つ | 弱 | いまのまま |
| 3 | 構えのあいだ攻め手に**集中線** | 大きな光・放射の光・破片8つ | 中 | +0.03秒(当たりの止め) |
| 4 | **帯のカットイン**(顔・技名・★4つ・0.76秒)→ 構え | 大爆発・二重の輪・地面の衝撃波 | 強 | +0.8秒 |
| 5 | **全画面カットイン**(暗転・回る集中線・斜めの大きな帯に立ち絵・技名・★5つ・最後に白い閃光・1.25秒)→ **背景が変わる** → 大技の構え | 特大の爆発・光の柱・破片12個 | 強 | +1.3秒 |

- カットインの絵は、いま試合で出ている立ち絵(染めた子は染めた色)をそのまま使う。新しい絵・音は足さない
- 相手の技は向きが逆(右から入る・絵が右・字が左)

## 技の種類・間合いでの違い

- **ちから技**: 橙と赤。破片は四角。ランク5の背景は「燃える赤い空」
- **かしこさ技**: 水色と紫。破片は星。ランク5は当たりに魔法陣が回り、背景は「星の夜空」
- **間合い**: 零・近は当たる場所で爆発するだけ。中・遠はランク2から、攻め手から相手へ光の筋が走ってから爆発

## 速さ・設定・オート・端末の重さ

- ×1: 全部出る / ×2: カットインを0.7倍に縮める(帯0.53秒・全画面0.88秒) / ×4(早送り): **カットインは出さない**(当たりの光だけ)
- 端末の「動きを減らす」設定・軽い表示(助手の練習試合の「ハイライト」)では、どれも出ない(いまと同じ)
- オート: 手動と同じに出す(見て楽しむ試合なので)。「結果だけ見る」では出ない
- 重さ: CSS のアニメーション(位置・大きさ・透明度だけ)。増える部品は1手で多くて25個ほど。絵の読み込みは増えない

## 社長に決めてほしいこと

1. この強さ・長さでよいか(ランク5の全画面カットイン 1.25秒が長いか)
2. 「演出を短くする」をどうするか
   - 案A(推奨): 新しい設定は作らず、試合の速さ(×2・×4)で決める。保存データに触れない
   - 案B: 試合の画面に「技の演出 派手/控えめ(カットインなし)」の切り替えを足す(端末に新しいキーで覚える)
3. 同じ試合でランク5を何回も撃つと毎回1.25秒増える。2回目からは帯(短い方)にするか
