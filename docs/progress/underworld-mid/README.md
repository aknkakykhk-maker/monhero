# シールドの見た目: 今の INFERNO と COCYTUS の違い(社長の質問への答え)

- **ゲージ(層の色)**: 同じ。どちらも 1枚目の淡い黄 → 黄 → 橙 → 赤 → 深紅、①〜⑤の印、本体のライフは紫
- **割れ方**: 同じ。赤い縁取り → 光が集まって揺れる → 白い光と破片が飛ぶ「SHIELD BREAK!!」→ 帯「🔥 ○○が怒った!」(COCYTUS でも帯は🔥のまま)
- **違うのは左の大きな札だけ**: INFERNO は「🔥 INFERNO」の橙、COCYTUS は「❄ COCYTUS」の水色の見出しと内側の水色の縁
- 別の演出は COCYTUS のボスの蘇り(凍りつく → 砕ける → 蘇る)だけ。これはシールドではなく蘇りの演出

## 気になる点(決めてほしい所)

- **長さ**: 全部出すと約3秒。毎WAVE(10回)出すと30秒ふえる。案: その挑戦の**最初のWAVEとボスのWAVEだけ**長い形、ほかは短い形(0.5秒)。長い形の間に画面をタップしたら短い形へ飛ばす
