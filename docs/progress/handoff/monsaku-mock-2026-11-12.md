## はまった所(足す)

- 手元の `main` が古いことがある。ブランチは `git fetch` のあと `git checkout -B 名前 origin/main` で切る
- シェルの heredoc に JS(バッククォート)を入れるときは `<<'EOF'`(引用つき)にする。引用なしだと壊れる
- 撮る道具は `NODE_PATH=$(npm root -g) node shoot-v3.js <フォントの files>`(入っている playwright を使う)。撮ったあとに 256色に落とす。`tools` で検査する前に `cd tools && npm ci`
- 絵のファイルがない名前(`undine`・`plant`)を使うと「読めない絵」で止まる。`monster-hero/images/monsters/` にあるものを使う

## 決まっていること(見本に入っている・台帳にもある)

- メイン: 案A。子は高さの約34%。景色は季節と時間で替わる(見本は昼)。上の帯は会話・大会の間も出したまま。助手の一言は帯の下。左に編成の6体(いつも出す)。左下に持ち物・右下にくわしく
- ボタン: 上の段 休む・訓練(大)・能力(能力ポイントの数字)/下の段 通院(いつも置く・ようすが無いとき薄く)・遊ぶ・修行(🎫 枚数)・大会
- 訓練: ボタンは絵・名前・小さな Lv だけ。友情タッグのある訓練は光る。マイナスなし。軽い/重いの切り替えなし。訓練Lv(最大5)とトレ経験値は選んだあとに見せる
- ごはん: 大会のあとのごほうび(メインにもターンのはじめにも置かない)
- 修行: チケットの数だけ。2段で能力2つ → 最後に技のくじ → 覚えられなかったら次の率アップ。編成の補正がかかる
- 大会: 優勝したことのある大会はスキップ(結果だけ)。負けたら「時渡りの砂時計」「虹の時渡りの砂時計」で1回の育成に3回までやり直し(名前と効果は社長の指示で参考のゲームのもの・絵は新しく)
- イッサ博士の成功の率は点4つ。編成の子の連続イベントの技の伝授は、その子が持つ技
- 呼び方: 「編成」「助手」「体力」(「応援」「コーチ」「げんき」は使わない)
