## はまった所・やってはいけないこと

- **モンサクの更新履歴には必ず `releaseFlag:'monheroSuccess', dev:true` を付ける**(status:'new' は付けない)。モンサクは公開前。付け忘れると本番の全員に出る(dev-entry-check ⑦ が止める)
- モンサクの本番の HOME の入口は RELEASE_FLAGS.monheroSuccess が偽なので出ない。「本番で見る所」はデバッグの入口から
- 60-app の BGM の effect の依存の並びは、検査が文字で見ている(monsuc-arena-check は `assistantLifeOpenNow, battleBgmOverlay]);`、bgm-arrangement-check は `bgmArrangement, runMode, … battleBgmOverlay]`)。足すなら `audioOn,` のうしろ
- 画面の高さは 100dvh / 100vh を直に書かない。`var(--mh-vh)`(viewport-height-check)
- 画面の要素を場の外へ広げると「横にはみ出さない」検査が要素の枠で数える。広げるのは ::before にする(#6056 の .msa-pan .msa-bg::before)
- 台本の正本は docs/progress/player-raise/script/*.js。生成物(data/monhero-success-script-*.js)を直したら node tools/success/build-script.js
- 音つきの録画: docs/progress/player-raise/wip/rec-motion.js(Tone は cdnjs に出られないので npm pack tone@14.8.49 の build/Tone.js を TONE_JS で渡す。音のずれ REC_AV 既定 0.12 秒)。バトルの移動の録画 docs/progress/player-raise/wip/rec-arena-move.js(TRACE=1 で立ち位置を記録)
- run-checks を回しているあいだに作業ツリーを書き換えない(古い中身で回る)。並行で直すときは git worktree を使う
- docs/progress/player-raise/shots/beta-2026-11-13/lock.png は検査が撮り直して変わる。コミットしない(git checkout で戻す)
