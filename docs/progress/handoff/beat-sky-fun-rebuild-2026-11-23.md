## なぜ単調になったか(前の会話で分かったこと)
- 言葉の頭をほぼ全部タップにし、帯は「声の伸ばしが長い所」だけにした。声の分離の音源では伸ばしが短く出るので、帯がほとんど生まれなかった
- スライドは「なめらかにつながる2音」だけ。メロディの上下を追う形が少ない
- 区間ごとの違いは「どちらの手が歌うか」だけで、形(交互・階段・同時押し・帯+タップ)の変化が無い

## 作り直しの方針(案。迷ったら窓口へ)
- 曲の展開ごとに手触りを変える: Aメロ(3.4〜49秒)=歌う手の階段+伸ばしのホールド / Bメロ・掛け合い=1行ずつ左右の受け渡し+行末のフリック /
  サビ=両手の同時押し・メロに沿うスライド・HELL は空中 / 落ちサビ(126〜146秒あたりの静かな所)=長いホールドとゆっくりのスライド / 2人・ハモり=左右対称のスライド・山場の見せ場 / 間奏=伴奏の交互
- 歌のメロディ(声の高さ `semitone`)の上下を、2〜4音まとめた**スライド**にする所を増やす(歌う手の側だけ=交差しない)
- 伸ばしの判定は声の長さだけでなく「次の言葉までの間」も使う(1拍以上空く言葉はホールドにしてよい)
- 目安: MASTER・HELL の帯の割合 10% 以上・EXPERT より多く・タップ 90% 未満。同じ形のくり返しを減らす
- 守る: 歌い分けの手の割り当て(r1119-105)・手の決まり・押さえ中の交差0・親指2本の押せない0・段変えの上限(r1119-090)・ノーツ数の目安・`rhythm-chart-review.js` の帯。記録はそのまま(r1119-105)
