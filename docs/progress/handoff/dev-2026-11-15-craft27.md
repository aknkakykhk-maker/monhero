## 048 の原因(曲の仕組みの要点・091 にも使う)

- モンサクを開いている間の曲は `SuccessSound`(`14-success-sound.jsx`)だけが決める。60-app の BGM effect は `successScreenOpen` の間は何もしない。`useMhBattleBgmHold` はモンサクの中では効かない
- 場面→曲の表は `monster-hero/data/success-sounds.js`(cupPre=monsuc_cup / cupMatch=ichika_battle / cupWin=monsuc_win / cupLose=monsuc_lose)。画面は `useSuccessScene(場面id)` を呼ぶだけ
- 原因: `MsxR3Battle`(`56-monhero-success-r3-cup.jsx`)は、デバッグの流れ(「勝ったことにする」→「決勝へ」)だと札からあとを `MonsucCupShow startAt='card'` で出すのに、場面の式が `showOn`(デバッグでないとき)の場合しか部品の段(`onPhase`)を見ていなかった → ずっと cupPre。`showView` で直した
- 追加の守り: `SuccessSound.keep(場面, 季節)` = 実際の曲(`Audio_.currentBgmKey`)と違えば鳴らし直し、止まっていれば `ensurePlaying`。試合のあいだ 1.5 秒ごとに呼ぶ。`success-sound-check.js` の許可の一覧に `ensurePlaying` を足した
- 試し方: `tools/success/success-r3-shoot.js` の W1 は `SuccessSound.scene` の呼び出しを `__bgmLog` に記録する。`Audio_.playBGM` も包めば実際の曲まで見える
