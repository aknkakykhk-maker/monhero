## r1115-075 同じ間合いで同じ評価が並ぶ技

オリジナルモンスター5体(パンドラ・エイキ・剣士モッチー・クロミー・メロディ)の全技を、**同じ間合い・同じ評価(ダメージ・命中・ガッツダウン・クリティカル)** で比べた。
並んだ組の1つ目はそのままにし、2つ目からを、ピクシー種の技の散らばり方にならった「型」に変える(威力の合計の釣り合いはランクの中で保つ)。

- 型: 命中型 = 威力 ×0.8・命中 +10・クリティカル −4 / クリティカル型 = 威力 ×0.9・命中 −8・クリティカル +9 / ガッツダウン型 = 威力 ×0.85・ガッツダウン +9 / 重撃型 = 威力 ×1.12・命中 −7
- 効果(バフ・デバフ)は試合の芯にまだ無い(技の効果は「当たったあと動く(moveTo)」だけ)。資料の「効果」の差は、まずこの数字の差で付ける。効果そのものを足すのはバトル部と別の頼みで
- パンドラはガッツダウン(11)・クリティカル(12)がほぼ全部同じなのも単調なので、下の065 の新しい技で散らす
