# r1113-040 と r1114-011 の確かめ(クラフト31)

## ② r1113-040 同じ月に同じ賞品の大会を並べない・名前だけ違う大会は中身を変える
`SUC.EX_CUPS`(55個)を、期・月ごとに並べて確かめた(`tools/success/load.js` で核を読んで数えた)。
- 同じ期・月・格・賞金で並ぶ大会の組は14組。うち、**賞品(bag)も、ごほうび(rw)も同じ**だったのは次の2組だけ:
  - ミドル 8月: 協会会長賞(春)・モンヒロ新聞杯(春) … `rw: { all:2, pts:10, pop:6, loy:3 }` が同じ
  - プロ 10月: 協会会長賞(秋)・モンヒロ新聞杯(秋) … `rw: { all:3, pts:15, pop:8, loy:3 }` が同じ
- そのほかの組(パワフル杯とブレーン杯・エナジー杯とクレバー杯など)は、ごほうびの能力が違う(丈夫さ/かしこさ・ライフ/回避)ので条件を満たしている。賞品の果実・秘薬を持つ組も、中身が組ごとに違う果実・秘薬
- **直した**(monster-hero/data/monhero-success.js の「協会会長賞・モンヒロ新聞杯」の行): 価値は同じまま中身を変えた。協会会長賞=忠誠度寄り(春 人気+4・忠誠度+5 / 秋 人気+6・忠誠度+5)・モンヒロ新聞杯=人気寄り(春 人気+9 / 秋 人気+11)。人気+忠誠度の合計は春9・秋11で、前と同じ。全能力・ポイント・賞金・修行チケットは変えていない
