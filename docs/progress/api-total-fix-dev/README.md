## 直さなかった物(確かめた結果)

- ① 窓の頭が切り欠き・時計の帯にかかる(HB2・HB3・OV1・OV2・OV4・M1D・S2FD・S2FT): **空振り**。外枠 `.msx-wrap` が safe-area を空けているので、帯を外枠ごと再現すると窓の頭は 61px・戻る/中断は 51px(帯 47px より下)。点検の撮影は外枠に帯を入れていなかった
- ① 子の詳細で技の中身が「閉じる」の後ろに隠れる(M1D・OV4・S1F・S1ZD・TP1): 升を押すとその技の中身まで送り、全部見える(M1DT)。開いた直後の最初の技が少し覗いているだけなので、遊べない物ではないと判断して触っていない
- ① みゅあの絵の左が「絵の中で縦22%まっすぐ切れる」: 大会受付 K1 を撮って見たが、羽が箱の端に触れる程度で読めない・押せない物ではない(絵そのものの直しは画像の決まりで別)
- ③ ヘルプの「揺れ」のうち、公開フラグで片方しか出ない物(モンヒロビートの本オープン前の文・助手の人数の段落・育成ノート 20/60・家具の置き方): 画面に出るのは1つだけなので空振り
