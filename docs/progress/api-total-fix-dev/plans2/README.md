## 見てほしい所

- 1 マーケット: 横はどちらの案も左の列(吹き出しの下)の空きは残る。案Aは横長の札が横の画面にも合う
- 2 ダイヤショップ: 全部見える札は、今が縦6枚・横3枚、案Aが縦9枚・横8枚、案Bが縦12枚・横6枚。どちらも「詳細」の小さなボタンが無くなる
