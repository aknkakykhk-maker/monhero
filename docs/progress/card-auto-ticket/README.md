# 案: セッション券1枚で「オートで挑む」のごほうびを1回ふやす(2026-11-07)

社長「セッション券1枚でオートごほうび1回分を復活できるようにしたい」(台帳 2026-11-07)。**案だけ。作るのは社長のオッケーのあと。**

## 止め絵

- `案-デッキえらびのボタン.jpg` … ほかのブリーダーと戦う前のデッキえらびで「🤖 オート」を選び、今日のごほうびを使い切ったときの見た目
- `案-確認の窓.jpg` … ボタンを押したときの確認の窓

(画面には入れていない、描いた案。見た目は今のデッキえらび(87-card-deck-pick.jsx)と確認の窓(41 の ConfirmSheet)の作りを写した)

## 1. ボタンの場所

- デッキえらびの「オートで挑む」の説明の欄(`data-card-deck-pick-auto-note`)の中。「今日のごほうびは終わりました。ごほうびなしで遊べます」のすぐ下
- 出すのは「🤖 オート」を選んでいて、今日のごほうびが0回のときだけ(残りがあるときは出さない)
- ボタンの下に小さく「持っているセッション券 N枚・今日ふやせるのはあと M回」
- 券が0枚のときは、ボタンを押せない形にして「セッション券がありません(モンヒロビートのランクが上がるともらえます)」
- 今日ふやせる回数を使い切ったら、ボタンは出さず「今日はこれ以上ふやせません」

## 2. 確認の出し方

確認の窓(ConfirmSheet と同じ形)で、次を見せる。

- 題: 「セッション券を1枚使いますか？」
- 「オートで挑むの今日のごほうびが1回ぶん戻ります。」
- 2つの数を並べる: セッション券「7 → 6枚」・今日のごほうび「0 → 1回」
- 小さく: 「ふやしたぶんは今日(朝4時まで)だけ使えます。今日ふやせるのはあと3回です。」
- ボタン: 「1枚使って1回ふやす」/「やめる」

## 3. 1日の上限(おすすめ: 1日3回まで)

- **おすすめは「1日3回まで」**。もともとの1日の回数(3回)と同じ数にそろえる。毎日のごほうびが最大6回になる
- 上限なしにすると、券をためた人が1日に何十回もごほうびを取れて、「1日はじめの3回だけ」(2026-11-02 案3)の決まりが意味を持たなくなる
- ほかの案: 1日1回まで(いちばん控えめ)/上限なし

## 4. 保存の形(既存キーの意味を変えず、足す形)

- いまのキー `mh_card_auto_reward_v1 = { v:1, day, n }`(n = その日にごほうびをもらった回数)は**意味を変えない**
- 同じ値に項目 `extra`(その日に券でふやした回数)を**足す**: `{ v:1, day, n, extra }`
- 残りの回数は `max(0, 3 + extra - n)`。`extra` が無い・壊れている・0〜3の整数でないときは0(今までの人は今までどおり)
- 日が変わったら `n` と同じく0に戻る(`cardAutoRewardNormalize` で `day` が今日でなければ0)
- ジン部長の「今日(11/7)の分を全員リセット」(一度きりのフラグ)とはぶつからない(`n` を0にしても `extra` は別に数える)。作る段で main を取り込んでから

## 5. 券を減らす処理

- 今あるセッション券の減らし方: **60-app.jsx の `consumeBuddyTicket`**(モンヒロビートのマルチでマスモンを呼ぶとき)。持ち物 `mh_owned_items` の `RHYTHM_BUDDY_TICKET_ITEM_ID`(= `'session_ticket'`、33-rhythm-buddy.jsx)を1減らして保存する
- 返すとき: **60-app.jsx の `refundBuddyTicket`**
- MFバトルカードの画面(84 の CardBattleScreen)には今、持ち物と券の関数を渡していないので、60 から「券の枚数」と「1枚使う」を渡す形にする(同じ `consumeBuddyTicket` を通す。別の減らし方は作らない)
- 順番: 券を1枚減らす → `extra` を1足して保存。足す保存に失敗したら `refundBuddyTicket` で1枚返す(券だけ減ってごほうびが戻らない、を作らない)
- ランキングへは何も送らない(ごほうびの回数は端末だけ)
