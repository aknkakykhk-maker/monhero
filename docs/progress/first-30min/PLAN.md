# はじめて遊ぶ人の最初の30分 ― 点検と改善案(2026-11-11・開発部ハジメテ)

社長「Fableで良くなりそうなのどんどん進めて」を受けて、セーブ無しのブラウザで本番と同じ main を開き、
はじめての人の道筋を縦(390×844)と横(844×390)でたどった。

## 道具(何度も回せる)

```
node tools/boot/first-30min-walk.js            縦と横(約5分)。最後の1行が OK / NG
node tools/boot/first-30min-walk.js --portrait --detail --out <置き場>   場面ごとの表と止め絵
```

- 保存先は毎回まっさら。Supabase への通信は全部ふさぐ(ランキングへ書かない)
- 出るもの: 場面ごとの手数・読む字数・押せるボタンの数・重なっている窓・止め絵、気づき(種類つき)、`report.json`
- NG は「進めなくなる気づき」([隠れ]・[行止]・画面の例外)があるとき。**いまは NG(2件)**。下の案1を直すと OK になる
- 調べものの道具なので `run-checks` には入れていない

## いまの数字(縦・横とも同じ)

| 見たもの | いま |
| --- | --- |
| 起動して「TAP TO START」が出るまで | 約1.5秒(手元の速い回線) |
| 最初のごほうび(ログインボーナス)が**見える**まで | 10手・人なら約1分半 |
| 村の案内 | 「次へ」11手(全12話) |
| れんしゅう(バトルのチュートリアル) | **全80手**。最初に自分で押すまで「次へ」7手 |
| HOME に着いたとき勝手に始まるお話 | 「みゅあ杯、はじまるよ！」**全70話**(横は54話) |
| HOME で押せるボタン | 19個(横18個) |
| ひと通り(入口だけ)見て回る | 112手・読む字 約5,800字・人なら約12分 |

機械で見られなかった所: れんしゅうのバトルの中身と、本番のバトル1回の結果・報酬(カードを選んで出す所は人の目で見る)。

## 迷う所・待たされる所(止め絵は `shots/`。`p-` は縦、`l-` は横)

1. **進めなくなる**: 名前を決めた直後、ログインボーナスの窓が出たまま、その上で村の案内とれんしゅうが進む。
   案内が指している建物は窓の下で見えず(`p-06-村の案内.png`・`p-村の案内-バトルを指している.png`・`l-06-村の案内.png`)、
   れんしゅうの「押してみて！」で光っている所も窓の下で押せない(`p-09-れんしゅう-押す所が隠れている.png`・`l-09-…png`)。
   ログインボーナスの「閉じる」を押せば進めるが、どこにもそう書いていない。「ギフトを確認」を押すと、れんしゅう中にギフトの画面が開く
2. れんしゅうが長い(全80手)。最初の7話は、まだ遊んでいない3つのバトル・3つのモード・ランキングの説明(`p-08-れんしゅうの始まり.png`)
3. れんしゅうを抜けて HOME に着くと、頼んでいないイベントのお話(全70話)がすぐ始まる。登場人物をまだ誰も知らない
   (`p-11-割り込み-…png`)。れんしゅうを断った道筋では、ワンポイントアドバイスの窓の上にお話が重なる
   (`p-れんしゅうを断ったあと-お話とアドバイスが重なる.png`)
4. HOME に「つぎに何をすればいいか」が無い。ギフトに③、ミッションに②の印が付くだけ(`p-12-HOME.png`・`l-12-HOME.png`)
5. れんしゅうの誘いが、前から遊んでいる人向けの文(「新しいれんしゅうができたよ！」「新しく追加されたよ」)
6. 助手えらびが最初の画面で709字(7人ぶんの紹介を読んで選ぶ。`p-03-助手えらび.png`)
7. ギフトでダイヤ150,500などを一度に受け取るが、何に使えるかが出ない(`p-14-ギフト-受け取ったあと.png`)。
   マーケットは通貨の札が4つ並ぶだけで、何が買えるか・まず何を買うとよいかが無い(`p-17-マーケット.png`)
8. 助手ライフ・MFバトルカードは、はじめて開いた時点で押せる所が20個(`p-19-助手ライフ.png`・`p-20-MFバトルカード.png`)

待たされる所(3秒以上)は、手元の回線では無し。鍵のかかった所で開け方の無いものも、たどった範囲では無し。
