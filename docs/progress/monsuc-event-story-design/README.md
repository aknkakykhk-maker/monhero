## 1. いまの作りの問題(要点3つ)

1. **助手のお話(第2〜4話)が、ほとんどの育成で出ない。** 第1話は必ず出るが、第2話以降は「その期のあいだに助手の親密度が 30/50/70 に届いたら」
   という条件で、届かないと**その期を過ぎた時点で残りの話が全部止まる**(次の話が前の期に縛られたまま進まない)。
   出た割合は 編成なし **0%** / B 6体 **8%** / S 6体・仲良し Lv5 でも **28%**。社長の「何が何だか分からない」の一番の原因は、
   見出しより先に「話が1話で途切れている」こと。前の点検(#6840 D-2)の「各話 40% で抜ける」は半分だけ正しく、本当の詰まりは親密度の門。
2. **イベントが多すぎて、種類の区別がつかない。** 1回の育成(46ターン)に、ランダムの育成イベント約29回+編成の子のイベント約15〜17回+助手のお話+博士で
   **約47回**。2つ以上が同じターンに重なるターンが **約11回**。見出しは「メインのお話」「育成イベント」「編成のモンスターのイベント」の3つの言い方だけで、
   助手のお話(第◯話)と助手だけの出来事(4つ)が同じ「メインのお話」の札で出る。何話目か・誰の話か・続きがあるかが見分けられない。
3. **「受け継ぐもの」(編成の子の第3話)で、何を受け継いだかが伝わらない。** 画面は「ライガーとの出来事 第3話」と小さな札「⚔ 技『もちき』を覚えた!」だけ。
   - 教えてくれた子の**どの技が元か**が出ない。育てる子が同じ技を持てないときは「同じ役割の別の技」を覚えるが、その説明が無いので「ライガーに教わって『もちき』?」になる
   - 半分くらいは技を覚えずに「熟練 +10」になる(B 6体で 1回の育成に 第3話 1.6回のうち技 0.8回・熟練 0.8回)。**ベースモンからは必ず熟練 +10**(技を教えない作り)で、理由が画面に出ない
   - 出るのが遅い(初めて出るターンの中央値 **35ターン目**・プロ期)。台本には「{tech}を教わる/自分のやり方で強くなる」の2択と `{tech}` 入りの台詞があるが、
     画面は選択肢を出さず、`{tech}` に何も渡していない(台詞を引くと「ひと呼吸のあと、技。」になる)
   - 「その1〜3」の並び(1話→2話→3話)が画面に出ず、2話の時点で「次は技を教わる」という予告も無い

## 2. いまの作りの洗い出し

### 2-1 種類ごとの出方(芯のどこで・いつ・どの条件・順番)

1ターンの順番(画面 `56-monhero-success-main.jsx` と試算が同じ): **助手のお話 → ターンのはじめの出来事(助手だけの出来事・ランダム) → 行動 → トレーニングのあと(編成の子・ランダム) → 博士 → 大会のあと(ランダム)**。
1ターンにいくつ出してよいかの上限は無い。

| 種類 | 芯 | 出る条件 | 1回の育成で(みゅあ・40周の平均) |
| --- | --- | --- | --- |
| 助手のお話 第1〜4話+特別 | `storyDue`・`storyStep`・`ASTORY` | 第N話は決まった期(デビュー/ジュニア/ミドル/プロ)の中で、助手の親密度 0/30/50/70 以上のターンに 40%、期の最後のターンは必ず。**親密度が届かないまま期が終わると、その後の話は出ない**。特別は仲良し Lv5・いい結末・最後の期の1〜2ターン目 | 第1話 100%(3ターン目)/ 第2〜4話 編成なし 0%・B6 8%・S6 Lv5 25〜28% |
| 助手だけの出来事(uq) | `monhero-success-events.js` の `uniqDue`・`monhero-success-arc.js` の `ARC.mua.uniq` | 4つ。各 from〜to のターンに 35%、**to のターンで必ず** | 4回(どの編成でも4つとも必ず出た) |
| 編成の子のイベント(連続 第1〜3話+小さな出来事) | `trainEvent`・`STORY`・`teachFrom` | トレーニングにその子がいたターンに 50%。話を進められる子が先。第1話は親密度 0、第2話 40 で 70%、第3話 60 で 50%。外れたら小さな出来事(自主練・ひと休み…) | 15.7〜16.7回(第1話 5.9・第2話 4.7・第3話 1.4〜1.6・小さな出来事 3.8〜4.5) |
| 第3話「受け継ぐもの」 | `teachFrom` | 教える子の技を新しい順に見て、同じ技を持てれば その技、持てなければ同じ役割の技。それも無い・技が上限・ベースモンなら熟練+10 | 技 0〜1.0回・熟練 0.4〜1.3回。初めて出るのは 35ターン目(中央値) |

| 博士(大きな賭け) | `issa` | 率で来る | 少数(ここでは数えていない) |

## 4. 設計の案

### 4-1 イベントの整理(出方の決まり)

**種類を6つに分け、帯の色と言い方を固定する**(画面の文は「イベント」に統一・Q-5-5)。

| 種類(帯の言葉) | 帯の色 | 中身 | 出る時期・回数の目安 |
| --- | --- | --- | --- |
| メインストーリー | 橙 | 助手のお話 第1〜4話+特別+結末 | **決まったターンに必ず**(4-3)。5〜6回 |
| ◯◯の日々(助手だけの出来事) | 桃 | 助手ごとの寄り道4つ | いまどおり from〜to のどこか・to で必ず。4回 |
| アシモンのイベント | 青 | 編成の子の連続 その1〜3 と小さな出来事 | トレーニングに居たとき 50%(いまどおり)。連続は最大 子の数×3 |
| 育成イベント | 緑 | ランダムの出来事(日常・季節・目標・体) | 約29回 → **約18回**へ減らす(下の上限で自然に減る分+季節を年2→年1) |
| 大会イベント | 金 | 大会のあと | いまどおり |
| 博士 | 紫 | イッサ博士 | いまどおり |

**重なったときの決まり**(いまは上限なし):

1. 1ターンに見せるイベントは**最大2つ**。「ターンのはじめ」は1つだけ
2. 優先の順: メインストーリー > ◯◯の日々 > アシモンの連続(その1〜3)> 大会 > 博士 > 育成イベント > アシモンの小さな出来事
3. 押し出された物は**消さずに次のターンへ回す**(ランダムは率を持ち越すだけ・助手の日々は to を1ターン延ばす)。メインストーリーのターンには育成イベントを出さない

**見せ方の共通の型**(全種類で同じ場所・同じ順番):

```
[入り]   連続物(メインストーリー・アシモンの連続)だけ、題字の1枚(帯の色・「第2話」「その3」・題・誰の顔)
[見出し] 1行目 種類の帯(色)+ 連続なら番号 例「メインストーリー 第2話」「アシモンのイベント その3」
         2行目 題 例「みゅあの『◯◯』」「ライガーの△△・その3」
[本文]   台詞(いまの話す箱)
[結果]   場面に大きな札(+12 ↑かしこさ・技の札・親密度)→ 下に明細の行(赤字)。「何をもらったか」は必ずこの2か所
[終わり] 連続物は「つづく ▶ 次は ◯◯期」(または「第4話は親密度で結末が分かれる」)の予告の1行
```

- 部品は1つにまとめる: `MsxEvHead`(見出し2行・帯の色・番号)/ `MsxEvTitleCard`(題字の1枚)/ `MsxEvResult`(大きな札+明細)/ `MsxEvNext`(予告)。
  いまの `56-monhero-success-arc.jsx`・`56-monsuc-tevent.jsx`・`56-monhero-success-main.jsx` のイベントの見出しをこれに替える
- イベント図鑑(`56-monsuc-dex`)も同じ6種類・同じ言い方で並べ、連続物は「その1〜3」「第1〜4話」を1行にまとめて見た/まだを出す

### 4-2 アシモンの連続イベント(その1〜3)と「受け継ぐもの」

**題**: 型(攻め・守り・支え・癒し・影)ごとに連続の題を1つ決め、「<子の名>の<題>・その1〜3」にする(題の言葉は台本の段で書く)。

| 話 | 役目 | いまの効き目(変えない) | 足す見せ方 |
| --- | --- | --- | --- |
| その1 | 出会い・その子の得意を知る | 得意の能力 小+・親密度 +10 | 終わりに「つづく ▶ 親密度 40 で その2」 |
| その2 | いっしょに試練 | 得意の能力 中+・体力 −10・親密度 +10 | 終わりに**受け継ぐ技の予告**: 「次は『<教える技>』を見せてくれそう」(技の札を小さく。`teachFrom` と同じ計算で、その時点の見込みを出すだけ・保存しない)|
| その3「受け継ぐもの」 | 技を受け継ぐ | 技を1つ覚える(無ければ熟練+10)・得意の能力 中+ | 下の演出と明細 |

**その3の見せ方**(上から順に):

1. 題字の1枚「<子の名>の<題>・その3 受け継ぐもの」
2. 台詞: 台本の `{tech}` に**教える子の技の名**を渡す(いまは空で「技。」になる)。2択は出さない(台本の choice 行は消す)
3. **継承の演出**: 左に教える子の技の札 → 光の線 → 右に育てる子の技の札。札はバトルの攻撃の札(r1115-184 案A の技の絵・技名・命中・威力・消費ガッツ)を小さくして使う
   - 同じ技を覚えたとき: 1枚が子から子へ移る形 + 「技『A』を受け継いだ!」
   - 同じ技を持てない種のとき: 左「ライガーの『A』(大技)」→ 右「もちまるの『B』(大技)」 + 「『A』を手本に、自分の大技『B』を覚えた!」(**役割の名で、なぜ別の技かを言う**)
   - 技を覚えられないとき: 「技の枠がいっぱい」「もう全部覚えている」と**理由を書いて**、技の札の代わりに「いまの技 全部 熟練 +10」の札
4. 結果の明細: 技の札(大)・得意の能力 +N・親密度 +N。育成の記録(引退のまとめ)にも「ライガーから受け継いだ技: B」を1行足す
5. 芯は保存の形を変えない。`trainEvent` の out に `teach: { from: <教える子の技 id>, to: <覚えた技 id>, same: true|false, why: 'full'|'known'|'base'|null }` を足すだけ(画面に渡すだけ・保存しない)

**出る時期**: その3の初めの中央値が35ターン目で遅い。その2→その3 の親密度の門(60)と率(50%)は変えず、
**メイン画面の編成の顔に「その1〜3」の進み(●●○)と、あと何で次の話か(親密度 60 まで あと12)を出す**。狙ってその子とトレーニングできるようにする。
数(門・率)を変えるかは、見せ方を入れたあとで試算して決める。

### 4-3 助手別ストーリー

**構成(どの助手も同じ枠・中身は助手ごと)**

| 枠 | 時期(必ず出す) | 題 | 役目(骨組みの型) |
| --- | --- | --- | --- |
| 序章 | 1ターン目 | 「<助手>編のはじまり」(いまどおり) | 助手の**目当て**(何を解決したいか)を1つ示す |
| 第1話 | 3ターン目(いまどおり) | 助手ごとに付ける | 目当ての入口 |
| 日々 その1 | 7〜12ターン | 助手ごと(いまの uq) | 寄り道・人となり |
| 第2話 | **11ターン目**(ジュニア期の中ほど) | 助手ごと | 揺れ(目当てを邪魔する物が出る) |
| 日々 その2・その3 | 14〜28ターン | 助手ごと | 寄り道 |
| 第3話 | **23ターン目**(ミドル期の中ほど) | 助手ごと | 試練・**分かれ道**(いまの 3話の2択。結末が分かれる) |
| 日々 その4 | 32〜40ターン | 助手ごと | 寄り道 |
| 第4話 | **39ターン目**(プロ期の最後の大会の前) | 助手ごと | 決着(いい結末/ほろ苦い結末) |
| 特別 | 最後の期 1〜2ターン目 | 助手ごと | 仲良し Lv5・いい結末のときだけ(いまどおり) |
| ヒーローズファイナル前後・結末 | いまどおり | — | — |

- **確率をやめ、決まったターンに必ず出す。親密度の門をやめる**(親密度は第3話の分かれ道と、超グッドエンディングの条件にだけ使う)。
  そのターンが大会の日・けが・家出で出せないときは、次に出せるターンへ回す(期をまたいでも消えない)
- 見出しは「メインストーリー 第2話 / <題>」。第2話からは**入りの題字の1枚に「前の話」の1行**(あらすじ)を出す。終わりに「つづく ▶ 第3話はミドル期」
- 日々(uq)は帯を桃にし「<助手>の日々 その1〜4 / <題>」にして、本編と見分ける

**助手ごとに違う骨組みにする作り方**(台詞はまだ書かない)

台本の形を、話の**中身の設計を先に書く**形にする。`data/monhero-success-arc.js` の `ARC.<助手>` に骨組みを足す:

```js
mua: {
  goal: '……',                        // 序章で示す目当て(1行)
  eps: [                              // 第1〜4話。無い助手は共通の既定に戻る(読み込みは必ず既定を通す)
    { ep: 1, turn: 3,  title: '……', aim: 'この話で示すこと(1行)', stage: 'town',  beat: 'goal' },
```
