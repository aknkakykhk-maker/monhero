## 1. 遊び方

### 【選ぶ①】どこで一緒に演奏するか

| 案 | 中身 | よい所 | 気になる所 |
| --- | --- | --- | --- |
| **A(推奨)ソロにもマルチにも「助手がつく」** | 曲えらびの上に「🎤 助手とセッション」の枠。助手を1人選んで演奏すると、助手が道の横(縦は判定ラインの右上、横は左のすみ)に立ち、コンボ・ミス・サビでひとこと。結果で助手の経験値・ごほうび。マルチの部屋でも自分の演奏に1人つけられる(席は使わない) | 毎回のソロがそのまま育成になる。マスモンのセッション(部屋の席を使う)とぶつからず、両方を同時に使える | 演奏中の場所を少し使う(小さい顔とふきだし・オプションで消せる) |
| B マスモンと同じく部屋の席に呼ぶ | 助手を CPU として部屋の1枠に呼ぶ。助手もスコアを出し、MVP も取れる | 作りの大半を使い回せる | マルチでしか遊べない。マスモンと席を取り合う。「一緒に」より「対戦相手」に近い |
| C 助手専用の「セッションライブ」 | 新しいモード。助手と交互に叩くパートがある専用の遊び方 | いちばん特別感がある | 譜面を作り直すことになり、⑩-2(公開中の譜面は変えない)とぶつかる。重い |

→ A で作り、**「デュオ」(2人つける)**は 3章の仲良し度で開く。B は後で足せる(マスモンの CPU の作りを流用)。

## 2. 助手のセッションLv

- 助手ごとに **セッションLv.1〜50**(新しいキー。絆 Lv.1〜30 とは別に数える。絆は「仲のよさ」、セッションLvは「一緒に演奏した慣れ」)。
- 経験値(1曲): `12 + 難易度×4 + ランク(MF 30・M 20・SS 16・S 13・A 10・B 7・C 5・それ以下 2)`、好きな曲 ×1.3・苦手な曲 ×1.5(苦手を一緒に乗りこえると大きく育つ)。デュオは2人とも同じだけ入る。
- 必要経験値: Lv n→n+1 に `20 + 3n`。

## 3. 助手どうしの掛け合い・親密度によるもの

ナカヨシの仲良し度(`mh_assistant_peer_bond_v1`・ペアごと Lv1〜5)と、プレイヤーとの絆 Lv(1〜30)を**読むだけ**(書き換えない)。
助手とのセッションで2人をつけると、ナカヨシの決まり「同じお話に出る +6 …」と同じく、仲良し度にも +3(1日12までの上限の中)を足してよいか(【選ぶ⑤】)。

| 条件 | 起きること |
| --- | --- |
| 絆 Lv.10 以上 | その助手を「デュオ」の1人目に選べる |
| 仲良し度 Lv.3 以上のペア | **デュオ**(2人つける)。演奏中に2人の掛け合いが流れる(1曲に最大3回)。経験値は2人とも満額 |
| 仲良し度 Lv.4 以上 | デュオの結果に「2人のひとこと」(掛け合いの締め)・ビートP +5% |
| 仲良し度 Lv.5(2人の特別なお話を見たあと) | サビで**合体の演出**(背中合わせ・2人の色が混ざる光。1曲1回)。2人の好きな曲のどちらかを演奏すると「デュオの記念」(プロフィールに2人の札) |
| 2人の好きな曲が同じ系統(例: みゅあ×ももすけ はアイドル系) | その曲で2人とも好み度 +2 |
| 絆 Lv.30(最大)× セッションLv.50 | その助手の「特別なセッション曲」が曲えらびで光る(新しい曲ではなく、好きな曲に専用の結果の演出と台詞) |

- 恋愛にしない・悪口なし・からかっても下げない(台帳)。呼び方は `ASSISTANT_PEER_CALLS` のまま。
- 28ペアぶんの「デュオの掛け合い」は、ナカヨシの台本版の形(`{c}` で呼び方が入る)に合わせる。

### 【選ぶ⑥】デュオを開く条件
A(推奨)仲良し度 Lv3 / B 仲良し度 Lv1 から(いつでも2人)/ C 2人ともセッションLv.20

## 4. 助手ごとの好みの曲

好み度は曲ごとに -2〜+3(遊ぶと動く。苦手な曲も一緒にクリアするたびに少しずつ上がり、+0 を超えると「好きになった」台詞)。
**好き**: 演奏前に喜ぶ・経験値 ×1.3・サビの演出が大きい。**苦手**: しぶる・経験値 ×1.5・クリアすると「乗りこえた」台詞。
1曲目は社長が決めたその助手の曲(カードの対戦曲)。
