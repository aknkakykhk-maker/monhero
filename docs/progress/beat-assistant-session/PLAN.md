## 1. 遊び方(決定: 部屋の席に呼ぶ)

- マルチ(フリーマッチ・プライベートルーム)の部屋の「呼ぶ」に、**「マスモン」「助手」のタブ**を足す。助手を選ぶと、マスモンと同じく空き枠に CPU として入る。
- 回数はマスモンと**同じ財布**: 呼ぶ1人(1体)ごとに無料1回か券1枚。1日の無料3回はマスモン・助手あわせて。1曲も始まらなければ返す(`rhythmBuddySettle` の1本をそのまま使う)。
- 呼んだ人が部屋にいるあいだは何曲でも一緒。呼んだ人が抜けると助手も帰る。人が来て席が足りなくなったら、うしろの CPU から席をゆずって帰り、払ったものを返す(今の `cpuBrain.refund`)。
- 同じ助手は2人呼べない。マスモンと助手は同じ部屋に混ぜられる(部屋は全部で5人まで)。
- 助手も**自分のスコアを出す**(マスモンと同じ作り: 呼んだ人の演奏が終わったときに、セッションLv・曲のなじみ・好み・調子から作る)。MVP も取れる。名前の横に「助手」の印。
- **プレイヤーのスコア・判定は変えない**(④)。助手のスコアは全国ランキング・自己ベスト・マスモンランキングのどれにも送らない。
- 報酬の人数ボーナス: マスモンと同じ1人につき +5%(`RHYTHM_MULTI_CPU_REWARD_STEPS`)。デュオのボーナスは下の3章。

### デュオと席の数

| 部屋の人 | 呼べる CPU | デュオ |
| --- | --- | --- |
| 自分だけ | 4 | 組める(助手2+マスモン2 まで) |
| 人が2人 | 3 | 組める |
| 人が3人 | 2 | 組める(CPU は助手2人だけになる) |
| 人が4人 | 1 | 組めない |

- 人が来て席をゆずるとき、デュオの片方だけが帰るとデュオがこわれるので、**デュオの2人は最後に帰す**(先にほかの CPU から帰す)。どうしても1人ぶん足りないときは2人いっしょに帰り、2人ぶん返す。
- 呼ぶシートで2人目を選ぶとき、仲良し度 Lv3 以上の相手だけに「デュオ」の印が付く。Lv2 以下の2人も呼べるが、デュオにはならない(掛け合いと合体なし)。

### 演奏中・結果での助手の動き

マルチの演奏中は、ほかの人のノーツは見えない。助手は**画面の上の参加者の列**(縦は上、横は左)に顔で並び、そこからふきだしを出す。

| 場面 | 助手の動き | 台詞の例 |
| --- | --- | --- |
| 呼んだとき・待機 | 好きな曲・苦手な曲・はじめての曲に反応(選曲の候補を出すとき) | みゅあ「トリコぢゃん！あたしこれ大好き♪」 |
| 50・100・300コンボ(自分の) | 表情が変わる・ひとこと | きき「いい流れでつね♪ このまま全部いきましょう」 |
| ミスが3つ続いた | 励ます(下げない) | ドラ「どんまいだな、次でとりかえすからな」 |
| サビ(`RHYTHM_SONG_CLIMAX`) | 顔が光る | ソラシド「うぉぉぉ！ここだぜ・・・！」 |
| デュオ・仲良し度 Lv5 | サビで2人の顔が重なり、2人の色の光が道のふちに流れる(1曲1回) | あつ「きゅうこ、ここ合わせるぞ笑」/きゅうこ「おけ〜！」 |
| 結果 | 参加者のカードに助手のスコア・MVP・経験値・Lv.UP・好み度。デュオは2人のひとこと | えるびん「フルコンかな？すごいね、おつかれさま」 |

- ふきだしは1.6秒で消え、同じ曲で同じ台詞は出さない。オプション「助手のひとこと」(全部/少なめ/切る)。
- 顔は 8表情の絵(`images/assistant/face/<id>_<表情>.PNG`)。新しい絵は要らない。
- 選曲: マスモンの `rhythmBuddyChooseSong` と同じく、助手は好きな曲を候補に出しやすい(シャッフル画面の演出だけ。本番の曲は人の選んだ曲から引く今のまま)。

## 2. 助手のセッションLv(決定: Lv.100・マスモンと同じ重さ)

- 助手ごとに **セッションLv.1〜100**(絆 Lv.1〜30 とは別)。
- 経験値はマスモンと同じ式: 1ライブ `20 + 難易度×6 + チームランク(MF 50・M 30・SS 26・S 22・A 18・B 14・C 10・D 7・E 5・F 3)`。
  助手の上乗せは調子の代わりに**好み**: 好きな曲 ×1.3・苦手な曲 ×1.5・ふつう ×1。デュオは2人とも満額。
- 必要経験値もマスモンと同じ `6 + 1.2n`(Lv n → n+1)。

### 助手のスコア(マスモンの作りを使う)

マスモンの `rhythmBuddy` のスコアの作り(Lv・曲のなじみ・難易度の熟練・譜面の難しさの補正・上限とブレ)をそのまま使い、
**調子の代わりに好み**(好き: 少し上がる・ブレ小 / 苦手: 少し下がる・ブレ大)を入れる。性格は持たない(人柄は台詞で出す)。
目安もマスモンと同じ(MASTER Lv.26・初めての曲: Lv.1 約62万 / Lv.50 約83万 / Lv.100 約94万)。

## 3. 助手どうしの掛け合い・親密度によるもの

ナカヨシの仲良し度(`mh_assistant_peer_bond_v1`・ペアごと Lv1〜5)と、プレイヤーとの絆 Lv(1〜30)を**読むだけ**(書き換えない)。
部屋に2人そろって1曲終えると、そのペアの仲良し度 +3(ナカヨシの1日12までの上限の中。決定⑤)。

| 条件 | 起きること |
| --- | --- |
| 仲良し度 Lv.3 以上のペア | **デュオ**(席を2つ使う)。演奏中に2人の掛け合いが流れる(1曲に最大3回)。経験値は2人とも満額 |
| 仲良し度 Lv.4 以上 | デュオの結果に「2人のひとこと」(掛け合いの締め)・ビートP +5% |
| 仲良し度 Lv.5(2人の特別なお話を見たあと) | サビで**合体の演出**(背中合わせ・2人の色が混ざる光。1曲1回)。2人の好きな曲のどちらかを演奏すると「デュオの記念」(プロフィールに2人の札) |
| 2人の好きな曲が同じ系統(例: みゅあ×ももすけ はアイドル系) | その曲で2人とも好み度 +2 |
| 絆 Lv.30(最大)× セッションLv.100 | その助手の「特別なセッション曲」が曲えらびで光る(新しい曲ではなく、好きな曲に専用の結果の演出と台詞) |

- 恋愛にしない・悪口なし・からかっても下げない(台帳)。呼び方は `ASSISTANT_PEER_CALLS` のまま。
- 28ペアぶんの「デュオの掛け合い」は、ナカヨシの台本版の形(`{c}` で呼び方が入る)に合わせる。

## 4. 助手ごとの好みの曲

好み度は曲ごとに -2〜+3(遊ぶと動く。苦手な曲も一緒にクリアするたびに少しずつ上がり、+0 を超えると「好きになった」台詞)。
**好き**: 演奏前に喜ぶ・経験値 ×1.3・サビの演出が大きい。**苦手**: しぶる・経験値 ×1.5・クリアすると「乗りこえた」台詞。
1曲目は社長が決めたその助手の曲(カードの対戦曲)。
