- 本文:
  1. マルチの部屋の「マスモン・助手を呼ぶ」から、助手を呼んで一緒に演奏できます。呼べる回数はマスモンと同じです(1日3回まで無料、そのあとはセッション券1枚)。
  2. 一緒に遊ぶほど、助手の「セッションLv」が上がります(最大Lv.100)。Lvが上がると、ビートPの上乗せ・セッション券・得意の応援・曲の聞きどころなどが開きます。
  3. 助手にはそれぞれ好きな曲と苦手な曲があります。苦手な曲も、一緒に遊ぶうちに少しずつ好きになっていきます。
  4. 演奏中は、画面の左上で助手がひとこと応援します。友情Lv3以上の2人を呼ぶと「デュオ」になり、2人の掛け合いが聞けます。
  5. 2人で1曲演奏すると、2人の友情Lvが上がります。
  6. あなたのスコア・判定・ランキングは今までどおりです。助手のスコアはランキングに入りません。

(§0-3 の確かめ: どれも画面で確かめられる・遊ぶ人に関係がある・出し分けの説明をしていない。サビの合体は見つけたときの楽しみにして書かない)
