# 書き方: 場面 | 話す人 表情 セリフ(表情は normal happy wink surprise troubled angry crying excited)。同じ場面に複数あれば、ゲームがその中から選ぶ(同じ曲で同じ台詞は出さない)
# 場面:
#   join(部屋に来た) / first(はじめての曲) / like(好きな曲) / dislike(苦手な曲)
#   combo(50・100・300コンボ) / miss(ミスが3つ続いた) / climax(サビ) / last(最後の10秒)

#   sp50 / sp80 / sp100(セッションLv.50・80・100 で開く特別な台詞。部屋に来たとき・結果でときどき)
# 守り: 恋愛にしない・悪口なし・下げない・ネタバレなし・プレイヤーは {name}(ゲームがその助手のいまの呼び方に置きかえる。「ブリーダー」と直に書かない・docs/rules/CALL_NAMES.md)
