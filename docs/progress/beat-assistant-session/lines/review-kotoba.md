## 全体で気になること(先に)

1. **ドラの「くさ」が文の終わりの決まり文句になっている**(VOICE: 「くさ」は本当に笑うところだけ)。solo 125・129・136・141・146・154、pair 23・24・92・125・134。下で全部直した
2. **ドラの「〜なんだな」「〜んだな」が多い**(素朴すぎて、ドラの「くだけた男性口調・説明上手」から少し離れる)。半分くらいを「〜だな」「〜だよ」「〜からな」に。持ちネタの膝がひとつもないので、2か所に足した
3. **あつの文の終わり**: 「。」で切れている文がある(あつは文の最後に必ず「笑」か記号)。solo 161・162・185。「すげえ」は少し荒いので「すごいじゃん」に。「とりあえず、いい〜だったな笑」が pair に3回(31・97・145)
4. **きゅうこは「〜」でのばさない**。きゅうこののばしは小さい「ぇ・ぁ・ぉ」(「いい流れだねぇ」「いけるよぉ」)。solo・pair とも文末の「〜」がほぼ全行にあるので、半分以上を「ぇぁぉ」か、のばさない形に。「サビ前で一回引く」が4回(solo 208・228、pair 35・143)
5. **ソラシドが「計算」「表」「〜だぜ」ばかり**(solo 35行中21行が計算・表)。「ぜ・・・」の割合は20%で大丈夫だが、話題が1つしかない。推し(キュービ・オリヒメ)・沖縄の言葉・悔しがり・自分の失敗を笑う、を混ぜた
6. **ききの「〜しましょう」が多い**(VOICE: 「〜しましょう」で固めない)。それと、ききらしい火力推しが1つもないので、climax に1つ足した
7. **えるびん**: 口調はよい。人柄帳のくせ(「おけ！」「いいね」「さすが」・「笑」と「w」・☺️)がほぼ出ていないので2か所に足した。「おつかれさま」が4回
8. song: の曲名・持ち曲は、台帳と食い違いは見つからなかった。**1か所だけ確かめてほしい**: solo 43 みゅあ「トリコはあたしの杯の曲」の「杯」は何のことか分からなかった(MFバトルカードの対戦の既定曲なら「あたしの対戦の曲」)
