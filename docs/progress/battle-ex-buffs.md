# タクティクス(とレイド)の EX で付く強化・弱化の一覧

2026-10-29 セコンドくん(バトル部)。社長の更新予定「EX関連のバフ表示を見やすく」の下調べ。**本体はまだ直していない**。
レフェリーくんが見せ方の案を作るための材料。

- 正本は本体の定義 `TACTICS_EX_SKILLS`(`monster-hero/src/parts/32-tactics-units.jsx`)。仕様書 `docs/spec/TACTICS_EX_LIST.md` には、あとから足した子(キュービ・オリヒメ・スプーキー・ゴースト・メロディー・クロミー・イルミネ・ドリーミィ)が載っていない
- **レイド(ジャック戦・グランドスラム)も同じ定義**(`raidExDefOf` → `tacticsExRoleDefOf`)。ちがいは、ジャック戦(A)だけ使える回数がどの子も2回(`RAID_JACK_A_EX_MAX_USES`)になること。オリヒメは、勇者モンかどうかで「星合の刻」と「焦がれ待つ天ノ河」に分かれる
- **WAVE をまたがない**。「◯ターン」の EX も、「このWAVE」の EX も、WAVE が変わると切れる(`isTacticsExEffectActive`)。数え方は、使ったターンを1ターン目とする
- 回数は「1ランで使える回数」。スネグーラチカだけ「各WAVE1回」

## どの EX でも出るもの(共通)

| 出る所 | 中身 |
| --- | --- |
| 使った瞬間 | EX のカットイン(帯・`showTacticsExCutin`) |
| 使った子の枠 | 「EX×N」(残り回数)。ターンで切れるものは、その子の枠に「⏳NT」(残りターン・`exTurns`) |
| 使った子を押した詳細の窓 | 「EX『名前』 効果中 あとNターン」の1行(`battleUnitStatusOf` の `lines`)。**数字(何%上がるか)は出ない** |
| 距離枠を押した EX の窓 | 名前・説明(desc)・残り回数・残りターン(`tacticsExInfo`) |

## 見えにくい所(レフェリーくんの案の材料)

1. **味方全員に効く EX が、使った子以外の枠・詳細の窓に出ない**: プラント・ユグドラシル・オボロゲソウ・スプーキー・メロディー・ドリーミィ・ミーア・スネグーラチカ。プラント🌱・ユグドラシル🍃は全員の枠に絵が出るが、数字と残りターンが無い。スプーキーの+10%、ドリーミィの+5%、メロディーの↑↓は、どこにも出ない
2. **詳細の窓は、使った子自身の EX の1行だけ**(「効果中 あとNターン」)。どれだけ上がっているか(何%)が出ない。ちから・丈夫さは「いまの値」に反映されるが、与ダメ・被ダメ・連撃・会心・自動回復の変化は出ない
3. **敵に付く弱化**は、敵の弱化一覧に出るもの(サイコロックオン・乱心・悪夢全開・水牢・氷結)と、出ないもの(焦がれ待つ天ノ河・悠久の刻)に分かれている
4. **残りターンの出し方**がばらばら: 使った子の枠の⏳NT・敵の弱化一覧の「残りNT」・🌌/🕯️のT・ユグドラシルの葉の数・パンドラの箱のふた
5. 同じ子に強化がいくつも重なると(自分の EX+ユグドラシル+プラントなど)、枠の絵のまわりの演出が重なって読みにくい(軽量表示・超省エネでは演出が出ないので、その表示では何も分からない)

## 調べた所(見直すときに)

- 定義: `32-tactics-units.jsx` の `TACTICS_EX_SKILLS`、効いているかの判定 `isTacticsExEffectActive`
- 枠の印: `60-app.jsx` の `tacticsSlotCountersAt`、印の絵柄 `22-enemy-and-bond-entries.jsx` の `BATTLE_STACK_MARKS`・`BATTLE_MONSTER_FX`
- 詳細の窓: `60-app.jsx` の `battleUnitStatusOf`(味方)・`enemyDebuffs`(敵)
- レイドの定義: `60-app.jsx` の `raidExDefOf`
