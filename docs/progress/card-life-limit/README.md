## 数え方(作り)

- 新しいキー `mh_card_life_reward_v1` = `{ slot: 時間帯の通し番号(assistantLifeSlotAt().abs), used: { 助手id: 回数 } }`。読むときに slot が今と違えば空(書き換えは対戦のあとだけ)。既存のキーは触らない
- 上がるかどうかは対戦を始めた時点で決める(カード部屋にいる+まだ使っていない)。数える時間帯も始めた時点。試合中に時間帯が変わっても、その試合は 1.5倍
- 数えるのは 1.5倍で本当に増えた試合だけ(もらえる数が0の試合は数えない)。結果を書くのと同じ取引で書く。保存のほうが新しい時間帯なら書かない
- ランキング・杯・マルチ・みんなのデッキ・オート・助手の3つのデッキには関係しない(今までどおり 1.5倍にならない)
- 助手部の 56 は、カード部の口 `cardLifeRewardSpent(id)` を typeof で確かめて読むだけ(HOME の顔の並びから外す・部屋のボタンを灰色に)。居場所は変えない
