# カード部屋のごほうび 1.5倍に「時間帯ごとの上限」を付ける案(案だけ・まだ作らない)

2026-11-08 カード部ルールくん。社長「助手の報酬は1回やったらいなくなるにしたほうがよさそう。それか3回とか上限をつけてるか。ずっといるはバランス崩れそう」「(上限は)その日じゃなくてその時間帯。助手が移動するときにまたリセット」。
いま(#4882)は「カード部屋にいるあいだは何回でも 1.5倍」。

## 1. 数(本物の決め方 `assistantLifeDecide` を120日ぶん回して数えた)

- 時間帯(助手が移動する区切り)は1日に **6つ**(深夜0時・朝5時・昼10時・午後14時・夕方18時・夜21時から。HOME の「あと◯時間◯分でみんなが動く」と同じ)
- 1時間帯にカード部屋にいる助手(8人と会っている人): **平均 0.74人**。だれもいない時間帯 55%・1人 25%・2人 14%・3人 5%・4人 2%
  - 会った助手が少ないとさらに少ない(6人: 平均 0.22人・4人: 0.08人)。よく来るのはソラシド・えるびん(好きな場所がカード部屋)
- 1日の「時間帯 × カード部屋にいた助手」は平均 **4.4**(8人と会っている人)

MASTER の勝ち 200 → 300(1回で **+100** ビートP)で比べる。1試合はおよそ6分とした。

| 案 | 1日に上乗せされる最大(ずっと遊び続けた人) | ふつうに遊ぶ人(1日10戦・2つの時間帯で5戦ずつ)の見込み |
| --- | --- | --- |
| いま(何回でも) | だれかいる時間(1日 約10.8時間)ずっと → 約108戦 → **+10,800** | 5戦 × 2 × 45% → 約4.5戦 → **+450** |
| A 1時間帯 1人1回 | 4.4回 → **+440**(いちばん多い日でも 6×4 = 24回 → +2,400) | 2つの時間帯 × 0.74人 → 約1.5戦 → **+150** |
| **B(推奨)1時間帯 1人3回** | 13.2回 → **+1,320**(いちばん多い日 +7,200) | 2つの時間帯 × min(5, 3×人数) → 約4戦 → **+400** |

- **B を推奨**: ずっと遊び続ける人の上乗せを 1/8 に抑えつつ、ふつうに遊ぶ人はいまとほぼ同じ(+450 → +400)。A は、ふつうに遊ぶ人の上乗せも 1/3 になり、印を見ても1回で消えるので「得した」感じが薄い
- くらべ: マルチの勝ち 800・MASTER の勝ち 200・その日はじめての勝ち +50

## 3. 数え方(作るとき)

- 新しいキー `mh_card_life_reward_v1` = `{ slot: 時間帯の通し番号(assistantLifeSlotAt().abs), used: { 助手id: 回数 } }`。読むときに slot が今と違えば `used` を空に戻す(書き換えは対戦のあとだけ)
- 数えるのは 1.5倍が付いた試合だけ(対戦を始めた時点でカード部屋にいて、上限が残っていて、もらえたビートPが 0 でない試合)。上限の判定も「始めた時点」(試合中に時間帯が変わっても、その試合は 1.5倍)
- 数えるのは結果を書くのと同じ取引の中(二重に数えない)。ランキング・杯・マルチ・みんなのデッキには関係させない
- 助手の3つのデッキ(cardGrowStyle)とは別のキー・別の所なのでぶつからない
