## C. 作り直しが要る大きな直し 上位3

### C1. 最初の面を「前回からの新着」にする
- イベント・新曲・ショップは絵つきの大きい札で上に出す。改善と修正は種類ごとに1行にまとめる。
- 既読になる時を1つに決め、タブ・HOME・札の数え方をそろえる。
- 開催中のイベントは、この面の帯に寄せる案もある(別担当と相談)。

```
✦更新履歴                ✕
[新着 9][すべて][不具合 3]
─────────────
前回(11/25)から 9件
┃🎄イベント 開催中 NEW
┃聖夜の名探偵 〜12/31
┃[絵・小]    [イベントへ▶]
🎵新曲 3件 winter fall…  ▶
👗着替え 4件 ドラ・…     ▶
🔧改善 2件                ▶
🩹不具合修正 3件          ▶
      [すべて既読にする]
```

### C2. 探せる一覧にする(検索・話題と種類の絞り込み・月で畳む)
- 当たった語は覗き見の中で色を付ける。0件のときは「絞り込みを外す」を出す。
- 不具合タブは「対応中」を先頭に固定する(issue の意味は**要確認**)。

```
✦更新履歴                ✕
[🔍 ことばで探す        ]
話題[全部][ビート][バトル]→
種類[新][改善][修正]
─────────────
▼2026年11月 (86)
 11/27 ✦その他 1 NEW
 11/25 🎵ビート 1 NEW
▶2026年10月 (120)
▶2026年9月 (98)
▶2026年7〜8月 (76)
```

### C3. 中身は一覧の中で伸ばさず「詳細の面」で読む
- 詳細は別の面に出す(スマホは下から全面、横はタブレットもスマホも左に一覧・右に詳細)。
- 面の上に要点と行動ボタンを置く。レベルのような数字は表にし、長い箇条は見出しごとに畳む。
- 戻ると一覧の元の位置に戻す。今の「1つだけ開く」で位置がずれるかは**要確認**。

```
← 一覧        11/28 10:00 NEW
クリスマスイベント開幕
[絵・小 押すと拡大]
期間 11/28 10:00〜12/31 3:59
場所 HOMEの「聖夜の名探偵」
[イベントページを開く ▶]
▼物語  ・…
▶レイド
▶ボーナス
[▶予告動画 押すと読み込み]
```
