# 育つ助手の型(MFバトルカードのデッキ)— カード部の受け口

2026-11-08 カード部ルールくん。社長「助手の相談の答えで、助手と対戦のデッキの中身が変わる。強さの段・ごほうびは同じ」。助手部キズナとすり合わせ(案: `docs/progress/assistant-peer/GROW-PLAN.md` の 6)。

## 決めたこと
- 型は8人とも `attack`(攻め)/`guard`(守り)/`normal`(ふつう)。82 の `CARD_AI_STYLE_IDS`
- `normal`・型なし(null)・知らない値は、今のデッキとまったく同じ(1枚も違わない。検査 A)
- 型はデッキを組むときのくせ(`CARD_AI_HABITS`)へ掛ける・足す数(`CARD_AI_STYLE_TUNE`)。prefer・field は今のまま
  - 攻め: 攻撃 ×1.3・守り ×0.75・大技 ×1.1
  - 守り: 守り +0.3・攻撃 ×0.95(掛け算だと守りのくせが 0.2 のみゅあで中身がほとんど変わらなかったので足す)
- えるびんは今の組み方(variants)が型に当たる: attack=blade・guard=shield・normal=mind。型が渡されなければ今どおり毎試合ランダム
  - ★助手部へ: 相談の答えがまだ無い助手には `assistantLifeCardStyle` が null を返すようにしてください('normal' を返すと、えるびんが mind に決まり、今のランダムから変わります)
- 型を渡すのは 84 の助手と対戦だけ(`cardLifeCardStyle` → `cardAiBuildDeck(..., { style })`)。公式杯・個人杯・マルチ・みんなのデッキは今のまま。82 から助手ライフの口は読まない
- 口 `assistantLifeCardStyle(id)` は 56 に受け口だけ置いた(いつも null)。中身は助手部が決める
- 読むだけの口 `cardAssistantDeckPreview(who, styleId, level)` → { monsters, cards, styleId, name }。助手・型・強さで決まった種で組む(毎回同じ並び)
- 対戦の記録(助手と対戦)の `foe.style` に使った型。古い記録・知らない値は `normal` として読む(93 の `cardReplayStyleOf`)
- 画面の言葉(型の名前)は社長の「この文で」待ちなので、まだ足していない。保存のキーは増やしていない

## 型ごとの強さ(プレイヤー役=スターター3つ・1組120試合)
`node tools/card/card-ai-balance.js --levels easy,normal,hard,expert,master --games 120 --style <型>`。表は「ふつうの勝率% / 攻めの差 / 守りの差」(点)。
1組120試合なので、1つのます目(360試合)のぶれは ±3点ほど。差はどれも ±11点以内。

## 方針の上書き(AI が決める plan)の幅(2026-11-08 測った)
`cardAiBuildDeck(db, who, level, rand, { plan })`。plan = { prefer: [カード番号], field: [場のカードの名前], habit: { big, saveGuts, keepGuard } }。82 の `CARD_AI_PLAN_RANGE`。

- prefer: 5〜8枚。受け付けるのは、その3体で組んだときの入れたい度の上位24枚(`cardAiPlanCandidates`。中継役へ送る候補もこれ)。助手らしい札(CARD_AI_DECKS の prefer)は残したまま、そのあとに足す。HARD から(今の prefer と同じ)
- field: 場のカード(種類 fld)の名前 1〜2。助手の場のカードと入れかえる。HARD から
- habit: その助手のもとの値(型のあと)× 倍率。big・saveGuts 0.8〜1.25 倍・keepGuard 0.8〜1.1 倍(`cardAiPlanHabitRange(who, level, style)` が数で返す。中継役へはこの数を送る)
- 幅の外の数は丸め、候補外のカード・場のカードでない名前は捨てる。全部捨てたら上書きしない(`cardAiPlanClean`)

測り方: `node tools/card/card-ai-plan-range.js --corner <0..7> --games 40`。くせを幅の両端に置いた8通り × prefer・field を候補から種でえらぶ(AI がいちばん下手に選んだときに近い)。プレイヤー役=スターター3つ。1つのます目は120試合なので ±6点ほどぶれる。

| 幅 | EASY | NORMAL | HARD | EXPERT | MASTER |
| --- | --- | --- | --- | --- | --- |
| 最初の案(くせ 0.6〜1.6 の数・prefer は使える札なら何でも・助手らしい札と入れかえ) | -16〜+16 | -18〜+13 | -30〜+3 | -38〜+4 | -34〜+11 |
| 2つめ(くせ 0.7〜1.4 の数・prefer は上位24枚・助手らしい札のあとに足す) | (測った・HARD 以上だけ記す) | | -16〜+15 | -27〜+8 | -26〜+12 |
| **決めた幅(くせは助手ごとの倍率)** | -13〜+18 | -11〜+12 | -18〜+8 | -17〜+15 | -13〜+15 |

決めた幅の全体: どの段も -18〜+18点、8通りの平均は -1〜-3点。いちばん下がったのは えるびん HARD -18(くせを全部下の端にしたとき)・ドラ EXPERT -17・ももすけ EXPERT -17。
守りのくせを数の幅(0.7〜1.3)にしていたときは、もとの値が小さい助手(ももすけ 0.6)で上の端が大きく効き、-25点まで下がっていた。
