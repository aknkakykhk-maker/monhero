# カード巡回部: MFバトルカードの見回り一覧

カード巡回部 リプレイ。統括部長の下で、公開中の MFバトルカードを実際のブラウザで遊び回し、怪しい所を集める。

- 回した物: main(8690f6e)と同じ中身をローカルで配信し、Playwright(Chromium)で人のように押して遊んだ。
  本番URLはこの環境のネットワークで開けなかった。
- **本番の Supabase へは1件も書いていない。** 端末の中で GET 以外を止めて偽の返事を返した。
  ゲーム自体にも「自動操作のブラウザからは書き込まない」守り(`26-supabase.jsx` の `sbAutomationWriteBlocked`)がある。
  本番の `card_battle_ranks` に試しの名前が無いことは、読むだけの SQL で確かめた。
- マルチは、既存の `tools/card/card-pvp-browser-check.js`(偽の中継で2台)を写真付きで回した。結果は全部 OK。
- 画面の大きさ: 320×568・375×667・390×844 の縦と、844×390 の横
