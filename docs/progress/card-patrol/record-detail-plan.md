# MFバトルカード: 記録を細かくする案(見本)

カード巡回部(リプレイ)。2026-10-26。**まだ作っていない。社長に見てもらうための案。**

見本の絵: [`img/09-record-detail-mock.jpg`](img/09-record-detail-mock.jpg)(左から ①全体 ②助手ごと ③マルチ。数字は見本)

## 画面

トップの「記録」を、タブ3つにする(いまは1枚の縦並び)。

| タブ | 出すもの |
| --- | --- |
| 全体 | いまの表(助手と対戦の勝ち負け・難易度ごと・ランキングの記録)＋ 勝つまでの平均の番数・いちばん早い勝ち・今日の勝ち・よく使うデッキ/モンスター/技・図鑑の数 |
| 助手ごと | 助手1人ずつの勝ち負け。押すと開いて、投了・最高の連勝・いちばん早い勝ち・難易度ごとの勝ち |
| マルチ | 勝ち負け・いまの強さ(順位)・いちばん高かった強さ・強さの移り(最近20戦の棒)・最近のマルチ |

## 数の出どころ

| 項目 | いまの保存で出せるか |
| --- | --- |
| 勝ち負け・投了・難易度ごと・連勝・今週の勝ち・図鑑 | **出せる**(`mh_card_record_v1` に既にある) |
| 助手ごとの勝ち負け | 一部。`recent`(最近の30戦。だれと・難易度・結果)から分かる分だけ。それより前は分からない |
| 勝つまでの番数・よく使うデッキ/モンスター/技・今日の勝ち・助手ごとの連勝・強さの移り・いちばん高かった強さ | **出せない**。これから数える |

これから数えるぶんは、**新しいキー `mh_card_record_detail_v1` に足す**(`mh_card_record_v1` は書き換えない。CLAUDE.md ⑦)。
読むときは無い・壊れているとき既定値(0・空)。画面には「この記録ができてからのぶんです」と書く。
はじめて開いた時に `recent` から助手ごとの数を1回だけ起こす(`mh_card_record_detail_v1` 自体の中に「起こした」印を持ち、二度は足さない)。

ランキング・Supabase には何も足さない(端末の中だけ)。
