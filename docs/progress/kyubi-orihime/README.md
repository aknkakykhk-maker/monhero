# キュービ・オリヒメ(2026-10-27〜 開発部ズカンくん)

社長「新モンスター2体実装」「2体とも5色マスクを作って」→「更新で予告出したいから染色マスクすすめて、カラー出してほしい」
「ちゃんと染め方ものっけて」。素材は tools/art-sources/kyubi-orihime-2026-10-27/。

## 済んだこと
- 立ち絵の取り込み(高さ916px・256色・ディザなし。ディザありだと暗い髪を染めたとき横縞が出た)
- 案の子(UPCOMING_MONSTER_DRAFTS)へ仮入れ・新しい血統「キュービ」・図鑑の文の案・待機アニメ(体の動きだけ)
- 5色マスク: 社長の見本(元のゲームの色違い=ツワモン)で一緒に色が変わる所を同じ部位にした
  - キュービ ①髪・しっぽ・耳 ②胸の紫・下駄・提灯の紫の房 ③手袋・脚 ④服の白・胸元の毛 ⑤提灯
  - オリヒメ ①髪・耳 ②しっぽ・羽衣 ③外の羽織・手袋・靴下 ④上の着物(帯・リボン) ⑤風鈴
  - 作り方: 色と位置で塗り分けた下書き → 5x5の多数決でちらばりを消す → 部位の決まらない暗い線を3px以内の近い部位で埋める
