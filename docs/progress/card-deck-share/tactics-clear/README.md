# 戦術カードを分かりやすくする(案)

2026-10-31 社長「戦術カードの効果がいまいちわかりづらい。もっとわかりやすい仕組みにできない?」。
分かりにくい所は4つ: ①カードの文が難しい ②組み合わせ方がわからない ③効いているかわからない ④セットしやすい工夫がない。
**まだ作っていない。** 見本の絵と案を社長に選んでもらってから作る(ツナグ・カード部)。

## ① カードの文(文-案A・文-案B)

- 決まり: **条件は「〜とき」、行動は「〜する」で終わる一文**。並べると「もし[倒せる相手がいる]とき → [いちばん良い技]で攻撃する」と読める
- 数字(1.5倍・点数・見込みなど)と例外(特殊技は除く など)は、カードの表から外して「くわしく」(押したとき)にだけ出す。いまの細かい文は「くわしく」としてそのまま残す(判定どおりの正しい文なので)
- 区分ごとのしるし(🎯ねらう相手・❤️ライフ・⚡ガッツ・🃏手札・🛡️受けたとき・📍場・📘基本の型)を名前の頭に
- 作り方: 82 の `CARD_TACTIC_TEXT` に「一文」(短い名前)を足す形(今の名前・効果は「くわしく」へ)。カードの id は変えない(保存は変わらない)
- 246枚ぶんの一文は、作る前に一覧(表)で社長に読んでもらう(前回の「名前と効果」と同じやり方)

## ② 組み合わせ方(組み方-案A・組み方-案B)

- **案A(おすすめ・先に入れる):** 行を「もし〜 なら → 〜」の2段で見せ、行のあいだに「↓ 当てはまらなければ、次へ」、いちばん下に「どれにも当てはまらなければ → 基本の型で打つ」。上の帯に「上から順に見て、**最初に当てはまった1つだけ**を使います」
  - モンスターの枠では、守りの行に「(攻撃を受けたときだけ見る)」、ブリーダーの手に「(ガッツの番・ブリーダーのカードを出すときに見る)」と、**いつ見るか**の札も付ける
- **案B:** はじめての人向けの「おすすめの組み方」(3〜5種)。中の並びを見せたまま選べて、「これで組む」で3体+ブリーダーへまとめて入る。持っていないカードは近いカードで代わり(無ければその行を飛ばす)
  - 「おまかせ」= いまの「おすすめで入れる」(モンスター1体ぶん)を、3体+ブリーダーへ広げたもの

## ③ 効いているか(効き目-案A・効き目-案B)

だいじなこと: **遊ぶ人が自分で打つ対戦では、自分の戦術カードは使われない。** 戦術カードが動くのは、ほかの人が自分のデッキと戦うとき(フリー対戦の「ほかのブリーダー」)・大会・助手の EXPERT/MASTER(基本カード)だけ。だから「自分のカードが働くところを見る場」が今は無い。

- **案A:** 戦術カードで動いたとき、動いたモンスターの上に使った1行を2秒光らせる(「📜 倒せる相手を ねらった!」)。「記録」に「ターン13 ゴーレム: 「倒せる相手がいる → いちばん良い技」で、ディノを攻撃」と残す
  - 出せる所: フリー対戦の「ほかのブリーダー」(相手のデッキの戦術カード)・大会の観戦/振り返り・下の「ためしに戦わせる」
  - 中の作り: 打ち方(82-card-tactics-core の `cardTacticDecide`)は、どの枠のどの行で決めたかを中で分かっている。返す物に `{ row, mi }`(行とモンスターの番号)を足し、`cardAiChooseAction` から盤面へ渡すだけ。基本の型で打ったときは「基本の型」と分かる。**打ち方そのもの(強さ)は変えない**
- **案B:** 戦い方の画面に「▶ ためしに戦わせる」。自分のデッキ(いまの戦い方)を、助手と自動で1戦させて盤面で見る(案Aの光る・記録つき・早送りあり)。終わったら「よく働いたカード」(当てはまって動いた回数の多い順)と「一度も当てはまらなかったカード」(上の行が先に当たっていた・条件がまれ)を出す
  - ためしの対戦は、ビートP・記録・ランク・クエストに数えない(練習と同じ)

## ④ セットしやすさ(一覧-案A)

- カードの一覧の上に「🔍 ことばでさがす」(名前・一文・くわしくを探す)
- 区分のしぼりこみ: ねらう相手・ライフ・ガッツ・手札・受けたとき・場(今の区分をまとめ直す)
- 「持っているだけ」(はじめは ON)・「**このデッキで効く**」(デッキに無い種類の技・全体攻撃の無いデッキの「全体攻撃がある」・ブリーダーのカードが無いデッキの「ブリーダーのカードがある」などを外す)
- 並び: 「★おすすめ順」(いまの行動カードと相性のいい物を上に)・「よく使う順」(自分が登録で入れた回数)
- カードは「しるし+一文」の大きめの2列(文-案B と同じ)。押すと「くわしく」+「相性のいい行動カード」

## 入れる順番(案)

1. **②案A「もし〜なら」の並び+①の一文**(見え方を変えるだけ。打ち方・保存は変えない。いちばん早く効く)
2. **④しぼりこみ・検索・このデッキで効く**(一覧の画面だけ)
3. **③案A 光る+記録**(打ち方から「どの行で決めたか」を渡す。ほかのブリーダーとの対戦で見える)
4. **③案B ためしに戦わせる+よく働いたカード**(3の上に、自動の対戦を足す)
5. **②案B おすすめの組み方・おまかせ**(型の中身は、勝ち方を測って決める)

①の246枚の一文は量が多いので、1と同時に「表」を出して社長に読んでもらい、決まった物から差しかえる。

## 保存データ

- ①②④の見え方・③案A は保存を増やさない
- 「よく使う順」を出すなら、新しいキー `mh_card_tactic_use_v1`(`{ v:1, used:{ [カードid]: 入れた回数 } }`。無い・壊れているときは空)
- 「ためしに戦わせる」の成績は、その場で出すだけで保存しない(残すなら新しいキー `mh_card_tactic_trial_v1`)
- 今のキー(`mh_card_tactics_v1` など)の名前・意味は変えない

## 社長に選んでもらうこと

1. ① 文の形: 案A(一文の言い換え)だけ/案B(しるし+一文のカード)も
2. ② 組み方: 案A(もし〜なら の並び)/案B(おすすめの組み方・おまかせ)/両方
3. ③ 効き目: 案A(光る+記録)/案B(ためしに戦わせる+よく働いたカード)/両方
4. ④ 一覧: 案Aのどれを入れるか(ことばでさがす・しぼりこみ・持っているだけ・このデッキで効く・おすすめ順・よく使う順)
5. 入れる順番(上の案のままでよいか)
