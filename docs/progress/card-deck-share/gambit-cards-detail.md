# 戦術カード ガンビット型・細かく刻んだ版(案)

絵: gambit-big-mock.png(左=組む画面と助手7人の例、右=全カードの表)

## 数とレア
- 合計 142枚 = 条件 98枚 + 行動 44枚
- N 86枚・R 50枚・SR 6枚
- 決め方: 粗い段(ライフ90/70/50/30/10%・ガッツ1/3/5/7 など)はN、間の細かい段(80/60/40/20%・ガッツ2/4/6 など)はR。場をひっくり返す物(相手が大技を構えている・番を飛ばす・切り札・臨機応変・山札切れ・捨て身)はSR
- はじめに配る8枚: いつでも・倒せる相手・相手のライフ50%以下・自分のガッツ3以上・攻める・大技(4以上)を出す・守る・ガッツをためる
- 種族は25枚に分けず「種族を決めた相手」1枚にし、組むときに種族を選ぶ(25種族×1枚にすると集めるのが重くなりすぎるため)
- 勇者モンはバトルカードに無いので「相手のリーダー(1体目に置いた子)」で代えた。相手の予告も無いので「溜めている相手」「相手が大技を構えている」で代えた

## ガチャ(1回300ビートP・N70%・R25%・SR5%)で無理がないか
引いた回数の目安(はじめの8枚を除く134枚。種類ごとに同じ確率として数えた):
- 半分そろう: 約90回(約2.7万ビートP)
- 全部そろう(だぶりをビートPに戻すだけ): 約900回(約27万ビートP)。重すぎる
- **だぶり10枚で、まだ持っていないカードを1枚えらべる(かけら)を足すと: 約350回(約10万ビートP)**
- だぶり5枚で1枚にすると: 約270回
- 助手と対戦の勝ちは1回80〜200ビートPなので、1回引くのに勝ち2〜3回。半分は約200勝、全部はかけらありで約800勝
- 推奨: だぶりは「かけら」にして、10個でまだ無いカードを1枚えらべる形(前に決めた「だぶりは一部ビートPで戻す」の代わり)。または、ビートPに戻すのはそのままで、かけらも足す

## 今の部品で効かせられない物と、作る量の見積もり
- 今の部品で見られる(今ある): 条件・行動の大半。場の数・ガッツ・手札・山札・番・状態(攻撃できない・溜め・空中・全体カード)は、場の中にそのまま書いてある。技の種類・重さ・全体・効き目・ブリーダーのカード・崩しの札は、カードの表にそのまま書いてある
- 新しく数える(新・小): 相手/自分のライフの割合、いちばんライフの低い/高い相手、相手のリーダー、前の番に攻撃してきた相手、回避と防御の先後
  - 「前の番に攻撃してきた相手」は、場の形(リプレイとマルチで同じ物を使う)を変えずに、コンピューターの側で覚える
- 見積もりで作る(新・見積もり): いちばん攻撃の強い相手(その子が使える技の最大ダメージ)、相手が大技を構えている(相手のガッツと残りの山札から)。手札は見ないので外れることもある
- 作る量(行数の目安):
  1. 条件を見る表と、標的を決める所 … 約300行
  2. 行動ごとに手を絞る所(攻撃・守り・ガッツ) … 約300行
  3. 行を上から見る仕組み・受け皿 … 約100行

  5. 持っているカード・ガチャ・かけら・レベル・保存(新しいキー mh_card_tactics_v1 と mh_card_level_v1) … 約500行
