# 戦術カード ガンビット型(案)

絵: gambit-mock.png(左=組む画面のモック、右=30枚、下=助手7人の例)

## 形
- 1行 = 「条件カード」▶「行動カード」。上の行から順に見て、条件に当たった行の行動をする。当たらなければ次の行へ
- いちばん下は、だれにもある受け皿「いつでも ▶ ふつうに打つ」(行数に数えない・動かせない)
- 行ごとに ON/OFF。OFF の行は飛ばす(消さずに残す)
- 行動には「いつ見るか」がある: 攻撃=自分の攻撃を選ぶとき/守り=攻撃を受けたとき/ガッツ=ガッツの番/すべて=どの場面でも。いまの場面に合わない行は飛ばす
- 当たった行の行動で出せる手が無ければ(例: 大技を出す なのに撃てる大技が無い)、その行も飛ばす
- 同じカードは何行でも使える(集めるのは種類)。だぶりはビートPに少し戻る
- 引く: 1回300ビートP(N70%・R25%・SR5%)。はじめに配るのは7枚(条件3+行動4)

## 行の数(バトルカードのレベルで開く)
- はじめ 3行(Lv1)・4行(Lv5)・最大 5行(Lv15)。受け皿は別
- レベルの案は card-level-plan.md のまま(「枠」を「行」と読む)

## 内訳 30枚 = 条件16枚+行動14枚
- 条件: N 8・R 7・SR 1
- 行動: N 6・R 4・SR 4
- 合わせて N 14・R 11・SR 5
- 条件は段ちがいを別のカードにする(ライフ50%/30%、ガッツ3/5、3番目まで/8番目から)

## 助手7人のガンビット(例。どれもいちばん下に受け皿)
- **みゅあ**(全速で殴る・守らない): 1. この攻撃で倒せる ▶ とどめを狙う / 2. いつでも ▶ 守らない / 3. いつでも ▶ 攻める
- **ももすけ**(崩し): 1. 相手の手札4枚以上 ▶ 崩しの札を出す / 2. この攻撃で倒せる ▶ とどめを狙う / 3. いつでも ▶ 崩しの札を出す
- **きき**(溜めて大技・守り): 1. 自分のガッツ5以上 ▶ 大技を出す / 2. 手札に守り札2枚以上 ▶ 守る / 3. いつでも ▶ ガッツをためる
- **きゅこ**(冷静): 1. この攻撃で倒せる ▶ とどめを狙う / 2. 自分のライフ半分以下 ▶ 守る
- **ドラ**(鉄壁): 1. 自分のライフ半分以下 ▶ 守る / 2. いつでも ▶ 守る / 3. 相手の山札10枚以下 ▶ ガッツをためる
- **あつ**(切り替え(今のあつと同じ並び)): 1. この攻撃で倒せる ▶ とどめを狙う / 2. 相手が3体そろっている ▶ 全体攻撃 / 3. 自分のライフ半分以下 ▶ 守る / 4. いつでも ▶ 攻める
- **ソラシド**(山札切れ): 1. 相手の山札10枚以下 ▶ 山札切れを待つ / 2. この攻撃で倒せる ▶ とどめを狙う / 3. いつでも ▶ 崩しの札を出す
- あつは、今のあつの切り替え(とどめ→全体→守り→攻める)をそのまま4行で書いた物。1枚の「臨機応変」でも同じ動きになる
- 「守らない」(助手の受け方)は、みゅあの2行目のように「いつでも ▶ 守らない」で書ける

## 今の部品で作れる所・新しく作る所
- **そのまま使える**: 攻撃の点数(とどめ・大技・全体・崩す・攻める の向き)、守りの選び方、ガッツの番の選び方、切り札、あつの切り替え(これがもともと上から順に見る並び)、ソラシドの山札切れ、ルールくんの条件の案(自分の場1体・ライフ半分・相手の場1体・ガッツ5・相手の手札4・相手が3体・相手の山札10・3番目まで・8番目から)
- **新しく作る**:
  1. 行を上から見て、当たった行の行動の手だけに絞る仕組み(今は「向きの倍率を掛けて全部の手から1つ」。行動ごとに「その向きの手だけを残して、その中で点数がいちばん高い手」にする)
  2. 新しい条件 4つ(相手のライフ50%/30%、自分のガッツ3、手札に守り札2枚、相手が大技を構えている)
  3. 新しい行動 1つ(回避で受ける)
  4. 組む画面(行の並べかえ・ON/OFF・カードの一覧)
  5. 保存: 新しいキー mh_card_tactics_v1 = { v:1, own:{カードid:枚数}, rows:[{c,a,on}], pulls } 。無い・壊れているときは、はじめの7枚と空の行。知らないカードidは消さずに残す
  6. みんなのデッキの登録に、並び(rows)を一緒に載せる(今の作戦の欄に足す形。古い登録は「並びなし=ふつうに打つ」で読む)
- 助手と対戦・マルチの助手の強さは変えない(助手を並びで動かすのは、社長が決めてから)
