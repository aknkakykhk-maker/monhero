# MFバトルカードのレベル(案)— 戦術カードの枠を開けていく

## 1. 経験値の入り方
| 対戦 | 勝ち | 負け | 投了・切断 |
| --- | --- | --- | --- |
| 助手と対戦 | 20 | 8 | 0 |
| マルチ対戦 | 40 | 15 | 0 |
| みんなのデッキと対戦 | 20 | 8 | 0 |
| 練習試合 | 0 | 0 | — |

- その日はじめての勝ち: さらに +30(どの対戦でも1日1回)
- 次のレベルまでに要る経験値: 60 + 20 × いまのレベル(Lv1→2 は 80、Lv10→11 は 260)。上限は Lv50

## 2. 開くもの
| レベル | 開くもの | 目安(助手と対戦・勝ち負け半々) | 目安(マルチ中心) |
| --- | --- | --- | --- |
| Lv1 | 戦術カード 3枠・みんなのデッキの登録 | はじめから | はじめから |
| Lv3 | 戦術カードを引く券 1枚 | 約12戦 | 約6戦 |
| Lv5 | **4枠** | 約30戦(累計440) | 約15戦 |
| Lv10 | 引く券 1枚 | 約100戦(累計1440) | 約50戦 |
| Lv15 | **5枠** | 約200戦(累計2940) | 約100戦 |
| Lv20〜50 | 5レベルごとに引く券 1枚 | — | — |

- 引く券 = 戦術カードを1回(300ビートP分)ただで引ける
- 名前の横などにレベルを出すかは、あとで決める(案では出さない)

## 3. 保存(セーブデータは壊さない)
- 新しいキー `mh_card_level_v1` = `{ v:1, xp, seeded, got:{ 'lv3':時刻, … } }`。無い・壊れているときは Lv1・経験値0
- 経験値は、戦績(`mh_card_record_v1`)を書くのと同じ取引で足す(片方だけ増えない)
- `got` … 引く券を受け取ったレベルの印。二度は配らない

## 4. いまの戦績からはじめのレベルを起こすか
- **起こす(推奨)**: はじめて開いたときに1回だけ、`mh_card_record_v1` の勝ち負けから経験値を作る
  (助手と対戦 勝ち×20+負け×8、マルチ 勝ち×40+負け×15。その日の初勝利の分は入れない)。
  `seeded: true` を同じ取引で書き、二度は足さない。起こした分で届いたレベルの引く券も配る
- 起こさない: 全員 Lv1 から。いままで遊んだ人も同じ所から始まる
