# 基本カード 20種の中身(案)

各カードは「攻撃の選び方・守りの出し方・ガッツの置き方・狙う相手・ブリーダーカードの使い方・やらないこと」を決める。
メインはそのまま、サブは3分の1ずつ効く。どの行にも当たらない場面は、これで打つ。

## N(5種)
### バランス型(はじめに配る・きゅこの型)
- 攻撃: 点数のいちばん高い手。倒せる相手がいれば少しだけ先に倒す
- 守り: ライフの半分以上を減らす攻撃と、倒れる攻撃は守る。小さい攻撃は、守り札が最後の1枚なら受ける
- ガッツ: 3〜4枚をめやすに置く。使えない札・重すぎる札から置く
- 狙い: 倒せる子 → ライフの少ない子の順
- ブリーダーカード: 効き目が大きいときだけ使う
- やらないこと: 極端な手(守り札を全部ガッツにする・ガッツを使い切る大技)
- 説明: 「くせのない、いちばん素直な打ち方。迷ったらこれ」

### 攻め型(みゅあの型)
- 攻撃: 攻撃できる子は全員攻撃する。攻撃を早く終えない
- 守り: 倒れる攻撃だけ守る。それ以外は守り札を残さず受ける
- ガッツ: 少なめ(2枚まで)。手札は攻撃の札を残す
- 狙い: いま当てられる相手をすぐ攻撃(待たない)
- ブリーダーカード: 攻撃を増やす札(もう1回攻撃させる・攻撃できないを消す)を先に使う
- やらないこと: ガッツをためて大技を待つ・守り札を手札にためる
- 説明: 「ためずに、毎ターン全員で殴る。守りはほとんどしない」

### 守り型(ドラの型)
- 攻撃: ガッツと守り札を残せる範囲で攻める。重い技は控える
- 守り: 小さい攻撃でも守る。守り札を2枚以上手札に残す
- ガッツ: 4枚前後。回避・防御の札はガッツにしない
- 狙い: 自分のライフが減ったら、いちばん攻撃の強い相手を先に止める
- ブリーダーカード: 回復・攻撃できないを消す札を優先
- やらないこと: 守り札をガッツにする・自分が傷つく技
- 説明: 「守り札を手札に残し、小さい攻撃でも守る。粘って勝つ」

### 溜め型(ききの型)
- 攻撃: ガッツがたまるまで軽い技は控え、たまったら大技を撃つ
- 守り: ライフの半分以上を減らす攻撃は、ガッツを払ってでも守る
- ガッツ: 5〜6枚まで置く。重い札は手札に残す
- 狙い: 大技で倒せる子・ライフの多い子
- ブリーダーカード: 山札からガッツ・ガッツを増やす札を優先
- やらないこと: 序盤にガッツを使い切る
- 説明: 「ガッツをためて、大技で一気に削る」

### 崩し型(ももすけの型)
- 攻撃: 手札を捨てさせる・攻撃できなくする・ガッツを減らす札を先に出す
- 守り: ふつう(半分以上・倒れる攻撃は守る)
- ガッツ: 3枚前後。崩しの札は手札に残す
- 狙い: 相手の手札が多いとき・相手のガッツが多いときに崩す
- ブリーダーカード: 相手のガッツを減らす・守りを封じる札を優先
- やらないこと: 崩しの札をガッツにする
- 説明: 「相手の手札とガッツを減らして、動けなくしてから攻める」

## R(10種)
### 大技型
- 攻撃: ダメージのいちばん大きい技を選ぶ。払うガッツは気にしない
- 守り: ふつう / ガッツ: 4〜5枚 / 狙い: ライフの多い子にも大技を当てる
- ブリーダーカード: 払うガッツを減らす全体カードを優先
- やらないこと: 小さい技で手数を稼ぐ
- 説明: 「一発の重さを大事にする」

### 全体型(あつの全体の好み)
- 攻撃: 相手が2体以上いれば、全体攻撃・全体カードを先に
- 守り: ふつう / ガッツ: 全体攻撃の重さぶんを残す
- 狙い: 3体まとめて削る(1体だけを狙い続けない)
- ブリーダーカード: 全体カードを場に出す
- やらないこと: 相手が1体のときの全体攻撃
- 説明: 「相手をまとめて削る」

### 仕留め型
- 攻撃: あと少しで倒せる子を最優先。倒せないなら攻撃を止めることもある
- 守り: 次の番にとどめを刺すガッツが残らない守りはしない
- ガッツ: とどめの技の重さぶんを残す
- 狙い: ライフの少ない子 → 倒せる子
- ブリーダーカード: 回避させない付け札・もう1回攻撃させる札を、とどめに使う
- やらないこと: 倒せない相手にガッツを使い切る
- 説明: 「倒せる子から確実に倒す」

### 速攻型
- 攻撃: 軽い技(ガッツ0〜1)で手数を出す。重い技は使わない
- 守り: 軽い守り(ガッツ0〜1)だけ使う
- ガッツ: 少なめ(2枚まで)
- 狙い: 先手で相手の数を減らす(序盤ほど攻める)
- ブリーダーカード: 引く札で手札を増やす
- やらないこと: 大技・重い守り
- 説明: 「軽い技を何度も当てて、序盤に押し切る」

### 堅実型
- 攻撃: 損をしない手だけ(回避されそうな技・自分が傷つく技は出さない)
- 守り: 守り型ほどではないが、守り札を1〜2枚残す
- ガッツ: 4枚前後。次の番に使う札を残す
- 狙い: 確実に当たる相手
- ブリーダーカード: 回復・引く札を、困ったときに使う
- やらないこと: 一か八かの手
- 説明: 「守りとガッツを残して、無理をしない」

### かく乱守り型
- 攻撃: 崩しの札を出しながら、守り札を残す
- 守り: 守り型に近い(小さい攻撃も守る)
- ガッツ: 3〜4枚。崩しと守りの札は残す
- 狙い: 相手の手札が多いときに崩す
- ブリーダーカード: 相手のガッツを減らす札
- やらないこと: 守り札・崩しの札をガッツにする
- 説明: 「相手を崩しつつ、自分は堅く守る」

### 慎重型(きゅこの損得)
- 攻撃: ほかの型の効きを半分にして、極端な手をしない
- 守り: 損得で決める(守ったほうが得なときだけ)
- ガッツ: ほかの型の半分の寄せ方
- 狙い: 点数どおり
- ブリーダーカード: 使って得なときだけ
- やらないこと: くせに引っぱられた手(サブに入れると、メインの型をおだやかにする)
- 説明: 「損得で冷静に打つ。ほかの型をおだやかにする」

### 手札温存型
- 攻撃: 手札を2枚以上残す。引く札は控える
- 守り: ふつう / ガッツ: 手札が少ないときは置かない
- 狙い: 点数どおり
- ブリーダーカード: 手札を引き直す・拾う札で手札を整える
- やらないこと: 手札を空にする
- 説明: 「手札を残して、次の番に備える」

### 山札節約型
- 攻撃: 引く札・山札を減らす札を出さない
- 守り: ふつう / ガッツ: 山札が少ないときは山札からガッツにしない
- 狙い: 長引きそうなら、相手の山札を減らす札を先に
- ブリーダーカード: 捨て札を山札に戻す札を優先
- やらないこと: 自分の山札切れを呼ぶ手
- 説明: 「長い試合でも山札を切らさない」

### 一点集中型
- 攻撃: 同じ相手を倒れるまで狙い続ける
- 守り: ふつう / ガッツ: ふつう
- 狙い: 前の番に攻撃した子 → いちばんライフの少ない子
- ブリーダーカード: 攻撃できなくする札で、狙う子を止める
- やらないこと: 狙いをころころ変える
- 説明: 「1体ずつ確実に減らす」

## SR(5種)
### 臨機応変型(あつの型)
- 攻撃: 場を見て、とどめ・全体・守り・攻めの4つの型を毎番切り替える
- 守り・ガッツ・狙い: そのとき選んだ型のとおり
- ブリーダーカード: 選んだ型に合う札
- やらないこと: 1つの型に固まる
- 説明: 「場に合わせて型を切り替える」

### 持久型(ソラシドの型)
- 攻撃: 長引かせる。相手の山札を減らす札・相手に引かせる札を先に
- 守り: 厚め / ガッツ: 自分の山札が相手より多いときだけためる
- 狙い: 倒しきるより、相手の山札切れを待つ
- ブリーダーカード: 山札を削る全体カード・捨て札を山札に戻す札
- やらないこと: 自分の山札を減らす手
- 説明: 「長引かせて、相手の山札切れで勝つ」

### 捨て身型
- 攻撃: 守り札を残さず、とどめを強く狙う
- 守り: 倒れる攻撃でも、とどめを刺せるなら受ける
- ガッツ: 攻撃に全部使う
- 狙い: 倒せる子
- ブリーダーカード: もう1回攻撃させる札
- やらないこと: 守る
- 説明: 「守らずに受けて、そのぶん倒しに行く」

### 分散型
- 攻撃: ライフのいちばん多い子から削り、相手をばらばらに弱らせる
- 守り: ふつう / ガッツ: ふつう
- 狙い: 毎番ちがう子(全体攻撃・割り振る技を好む)
- ブリーダーカード: 全体カード
- やらないこと: 1体だけを倒しきる
- 説明: 「全員を少しずつ削り、最後にまとめて倒す」

### 逆転型
- 攻撃: 倒された数で負けている・ライフが少ないときだけ、大技と全体攻撃を強く
- 守り: 勝っているあいだは守り型、負けたら捨て身型に切り替える
- ガッツ: 負けているあいだはためる
- 狙い: 相手のいちばん強い子
- ブリーダーカード: 倒れた子を戻す・回復を、負けているときに
- やらないこと: 勝っているときの無理攻め
- 説明: 「追いつめられてから本気を出す」
