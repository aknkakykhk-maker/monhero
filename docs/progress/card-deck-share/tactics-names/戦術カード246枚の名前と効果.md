# 戦術カード 246枚の名前と効果(案)

- 「新しい名前」「効果」は、ゲームの中の実際の動き(82-card-tactics-core の判定)どおりに書いた案です。
- 表には区分を文字でも出します(例: 「条件」「基本」「ブリーダー」「モンスター」)。
- 条件カードと行動カード(ブリーダー・モンスター)は2枚1組でセットします。「〜なら(条件) → 〜する(行動)」。上から順に見て、当てはまって、その手が出せる組の手を出します。どれにも当たらないときは基本カードの打ち方で打ちます。
- 基本カード: メイン1枚はいつも効きます。サブ2枚は重みが3分の1で、「〜だけ守る」などの決まりは3回に1回の番だけ効きます。
- 「点数」… 手ごとの損得(ダメージ・とどめ・ガッツの損得など)を数にしたもの。基本カードの型で重みが変わります。
