# プロフィールの整理案(2026-10-29 開発部クラフト)

社長「プロフィールページもごちゃ付いてきたから、これを機に改良したい」。
きっかけは、MFバトルカードの登録デッキを「好きなモンスター」と同じ見せ方でプロフィールに載せる件(カード部ツナグくん)。
**まだ作らない。** 見た目と並べ方だけの案で、保存キー・ランキング・フレンドの仕組みは変えない。

## 今(写真: 今-*.png)

- **今-1 自分のプロフィール**: タブが無い1枚の長いページ(スマホで約4画面ぶん)。上から順に、吹き出し → 名前・Lv → 6つのタイル(アイコン・フレーム・図鑑・着替え・ひとこと・好きなモンスター) → ダイヤ・ブリーダーP・プレイ時間 → プレイ時間のくわしい記録 → フレンド・アイテム → 助手(仲良し度・ごほうび一覧・飾り枠・助手えらび6人) → バトル記録(大きい札7枚) → モンヒロビートの記録 → イベント回想
- **今-3〜6 フレンドのプロフィール**: 上に名前の大きい札、下にタブ4つ(概要・バトル・曲のベスト・集めたもの)。好きなモンスターは「概要」の下のほう
- MFバトルカードのデッキの欄(CardShareProfileDeck)は、自分では「バトル記録」の上、フレンドでは「遊んだ記録」の上に、大きい欄で入る(写真はデッキを登録していない人なので出ていない)

### ごちゃついている所

1. 「好きなモンスター」が、アイコン・フレームなどの設定のタイルに混ざって、小さな字だけで出ている。人に見せたい物と、設定のボタンが同じ並び
2. フレンドから自分がどう見えるかが、自分のプロフィールでは分からない(並びも違う)
3. 助手の欄が長い(仲良し度・ごほうび・飾り枠・6人の選び方が全部開いている)
4. バトル記録が大きい札7枚で、ページの半分を使う
5. デッキ・カードの戦績など、あとから足した欄が、記録の間に挟まっていく(足すたびに長くなる)

## 案(写真: 案A/B/C-*.png。1案につき自分・フレンドの2枚)

どの案も、**好きなモンスター と バトルカードのデッキ を同じ形の札で並べ**、自分とフレンドで同じ並びにする。
デッキの札を押すと、今の「デッキ登録」の画面(ツナグくんの CardTacticsScreen)をそのまま開く。フレンドのほうは「このデッキと戦う」「借りる」を札の下に置く。

| 案 | 形 | よい所 | 気になる所 |
| --- | --- | --- | --- |
| **A タブで分ける** | 上(名前・ひとこと・好きなモンスター・デッキ)はいつも出す。下を「わたし/助手/記録」のタブに | 1画面に収まる。フレンドの画面(タブあり)と形がそろう | 助手・記録はタブを押さないと見えない |
| **B 1ページのまま並べ替え** | タブなし。上に「見せる札」2枚を横に並べ、着せかえ→お金→入口→助手→記録。記録は1行ずつにたたむ | 今と同じく下へ巻くだけ。見た目の変化が小さく、慣れた人が迷わない | Aより長い(今よりは短い) |
| **C 名刺+メニュー** | 上に「フレンドから見えるあなた」の名刺(フレンドの画面と同じ形)。下はメニューの行だけで、助手・記録は押した先で見る | いちばんすっきり。見せる物と設定がはっきり分かれる | 開く回数が増える(押した先の画面を足す) |

開発部のおすすめは **B**(今の作りを生かして並べ替えるだけで済み、遊んでいる人が迷いにくい)。
