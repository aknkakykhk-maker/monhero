## 1行の形

```js
{ id:'turn.start.great.mua1', who:'mua', e:'excited', t:'{mon}、今日まぢ絶好調ぢゃん✨ 目がキラッキラしてるもん！' }
```

| 項目 | 意味 |
| --- | --- |
| `id` | 場面のid + 「.」+ だれ・番号。**場面のidは最後の「.」より前**。重ならない(見張りが止める) |
| `who` | `mua` / `atsu`(シナリオの助手。選んだ助手の行だけ出す)/ `issa`(イッサ博士)/ `narr`(地の文)/ `choice`(選択肢の札) |
| `e` | 助手の表情(`assistants.js` の `ASSISTANT_EXPRESSIONS`) |
| `t` | 台詞。差しこみは下の表 |
| `c` | 選択肢の記号。`choice` の行と、その選択肢を選んだあとの行に付く |
| `end` | 4話の結末(`good` / `bitter`) |
| `bond` | その助手の仲良し度の段がこの範囲のときだけ出す(みゅあの1話の Lv1・2 はていねい語。`assistants.js` と同じ決まり) |

| 差しこみ | 中身 |
| --- | --- |
| `{name}` | プレイヤーの呼び方(話している助手の、いまの呼び方。CALL_NAMES.md) |
| `{mon}` | 育てているモンスターの名前 |
| `{cheer}` / `{cheer2}` | 編成の子の名前(フレンドから借りた子は「◯◯さんの◯◯」) |
| `{stat}` / `{train}` / `{tech}` | 能力の名前 / 訓練の名前 / 技の名前 |
| `{cup}` | 大会の名前(シナリオの大会は、その期の ★★★ か 👑 から画面側で1つ選ぶ) |
| `{food}` | 苦手な食べ物の名前(種ごと) |

- 同じ場面に2本以上あるときは、くじで1本を出す
- 結果の数字(能力 +中 など)は台本に書かない。画面側が出す。助手は数字を言わない(PLAN §6)
- 地の文・選択肢の札ではモンスターを「子」と呼ばない(`{mon}` か名前)。助手が言うのは「この子」だけ
