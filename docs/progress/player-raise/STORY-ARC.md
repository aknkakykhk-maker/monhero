# モンヒロサクセス 助手1人分のストーリーを通して遊べるようにする(設計・第2版・みゅあ編)

クラフトくん 2026-11-13。社長「モンサクをβ版で公開したいから助手1つ分のストーリーは1連で完成させて」。
助手は **みゅあ**。公開の印 `monheroSuccess` は偽のまま作る(公開の手順は窓口が社長と決める)。
第1版を社長に見せ、答え(2026-11-13・窓口経由)を入れたのが第2版。§6 が決まったこと。作ったものは §8。

## 0. ひとことで

いまある「連続イベント(1〜4話+特別な1話)」と「頂への道(最後の3戦)」に、
**固有イベント・相手えらびと試合前後の掛け合い・3つのエンディング・お祝いイベント・特別演出** を足して、
デビューから引退まで1本の話として通す。仕組みは助手ごとの **表** で持ち、次の助手は「表1つと台本の行」を足すだけで増やせる。

| デビュー期 | 連続1話「得意、いっしょに見つけよ！」 | ある | — |
| ジュニア期 | 連続2話「張り切りすぎた」/ **固有A「写真とろ！」** | 2話はある | 固有A |

| プロ期 | 連続4話「声、届いた？」(いい結末/ほろ苦い結末)/ **固有D「応援うちわ作り」** | 4話はある | 固有D |

## 2. 固有イベント(その助手だけの出来事・みゅあは4つ)

- ランダムイベントの山とは別に、**決まった期のどこかで1回だけ** 起きる(そのターンの出来事の枠を使う。期の最後のターンまでに出なければ最後のターンに出る)
- 1回の育成で各1回。2択(どちらも得がある・数の大きさは EVENTS §3 の物差し)

| | 期 | あらすじ | 2択 |
| --- | --- | --- | --- |
| A「写真とろ！」 | ジュニア | みゅあが{育てる子}の写真を撮りまくる。「この角度、盛れるｗ」 | いっしょに映る(人気 小+・親密度 +5)/ベストショットを狙う(回避 中+) |
| B「おやつ作戦会議」 | ジュニア後半〜ミドル前半 | 手作りおやつを持ってきた。ちょっと焦げてる | いま食べる(体力 中+・ストレス −中)/ごほうびにとっておく(🔥やる気満々) |
| C「夜の電話」 | ミドル | 大会の前の夜、みゅあから「起きてる…？」 | 話を聞く(親密度 +10・ストレス −小)/早く寝よって言う(体力 小+・忠誠 小+) |
| D「応援うちわ作り」 | プロ | 頂への道に向けて、文字入りのうちわを作る | いっしょに作る(人気 中+・親密度 +5)/練習に集中する(主の能力 中+) |

## 3. 頂への道の3連戦(相手はみゅあが選ぶ)

- 戦う日・強さ・負けたら終わり、はいまのまま(1回戦 ×1.2・準決勝 ×1.3・決勝 ×1.4)。**変わるのは「誰と当たるか」と会話だけ**
- 毎戦、試合の前に「みゅあの相手えらび」の会話(相手の札を見せて、なぜこの子かを話す)→ 試合 → 勝ち/負けの掛け合い

| 戦 | みゅあの選び方(表の `pick`) | 前のひとこと(案) |
| --- | --- | --- |
| 1回戦 | 人気がいちばん高い常連(`pop`) | 「いちばん笑顔がまぶしい子、選んぢゃったｗ 負けないくらい笑お！」 |
| 準決勝 | この育成で出会ったライバル(`rival`・いなければ強い常連) | 「…やっぱ、あの子とやらなきゃ終われないぢゃん」 |
| 決勝 | 王者(`champ`) | 「さいごは、いちばん上。{mon}なら届くって、あたし知ってる」 |

- 選び方は助手ごとの表(`pop`・`rival`・`champ`・`strong`・`type` など)。次の助手は表の3行を変えるだけ
- 負けたとき: いまある砂時計でやり直せる(1回の育成で3回まで)。やり直さない・使い切ったらバッドへ

## 4. エンディングの分かれ方

| エンディング | 条件 | 中身(案) |
| --- | --- | --- |
| バッド | 頂への道のどこかで負けて終わる | 夕暮れの帰り道。「…くやしいね。でも{mon}と来れたとこ、ぜんぶ宝物だよ」 |
| グッド | 決勝に勝つ | 表彰台。「{mon}が世界でいちばん！ あたしの声、ちゃんと届いてた？」 |
| 超グッド | 決勝に勝つ **かつ** 育成中のみゅあの親密度が最大(100)**かつ** 連続イベントを完走(4話まで見た・結末はどちらでも)。砂時計を使ってもよい | 表彰台のあと、町じゅうがお祝い。「最高のチームだったよね…まぢで」 |
| (特別演出) | 超グッドなら必ず出る(親密度100が条件に入っているため) | 節目なので長め(5〜6秒): みゅあの全身画+花吹雪+「ふたりの記念写真」の1枚。称号「みゅあの最高のチーム」 |

- **どのエンディングでも育成完了**(保存枠に入る・記録帳・ランキングもいまの引退と同じ)。保存枠の子に、どのエンディングだったかの印を足す
- ゲームオーバー(デビュー戦3回負け)はいままでどおり保存枠に残らない(エンディングなし)

## 5. お祝いイベント(最後に能力が上がる)

| エンディング | 回数 | 1回ごとの上がり方(全能力) | 6能力の合計 | 総合力の目安 |
| --- | --- | --- | --- | --- |
| バッド | 1回「おつかれさま会」 | +5 | +30 | +約100 |
| グッド | 3回「祝勝会」「町のパレード」「みゅあの手紙」 | +10・+10・+10 | +180 | +約570(評価1段ぶん) |
| 超グッド | 3回「町じゅうのお祝い」「ヒーローの取材」「ふたりの打ち上げ」 | +15・+17・+20 | +312 | +約980(評価2段ぶん) |

- 物差し: 試算(B 6体)の中央値は 6能力の合計 約3,050・総合力 約9,600。頂への道を3つ勝ち切る子は約4割
- **いまの「頂への道の決勝に勝ったときの全能力 +8 / 👑ありで +15」はお祝いに置きかえる**(二重にしない。能力ポイント・人気・称号はそのまま)
- 作ったあと試算で、超グッドの子が強くなりすぎないか(SS 以上がいまより大きく増えないか)を確かめる

## 6. 決まったこと(社長 2026-11-13・窓口経由)

1. 連続イベントの1〜4話は、助手ライフの仲良し度 Lv に関係なく見られる(育成中の親密度の条件だけ)。特別な1話だけ Lv5 以上
2. 超グッドの条件は「決勝に勝つ」「育成中の親密度が最大(100)」「連続イベントを完走」の3つ。砂時計なしの条件は入れない
3. 特別演出の「親密度マックス」は、育成中のみゅあの親密度100。→ 超グッドになれば、そのまま特別演出も出る

## 7. 作り方(助手ごとに足せる形)

- 表: `data/monhero-success-arc.js`(新しいファイル)に `mua: { uniq:[A〜D の期と2択の効き], summit:['pop','rival','champ'], fx:{ special:'photo' } }`。お祝いの数字は芯で全助手共通
- 文: 台本 `docs/progress/player-raise/script/` に `scn.mua.uniq.*`・`scn.mua.summit.r1〜3.(pick|win|lose)`・`scn.mua.end.(bad|good|super)`・`scn.mua.party.*` を足し、`build-script.js` で生成物へ
- 芯 `monhero-success.js`: 固有イベントの出る時期・効き/頂への道の相手えらび/エンディングの判定/お祝いの能力。試算 `success-sim.js` に入れる
- 画面: 出来事の画面(いまの連続イベントと同じ形)・相手えらびの会話・エンディング・お祝い・特別演出
- 保存(⑦): 育成中の状態に `arc`(見た固有イベント・やり直しの有無・エンディング)を足すだけ。読み込みは無い/壊れているときの既定値を通す。
  保存枠の子に `ending` を足す。既存のキーは変えない
- 止め絵(窓口へ): 固有イベントの会話/相手えらびの会話/試合後の掛け合い/バッド・グッド・超グッド/お祝い/特別演出
