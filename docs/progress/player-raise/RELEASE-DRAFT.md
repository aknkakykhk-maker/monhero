# モンヒロサクセス 公開のときの更新履歴・ヘルプ・助手の告知(下書き・第1版)

開発部 2026-11-12。**資料だけ。ゲーム(`changelog.js`・`help.js`・`assistants.js`)にはまだ入れない。**
公開の日が決まったら、この文をそのまま写し、**数字は下の「数字の出どころ」で芯と見くらべてから**入れる。
文は `changelog-help-update` スキルの §0-2(プレイヤー向け)・§0-3(3つの問い)・`player-words-check` に沿って書いた
(「仕組み」「判定」「保存の」「検査」などの語、「子」呼び、敵の数字、まだ出ていない話の予告は使っていない)。
正式名称は「モンヒロサクセス」。略称「モンサク」はキャラクターの台詞(告知の台本)だけ。

数字の根拠は `monster-hero/data/monhero-success.js`(VERSION 1・読んだ日 2026-11-12)。**仮**と付けたものは、芯が仮置きか、画面と食い違うかもしれない所。公開の直前にもう一度見くらべる。

書き方の根拠(§0-3 の3つの問い)

1. 画面で確かめられることだけ。まだ出ていない大会の名前・相手の強さ・イッサ博士の中身(確率や効き)は書かない。博士のことはヘルプにだけ書く(出会ってから分かる楽しみを残すなら、ヘルプも「ときどき訪ねてくる博士」までに絞る案は §5 の決めてほしいこと)
2. 助手の口調やお話の小さな直しは書かない
3. 「公開の印」「出し分け」などは書かない

### 予告の項目との関係(`update_notice_monsaku_soon_v1`・2026-11-12 12:40)

- いまの予告は `type:'content'`・`group:'success'`・題「新コンテンツ「モンヒロサクセス」開発中・近日公開」で、最後の2行が「画像は開発中の画面です。公開までに変わることがあります。」「近日公開予定です。お楽しみに！」。助手の告知 `update_notice_monsaku_soon_v1` は、読んだ人には出ない(一度きり)

### 本文(`blocks` の案。`p` / `note` / `list` / `steps` / `kv` / `data` の6種)

#### 1. はじめに(`success-start`)

- `p`: モンヒロサクセスは、モンスターを1体、デビューからヒーローの頂まで46ターンかけて育てる遊びです。毎ターンやることをひとつ選び、期ごとの大会を勝ち上がります。育て終えたモンスターは保存枠に残り、次の育成を助けます。
- `steps`:
  1. 育てるモンスターを選ぶ(ベースモン、または合体で生まれた育てる前のモンスター)
  2. 編成のマスモンを選ぶ(6体まで。うち1体はフレンドから借りられます)
  3. 助手を1人選ぶ(筋書きが助手ごとに変わります)
  4. 持ちこみの物を選ぶ(2つまで)
  5. 名前と染色を決めて、確認して始める
- `note`「いつでも中断できます」: 1ターンごとに保存されます。閉じても続きから始められます。1回の育成は、大会の観戦を速送りにして、およそ8〜15分です(**仮**・芯の目安)。
- `note`「1日の回数に制限はありません」

#### 2. 期とターン(`success-turn`)

- `p`: 育成は全部で46ターンです。1ターンは1か月にあたります。
- `kv`(芯 `PERIODS`): デビュー期 5ターン / ジュニア期 12ターン / ミドル期 12ターン / プロ期 12ターン / 最後の期 5ターン
- `p`: 画面の上に「この期の残りターン」と、小さく「最後まで」の残りが出ます。期の長さは、助手やモンスターによって変わりません。
- `list`:
  - デビュー期の終わりに「デビュー戦」があります。ターンは使いません
  - ジュニア・ミドル・プロ期の終わりにも、ターンを使わない大会があります
  - 最後の期は、残り3ターンから毎ターン「頂への道」の大会です。負けるとそこで育成が終わります
- `note`「けが・病気はターンを減らしません」: そのターンが休みになるだけです。

#### 3. 訓練と訓練Lv(`success-train`)

- `p`: 訓練は6つ(ライフ・ちから・かしこさ・命中・回避・丈夫さ)から選びます。1回の訓練で、主の能力と、ほかの2つの能力が上がります(下がる能力はありません)。いっしょに上がる2つは、助手によって組み合わせが変わります。
- `p`: 訓練の札には、そのターンに集まった編成のマスモンの顔が並びます。だれも来ていない札もあります。集まった札ほどよく伸びます。
- `p`: 訓練ごとに経験がたまり、**訓練Lv**が上がります。最大Lv5です(芯 `TRAIN_LV`)。
- `kv`: 訓練Lv2: 4回 / Lv3: 9回 / Lv4: 15回 / Lv5: 22回(**踏んだ回数の合計**)。伸びの大きさは Lv1 を基準に、Lv2 で約1.08倍 → Lv3 で約1.16倍 → Lv4 で約1.25倍 → Lv5 で約1.35倍
- `note`「疲れはゲージとようすで分かります」: 体力が減ると失敗しやすくなります。くわしい数字は「くわしく見る」に出ます。

#### 4. 訓練の結果と叱る・褒める(`success-result`)

- `p`: 訓練の結果は4種類です(芯 `RESULTS`)。
- `kv`: 🌟大成功 → 伸びが1.5倍 / ⭕成功 → ふつうに伸びる / ❌失敗 → 伸びない / 💤サボり → 伸びが3割
- `list`:
  - 失敗は、体力が上限の半分を下回ると、体力が減るほど起きやすくなります
  - サボりは、育成方針が「普通」より甘い(甘い・溺愛・超溺愛)ときだけ起きます。甘いほど起きやすくなります
  - 大成功は、忠誠度が高いと少し出やすくなります。アシスト能力の「ひらめき」でも上がります
- `p`: 結果のあとに「📣 叱る」「👏 褒める」を1回選べます(選ばなくてもかまいません)。モンスターの**甘え度**と**恐れ度**、そして**育成方針**が動きます。
- `kv`: 忠誠度 = 甘え度 + 恐れ度(各50まで)。忠誠度が高いほど、訓練が少しだけ伸びます
- `note`「褒めても叱っても正解はありません」: 甘え度が高いとサボりやすく、恐れ度が高いと失敗しにくい、というように、どちらも長所と短所があります。

#### 5. 体力とようす・通院(`success-body`)

- `p`: 体力は100がはじめの上限です(アイテムやイッサ博士で上がります)。訓練や大会で減り、休む・遊ぶ・ごはんで回復します。
- `p`: 疲れやストレスがたまると、**けが・病気・家出**が起きることがあります。そのターンは休み扱いになりますが、能力は下がりません。けがは1〜2ターン、病気と家出は1ターンです。
- `p`: イッサ博士の装置の失敗や悪い出来事で、悪い**ようす**が付くことがあります。
- `kv`(芯 / EVENTS): 😪サボりグセ → 訓練がサボりになりやすい(失敗の下限が +5%) / 🌧うつ病 → 訓練の伸びが2割減り、休んでも回復しにくく、忠誠度が動かない。どちらも**時間では治りません**
- `p`: ようすは「🏥 通院」で治せます。通院は1ターンを使います。1回目は**70%**で治り、2回目は**必ず**治ります。ようすが付いていないときは押せません。助手のえるびん・ソラシドは、けがや病気の扱いが少し変わります。
- `note`「アイテムでも治ります」: 持ちこみの「悪様散」で、悪いようすを治せます。

#### 6. 休む・遊ぶ(`success-rest`)

- `kv`(芯 `REST`): 🛌休む → くじで3つ: あんまり休めなかった(10%)は体力が上限の半分 / 普通の休養(70%)は上限の7割 / がっつり休めた(20%)は上限の9割
- `kv`(芯 `PLAY`): 🎈遊ぶ → 体力が上限の半分 回復。**甘え度 +5**。うつ病が治る
- `note`「ごほうびのごはん」: 大会が終わるたびに1回、ごはんを選べます(選ばなくてもよい)。値段はこの遊びの中のお金「名声」です。スタミナごはん 150 / なかよしごはん 300 / パワーごはん 500(**仮**・試算で変わることがあります)。

#### 7. 修行とチケット(`success-shugyo`)

- `p`: 修行は、行き先を選び、2つの段で能力が2つずつ上がり、最後に**技を覚えるくじ**を引きます。体力を多めに使います。**修行チケット**の数だけ行けます(回数の決まりはありません)。チケットは大会に勝つともらえます。賞金が大きい大会ほど多くもらえます。
- `kv`(芯 `SHUGYO`): 行き先は4つ(炎の谷・氷の峰・風の森・星の湖)。覚えたい技は2つまで選べる(1回の修行で覚えるのは1つまで)。外れるたびに、次の覚える率が +15 上がる(覚えたら元に戻る)。覚えた技の熟練は、修行のたびに +10
- `note`「技を覚える道は2つ」: 修行と、編成のマスモンとの連続イベント(3話の伝授)です。覚えられる技の数は8つまでです。

#### 8. 大会(`success-cup`)

- `p`: 毎ターン、期に応じて2〜4つの大会が並びます。出ればそのターンを使います。大会には星の階級(★・★★・★★★・👑)があり、勝つと賞金(名声)と、一部の大会ではごほうび(能力・能力ポイント・人気・称号)がもらえます。
- `p`: 大会で戦うのは**1戦だけ**です。組み合わせ表(トーナメントなど)は演出です。
- `list`:
  - **スキップ**: 一度でも(前の育成も含めて)優勝した大会は、次から結果だけを見てスキップできます
  - **やり直し**: 負けたら「時渡りの砂時計」(同じ相手ともう一度)か「虹の時渡りの砂時計」(相手を変えてもう一度)でやり直せます。この2つを合わせて、**1回の育成で3回まで**です(芯 `REMATCH`)。砂時計は持ちこみ・出来事・大会のごほうび・マーケットで手に入ります
  - **ライバル**: ときどき、自分の助手のマスモンやフレンドのモンスターがライバルとして出ます。月の大会があるターンの約4分の1で、その月の大会のどれか1つに出ます(札にアイコンが付きます)。ふつうの強豪より少し強いですが、勝てば賞金が1.5倍・**全能力 +12**・能力ポイント +5・修行チケット +1・称号「ライバルに勝った」がもらえます。ライバルの強さは期に合わせて整えるので、勝てないほど強くはなりません
  - **デビュー戦**: 負けると、ジュニア期は勝つまで毎ターン再挑戦の大会になり、訓練ができません。負けるたびに相手が1割ずつ弱くなります(最大でもとの6割まで)
  - **頂への道**: 最後の期の残り3ターンで、1回戦 → 準決勝 → 決勝を月に1戦ずつ戦います。決勝のごほうびは2通りから選べます
- `note`「能力ポイント」: 大会でもらえるポイントです。引退までに、好きな能力へ振れます。

#### 9. 持ちこみ(`success-carry`)

- `p`: 始める前に、持ちこみの物を**2つまで**選べます(始める前に効く物と、育成中に使う物を合わせて2つ)。色で2種類に分かれます。育成中に使う物は、1ターンに1個までで、ターンを使いません。
- 表(**芯 `ITEMS` / PLAN。仮**・値段と手に入れ方は決まり次第):

| 物 | 使う時 | 効き |
| --- | --- | --- |

- `note`「大会や出来事でもらった物は2つに数えません」

#### 10. 編成・親密度・友情タッグ(`success-team`)

- `p`: 編成は**マスモン6体**です。保存枠の育て終えたモンスターから5体まで選び、1体はフレンドから借りられます。空いた枠はベースモンで埋まります(効きはいちばん弱い)。
- `p`: 編成のマスモンは、毎ターン**得意な訓練**に集まります。引退のときに高かった能力の上位3つが、そのマスモンの「集まりやすい訓練」です(ベースモンは種の伸びやすさの上位3つ)。1位の訓練に約30%・2位に約20%・3位に約15%で顔を出します。
- `p`: 集まった訓練は、そのマスモンの能力に応じて伸びが増えます。**能力が高く、ランクが高い子ほど大きく**、1位の能力 > 2位 > 3位の順に少しずつ小さくなります。
- `list`:
  - **親密度**: 編成のマスモンと助手には、それぞれ親密度があります。いっしょに訓練すると1回で +8 上がります。はじめは、ベースモンより育てたマスモン、助手は仲良し度が高いほど高めから始まります
  - **友情タッグ**: 親密度が80に届いた仲間がその訓練に来ていると、友情タッグになって伸びが大きくなります。ベースモン +15% / ランクが高いほど大きく(最大 M で +35%) / 助手は +25%。**タッグの仲間が多いほど、効果が重なります**
  - **3体以上**集まると、さらに +10%
  - 親密度が高い仲間との連続イベントが起きることがあります(3話まで。2話は親密度40以上、3話は60以上が目安・**仮**)
- `note`「編成のマスモンは疲れません」: 編成に使っても、疲れたり減ったりしません。対戦に出ることもありません。
- フレンドの貸し出し: フレンド1人につき1体(そのフレンドが選んだ貸し出しのモンスター)。借りられると、貸した人にも名声が入り、知らせが届きます(**仮**・決まり次第)。

#### 11. アシスト能力(`success-assist`)

- `p`: 育て終えたとき、最終の総合力に応じて**アシストポイント**がもらえます。ポイントは「総合力 ÷ 50」(最低 20・最高 400)です。このポイントで、**アシスト能力**を選んで取ります(育成の最後の画面で、その育成につき1回)。
- `p`: 取ったアシスト能力は、そのモンスターを**次の育成の編成に連れていくと**効きます。1体につき**4種類まで**持てます。
- 表(**データ表 `monsukeAssists` にして実データから出す案**。いまは仮に手で書いた9種類の表です。**アシスト能力は30〜40個に増やしている最中**なので、公開のときは増えた一覧に合わせて、この表と「9種類」の文・値段・「4種類まで」を書き直す。手で写さず `{ t:'data' }` で出すのが前提):

| 名前 | 効き | 段1 / 段2 / 段3 | 値段(ポイント) |
| --- | --- | --- | --- |
| 🔥 特訓の底力 | いっしょの訓練の伸びが上がる | +4% / +7% / +10% | 40 / 80 / 128 |
| 📯 かけつけ | 得意な訓練に来る率が上がる | +8 / +14 / +20 点 | 32 / 64 / 104 |
| ✨ ひらめき | 大成功の率が上がる | +3 / +5 / +8 点 | 32 / 64 / 104 |
| 🎯 得意の後押し | 1位の能力の訓練の伸びがさらに上がる | +8% / +14% / +20% | 24 / 48 / 80 |
| 💞 信頼のきずな | 忠誠度が高いほど伸びが上がる | 忠誠100で +6% / +10% / +14% | 40 / 80 / 128 |
| 🧘 落ち着き | 失敗の率が下がる | −15% / −25% / −35% | 24 / 48 / 80 |
| 🩹 いたわり | 訓練で減る体力が少なくなる | −8% / −14% / −20% | 24 / 48 / 80 |
| ⚔ 修行の手ほどき | 修行の伸びと熟練が上がる | +10% / +18% / +25% | 24 / 48 / 80 |
| 🤝 人なつっこさ | 親密度の上がりが速く、はじめも高くなる | 上がり ×1.2 / ×1.4 / ×1.6 | 32 / 64 / 104 |

- `note`「余ったポイントはなくなります」: その育成の最後にだけ使えます。
- `note`「アシストの足し算に上限はありません」

#### 12. イッサ博士(`success-issa`)

- `p`: 町はずれの時計塔に住む発明家のイッサ博士が、育成の途中でときどき訪ねてきます。装置でモンスターを強くしてみないかと持ちかけます。6つの選択肢から1つを選びます。失敗すると下がったり、悪いようすが付いたりしますが、「何もしない」と断れば損はありません。
- 表(**芯 `ISSA` の確率。仮**・出会える回数の目安と同じく試算で変わることがあります):

| 選ぶ | 成功しやすさ | 成功したとき | 失敗したとき |
| --- | --- | --- | --- |
| 💪 ステータスアップ | 35% | 全能力 +50 | 全能力 −10 と、ようす「サボりグセ」 |
| 🔋 体力上限アップ | 60% | 体力の上限 +20 | 体力 −20 |
| ❤️ 体力回復 | 90% | 体力を上限の8割回復 | 体力 −30 と、ようす「うつ病」 |
| 🤝 忠誠度アップ | 75% | 忠誠度 +15 | 忠誠度 −5 |
| ⭐ 人気アップ | 75% | 人気 +15 | 人気 −5 |
| 🙅 何もしない | — | 断る(損はありません) | — |

- `list`:
  - 出会えるのは、ジュニア期の7ターン目からプロ期の終わりまでです。1ターンあたり約3%で、**1回の育成で3回まで**
  - ストレスが高い(70以上)ときは来ません
  - 「博士の導き書」を持ちこむと、1度必ず現れます。「博士のルーペ」を使うと、実験が必ず成功します
- `note`「博士はちょっと頼りない」: 軽いノリで「へーきへーき」と言ってきます。助手にいじられることもあります。

#### 13. 引退と評価・保存枠と合体・ゲームオーバー(`success-end`)

- `p`: 46ターンを走り切ったとき、頂への道で負けたとき、途中で「ここで引退する」を選んだとき、育成が終わって**引退**します(モンスターは消えません)。
- `list`:
  - 振り返りで、能力の伸びの線・大会の成績・助手の一言が見られます
  - 最終の総合力で**評価**が決まります。評価は助手マスモンと同じランク表です(社長の最新の決め)。G 0〜 / F 2,000〜 / E 3,000〜 / D 4,500〜 / C 6,000〜 / B 8,000〜 / A 11,000〜 / S 14,000〜 / SS 16,000〜 / SSS 18,000〜 / M 19,500〜。さらに **500ごとに下から数字**が付きます(C1 は 6,000〜・C2 は 6,500〜・C3 は 7,000〜・C4 は 7,500〜。M は上限がなく M1・M2…と続きます)。**表は手で写さず、実データ(`gradeOf(power)`・芯に入る予定)から出す**案
  - 評価に応じてアシストポイントがもらえます(上の「アシスト能力」)
  - 引退した助手の仲良し度が少し上がります(**1日3回の引退まで**)
- `p`: 引退したモンスターは**保存枠**に入ります。
- `kv`(PLAN §3): 保存枠の数: はじめ30体 / 引退10回ごとに +5 / 最大60体。いっぱいのときは、お別れ(2回確かめます。名前とランクが「思い出」に残ります)か合体で減らしてください。自動では消えません。
- `list`:
  - 保存枠のモンスターは、**編成**に入れる・**フレンドに貸す**・**バトル**(モンヒロサクセスの対戦)に出す・**合体**の材料にする、ことができます
  - **名前と染色**は、育成を終えたあとでも、いつでも変えられます
  - **合体**: 保存枠から「主の親」と「もう一方の親」を選ぶと、**血統**で決まる種類の、育てる前の新しいモンスターが生まれます。親2体は保存枠から外れ、「思い出」に残ります(最後に2回確かめます)
- `p`: **ゲームオーバー**: デビュー戦に3回負けると、育成が終わります。持ちこみ・使ったアイテム・チケットは戻りません。ただし、砂時計でやり直して勝てた負けは、3回に数えません。ランキングにも載りません。
- `note`「ゲームオーバーは悪いことばかりではありません」: ベースモンはまたすぐ育て直せます。

#### 14. ランキング(`success-rank`)

- `p`: 育成を終えたモンスターは、**最終の総合力**でランキングに載ります。2つあります。**全モンスター**と**血統別**(血統の札を選んで切り替えます)。
- `list`:
  - 期間は「ずっと」だけです(月ごとなどの区切りはありません)
  - 育てたモンスター**1体ずつ**載ります(1人1件ではありません)
  - 1行に、順位・染めた姿の絵・名前・評価・総合力・育てた人の名前が出ます。押すと6能力が見られます
  - 評価に関係なく、全部載ります
  - 自分のモンスターは色が変わり、「自分のだけ」の絞りこみもあります
- `note`「載らない遊びかた」: デバッグで進めた育成や、デビュー戦でゲームオーバーになった育成は載りません。載るのは、引退して育成が完了したときの1回だけです。
- `note`「名前の言葉は見張られています」: ほかの人にも見える名前なので、使えない言葉があります。
