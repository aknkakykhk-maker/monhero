# モンサクのアシスト効果: 書き方の型・タブ・72種類の一覧(2026-11-14 クラフトくん9・社長に見せる前)

社長「大成功アップが確率書いてなかった」「他にも%じゃないやつとか分かりにくいやつとか見直して、みんな同じような書き方にして」

## 型の決まり

1. **文頭は効く場面**: 「いっしょにトレーニングしたとき、」/「『◯◯』のトレーニングにいっしょに来たとき、」/「このモンスターが…」/「編成にいるだけで、」/「助手が来たトレーニングでは、」
2. **数字の書き方は6種類だけ**(説明の文・右上の値・取るものの行・ヘルプの表で同じ)

| 数字の種類 | 書き方 | 意味 | 例 |
| --- | --- | --- | --- |
| 伸び | `+5%` | 上がる量の補正に足す(いっしょの子・ほかの効果と足し合わせる) | トレ効果アップ・◯◯アップ・助手・鍛錬 |
| 確率(足し算) | 文の中は「◯◯の確率 +5%」・右上の値と取るものの行は `確率+5%` / `確率−5%` | 元の確率に足す・引く | 大成功率アップ(元 5% → 10%)・得意率アップ・技習得率アップ |
| 倍率(掛け算) | `×1.05` / `×0.95` | その量・確率にかける | 賞金 ×1.05・失敗の確率 ×0.95(元の確率の95%になる) |
| 値 | `+5` | 能力・体力・親密度・ガッツの値 | 初期ステータスアップ・初期親密度アップ |
| 数 | `+1回` `+1枚` `+1ターン` `Lv+1` | 回数・枚数・ターン・トレーニングLv | 超修行アップ・修行チケットボーナス |
| 1つだけ | `あり` | 取るか取らないか | 助手・継承 |

3. 「点」「段」は使わない(`tools/success/monhero-success-tables-check.js` が見張る)

## 集合率アップ(社長 2026-11-14「集合率アップもつくって。みんなが同じとこに集まりやすくなる」)

- いるだけ型。トレーニングのくじのあと、いちばん多く集まったトレーニングにいないモンスターが、それぞれこの確率でそこへ移る(来なかったモンスターは対象外。同じ数なら、その能力を得意にしているモンスターが多いほう)。別の乱数なので、いまの並びは変わらない
- 1目盛り 確率+2%・6pt・最大 +20%(60pt)
- 試算(6体・40ターン×300回): いちばん多い札の平均 2.42体 → 2.95体(+20%)/ 3体以上の札があるターン 39.8% → 65.9%
- 試算(success-sim・150回・総合力の中央値・1体だけ満タン): B 13,207 → 13,774(+4.3%)/ M 16,057 → 16,290(+1.5%)。+30%(4pt)にすると B +6.6% で強すぎたので、+20%・6pt にした
