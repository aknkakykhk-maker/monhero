## 0. おすすめで進めた点(社長「返事は待たないで進めて」・違ったらあとで直す)

1. **称号は名誉だけ**(持っていても強さは変わらない)。取ったときのごほうびは今の芯のまま。サクセス杯・対戦のつり合いに響かないため
   - ほかの案: 称号ごとに小さな効き目(編成に入れると親密度 +5 など)= 第2弾で
2. **保存枠の子の `titles` には id を入れる**(名前を直しても記録が変わらない)。芯が積んでいる文字は `finalize` で id に直す。表にない文字は消さずに残す(⑦)
3. 👑 の芯の文字「ヒーロー記念」は、画面では **「冬のヒーロー記念の覇者」**(TOURNAMENT §8 の名前)と出す
4. 評価の称号は **B 以上**で、いちばん上の1つだけ(一人前 → 腕きき → スター → 語りつがれる → モンスターヒーロー)
5. **お話のひらめきの5つ**(ガッツ・見せ場・見立て・検証・見守り)は、**名前どおり試合の中で効く**(社長 2026-11-12)。対戦の芯の buffs の入口(#5722)を使う。どの試合にも効くので、助手の特別な1話(頂への道の1回戦だけ)より小さい数字。値段は安い組(24/48/80)
6. 記録帳は **新しいキー `mh_monsuc_record_v1`**。保存枠から外れた子(合体・手放す)も残る。200件まで(育てた数は数え続ける)

## 2. アシスト能力(モンサク専用の能力・第2版 40種類・どれも5段)

> **社長 2026-11-12**: ①ひらめきの5つは「試合の中で効く形」→ 直した(対戦の芯の buffs #5722)。**ただし台帳ではこのあと「保留」になった**(社長「バトルシステムが俺の思ってるのとちがそう」→ 社長のイメージを聞いてから・バトルは自分で操作する形に決まった)。表の試合型5つは仮の形として残し、決まったら直す。②「14個では少ない。30〜40個に」→ 40種類。③「種類ごとに数値も多く(トレ効果アップ 5%・10%・15% など)」→ どれも5段。

- 参考(`docs/reference/line-mf/assist-effects.json`)からは **どんな種類があるか** だけを拾い、血統・タイプの条件つきは入れていない。名前と数字はモンサクの物差しで作り直した
- **この表が正**。芯(`monhero-success.js` の `ASSISTS`)はまだ第1版(9種類・3段)。芯がこの表を読むように直すまで、訓練の計算には第1版の数字が使われる(下の4)
- 1体4種類まで・ポイント = 切り捨て(総合力 ÷ 50)・20〜400
- 値段の組(段1〜5 の合計): **高** 30 / 60 / 100 / 150 / 210・**中** 24 / 48 / 80 / 120 / 170・**低** 16 / 32 / 56 / 88 / 128
  - 低の段1(16)は、ポイントの最低(20)の子でも1つ取れる
  - 高の段5(210)は総合力 10,500〜(A ランク〜)で届く。M(400)なら「高 段5 + 中 段4 + 低 段3」(386)まで
- 「おまかせ」(`autoPick`): ひらめきの候補 → 特訓の底力 → 人なつっこさ → かけつけ → 信頼のきずな → ひらめき → 残りの順に段を上げる
- 試合型(お話のひらめき5つ): 編成にいると、**育てる子の大会の試合**で効く。編成でいちばん高い段の1つだけ。`battleBuffs(編成の子の assists の配列, 特別な1話の battleMods)` が対戦の芯の `buffs.A`(#5722)の形にまとめる
- いるだけ型の効き目は `stayValue(編成の子の assists の配列, id)`(編成でいちばん高い段の数字)

## 4. 芯(クラフト)への引き継ぎ

- アシスト: 第2版(40種類・5段)はこの表が正。芯の `ASSISTS`(第1版)を、この表を読む形(`create({ …, assist: MONHERO_SUCCESS_ASSIST })` など)に直してほしい。段は1〜5(`normAssists` の上限 3 → 5)。ひらめきの5つ(`gatsu`・`miseba`・`mitate`・`kensho`・`mimamori`)は試合型。訓練の計算には入れない。大会の試合を回すとき `MONHERO_SUCCESS_ASSIST.battleBuffs(編成の子の assists, battleMods(s))` を `simulate({ …, buffs: { A: … } })` に渡す
