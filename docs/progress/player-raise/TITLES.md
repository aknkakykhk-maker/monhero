6. 記録帳は **新しいキー `mh_monsuc_record_v1`**。保存枠から外れた子(合体・手放す)も残る。200件まで(育てた数は数え続ける)

## 3. 育成の記録帳(画面の見本・画面は回3)

- アシスト: 芯の `ASSISTS` を変えたら `monhero-success-assist.js` も同じに直す(見張りが止める)。ひらめきの5つ(`gatsu`・`miseba`・`mitate`・`kensho`・`mimamori`)は試合型。訓練の計算には入れない。大会の試合を回すとき `MONHERO_SUCCESS_ASSIST.battleBuffs(編成の子の assists, battleMods(s))` を `simulate({ …, buffs: { A: … } })` に渡す
- 称号: ★★★ の系統・夏の👑・制覇を積むときは `s.titles.push('star3-str')` のように **id で**積む(`resolve` は id でも引ける)
- 引退: `titles = MONHERO_SUCCESS_TITLES.finalize(s.titles, SUC.evaluate(s), s)` を保存枠の子と記録帳に入れる
- 試算で見てほしいこと: 試合型の5つを全部段3でそろえたとき(ガッツ +8・会心 +8%・命中 −8%・外れ −35%・最初の一撃 +10%)、大会の勝ち率がどれだけ上がるか

## 5. 決まったこと(社長 2026-11-12・窓口経由)

1. 称号は **名誉だけ**(効き目なし)
2. ポイント 20〜23 点の子が段1を取れないのは **そのまま**(最低は上げない)
3. お話のひらめき5つは **試合の中で効く形**(対戦の芯の buffs #5722。数字はクラフトの試算と合わせる)
