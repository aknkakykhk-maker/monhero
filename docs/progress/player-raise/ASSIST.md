## 0. ひとことで

- 1体が持てるアシスト能力は **4種類まで**。1種類ごとに **段1〜3**(段が上がるほど強く、ポイントも多く要る)
- 効き方は2通り
  - **いっしょ型**: その子が **集まった訓練でだけ** 効く(ほとんどがこれ)
  - **いるだけ型**: **編成にいるだけで** 効く(修行・親密度など、編成の子が来ない場面のもの)
- 伸びの式は「基礎数値 × 素質 × 育成方針 × 時期 × 結果 ×(1 + 編成の効き + アシスト)× 友情タッグ × 忠誠度の補正」(§4)

## 4. 訓練の伸びの式(1本にまとめた・社長の形)

社長「モンスターごとの素質や育成方針(スパルタや溺愛など)、それに時期的な補正。基礎数値をもとにいろんな要素が合わさってトレ数値になる」

```
伸び = 基礎数値(訓練ごと・軽い/重い)
       × 素質(種ごとの伸びやすさ `AMG_APT`。その能力の)
       × 育成方針(超溺愛 ×0.80 〜 超スパルタ ×1.18・POWER.md §5)
       × 時期(成長の型とピーク。いまのターン ÷ 46)
       × 結果(🌟大成功 ×1.5 / ⭕成功 ×1 / ❌失敗 ×0(上がらない)/ 💤サボり ×0.3)
       × (1 + 編成の効き + アシスト)       ← 足し算・上限なし
       × 友情タッグ(1 + 0.5 × タッグの数)  ← 上限なし
       × 忠誠度の補正(1 + 忠誠度 ÷ 100。60で頭打ち)
```

| 段 | 中身 |
| --- | --- |
| 基礎数値 | 訓練ごとの決まった数(PLAN §1 の軽い/重い訓練の表)。**ほかの倍率を全部かけた後に、ふつうの育成で狙いのランクに届くよう、試算でここを合わせる** |
| 素質 | 種ごとに能力の伸びやすさが違う(助手マスモンと同じ表)。同じ訓練でも、得意な能力はよく伸びる |
| 育成方針 | 叱る/褒めるで動く7段(PLAN §1・POWER.md §5)。厳しいほど伸びるが、ストレスがたまりやすい |
| 時期 | 成長の型(超早熟〜超晩成・持続)とピーク。ピークの時期は大きく伸びる |
| 編成の効き+アシスト | その訓練に **集まった子ごと** に、ランクの%(得意なら ×1.5)+ いっしょ型アシスト(底力・後押し・きずな)を足す。3体以上集まったら +10%。**上限なし**(社長) |
| 友情タッグ | タッグの子(助手も1人と数える)1つごとに **+50%**。**足し算で重ねる・上限なし**(社長) |
| 忠誠度の補正 | §4c |

- 大成功(3)・失敗(6)・体力(7)・集まり方(2)は伸びの式の外で効く(率と体力の計算に直接)
- 「信頼のきずな」(忠誠で伸びが上がるアシスト)は足し算の中、忠誠度の補正は最後の掛け算。忠誠の高い子ほど二重に得をする

### 4c. 忠誠度 = 甘え度 + 恐れ度(社長)

社長「60が上限で60%アップ、それ以降は補正なし。忠誠度の仕組みは甘え度+恐れ度。ただし甘え度と恐れ度の上限は50」

- **忠誠度 = 甘え度(0〜50)+ 恐れ度(0〜50)** → 0〜100。画面は忠誠度の棒の中を2色(甘え=桃・恐れ=紺)で分けて見せる
- **補正 = 1 + min(忠誠度, 60) ÷ 100**: 忠誠0で ±0%・30で +30%・60で +60%、60より上は +60% のまま(1点で +1% の直線)
- **60より上は、総合力とバトルに効く**(社長「忠誠度が高ければ総合力やバトルでの影響」)。伸びの補正は60で止める
  - 育て終えた子の **忠誠度は引退のときの値で保存枠に残る**(`loy`。甘え・恐れの内訳も `ama`・`fear` で残す)
  - **総合力**: 助手マスモンと同じ式で **忠誠度 × 10** が入る(忠誠100で +1,000・60なら +600)→ アシストポイントも増える
  - **バトル**(サクセス杯・対戦): 助手マスモンと同じ「そっぽを向く」— 自分の番ごとに **(100 − 忠誠度) × 0.25%** で動かない(忠誠100で0%・60で10%・20で20%)
  - ほかに大成功の率 +3%(80〜)・EVENTS の「甘えん坊」(80〜)など、今の案の忠誠の段はそのまま
- はじめ: 甘え 10・恐れ 10(忠誠 20)。保存枠の子・合体の子も同じ(育成ごとに一から)

| 何で | 甘え度 | 恐れ度 |
| --- | --- | --- |
| 👏 成功・大成功を褒める(合う) | +4 | — |
| 👏 失敗・サボりを褒める(合わない) | +2 | −2 |
| 📣 失敗・サボりを叱る(合う) | — | +4 |
| 📣 成功・大成功を叱る(合わない) | −3 | +1 |
| 🎈 遊ぶ / ごちそう | +2 / +2 | — |
| 大会で勝つ / 負けて叱る | +2 / — | — / +3 |
| 家出 | −8 | −4 |
| 何もしない(褒めも叱りもしない)ターンが4回続く | −1 | −1 |
