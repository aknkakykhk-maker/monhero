- 社長「血統とかタイプは難しいから、トレ効果とか集合率アップとか誰にでも効果があるやつを優先で」→ **第1弾は条件なしの効果だけ**。血統・タイプの条件つきは「あとで」(§9)

## 0. ひとことで

- 1体が持てるアシスト能力は **4種類まで**。1種類ごとに **段1〜3**(段が上がるほど強く、ポイントも多く要る)
- 効き方は2通り
  - **いっしょ型**: その子が **集まった訓練でだけ** 効く(ほとんどがこれ)
  - **いるだけ型**: **編成にいるだけで** 効く(修行・親密度など、編成の子が来ない場面のもの)
- 重ね方は「**編成の効き × 友情タッグ × アシスト**」の3つの層を掛け、**層ごとに上限**(§4)

## 4. 編成の効き・友情タッグ・アシストの重ね方

```
伸び = 基本 × 成長の型 × 方針 × 結果
       × 編成の上乗せ   (PLAN §2 のランクごとの%を足し算・上限 ×2.5)
       × 友情タッグ     (タッグの数で足し算・上限 ×1.6)
       × アシスト       (いっしょ型の 1・4・5 を足し算・上限 ×1.5)
```

- 3つの層を **掛け算**、**層ごとに上限**。どの層も「強い子を育てると次が伸びる」に効くが、1つの層だけ積んでも上限で止まる
- 3つとも上限でも ×6.0 になるので、**全体の上限 ×4.0** を置く(6体 M・全員タッグ・アシスト満載のときだけ当たる)
- 大成功(3)・失敗(6)・体力(7)・集まり方(2)は伸びの式の外で効く(率と体力の計算に直接)

### 友情タッグ(案・PLAN §2 の「一定の値・効果」の数字)

| 項目 | 案 |
| --- | --- |
| 親密度 | 0〜100。いっしょに訓練すると +6(人なつっこさで ×1.2〜1.6)、遊ぶ・できごとで + |
| はじめの親密度 | ベースモン 0・保存枠の子 20・フレンドの子 10。助手は助手ライフの仲良し度 Lv × 8(Lv5 で 40)。人なつっこさで +5〜15 |
| タッグになる値 | **80 以上**(はじめ20の子で、集まりやすい訓練に10回ほど来れば届く) |
| 効果 | タッグ1つごとに **+12%**(足し算・上限 ×1.6 = 5つぶん)。助手も、タッグになって同じ訓練にいれば1つと数える |
| 画面 | タッグの子の顔に金の枠。札に「友情タッグ ×2」 |

### 目安(B の子6体・保存枠から・中ほどのターン)

| 場面 | 編成 | タッグ | アシスト | かけた後 |
| --- | --- | --- | --- | --- |
| アシストなし・タッグなし・3体集まる | ×1.55 | ×1.0 | ×1.0 | ×1.55 |
| 同じ・3体ともタッグ | ×1.55 | ×1.36 | ×1.0 | ×2.11 |
| 3体とも「特訓の底力 段2」 | ×1.55 | ×1.36 | ×1.21 | ×2.55 |

- アシストは「タッグに届いたあとの、もう一押し」くらいの重さにした。編成のランクの%(PLAN §2)は今のまま変えない

## 6. 保存(CLAUDE.md ⑦)

- **保存枠の子の中に足す**(`mh_monsuc_box_v1` の `mons[]` の1体ずつ。PLAN §9)。新しいキーは作らない(保存枠はまだ出していないので、出す前の形に足すだけ)

```
asp: { v:1, pts:72, picks:{ boost:2, spark:1 }, at:引退の時刻 }
```

| 項目 | 中身 |
| --- | --- |
| `pts` | 引退のときに決めたポイント。**あとで総合力が変わっても(名前・染色を変えても)増減しない** |
| `picks` | 効果の id → 段(1〜3)。id は英字で固定(boost・call・spark・fav・trust・calm・care・dojo・warm) |
| `at` | 取った時刻。`pts` は `asp` が無いときに1回だけ付ける(二重に付けない) |

- 読み込み: `asp` が無い・壊れている → アシストなし。`pts` は `Number.isFinite` で 0〜100 に丸める。`picks` は知らない id を捨て、段は 1〜3 に丸め、4種類を超えたら先頭4つ、値段の合計が `pts` を超えたら後ろから外す
- 合体で生まれた子は `asp` を持たない
- レンタルの表(`monsuc_lend`・PLAN §2)に `picks` を足す。借りる側で上の確かめ方を通す

## 8. 決めてほしいこと(おすすめが先頭)

1. **重ね方**: ①(推奨)3つの層を掛け算・層ごとに上限+全体 ×4.0 ② 編成の%とアシストの%を1つに足し算(上限 ×2.5 のまま・アシストの得が小さく見える) ③ アシストは上限なし(強い子ほど青天井)
2. **友情タッグの強さ**: ①(推奨)タッグ1つ +12%・上限 ×1.6・親密度80で成立 ② 1つ +8%・上限 ×1.4(控えめ) ③ 1つ +15%・上限 ×1.75(派手)
3. **ポイントの式**: ①(推奨)総合力 ÷ 200(最低5・最大100) ② ランクで決まった数(G 5・C 30・S 70・M 100 など。ランクの中の差は出ない) ③ 総合力 ÷ 250(最大80。段3が取りにくい)
4. **取り直し**: ①(推奨)余りはあとで足せる・振り直しはできない ② 1体につき1回だけ振り直せる ③ 名声を払えば何度でも振り直せる
5. **フレンドから借りた子のアシスト能力**: ①(推奨)効く(借りる側で確かめる) ② 効かない(編成の%だけ)
