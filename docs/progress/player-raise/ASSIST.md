## 0. ひとことで

- 1体が持てるアシスト能力は **4種類まで**。1種類ごとに **段1〜3**(段が上がるほど強く、ポイントも多く要る)
- 効き方は2通り
  - **いっしょ型**: その子が **集まった訓練でだけ** 効く(ほとんどがこれ)
  - **いるだけ型**: **編成にいるだけで** 効く(修行・親密度など、編成の子が来ない場面のもの)
- 伸びの式は「訓練の基本 ×(1 + 集まった子の効きの足し算)× 友情タッグ × 忠誠度の補正」(§4)

## 4. 伸びの式(社長の形)

```
伸び = 訓練の基本(成長の型 × 方針 × 結果をかけたもの)
       × (1 + Σ その訓練に集まった子の効き)            ← アシストの足し算
       × 友情タッグ(1 + 0.5 × タッグの数)
       × 忠誠度の補正
```

| 段 | 中身 |
| --- | --- |
| 集まった子の効き(1体ぶん) | **編成の効き**(PLAN §2 のランクごとの%。得意なら ×1.5)+ その子の **いっしょ型アシスト**(底力・後押し・きずな)。3体以上集まったら +10% |
| 足し算の上限 | (1 + Σ)は **×3.0 まで**(第1版の編成だけの ×2.5 から、アシストのぶん広げた) |
| 友情タッグ | タッグの子(助手も1人と数える)1つごとに **+50%**。**足し算で重ねる**(2つで ×2.0・3つで ×2.5)。上限は置かない案(§4b) |
| 忠誠度の補正 | **×(0.8 + 0.4 × 忠誠 ÷ 100)**: 忠誠0で ×0.8・50で ×1.0・100で ×1.2。叱る/褒めるで忠誠を育てる意味がはっきりする |

- 編成の効き(ランクごとの%)は、**アシストと同じ足し算に入れる** 案にした(社長の「アシスト同士は足し算」に近い形。強い子は「ランクの%」と「アシスト」の両方で効く)。別の掛け算にするかは決めてほしいこと ①
- 「信頼のきずな」(忠誠で伸びが上がるアシスト)は足し算の中、忠誠度の補正は最後の掛け算。忠誠の高い子ほど二重に得をする
- 大成功(3)・失敗(6)・体力(7)・集まり方(2)は伸びの式の外で効く(率と体力の計算に直接)

### 4b. タッグは何体重なるか(試算)

決めた仮の数: 親密度 0〜100・タッグは **80 以上**・**いっしょに訓練すると +10**(第1版の +6 だとタッグがほとんど起きないので上げた)・はじめは保存枠の子 20・ベースモン 0・助手 40(仲良し度 Lv5)。

- 社長の見立てのとおり、**ふつうはタッグ0〜1体**。2体以上が多いのは「得意を1つにそろえ、人なつっこさで早くタッグにした」ねらった編成だけ
- 3体以上(×2.5 以上)は、ねらった編成でも1回の育成に5回ほど。4体以上は1回前後
- だから **上限なしの案**。ねらった編成の得(同じ能力ばかり伸びて偏る・体力の減りが重い)とのせめぎ合いで釣り合う見込み。上限を置くかは決めてほしいこと ③

## 5. 取る画面(育成の最後・1回だけ)

引退の流れ: 振り返り → 育成ランク → **アシスト能力を取る**(ここ)→ 保存枠へ

- 上に「アシストポイント 288」と、総合力の帯(次の1点まであと何か)
- 9種類の札を2列で並べ、札ごとに「段1・段2・段3」のボタンと値段。取れない段は薄く、4種類取ったら残りの札は薄く
- 押すと下に「特訓の底力 段2・ひらめき 段1(使う 112・残り 176)」とまとめ
- 「おまかせ」: 1 → 9 → 2 → 5 → 3 の順に段を上げて埋める
- 「決める」で決まる(**このあと変えられない**ことを1行で出す)。余ったポイントは「残り◯点はなくなります」と出してから決める
- 決めずに閉じた・途中で落ちたときは、次に開いたときにこの画面から続ける(引退は済んでいても、取るまでは保存枠の子に「まだ取っていない」印)
- 助手の一言: 取ったものに合わせて「次の子といっしょに特訓すると、よく伸びそう!」など(台本は助手部)
- 編成を選ぶ画面では、子の顔の下にアシスト能力のアイコン(🔥✨…)と段の点を出す

- **保存枠の子の中に足す**(`mh_monsuc_box_v1` の `mons[]` の1体ずつ。PLAN §9)。新しいキーは作らない(保存枠はまだ出していないので、出す前の形に足すだけ)

```
asp: { v:1, pts:288, picks:{ boost:2, spark:1 }, done:true, at:取った時刻 }
```

| 項目 | 中身 |
| --- | --- |
| `pts` | 引退のときに決めたポイント。**あとで総合力が変わっても(名前・染色を変えても)増減しない** |
| `picks` | 効果の id → 段(1〜3)。id は英字で固定(boost・call・spark・fav・trust・calm・care・dojo・warm) |
| `done` | 取り終えた印。真になったら二度と書き換えない(取り直しなし)。偽の間だけ §5 の画面を出す |
| `at` | 取った時刻 |

- 読み込み: `asp` が無い・壊れている → アシストなし。`pts` は `Number.isFinite` で 0〜400 に丸める。`picks` は知らない id を捨て、段は 1〜3 に丸め、4種類を超えたら先頭4つ、値段の合計が `pts` を超えたら後ろから外す
- 合体で生まれた子は `asp` を持たない
- レンタルの表(`monsuc_lend`・PLAN §2)に `picks` を足す。借りる側で §3 の確かめ方を通す

## 8. 決めてほしいこと(おすすめが先頭)

1. **編成の効き(ランクごとの%)の置き場所**: ①(推奨)アシストと同じ足し算に入れる(1つの「集まった子の効き」になり、画面でも「この札 +84%」と1つで見せられる) ② 別の掛け算にする(ランクの%の段 × アシストの段。強い子がいると大きく伸びる・数字が膨らみやすい)
2. **足し算の上限**: ①(推奨)×3.0 ② ×2.5 のまま(アシストの得が上限で消えやすい) ③ 上限なし
3. **友情タッグの重ね方と上限**: ①(推奨)足し算(1 + 0.5 × 数)・上限なし ② 足し算・上限 ×2.5(3体ぶん) ③ 掛け算(1.5 × 1.5 …・3体で ×3.4)
4. **親密度の上がり(一緒の訓練1回)**: ①(推奨)+10(ばらばらの編成で訓練の半分ほどにタッグ) ② +6(タッグはまれ・1回の育成で5回ほど) ③ +15(ほとんどの訓練にタッグ)
5. **忠誠度の補正の幅**: ①(推奨)×0.8〜×1.2 ② ×0.9〜×1.1(控えめ) ③ ×0.7〜×1.3(忠誠が大事)

## 9. あとで(第2弾の候補・いまは作らない)

- 条件つきの効果: 育てる子と **主血統が同じ / 副血統が同じ / タイプ(5つ)が同じ** ときだけ効く、条件なしより強い効果(例: 同じ血統なら特訓の底力が倍)

- 大会のごほうび・人気の上がりを増やす効果
- 段を開く別の道(同じ子をくり返し編成に入れると段が上がる など)
