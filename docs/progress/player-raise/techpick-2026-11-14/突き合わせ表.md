# 被った升で覚える技を選ぶ仕組み(r1114-128・131)突き合わせ表

| 社長の決め | できた形 | 確かめた所 |
| --- | --- | --- |
| 1升に1技。同じ間合い・同じランクに2つ以上ある升は選べる印 | 升は1技、右上に ⇄(押せる)。升に出る技は「覚えた技 → 選んだ技 → 並びの1つ目」 | TP1(390・320) |
| ⇄ を押すと候補の技を並べて選ぶ窓。画面の文は漢字 | 「覚える技を選ぶ」窓に候補を並べる(技名・種類・消費ガッツ・ダメージ/命中率/クリティカル率・覚え方)。「選ぶ」「閉じる」 | TP2(390・320) |
| 選べる所: 育成を始める前のベースモンの詳細 | 育てる子の詳細(種族ごとに保存) | TP1〜TP3・monsuc-techpick-browser-check.js |
| 選べる所: 合体で生まれた子の詳細 | マスモンボックスの未育成の子の詳細(その子ごとに保存) | 画面の組み込みのみ(止め絵なし) |
| 育成中も、その技を覚えるまでは変えられる(覚えたあとは変えられない) | 育成中の詳細で ⇄ が出る。その升の技を1つでも覚えたら窓は「選び直せません」で固定 | 芯の単体確認 monsuc-techpick-check.js(`setTechPick`/`techPickLocked`) |
| 選ばなかった技はその升では覚えない | 修行の覚える候補(`learnable`)と覚える判定(`canLearn`)から外れる | monsuc-techpick-check.js |
| 既定は1つ目 | 選びが無い・壊れた升は並びの1つ目 | monsuc-techpick-browser-check.js(壊れた保存) |
| 保存は新しいキーか既存への項目足し・古いセーブで壊れない | 新しいキー `mh_monsuc_techpick_v1`(種族ごと/箱の子ごと)＋育成の状態に項目 `techPick`。項目の無い古い育成は絞らない | docs/spec/SAVE_DATA.md に追記 |
