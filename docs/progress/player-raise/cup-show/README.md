## おすすめで進めた点

- 組み合わせ表の人気の番号は演出(王者 1・ライバル 2・ほかは決まった乱数・自分は人気で上下)
- 相手の技は種の技表の先頭から芯の `techs` の数だけ・熟練は芯の値。相手の作戦の型は `atsu`(観戦の札には助手を出さず、育てた人の名前を出す)
- 試合の乱数の種は「育成の id + ターン + 大会 + 再戦の回数」。結果だけ見る・観戦・中断のどれでも同じ結果
- 特別な1話の効き目: guts→ガッツ・firstHit→最初の技の命中・crit→会心・eva→回避・techFail→はずれを減らす・noIdle→そっぽを向かない。noInjury・showFirst・line は見せるだけ(芯に入力がない)
- サイズ(ふつう/大きい)はデータが無いので出していない
