# 持ちこみアイテムの参考(社長 2026-11-12)

社長が参考ゲームの「もちもの」の画面を送ってきた(`docs/reference/line-mf/mochikomi/item-01〜12.png`)。
**決まり(社長)**: 効果も名前も参考のものをそのまま使う(博士だけはイッサ博士)。持ちこみは1回の育成で2つまで。始める前に効く物と育成中に使う物は色で分けて見せる。絵は参考に寄せて新しく作る(写さない)。
再戦の「時渡りの砂時計」「虹の時渡りの砂時計」は名前も効果もそのまま(TOURNAMENT.md §14)。

## 一覧(参考の名前 → 効果。モンヒロの名前の案は仕組みの担当が付ける)

1. 博士の導き書(item-01): 博士の大事な書類。1度、博士(モンヒロではイッサ博士)が現れる
2. 博士のルーペ(item-02): 博士のお気に入りのルーペ。博士の実験が成功する
3. 出会いのミサンガ(item-03): 交流を増やすミサンガ。ようす「イベントメーカー」を付ける
4. 週刊!トレーニング(item-04): ハウツー雑誌。ようす「トレーニング得意」を付ける
5. 修行のハチマキ(item-05): 気合いが入るハチマキ。ようす「修行得意」を付ける
6. 縁結びのお守り(item-06): 良縁に恵まれるお守り。ようす「スターの素質○」を付ける
7. モモのキビダンゴ(item-07): スタミナがつく。体力の最大値が初めから上がる
8. うけつぎ草(item-08): 伝授でいい結果を残せる草。ようす「うけつぐ魂」を付ける
9. ガロエ印の野菜ジュース(item-09): 育成中にも使える。体力を完全に回復する
10. 悪様散(item-10): 育成中にも使える。悪いようすを治して体力を回復する
11. ブリーダーライセンス(item-11): 育成中にも使える。忠誠度が一定数上がる
12. オイリーパック(item-12): オイル2個と薬草の詰め合わせ。育成中にも使える(中身のオイル=体力回復の小物)

## 分け方

- 始める前に使う物(1つの育成にかける): 7(体力の最大値)・3〜6・8(よいようすを付ける)・1(博士が1度来る)
- 育成中にも使える物(1ターン1個まで): 9・10・11・12・2(博士の実験の前に)
- よいようす(イベントメーカー・トレーニング得意・修行得意・スターの素質○・うけつぐ魂)は EVENTS.md の「ようす」に足す
