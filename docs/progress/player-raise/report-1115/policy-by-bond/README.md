# r1115-059 育成方針を甘え度と恐れ度の差で決める

差 = 甘え度 − 恐れ度(甘え度が多いほど甘い側・恐れ度が多いほどスパルタ側)。社長が決めた表のとおり:

| 差の大きさ | 方針 |
| --- | --- |
| 0〜4 | 普通 |
| 5〜10 | 甘い(甘え度が多い)/ 厳しい(恐れ度が多い) |
| 11〜15 | 溺愛 / スパルタ |
| 16以上 | 超溺愛 / 超スパルタ |

- 核: `polOfBond`・`syncPol`(monhero-success.js)。甘え度・恐れ度が動く所(addLoyal・addLoyalRaw)の最後と、保存から戻すときに方針を決め直す。ほめる・しかるの点(s.pp)では動かさない(保存の pp は読めるまま残す)
- 助手ライフのマスモン(56-assistant-life-masmon-calc.jsx の policyOf/policyMove)は変えていない
- 画面: 方針が変わった次の画面で、そのターンのあいだ助手が「育成方針が「甘い」に変わったよ」と知らせる(after-policy-changed.png)。「能力」の画面の説明も「甘え度と恐れ度の差で決まる」に
