## 追記: 合体中のボタン(success-r3-shoot F4・F5 の NG)

- 原因: 合体の見せ場の下のボタン `.mf-next`(56-monsuc-fuse.jsx)の字が左に寄っていた(「合体中…」が横 −148px)。揺れではなく本物のずれ。ミハリの手元で 0 だったのは、撮った時刻に見せ場が終わっていたためと思われる
- 直し: ボタンを flex で上下左右とも真ん中に。あわせて見出し「2体が1つになろうとしている…」が「してい/る…」と言葉の途中で折れていたので `jaWrap` で言葉の切れ目で折る
- 止め絵: `fuse-btn-center.png`(390)・`fuse-btn-center-s320.png`(320)。`ONLY=F4,F5,F6` で NG 0
