# r1115-046 オリジナルモンスターの技アイコン 案(技 → 種類 → 絵)

- 作り方: 同じ種類の資料の技アイコン(sk-####)から**形だけ**を抜き出し、技の雰囲気に合うオーラ色の地(枠と左下の紋も資料の物)に載せ替え、技の種の色(ちから=黄/かしこさ=緑)に塗り替える。資料に同じ種類が無い技(5つ)は、資料と同じ描き方(単色の面+暗い縁+効果線)で新しく描いた
- 同じ子の中で、別の技が同じ絵(同じ土台)にならないことを道具が確かめる(tools/success/skill-icons-original/make.py)
- 元が82×82の絵(クロミーの「悪夢フィナーレ」1つ)は資料のまま(右下の数字は画面の消費ガッツの札がかぶさる。資料の技と同じ扱い)
