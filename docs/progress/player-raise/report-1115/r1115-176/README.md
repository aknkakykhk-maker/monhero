### 全6能力型が4能力型より伸びる理由

全6能力型(通常 +565)は4能力型(+384)より 181 多い。内訳(後の数字):

1. 🗡 修行特別効果アップ: 上がる能力それぞれに足すので、命中・回避にも乗る。2能力 × 24(6体ぶん)× 1.92(⚔ +60% とハチマキ +20%)= 約 +92
2. 編成の得意の分: 命中・回避が得意の仲間の分(1位 3%)が命中・回避に入り、⚔とハチマキがかかる = 約 +95
3. 代わりに ちから・丈夫さ・ライフ は得意の仲間が半分になったので −14、かしこさは得意の仲間が増えて +8(合わせて −6)

いちばん差を広げているのは 1(能力の数だけ足す 🗡)。社長の決めどおり、全6能力型に上限は付けていない。
追加で抑えるなら(案だけ・入れていない): 🗡 を「行き先の4能力だけ」に足す、または 🗡 の分を ⚔ の倍率の外に出す。
