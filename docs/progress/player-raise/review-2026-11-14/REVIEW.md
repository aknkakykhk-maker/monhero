## ④ 参考資料との違い(実物を見て比べた)

2026-11-14 社長「参考資料を渡しているのに、全然参考にしてくれない」「画像とか動画とか、ちゃんと確認してるの?」を受けて足した欄。

### ④の所見(いちばん大きい違い6つ)

1. **結果の見せ方が根本から違う。** 参考はどの出来事でも、場面の中に「+5 命中」「+21 能力Pt」のメダルが飛び、下の箱に「命中が5上がった/◯◯の親密度が5上がった」と**上がった物を1行ずつ**出す(v1 6秒・v2 32秒・v2 50秒・v2 128秒・v4 140秒・te-172)。うちは「いい時間になった。」。②-1〜4 の直しは、この参考の形にそろえるのが近道。

3. **大会まわりの組み立て。** 参考は 受付の人+吹き出しに大会のロゴ → 確認の窓(賞金と賞品の絵)→ 賞品の詳細 → 読み込みの4コマ → 会場とロゴの入り → 表(自分がいちばん上・線が進む)→ 比べ → 設定 → 試合(30〜40秒)→ WON と決め技 → リザルト(写真の札・ピラミッド・人気・アイテム)。うちは流れの段は近いが、入り・線の進み・試合の中身・写真の札・人気の棒が無い。
4. **大会の名前と並び。** 参考は半月ごとに「星の名前の銀杯+花や虫の名前の銅杯」が必ず2つあり、同じ名前が次の年に賞金を上げて戻ってくる。その上に系統の大会(下の大会の優勝で出られる)が重なる。うちは「ちから自慢の大会」「間合い(零)」「タイプ(サポーター)」「ふつうの大会」という**仕組みの呼び名がそのまま大会の名前**で、覚えられる固有の名前が無い。下の「月ごとの大会の突き合わせ」。
5. **期末と最後の大会の名前がつながっていない。** 参考は期末が3回とも同じリーグ(6,000 → 7,000 → 8,000G)、最後が同じ名前のファイナルで、NEXT のはしごのいちばん上と、ストーリー選択の印にも同じ名前が出る(te-31・109・171 → te-174〜177・te-41・sc-01)。うちは「ジュニアしめくくり杯/ミドルしめくくり杯/冬のヒーロー記念/頂への道」と4つとも別の名前で、はしごのいちばん上は「最後」。最後の大会が「ヒーローズファイナル」に決まったので、期末を「ヒーローズリーグ」にそろえるとつながる。

**突き合わせから言えること**

1. **大会に固有の名前を付ける。** いまは仕組みの呼び名(ちから自慢・間合い(零)・タイプ(…)・ふつうの大会)がそのまま名前。参考のように「ふつうの杯」に名前の系統(たとえば 星・花・宝石・色)を持たせ、格(銅・銀・金)を色で見せる。系統の中身(能力・間合い・タイプ)は印で示せば足りる。
2. **並ぶ数の山と谷を作る。** 参考は、ふだんは2つ(銀と銅)、山場の月だけ4〜7つ。うちはミドル6月とプロ12月が12個、ジュニアはずっと2つで、どちらも選びにくい。
3. **「去年の杯にもう一度」を見せる。** 参考は同じ名前の杯がプロ期に賞金を上げて戻る。うちも `YEAR` は同じ並びをくり返しているので、名前が付けば自然にそうなる。
4. **期末と最後の大会の名前をそろえる。** 期末3回を同じ名前のリーグ(賞金だけ上がる)、最後を同じ名前のファイナルに。NEXT のはしご・ストーリー選択の印・受付の札にも同じ名前を出す。
5. **ジュニア期の能力の大会は条件を外すか下げる。** 参考の最初の能力の杯は条件なし。うちは1ターン目から「能力150以上」で、新しい人は出られない大会が先頭に並ぶ。
6. **賞品を絵で見せる。** 参考はどの大会も賞品が絵で並び、押すと効果が読める。うちは「✨ ごほうび」。
7. **四大大会の月。** 1つ目がミドル期の1ターン目(賞金ランクの条件に届きにくい)。参考は3ターン目。

## 何から直すと効くか(根が同じ物)

1. ①-1(1行)と ①-2(1行)を先に出す。どちらも小さく、遊べなくなる・押せないを止める
2. 「結果の段」の共通の部品(ひとこと+動いた数字の札+音)を作り、イベント・ほめる/しかる・休む/遊ぶ/通院・ごはん・アイテム・ランクアップで使う(②-1〜4・6・9)。同時に、帯と能力の数字を結果の段で動かす(①-11)
3. 曲の持ち主を場面1か所にまとめる(①-3)。メインに戻ったら必ず鳴る、を検査に
4. 試合(①-4・5・6・7・②-15・③-2・3)はキズナの後継の作り直しにまとめて渡す
5. 台詞を助手の台本から引く(①-15・16)。代わりの文が出た場面を数える検査
6. 通しの検査(`success-screen-browser-check.js`)に足すと、次から機械で止まる物: 月の大会の負け → あきらめる → 続きから/見えているボタンの高さと当たり判定/メインに戻ったときの曲/「準備中」「次の回で入ります」「参考」の字が画面に出ていない
