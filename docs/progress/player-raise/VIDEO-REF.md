# 育成中の参考動画のメモ(仕組みだけ)

2026-11-12 社長が LINEモンスターファームの育成中の画面の動画(30秒)を「参考動画」として送ってきた。他社の動画なので、リポジトリには入れない。画面の流れと仕組みの考え方だけ書く(絵・名前・文は写さない)。

## 画面の流れ(動画で見えたもの)

1. **メイン**: 上の帯に「期・残りターン」「総合力」「体力の棒(数字つき・例 9/103)」。真ん中に育てる子が大きく、住む場所の景色(家・木・花)。下に6能力が横一列(今の値と上限)。その下に行動のボタン(休養・トレーニング・遊ぶ・修行・大会 など)
2. **トレーニングを選ぶ**: 下に丸い訓練のボタンが6つ並び、それぞれ訓練のLv(Lv.1〜)と、そこに来ている編成の子の顔。右に来ている子の顔と親密度の棒。選ぶと6能力の上に、上がる量(+8 など)と下がる量が先に見える。体力の使う分も棒で見える
3. **結果**: 訓練の絵(丸太を叩くなど)と大きな「大成功」の字。下の文に「ライフが1上がった」など
4. **叱る/褒める**: 助手が出てきて「ほめてあげる?」→「ほめる」「ほめない」の2択
5. **編成の子の連続イベント**: 町の景色で、編成の子たちが会話する小さな話(「アシストカードイベント1」のような見出し)
6. **トレーニングの結果の別の形**: 浜辺などの景色に子がいて、下の文に「丈夫さが3上がった/体力が28下がった/◯◯の親密度が4上がった」
7. **ターンが進む**: 時計の絵の短い演出 → メインに戻る

## モンサクに当てはめるとき

- メイン画面の案A(住む場所が大きく・下に行動のボタン)と同じ組み立て。上の帯に体力の棒(数字つき)を出す
- 訓練を選ぶ画面で「上がる量・下がる量・体力の使う分」を先に見せる
- 結果 → 叱る/褒める → 出来事 → ターンが進む の順。ふだんは短く(台帳)

# 参考動画2(161秒・デビュー期の大会まで)

2026-11-12 社長の2本目の参考動画。実物は `docs/reference/line-mf/ikusei-video-2-2026-11-12.mp4`(個人で遊ぶ用に保存してよい・ゲーム内には使わない)。

## 画面の流れ

1. **育成イベント**(見出し「育成イベント ◯◯」): 住む場所の景色で、助手と子の短い会話(遊んだあとの一言など)。どの帯にも「期・ターン・総合力・体力の棒」が出たまま
2. **アシストカードイベント**: 町の景色で編成の子2人の会話(連続イベントの1話)。話の途中に景色だけの地の文も入る
3. **休んだあと**: 子が寝ている絵と「体力は満タンだ」
4. **大会のエントリー**: 受付の人が「どの大会に参加しますか?」。上に「◯年◯月後半」、大会の札(デビュー戦・賞金1,000G・星の数)。下に「大会予想」「出場」「予約一覧」
5. **読み込み中のヒント**: 4コマ漫画で仕組みの説明(「仲間と一緒にトレーニング → 親密度が上がると『応援』が発生 → 誰も応援してくれないと寂しい」)
6. **組み合わせ表**: 8体のトーナメント表、下に解説の人の一言(「1番人気は◯◯」)
7. **試合の前**: 自分と相手の能力を棒で並べる(6能力・人気・間合いの適性・地形の適性・大きさ)。「結果だけ見る」「準備完了」の2つ
8. **試合 → 勝利**: 子の大きな絵 → 「勝利」とアイテム獲得(修行チケット)
9. **メインストーリーイベント**: 「称号獲得!!」の札と、文「ちからが5上がった/能力Ptを21Pt獲得した/◯◯の称号を得た」
10. **ターンの区切り**: 子の大きな絵と「ちからが15上がった」→ 上の帯が「ジュニア期 12ターン」に変わる → 次の育成イベント

## モンサクに当てはめるとき

- 上の帯(期・残りターン・総合力・体力の棒)は、会話中もずっと出しておく
- イベントの見出しを3種類に分ける: 育成イベント(助手と子)/編成の子のイベント(連続3話)/メインのお話(称号・能力ポイント)
- 大会は「受付 → 組み合わせ表 → 能力の比べ → 試合(結果だけ見るも選べる)→ 賞品」。勝つと称号と能力ポイント(TOURNAMENT.md の流れと同じ)
- 仕組みの説明は、読み込み中の4コマのように絵で短く見せる(友情タッグ・親密度など)
- デビュー期が終わるとすぐジュニア期の12ターンに入る(TOURNAMENT.md の期の長さと合う)

# 参考動画3(49秒・修行とアイテム)

2026-11-12 社長の3本目。実物は `docs/reference/line-mf/ikusei-video-3-2026-11-12.mp4`。

## 画面の流れ

1. **アシストカードイベント**(続き): 部屋の中で編成の子2人の会話
2. **メイン**: ボタンは2段。上の段「休養・トレーニング(大きい)・能力(ポイントの数字つき)」、下の段「診療所・あそぶ・修行(残り回数の印)・大会(予約の状態)」。左下に持ち物の袋(印つき)、右下に詳細。帯の下に助手の一言の吹き出し。上に「イベントミッション達成」の知らせ
3. **持ち物**: アイテムの一覧と説明 →「使用する」。アイテムは1ターンに1個まで
4. **修行**: 師匠の人が出てきて一言。上に選んだ技(2つまで)、下に「覚えられる技の一覧」(間合いごとの列・それぞれに覚える率%)。下に「修行の残り 2/2」と「修行する(チケット 3→2)」
5. **修行の場面**: 「STAGE 1 命中&ライフ」→「STAGE 2 丈夫さ&回避」と2段。景色が段ごとに替わる(火山・氷山)。編成の子の顔が並ぶ
6. **結果**: 「技習得失敗…(次回 技習得率アップ!)」と、上がった能力・下がった体力・「技を覚えることは出来なかった」
7. **褒める/叱る** → メインへ戻る(ターンが1つ進む)

## モンサクに当てはめるとき

- メインのボタンに「修行」(技を覚える・チケットを使う・期ごとに回数あり)と「診療所」(通院)と「持ち物」を置く。ごはんは大会のあとのご褒美(台帳)
- 修行は2つの能力を2段で上げ、最後に技を覚えるくじ。失敗すると次の率が上がる(救済)
- アイテムは1ターンに1個まで
- 能力ポイントの数字をメインのボタンに出しておく(引退のときにまとめて使う決まり。TOURNAMENT.md)
