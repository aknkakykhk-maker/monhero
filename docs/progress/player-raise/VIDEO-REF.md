# 育成中の参考動画のメモ(仕組みだけ)

2026-11-12 社長が LINEモンスターファームの育成中の画面の動画(30秒)を「参考動画」として送ってきた。他社の動画なので、リポジトリには入れない。画面の流れと仕組みの考え方だけ書く(絵・名前・文は写さない)。

## 画面の流れ(動画で見えたもの)

1. **メイン**: 上の帯に「期・残りターン」「総合力」「体力の棒(数字つき・例 9/103)」。真ん中に育てる子が大きく、住む場所の景色(家・木・花)。下に6能力が横一列(今の値と上限)。その下に行動のボタン(休養・トレーニング・遊ぶ・修行・大会 など)
2. **トレーニングを選ぶ**: 下に丸い訓練のボタンが6つ並び、それぞれ訓練のLv(Lv.1〜)と、そこに来ている編成の子の顔。右に来ている子の顔と親密度の棒。選ぶと6能力の上に、上がる量(+8 など)と下がる量が先に見える。体力の使う分も棒で見える
3. **結果**: 訓練の絵(丸太を叩くなど)と大きな「大成功」の字。下の文に「ライフが1上がった」など
4. **叱る/褒める**: 助手が出てきて「ほめてあげる?」→「ほめる」「ほめない」の2択
5. **編成の子の連続イベント**: 町の景色で、編成の子たちが会話する小さな話(「アシストカードイベント1」のような見出し)
6. **トレーニングの結果の別の形**: 浜辺などの景色に子がいて、下の文に「丈夫さが3上がった/体力が28下がった/◯◯の親密度が4上がった」
7. **ターンが進む**: 時計の絵の短い演出 → メインに戻る

## モンサクに当てはめるとき

- メイン画面の案A(住む場所が大きく・下に行動のボタン)と同じ組み立て。上の帯に体力の棒(数字つき)を出す
- 訓練を選ぶ画面で「上がる量・下がる量・体力の使う分」を先に見せる
- 結果 → 叱る/褒める → 出来事 → ターンが進む の順。ふだんは短く(台帳)

## モンサクに当てはめるとき

- 大会の画面は、受付の人の吹き出し+月の切り替え+大会の札+確認の窓の形にする。賞金は G で大きく(名声は賞金に統一済み)。賞品はアイテムの絵で見せ、押すと詳細
- 出られない大会も並べて、理由を重ねて見せる
- 覚醒は、見出しの帯 → 子が画面いっぱい → 気が噴き出す、の順で溜めを作る
