## 0. ひとことで

1体のモンスターを、**1ターン=1週** で、そのモンスターの **寿命(週の数)** が尽きるまで育てる。毎週「何をするか」を1つ選び、結果を見て叱る/褒める。
毎月の大会でランクを上げ、休養・ごはん・修行で整える。寿命が来ると **引退** して保管場に入る。
保管場の子は **バトルに出せる**、そして **2体を合体させて新しい子を生み、1から育て直せる**。
**今のマスモン(`mh_masu_mons`)・モンヒロバトル・カード・既存のランキングの強さには触れない**(どのバトルに出せるかは聞くこと 1)。

## 1. 1回の育成の流れ

### はじめる

1. **育てる子を決める**: 「新しく迎える」(解放済みの種類から1つ・`mh_unlocked_monsters` を読むだけ)か、「合体で生まれた子」(下の3)
2. **コーチの助手を1人選ぶ**(解放済みの助手だけ。下の5)
3. 成長の型がくじで決まる(合体の子は主の親の型を受け継ぐ)。名前を付けて始める

### 寿命(週の数)

- 寿命 = 種ごとの基本(**普通 約150週=約3年**。種で 130〜170週)× 方針の比(助手マスモンの寿命の比をそのまま: 超溺愛 ×1.33 〜 普通 ×1 〜 超スパルタ ×0.67)
- 年齢の部品へは「いまの週 ÷ 寿命」を入れる(方針が途中で変わったら、残りの週が伸び縮みする。助手マスモンと同じ「寿命の進み」の足し方)
- けが・病気は寿命を少し縮める(1回 −1〜2週)。大切に育てるほど長く育てられる
- 1ターンは結果をさっと見せて **3〜6秒**。1回の育成は **約15〜25分**(大会の観戦を速送りにした目安)。1週ごとに保存し、いつでも中断して続きから

### 1週(1ターン)にすること

上に「2年目 6月 3週(98/150)」と残りの目盛り。6能力(ライフ・ちから・かしこさ・命中・回避・丈夫さ)・疲れ・ストレス・忠誠・人気・成長の曲線の「いまここ」。コーチの一言。下にコマンド。

| コマンド | 中身(数字は助手マスモンの訓練の表を使い回し、週の数に合わせて倍率を決める) |
| --- | --- |
| 💪 軽い訓練(6つから1つ) | 主の能力 +中・疲れ +・ストレス 少し + |
| 🔥 重い訓練(6つから1つ) | 主 +大・副 +小・ほかの能力が少し下がる・疲れ ++・ストレス + |
| 🛌 休む | 疲れ −大・ストレス −小 |
| 🎈 遊ぶ | ストレス −大・疲れ −小・忠誠 +(コーチとの出来事が起きやすい) |
| ⚔ 修行(4週かかる・年に2回まで) | 技を1つ覚える/熟練を上げる/能力が少し上がる。行き先(場所)で覚える技が違う。修行中のできごとがときどき |
| 🏆 大会に出る(その月の大会の週だけ) | 下の「大会」 |

- 伸び = 種の伸びやすさ × 成長の型(週 ÷ 寿命)× 方針 × コーチの得意(下の5)× 結果
- **結果**(助手マスモンと同じ5種類): 🌟大成功 / ⭕成功 / ❌失敗 / 🤫ズル / 💤サボり。結果のあと「📣 叱る」「👏 褒める」を1回(しなくてもよい)→ 忠誠と方針が動く
- **けが・病気・家出**: 起きる条件は助手マスモンと同じ。長さは週で数える(けが2〜4週・病気2〜3週・家出1〜2週)。その間は休み扱い
- **月のはじめ(4週に1回)に「ごはん」** を選ぶ(安い・ふつう・ごちそう の3つ。ごちそうは忠誠・ストレスに良いが、育成の中のお金「名声」を使う)
- 疲れ・ストレスの「見える数字」は出さず、コーチの一言と表情で分かるようにする案(モンスターファームの考え方。上級者向けに「くわしく見る」で数字も出す。下の6)

### 大会(毎月)

| 大会 | いつ | 出られる | 勝つと |
| --- | --- | --- | --- |
| クラス戦(E・D・C・B・A・S) | 毎月の第4週 | 今の大会ランク以下 | 名声・人気 + |
| 昇格戦 | 年4回(3・6・9・12月) | 今の大会ランクの1つ上へ | 勝てば大会ランクが1つ上がる |
| 大きな大会(年1回) | 12月 | B以上 | 称号・名声 大 |

- 試合は **助手マスモンの対戦の芯**(1対1)。観戦の画面も助手マスモン対戦の物を使い回す(速送り・とばすあり)。相手は「大会の相手を作る部品」(下の7)
- 出ない月があってもよい(育てる方を優先できる)。大会の前の週に重い訓練をすると疲れたまま出ることになる、などの組み立てが遊びの中心

### 引退(寿命が来たとき)

- 寿命の週が来たら **引退**(消えない)。途中で「ここで引退する」も選べる
- 引退の振り返り: 能力の伸びの線・大会の成績・コーチの一言
- **評価**: 総合力(キズナの式)+ 大会ランクと勝ち星 + 忠誠・人気 → **育成ランク G〜M**(キズナのランク表を使い回す)
- 保管場へ入る(下の2)

## 2. 育て終えた子: 保管場とバトル

### 保管場

- 引退した子が入る別枠(**はじめ20体・最大50体**。今のマスモンの一覧とは別)。並び替え・くわしい画面(助手マスモンのくわしい画面の部品を読むだけの形で)
- いっぱいのときは、お別れ(2回確かめる・「思い出」に名前とランクだけ残る)か、合体で数を減らす

### バトルに使う(強さのつり合いを壊さない形)

保管場の子の強さは **6能力の線**(助手マスモンと同じ物差し)。今のモンヒロバトル(4能力・絆Lv・強化・固有技)とは物差しが違うので、**どのバトルに出せるか** を社長に選んでもらう(聞くこと 1)。どの案でも次を守る。

- **クラス分け**: 出場するときに育成ランク(G〜M)でクラスを分ける(G〜D / C〜B / A〜S / SS以上・無差別)。上のクラスの子は下のクラスに出られない
- **持ち込みの上限**: 6能力は999で止まる(合体で上限は上げない)。技は8つまで
- **既存のランキングへは送らない**。モンヒロサクセスのランキングは新しい表を足すだけ(Supabase は窓口の判断で。今は触らない)
- 対戦の計算はサーバと同じ芯(`assistant-masmon-battle.js`)。保管場の子は引退したら能力が動かないので、サーバの見張りは「引退のときの値の写し」と「合体の式」で確かめられる

| 案 | 出せるバトル | つり合いへの効き |
| --- | --- | --- |
| ①(推奨) | **モンヒロサクセスの対戦だけ**: 保管場の3体でチーム → フレンド対戦(非同期)・クラス別のランキング・月ごとの大会(ほかのプレイヤーのチームの写しと戦う) | 既存には効かない |
| ② | ①+**助手マスモンのフレンド対戦にも出せる**(同じ6能力。クラスを助手マスモンのランクに合わせる) | 助手マスモンの対戦の見張り(1日の伸び)とは別の扱いが要る。対戦の受け持ちと相談 |
| ③ | ①+**今のモンヒロバトルの一部**(例: 新しい「サクセス杯」だけ)に、4能力へ換算して出せる | 換算の式と上限を新しく決める。既存のチャレンジ・ランキングには出さない |

## 3. 合体(新しい子を生んで1から育て直す)

1. 保管場から **主の親** と **もう一方の親** を選ぶ
2. 生まれる子の **種類** と、はじめの6能力の見通し・受け継ぐ技・型を見る
3. 最後の確認(親がどうなるか・聞くこと 3)→ 生まれた子でそのまま新しい育成を始める(寿命は新しく・年齢0)

- **6能力**: 助手マスモンの合体の式をそのまま使う ── 「生まれた種類の初期値 + 上乗せ(2体の平均を元に・そろいで効く・上限なし。平均999で約+200)」
- **技**: 親の技のうち、生まれた種類でも覚えられる技を2つまで最初から覚えている(熟練は0から)
- **成長の型**: 主の親の型を受け継ぐ(くじで別の型になることも少し)
- **世代**: 「◯代目」を数える。代を重ねるほどはじめが強く、上のランクに届きやすい(合体を重ねる遊び)

## 4. 毎日・長く遊ぶ理由(回数の上限はなし)

- 回数の制限はなし(社長)。1回が15〜25分なので、遊ぶ量は時間で自然に決まる
- 長く遊ぶ理由: ① 合体で代を重ねて M を目指す ② 種ごとの最高ランク(30種の図鑑・S で称号) ③ クラス別のランキングと月ごとの大会 ④ 助手ごとのイベントを全部見る ⑤ ミッション(今の仕組みに足す)
- ごほうび(今のマスモンへの見た目の称号・既存の物を少し)は、**1回の引退ごとに1度だけ**・回数の上限が無いので **1日にもらえる量の上限** を付ける(数は経済の担当と窓口で)

## 6. ターンごとのことば(助手・モンスター)

考え方(モンスターファームの「場面ごとに何を言うか」を参考に、言い回しは写さない):
**コーチは数字を言わず、様子で伝える**(疲れていそう・機嫌がいい・いまが伸びどき)。プレイヤーは一言を読んで次を決める。

| 場面 | だれが | 何を言うか | 1人あたりの本数 |
| --- | --- | --- | --- |
| 週のはじめの様子 | コーチ | 疲れ・ストレス・機嫌を5段で(元気〜危ない) | 5段 × 2 = 10 |
| 訓練の結果 | コーチ | 大成功〜サボりの5種類への反応 | 5 × 2 = 10 |
| 叱る/褒めるのあと | コーチ | 合っていた/合っていなかった × 叱る/褒める | 4 × 2 = 8 |
| 年齢の節目 | コーチ | ピークに入った・ピークを過ぎた・寿命が近い | 3 × 2 = 6 |
| 月のはじめ・ごはん | コーチ | ごはんの3つへの一言 | 3 |
| 大会 | コーチ | 出る前・勝った・負けた・昇格した | 4 × 2 = 8 |
| 引退 | コーチ | 評価の段(G〜D/C〜B/A〜S/SS以上) | 4 |
| けが・病気・家出 | コーチ | 起きた・治った | 6 |
| イベント | コーチ+モンスター | 4話 × 5〜6行 + 特別な1話 | 約 30 |
| **助手1人の合計** | | | **約 85本** |
| モンスターの反応 | モンスター | 鳴き声と気分(うれしい・いやがる・すねる・得意げ など8つ)。言葉ではなく短い声と表情。種ごとの鳴き声1語 × 30種 | 共通 40 + 30 = **70本** |

- 合計の見込み: 85 × 8人 + 70 = **約 750本**
- 一度に全部は書かない: **第1弾は みゅあ・あつ の2人(約 240本)** で公開し、残り6人は順に足す(コーチに選べる助手が増えていく)
- 台本は助手部(コトバ・ココロ)。場面と本数の表はこちらで用意する

## 7. 使い回す部品と、足りない部品

### そのまま使う(キズナ・対戦の受け持ち)

| 部品 | モンヒロサクセスでの入れ方 |
| --- | --- |
| 伸び(訓練の伸び・失敗) | 1週の訓練 = 助手マスモンの1回の訓練 × 倍率(150週で M に届くかを試算で合わせる) |
| 成長の型とピーク | 割合 = いまの週 ÷ 寿命の週 |
| 叱る/褒めると育成方針 | そのまま(10点で1段)。方針で寿命の週の数も変わる |
| 忠誠度・人気 | そのまま(大会で「動かない番」・クリティカル率も効く) |
| 総合力とランク | 引退の評価のもと |
| 合体 | 6能力の式をそのまま(種類の決め方だけ上の3) |
| 対戦の芯・観戦 | 大会とバトル |

### 足りない部品(頼む候補)

1. **年齢の時計を「週(ターン)」で回す入れ口**: けが・病気・家出の長さと寿命の進みを「回数」で渡せる形
2. **大会の相手を作る部品**: クラス(E〜S)と種とくじの種(seed)から、決まった1体を作る(同じ種なら同じ相手)
3. **評価の式**: 総合力 + 大会の成績 + 忠誠・人気 → 育成ランク
4. **合体の種類を血統で決める部品**(案①を選んだとき): 親2体 → 子の種類。`lineages.js` を読むだけ
5. **週の訓練の決まった乱数**: 「育成の id + 週」から引く(開き直しても結果が変わらない)
6. **週単位の試算の道具**(こちらで作る): 寿命・型・方針・コーチごとの終わりの6能力とランクの分布、代を重ねたときの届き方

## 10. 社長に聞くこと(大きな分かれ道だけ・おすすめが先頭)

## 11. 止め絵の依頼に使う「画面の一覧と、それぞれで見せたいもの」(窓口が fable に1回だけ頼む用)
