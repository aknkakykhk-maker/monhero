## 0. ひとことで

**育てる1体** を、**全46ターン**(1ターン=1か月の案)で育てる。毎ターンひとつ行動を選ぶと、**編成のマスモン6体** がそれぞれ得意な訓練に集まっていて、集まった訓練ほどよく伸びる。
助手は方針・様子・体調の見張り・お話の役。期ごとの大会で上の星をめざし、46ターン目(または最後の期の大会で負けたとき)に引退して **保存枠** に入る。
保存枠の子は、次の育成の **編成** になり(強い子ほど伸びを押し上げる)、**フレンドに貸せて**、**バトル** に出られ、**合体** して新しい子を生む。

## 1. 1回の育成の流れ

### はじめる

1. **育てる子を選ぶ**(決まった): ベースモン(下の「ベースモン」)か、**保存枠の「合体で生まれた未育成の子」**。引退した子はそのまま育て直さない(編成・バトル・サクセス杯・合体の材料になる)
2. **編成**: 保存枠から5体まで+フレンドから1体(任意)。空いた枠はベースモンで埋まる。編成は「いつもの編成」として覚えておく
3. **助手を1人選ぶ**(解放済みの助手だけ・下の4)
4. 成長の型がくじで決まる(保存枠の子・合体の子は決まった型)。名前を付けて始める
5. **名前と染色を決める**(決まった・2026-11-12 社長): 始めるときに名前と染色(今の染色のしくみ・部位ごとの色)を決められる。**育成を終えた子(保存枠)も、あとからいつでも名前と染色を変えられる**。名前は言葉の見張りに通す。染色の値は保存枠の子の中に足す(新しいキー)

### ベースモンとは

- **ベースモン = モンスターの「種」そのもの**(図鑑の30種・`ALL_PLAYER_MONSTERS`。今のゲームでもこの呼び名で使っている)。育てた中身を持たない、まっさらな1体
- 手に入れ方: **今のゲームで解放している種**(`mh_unlocked_monsters` を読むだけ)がそのまま使える。新しく手に入れる物は要らない
- 育てる子に選ぶ: その種の初期値(Lv1)から始める
- 編成の枠を埋める: 空いた枠は、育てる子と同じ種+解放済みの種から自動で入る。**効きはいちばん弱い**(下の2)

### 期とターン数(決まった・2026-11-12 社長「ターン数長いね」)

- **デビュー期 5・ジュニア期 12・ミドル期 12・プロ期 12・最後の期 5 = 合計46ターン**。くわしくは [TOURNAMENT.md](TOURNAMENT.md) §1
- デビュー・ジュニア・ミドル・プロは **期末に強制大会**(ターンを使わない・ターン数に数えない)。**デビュー戦に負けると、ジュニア期は勝つまで毎ターン強制大会(再挑戦)で、訓練ができない**(TOURNAMENT.md §1b)。最後の期は **残り3ターンから毎ターン大会** で、負けたらそこで育成が終わる
- **1ターン = 1か月**(案。窓口へ確認中)。デビューは1年目8〜12月、ジュニア・ミドル・プロがそれぞれ1年(1〜12月)、最後は5年目1〜5月。四季の大会がどの期にも1回ずつ来る
- **方針・種で期の長さは変えない**(案。窓口へ確認中)。助手マスモンの「方針で寿命が伸び縮み」は使わず、方針は伸び・けがの起きやすさ・忠誠の動きだけに効かせる。「この期の残りターン」が動かない
- 年齢の部品へは「いまのターン ÷ 46」を入れる(成長の型とピークもこの割合で決まる)
- けが・病気は長さを縮めない。そのターンが休みになるだけ
- 1ターンは結果をさっと見せて **3〜6秒**。1回の育成は **約8〜15分**(大会の観戦を速送りにした目安)。1ターンごとに保存し、いつでも中断して続きから

### 1ターンにすること

上に「ミドル期 残り7ターン(最後まで 22)」と期の目盛り。6能力(ライフ・ちから・かしこさ・命中・回避・丈夫さ)・忠誠・人気・成長の曲線の「いまここ」。助手の一言。
下に訓練の札。**札ごとに、そのターンに集まった編成のマスモンの顔が並ぶ**(だれも来ていない札もある)。

| コマンド | 中身(数字は助手マスモンの訓練の表を使い回し、46ターンに合わせて倍率を決める。1ターンの伸びは148ターンの案の約3倍が目安) |
| --- | --- |
| 💪 軽い訓練(6つ) | 主の能力 +中・疲れ +・ストレス 少し + |
| 🔥 重い訓練(6つ) | 主 +大・副 +小・ほかの能力が少し下がる・疲れ ++・ストレス + |
| 🛌 休む | 疲れ −大・ストレス −小 |
| 🎈 遊ぶ | ストレス −大・疲れ −小・忠誠 + |
| ⚔ 修行(1ターン・各期1回まで) | 技を1つ覚える/熟練を上げる/能力が少し上がる。行き先で覚える技が違う |
| 🏆 大会に出る(出ればそのターンを使う。強制大会は別) | 下の「大会」 |

- 伸び = 基礎数値 × 素質 × 方針 × 時期(成長の型・ターン ÷ 46)× 結果 ×(1 + 編成の効き + アシスト)× 友情タッグ × 忠誠度の補正(1本の式は [ASSIST.md](ASSIST.md) §4・社長 2026-11-12)
- **結果**(決まった・社長 2026-11-12): 🌟大成功 ×1.5 / ⭕成功 ×1 / ❌失敗 ×0(上がらない)/ 💤サボり ×0.3 の4種類(倍率は社長 2026-11-12「失敗は上がる数値0、サボりは30%」)(ズルは無い)。結果のあと「📣 叱る」「👏 褒める」を1回(しなくてもよい)→ 忠誠と方針が動く
  - **サボり**は、育成方針が「普通」より甘い(甘い・溺愛・超溺愛)ときだけ、確率で起きる(甘いほど起きやすい)。普通〜厳しい側では起きない
  - **失敗**は、体力が上限から見て一定の割合より下がると、失敗の確率がどんどん上がっていく(上限の何%から・どれくらいの上がり方かは試算で決める。体力の上限が上がった子は、同じ体力の数でも失敗しにくい)

- **ターンのはじめに「ごはん」**(安い・ふつう・ごちそう)。ごちそうは忠誠・ストレスに良いが、育成の中のお金「名声」を使う
- 疲れ・ストレスは数字を出さず、助手の一言とモンスターの表情で伝える(「くわしく見る」で数字も出す)

## 2. 編成(マスモン6体)

### 親密度と友情タッグトレーニング(決まった・2026-11-12 社長)

- 育成中は、**編成のマスモン(6体)と助手のそれぞれに親密度**がある。トレーニングを一緒にするなどで上がる
- 親密度が一定まで上がった子(助手)がそのトレーニングに集まっていると、**友情タッグトレーニング**になり、トレーニングの効果が上がる
- **タッグになる子が多いほど効果が重なる**(2体なら2体ぶん)
- **はじめの親密度**: ベースモンより育てたマスモン(保存枠の子)のほうが高めから始まる。助手は、今のゲームでの親密度(仲良し度)が高いほど高めから始まる
- 一定の値・上がり方・効果の大きさは、案を作る会話で決める(社長に聞くときは選択式で)

### モンサク専用の能力(決まった・2026-11-12 社長。中身は参考資料が届いてから)

- **育成を終えた子は、モンサク専用の能力を取れる**(例: トレーニングの効果アップ・修行の効果アップ)
- その子を**育成中の編成に連れていくと有利になる**(上の「編成の効き」に重なる)
- **取り方(決まった・2026-11-12 社長)**: 育成を終えたとき、**最終の総合力(総合評価)に応じてポイント**がもらえ、そのポイントで**アシスト能力**を選んで取る(育成の最後の画面で)。総合力が高いほど多くもらえる
- 種類・強さ・ポイントの数・何個持てるかは、社長が追って貼る参考資料を見てから決める。保存は保存枠の子の中に足す(新しいキー)
- **案(第3版)**: [ASSIST.md](ASSIST.md)(9種類・条件なし・ポイントは総合力 ÷ 50・1体4種類まで・育成の最後に1回だけ・伸びの式・親密度とタッグ・編成の子との訓練イベント・忠誠度 = 甘え度 + 恐れ度)
- **アシストの基本値(決まった・2026-11-12 社長)**: タッグの強さはランクで 15〜35%(ベースモン 15%・B 25%・M 35%・助手 25%)/はじめの能力は「1位の値 ÷ 25」/得意率は一律 65%(かけつけで上限 90%まで)/4位以下の訓練は補正 0%・アシストは効く。くわしくは ASSIST.md §0b・§8

### 編成の効き(1体ぶん・能力ごと。社長 2026-11-12)

社長「ステータスの高さで補正が変わる。上位3位から選ばれる。順位ごとに補正値が少し下がる」「これにさらにアシスト能力も加味される」。
前の「ランクの%を一律+得意1つだけ×1.5」は置きかえた。式と例は [ASSIST.md](ASSIST.md) §4・§4a。

- 引退したときの **6能力の上位3つ** に補正が付く。**1位がいちばん大きく、2位・3位と少しずつ下がる**(例: ちから 15%・命中 12%・回避 10%)
- 大きさは **その能力の高さ** と **ランク** で決まる: `補正(%) = その能力の値 ÷ 40 × 順位の係数(1位 1.0・2位 0.9・3位 0.8)+ ランクの上乗せ`
- ランクの上乗せ: G・F +0 / E・D +1 / C +2 / B +3 / A +4 / S +5 / SS・SSS +6 / M +8
- 4位以下の能力の訓練では **能力の補正は 0%、その子のアシスト効果は効く**(社長「アシスト効果はきく。トレ補正はなし」)
- ベースモン(空いた枠)は種の初期値なので、1位でも 3〜4% ほど(いちばん弱い)
- その訓練に集まった子ごとに「能力ごとの補正 + いっしょ型アシスト」を足す。3体以上集まったら +10%。**上限なし**

```
その訓練の足し算 = 1 + Σ(集まった子の「その能力の補正」+ その子のいっしょ型アシスト)+ 3体以上なら +10%
```

- だから **強い子を育てる → 編成に入れる → 次の子がもっと伸びる** のくり返しが長く遊ぶ芯になる(合体と並ぶもう1本の道)。どの能力を伸ばしたかで、編成で効く訓練が変わる
- 編成の子が対戦に出ることはない(育成の中の伸びだけ)。編成に使っても疲れたり減ったりしない

### 集まりやすい訓練(上位3つ)

- 1体ごとに **集まりやすい能力が3つ**(引退のときの上位3つ・同じ値なら種の伸びやすさ `AMG_APT` が高い方)。「かしこさの編成がほしいから、かしこさを1位に育てる」という狙いが立つ
- ベースモンは種の伸びやすさの上位3つ。合体で生まれて育てる前の子は、主の親の上位3つ
- 毎ターンの集まり方: **1位の訓練 30%・2位 20%・3位 15%**・ほかの訓練に散らばって 20%・来ない 15%(決まった乱数・育成の id + ターン)。軽い/重いは半々。休む・遊ぶ・修行には来ない
- 札に顔が並ぶので、プレイヤーは「どの札に何体来ているか」を見て選ぶ。体力・ストレスとのせめぎ合いが毎ターンの悩みどころ

## 3. 保存枠と合体

### 保存枠

- 引退した子・合体で生まれた子が入る別枠(今のマスモン `mh_masu_mons` とは別)
- **上限: はじめ30体・最大60体**(引退10回ごとに+5)。編成6体ぶん+合体の材料+合体で生まれた未育成の子をためられる数
- いっぱいのときは、お別れ(2回確かめる・「思い出」に名前とランクだけ残る)か合体で減らす。新しく入れられないだけで、自動では消さない

### 合体

1. 保存枠から **主の親** と **もう一方の親** を選ぶ
2. 生まれる子の種類・はじめの6能力の見通し・受け継ぐ技・型を見る
3. 最後の確認(決まった: 親2体とも保存枠から外れ、「思い出」に名前・ランク・代が残る。2回押す)→ 生まれた子は保存枠へ(未育成)。そのまま育成を始めてもよい

- **6能力**: 助手マスモンの合体の式 ──「生まれた種類の初期値 + 上乗せ(2体の平均を元に・そろいで効く・上限なし。平均999で約+200)」
- **技**: 親の技のうち、生まれた種類でも覚えられる技を2つまで(熟練は0から)
- **型**: 主の親の型を受け継ぐ(くじで別の型になることも少し)
- **世代**: 「◯代目」を数える
- **生まれる子の種類**(決まった: 血統で決まる) ── 子の主血統=主の親の主血統、子の副血統=もう一方の親の主血統か副血統(くじ)。その組み合わせのモンスターがいればその種類、いなければ主の親の種類(例: ウンディーネ + モッチー → ヤオビクニ)。血統の正本 `monster-hero/data/lineages.js` を読むだけ

#### 換算の式(6能力 → 4能力・案)

```
割合(x) = 0.8 + (その能力 ÷ 999) × 0.8          … 0 で ×0.8、999 で ×1.6
ライフ   = 種の baseHp   × 割合(ライフ)
ちから   = 種の baseAtk  × 割合(ちからとかしこさの高い方 × 0.7 + 低い方 × 0.3)
丈夫さ   = 種の baseDef  × 割合(丈夫さ)
ガッツ   = 種の baseGuts × 割合((命中 + 回避) ÷ 2)
```

- 例: モッチー(基礎 ライフ720・ちから140・丈夫さ140・ガッツ140)で6能力みな500 → ライフ 約1,008・ちから・丈夫さ・ガッツ 約196(基礎の約1.4倍)
- 距離適性は種のまま。固有技は種の固有技で、Lv は覚えた技の熟練の平均から 1〜9(熟練0 → Lv1・100 → Lv9)
- 強化ポイント・限界突破・魂格・継承技は持たない(マスモンの育成の物は入れない)
- **幅(×0.8〜×1.6)は仮**。ジン(バトル部)の返事: 「プロと同じ流れで `Suc` を別枠にする作りは、バトル側の仕組みと相性が良い」「倍率は机の上では言えない。測るなら6能力が全部 0・500・999 の3パターンをプロの各段階と戦わせるのが最小」「測るのは重い調査なので窓口の了解のあと」
- タクティクスの公開の予定とぶつからないかは窓口が確かめる
- 数字は段取り5b の前に、窓口の了解でジンが測って決める(それまで ×0.8〜×1.6 で作る)
