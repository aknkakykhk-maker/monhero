- 参考にするのは**仕組みの考え方だけ**(画面・用語・絵は写さない)。画面の言葉はうちの言葉(マスモン・助手・修行・方針・ピーク など)

- 使い回す部品: 助手マスモンの計算(キズナが作っている。入力は「育成期間のうち何割まで来たか(0〜1)」)と、助手マスモンの対戦の芯 `ASSISTANT_MASMON_BATTLE`(6能力・専用の技表・距離・ガッツ)

## 0. ひとことで

1体のモンスターを **48ターン(=4年・1ターン=1か月)** だけ育てる。毎ターン「何をするか」を1つ選び、結果を見て叱る/褒める。
ときどき助手のイベントと大会。48ターンが終わると「引退」して、その子は **殿堂** に入り、ランクと総合力が残る。
殿堂の子は **次の育成の「親」** になって伸びやすさを受け継がせられ、**育成ランの対戦・ランキング** に出られる。
**今のマスモン(`mh_masu_mons`)・モンヒロバトル・カード・既存のランキングの強さには触れない**(つながるのは見た目・称号・ごほうびだけ)。

| 参考にした考え方 | 確かさ | うちではこう置き換える |
| --- | --- | --- |
| 1ターンに1つ行動を選び、ターン数が寿命の代わり(LINEモンスターファーム) | 社長のことば | 48ターン・1ターン=1か月。年齢は「ターン ÷ 48」を部品に入れる |
| 成長の型とピーク・叱る/褒める・忠誠(モンスターファーム) | 助手マスモンで採用済み | キズナの部品をそのまま使う |
| 1回ずつの育成・仲間との絆でイベントと練習が強くなる・終わりに評価(サクセス) | 一般 | 助手を「コーチ」に1人・「応援」に2人まで選ぶ。仲良し度が高い助手ほどイベントが強い |
| 親の能力を受け継いで次を始める(合体・秘伝の考え方) | 一般 | 殿堂の子を「親」に選ぶと、6能力のはじめの値と伸びやすさが少し上がる(上限あり) |

## 1. 1回の育成の流れ

### はじめる(1分)

1. **育てる子を選ぶ**: 解放済みのモンスターの種類から1つ(`mh_unlocked_monsters` を読むだけ)。種類で6能力のはじめの値・伸びやすさ(助手マスモンの `AMG_APT` と同じ表)・出やすい成長の型が決まる
2. **親を選ぶ(任意・2体まで)**: 殿堂の子から。下の「4. 受け継ぎ」
3. **助手を選ぶ**: コーチ1人(必須)+ 応援2人まで(任意)。解放済みの助手だけ。下の「5. 助手」
4. 成長の型がくじで決まって見せる(「🌱 早熟」など。ここで初めて分かる)。名前を付けて始める

### 1ターン(1か月)にすること

画面の上に「2年目 5月(17/48)」・6能力・疲れ・ストレス・忠誠・成長の曲線の「いまここ」。下にコマンド。

| コマンド | 中身(数字は助手マスモンの訓練の表を使い回す) |
| --- | --- |
| 💪 軽い訓練(6能力から1つ) | 主の能力 +中・疲れ +5・ストレス +1 |
| 🔥 重い訓練(6能力から1つ) | 主 +大・副 +小・下がる能力 −小・疲れ +14・ストレス +4 |
| ⚔ 修行(年に2回まで・2ターン使う) | 技を1つ覚える/熟練を上げる(助手マスモンの技表) |
| 🛌 休む | 疲れ −30・ストレス −5 |
| 🎈 遊ぶ | ストレス −15・疲れ −10・忠誠 +1(コーチの助手と出かけるイベントが起きやすい) |
| 🏆 大会に出る(開催月だけ) | 下の「大会」 |

- 伸び = 種の伸びやすさ × **成長の型(ターン ÷ 48 の割合で引く)** × 方針の掛け算 × コーチの得意(下の5)× 結果
- **結果**(助手マスモンと同じ表): 🌟大成功 / ⭕成功 / ❌失敗 / 🤫ズル / 💤サボり。結果のあと「📣 叱る」「👏 褒める」を1回(しなくてもよい)→ 忠誠と方針が動く
- **けが・病気・家出**: 助手マスモンと同じ起きる条件。長さは **ターンで数える**(けが2ターン・病気2ターン・家出1ターン)。その間は休み扱い
- 4ターンに1回(季節のはじめ)に **おやつ** を3つから1つ(ストレス・疲れ・忠誠のどれかが少し動く・ごほうびの物ではなく育成の中だけ)

### イベント(だいたい3ターンに1回)

- **助手のイベント**: コーチ・応援の助手との掛け合い → 2択(例:「もう少しがんばる/今日は休もう」)。選んだ方で能力・忠誠・ストレス・ヒント(下の5)が動く。同じ助手のイベントは1回の育成で順番に進む(3〜4話)
- **ふつうのイベント**: 町の人・ライバル・季節のできごと。数は少なめから
- 台本は助手部(コトバ・ココロ)。数字はこちらで表にする

### 大会

| いつ | 大会 | 相手 | 勝つと |
| --- | --- | --- | --- |
| 毎年 4月・10月(8回) | ふつうの大会(ランク別 E〜S) | 決まった種から作る相手(下の「足りない部品」②) | 賞金(育成の中の「名声」)・人気 +・称号のかけら |
| 4年目 3月(最後のターン) | **引退試合** | そのランクの強い相手3体 | 評価に大きく足す |

- 試合は **助手マスモンの対戦の芯** をそのまま使う(1対1・3本勝負)。観戦の画面も助手マスモン対戦の物を使い回す(速送り・とばすあり)
- 出られるのは今のランク以下の大会。勝つとランクの大会が1つ上がる(ランクは総合力のランクとは別の「大会ランク」)
- 大会の月に出なくてもよい(育成を優先する選び方も残す)

### 終わり方

- 48ターン目で **引退**(寿命の代わり。消えない)。方針で長さが変わる案: 超溺愛 56 〜 普通 48 〜 超スパルタ 40(助手マスモンの寿命の比をそのまま使う)
- 途中でやめる(「ここで引退する」)もできる。そのときも殿堂に入る(評価は低め)
- **評価**: 総合力(キズナの式)+ 大会の成績 + 忠誠・人気 → 「育成ランク」G〜M(キズナのランク表を使い回す)
- **中断と再開**: 1ターンごとに保存。アプリを閉じても次に開いたとき続きから

### 1回の長さの目安

1ターン 10〜15秒 × 48 + イベント・大会 ≒ **12〜18分**。大会を速送りにすれば10分ほど。

## 2. 育て終えた子はどうなるか(既存とのつなぎ・強さのつり合い)

**決まり: 育成ランの子は、今のマスモン・モンヒロバトル・カード・既存のランキングの強さに入らない。** 6能力は助手マスモンの線で、今のマスモンの4能力(ライフ・ちから・丈夫さ・ガッツ)とは別の物。

| どこ | つなぎ方(案) | 強さへの効き |
| --- | --- | --- |
| 殿堂(新しい) | 引退した子を残す(はじめ20体・増やせる)。くわしい画面は助手マスモンのくわしい画面の部品(読むだけの形) | — |
| 次の育成 | 親として受け継ぎ(下の4) | 育成ランの中だけ |
| 育成ランの対戦・ランキング | 殿堂の3体でチームを組み、フレンドの殿堂チームと対戦(助手マスモンのフレンド対戦の作りを使い回す)。ランキングは「育成ランク(1体の最高)」と「対戦の段」 | 育成ランの中だけ |
| 今のマスモン | **強さは渡さない**。引退の評価で、その種のマスモンに付けられる「称号」(名前の横の小さな印・プロフィールに出る)と、殿堂の子の色をマスモンの染めの色として使える(見た目だけ) | なし |
| ごほうび | 引退のとき評価に応じて既存の物を少し(ダイヤ・プシュケー・育成のかけら)。1日の上限は下の3。数は経済の担当と窓口で決める | 既存の手に入れ方の1つが増えるだけ |
| 助手マスモン | 案のみ(聞くこと 1 の ②): 殿堂の子を助手に「預ける」と、その助手の冬眠の箱に Lv1・初期値で入る(6能力は持ち込まない) | 助手マスモン対戦の見張りに引っかからない形だけ |
| カード | 触らない(あとで殿堂の子のカードの絵柄などを足すかは別の話) | なし |

- 既存のランキングへは何も送らない。育成ランのランキングは**新しい表を足すだけ**(Supabase は窓口の判断で。いまは触らない)
- スキップチケット・クイックモードのような「とばす」物は育成ランには使わせない(ランキングのつり合い)

## 3. 毎日遊ぶ理由と回数の上限

- **育成チケット 🎟**: 1日 **2枚** もらえる(朝4時に戻る・持てるのは4枚まで=2日ためられる)。1回の育成をはじめるときに1枚使う。途中の再開は無料
  - ためる上限を小さくして「毎日少し」に寄せる。追加はミッションのごほうびで1日1枚まで(ダイヤでは買えない案)
- **毎日の理由**
  1. 今日の2回で、きのうより上のランクを目指す(殿堂の最高ランク・種ごとの最高)
  2. **今週の大会**: 週ごとに「この週の育成ランの成績」を集計(最高の評価)。週替わりのお題(例: かしこさが高い子が有利・この種が出やすい)
  3. **種ごとの図鑑**: 30種それぞれで S を取ると、その種の称号(上の2)。集める目標が長く続く
  4. 助手のイベントを全部見る(助手ごとの話の進み)
  5. ミッション(「育成ランで大会に3回勝つ」など)を今のミッションの仕組みに足す
- 中断中の育成は1つだけ(新しく始めるには、今のを引退させる)

## 4. 受け継ぎ(親)

- 親は殿堂の子から **2体まで**。同じ子は1回の育成で1回だけ。親に使っても殿堂からは消えない(**素材にして消す形にはしない**)
- 効き(案): 子の6能力の **はじめの値 + 親2体の平均の 5%**(1能力 最大+40)/ 親と同じ能力の伸びやすさが1段だけ上がる(1回の育成で最大2つ)/ 親の技を1つ、最初から覚えている
- 同じ親は1日に何回でも使える(チケットで回数は止まる)。殿堂がいっぱいのときは、古い子をお別れさせるか(2回確かめる)、新しい子を入れない

## 5. 助手の関わり方

| 役 | 人数 | すること |
| --- | --- | --- |
| **コーチ** | 1人(必須) | 毎ターンの「おすすめ」を一言で出す(性格で違う: みゅあ=休みを大事に・あつ=重い訓練を押す など)。結果のあとの一言。コーチの得意の能力は伸び ×1.1 |
| **応援** | 2人まで | 訓練のときにときどき顔を出し、その回の伸び +20%・ストレス −2(サクセスの「練習に来てくれる仲間」の考え方) |
| イベント | 3人とも | 助手ごとの話(3〜4話)。最後まで見ると「ヒント」(技を1つ覚える・ある能力の伸びやすさ +1段) |

- **仲良し度**(助手ライフ)が高い助手ほど、顔を出しやすい・イベントの得が少し大きい。助手ライフの仲良し度は**読むだけ**(育成ランから仲良し度を上げるかは聞くこと 3)
- 解放前の助手は選べない(解放のアシストカード40回のまま)
- 引退のとき、コーチの助手が一言(評価で台詞が変わる)。殿堂の子のくわしい画面に「コーチ: みゅあ」と残る
- 助手の性格・呼び方は今の決まり(`{name}`・CALL_NAMES.md)に従う

## 6. 使い回す部品と、足りない部品

### キズナの部品をそのまま使う(入力: 育成期間のうち何割まで来たか 0〜1)

| 部品 | 育成ランでの入れ方 |
| --- | --- |
| 伸び(訓練の伸び・失敗) | 1ターンの訓練 = 助手マスモンの1回の訓練 × 倍率(作るときに試算で決める) |
| 成長の型とピーク | 割合 = いまのターン ÷ その育成の全ターン |
| 叱る/褒めると育成方針 | そのまま(10点で1段)。方針は全ターン数にも効く(40〜56) |
| 忠誠度 | そのまま(大会の「動かない番」もそのまま効く) |
| 人気 | 大会で上がる。クリティカル率もそのまま |
| 総合力とランク | 引退の評価のもと |
| 合体 | 使わない(受け継ぎは別の式・消さないため) |

### 足りない部品(キズナか対戦の受け持ちに頼む候補)

1. **年齢の時計を「ターン」で回す入れ口**: 部品の入力が0〜1なら足りる。けが・病気・家出の長さを「日」ではなく「回数(ターン)」で渡せる形にしてほしい
2. **大会の相手を作る部品**: ランク(E〜S)と種とくじの種(seed)から、6能力・技・熟練・忠誠・人気の決まった1体を作る(同じ種なら同じ相手)
3. **評価の式**: 総合力 + 大会の成績 + 忠誠・人気 → 育成ランク。総合力の式は助手マスモンのものを使い、大会の分を足す
4. **受け継ぎの式**: 親2体 → はじめの値と伸びやすさ(上の4)。合体の式とは別
5. **ターン単位の試算の道具**: `--sim` の形で「48ターン・型ごと・方針ごと」の終わりの6能力とランクの分布を出す(こちらで作る)
6. **1ターンの訓練の決まった乱数**: 回の番号ではなく「育成の id + ターン」から引けるように(開き直しても結果が変わらない)

## 9. 社長に聞くこと(大きな分かれ道だけ・おすすめが先頭)

1. **育て終えた子の行き先**
   - ①(推奨)殿堂に残し、次の育成の親・育成ランの対戦とランキングに使う。今のマスモンへは称号と色(見た目)だけ
   - ② ①に加えて、助手に「預ける」と助手マスモン(Lv1・初期値)として迎えられる
   - ③ 今のマスモンとして手持ちに入る(4能力に直して Lv1。強さのつり合いの見直しが要る)
2. **1回の長さと毎日の回数**
   - ①(推奨)48ターン(12〜18分)・1日2回(ためられるのは2日ぶん)
   - ② 24ターン(6〜9分)・1日3回
   - ③ 72ターン(20〜25分)・1日1回
3. **助手の仲良し度とのつながり**
   - ①(推奨)仲良し度を読むだけ(高いと助手の得が大きい)。育成ランでは仲良し度は上がらない
   - ② 1回の育成ごとに、コーチの助手の仲良し度が少し上がる(1日の上限あり)
4. **名前**: 自由に決めてもらう(仮「育成ラン」。ほかの候補: 「マスモン育成記」「そだてる4年」)

## 10. 止め絵の依頼に使う「画面の一覧と、それぞれで見せたいもの」(窓口が fable に1回だけ頼む用)

スマホ縦。絵そのもの(モンスター・助手)は今ある立ち絵を仮に置く(社長が用意する物と差し替える前提)。参考のゲームの画面・用語・絵は写さない。
