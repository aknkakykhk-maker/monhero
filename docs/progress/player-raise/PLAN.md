## 0. ひとことで

**育てる1体** を、1ターン=1週で、寿命(週の数)が尽きるまで育てる。毎週ひとつ行動を選ぶと、**応援の編成のマスモン6体** がそれぞれ得意な訓練に集まっていて、集まった訓練ほどよく伸びる。
コーチの助手は方針・様子・体調の見張り・お話の役。毎月の大会でランクを上げ、寿命が来ると引退して **保存枠** に入る。
保存枠の子は、次の育成の **応援** になり(強い子ほど伸びを押し上げる)、**フレンドに貸せて**、**バトル** に出られ、**合体** して新しい子を生む。

| 役 | だれ | 何をするか |
| --- | --- | --- |
| 育てる子 | ベースモン か 合体で生まれた未育成の子 1体 | 毎週の訓練で育つ本人 |
| **応援の編成(6体)** | 保存枠のマスモン(1体はフレンドから借りられる)。いない枠はベースモン | **伸び**: 毎週それぞれ集まりやすい訓練に顔を出し、その訓練の伸びを押し上げる |
| **コーチ(1人)** | 助手 | **方針と話**: 様子を数字なしで伝える・叱る/褒めるの効き・体調(けが・病気・家出)の見張り・イベント・技のヒント |

| 考え方(参考) | うちではこう置き換える |
| --- | --- |

## 1. 1回の育成の流れ

### はじめる

1. **育てる子を選ぶ**(決まった): ベースモン(下の「ベースモン」)か、**保存枠の「合体で生まれた未育成の子」**。引退した子はそのまま育て直さない(応援・バトル・サクセス杯・合体の材料になる)
2. **応援の編成**: 保存枠から5体まで+フレンドから1体(任意)。空いた枠はベースモンで埋まる。編成は「いつもの編成」として覚えておく
3. **コーチの助手を1人選ぶ**(解放済みの助手だけ・下の4)
4. 成長の型がくじで決まる(保存枠の子・合体の子は決まった型)。名前を付けて始める
5. **名前と染色を決める**(決まった・2026-11-12 社長): 始めるときに名前と染色(今の染色のしくみ・部位ごとの色)を決められる。**育成を終えた子(保存枠)も、あとからいつでも名前と染色を変えられる**。名前は言葉の見張りに通す。染色の値は保存枠の子の中に足す(新しいキー)

### ベースモンとは

- **ベースモン = モンスターの「種」そのもの**(図鑑の30種・`ALL_PLAYER_MONSTERS`。今のゲームでもこの呼び名で使っている)。育てた中身を持たない、まっさらな1体
- 手に入れ方: **今のゲームで解放している種**(`mh_unlocked_monsters` を読むだけ)がそのまま使える。新しく手に入れる物は要らない
- 育てる子に選ぶ: その種の初期値(Lv1)から始める
- 応援の枠を埋める: 空いた枠は、育てる子と同じ種+解放済みの種から自動で入る。**効きはいちばん弱い**(下の2)

### 寿命(週の数)

- 寿命 = 種ごとの基本(**普通 約150週=約3年**。種で 130〜170週)× 方針の比(助手マスモンの寿命の比: 超溺愛 ×1.33 〜 普通 ×1 〜 超スパルタ ×0.67)
- 年齢の部品へは「いまの週 ÷ 寿命」を入れる(方針が途中で変わったら残りの週が伸び縮みする)
- けが・病気は寿命を少し縮める(1回 −1〜2週)
- 1ターンは結果をさっと見せて **3〜6秒**。1回の育成は **約15〜25分**(大会の観戦を速送りにした目安)。1週ごとに保存し、いつでも中断して続きから

### 1週(1ターン)にすること

上に「2年目 6月 3週(98/150)」と寿命の目盛り。6能力(ライフ・ちから・かしこさ・命中・回避・丈夫さ)・忠誠・人気・成長の曲線の「いまここ」。コーチの一言。
下に訓練の札。**札ごとに、その週に集まった応援のマスモンの顔が並ぶ**(だれも来ていない札もある)。

| コマンド | 中身(数字は助手マスモンの訓練の表を使い回し、週の数に合わせて倍率を決める) |
| --- | --- |
| 💪 軽い訓練(6つ) | 主の能力 +中・疲れ +・ストレス 少し + |
| 🔥 重い訓練(6つ) | 主 +大・副 +小・ほかの能力が少し下がる・疲れ ++・ストレス + |
| 🛌 休む | 疲れ −大・ストレス −小 |
| 🎈 遊ぶ | ストレス −大・疲れ −小・忠誠 + |
| ⚔ 修行(4週かかる・年に2回まで) | 技を1つ覚える/熟練を上げる/能力が少し上がる。行き先で覚える技が違う |
| 🏆 大会に出る(大会の週だけ) | 下の「大会」 |

- 伸び = 基本 × 成長の型(週 ÷ 寿命)× 方針 × 結果 × **応援の上乗せ**(下の2)
- **結果**(助手マスモンと同じ5種類): 🌟大成功 / ⭕成功 / ❌失敗 / 🤫ズル / 💤サボり。結果のあと「📣 叱る」「👏 褒める」を1回(しなくてもよい)→ 忠誠と方針が動く
- **けが・病気・家出**: 起きる条件は助手マスモンと同じ。長さは週で数える(けが2〜4週・病気2〜3週・家出1〜2週)。その間は休み扱い
- **月のはじめに「ごはん」**(安い・ふつう・ごちそう)。ごちそうは忠誠・ストレスに良いが、育成の中のお金「名声」を使う
- 疲れ・ストレスは数字を出さず、コーチの一言とモンスターの表情で伝える(「くわしく見る」で数字も出す)

### 大会(毎月)

| 大会 | いつ | 出られる | 勝つと |
| --- | --- | --- | --- |
| クラス戦(E・D・C・B・A・S) | 毎月の第4週 | 今の大会ランク以下 | 名声・人気 + |
| 昇格戦 | 年4回(3・6・9・12月) | 1つ上のランクへ | 勝てば大会ランクが1つ上がる |
| 大きな大会(年1回) | 12月 | B以上 | 称号・名声 大 |

- 試合は **助手マスモンの対戦の芯**(1対1)と観戦の画面をそのまま使う(速送り・とばすあり)。相手は「大会の相手を作る部品」(下の6)。育成中の大会は端末だけで回す(ランキングに数えないので、サーバは要らない)

### 引退

- 寿命の週が来たら **引退**(消えない)。途中で「ここで引退する」も選べる
- 振り返り(能力の伸びの線・大会の成績・コーチの一言)→ **育成ランク G〜M**(総合力はキズナの式・ランクの区切りもキズナの表)
- 保存枠へ入る。**この子の「集まりやすい訓練」がここで決まる**(下の2)

### 画面の見本の答え(決まった・2026-11-12 社長。見本は mock/png/redo-*.png)

- **メイン画面は案A**: 住む場所を真ん中に大きく、下に行動のボタン(休む・訓練・ごはん/遊ぶ・修行・大会・能力)。訓練を押すと同じ景色のまま訓練を選ぶ画面へ
- **始めるまでの流れ**: 育てる子 → 応援 → コーチ → **持ちこみ**(育成に持っていく物) → 名前と染色 → 確認。**コーチの助手選びを「シナリオ」のように分けて作る**(助手ごとに育成の筋書き・できごと・訓練の組み合わせが違う。とりあえずはこの形で始める)。親からの受け継ぎの段は足さない
- **げんき・ストレスはゲージで出す**。中の数は0〜100。**アイテムで上限が上がる**物もある
- **ターンは期(フェーズ)ごとに数える**: 画面には「この期の残りターン」を出す。最後までの残りターンも出してよい(期の区切りは大会の案 TOURNAMENT.md と合わせる)

## 2. 応援の編成(マスモン6体)

### 親密度と友情タッグトレーニング(決まった・2026-11-12 社長)

- 育成中は、**応援のマスモン(6体)とコーチの助手のそれぞれに親密度**がある。トレーニングを一緒にするなどで上がる
- 親密度が一定まで上がった子(助手)がそのトレーニングに集まっていると、**友情タッグトレーニング**になり、トレーニングの効果が上がる
- **タッグになる子が多いほど効果が重なる**(2体なら2体ぶん)
- **はじめの親密度**: ベースモンより育てたマスモン(保存枠の子)のほうが高めから始まる。助手は、今のゲームでの親密度(仲良し度)が高いほど高めから始まる
- 一定の値・上がり方・効果の大きさは、案を作る会話で決める(社長に聞くときは選択式で)

### モンサク専用の能力(決まった・2026-11-12 社長。中身は参考資料が届いてから)

- **育成を終えた子は、モンサク専用の能力を取れる**(例: トレーニングの効果アップ・修行の効果アップ)
- その子を**育成中の応援の編成に連れていくと有利になる**(上の「応援の効き」に重なる)
- 取り方・種類・強さ・何個持てるかは、社長が追って貼る参考資料を見てから決める。保存は保存枠の子の中に足す(新しいキー)

### 応援の効き(1体ぶん)

保存枠の子は育成ランクで効きが決まる。ベースモンはいちばん弱い。

| 応援の子 | 効き(集まった訓練の伸びに足す) |
| --- | --- |
| ベースモン(空いた枠) | +4% |
| G・F | +6% |
| E・D | +9% |
| C | +12% |
| B | +15% |
| A | +18% |
| S | +22% |
| SS・SSS | +25% |
| M | +30% |

```
その訓練の応援の上乗せ = 1 + Σ(集まった子の効き × 得意なら1.5)+ 3体以上集まったら +10%
上限: ×2.5(6体みな M が同じ訓練に集まっても ×2.5 で止まる)
```

- 目安: ベースモン6枠だと、集まった訓練で ×1.04〜1.15 ほど。保存枠を B で6体そろえると ×1.3〜1.8。M をそろえると ×2.5 近く
- だから **強い子を育てる → 応援に入れる → 次の子がもっと伸びる** のくり返しが長く遊ぶ芯になる(合体と並ぶもう1本の道)
- 応援の子が対戦に出ることはない(育成の中の伸びだけ)。応援に使っても疲れたり減ったりしない

### 集まりやすい訓練(決め方の案)

- 1体ごとに **集まりやすい能力を1つ**(+ 重い/軽いは問わない)
- 決め方: **引退のとき、その子の6能力でいちばん高い能力**(同じなら種の伸びやすさ `AMG_APT` が高い方)。育て方で決まるので、「かしこさの応援がほしいから、かしこさ型に育てる」という狙いが立つ
- ベースモンは種の伸びやすさがいちばん高い能力
- 合体で生まれて育てる前の子は、主の親の集まりやすい能力
- 毎週の集まり方: それぞれの子が「集まりやすい能力の訓練」に **50%**、ほかの訓練に散らばって **35%**、来ない **15%**(決まった乱数・育成の id + 週)。休む・遊ぶ・修行には来ない
- 札に顔が並ぶので、プレイヤーは「どの札に何体来ているか」を見て選ぶ。疲れ・ストレスとのせめぎ合いが毎週の悩みどころ

### フレンドからのレンタル

| 項目 | 案 |
| --- | --- |
| 見られる数 | フレンド1人につき1体(その人が保存枠から選んだ「貸し出しの子」)。フレンドの数だけ並ぶ(今のフレンドの上限のまま) |
| 1回の育成 | 1体まで借りられる(6枠のうち1枠) |
| 1日の回数 | 制限なし(回数の制限はなし、の社長の答えに合わせる)。ただし同じフレンドの子は続けて2回までにして、ほかの人の子も回す |
| 貸した側の得 | 借りられた回数を数え、1回ごとに名声(モンヒロサクセスの中のお金)+少し。1日の量に上限。「あなたの◯◯が3回応援に行きました」の知らせ |
| 守り方 | 下の「表と守り方」 |

#### 表と守り方(フレンドに見せる助手マスモンの表 `alf_masmon_share` との違い)

- 助手マスモンの見せる表は「見るだけで得につながらない」ので、ほかの人に書き換えられても1日1回の送り直しで戻す形にした(台帳 2026-11-12)
- レンタルの子は **借りた人の伸びに効く(得につながる)** ので、同じ形だけでは足りない。次を足す案:
  1. **新しい表**(足すだけ・例 `monsuc_lend`)。書けるのは本人だけ: 書くのはサーバの関数だけにし、`masmon-pvp` の **持ち主の鍵** を使い回す(端末には insert・update を渡さない)
  2. 送る中身は **6能力・種・名前・色・型・集まりやすい能力** だけ。**ランクと効きは送らない**。借りる端末が6能力からランクと効きを計算し直す(送られた数字を信じない)
  3. サーバの見張り: 6能力 0〜999・種は実装済み・合計の上限。M の効き(+30%)が上限なので、盛っても ×2.5 の上限を超えない
- Supabase には今は触らない(段取り5で、足すだけの表を窓口の判断で)

## 3. 保存枠と合体

### 保存枠

- 引退した子・合体で生まれた子が入る別枠(今のマスモン `mh_masu_mons` とは別)
- **上限: はじめ30体・最大60体**(引退10回ごとに+5)。応援6体ぶん+合体の材料+合体で生まれた未育成の子をためられる数
- いっぱいのときは、お別れ(2回確かめる・「思い出」に名前とランクだけ残る)か合体で減らす。新しく入れられないだけで、自動では消さない

### 合体

1. 保存枠から **主の親** と **もう一方の親** を選ぶ
2. 生まれる子の種類・はじめの6能力の見通し・受け継ぐ技・型を見る
3. 最後の確認(決まった: 親2体とも保存枠から外れ、「思い出」に名前・ランク・代が残る。2回押す)→ 生まれた子は保存枠へ(未育成)。そのまま育成を始めてもよい

- **6能力**: 助手マスモンの合体の式 ──「生まれた種類の初期値 + 上乗せ(2体の平均を元に・そろいで効く・上限なし。平均999で約+200)」
- **技**: 親の技のうち、生まれた種類でも覚えられる技を2つまで(熟練は0から)
- **型**: 主の親の型を受け継ぐ(くじで別の型になることも少し)
- **世代**: 「◯代目」を数える
- **生まれる子の種類**(決まった: 血統で決まる) ── 子の主血統=主の親の主血統、子の副血統=もう一方の親の主血統か副血統(くじ)。その組み合わせのモンスターがいればその種類、いなければ主の親の種類(例: ウンディーネ + モッチー → ヤオビクニ)。血統の正本 `monster-hero/data/lineages.js` を読むだけ

## 4. コーチの助手(方針と話の役)

### サクセス杯(モンヒロバトルの新しい大会・決まった)

保存枠の子が、**この大会のときだけ** 今のモンヒロバトルの4能力に換算されて出る。ほかのモンヒロバトル(チャレンジ・クイック・プロ・極限)と既存ランキングには入れない。**どこに足すかはバトル部(ジン)とすり合わせ中**(下はたたき台)。

| 項目 | たたき台 |
| --- | --- |
| 置き場所 | バトルモード選択の新しいカード(id `success`)。流れはプロと同じ形(勇者モン → 置く距離 → 供モンの候補5体 → 教えカード → WAVE1〜10) |
| 出られる子 | 勇者モンも供モンも **保存枠の引退した子**(育成中・未育成の合体の子は出られない)。足りない枠はベースモン(下の11の問い)。今のマスモン(`mh_masu_mons`)は使わない |

| 難易度 | 今の9段のまま(難易度の倍率も今のまま) |

| ごほうび | ブリーダーXP ×1・ダイヤ ×1。絆XP は出ない(マスモンではないため)。かわりに優勝・WAVE数で **モンヒロサクセスの名声** と、出た子に「サクセス杯 優勝」の称号(保存枠の行に足す) |

#### 換算の式(6能力 → 4能力・案)

```
割合(x) = 0.8 + (その能力 ÷ 999) × 0.8          … 0 で ×0.8、999 で ×1.6
ライフ   = 種の baseHp   × 割合(ライフ)
ちから   = 種の baseAtk  × 割合(ちからとかしこさの高い方 × 0.7 + 低い方 × 0.3)
丈夫さ   = 種の baseDef  × 割合(丈夫さ)
ガッツ   = 種の baseGuts × 割合((命中 + 回避) ÷ 2)
```

- 例: モッチー(基礎 ライフ720・ちから140・丈夫さ140・ガッツ140)で6能力みな500 → ライフ 約1,008・ちから・丈夫さ・ガッツ 約196(基礎の約1.4倍)
- 距離適性は種のまま。固有技は種の固有技で、Lv は覚えた技の熟練の平均から 1〜9(熟練0 → Lv1・100 → Lv9)
- 強化ポイント・限界突破・魂格・継承技は持たない(マスモンの育成の物は入れない)
- **幅(×0.8〜×1.6)は仮**。ジン(バトル部)の返事: 「プロと同じ流れで `Suc` を別枠にする作りは、バトル側の仕組みと相性が良い」「倍率は机の上では言えない。測るなら6能力が全部 0・500・999 の3パターンをプロの各段階と戦わせるのが最小」「測るのは重い調査なので窓口の了解のあと」
- タクティクスの公開の予定とぶつからないかは窓口が確かめる
- 数字は段取り5b の前に、窓口の了解でジンが測って決める(それまで ×0.8〜×1.6 で作る)
