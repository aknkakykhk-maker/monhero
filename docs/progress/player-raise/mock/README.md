## 社長に聞くこと(おすすめが先頭)

1. **育成のメイン画面の配置**(`png/screen-04.png` に3案)
   - **A(推奨)上に立ち絵とコーチ・下に訓練の札6枚を全部ならべる**: どの札に何体来ているかを1画面で見くらべられる。1週3〜6秒の速さに合う
   - B 立ち絵をいちばん大きく・訓練の札は大きい1枚を横にめくる: かわいさは一番。6枚を見くらべるのに指が要る
   - C 能力の一覧がそのまま訓練の入口: 軽い/重いを同時に見られて数字に強い。立ち絵は小さい
2. **全体の色の方向**
   - **(推奨)今の助手マスモンの画面と同じ、暗い紺+ピンク/オレンジ/黄**(この止め絵): 観戦の画面とそのままつながる
   - 昼の牧場のような明るい色に変える: 別の遊びだと伝わりやすいが、観戦・保存枠との行き来で色が切り替わる
3. **演出の長さ**(訓練の結果・ランクが決まる・合体で生まれる)
   - **(推奨)短く(結果 約1.5秒・ランク 約3秒・合体 約3.5秒)・ぜんぶタップでとばせる**: 1回の育成 15〜25分の見込みを守れる
   - 節目(引退・合体・昇格)だけ長めに見せる(5〜6秒): 特別感は出るが、周回が長くなる

## 作り直し

```
npm pack @fontsource/noto-sans-jp   # 日本語フォント(端末に無いとき)。解いて files/ を渡す
node docs/progress/player-raise/mock/shoot.js <フォントの files フォルダ>
```

撮ったあと容量を下げるため 256色に落としている(Pillow の `quantize`)。中身は `screens-a.js`(1〜5)・`screens-b.js`(6〜10)・`screens-c.js`(11〜14)、部品は `lib.js`、見た目は `mock.css`。
