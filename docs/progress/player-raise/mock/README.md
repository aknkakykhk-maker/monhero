### 社長の答え(2026-11-12・窓口経由)

- メインの育てる子は **もっと小さくしてよい** → 高さの約34%にした(景色の昼/夜はまだ未定・いまは昼のまま)
- イッサ博士の成功の率は **点4つ** で見せる
- 編成の6体の列は **いつも出す**
- ごはんは **大会のあとのごほうび** であげる(メインのボタンにもターンのはじめにも置かない)→ C3 を足した
- 景色は **季節と時間で替わる**(見本は昼のまま)
- 修行は参考と同じ形(2段で能力2つ・最後に技を覚えるくじ・失敗で次の率アップ)→ Q1・Q2 はこの形
- 編成の子の連続イベントの技の伝授は **その編成の子が持つ技** を教わる → K4 の文を合わせた
- 参考動画の3本目(修行とアイテム)から: メインのボタンを2段に並べ直し、持ち物の袋と能力ポイントの数字を足し、修行の2コマ(Q1・Q2)を足した
