# 技の絵を資料の技アイコンへ(r1115-003)突き合わせ表

| 社長の頼み | できた形 | 見る所 |
| --- | --- | --- |
| 絵は資料 `skill-icons/sk-####.png` | ゲームの技 id と資料の skillId が同じ技(名前も同じと確認済み)は、その絵を使う。ゲームの技 515 のうち 425 技(絵は重複なしで 254 種) | X4・X10 |
| 2種類の大きさ(82×82・123×124)・右下の数字の二重 | 82×82 の元絵は右下に消費ガッツの数字が焼き込まれている(ゲームの値と食い違う)ので、升の右下の「うちの数字の札」(黒地の札)でかぶせる。元絵は加工しない。123×124 は数字なし(属性の玉だけ) | zoom-X10-grid.png |
| 使う技の分だけ・小さくして入れる | `monster-hero/images/success/skill/` に 254 枚(96×96・減色PNG・合計約1.5MB・技の詳細を開いたときに読む)。作る道具 `tools/success/build-skill-icons.js`(--check で一覧と絵のずれを見る) | image-asset-check |
| 資料にない技(オリジナルの子のオリジナル技)は資料の絵にならって作る | 90 技。同じ灰色の枠で、ちから技=黄・かしこさ技=緑の単色の影絵を、間合い(零・近・中・遠)ごとの8種の形で描く(技ごとの専用の絵ではない) | X11(エイキ)・X12(ケンシモッチー)・shadow-sheet |
| 覚えた/覚えていないの見分け | 覚えていない技は絵を暗くして彩度を落とす。升の枠の色(ちから=金・かしこさ=緑)はそのまま | X10 |
| ランクの色(銅・銀・金・紫・虹) | 絵が資料のものになったので、ランクは升の左上の小さな色札(数字つき)で示す | X10 |
