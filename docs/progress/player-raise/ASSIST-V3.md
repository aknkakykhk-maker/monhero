## 3. 保存(CLAUDE.md ⑦)

- 育てた子の `assists:[{ id, lv }]` はそのまま読む。新しい形は `{ id, lv, n }`(n = 目盛り)。**n が無い古い子は、段 lv の効き目と同じ目盛りに読み替える**(例: 特訓の底力 段2 = +10% → トレ効果アップ 目盛り10)。古い子の効き目は変わらない
- 書くときは `lv` も残す(いちばん近い段)。古い版のアプリで開いても読める
- 名前を変える物も id は変えない(sokoji のまま「トレ効果アップ」)。4種類を超えて持つ子は古い版では先頭4つだけ効く
- 新しい保存キーは足さない
