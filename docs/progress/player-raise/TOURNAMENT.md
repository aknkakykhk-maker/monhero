# モンヒロサクセスの大会(育成中の大会)の案(第4版)

キズナ 2026-11-12。**案だけ(コードは書かない)**。土台は [PLAN.md](PLAN.md)(第5版)と、社長が送った参考資料の仕組みのメモ [TOURNAMENT-REF.md](TOURNAMENT-REF.md)。
参考にしたのは仕組みの考え方だけ。大会名・称号名・イベント名・数字はすべてモンスターヒーローの言葉で作り直した。
**サクセス杯(育て終えた子の大会)は保留のまま。この案には入れない。**

- 第2版(2026-11-12): 社長の決めごと「ターンは期(フェーズ)ごとに数え、画面に『この期の残りターン』を出す」(PLAN.md §1 画面の見本の答え)に合わせ、期の区切りを割合から **期ごとのターン数** に直した。コーチ選びがシナリオになったので、シナリオと大会の並びの問いを足した(12の⑤)
- 第3版(2026-11-12 社長の答え・窓口経由): ①地形の大会はやめる(「場」も作らない)→ 自慢・間合い・タイプ・四季で組み直した ②大会ランク E〜S と昇格戦は期と星に置き換える ③能力ポイントは入れる(下の7b) ④コーチの仲良し度は引退のときにまとめて足す(1回の育成で最大3つ)。残る問いはシナリオの1つ(12)
- 第4版(2026-11-12 社長の答え⑤): 大会の並びは全シナリオで共通にし、シナリオごとに「そのシナリオだけの大会」を1〜2つ足す(下の4b)。これで社長に聞くことはなくなった

PLAN.md §1「大会」の表はこの案に置き換えた(大会ランク E〜S と昇格戦はなくなった)。

## 0. ひとことで

1回の育成(普通で148ターン=約3年)を **デビュー期 → ジュニア期 → ミドル期 → プロ期 → 最後の期** に分けて期ごとにターンを数え、**半月ごとに2〜4つの大会** が並ぶ。
大会の週は、訓練のかわりに大会へ出るか、出ずに訓練するかを選ぶ(出れば1週を使う)。
大会には **星の階級**(一つ星 ★・二つ星 ★★・三つ星 ★★★・ヒーロー級 👑)があり、勝つと **賞金(名声)** と、一部の大会では **ごほうび**(能力・**能力ポイント**・人気・まれに適性や技)が入る。
同じ系統の大会を勝ち進むと上の大会が開き、系統をそろえて勝つと **制覇**。最後の期は数か月かけて勝ち上がる **「頂への道」** が育成のしめくくり。

## 1. 期の区切りとターン数

**1ターン = 1週・4ターン = 1か月**(PLAN のまま)。期は **月の切れ目でそろえ**、期ごとにターンを数える。
画面には「ジュニア期 残り18ターン」と、その横に小さく「最後まで 102」を出す(社長の決めごと)。

| 期 | 基本のターン数(普通の方針・寿命の比1) | 方針・種で伸び縮みするか | 半月ごとの大会の数 | 出られる星 |
| --- | --- | --- | --- | --- |
| デビュー期 | 4(1か月。最後のターンがデビュー戦) | しない | 1(デビュー戦) | デビュー戦だけ |
| ジュニア期 | 44(11か月) | する | 2 | ★(賞金の合計で ★★ が開く) |
| ミドル期 | 48(12か月) | する | 3 | ★・★★(つながりと賞金で ★★★) |
| プロ期 | 40(10か月) | する | 3〜4 | ★★・★★★・👑 |
| 最後の期 | 12(3か月) | しない | 2〜3(頂への道を含む) | プロ期と同じ+頂への道 |
| 合計 | **148(約3年)** | | | |

- **伸び縮み**: ジュニア・ミドル・プロの3つに「寿命の比」(種の基本 ÷ 150 × 方針の比 ×0.67〜×1.33・PLAN §1 寿命)をかけ、**月(4ターン)単位に丸める**。
  例: 超スパルタ(×0.67)は 28・32・28 で合計 104/超溺愛(×1.33)は 60・64・52 で合計 192。デビューと最後は誰でも同じ長さ
- **期の長さはその期が始まるときに決める**。期の途中で方針が変わっても「この期の残り」は動かない(次の期から効く)。画面の数字が急に飛ばないように
- けが・病気で寿命が縮む分(1回 −1〜2週・PLAN §1)は、**プロ期の長さから引く**(プロ期の途中なら今の期の残りが減り、その場で知らせる)。デビュー・最後の期は縮まない
- 年齢の部品へは今までどおり「いまのターン ÷ 合計」を入れる(合計が決まっていない先の期は、今の方針で見積もった長さで数える)
- 季節や月の並び(下の4)は1か月目を1年目1月とする暦で決める。期が月の切れ目でそろうので、どの期でも半月ごとの並びがくずれない
- 半月 = 2ターン。大会があるのは各月の **2ターン目(前半)と4ターン目(後半)**。148ターンなら大会のターンは74回。全部に出ると育たないので、どれに出るかが育て方の目標になる
- デビュー戦は相手が弱く、出れば1つ目の称号と初めての出来事がある(負けても進める)

## 2. 星の階級と賞金

| 星 | 試合の数(1週の中) | 優勝の賞金(名声・ジュニア基準) | ごほうびが付く大会 |
| --- | --- | --- | --- |
| ★ 一つ星 | 1 | 100 | なし(デビュー戦だけ人気 +3) |
| ★★ 二つ星 | 2(準決勝・決勝) | 250 | ふつう以外(人気。自慢は得意な能力も) |
| ★★★ 三つ星 | 3(1回戦から) | 600 | ふつう以外のすべて |
| 👑 ヒーロー級 | 3 | 1,500 | すべて |

- 期の倍率: ジュニア ×1・ミドル ×1.25・プロと最後 ×1.5
- 負けたときも一部: 準優勝 40%・ベスト4 15%(★は1試合なので勝ちか負けだけ)
- 試合の間にライフとガッツは戻す。大会に出た週は疲れ +中(★★★・👑 は +大)。けがの起きやすさは訓練の重いほうと同じ
- 賞金は PLAN の「名声」(育成の中のお金・ごちそうに使う)。**賞金の合計** は使っても減らない別の数で、上の大会が開く条件に使う
- 数字は仮。経済の担当とごちそうの値段に合わせて、試算で決める

## 3. 大会の系統

地形の大会は作らない(社長 ①)。モンスターヒーローにある物(6能力・間合い適性・タイプ)と暦で組む。

| 系統 | 中身 | 味付け | イベント名(ひとこと) |
| --- | --- | --- | --- |
| 自慢の大会(6つ) | ちから・かしこさ・命中・回避・丈夫さ・ライフのどれか1つが高い子だけ(下の表) | 相手もその能力が高めに作られる(下の9の4) | 能力ごとに1つ(下の表) |
| 間合いの大会(4つ) | 零・近・中・遠。モンスターヒーローの **間合い適性**(図鑑の `distAptitude`・対戦の芯がすでに使っている)をそのまま使う | 相手はその間合いが得意な種から出る | 「間合いを制す」 |
| タイプの大会(5つ) | アタッカー・タンク・サポーター・ヒーラー・シャドウ(`MONSTER_TYPES`)。メインかサブが合う子だけ | 相手も同じタイプ | 「同じ道を行く者たち」 |
| 四季の大会(4つ) | 3・6・9・12月の後半に春・夏・秋・冬の1つずつ | 季節で出やすい相手の種が変わる | 「季節をめぐって」 |
| ふつうの大会 | しばりなし。どの期にもある | なし | なし |
| ヒーロー記念(👑) | 6月後半と12月後半。プロ期だけ | なし | 「ヒーローの名にかけて」 |
| 頂への道 | 最後の期だけの勝ち上がり(下の6) | なし | 「頂に手をのばす」 |

## 4b. シナリオの大会(社長 ⑤ 決まった)

並び(上の4)は全シナリオで共通。コーチの助手ごとのシナリオに、**そのシナリオだけの大会を1〜2つ** 足す。
置き場所は、その期の「ふつう」の枠を1つ差し替える(半月ごとの数は変わらない)。相手の強さの表と試算は共通のものを使い、星の倍率だけで決める。

| シナリオ(コーチ) | 大会 | いつ・星 | 中身 | 勝つと(共通のごほうびに足す) |
| --- | --- | --- | --- | --- |
| みゅあ | 笑顔の大会 | ジュニア・ミドルの8月前半 ★★ | 勝ったあとに機嫌がよいと賞金が上がる(ストレスが少ないほど ×1.0〜1.3) | ストレス −大・忠誠 + |
| きき | 静かな一撃の大会 | ミドル・プロの10月前半 ★★★ | ちからかかしこさが 400 以上の子だけ | 得意な能力 +12 |
| ももすけ | 人気投票の大会 | 各期の11月前半 ★★(プロは ★★★) | 人気が高いほど出られる星が上がる(人気 50 以上で ★★★) | 人気 +10(コーチの ×1.5 も効く) |
| ドラ | 技くらべの大会 | ミドル・プロの7月前半 ★★ | 覚えている技が3つ以上の子だけ | 技の素質が出やすい(5%→20%) |
| あつ | 格上への挑戦 | プロの4月前半 ★★★ | 相手が1つ上の星の強さ(×1.25)。負けても賞金の半分 | 能力ポイント +15 |
| きゅうこ | ピークの大会 | 成長のピークに入った最初の前半(1回の育成に1度) ★★ | ピークの子だけ | 全能力 +3 |
| ソラシド | 計算どおりの大会 | ミドル・プロの2月前半 ★★ | けが・病気が1度もない子だけ(数字で見せる) | 能力ポイント +10 |
| えるびん | 見守りの大会 | ジュニアの5月前半 ★・プロの5月前半 ★★ | 忠誠が 70 以上の子だけ | 忠誠 +・次の月のごはんが1回ごちそうになる(名声は使わない) |

- ★★★ のシナリオの大会の優勝は称号と出来事の節目に入れる(8)。仲良し度の対象(👑・制覇・頂への道)には入れない
- 大会の id は `期:月:前後:sc-コーチ:星`。シナリオを持たない育成はない(コーチは必ず1人)ので、どの育成にも1〜2つ出る
- 第1弾(みゅあ・あつ)の大会から作り、残り6人はシナリオを足すときに一緒に足す(PLAN §10 の7〜)

## 5. 出る条件と系統のつながり

| 条件 | 例 |
| --- | --- |
| 前の期の優勝(つながり) | 「ちから自慢 ★★」はジュニアで「ちから自慢 ★」に優勝した子だけ。「ちから自慢 ★★★」はミドルで ★★ に優勝した子だけ。間合い・タイプも同じ |
| 賞金の合計 | ふつうの大会: ★★ は合計 500 以上・★★★ は 2,000 以上・👑 は 5,000 以上(プロ期) |
| 能力 | 自慢の大会: その能力がジュニア 150 以上・ミドル 300 以上・プロ 500 以上(能力ポイントを振って届かせてもよい) |
| 種類のしばり | タイプの大会: メインかサブのタイプが合う子だけ |
| 間合い適性 | 間合いの大会 ★★ 以上: その間合いの適性 C 以上(ごほうびで上がれば出られるようになる) |

- 出られない大会も札は見せる(鍵の印と「ジュニアで ★ に勝つと出られます」のような一言)。目標が見えるように
- つながりは系統ごと。ジュニアで負けても、ふつうの大会で賞金を貯めれば ★★★ のふつうには届く(取りこぼしても詰まない)

## 6. 頂への道(最後の期)

- 最後の期(12ターン)に入ると始まる。**1回戦 → 準決勝 → 決勝** を、最後の期の各月の4ターン目に1戦ずつ(1ターンの中で1試合)
- 出る条件: プロ期に ★★★ 以上を1つ以上優勝、または賞金の合計 5,000 以上。出られないときは、最後の期もふつうの大会だけ
- 負けたらそこで終わり(残りのターンはふつうに育てる)。勝ち進むほど賞金が上がる: 1回戦 800・準決勝 1,500・決勝 3,000(×1.5 はかけない)
- **決勝のごほうびは2通り**:
  - ふつう: 全能力 +8・能力ポイント +30・人気 +10・称号「頂に立った子」
  - 大きいほう(この育成で 👑 を1つ以上勝っている、または制覇を2つ以上): 全能力 +15・能力ポイント +60・人気 +20・称号「ヒーローの頂」
  - 決勝が最後のターンなので、決勝でもらった能力ポイントは引退の画面で振る(下の7b)
- 最後の期は長さが変わらない(上の1)ので、決勝の前に寿命が来ることはない。決勝のターンが最後のターン

## 7b. 能力ポイント(社長 ③「入れる」)

大会でもらった点を、**引退までに好きな能力へ振れる**。育て方の足りないところを埋めたり、自慢の大会の条件に届かせたりに使う。

| 項目 | 案 |
| --- | --- |
| もらえる所 | 大会だけ(7の表)。訓練・できごとでは増えない(大会に出る意味をはっきりさせる) |
| 見込み | よく勝つ育成で 1回の育成に約150〜200点(デビュー5+★★★ 3つで30+👑 2つで40+制覇 2つで30+頂への道 60) |
| 振り方 | **1点で能力 +1**。ただし **その能力が期の目安を超えると 2点で +1**(目安はジュニア 300・ミドル 500・プロと最後 700。伸びきった能力ばかりに積まないように) |
| 上限 | 1つの能力は 999 まで。**持っておける点は 200 まで**(超えた分は「もらえなかった」と出す。早めに振るきっかけ) |
| いつ振るか | いつでも(1ターンを使わない)。メイン画面の「能力」ボタンから。引退の画面でも最後に振れる |
| 振った後 | **そのターンのうちは取り消せる**(次のターンへ進むと決まる)。決まったら戻せない |
| 振らずに引退 | 引退の画面で「残り◯点」を見せ、振るか「おまかせ(低い能力から順に)」を選ぶ。何もしないで閉じても、おまかせで振る(点を無駄にしない) |
| 伸びとの関係 | 振った分は成長の型・方針・応援の倍率をかけない(そのまま +1)。叱る/褒める・忠誠にも効かない |

**振る画面**(メインの「能力」ボタン → 下から出る板):

- 上に「能力ポイント 残り 45/200」
- 6能力の棒を縦に並べ、それぞれに今の値・「+1」「+10」ボタン・その能力の1点あたりの重さ(1点/2点)。目安を超えるところで棒の色を変える
- 押すと棒の先が薄く伸び(まだ決めていない分)、下に「ちから +12・回避 +8(使う点 28)」とまとめが出る
- 「決める」「やめる」。決めたあともそのターンのうちは「取り消す」が出る
- 自慢の大会の条件まであと少しの能力には「あと 12 で ねらい自慢 ★★ に出られます」と出す

### コーチの助手との仲良し(社長 ④ 決まった)

- 出来事のうち **👑 優勝・制覇・頂への道 優勝** の3種で、コーチの助手の仲良し度が上がる(1つで助手ライフの「できごと半回ぶん」くらい・**1回の育成で最大3つ**)
- 育成中は貯めておくだけにして、**引退のときに引退の分とまとめて1回で足す**。二重に足さない印(保存枠の行の `bond:true`)も、1日3回の引退までの上限も PLAN のまま使う
- 1つあたりの量は助手ライフ部と決める

## 9. 戦いと相手の強さ

- 試合は **助手マスモン対戦の芯**(`ASSISTANT_MASMON_BATTLE.simulate`)を1対1で回し、観戦の画面を使う(速送り・とばすあり)。育成値そのまま(公平の区分は使わない)。育てる子の忠誠度が低いと「動かない番」が出るのも助手マスモンと同じ
- 端末だけで回す(ランキングに数えない。サーバ・Supabase は要らない)
- 自慢・タイプ・間合いの大会は、相手の作り方と出る条件だけで味を付けるので、**芯は変えない**。間合いの大会で「始まりの距離をその間合いにする」を足したくなったら、対戦の担当に入力を頼む(芯の版が上がるので、masmon-pvp の結果に効かない形で)

### 大会の相手を作る部品(PLAN §7 の足りない部品②)

入力: `{ 期, 星, 系統, 試合の回(1回戦・準決勝・決勝), 週, 育成の id }` → 出力: 相手1体 `{ 種, 名前, 6能力, 技, 熟練, 作戦 }`

1. **基準の強さ B(期)**: その期の終わりに「ふつうに育てた子」の6能力の合計。試算の道具(`tools/success/success-sim.js`・PLAN §10 の1)で測って表にする
2. **星の倍率**: ★ ×0.75・★★ ×0.95・★★★ ×1.1・👑 ×1.25。頂への道は B(プロ期の終わり)に 1回戦 ×1.2・準決勝 ×1.3・決勝 ×1.4
3. **回の上げ**: 同じ大会の中で準決勝 +5%・決勝 +10%。**ゆらぎ** ±8%
4. **配り方**: 合計を種の伸びやすさ(GROW-BASE)に沿って6能力に配る。自慢の大会は、その能力を +15% 寄せる
5. **種**: 系統で選ぶ(間合いの大会はその間合いの適性 A 以上の種・タイプの大会はそのタイプの種・四季は季節の表)。公開ずみの種だけ(`draft` の子は出さない・ネタバレを避ける)
6. **技と熟練・作戦**: 期で増える(ジュニア 技2・熟練20・作戦10/ミドル 3・40・20/プロ 4・60・30/頂への道 5・80・40)
7. **決まった乱数**(育成の id + 週 + 回)。中断して続きから始めても、同じ相手・同じ結果になる(やり直しで勝つまで引けない)
8. **合わせ方**: 試算で「ふつうに育てた子」の勝率が ★ 約80%・★★ 約60%・★★★ 約45%・👑 約30%・頂への道の決勝 約25% になるよう、1 の B を直す

## 10. 保存(CLAUDE.md ⑦)

まだ公開していない新しいキー(`mh_monsuc_run_v1`)の中に足すだけ。既存のキーは触らない。

- 途中の育成に `phase:{ i:いまの期(0〜4), len:[期ごとのターン数(決まった期だけ)], t:この期の何ターン目 }` と `cups:{ won:[大会の id], total:賞金の合計, titles:[], seen:{出来事の印}, bond:貯めた仲良しの数(0〜3), apt:{その子だけの間合い適性} }` と `ap:{ have:持っている点(0〜200), got:もらった合計, used:{6能力ごとに振った点}, undo:{このターンに振った分} }` を足す(PLAN の `rankT` は使わない)
- 大会の id は `期:月:前後:系統:星` の決まった形(並びの表から作り直せる)。読めない・壊れているときは「まだ何も勝っていない」

## 11. 足りない部品(頼む先)
