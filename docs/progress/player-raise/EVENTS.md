- 参考にするのは **育成ゲームのランダムイベントの考え方だけ**(ターンの合間に起きる・選択肢で結果が分かれる・仲間との出来事・連続する話・季節の行事・大きな賭け)。他社のキャラ・名前・せりふ・画面は使わない。人物・場所・道具はすべてモンスターヒーローのオリジナル

## 0. ひとことで

46ターンの育成のあいだに、**約15回(3ターンに1回くらい)** の出来事が起きる。ほとんどは2〜3秒の短い場面で、**2択(ときどき3択)** を選ぶと、能力・忠誠・人気・げんき・ストレス・親密度・技のヒントなどが動く。
出来事には8つの種類がある。中でも **助手の連続イベント(シナリオの話)** と **賭けの出来事(町はずれの怪しい人物)** が、育成ごとの思い出と「もう1回」の芯になる。

| 何を足すか | ねらい |
| --- | --- |
| ふだんの出来事・編成の出来事 | 毎ターンの訓練の単調さを崩す。編成の顔ぶれで中身が変わる |
| 助手の連続イベント | シナリオ(選んだ助手)ごとの物語。完走すると技やアシスト能力につながる大きなごほうび |
| 季節・期の出来事 | 1年(期)の区切りを感じさせる。3年ぶん回るので、年ごとに中身を変える |
| 賭けの出来事 | 低い確率で大きく強くなるか、失敗してけが・能力が下がるかを **自分で受けるか選ぶ**。育成ごとのドラマの山 |

## 1. 出来事の8つの種類

| # | 種類 | どんな出来事か | 1回の育成で(目安) | 選択肢 |
| --- | --- | --- | --- | --- |
| ① | ふだんの出来事 | 住む場所・町で起きる小さな場面(落とし物・雨の日・夜ふかし・差し入れ など) | 4〜5回 | 2択が多い。選ばない(見るだけ)もある |
| ② | 助手の連続イベント | シナリオの助手の4話+特別な1話(PLAN §4 の「イベント(4話)」をここで形にする) | 4〜5回 | 毎話2択。前の話の選び方で次の話が変わる |
| ③ | 編成の出来事 | 編成のマスモンが訓練の外で顔を出す(一緒に自主練・けんか・励まし)。親密度が動き、友情タッグに近づく | 2〜3回 | 2択 |
| ④ | 育てる子の出来事 | 育てる子の気分・成長の節目(ピークに入った・伸び悩み・好き嫌い) | 1〜2回 | 2択 |
| ⑤ | 季節・期の出来事 | 決まった月に起きる行事と、期のはじめの「この期の目標」 | 6〜8回(決まって起きる) | 2〜3択 |
| ⑥ | 賭けの出来事 | 町はずれの怪しい人物が「一気に強くなれる」話を持ちかける(大きな賭け)。小さな賭け(くじ・怪しい品)もある | 大きな賭け 0〜2回・小さな賭け 1〜2回 | 受ける/断る |
| ⑦ | 体調の出来事 | けが・病気・家出の **前触れ**(防げることがある)と、治ったときの場面 | 0〜2回(体調しだい) | 2択 |
| ⑧ | 大会まわりの出来事 | 大会の前夜・ライバルの前触れ・勝ったあとの取材(TOURNAMENT §8・§8b とつなぐ) | 1〜2回 | 2択 |

- 合計の目安: **1回の育成で 約15回**(⑤の決まって起きる分を含む)。46ターンの3ターンに1回ほど
- ⑤の「期のはじめの目標」と季節の行事は **決まって起きる**(ランダムではない)。そのほかは下の2の確率で起きる

## 2. 起きる仕組み(確率と条件)

### いつ起きるか

| すき間 | 起きやすい種類 | 1ターンに |
| --- | --- | --- |
| ターンのはじめ(ごはんの前) | ①・④・⑤・⑥・⑦ | 0か1つ |
| 訓練の結果のあと(叱る/褒めるのあと) | ②・③(その訓練に集まった編成の子) | 0か1つ |
| 大会の前後 | ⑧ | 0か1つ |

- **1ターンに出来事は最大2つ**(はじめと結果のあとで1つずつ)。大会のターンは⑧だけ
- 決まって起きる⑤は、ほかより先に出る(⑤が出たターンのはじめには、ほかの出来事は出ない)

### 起きる確率(ランダムの分)

```
そのすき間で何か起きる確率 = 基本 22%
  + 前の出来事から空いたターン × 4%(最大 +20%。間が空きすぎないように)
  − 前のターンに出来事があった −10%(続きすぎないように)
起きると決まったら、条件を満たす出来事の山から「重み」でくじを引く
```

- 決まった乱数(育成の id + ターン + すき間)で引く。**同じ所から始め直しても同じ出来事・同じ結果** になる(中断・再開で結果を引き直せない・下の10)
- **同じ出来事は1回の育成で1回まで**(連続イベントの話・季節の行事・賭けの人物は別の決まり)

### 重みを動かす条件

| 条件 | 出やすくなる出来事 | 出にくくなる出来事 |
| --- | --- | --- |
| 期(デビュー〜最後) | 期ごとの出来事(デビューは出会い・ジュニアは失敗から学ぶ・プロは挑戦) | 期に合わない出来事は山に入らない |
| 忠誠が高い(70〜) | 育てる子が自分から頑張る・助手に甘える | サボり・ズルの出来事 |
| 忠誠が低い(〜30) | サボりたがる・いうことを聞かない(選び方で忠誠を戻せる) | 自主練の出来事 |
| ストレスが高い(70〜) | ⑦家出の前触れ・気晴らしの誘い | 賭けの人物(下の6・ストレス高いと失敗しやすいので出にくくする) |
| げんきが低い(〜30) | ⑦けがの前触れ・助手の「休もう」 | 自主練・夜ふかし |
| 人気が高い(60〜) | ファン・取材・町の子どもの出来事 | — |
| 親密度(編成の子・助手) | 親密度が高い子の③・助手の連続イベントの次の話 | 親密度が低い子の③は「仲良くなるきっかけ」の話だけ |
| シナリオの助手 | その助手の②と、その助手らしい①の言い回し | ほかの助手の②は出ない |
| 編成の顔ぶれ | 編成にいる種・タイプ(アタッカー〜シャドウ)の③ | 編成にいない子の③は出ない |
| 成長の型とピーク | ピークの入りと終わりに④ | — |
| まだ見ていない出来事(`mh_monsuc_meta_v1` の `seen`) | 重み ×1.5(はじめて見る出来事を出やすく) | 何度も見た出来事は ×0.7 まで下げる |

## 3. 選択肢と結果の振れ幅

### 効き目の大きさの物差し

数字は試算の道具で決めるので、ここでは **「軽い訓練1回ぶん」(そのターンの軽い訓練で主の能力が伸びる量)** を物差しにする。

| 大きさ | 能力 | 忠誠・人気(0〜100) | げんき・ストレス(0〜100) | 親密度 |
| --- | --- | --- | --- | --- |
| 小 | 1つの能力 +訓練0.5回ぶん | ±3 | ±10 | +5 |
| 中 | 1〜2つの能力 +訓練1回ぶん | ±6 | ±20 | +10 |
| 大 | 全能力 +訓練0.5回ぶん、または1つ +訓練2回ぶん | ±10 | ±30 | +20 |
| 特大(賭け・連続の最終話) | 全能力 +訓練1.5〜2回ぶん+特別なごほうび | ±15 | — | +30 |

- **ふだんの出来事はほとんど「小〜中」**。損だけの選択肢は作らない(片方は確実に小さく得・もう片方は確率で中〜大か空振り、のように **安全と冒険の2択** を基本にする)
- 能力が下がるのは **賭けの出来事と⑦の一部だけ**。下がる幅は「訓練1〜2回ぶん」まで・0未満にならない
- 1つの出来事で動くのは **3項目まで**(見てすぐ分かるように)

### 効くもの

| 効くもの | どの出来事で | メモ |
| --- | --- | --- |
| 6能力 | ほぼ全部 | 上の物差し |
| 能力ポイント | ⑤目標の達成・⑧・②の最終話 | TOURNAMENT §7b の点(引退までに好きな能力へ振る)。出来事で入るのは1回 +3〜10 |
| 忠誠・人気 | ①・④・⑧ | 忠誠は叱る/褒めると同じ向きで動く |
| げんき・ストレス | ①・⑦・⑤の行事 | ゲージ(0〜100)。上限が上がる出来事も少しだけ(PLAN「アイテムで上限が上がる」と同じ形) |
| 親密度 | ②(助手)・③(編成の子) | 友情タッグの一定の値に近づく。③は「その子と一緒に次の訓練に来やすくなる」も付く |
| 技 | ②の最終話・修行の行き先のヒント | 技を直接覚えるのは②の最終話と賭けの成功だけ。ふだんは **技のヒント**(次の修行でその技を覚えやすい) |
| 熟練 | ③の自主練 | 持っている技の熟練 +1 |
| ひとときの状態 | ①・③・④・⑥ | 下の表。数ターンだけ続く印 |
| アシスト能力 | ②の最終話・⑥の成功 | **「ひらめき」** を得る: 引退のときのアシスト能力の候補に、その出来事にちなんだ能力が並ぶ・取るポイントが少し安くなる(PLAN §2) |
| 名声 | ⑧・小さな賭け | 育成の中のお金。ごちそう・行商人の品に使う |

### ひとときの状態(数ターンだけ続く印)

出来事で付き、メイン画面の育てる子のそばに小さな印で出る。**同時に2つまで**(3つ目が来たら古いほうが消える)。

| 状態 | 続く | 効き | 付く出来事の例 |
| --- | --- | --- | --- |
| 🔥 やる気満々 | 3ターン | 訓練の大成功 +10% | 自主練・ファンの声援・目標を決めた |
| 🎵 ごきげん | 3ターン | ストレスの増え −50% | 遊びの誘い・季節の行事 |
| 💤 ねぼけ | 2ターン | サボり +10% | 夜ふかし |
| 🌀 ふてくされ | 2ターン | 叱ると忠誠が余計に下がる | けんか・負けたあと |
| ✨ ひらめき中 | 次の修行まで | 修行で技を覚えやすい | 技のヒント |
| 🤝 息ぴったり(◯◯と) | 3ターン | その編成の子が訓練に来やすい(+20%) | ③の出来事 |

- 悪い状態は2ターンまで。良い状態は3ターンまで。数字は試算で合わせる

### 見える確率

- 確率で結果が分かれる選択肢には、助手が **数字なしの見立て** を言う(「いけそう」「五分五分」「ちょっとあぶない」の3段)。PLAN §6「助手は数字を言わない」に合わせる
- **ソラシドだけは数字で言う**(PLAN §4「起きやすさを数字で見せる」と同じ役)。**きゅうこ** は「どっちが得か」をひとことで言う(頭脳派)

## 4. 種類ごとの中身

### ① ふだんの出来事(共通の山・第1弾 16)

住む場所と町(おやつ屋さん・広場・ひなたの丘・図書室など、助手ライフの町の場所を背景に使い回す)の小さな場面。言い回しはシナリオの助手の口調で出す。

| 出来事 | 選択肢 → 結果(例) |
| --- | --- |
| 落とし物の木の実 | 届ける → 人気 小+・名声 少し / 食べちゃう → げんき 中+・忠誠 小− |
| 雨の日 | 屋根の下で軽く体を動かす → かしこさ 小+ / 思いきり雨の中で走る → 50%でライフ 中+、50%でげんき 小− |
| 夜ふかし | 早く寝かせる → 何もなし / 一緒に星を見る → ストレス 中−・💤ねぼけ |
| 町の子どもたち | 遊んであげる → 人気 小+・げんき 小− / 技を見せる → 人気 中+(人気が高いと 大+) |
| おやつ屋さんの新作 | 買う(名声)→ 🎵ごきげん / がまん → 忠誠 小+ |
| 図書室で古い本 | 一緒に読む → かしこさ 小+・✨ひらめき中 / 枕にして寝る → げんき 中+ |
| ひなたの丘の追いかけっこ | 本気で走る → 回避 小+ / のんびり → ストレス 小− |
| 広場の大道芸 | まねする → 命中 小+ / 見るだけ → ストレス 小− |
| 力くらべを挑まれた | 受ける → 60%でちから 中+、40%でげんき 小− / 断る → 何もなし |
| こわい夢 | なだめる → 忠誠 小+ / 朝まで一緒にいる → 忠誠 中+・げんき 小−(助手) |
| 苦手な食べ物 | 好き嫌いを直す → 丈夫さ 小+・ストレス 小+ / 好きな物にする → ストレス 小− |
| 鏡の前でポーズ | 褒める → 人気 小+・忠誠 小+ / 練習させる → 命中 小+ |
| 迷子のモンスター | 一緒に探す → 人気 小+・げんき 小− / 助手に任せる → 何もなし |
| 古い修行の地図 | 修行の行き先のヒント(✨ひらめき中) |
| 思いがけない差し入れ | 見るだけ: げんき 中+ |
| ひとりで黙々と | 見るだけ: 忠誠が高いと主の能力 小+ |

### ② 助手の連続イベント(シナリオの話)

PLAN §4 の「イベント(4話)」と「仲良し度の段で話が増える」を、ここで1本の話の流れにする。**第1弾は みゅあ・あつ**(PLAN §6・§10 の4と同じ)。

**話の進み方(どの助手も同じ形)**

| 話 | 出る時期 | 出る条件 | ねらい |
| --- | --- | --- | --- |
| 1話 | デビュー期〜ジュニア期の前半 | 必ず出る(デビュー期のどこか) | 出会いと、この助手の育て方の色 |
| 2話 | ジュニア期 | 助手の親密度 30〜 | 小さな壁と、助手の弱いところ |
| 3話 | ミドル期 | 親密度 50〜 | 話の山。2択の結果で4話が分かれる |
| 4話 | プロ期 | 親密度 70〜 | しめくくり。**特大のごほうび**(技・アシスト能力のひらめき・称号) |
| 特別な1話 | 最後の期 | 助手ライフの仲良し度 Lv5〜 かつ 4話を「いい結末」で終えた | 引退の振り返りにつながる長めの話 |

- 仲良し度の段(PLAN §4): Lv1〜2 は1話だけ・Lv3〜4 は3話まで・Lv5〜 は4話+特別な1話。届かない話は「ふだんの出来事」で埋まる
- 各話は5〜6行+2択。**3話の選び方で4話が「いい結末/ほろ苦い結末」に分かれる**(どちらでもごほうびはある。いい結末だけ特別な1話へつながる)
- 話を完走すると称号(助手ごと)。保存枠の子の `titles` に入る

**みゅあの話(第1弾・あらすじ)**

| 話 | あらすじ | 2択(例) |
| --- | --- | --- |
| 1 | 「ねーねー、この子の得意、いっしょに見つけよ！」町じゅうを連れ回して、いちばん楽しそうだったことを探す | 走るのが好きそう(回避)/食べるのが好きそう(ライフ) → その能力 中+・🎵ごきげん |
| 2 | みゅあが張り切りすぎて、育てる子がへとへとに。「まぢごめん…あたし、楽しいとつい」 | 今日は休もう(げんき 大+・親密度 +)/もう1本だけ(主の能力 中+・ストレス 中+) |
| 3 | 大会の前の日、みゅあが手作りのお守りを用意。でも本人がいちばん緊張している | 一緒に深呼吸(→ いい結末へ)/お守りだけもらう(→ ほろ苦い結末へ) |
| 4 | 大舞台で、みゅあの声がちゃんと届く。いい結末: 技「みんなの声」系のひらめき+全能力 特大/ほろ苦い: 人気 大+・称号 | 見るだけ(結末で分かれる) |
| 特別 | 最後の期、ふたりで町を一周して「ここまで来たぢゃん」と振り返る | 見るだけ(引退の振り返りの最後の一言が変わる) |

**あつの話(第1弾・あらすじ)**

| 話 | あらすじ | 2択(例) |
| --- | --- | --- |
| 1 | 「とりあえず、上の星だけ見とこっか笑」初日にいきなり一番上の大会の会場を見せに行く | 燃える(🔥やる気満々)/こわい(忠誠 小+・あつが気づかって一言) |
| 2 | ジュニアの大会で格上に当たり、あつが作戦だけはきっちり詰めてくる。「準備で負けんのはナシな笑」 | 作戦どおり(かしこさ 中+)/自分の得意で押す(主の能力 中+) |
| 3 | あつが昔くやしい負けをした大会の話をする。「…別に、気にしてないけど笑」 | その大会に出ると約束(→ いい結末へ)/今は自分のペースで(→ ほろ苦い結末へ) |
| 4 | 約束の大会。いい結末: 試合のはじめのガッツが上がるアシスト能力のひらめき+全能力 特大/ほろ苦い: 能力ポイント +10・称号 | 見るだけ |

- 残り6人の話の芯(後回し・PLAN §4 の「イベント」の列を広げる): きき=静かな特訓と火力の見せどころ/ももすけ=見せ方の練習とファン/ドラ=技のコツ(冗談まじり)/きゅうこ=育て方の極意と数字にしない勘/ソラシド=表で組み立てる1か月/えるびん=見守る・ごはんが豪華になる

### ③ 編成の出来事(第1弾 8・タイプ別の共通の山)

編成のマスモン(保存枠の子・フレンドから借りた子・ベースモン)が、訓練のあとに顔を出す。**その子の名前(ニックネーム)と立ち絵で出す**ので、自分で育てた子が出てくるのがうれしい所。

| 出来事 | 起きる子 | 選択肢 → 結果 |
| --- | --- | --- |
| 自主練に誘われた | 親密度 40〜 の子 | 一緒にやる → その子の得意な能力 小+・熟練 +1・親密度 中+ / 休む → げんき 小+ |

## 6. くり返し遊んでも飽きない工夫

1. **はじめて見る出来事を出やすく**(重み ×1.5)・何度も見たものは下げる(×0.7 まで)
2. **同じ出来事でも中身が変わる**: シナリオの助手の口調・編成の子の名前と立ち絵・育てる子の種・季節の年ごとの中身で、言い回しと結果が変わる
3. **同じ選択でも結果に幅**: 確率で2〜3通り(安全な選択肢は確実・冒険の選択肢は振れる)
4. **連続イベントの分かれ道**: 3話の選び方で結末が2通り。特別な1話は仲良し度 Lv5〜 といい結末の両方が要る(何度も遊ぶ目標になる)
5. **賭けの人物とのくり返し**: 会うたびに台詞が変わり、成功した回数が記録に残る。「◯回目の成功」で人物の反応が変わる
6. **できごと帳**(後回し・下の9): 見た出来事・結末・賭けの成功を集める帳面。集めた数で小さなごほうび(名声・称号)
7. **とばす**: 一度見た出来事は「とばす」で結果だけにできる(選択肢は必ず出す)。12 の Q4
8. **助手どうしのゲスト**(後回し): シナリオでない助手がふだんの出来事に顔を出す(ドラの冗談にもも・みゅあが反応する、など今の関係のまま)
