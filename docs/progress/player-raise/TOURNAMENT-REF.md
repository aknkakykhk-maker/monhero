# モンヒロサクセスの大会(育成中の大会)の参考メモ

2026-11-12 社長が LINEモンスターファームの大会の一覧(攻略サイトの表・16枚)を「大会参考資料」として送ってきた。
他社のゲームの資料なので、画像はリポジトリに入れない。**仕組みの考え方だけ**をここに書く。
大会の名前・アイテムの名前・数字は写さない(モンサクで作るときは、モンスターヒーローの言葉と数字で作り直す)。

## 表から読み取れる仕組み

- **期ごとに大会の並びが決まっている**: デビュー期(最初の大会1つ)→ ジュニア期 → ミドル期 → プロ期 → 最後の大会。
  時期は「◯月前半/後半」の半月単位で、1つの時期に2〜4つの大会が並び、どれか1つに出る
- **階級**: 銅・銀・金と、年に数回の「四大」(いちばん大きい大会)。階級が上がるほど賞金が大きい(銅を1とすると 銀2・金4・四大8 くらい)。
  同じ大会でも、期が進むと賞金が上がる(ジュニア→プロで1.5倍ほど)
- **賞金(G)**: 勝つともらえるお金。育成中の買い物や、評価に使う
- **報酬**: 勝つともらえる育成中のアイテム(ごはん・特別な果物など)
- **優勝後の効果**(色つきの行だけ。全部の大会には付かない):
  - 全能力+いくつ/得意な能力+いくつ/能力ポイント+いくつ/人気+いくつ
  - (まれに)地形や間合いの適性が1段上がる・得意技の素質が付く などの珍しいごほうび
  - 年に数回の「制覇イベント」: 同じ系統の大会を全部勝つと、まとめて大きなごほうび
- **参加条件**(色つきの大会の一部):
  - それまでの賞金の合計が◯以上
  - 前の期で、対になる大会に優勝している(例: 地形の大会に勝つと、次の期の同じ地形の上の大会に出られる)
  - 能力が◯以上(例: ライフ500以上の子だけの大会)
  - 種類のしばり(例: ◯◯系のモンスターだけ)
- **大会の系統**(表の並びから): 地形(砂漠・森林・海岸・雪山・火山)の大会/間合い(零・近・中・遠)の大会/
  能力が高い子の選抜大会/季節の大会(春夏秋冬)/大きな記念の大会。系統ごとに「ジュニアで勝つ → ミドル・プロで上の大会に出られる」のつながりがある

## モンサクに当てはめるときの考え(まだ決めていない・案)

- モンサクの寿命は約150週。期の区切り(デビュー/ジュニア/ミドル/プロ/最後)と、半月ごとの大会の並びで「育て方の目標」を作れる
- 地形・間合いの適性はモンスターヒーローにもある(図鑑の地形適性・間合い適性)ので、大会の系統にそのまま使える
- 戦いは助手マスモン対戦の仕組みがもと(台帳 2026-11-12)
- 大会まわり(サクセス杯を含む)は社長が「追って決めよう」と保留中(台帳 2026-11-12)。この資料は、そのときの土台にする
