# r1113-034 修行の「覚える率が上がる条件」(社長が案A)

覚えたい技の枠に、その技の「条件」を最大4つ出す。満たした条件には「済 +5%」、満たしていないものは「まだ」。満たした1つにつき覚える率が +5%(上限 99%)。門ではない(満たさなくても、能力・熟練の門を越えていれば覚えられる)。

| 技のランク | 条件の数と値 |
| --- | --- |
| R1 | 覚えた技 2つ以上 |
| R2 | 覚えた技 4つ以上・人気 30以上 |
| R3 | 覚えた技 6つ以上・人気 50以上・選んだ技の段の合計 5以上 |
| R4 | 覚えた技 8つ以上・人気 60以上・選んだ技の段の合計 7以上・人気 80以上 |
| R5 | 覚えた技 10つ以上・人気 70以上・選んだ技の段の合計 9以上・人気 90以上 |

## 止め絵
- `Q4-1つ選ぶ.png`(幅390)・`Q4-1つ選ぶ-s320.png`(幅320): R2 の技を1つ選んだとき(条件2つとも「まだ」・率 70%)
- `Q5-2つ選ぶ.png`・`Q5-2つ選ぶ-s320.png`: 2つ選んで超修行(率に超修行の +15%)

## 突き合わせ
| 決めごと | 満たす所 |
| --- | --- |
| 選んだ技ごとに条件(能力の値・覚えた技の数・人気・選んだ技の段の合計)を最大4つ見られる | 枠の「条件1〜」。能力の値は今までどおり🔒の札を押した窓に出る(門のため) |
| 満たした条件に印 | 「済 +5%」(緑)と「まだ」(灰) |
| 強い技ほど条件が多く厳しい | R1 の1つ〜R4・R5 の4つ(表) |
| 率の表示と実際の抽選が同じ | 芯の techRate が条件を数える(act の rates も同じ式)。monsuc-learn-conds-check.js が見る |
