# カード部 ナガメくん(マルチの観戦) 見つけた物・済んだ物

案: [`card-multi-plus/README.md`](card-multi-plus/README.md) の「3. 観戦」(ツナグくん)。社長の決め: 観戦は全部だれでも見られる・見る人に手札は届かない(台帳 2026-10-27)。

## 作り(92-card-pvp-watch.jsx)
- 対戦の部屋とは別の通り道 `realtime:mhc-watch-<試合の番号>`。流すのはホストだけ(相手は古い版でもよい)。表・保存キーは足していない
- 流す物: 手・使った札(reveal)・捨て札の並び・名前とアイコンと3体と枚数。手札・山札・ガッツの中身・封・ホストの場そのものは流さない
- 見る人は両方の手札と山札を仮の札にした場で、はじめからの手をなぞる(途中から見る人は150手ずつまとめてもらう)
- 対戦中の一覧は `realtime:mhc-live`(ホストが10秒おき)。見る人は4秒おきに「見ています」。上限30人。2人の画面に「👀 n」(相手へは部屋の hb の `w`)
- 検査: `tools/card/card-pvp-watch-check.js`(node・200戦で見る人の場がホストと同じか)/ `tools/card/card-pvp-watch-browser-check.js`(3ページ・偽の中継)

## 済んだ物
- 2026-10-27 区切り1: マルチ対戦の入口の「フレンドの対戦を観戦する」から、対戦中のフレンドの試合を見る(更新履歴とヘルプは社長の「この文で」待ち)

## これから(次の区切り)
- フレンドの画面からの入口(フレンドの部品は別の部署の場所。触る前に知らせる)
- ランキング(90・リプレイくんの場所)の強さの上位の人の対戦を見る入口。一覧はもう全部の試合を受け取っているので、フレンド以外も出すだけ
- 観戦の画面で、使われた札を大きく出す動き・ダメージの数字(いまは場とまんなかの1枚と記録の3行)
