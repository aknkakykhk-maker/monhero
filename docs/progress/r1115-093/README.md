# アシスト効果の重なり方の表(r1115-093)

クラフト30。**まだ作り変えていない**(社長が1行ずつ決める用の表)。社長「アシスト効果は上限とか重複不可とか作らないと大変なことになるね」。

- 効果は第3版の表 `data/monhero-success-assist.js` の72種。「いまの重なり方」は計算の芯 `data/monhero-success.js` の作りを機械で拾った
- 型: いっしょ型 = その子がトレーニングに来たときに効く / 自分だけ型 = その子自身にだけ効く / いるだけ型 = 編成にいれば効く / 試合型 = 大会の試合に効く
- 「6体全員が最大」は、6体とも同じ効果を最大で持ち、いっしょ型は6体が同じトレーニングに集まったときの値
- 「減らしながら重ねる」は、大きい順に 1・1/2・1/4・1/8…(6体そろって最大の 約1.97倍で頭打ち)

## 要点

1. **上限なしで足されるのは、いっしょ型の19種**(トレ効果アップ・得意の後押し・能力別アップ6種・季節4種・励・人数・忠誠度・大成功・人気度大成功・幸運・回復)。6体そろうと 1体の最大の6倍(トレ効果アップ +150%・得意の後押し +180%)
2. 合計に上限があるのが4種(失敗率ダウン・見張り役・気晴らし 80%・体力消費ダウン 60%)。失敗率ダウンは2体で 80% に届く
3. いるだけ型(36種。うち助手・継承は「編成で1体まで」)・試合型(5種)・トレレベルアップ／逆境トレレベルアップ／追加トレボーナスの3種は、**すでに「いちばん高い1つ」だけ**(重複不可)。自分だけ型3種と、応援効果アップ・仲良し特訓はその子自身の分だけで重ならない
4. おすすめ: 上限なしの19種は「減らしながら重ねる」。合計の上限がある4種は上限を下げる(失敗・サボり・ストレス 50%・体力消費 40%)。ほかは今のまま
5. **071 の案A3 とは矛盾しない**。A3 は「編成の子そのものの補正(能力・ランク・タッグ・親密度)」を強くし、この表は「アシスト効果の積み過ぎ」を抑える。別の数字なので両方入れられる(下の試算は両方入れた形も出した)
