## ④ 公開してすぐ切り替えるときの数え方

守ること:
- (1) すでに達成・受け取り済みの物を二重に受け取れない
- (2) 途中までの数が消えて損をしない

| 項目 | 切り替えたときの扱い |
| --- | --- |
| 同じidで同じ中身(login・enhance・wins(クイック)・donations(チャレンジ)・quick_runs・challenge_runs・pro_clears・enhances・logins・コンプ系の回数) | **引き継ぐ**(数も受け取り済み sent もそのまま) |
| 同じidで中身が広がる(daily_battles・weekly_battles・monthly_battles「バトル→好きな遊び」/monthly_wins「バトル勝ち→好きな遊びの勝ち」) | **引き継ぐ**。今の期間のバトルの数を「好きな遊び」の数の始まりにし、そこへビート・カードを足していく。受け取り済みならそのまま(二重にならない) |
| 同じidで報酬だけ増える | 受け取り済みはそのまま(差額は配らない)。まだなら新しい報酬で受け取る |
| 新しいid(daily_assistant・weekly_beat/card/assistant・monthly_beat/card/assistant) | **新しく数え始める**。ただし「またはバトル」の側は、今の期間のバトルの数をそのまま使う(バトル中心の人は、切り替えた時点でもう進んでいる) |
| 日替わり・週替わり(同じid `daily_rotation`・`weekly_rotation`、中身が変わる) | その日・その週に受け取り済みなら**済み扱い**(sent が同じidなので二重にならない)。まだなら新しい中身を、今の期間の数で見る |
| 週替わりへ移す項目(weekly_market・weekly_daily_claims) | **その週の終わり(月曜4:00)までは今のまま残す**。次の週から週替わりへ |
| 外す項目(monthly_market・monthly_mode_runs) | **その月の終わり(12/1 4:00)までは今のまま残す**。達成済みで未受取なら受け取れる。12/1 から出さない(受け取り履歴は消さない) |
| コンプリートの目安(日 4/5 → 5/6・週 6/8 → 7/9・月 8/11 → 9/12) | 切り替えたその日・その週・その月だけは、今の目安と新しい目安の**少ないほうで達成**。受け取り済みならそのまま |
| ギフトの固定id・#4800 の受け取りの直し | 変えない(受け取りは今の `runGiftWrite` の中のまま) |

- 一度きりの印は、新しいキー `mh_mission_renew_v1` に「切り替えた日時と、その時点の期間」を置く
  - これで「切り替えの期間だけの特別な数え方」(残す項目・少ないほうで達成)を、次の期間に持ち越さない
- 数の保存は `mh_missions` の中に項目を足すだけ(beatPlays・cardWins・assistantDays など)。キー名・既存の形は変えない
