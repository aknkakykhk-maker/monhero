# 助手の解放(アシカを使った回数で助手になる)設計 1枚

2026-11-11 開発部カイホウ。社長「これから始める人はアシカの助手を使った回数で解放されるようにしようか。最初は好きな助手を選べてあとは解放条件を満たしたら助手として使えるようになる。これなら存在はするからイベント的にも違和感がないはず」

- 使った回数を数える場所はすでにある: `60-app.jsx` の手札を切る処理(`assistantCardUse` で「カード本人」の仲良し度を足している所)。AIコピー・デバッグ戦は数えていない。ここに1行足すだけで数えられる
- 助手の名簿は1本(`assistantsUnlockedFrom` → `metIds`)で、助手えらび・プロフィールの仲良し度・助手どうしの掛け合い・助手ライフ(町・家・部屋・フレンドの家)・MFバトルカードの対戦相手が全部これを見ている
- ダイヤはミッションで1日約24,000 → きき・ももすけのカードは約6日で買える。**条件はどの助手でも満たせる流れになっている**(ただし きき・ももすけ・きゅうこ等は「買う → 使う」の2段)
- 引き継ぎ(`.mhsave`)は `mh_*` を全部運ぶので、新しいキーもそのまま引き継がれる

## 2. 作り(案)

- **新しいキーを2つ足すだけ**(既存キーの意味は変えない・Supabase は触らない)
  - `mh_assistant_partner_v1` … `{ v:1, mode:'all'|'earn', first:'kiki', unlocked:['kiki',…], noticed:[…] }`
    - **一度きりの判定**: このキーが無く、すでに遊んでいる人(プロフィールを決め終えた・助手を選んだことがある)→ `mode:'all'`(今のまま全員選べる)。以後は読むだけで判定し直さない
    - はじめての人は、最初の助手えらびで決めたときに `mode:'earn'`・`first`・`unlocked:[first]` を書く
    - 解放は `unlocked` に足すだけ(消さない・戻さない)
  - `mh_assistant_card_uses_v1` … `{ atsu:12, kiki:3, … }` 使った回数(全員数える。'all' の人には表示しない)
- 判定は1か所の関数 `assistantPartnerOk(id)` = 公開済み(`assistantReleased`)かつ(`mode:'all'` または `unlocked` に入っている)かつ いまの加入のお話の条件
  - 「会った」(`metIds`・町に出る)と「助手」(`partnerIds`・関われる)を分ける。公開前の助手を隠す決まり(unreleased-assistant-hidden)は今のまま `assistantReleased` が先に止める(混ぜない)
- 解放前の助手は: 助手に選べない・仲良し度が増えない(あつのときと同じ扱い。貯まらない)・おしゃべり/贈る/部屋/きずな/マスモン/提案は押せない

## 3. 決めてほしいこと(推奨は先頭)

**A. 何回使ったら解放か**
1. **20回(推奨)** … モンヒロバトル数回ぶん。最初の数日で1〜2人増える
2. 10回 … すぐ増える。「選ぶ楽しみ」より「集まる早さ」
3. 40回 … 長い目標。ききなど「買う → 使う」の助手はかなり先になる

数え方(推奨): プレイヤーの手札から切った分だけ。オート・クイックも数える(自分の山札なので)。AIコピー・デバッグ戦は数えない。1日の上限なし

**B. 解放前でもその助手のアシカを持てる・使えるか**
1. **今のまま持てる・使える(推奨)** … みゅあ・ドラ・あつは最初から、きき・ももすけ等はダイヤショップで買う。ショップの札に「使うと◯◯が助手として選べるようになります」を1行足す
2. はじめての人だけ、きき・ももすけのカードも最初から渡す … 早いが、買った今の人と差が出る

**C. お話がからむ助手(あつ・きゅうこ・ソラシド・えるびん)**
1. **(推奨)お話は今のまま流れて「会う」。助手になるのは回数で**。あつだけは、はじめての人は仲良し度 Lv5 の条件が遠い(きき・ももすけを解放してから Lv5)ので、**はじめての人の あつの加入のお話は「あつの挑発を20回」で流れ、見たら助手になる**(お話がそのまま解放の演出)
2. お話を見たら助手になる(今のまま)。回数で解放するのは お話の無い みゅあ・きき・ももすけ・ドラ だけ

**D. 解放の演出とお知らせ**
1. **バトルの結果のあとに全画面の「◯◯が助手になりました！」(止め絵③)+その助手の一言+「◯◯を助手にする/あとで」(推奨)**。進み具合はバトルの結果に1行(「ききの応援 12/20」)と、助手を変える小窓に棒(止め絵②)
2. HOME に戻ったときに小窓だけ
3. ギフト箱にお知らせを入れるだけ

**E. 助手ライフで関われないことの見せ方**
1. **町・場所には出る(顔の色を少し落とし「町の人」の札)。押すと一言と「あと何回」の案内、話す・贈る・部屋は 🔒(止め絵④・推奨)**。家の部屋は「留守」と同じ扱いで入れない
2. 町には出るが押しても何も起きない
3. 遠くの人影だけ(顔を出さない)

**F. おしゃべり・掛け合い・告知・イベントのお話**
1. **(推奨)イベントや加入のお話は今のまま全員出る / 助手どうしの掛け合い(HOME 等で2人が話す)は町の人として出てよい / 助手の告知は選んでいる助手が話すので変わらない / MFバトルカードの「助手と対戦」の相手は今のまま(会った助手)/ プロフィールの仲良し度の並びは助手になった人だけ**
2. 掛け合いも助手になった人だけに絞る
