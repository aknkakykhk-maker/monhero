# ウンディーネ 実装用パッケージ(2026-11-11 最終版)

MFバトルカードの新しい血統「ウンディーネ」と、その混血「スネグーラチカ」を入れるための一式です。
キュービ・オリヒメと同じ手順で入れられるよう、形をそろえています。

## 1. 中身

| フォルダ | 中身 | 大きさ |
|---|---|---|
| `images/` | カードの画像 19枚(480×672 の JPEG。キュービと同じ軽い版) | 約1.4MB |
| `data/` | カードのデータ(数値・効果の文・効果の部品) | 約16KB |
| `docs/` | 設計書 `undine.md` と、まとめ画像5枚 | 約1MB |
| `preview/card-list.jpg` | カード一覧(確認用。ゲームには使わない) | 約0.5MB |

## 2. カードの一覧と番号

番号の付け方は、キュービ(サーバの番号 C-901、画面の番号 C-◆01)にそろえています。
**サーバの番号は案です。** 本家で空いている番号に合わせて決めてください。

## 3. 本家に足す必要があるもの

既存の部品で作れない効果が2つあります。くわしい決まりは `docs/undine.md` の「効果の部品」の表にあります。

| 部品 | 使う札 | 中身 |
|---|---|---|
| `costUpOnHit(n)` | アクアウェイブ・クリスタルレイン | ダメージを受けたモンスターだけ、次の相手のターン、ちから技・かしこさ技の消費ガッツ+n。重ねがけは大きいほう。特殊・防御・回避は増えない |
| `costUpAll(n)` | アクアドーム | 次の相手のターン、水中にいない相手全員の、ちから技・かしこさ技の消費ガッツ+n。水中かどうかは、次の相手のターンで判定する |

- アクアキッスの「ガッツを全て失わせる」は、既存の `gutsLossOnHit(all)`(ピクシーのキッスなど)で作れます。
- 特徴「水中」は、アローヘッドと同じものです。
- **AIの使い方(測定に使った仮の値)**: アクアドームは、相手のガッツが2〜4のときだけ使うようにすると、勝率がいちばん良くなりました。仮の値なので、本家のAIの作りに合わせて決めてください。
  - 測定の結果: AIが組むデッキの勝率は60.2%でした。同じ測り方で、スエゾー62.5%・ピクシー61.3%・タイガー56.3%です。

## 4. 画像について

- 届いた完成イラストを、480×672 に縮めた JPEG です(1枚 50〜75KB)。キュービのときと同じ大きさなので、本家の `card-image-build` などでそのまま `l/`・`s/` を作れるはずです。
- カードの中の数字・番号・枠は、届いた絵からこちらで直しています。
  - 消費ガッツを変えた5枚は、数字を描き直しました。
  - 技カードの枠は、クリスタルレインの柄にそろえました。
  - ドルフィンブローは、絵を8%拡大しました。
  - モンスターの番号を ◆03・◆04 にしました。
  - スネグーラチカに、メイン・サブの札を足しました。
- 原寸(742×1038 の PNG)や、届いたままの絵が必要な場合は、別に渡します。容量が大きい(合わせて数十MB)ので、このパッケージには入れていません。
