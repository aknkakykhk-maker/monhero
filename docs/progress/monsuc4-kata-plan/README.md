## 案ごとの違い(一言ずつ)

| 案 | 一言 | 上の帯 | 主役の大きさ(場面の高さに対して) | 成長のピークの炎 | マスモンの詳細 |

| **A 参考どおり**(推奨) | 帯を2段に詰めて場面を広げ、主役を場面の半分に | 期・残りターン・総合力/体力・ストレスの2段。忠誠・人気・方針の行は畳む(能力の窓・総合力を押した窓へ移す) | 50%(どの画面も同じ) | 足元だけ(高さ半分・薄く) | 絵を上に大きく、能力の表は絵の下に全幅。「/999」は消す |

- イベント(E1)は主役が助手の立ち絵の後ろに重なる。入れるときは主役を左へ寄せ、文の箱は場面の下(絵の外)へ出す(育-216)
- 案C はイベントで主役の頭が上の見出しに近い。入れるときは見出しを避ける高さにする
- 育-219 の「場面の左上にモンスター名と Lv」は、どの案でも足す(止め絵の CSS だけでは足せないので未表示)
