## #8064 の案から変えた所

| ねらい | どうしたか |
| --- | --- |
| 闇の濃淡 | 色をさらに黒へ(墨 #030304)。上と下から闇がかぶさり、7秒でゆっくり息をするように濃くなる。四隅に乾いた赤がにじむ。背景の絵は色を抜いてさらに暗く |
