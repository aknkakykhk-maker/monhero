## 方向

「古い捜査記録(調書)」。いまの「紺の箱に金の枠」を、墨の黒・暗い紙・乾いた赤の判・くすんだ真鍮に替える。
光らせない・明るくしない(r1126-093 追記1)。字は今のとおり左寄せ・明朝は見出しだけ。他作品の見た目は写していない。
