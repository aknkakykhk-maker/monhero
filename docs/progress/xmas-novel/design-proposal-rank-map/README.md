# 事件簿のランキング・見取り図・エンドの種類の札の見た目の案(台帳 r1126-112・追跡表 r1128-064)

社長「事件簿はクロードデザイン活用していいかんじにしてもいいよ」。本体の案([`../design-proposal/`](../design-proposal/README.md))が「見取り図・ランキングは別の会話の受け持ち」として残した分を、同じ方向でそろえた。**案だけ。ゲームにはまだ入れていない**(社長に見せてから組み込む)。

- 見本(iPhone 縦 390×844 の3枚): [`proposal.html`](proposal.html)(ブラウザで開くと3枚が並ぶ)
- 比べ絵(左が今・右が案): [`compare-all.jpg`](compare-all.jpg)(3つまとめ)/ 1つずつ `compare-rank.jpg` `compare-map.jpg` `compare-ending.jpg`
- 名前・数は仮。まだ読んでいない所・まだ見ていないエンドは「？？？」のまま(ネタバレしない)

## 方向

本体の案と同じ「古い捜査記録(調書)」。墨の黒・暗い紙・乾いた赤の判・くすんだ真鍮。光らせない・明るくしない。他作品の見た目は写していない。

## どこをどう変えるか

| 画面 | 今 | 案 |
| --- | --- | --- |
| ランキング | 紺の箱に金の枠、金の丸いタブ、順位の行は紺の札 | 綴りの見出しの札「全国の記録」。タブは綴りのつまみ(選んでいるつまみの上に赤い線)。順位は帳簿の1行(順位は真鍮の数字・1〜3位は赤・1位に「首位」の判)。見たエンドの内訳は小さな四角の印(種類の色だけ・どのエンドかは出さない)。自分の行は、綴りにクリップで留めた紙片(左に赤い線) |
| 見取り図 | 紺の方眼に金の太い背骨、扉の形の章の札 | 赤い糸でつないだ捜査の板。章は仕切り紙の札、分かれ道は赤い四角・推理の問いは真鍮の丸・寄り道は点線の四角。エンドは少し傾けて留めた記録の札(左の線が種類の色)。まだの所は暗い紙の「？？？」。もしもの道は金の点線の段 |
| エンドの種類の札 | 色のついた小さな札(真グッド・名指しエンド など) | 種類ごとの判(丸か四角・字は1〜2字)。迷宮入りは青みのある灰色。エンドの札は、紙の上に斜めに判を押した形 |

## 組み込むときの見積もり

- ランキングは `79-xmas-novel-rank.jsx` の見た目の決まり(XMAS_NOVEL_RANK_CSS)と並びだけ。送る処理・保存は変えない
- 見取り図は `79-xmas-novel-map.jsx` の見た目の決まりと札の形。台本から並べる仕組み・読み直しの保存は変えない
- エンドの種類の判は `XMAS_NOVEL_ENDING_KINDS` に判の字を足し、エンドの札・エンドヒストリー・見取り図で同じ判を使う
- 本体の案と一緒に入れるのがよい(片方だけ変えると、起動画面とランキングで見た目が分かれる)
- 字の大きさ・押せる大きさは今と同じにする。縦・横・タブレットで止め絵を撮って確かめる
