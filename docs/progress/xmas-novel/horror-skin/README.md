## 変えた所

- 色: 金と紺 → 墨の黒・古い紙の白・にじむ暗い赤。画面全体にざらつき、上下の闇がゆっくり濃くなる、四隅に暗い赤
- 起動画面: 傷んだ事件ファイルの表紙(見出しの札「事件記録 No.13」・赤い「記録」の判)。項目は番号つきの目次。後ろに黒いサンタの影がゆっくり寄る
- 文字の窓: 墨の黒に暗い赤の細い線、名札は左に赤い刻みと垂れる赤。送りの印は赤くちらつく
- 選ぶ窓(行動・突きつけ・名指し): 墨の板、札は左に赤い線。後ろに黒いサンタの影と暗い赤の目
- 章の札: 題が数秒に1度ちらつく。脇に黒いサンタの影
- エンド: 上から赤が垂れ、斜めの「記録終了」の判。強制バッドの GAME OVER は残した(暗い赤に)
- 人物の写真は少し色あせ。選んだ状態は暗い赤の縁
