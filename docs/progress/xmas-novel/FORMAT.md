## 読む所

- `## 序章` / `## 第N章 ～題～` / `## 終章 ～題～` / `## エンディング` の見出しから下の表。`## みんなで進む話`(レイド)と `# 旧案` から下は読まない
- 章の題(`～`と`～`の間)が、章に入ったときの札に出る(「第三章 / 雪の上の影」)
- `## 後半 第8章 ～題～` のように頭に「後半」が付く章は、画面では見出しの番号(第八章)で出し、中身の章ID は場面ID(`C10-1` → `C10`)に合わせる
- エンディングの名前は `### END-G 真グッド「やり直しのクリスマス会」` の小見出しから(場面の見出しが `**END-G**` だけでもよい)。「」の前の言葉(真グッド・偽りエンド など)が札の種類の名前

## 場面の見出し

`| | **C3-1a 雪の上の影** | | 条件: f_kuroba=0 / 曲: 怖 / 背景: 雪原 / 次: C3-2 |`

| 欄 | 読み方 |
| --- | --- |
| 条件 | `f_xxx=1` `score>=7` など。`かつ` / `または` でつなぐ。比べ方は `= != >= <= > <`。書いていないフラグは0。**文で書いた条件**(「Q7a でドラを選んだ」)は、その場面を「問いの行き先・次でだけ入る場面」にする(並びでは入らない) |
| 曲 | 印(日・不・怖・推・決・切・温・戦・屋)か曲のid。`★` が付いた場面は新曲「Kissからはじまるミステリー」。`なし` で止める |
| 背景 | 名前のまま。今ある絵の名前(`monhero_plaza` など英字)は絵、雪山・ペンションの名前は言葉で色を描く(雪原・ホール・廊下・鏡・屋根裏・会場・台所・書斎・通り道・柱時計・山道・停電)。絵が来たら `79-screen-xmas-novel.jsx` の `XMAS_NOVEL_BG` に足すだけ |
| 次 | 文(「Q7a で決まる」「おしまい」)は覚え書きとして読み飛ばす。読むのは ID だけ: 場面ID(`C3-2`)・仲間のID(`C3-2` で `C3-2a`/`C3-2b` の条件の合う方)・行ID(`Q7a` 「選び直す」の行き先)・`END`(条件の合うエンディングへ) |

- 「次」が無い場面は、台本の並びで次の(条件の合う)場面へ。同じ所で分かれた仲間(`C3-1a` のあとの `C3-1b`)は飛ばす
- エンディングの場面(`END-G` など)へは並びでは入らない。終章の最後の場面に `次: END` と書くか、最後の場面のあとで自動で選ぶ
- エンディングの見出しは `**END-G グッド「やり直しのクリスマス会」**`。英字 G/N/B/A が グッド/ノーマル/バッド/あつルート。「」の中が記録に出る名前
- エンディングの場面に「次」があると:
  - 「次」が**場面**(カーテンコール)なら、そのまま続けて読み、その場面が終わったところでエンディングの札を出す。カーテンコールの場面は、題か ID に「カーテンコール」「CC」を入れる(`**CC-G カーテンコール**`)。見出し `## カーテンコール` の下に置いてよい
  - カーテンコールの見出しの条件に `END-G の G-9 のあと` と書くと、エンディングの G-9 のあとに差しこむ(道具がエンディングの場面を分ける)。`END-N のあと` ならエンディングの終わりに続ける。カーテンコールの「次」`G-10` は、分けたうしろへ戻る
  - カーテンコールの場面のあいだは幕を下ろしたまま、12人の並びを幕の前に出す。場面を出ると幕が上がる。話し手「全員」は名前だけ出す
  - 「次」が**問いの行**(`Q7a`)なら、終わりの札に「選び直す」が出て、そこへ戻る
- エンディングの場面の**すぐうしろに置いた場面**(外側の `OUT-G` など)は、「次」が無ければそのエンディングの続きとして読み、終わったところでエンディングの札を出す
- **過去編**(r1126-046): `## 過去編 ～題～` の見出しの下の場面(章ID `C12`・場面 `C12-1` など)。並びでは入らず、真グッド(END-G)を見たあと「章から」に出る(保存の `endings` で決める)。読むだけで、最後の場面のあとは起動画面へ戻る(エンディングへは進まない)。過去編だけの人(カノン・祖父・幼いきゅうこ など)は名前だけ出す(道具の `PAST_SPEAKERS`)。背景の名前に「12年前」と書くと、古い写真の色をかぶせる
- **幕間**(r1126-046): ふつうの場面と同じ書き方(場面ID `C2-M` など。末尾を英大文字にすると仲間の場面と見なされない)。前の場面の「次」を幕間へ、幕間の「次」を元の行き先へ
- 外側の場面: 見出しの欄の頭に「外側」と書いた場面。`## 外側の場面 … ～題～` の見出しの下に置いてよい。外側の章は章の札・「章を選んで読む」に出さない
- **強制バッド**(`## 強制バッド` の見出しの下・`### C2-X → END-X1「名前」` の小見出し): `END-X1` などはエンディングとして扱い、エンドヒストリーにも並ぶ。見出しの「次: 「選択の直前からやり直す」で A2 へ」は、終わりの札の「選択の直前からやり直す」ボタンになる。覚えだけの帯(「(「選択の直前からやり直す」で、A2 へ戻る)」)は出さない
- 台詞の `{犯人にした人}` は、いちばんあとの「人を選ぶ」推理で選んだ人の名前になる
- エンディングの記録から、見たエンディングを「見返す」ことができる(カーテンコールまで流れる。進み具合・記録は変わらない)

- 行の番号の末尾 `a` / `s`(`7-1-3a`)は、あつ派 / ソラシド派だけの行(第1章の `A1` の1つめ / 2つめ。中では `f_A1=1` / `f_A1=2`)。強制バッド(`2-X-4a`)・分かれた場面(`7-A-1a`)・エンド(`G-17a`)・外側(`OUT-G-3a`)の番号にも付けられる。行動の選択肢だけを派で替えるときは、選択肢に `[f_A1=1]` / `[f_A1=2]` を付ける(出る方だけが並ぶ)
- 行の番号の末尾 `g3` / `g2` / `g1`(`G-20g3`)は結びの一言: 7問とも一発 / 4〜6問 / 3問以下

- 行の番号は場面の中で同じにしない(読んだ印に使う。同じだと既読スキップがまちがう)

## 選択

番号が `Q…` は推理の問い(成績に数える)、`A…` は行動の選択(数えない)。台詞の欄の頭の【…】で形を決める。

- **突きつけ**: `【推理の問い①・一発目で決まる f_kuroba】問いの文 / 【正解】閉まった裏口`
  - 正解が2つなら `【正解】A / B`。手がかりの名前は手がかりの行と一字ちがわずに
  - **一発目で決まる問いは、フラグの名前を【】の中に書く**(`一発目で決まる f_kuroba`)。一発目で当てたら1、まちがえたら0。あとから当てても変わらない
- **人を選ぶ**: `【最後の問い 1段目・人を選ぶ】黒いサンタは、だれ？ / 【正解】きゅうこ`(12人の並びから選ぶ)
- **最後の問い**: 【】に「最後の問い」が入った問いは、1段目と2段目で1問に数える(両方一発目のときだけ)
- **行動**: `【行動】問いの文 / 選択肢1 / 選択肢2 …`。選択肢の後ろに
  - `{f_lullaby=1}` 選んだらフラグを書く / `[f_lullaby=1]` その条件のときだけ出る / `(→C9-2へ)` 選んだら行き先へ

- **やり直しのない推理**(1回目・2回目の推理): 最後の選択肢のうしろに、行き先の書き添え `(ドラ → C7-A へ。きゅうこ → Q7m へ。ほかの人・まだ決めない → C7-B へ)` があると、その問いは選んだらやり直しなしで行き先へ進む
  - 人を選ぶ形: 12人の名前を「 / 」で並べ、正解の人に `【正解】`。人でない選択肢(「まだ決めない」)はボタンで足す
  - 行動の形(`【1回目の推理 2段目・動機を選ぶ】`): 正解の選択肢のうしろに `【正解】`。行き先は丸数字で `④ → C8-1 へ。ほか → C7-B へ`
  - 書き添えの左: 人の名前 / `ほかの人`・`ほか` / `まだ決めない` / 丸数字。右: 場面ID・行ID(`Q7m`)・`END-A`
  - 正解のときに `-ok` の返しがあれば読ませてから進む
- **成績に数えない問い**: 【】に「2回目」「推理の問い⑦」「数えない」が入った問い。【】に「1回目の推理」「最後の問い」が入った問いは、1段目と2段目で1問(両方一発目のときだけ)

## 保存(新しいキー `mh_xmas_novel_v1`・既存のキーは触らない)

`{ v:1, cur:{scene, idx, flags, clues:[{n,d}], ans:{問い:{t,f,w}}} | null, read:[読んだ行], endings:[見たエンディング], first:{問い:{f}}, snaps:{章:章に入ったときの cur}, titleSent, auto }`

- `first` は一番はじめに答えたときだけ書く(章から読み直しても変わらない)。称号はこれで数える(全部 true)
- 章から読み直すと、`snaps` の「その章に入ったときのフラグ・手がかり・答え」から始まる
- 壊れた値・台本に無い場面IDは `xmasNovelNormalize` で既定へ戻す

## 入口・ゲームの名前・遊べる期間

- `openXmasNovel({ playerName, onClose })` … 関数1つで開く(body に重ねる。App の状態は使わない)。開くと届いたゲームの起動画面(題字・ノイズ・走査線・「はじめから/つづきから/章から/エンドヒストリー」)
