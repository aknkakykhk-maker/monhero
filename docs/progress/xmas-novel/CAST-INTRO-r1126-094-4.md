# 事件簿: 人物紹介(「登場人物 12人」の行)の演出(台帳 r1126-094 追記4・追跡表 r1128-049)

社長「登場人物出すときはどまんなかにもっと演出じみていれて」(本番・iPhone 縦・第一章「最初の夜」)。

## 前 → 後

- 前: 画面の上(上から12%)に寄せた枠に、12人の顔が一度に並ぶだけ。縦では枠が章の題の帯にかぶっていた
- 後: 上の帯(ボタンと章の題)と文字の箱のあいだの、まん中に出す。縦は 4人×3段で顔を大きく
  1. 枠が暗がりから開く(0.7秒)→ 見出し「登場人物」の字の間が詰まり、線が中から伸びる
  2. 1人ずつ(0.16秒おき)、黒い影の姿から色が戻り、名前と一緒に下から入る
  3. 12人そろったら、全員の枠に金の光が1度走る(約3.5秒で終わる)
- 1回目のタップで全員そろった所へ、2回目で次の行へ。既読・オートは約1秒に縮める。既読スキップ中・動きを減らす設定では、そろった所から
- 揺れ・振動は足していない(r1126-094 追記3 の表のまま)。暗い色のまま(金の細い線と弱い光だけ)

対象の行: 1-6-4(第一章 最初の夜)・2-5-8・10-4-7(「登場人物 12人」の3行)。
同じ置き場を使う所(印の付く並び 3-1-17 ほか・悪いエンドの判・カーテンコールの並び)も、まん中に置くように直した。
印の出る動き(赤いバツ・行方不明・黒いサンタの判)は前のまま。推理で人を選ぶ窓(下から出る板)は変えていない。
