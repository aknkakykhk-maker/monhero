## 決めた順番(全部の場面に効く)

「文が出る → 一拍 → 演出」にそろえた。

| 演出 | 前 | 後 |
| --- | --- | --- |
| 遺体・倒れた影(黒羽 3-1-4、白瀬 5-4-5、えるびん 10-1-4、ももすけ 10-2-7、もちまる 10-3-7、強制バッド・悪いエンドの各遺体、過去編 12-6-1) | 見つける文と同時に出た | 見つける文のあいだは暗転 → 文が出きって一拍 → ゆっくり明けて出る。暗いうちにタップすると、まず明ける(暗いまま次へ進まない)。台詞をはさんで同じ人の影に戻るときは暗転させない |
| 様子を書いた帯の赤・にじみ・揺れ(3-1-7、3-1-9、6-5-3、6-5-6、10-1-5、10-2-8、10-3-6、各エンドの red/bleed) | 文の1文字目と同時に光った | 文が出きって0.3秒後(遺体が明けた行は明けたあと) |
| 音の帯(ドン・ギィ・ボーン など fx に se がある行) | 文と同時 | 文と同時のまま(音と字が一緒に来る所) |
| 暗転の行(dark) | 文と同時 | 同時のまま |
| 場所が替わる | 背景がぱっと替わるだけ | 暗い幕が横に流れて明け、絵がゆっくり寄る。左上に場所の札(「夜の裏口　吹雪」など)。遺体を見つける行では幕を出さず暗転だけ |
| 時間が飛ぶ(朝・夜が替わる) | 同上 | 暗転して、ゆっくり明ける |
| 過去編へ入る | 同上 | 色あせた光がにじんで、古い写真の色になる(札は「12年前の…」) |
| 章の札 | 0.6秒で出るだけ | 黒から明け、章の名前が字の間を詰めながら浮かび、線が中から伸び、題がにじみから浮かぶ。札を閉じると、場面が黒から明ける |
| 人物の初登場(台本でその人が初めて話す行だけ) | 下から少し上がるだけ | 黒い影の姿から色が戻る。左上に金の線と名札(イチーカ「ペンションのオーナー」、もちまる「ペンションの世話役」、黒羽・白瀬「招かれざる客」。助手たちは名前だけ) |
| 話し手が替わる | 同上 | 少し寄って出る(0.5秒) |
| 表情だけ替わる | 同上 | すっと替わる(0.2秒) |
| 「？？？」の話し手 | 笑い声だけ黒いサンタの影、ほかは丸い頭の影 | いつも黒いサンタの影(追記2) |

既読の行・オートは短く(0.3〜0.5秒)、既読スキップ中は出さない。どれもタップで飛ばせる。動きを減らす設定の端末では、すぐ終わる。

丸い頭の影(XmasNovelShadow)が残る所: 名前のある人の絵が読めなかったときの代わりと、登場人物の並びの顔が無いとき。
黒いサンタにすると「その人が黒いサンタ」と読めてしまうので替えていない。

## 音の合図の名前(効果音の会話 r1126-093 へ)

こちらは見た目だけ。鳴らす所を足すなら、次の名前で:

- `scene_place`(場所の幕が流れる) / `scene_time`(暗転して明ける) / `scene_past`(過去編へ入る) / `chapter_open`(章の札が浮かぶ)
- `figure_first`(人物が初めて出る・名札) / `body_reveal`(遺体を見つける行で暗転が明ける瞬間)
