既読の行・オートは短く(0.3〜0.5秒)、既読スキップ中は出さない。どれもタップで飛ばせる。動きを減らす設定の端末では、すぐ終わる。

丸い頭の影(XmasNovelShadow)が残る所: 名前のある人の絵が読めなかったときの代わりと、登場人物の並びの顔が無いとき。
黒いサンタにすると「その人が黒いサンタ」と読めてしまうので替えていない。

## 場面ごとの揺れ・振動(追記3の2)

台本の「揺れ」(fx の shake)は、どの行にも書かれておらず、1度も揺れていなかった。
画面全体を作り直して揺らしていたので、立ち絵や遺体の出る動きまでやり直しになる作りでもあった。揺れは画面の位置だけを動かす形に替えた。

| 行 | 文 | 強さ |
| --- | --- | --- |
| 1-3-1 | ドン、ドン(玄関の扉を叩く) | ふつう |
| 2-1-10 / 2-3-4 / 2-3-7 / 2-3-9b | バタン・12の鐘・ブツン(停電)・ゴトン | 小 |
| 2-3-9c / 2-5-1 | ガタン(裏口の重い音)・ガタン！(かんぬき) | ふつう |
| 5-4-4 | ギィ……(鏡が開く) | 小 |
| 6-5-1 | ドサッ……！(通り道の奥で落ちる) | 強 |
| 6-7-4b / 10-2-6 | 叫び声・小さな声と落ちる音 | ふつう |
| 7-P1-13 / 7-P3-11 / 7-P3-12 / 7-W-8 / 9-1-4 | 0時の鐘・窓の開く音・針 | 小 |
| 2-X-2 / 5-X-3 / 6-X-4 / 2-Y-9 / 10-X-8 | 強制バッドの衝撃(ゴッ・ガシャン・ドサッ) | 強 |
| 6-X-5 / 6-X-8 / B-4 / B-13 | かんぬき・扉を叩く・悲鳴・倒れる音 | ふつう |
| 2-Y-17 / B-2 / B-3 / 1-O-22 / 12-3-2 / 12-4-2 / 12-4-5 | 鐘・停電・過去編の音 | 小 |
| 遺体を見つける行(すべて) | 暗転が明けて影が出る瞬間 | 小 |

- 音の帯は音と同時。章の札の下で着いた行(第一章の頭の「ドン、ドン」)は、札を閉じてから揺れる
- 端末の振動: `navigator.vibrate` がある端末(Android)だけ、小 20ms・ふつう 45ms・強 70-40-90ms。iPhone の Safari には無いので、画面の揺れと音だけ
- 事件簿には振動・揺れの設定が無いので、端末の「視差効果を減らす(動きを減らす)」に従い、そのときは揺れも振動も出さない。既読スキップ中も出さない
- 確かめ: 1-3-1 で揺れの途中の画面の位置が -1.6px → +3.0px → 0(0.4秒で戻る)、振動が 45ms で1回呼ばれた
