# 事件簿: 大事な選択は「押して選ぶ → 決定」(台帳 r1126-113・追跡表 r1128-065)

社長「犯人選ぶときに押したら選択になってもっかい決定が出るようにして」。

- 押すと、選んだ状態になる(真鍮の縁と光・人は左上に赤い ✓・手がかりのボタンは「選んだ」)。窓は閉じない
- 下に「『(選んだもの)』を名指しする / を突きつける / に決める」と「決定」。決定を押して初めて答えになる。ほかを押せば選び直せる
- 一発で当てた記録・保存の形は変えていない(決定を押した答えを、前と同じ道で記録する)

## 当てた所

| 問い | 数 | 形 |
| --- | --- | --- |
| 人を名指し(黒いサンタの正体・Q7a・Q11a) | 2 | 選ぶ → 決定(「まだ決めない」も同じ) |
| 手がかりを突きつける(推理の問い Q2a〜Q10a) | 7 | 「これを選ぶ」→ 決定 |
| 行動の選択で、一発で当てる記録がある/やり直せない物(Q7m) | 1 | 選ぶ → 決定 |
| ふつうの行動の選択(A1〜A10・話の分かれ道) | 7 | 前のまま、押してすぐ決まる |

背の低い横持ちでは、窓の全体を1つに流し、決定の札を下に貼りつけた(決定の札の分だけ人の並びがつぶれたため)。
