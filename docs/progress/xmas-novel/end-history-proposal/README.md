## 案1 種類ごとの札

- 上に「30個中5個」と、見た割合の細い赤い帯
- 真グッド・ノーマルグッド・バッドエンド・偽りエンド・強制バッド・名指しエンド・迷宮入り・真相のその先・おまけの見出しごとに、「見た数 / その種類の数」
- 札は2列。見た札は左に種類の色の線・種類・名前・赤い「記録」の判。押すと見返す(札そのものが押す所になるので、押せる大きさは今の「見返す」より大きい)
- 未見は「？？？」でひびの線
- 気になる所: 見出しで、まだ見ていない種類の名前と数も分かる(例「真相のその先 0 / 1」)。伏せるなら、未見だけの種類は見出しを「？？？」にする

## 案2 事件ファイルの棚

- 綴じた調書が、7冊ずつの棚に並ぶ。背に番号と名前(縦書き)、背の左の色がエンドの種類
- 見た物には赤い「済」の判。未見は暗い背に「？？？」
- 上に「30冊中5冊に判」
- 押すと調書が開いて見返す。背の幅 44px(押せる大きさは今の「見返す」より大きい)
- 種類の名前は出ないので、見ていない種類は分からない

## どちらも

- 字の大きさ: 名前 17px・種類 10px・見出し 22px は今と同じ
- 第3弾でエンドが増えても、案1 は見出しの中に札が増える、案2 は棚が1段増える
- 動きを減らす設定・暗い色の決まり(r1126-093 追記1)はホラー案と同じ
