# カード部屋にいる助手と対戦すると、ごほうびアップ(案・まだ作らない)

2026-11-07 カード部ルールくん。社長「バトルカードをやってる助手がいて、その助手と戦った場合、報酬が上がるとかもいれたいね」(台帳 2026-11-07「上がり方は案で選ぶ」)。
モンヒロビートの「助手が自分でモンビーにいる間は、その助手と何回でも券なしでセッション」と対になる形。

## いまのごほうび(比べる元・main の数字)

| 遊び方 | 勝ち | 負け(最後まで) | ほか |
| --- | --- | --- | --- |
| 助手と対戦 EASY〜MASTER | ビートP 80 / 110 / 140 / 170 / 200 | 勝ちの 3/4(自分の番10回で満額) | 1日の上限なし・その日はじめての勝ち +50 |
| カードランクの経験値(助手と対戦) | 6 / 8 / 10 / 14 / 18 | 勝ちの 1/3 | その日はじめての勝ち +30 |
| ほかのブリーダーのデッキ(手で) | MASTER と同じ(200) | MASTER と同じ | |
| オートで挑む(ほかのブリーダーのデッキ) | 手の半分 | 手の半分 | 1日はじめの3回だけ(セッション券で1日20回まで足せる) |
| マルチ対戦 | 800 | 300 | |

★「助手と対戦」には、今はオートが無い(オートはほかのブリーダーのデッキだけ)。

## 1. 上がり方

| 案 | 中身 | MASTER の勝ち | 釣り合い |
| --- | --- | --- | --- |
| **A(推奨)1.5倍** | ビートP・カードランクの経験値・クイック周回を 1.5倍(その日はじめての勝ちの +50・+30 は倍にしない) | ビートP 300・経験値 27 | ふだんの助手戦(200)より上、マルチ(800)より下。いる時間だけなので、ねらって来る楽しみになる程度 |
| B 2倍 | 同じものを 2倍 | ビートP 400・経験値 36 | マルチの半分。いる時間に助手戦を回すのがいちばん得になり、マルチより手軽に稼げる |
| C 上乗せ | 3ターン以上やった試合に、勝ち負けにかかわらず ビートP +100・経験値 +10 | 勝ち 300・負けでも +100 | 数字が分かりやすい。EASY でも同じだけ増えるので、弱い強さで回すのが得になる |

## 2. 何回まで

| 案 | 中身 |
| --- | --- |
| **A(推奨)いるあいだは何回でも** | モンビーの「いるあいだは何回でも券なしでセッション」とそろえる。居場所は時間の区切り(4時間ほど)で変わるので、ずっと続くわけではない |
| B 1日1回 | その日はじめてカード部屋の助手と対戦した1戦だけ |
| C 時間の区切りごとに3回 | 居場所が変わるまでに3戦まで |

## 3. オートのときも上がるか

| 案 | 中身 |
| --- | --- |
| **A(推奨)手で遊んだときだけ** | 助手と対戦には今オートが無いので、今の形のまま。上がるのは手で遊んだ試合だけ |
| B オートも足して、オートでも上がる | 助手と対戦にもオートを足す。オートはほかのオートと同じく手の半分で、そのうえで 1.5倍。オートのごほうびの回数(1日3回)は使わない |

## いまカード部屋にいる助手の読み方(ナカヨシ5とすり合わせ済み)

- 保存のキーは増やさない。読むだけ
- 助手ライフ段階2(ナカヨシ6)で、読むだけの口 `assistantLifeAtCard(id)`・`assistantLifeCardIds()` が入る(モンビーの `assistantLifeAtBeat` と同じ形)。中身は「カード部屋でカード研究」(HOME の MFバトルカードの札の下に顔が出る助手と同じ)。組で一緒にいる助手も全員「いる」
- 対戦の画面からは `assistantLifeNow` を呼ばない(様子を決め直して保存してしまうため)
- ごほうびアップは「対戦を始めた時点でカード部屋にいたか」で決める(試合中に時間の区切りをまたいで出ていっても、その試合は上げる)
- その助手と対戦したら `assistantLifeOnCardMatch({ assistantId, won, at })`(段階2で足す口)を呼ぶ。今日あったこと・生活のリズムに数える
