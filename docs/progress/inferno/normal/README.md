# インフェルノ: ふつうの敵の層のシールドの見え方と、ボスとの見分け方の案(2026-10-31・レフェリーくん)

社長「W1〜8のふつうの敵にも層を」(ジン部長経由)。W1・W2の敵は2層、W3〜W8(ふつうの敵もボスも)3層、W9 デュラハン4層・W10 ムー5層。
ゲージと割れる演出はボスと同じ形(#4422)。ボスかどうかは、セコンドくんの `enemyShellView(enemy).boss` で読む(W3/5/7/9/10 の敵だけ true)。
**本体はまだ直していない(見本だけ)。** 極限チャレンジのバトル(クラシック)を立ち上げ、シールドの数だけ外から差し替え、見分けの印はブラウザで描き足した。
数値・敵の名前は仮(ライフの数字は最初の難易度の WAVE1 のまま)。中央の「ためる」はその時の敵の予告。
