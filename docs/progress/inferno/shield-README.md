# 作り直し(2026-10-31・社長の答えを入れた版 `shield2-*`)

社長の答え(ジン部長経由): ①層ごとに数値 ②下の層から割れる ③割れた層は点線をやめて自然に残す(1〜2案) ④割れる演出をもっと派手に(ひび→溜め→砕ける、最後の層はいちばん派手) ⑤案A/案Bは両方。
**本体はまだ直していない(見本だけ)。** 撮り方は前と同じ(タクティクスのバトル画面に描き足し・敵の絵はカワズモーのまま名前だけ「ムー」)。場面は5層のうち3層残り・今の層は 1,240 / 1,800(数値は仮)。

- 層の数値は、ボスのライフ(「120 / 120」)と同じ「今 / 上限」の書き方で、ゲージの中の右に出す
- 割れる順は下から。いちばん下の残っている層が、いま削られている層
