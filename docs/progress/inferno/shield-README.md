# インフェルノのボスのシールドの見せ方の案(2026-10-31・レフェリーくん)

社長「シールドの表示案。これをモンヒロ風にアレンジしてこの1ゲージが1シールドして割れると演出が入り、強化」(ジン部長経由)。
**本体はまだ直していない(見本だけ)。** 参考の絵(よその作品)は形・色・字・飾りを写さず、モンヒロの画面の色(赤・橙・金)と字で作り直した。

写真はタクティクスのバトル画面に、ゲージ・札・演出をブラウザで描き足して撮った(本体のコードは変えていない)。
敵の絵はカワズモーのまま、名前だけ「ムー」に書きかえている。場面は「5層のうち3層残り」。帯の文は仮。
