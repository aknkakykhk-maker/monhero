# 3層のボスの見え方・4枚目の連撃の演出・ゲージの色の案(2026-10-31・`shield3-*`)

決まったこと(ジン部長経由): 残り方は1(ひびと色抜け)・札は案B・ゲージと札はそのボスの層の数だけ(ムー5・デュラハン4・ほか3)。
演出は「何枚目が割れたか」で決まる: 1〜3枚目=途中の層の演出+攻撃+60%の帯(3層のボスは3枚目でも最終形態にしない)/4枚目=「必殺技が連撃に!」(デュラハン・ムー)/5枚目=いちばん派手(ALL SHIELD BREAK・最終形態の帯)+3連撃(ムーだけ。`shield2-演出_最後の層_*` の絵)。
シールドは割れるたびに+30%ずつ大きくなる(見本の数は 1,800 → 2,340 → 3,042 → 3,955 → 5,141。仮)。
