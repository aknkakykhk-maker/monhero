## 撮って直した所

- 横向き・背の低い画面の細い1本(ライフの棒のすぐ下)に、敵の移動の予告(「◯距離に移動しようとしている…?」)が重なった → 細い1本を左に寄せた
- 味方の枠の EX の札に「あとnull」と出ていた(残りターンの無い効果)→ 数を出さないように直した(2026-10-29 の EX の札の直し漏れ)

- 敵が技を選んだ瞬間に一瞬浮かぶ「ためる」などの文字は、縦のクラシックでゲージの下の層に一瞬かかる(浮かんで消える文字なので、そのままにした)
- 背の低い縦画面(360×640)では、コピーの小窓の右端(次の札「でこぴん」)が敵の絵にかかって切れる。前からある小窓の形で、シールドとは関係ない
