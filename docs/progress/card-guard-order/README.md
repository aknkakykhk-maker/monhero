# MFバトルカード: 攻撃の動きの順番(2026-10-31・カード部ソランド)

社長「バトル中の攻撃演出で攻撃モーションがあったあとに回避防御を選ぶがややこしい。…相手が攻撃してきて効果をわかるようにして、防御とか選べるようにしてそのあとにモーションが正しい」

- 今: 技を出した手で攻撃の動き → 守りを選ぶ → よける・防ぐ・当たるの動き(攻撃が2回あるように見える)
- 直したあと: 技を出した手では動かさず、まんなかに「◯◯の「技」が△△に！(ダメージ◯)」と受けるダメージを出すだけ → 守りを選ぶ → 攻撃の動きを1回 → 届くころに、よける・防ぐ・当たる・数字・音
- 作り: 84 の step() で、相手の守りの番に入る技の動きを pendingAtk に控え、守りが決まった手(回避・防御・何もしない)で流す。
  当たりの動き・数字・音・ダウンの帯・はね返しの光線は、攻撃の動きの半分ぶん遅らせる(lead)。動きの設定が「ふつう」のときだけ(短め・出さないは今までどおり)
- 自分が攻撃する側も、マルチ・観戦・見返し・大会の見返しも、同じ step() を通るので同じ順番になる
- 手の決まり方・勝率は変えていない(82 は触っていない)
