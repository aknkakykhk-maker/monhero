# 助手どうしの共有・仲良し度・掛け合い(作る前の決めごとと段取り)

2026-11-06 リバースがまとめた。社長の依頼「助手との会話を助手同士でも共有というか、助手同士での親密度とか、勝手に助手同士で会話したり仲良くなったりとか。API使ってもいい」。
**新しい会話で作るときは、まずこの1枚と `docs/rules/PRESIDENT_DECISIONS.md` を読む。**

## 今あるもの(使い回す)

- おしゃべり: `supabase/functions/assistant-chat/`(`core.js` が本体)。モデルは `claude-haiku-5-5`。回数は1人1日100往復・全員1日2,000往復まで。仕様の正本は `docs/spec/ASSISTANT_CHAT.md`
- 思い出メモ: `mh_assistant_chat_memo_v2` = `{ [助手id]: { likes, goals, events, topics, summary } }`(端末だけ)。会話は `mh_assistant_chat_log_v1`
- ふだんの吹き出しを1日1回まとめて作る仕組み: `kind:'daily_lines'`(`core.js` の `DAILY_*`。1人1日3回まで、全員分はおしゃべりと同じ表で数える)。API 版の掛け合いは、この形をまねる
- 助手どうしの呼び方: `data/assistants.js` の `ASSISTANT_PEER_CALLS`
- 端末側のおしゃべり: `src/parts/56-assistant-chat.jsx`

## 段階と設計

| 段階 | 中身 | 保存(新しいキーだけ) | API |
| --- | --- | --- | --- |
| 1 会話の共有 | おしゃべりのとき、ほかの助手の思い出メモを渡す(例: ききが「みゅあちんから聞きましたよ」と話題にできる)。「ないしょ」の印が付いたものと、30日話していない助手の分は渡さない | 話した日: `mh_assistant_chat_last_v1` `{ [助手id]: 'YYYY-MM-DD' }`。ないしょの印はメモの中で持つ(下の注意) | 今のおしゃべりに相乗り。`core.js` で `peerMemos` を受け取って決まり文に足す |
| 2 助手どうしの仲良し度 | ペアごとに Lv1〜5。上がるのは、同じお話に2人が出た・その日に2人を交互に選んだ・掛け合いを見たとき(1日に上がる上限あり)。Lv2: 掛け合いが増える / Lv3: プロフィールに関係図 / Lv4: 息の合った掛け合いが増える・API 版でお互いの話題を多めに出す(2026-11-07 社長「呼び方は変えないでいい」で呼び方を変える案はやめた) / Lv5: 2人の特別なお話 | `mh_assistant_peer_bond_v1` `{ "kiki-mua"(名前順): 点数 }` | 不要 |
| 3 台本版の掛け合い | ペア×場面ごとの決まった台詞(まず全ペアに数本ずつ)。HOME で1日5回まで、ほかの画面でもときどき流す | `mh_assistant_peer_talk_log_v1`(最近30件)・`mh_assistant_peer_talk_day_v1` `{ day, count }` | 不要 |
| 3 API 版の掛け合い | 1日2〜3回、その日の遊んだ記録(数字だけ)と共有メモから、その日の掛け合いを数本まとめて作る。足りないとき・失敗したときは台本版へ戻る | 作った掛け合いを置く `mh_assistant_peer_talk_gen_v1` `{ day, talks:[…] }` | `kind:'peer_talks'` を `core.js` に足す。1人1日3回・全員1日3,000回 |

注意:
- 既存のキーの形は変えない(CLAUDE.md ⑦)。「ないしょ」の印をメモ v2 の中に足すなら、項目を足す形にして、無い人は「印なし」として読む
- 掛け合いの台詞は助手の口調のくせ(`ASSISTANT_CHAT_PERSONAS` など)と `ASSISTANT_PEER_CALLS` に合わせる。台本を書いたら `tools/assistant/assistant-chat-check.js` が突き合わせる
- モンスターを「子」と呼ばない(助手が特定のマスモンを「この子」「あの子」と言う台詞だけは例外)

## 費用の見積もり(Haiku 5.5。料金は入力 $0.10・キャッシュ読み $0.01・出力 $0.50 / 100万トークン)

| もの | 1回あたり | 上限まで使い切ったとき(月) | ふつうの見立て(月) |
| --- | --- | --- | --- |
| 今のおしゃべり(変えない) | 約 $0.0007〜0.0015 | 約 $97(全員1日2,000往復) | それより少ない |
| 段階1 共有メモの相乗り(全部の欄を7人分、約4,000トークン増える) | +約 $0.0004(キャッシュに乗せれば +約 $0.00005) | +約 $24(キャッシュに乗せれば +約 $3) | +数ドル |
| 段階3 API 版(入力 約5,000〜8,000・出力 約1,000〜1,600) | 約 $0.001〜0.0016 | 全員1日3,000回で 約 $90〜144 | 毎日遊ぶ人100人×3回なら 約 $9、1,000人なら 約 $90 |
| **合計の最悪** | | **約 $265**(キャッシュを使えば 約 $245) | 遊ぶ人の数しだい |

- 上限は Secrets で下げられるようにする(今のおしゃべりと同じ作り)。上振れしたら上限を下げる
- 共有メモは会話のたびに同じ文になりやすいので、決まり文と一緒にキャッシュへ乗せる
