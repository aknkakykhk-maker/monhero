## 1. モンスター以外で、絵がキラの見た目のカード

- レアの段(通常・キラ・別絵キラ)を持つのはモンスターだけ。モンスター以外は全部「絵がキラっぽいだけ」(段も確率も無い)
- いちばんキラっぽいのは **ブリーダーのカード 33枚**(銀〜黒の金属の枠に光沢のグラデーション):
  112・113・114・122・126・127・128・252・253・254・276〜280・351・352・366・F115〜F120・F255〜F263
- 金色・銀色の枠の技カード(ガリ・スエゾー・ミュウ・ワーム・カラーパンドラ / ゴーレム・デュラハン・メタルナー)は、その種族の枠の色(キラではない)
- 測り方: 全361枚の絵の左の枠の色を測って分け、目でも確かめた
