# MFバトルカード: パックの演出とキラの光り方(案・まだ入れない)

2026-10-31 ルールくん。社長「パックのガチャ演出をもっと強化して。レアキラはもっと派手にするとか、昇格演出とかいろいろほしい。設定でオンオフも可能」
「モンスターカード以外にも見た目がキラのやつもあるからあれも扱い変えてほしい」「キラやレアキラの光り方が地味だった」。

**このブランチだけの試し作り。社長の「これで入れて」までは main に入れない。** 確率と中身は変えない(見せ方だけ)。

## 1. モンスター以外で、絵がキラの見た目のカード

- レアの段(通常・キラ・別絵キラ)を持つのはモンスターだけ。モンスター以外は全部「絵がキラっぽいだけ」(段も確率も無い)
- いちばんキラっぽいのは **ブリーダーのカード 33枚**(銀〜黒の金属の枠に光沢のグラデーション):
  112・113・114・122・126・127・128・252・253・254・276〜280・351・352・366・F115〜F120・F255〜F263
- 金色・銀色の枠の技カード(ガリ・スエゾー・ミュウ・ワーム・カラーパンドラ / ゴーレム・デュラハン・メタルナー)は、その種族の枠の色(キラではない)
- 測り方: 全361枚の絵の左の枠の色を測って分け、目でも確かめた

- 光り方は絵の上に重ねた光の層だけを動かす(絵そのものは動かさない)ので、たくさん並べても重くなりにくい
- 動きを減らす設定(prefers-reduced-motion)・カードのオプションの「揺らさない」では、ふちの光だけにする
- 試し作りのページ: `mock/mock.html`(録り方 `mock/rec-mock.js`・今の動画 `mock/rec-now.js`)

## 3. 入れるときの決まり(案)

- 設定に「パックの演出」オン/オフ。保存は新しいキー(例 `mh_card_pack_fx_v1`・既定はオン)。オフなら今くらいの短い開け方
- キラの光り方は設定に関係なく新しい形(重さは一覧で確かめる)
- 確率・中身・保存は変えない
- 更新履歴の文案は、案が決まってから
