# ChatGPT(画像生成)に貼るプロンプト

使い方:
1. ChatGPT の新しい会話に、案ごとに書いた画像を添付する。
2. 下の枠の文を、そのまま貼って送る。
3. 文字が崩れたら「文字だけ直して。ほかは変えないで」と頼む。直らなければ ④ の文字なし版で作り、文字はあとで載せる。

画像に入れる文字は次の3つだけ(正式名称。略称「モンビー」は画像に入れない)。
- モンヒロビート
- 本オープン
- 11月9日(月) 10:00

## ① ゲーム内の更新情報用(横長 16:9)

添付: `01-assistants-8.jpg` `02-myua.jpg` `03-kiki.jpg` `04-play-grand-stage.jpg` `05-past-event-poster.jpg`

```
スマホのリズムゲーム「モンヒロビート」の本オープンを予告する告知画像を作ってください。横長 16:9 です。

【雰囲気】
・添付の 05 番(以前のイベント画像)と同じ、華やかなアニメ調のお祭りの雰囲気にしてください。
・夜のライブステージで、金色の光・紙吹雪・音符・スポットライトが舞っている。添付の 04 番(演奏画面)にある、奥へのびる光るレーンと紙吹雪をステージの床に取り入れてください。
・色は金色と、深い紫・紺を中心に、ピンクと水色の光を差し色にします。

【キャラクター】
・添付の 02 番(白い髪・天使の羽の女の子「みゅあ」)と 03 番(ピンクの髪・赤いパーカーの女の子「きき」)を、中央の前に大きく描いてください。2人とも笑顔で、マイクを持ったり手を振ったりしてお祝いしている。
・添付の 01 番にいるほかの6人(あつ・ドラ・えるびん・きゅうこ・ももすけ・ソラシド)を、2人の後ろや左右に小さめに描いてください。楽器を鳴らしたり拍手をしたりして盛り上げている。
・全員、添付画像の髪型・髪の色・目の色・服・顔立ちに忠実に描いてください。別人の顔にしたり、服を変えたりしないでください。ドラは添付どおり、丸い顔にめがねの簡単な絵のキャラクターです。

【文字】
・入れる文字は、次の3つだけです。ほかの文字・英語・ロゴ・透かしは入れないでください。
  1. 「モンヒロビート」 … いちばん大きく、上の中央に。05 番のタイトル文字のような、金のふちどりの太い文字にします。
  2. 「本オープン」 … タイトルのすぐ下に、リボンの帯の上へ大きく。
  3. 「11月9日(月) 10:00」 … 下の中央に、はっきり読める大きさで。
・日本語の文字は、1文字も崩したり、ほかの字に変えたりしないでください。

【そのほか】
・キャラクターの顔と文字が重ならないようにしてください。
・画面の端から少し内側に、大事なもの(キャラクターと文字)を収めてください。
```
