# モンヒロビート 本オープン前の iPhone 通し確認(社長が実機で見る所)

2026-11-07 本オープン案 A3。上から順に1回通すと、本オープンで人が多く通る道をひと回りできる。
見る場所は本番 `https://aknkakykhk-maker.github.io/monhero/`。気になった所は番号で知らせてもらう。

## 1. 入口
1. HOME →「モンヒロビート」→ モードえらび →「ソロライブ」で曲えらびが開く
2. 曲えらびの上の帯(イベント・ビートPの案内)が、曲の一覧を隠しすぎていない
3. 一覧をなでて、止まる・引っかかる所がない(輪になって続く)
4. 「🔰 はじめての1曲」は、まだ1曲も遊んでいない端末でだけ出る(遊んだ端末では出ないのが正しい)

## 2. 1曲を通す(EASY で十分)
1. 曲を選ぶと試聴が流れる。決定 → 演奏が始まるまでの待ちが長すぎない
2. 押した所と反応する所がずれていない(11/2 の直し)。とくに **画面を回したあと・通知を開いて戻ったあと**
3. ホールド・スライドを帯から外すと帯が暗くなり、戻すと光る
4. 結果画面:スコア・ランク・コンボ・ビートP・マスモンの経験値が出る。「もう一度」「曲えらびへ」が押せる

## 3. 横画面
1. 曲えらびの「🔄 横」で横に切り替わる。字が切れていない
2. 横のまま1曲遊んで、ノーツの位置と指の位置が合っている
3. 縦へ戻して、曲えらびの一覧がずれていない

## 4. ランキング
1. 曲えらびの「🏆 順位」→ 全国ランキング。タブ「この曲」「総合」「週間」「イベント」が並ぶ
2. 「週間」タブに今週の順位が出る。残り時間が出ている
3. 自分の行が上に出る(遊んだあと)

## 5. マスモン・セッション
1. モードえらびの「マスモンのセッション」から1曲。マスモンが一緒に出る
2. 今日の無料の残り回数が減る

## 6. 音
1. マナーモード・音量ボタンで、曲とタップ音の大きさが変わる
2. 途中で別のアプリへ行って戻ったとき、音が止まったまま・二重にならない
3. イヤホン(有線・Bluetooth)で、音と判定がずれていない。ずれたらオプションの「タイミング調整」で直せる

## 7. 本オープンの日に見る所(印を立てたあと)
1. 予告:HOME で予告のお話が1回だけ流れる。更新情報・助手の告知に予告が出る
2. 本オープン:HOME で本オープンのお話が1回だけ流れる(途中、クラッカーから曲が Rising Hope に替わる)
3. ギフトボックスに「モンヒロビート 本オープン記念」が1つ届く。受け取ってダイヤ等が増える。2回目は届かない
4. ヘルプの「いまの状態」が本オープンの言い方になっている
5. プロフィール →「イベント回想」に、予告と本オープンのお話が並ぶ
