## 5. 目視はどこまで会話でやるか(トークンの案)

止め絵1枚(390×844)を会話で見ると、だいたい **400〜500トークン**。全部(1,320枚)見ると 約60万トークンで、会話が持たない。

| 案 | 中身 | 会話で見る枚数 | 目安 |
| --- | --- | --- | --- |
| **A(推奨)** | 390 縦は全場面を **12枚ずつの一覧の絵(縮小)** にして見る(約20枚)。ほかの幅は **機械が NG を出した所と、前の main との差が大きい所だけ** 実寸で見る。文は一覧の表(文字)で全部読む | 一覧 約20枚 + NG の実寸 30〜60枚 | 1回 約4〜5万トークン |
| B | 390 縦の全場面を実寸で見る + ほかの幅は NG だけ | 約220枚 + NG | 約12万トークン(2回の会話に分ける) |
| C | 機械の NG だけ見る(目で見ない) | NG だけ | 約1〜2万トークン。依頼文の「止め絵を実際に見て違和感も評価」を満たさない |

- 一覧の絵で「おかしい」と思った物だけ実寸を開く。報告では **自動確認済み / 目視確認済み(一覧の縮小で / 実寸で) / 未確認** を分けて書く
- 実機 iPhone Safari は **未確認** と必ず書く(Safe Area・ホームインジケーターは Playwright の iPhone 相当で近い値を入れて撮るだけ)。実機で見るのは社長にお願いする項目の表を報告に付ける
