# 実装済みモンスターの染色マスクの見直し(2026-10-26〜 ソメくん)

社長「実装されてるモンスターの染色マスクも確認してズレがあったら調整してきれいにして」。
キュービ・オリヒメは部長(ズカンくん)が仕上げたばかりなので対象外。対象は `ALL_PLAYER_MONSTERS` の28体。

## どう見たか

- `node tools/image/dye-mask-review.js <出力フォルダ> [id …]` で、**ゲームと同じ処理**(`getDyeRegionMasks` で部位マスクを作り、
  `getRecoloredImage` で染めた絵をマスクで切り抜いて元絵へ重ねる)で、濃い色(紺・赤・深緑・紫・橙)・白・パステルに染めた全身と、
  部位図(部位ごとの色を元絵に重ねたもの)を作り、原寸の4倍で問題の多い所を切り出して1体ずつ目で見た
- 数でも見た(図の題の行): **平らな所の境目**=境目の両側3画素先の元の絵の色がほぼ同じ(=境目が絵の線や色の変わり目に乗っていない)割合 /
  **まっすぐ**=縦横一直線に24画素以上続く境目の長さ(四角い範囲で決めた跡) / **点**=ほかの部位に囲まれた小さな点の数。
  ただし数は目安で、絵の線そのものがまっすぐな所(ウンディーネの耳の付け根の毛束)や、わざと形で分けている子(モノリスの帯)でも数が出る
- 写真: `before/<id>.jpg`(直す前。左から 元絵 / 部位図 / 濃い色 / 白 / パステル、下は4倍)。部位図の水色=平らな所の境目、黒=まっすぐな切れ目

## 直し方

- 道具: `node tools/image/refine-dye-mask.js <id>`(試す)/ `--apply`(配信マスクへ書く)。出発点は「いまゲームが使っている部位分け」で、
  **分け方はそのまま、境目だけ**元の絵の線・色の変わり目へ寄せる(元の絵を「同じ色が続くかたまり」に分け、かたまりごとに今の部位の多数決)。
  暗い線・塗り残しの点・細い筋・部位と部位の間の淡い線も、まわりの部位へそろえる
- 今の部位分けが部品を丸ごと別の部位に入れている所(ウンディーネの手など)は、**形でなく色で**直す。`CONFIGS` の `grow` で、
  正しい部位から「となりとの色の差が小さく、色相・彩度が条件に合う画素」をたどって広げる。暗い線や色の切れ目で止まる。
  進んでよい範囲(箱)はゆるく取り、部品がその中に収まるようにする(箱のふちが境目にならないよう、箱のふちの上で
  同じ色なのに部位が分かれている画素を数えて確かめる)
- 色相ルール・埋め込み部位マップの子も、仕上げた配信マスク(`images/monsters/<名前>-dye-mask.PNG`)で染めるようにする
  (`15-dye-and-art.jsx` の `EXACT_DYE_MASKS` に足す)。出発点は `tools/art-sources/dye-masks/<名前>-dye-mask-before-refine.png` に残すので、
  何度仕上げ直しても同じ結果になる
- 正解見本と比べる検査がある子(ミーア・ウンディーネ)は、見本も新しいマスクにそろえる
