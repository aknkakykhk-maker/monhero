# マスモン対戦の技を、資料の血統別の技へ移す段取り(2026-11-13 バトル部)

社長の決め(台帳 2026-11-13): 25種は「主血統の共通技+その種類が owners にいる固有技」、オリジナル5種は全部オリジナル(技種は社長が90技を決定・通常/固有の区別なし)。
技は資料の全部を持てる(8技の上限はなくす)。強さは調整してよいが個性(種類の得意の順位)は残す。オリジナル5種は勝率50%前後。

## 数字(済み・この枝)

- 写し表と調整: `tools/masmon-battle/masmon-grade-map.js --tune`(結果 `tune-2026-11-13.txt`・技表の形 `tuned-draft.json`)
  - 等級(17段)→数: 資料852技の並びを、いまの技表240技の幅へ分位で写す
  - 調整: 種類の平均(会心・削り 5割/命中 7割)を全体の平均へ寄せる・威力あたりのガッツを5割寄せる・威力の倍率は勝率が 38〜70% の外の種類だけ
  - オリジナル5種は 47〜50%(倍率が上限ならガッツを軽くする。命中では足さない)
- 勝率(能力をそろえた1対1の総当たり): いま 25〜74% → 38〜68%
