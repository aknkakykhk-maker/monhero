## まず分かったこと(直し方を決める前提)

1. **作り直しは公開中の譜面には向かない。** 59曲を作り直すと、押せない 83→7・帯の中 849→76・交差 1157→739 と形はよくなるが、
   **Lv. が2以上動く譜面が75**・ノーツ数が変わる譜面も多い(人の手直し・公開時のつまみが消えるため)。自己ベスト・フルコンボ・ランキングの意味が変わる
2. **位置だけ直す(ノーツの数・タイミング・種類はそのまま)なら記録はそのまま使える。** 押せない所は48譜面のうち42譜面で0になる。
   ただし公開中の譜面へ当てる口(`--song`)は「交差・届きにくいも全部減らす」形しかなく、**直す譜面の合計で約4300か所動く**(Evans MASTER だけで137か所)。
   覚えて遊んでいる人には別の譜面に近い。押せない所だけ直す段(`--mode must`)は今は新曲の書き出しにしか効かない → 公開中にも効くようにする小さな足しが要る(決めてほしいこと①)
3. 「押せない」は横持ちの親指2本で見た厳しい物差し。両手のシミュレート(公開の関門)は全部通っている。3本目の指・持ち替えで押せる所も含む
4. **表示の Lv. はほかの仕組みに使われていない**(ビートランクの経験値は難易度の種類で決まる)。表示を直しても記録・報酬には響かない。曲えらびの表示と並び順だけ
5. HELL は位置を直す道具が無い。Lv. の測り方はジゴクが作り直し中(v4)なので、HELL は v4 を待ってから決めるのがよい

直した曲と難易度の一覧はヘルプ(攻略情報局のモンヒロビートの項)に載せる案。

## 数字の作り直し方

```
node tools/mode/rhythm-chart-audit.js --write <フォルダ> --pictures 6                 公開中の全譜面の点検
node tools/mode/rhythm-chart-flow-fix.js --song <songId> --difficulty <難易度>          位置だけ直したら何件減るか(書かない)
node tools/mode/rhythm-chart-compare.js --make <作業フォルダ> --tracks <曲,…>           作り直し(作業フォルダだけ)
node tools/mode/rhythm-chart-compare.js --released --after <作業フォルダ> --tracks <曲,…>
```

- 前からある43曲は `--make` の手の仕上げが飛ばされる(`rhythm-held-band-existing.json`)。新曲と同じ条件にするため、作業フォルダの中だけ `--mode must`(EASY〜HARD)・`keep-climax`(EXPERT・MASTER)で仕上げ直して比べた
- ANiMA・Rebellion は作り直しの自動修正が最後の確かめで止まった(書き出しはできている)。作り直しを選ぶならこの2曲は中身を見てから
