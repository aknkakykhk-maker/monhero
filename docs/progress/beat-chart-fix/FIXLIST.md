## 決まり(全部の行に共通)

- **位置だけ直す**: ノーツの数・時刻・種類・幅は変えない。動かすのは「どのレーンか」だけ。1番(位置)は 0〜6 の横位置(左端=0、右端=6)。
- HELL は作り直さない(位置だけ。空中の高さ・親指の高さも変えない)。Grievous Lady は入れていない(社長が耳で確かめる)。
- 動かす先は、その音の前後 0.15秒に他のノーツがなく、押さえている HOLD・スライドの帯とも重ならない所を、元の位置に近い順に選んだ。**同じ側(左半分・右半分)に置けるときは同じ側**。
- ランキング・自己ベストへの影響: 点数は MARVELOUS などの数だけで決まり、満点の上限も(ノーツ数が変わらない限り)同じ。**位置だけ直す行は、既存の自己ベスト・ランキングはそのまま使える**(取り直しは不要)。
  ノーツ数が変わる行(C の4件)だけは、その難易度の満点の上限が下がる。ランキング送信の形(`mh_*`)は変えない。

## 「押せない速さの同じ所の連打」の数え方(窓口の報告の数と合わない理由)

報告の数え方の道具がリポジトリに見つからなかったため、**この文書では次の決まりで数え直した**(報告の件数とは一致しない。違いは窓口で見てほしい)。
同じ難易度の TAP・FLICK を時刻順に並べ、**続く2つが 90ms 未満で、横位置が 0.5 以内にしか離れていない**(親指が同じ場所で叩き直せない)組。90ms は
`rhythm-chart-hand-rules.js` の「同じ側の押し始めの下限(1秒に約11回)」と同じ。HOLD・スライドの頭は数えていない。
この決まりだと Sparkling Pink Overture HARD は 5(報告 18)、メガロバニア HELL は 23(報告 54)。しきい値を 100ms にすると SPO HARD は 10、120ms にすると SIX ÉTERNEL HARD も出る。
