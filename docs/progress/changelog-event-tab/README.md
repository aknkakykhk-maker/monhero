## 台帳 r1119-113 との突き合わせ

| 台帳の言葉 | どう満たしたか | 確かめ方 |
| --- | --- | --- |
| 上のタブを 更新情報・イベント・不具合情報 の3つにし | `.mh-changelog-tabs` を3列にし、まんなかに「イベント」(60-app.jsx の更新履歴の窓) | event-tab-check ①(5姿勢) |
| 開催中・開催予定の札はイベントタブへ | 札は `changelogTab==='event'` のときだけ出す。無いときは「いま開催中・開催予定のイベントはありません。」 | ③ |
| (開催中が上) | `changelogPinnedEntries`(17-release…jsx)が開催中→開催予定の順に並べる。それぞれの中は新しい順 | ③ |
| 更新情報タブは一番上から更新内容 | 更新情報タブから札を外した。一番上は日付の見出し | ② |
| 新しいイベントがある間はイベントタブに印 | まだ見ていない札があればタブに「!」(ほかのタブと同じ `mh-unread-badge`)。イベントタブを見てから移る・閉じると既読 | ④(開き直しても消えたまま) |
| (保存のキーは増やさない) | 既読は今ある `mh_changelog_seen_ids_update` / `_issue` へ足すだけ。札の項目は更新情報タブを見ただけでは既読にしない | コードの読み合わせ |
| 押しやすい(44px 以上)・切れない | タブの高さを 40→44px。文字は折り返さず切れない | ①(縦・横・568×320・切り欠き縦・切り欠き横) |
