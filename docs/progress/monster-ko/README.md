# 台詞で、複数・一般のモンスターを「子」と呼んでいた所の言い換え(2026-11-07)

決まり: モンスターを「子」と呼ばない。例外は、助手が特定のマスモン1体を指して「この子」と言うときだけ。
直したのは data/assistants.js の台詞だけ(文の意味は変えない・口調はその助手のまま)。

## 触らなかった所
- パンドラとふたつの翼のお話(EP3「……あの子たちは、悪くない」・EP7「……外で、あの子たちが歌ってる」): 開催中のイベント(〜11/9 3:59)の台詞なので触らない決まり。
  見張りの検査は 2026-11-09 04:00 まで見送り、過ぎると NG になる(終わったら言い換える)
- みゅあ「モンビー始めたばっかりの子でも」: 遊ぶ人を指しているので、モンスターの言い方ではない

## 見張り
tools/changelog/monster-ko-check.js に、助手などの台詞で「子たち」「子ら」「〜子ほど」「どの子・ほかの子」を NG にする見張りを足した(特定1体の「この子」「あの子」は通す)。

## 止め絵
マスモン一覧の吹き出し(みゅあ・ドラ)を縦・横・🔄横で開き、出ている台詞を新しい文に差し替えて、折り返しと収まりを見た。
