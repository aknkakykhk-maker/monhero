# 公式杯の入口を HOME に置く案(写真)

2026-10-31 社長「公式の大会はイベント的にするからホームに置く」。まだ入れていない。写真は本物の HOME(390×844)に入口を重ねたもの。大会名・残り時間・ごほうびは仮の文字。

| 写真 | 置く位置 | よいところ | 気になるところ |
| --- | --- | --- | --- |
| 案A.png | 左の列(イベントの並び)。ハロウィン・ナイトの札の下、MFバトルカードの上に金色の札を1枚挟む | いまのイベントの札と同じ形・同じ列なので「イベントが来ている」と読める。町の絵と助手の吹き出しを隠さない | 左の列が4段になる。札が小さいので、ごほうびは短い言葉しか入らない |
| 案B.png | 上の帯。助手の吹き出しのすぐ下に横いっぱい | いちばん目立つ。大会名・残り時間・1位のごほうび・「エントリー」ボタンまで1行で入る | 町の絵(家並み)を横いっぱいに隠す。ほかのイベントも同じ帯を欲しがると取り合いになる |
| 案C.png | 右上の小さな札。更新履歴の下 | 町の絵をほとんど隠さない。ほかの入口の並びを動かさない | 小さくて「イベント」らしさが弱い。ごほうびが入らない |

**おすすめ: 案A。** いまのハロウィン・ナイトの札と同じ列・同じ扱いにすると、「期間のあいだだけ出る札」の決まりがそろう。

## 出すあいだと文字の移り変わり(どの案も同じ)

| 時期 | 札の2行目 |
| --- | --- |
| 受付中 | 受付中 あと◯日◯時間 |
| 開催中(組み合わせ〜試合) | 開催中 ◯回戦 |
| 結果発表(最終日 4:00 〜 少しのあいだ) | 結果発表 優勝 ◯◯ |
| 大会が無いとき | 札を出さない(1段上がる) |

## ほかの入口と重なったときの並び(案A)

左の列は上から モンヒロビート → 全体のイベント(ハロウィンなど) → 公式杯 → MFバトルカード。
全体のイベントが無いときは、公式杯がその段へ上がる(いまの MFバトルカードの札と同じ動き)。入れるときは home-layout-check に公式杯の札を足して、重なりを見張る。

## MFバトルカードの中の入口

**おすすめ: 残す。** HOME の札は期間のあいだだけ出るが、カードの中の入口は、終わった大会の結果・見返しを見に行く道として要る。HOME の札を押したときも、同じ大会の画面を開く。

## 決めてほしいこと

1. 置く位置: 案A / 案B / 案C(おすすめ 案A)
2. MFバトルカードの中の入口を残すか(おすすめ 残す)
3. 第1回の大会名(例:「第1回 MF公式杯」)
4. 受付・開催の期間(受付開始・締め切り・最終日)
5. 結果発表のあと、札を出しておく長さ(例: 発表から24時間)
6. 1位のごほうび(札に出す短い言葉。例:「限定フレーム」)と、2位以下を札に出すか
7. 告知文(更新履歴・助手のお知らせ)と、HOME の札を押したときの最初の画面(エントリー / 組み合わせ / 結果)
