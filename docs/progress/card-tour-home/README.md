## ほかの入口と重なったときの並び(案A)

左の列は上から モンヒロビート → 全体のイベント(ハロウィンなど) → 公式杯 → MFバトルカード。
全体のイベントが無いときは、公式杯がその段へ上がる(いまの MFバトルカードの札と同じ動き)。入れるときは home-layout-check に公式杯の札を足して、重なりを見張る。

## MFバトルカードの中の入口

**おすすめ: 残す。** HOME の札は期間のあいだだけ出るが、カードの中の入口は、終わった大会の結果・見返しを見に行く道として要る。HOME の札を押したときも、同じ大会の画面を開く。

## 決めてほしいこと

1. 置く位置: 案A / 案B / 案C(おすすめ 案A)
2. MFバトルカードの中の入口を残すか(おすすめ 残す)
3. 第1回の大会名(例:「第1回 MF公式杯」)
4. 受付・開催の期間(受付開始・締め切り・最終日)
5. 結果発表のあと、札を出しておく長さ(例: 発表から24時間)
6. 1位のごほうび(札に出す短い言葉。例:「限定フレーム」)と、2位以下を札に出すか
7. 告知文(更新履歴・助手のお知らせ)と、HOME の札を押したときの最初の画面(エントリー / 組み合わせ / 結果)

# 社長の判断(2026-10-31)と、続きの案

決まったこと: HOME の札は **案A**。結果発表のあと **1週間** 出す。押したら **いつも大会のトップ**。ごほうびは **ビートPだけ**(札には1位のビートPの量)。
終わった大会は **プロフィールから見られる** ようにする。その置き場所の案:

| 写真 | 置く位置 | 一言 |
| --- | --- | --- |
| プロフィール_案A.png | 「MFバトルカードの戦績」の区画の中、いちばん下に1行(出場◯回・最高◯位・優勝◯回) | 戦績とひとまとまりで、カードの記録だと分かる。自分の成績がひと目で見える |
| プロフィール_案B.png | 戦績の区画のすぐ下に、「モンヒロビート これまでの記録」と同じ形のボタン | ほかの遊びの「これまでの記録」とそろう。件数が出る |
| プロフィール_一覧の見本.png | 押したあとの一覧(どちらの案も同じ) | 新しい順。大会ごとに、期間・優勝した人・1位のビートP・自分の順位、「結果を見る」「対戦表・見返し」 |

**おすすめ: 案A。** 戦績と同じ区画に入るので、フレンドのプロフィールにも同じ形で出しやすい(出すかどうかは別に決める)。
押した先の「結果を見る」「対戦表・見返し」は、いまの大会の画面(結果・対戦表・見返し)をそのまま開き、戻るとプロフィールへ帰る。
