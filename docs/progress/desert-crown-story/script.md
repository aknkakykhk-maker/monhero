## 生い立ちとのつじつま(登場のお話「砂の向こうから来た人」・人柄のメモどおり)

- 砂漠の白い宮殿にいた → 穴に落ちてモンヒロの世界へ → 帰り方はまだ分からない。この流れは変えない
- 石油王ネタは「いじられ役」のまま。本人は「普通」と言い張る。お話の中でも石油王かどうかははっきりさせない
  (向こうでも「なぜか王様あつかいされていた」とだけ言う。歌詞の「世界が俺を王と呼んでも」につなげる)
- 着いた日に、みんなが会って1分で呼び名をつけた(るびちん・えるニキ・ビンビン…)。これを歌詞の「君の名前が残っている」につなげる
- 年上の穏やかな見守り役。ききの曲のお話では、えるびんがききに「どんな気持ちになってほしい？」と聞いた。今回はききが同じことを聞き返す
- バトルカードの話は入れない。数字(BPM・Lv・長さ)は台詞に書かない

## 「みんなが曲を作っている」とのつじつま

- ききの曲「Sparkling Pink Overture」と、みゅあたちの帳面の歌「Beyond the Same Sky」を見て、自分もやってみたくなった
- 「同じ空の先へ」は、あつに会っていない人には「みゅあの歌と、旗のそばに残されていたあつの字」の話なので、
  このお話では**だれにでも通じる言い方「みゅあちゃんたちの帳面の歌」**にする(あつの名前を出すのはあつ有の行だけ)
- 2つのお話は同じ日に出る。**こちらは「同じ空の先へ」を見たあとに流れる**順にしたい(末尾の決めてほしいこと①)

## あつの出し分け(今のお話の決まりどおり)

- `atsu:'with'` … あつを解放している人だけの行 / `atsu:'without'` … まだ会っていない人だけの行 / 印なし … 両方
- 会っていない人には、あつは出ない。あつの行は、その人にはソラシドかドラの行に差し替える

## 呼び方(CALL_NAMES の表どおり)

- えるびん → みゅあちゃん・ききさん・ももちゃん・ドラちゃん・あっくん・きゅうこちゃん・ソラくん / プレイヤーは `{name}`(呼び方の設定で「◯◯さん」になる)

## 決めてほしいこと(社長)

① 同じ日に出る「同じ空の先へ」との順番
  - **A(推奨)** 「同じ空の先へ」を見たあとに、このお話が流れる(1場面目の「帳面の歌」がつながる)。同じ HOME では続けて流さず、次に HOME に着いたとき
  - B 順番は気にしない(どちらが先でも、台詞は「帳面の歌」とだけ言っているので大きくは崩れない)

② 題
  - **A(推奨)** 「砂の向こうの歌 ～Desert Crown～」
  - B 「王冠はいらない ～Desert Crown～」
  - C 「はじめての歌詞 ～Desert Crown～」

③ 向こうの世界の暮らしの描き方(3場面目)
  - **A(推奨)** 今の文のまま。「白い宮殿・何でもそろっていた・王様あつかい・名前で呼ぶ人が少なかった」まで。石油王かどうかはぼかす
  - B もっとぼかす。「何でもそろっていた」「王様あつかい」を外し、景色と「胸の奥が空いていた」だけにする

④ 帰るかどうか(6場面目)
  - **A(推奨)** 今の文のまま「帰り方は、まだ分からないけど……今は、みんなと選んだこの道を行きたい」(決めきらない、やわらかい言い方)
  - B もっとはっきり「分かっても、ここを選ぶ」
  - C 帰る話には触れない(ききの問いかけの2行を外す)
