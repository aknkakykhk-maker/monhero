## 3. 新しく出た問題・まだ残る問題(重い順)

### 高

**1. スマホで「助手どうしの会話」の窓が出ない**
- 絵: `t2-1128-1005-phone-tate-peer`、`t2-1128-1005-phone-yoko-peer`
- 確かめたこと: どちらの絵も fold と同じで、会話の窓がありません。スマホの顔には💬が1度も付かず、いつも赤い点だけです(スマホの絵8枚すべて)。
- 見込み: 原因は次のどれかです。スマホでは会話が待っていなかった、撮る前に窓が出きっていなかった、スマホでは窓が出ない作りになっている。いちばん多い遊び方(スマホ)で、この楽しみに入れないおそれがあります。

**2. 入口の赤い点が「新しいお知らせ」に見える**
- 絵: `t1-1127-1907-phone-tate-fold` ほか全部
- 確かめたこと: ☰の数字と同じ赤い色です。t1 のスマホ縦では、入口5か所(バトル・ビート・MF・M/B管理・助手ライフ)に付いています。同じ t1 でも、絵ごとに場所がちがいます。phone-yoko はビート・MF・助手ライフ、tablet-yoko は M/B管理・助手ライフです。
- 見込み: 子どもは「何かもらえる」と思って押し、何もなくてがっかりします。点の場所が毎回変わるので、「見なくていい印」だと覚えてしまい、本当のお知らせも見なくなるおそれがあります。

### 中

**3. 会話の窓が顔から遠く、入口の札にかぶる**
- 絵: `t2-1128-1005-tablet-yoko-peer`
- 確かめたこと: 押す顔は左上(x≈110, y≈205)ですが、窓は下のまん中(x≈367〜813, y≈627〜731)に出ます。ビートとMFバトルカードの札の上半分と「開催中」の札がかくれ、バトルの札の右はしにもかかります。
- 「押した物」と「開いた物」がつながって見えません。

**4. ☰の数字が、中の数と合って見えない・大きさで数がちがう**
- 絵: `t2-…-phone-tate-menu`(8 = 1+6+!)、`t2-…-tablet-yoko-menu`(9 = 2+6+!)、`t2-…-tablet-tate-fold`(8)と `t2-…-tablet-yoko-fold`(9)
- 確かめたこと: 「!」がいくつ分なのか、見ても分かりません。同じ時刻なのに、タブレット横だけ数が多いです。
- 見込み: 大きさごとに遊んだ状態がちがっていたのかもしれません。💬が付いている絵と「9」の絵が同じなのも気になります。

**5. ボスがHPの札より右にずれている**
- 絵: `t2-1128-1005-phone-tate-fold`、`t2-1128-1005-tablet-yoko-fold`、t3 の絵ほか
- 確かめたこと: スマホ縦はボスが x≈200〜310、HPの札が x≈110〜280 です。タブレット横はボスが x≈588〜710、札が x≈495〜685 です。どれもボスの左はしが、ちょうど画面のまん中にあります。
- 見込み: ボスの「左はし」をまん中に合わせていて、「ボスのまん中」を合わせていないのかもしれません。

**6. 共有HPの字がとても小さい**
- 絵: t2・t3 の全部
- 確かめたこと: 「共有HP 8,750,000」は約7〜8px、題の「黒いサンタ・鈴があらわれた！」は約10pxです。札の大きさ(約170〜190×40px)はタブレットでも同じで、大きな画面では豆つぶのように見えます。
- 見込み: t3 でも 8,750,000 のまま変わっていないのは、ためしのデータだからかもしれません。本番でも数が動かないと、「みんなで減らしている」感じが出ません。

**7. t1 では「今遊べるイベント」が2枚目にかくれている**

**8. 💬の印が見えにくい**

## 4. すぐ直せる小さな直し(効き目の大きい順)

1. **入口の「助手がいる」印を、赤い点から助手の小さな顔に変える。** 赤い色は「お知らせ(数・!)」だけに使います。これで入口の赤い点が消え、本当のお知らせが目立ちます。
2. **スマホでも顔に💬を出し、会話の窓は吹き出しと同じ「顔のとなり」に出す。** 💬は白い丸に色をつけて、約20px以上にします。入口の札にもかぶらなくなります。
3. **ボスの「まん中」をHPの札の「まん中」に合わせ、HPの字を大きくする。** 目安は「共有HP」と数字で約12px以上、数字は太字です。タブレットでは札も大きくします。
4. **☰の数を「見て足せる」形にする。** 更新履歴は「!」をやめて数(例: 1)にするか、☰の数には入れずに中の赤い点だけにします。あわせて、大きさがちがっても同じ数になっているかを確かめます。
5. **帯の並び順を「今遊べる物が1枚目」にする。** t1 のような「予告だけ」の時期は、開催中の花のイベントを1枚目にして、クリスマスの予告を2枚目にします。
