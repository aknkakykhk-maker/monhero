## 2. 筋と山場

**{name}はどちらの話にも出てこない(助手たちの側の話)。** モンサクを開くと、中の始まりの話「みゅあがチラシを手に走ってきた」「助手の一番乗り、手あげてきちゃったｗ」「ももやドラケンたちは準備中」へそのままつながる。

### 第1話 ～一番乗りは、だれだ～(HOME → 広場)

1. **冒頭(つかみ)**: 暗がりから育成場の会場。演出の字だけで「とある町に、新しい育成場ができた。デビューを夢見るモンスターたちが、今日も駆けている」→ 広場へ切りかわる
2. きゅうこが町の掲示板のチラシを持ってくる。「モンヒロサクセス、オープン」「助手もいっしょに育成場へ」→ みんな大さわぎ
3. 「いまはβ版。助手はまずおひとりから」→ だれが行くかで言い合い
4. 順番に準備を言う(ドラ=膝・きき=帳面・ソラシド=表・もも=お洋服・きゅうこ=編成の作戦・えるびん=お弁当・あつ=大会の下見)
5. **山場**: 夕方。準備がいらないのは、みゅあだけ。「わかんないことは、{name}といっしょに覚えればいいぢゃん！」→ 一番乗りが決まる。「育成場に、手あげに行ってくる！」
6. 終わりの札 →「次のお話 第2話」

### 第2話 ～ヒーローへの道～(育成場の町 → 住む場所 → 会場 → 闘技場)

みゅあが育成場へ「助手の一番乗り」を名乗りに行く。付きそいはドラ(膝の準備運動をかねて)ともも(お洋服の下見)。

1. **育成場の町の門**: 大きな看板。「ここがモンヒロサクセス……！」
2. **住む場所**(赤い屋根の家・大きな木・広場): 「育成のあいだ、モンスターとここで暮らすんだって」
3. **トレーニングの場**: 坂道を駆け上がるモンスター、滝に打たれるモンスター。みゅあ「みんな、デビューを目指してるんだ……」/ドラ「トレーニングごとに、やることがぜんぜんちがうな」
4. **デビュー戦の会場**: 木の観客席とテント。「最初の大会はここ。どの子も、まずはここから」
5. **山場 = 闘技場**: 大きな闘技場のまんなかに立つ。上のほうに、ヒーローの頂を示す紋(金の縁どり)。みゅあ「デビューから、あそこまで……{name}とあたしで、ぜったい行く」/ドラ「ヒーローへの道、か。いい名前だ」/もも「みゅあねぇ、ちょっとかっこいい……けど、すぐ追いつくから♡」
6. 受付で「助手の一番乗り、みゅあです！」→ チラシに一番乗りの印 →「{name}に知らせなきゃ！」と駆けだす
7. 終わりの札(下の4)
