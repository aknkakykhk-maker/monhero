# 本編のお話「モンヒロサクセス」全2話 台詞の全文(2026-11-14 ココロ)

構成(structure.md)は社長 OK・題は A(窓口経由)。題字ロゴと育成場の町の門の絵は社長が用意する。届くまでは
代わりの絵(金色の字の題字・`venue-debut`)で作り、届いたら差し替える。

書き方: assistants.js の台本と同じ形(`{who, e, t}`)。`bg` は背景の名前(入れるときに `STORY_SCENE_IMAGES` へ足す)、
`bgm` はその行から替える曲、`fxText` は画面の真ん中に出る場面の説明(話し手の行に乗せる。地の文だけの行は無い仕組み)。
`atsu:'with'` はあつを解放した人にだけ出す行(抜けても話がつながるように書いてある)。`{name}` は話している助手のいまの呼び方。
