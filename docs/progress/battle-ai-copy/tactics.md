# AIコピー(5人目)— タクティクスで「4人」「全員倒れたら」を前提にしている所(洗い出し)

バトル部セコンドくん・2026-10-27。ソラシドのアシカ「自動化 → 全自動 → 無人運転」で出る AIコピーの、タクティクス側の受け持ち
(①置き場所 ②ヘイトの初め ③狙い ④ターンの順番 ⑤倒れたら消す・4人まで/全滅の決まりから外す)。**まだ作っていない。**

## まず決めてほしいこと(作り始める前)

1. **コピーの間合い**: 4つの枠は、そのまま敵との間合い(0=零・1=近・2=中・3=遠)。枠の番号=間合いとして、
   距離の倍率・間合い攻撃の狙い(`tacticsIntentTargets` の sweep)・適性に使っている。**5つ目の間合いは無い**。
   - 案A(推奨): コピーは元の子と**同じ間合い**に立つ(絵は元の枠の隣=枠の右上などに小さく重ねる)。距離の倍率・間合い攻撃は元の子と同じ扱い
   - 案B: 元の子の隣の間合いの枠へ置く → その枠に別の子がいると重なるので不可(4人いると置けない)
2. **コピーを盤面の配列(4枠)に入れない**(推奨)。下の「4枠の並び」は全部、長さ4・番号=間合いで、ライフの合計・全滅・ヘイト・狙いの%・記録が
   それに乗っている。5つ目を足すと全部に手が入り、「全員倒れたら負け」「倒れた数」にもコピーが混ざる。
   → コピーは別の入れ物 `tacticsCopy`(元の枠・ライフ・ガッツ・手札・残りターン・ヘイト)で持ち、**狙いの抽選とヘイトだけ**にもう1人として足す
