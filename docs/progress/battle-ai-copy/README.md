# ソラシドのアシカ「AIコピー(5人目)」 バトル部の受け持ち

2026-10-27 社長の決め(窓口から)。キュービ・オリヒメと同じ日に公開。それまでは RELEASE_FLAGS.assistantSorashido(偽)の裏に置き、ふだんの遊びに出さない。
MFバトルカードには入れない。保存データは増やさない。

## 効果(社長の決め)

- 使った子の「AIコピー」が、次のターンから5人目の味方として戦う。続くターンは Lv1=2・Lv2=3・Lv3=4
- 強さ: 元の子のライフ50%・ちから60%・丈夫さ50%・ガッツ60%(Lv2 +10%・Lv3 +20%)
- コピーの固有技が山札にいつも1枚増える。コピーが消えたら抜く
- コピーは自分の手札とガッツを持ち、毎ターン1枚(プレイヤーのカードのあと、AUTO の見方で。うまさ 50→65→80%。距離技とこのアシカは選ばない。固有技・ほかのアシカは使える)
- もう一度使うと: 同じ子なら続くターンが最初に戻る/別の子ならそちらに切りかわる
- 敵に狙われる。倒されたらその場で消える。負けの判定・倒れた味方の数には入れない
- 手札と「次に使うカード」はプレイヤーが見られる
- 5つの遊び: 4人の横に5人目の枠(縦は列の右はし・横向きは列の下)/タクティクス: 元の子のとなりの空いたマス・ヘイトは元の子の🔥の半分から

## 約束

- 境目: アシカの効果が `summonAiCopy(slotIdx, level)` を呼ぶ。コピーの状態・枠・狙い・ヘイト・倒れ・手札とガッツ・選んだ1枚を使う所はバトル部
- 状態(保存しない): `aiCopy = { srcSlot, srcMonsterId, level, spawnTurn, turnsLeft, hp, maxHp, atk, def, guts, maxGuts, hand, nextCard, uniqueCardUid, pos? }`(pos はタクティクスだけ)
- 印: `RELEASE_FLAGS.assistantSorashido` を見るたびに引く(読み込み時の値を取っておかない)
- 関数の名前・受け渡しは、ドライバーくんとセコンドくん・ダイスくんで決める
