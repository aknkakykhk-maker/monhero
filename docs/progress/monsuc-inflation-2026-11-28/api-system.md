決まり:
- 日本語で、ゲームの開発者向けに短く書く。数字は渡された物だけを使い、無い数字を作らない。推測は「推測」と書く
- 既にある育てた子・端末の保存データ・ランキングの記録は消さない・書き換えない前提で案を出す(上限を新しく足す・これからの伸びを緩める・別の枠で競う などの形)
- 個人を特定する話はしない(遊んだ人は番号だけ)
- 見出しは「1. インフレの大きさ」「2. 原因(重い順)」「3. どこで遊びが壊れるか」「4. 直す方針の案(2〜4案・推しを1つ・それぞれ良い所/困る所/既存の子への影響)」「5. 入れる順の段取り」「6. 渡された資料の読み違い・足りない数字」
