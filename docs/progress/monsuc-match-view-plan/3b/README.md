## 確かめてほしい所(社長)

- **助手対戦βの場の高さ**: モンサクと同じ「下のボタン列まで1画面に収める」決まり(場は 420px から 260px までで縮む)になった。
  - 観戦(オート)は今と同じ 420px のまま1画面に入る
  - **手動の番は、操作の帯(交代の段がある分だけ高い)まで1画面に入れるため、場が約 270px になる**(今は 420px で、操作の帯は下へ送って見る)。`ambb-manual-390.png`
  - 今のように場を大きいまま下へ送る形がよければ、βだけ縮めない形にもできる
- 幅320 の手動は、モンサクと同じく場面(体力の帯・場・実況)を上に留めたまま操作の帯を送る。`ambb-manual-320.png`
- 横の低い画面は、モンサクの試合と同じ「自分の技と操作(左)/場(まん中)/相手の技(右)」。`ambb-manual-land.png`
