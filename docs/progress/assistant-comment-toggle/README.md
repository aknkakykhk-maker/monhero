## ② 案(どれも HOME の「隠す」と同じ考え方: 今の値を使う・切っても1押しで戻せる)

### 案A(おすすめ)「どの画面も HOME と同じ『隠す』」 ― 止め絵 `plan-a-tate.png` / `plan-a-yoko.png`
- 画面ごとのひとこと(❹)の顔の下に小さな「隠す」。押すと設定「助手のひとこと」が「出さない」になり、**全部の画面**で隠れる。
  隠したあとは顔の丸いボタン+💬だけ残り、押すと「いつも」に戻る(HOME の切と同じ形)
- ミッションの1日1行(❷)も、この3択に従うようにする(今は文を直接渡すので効かない)
- 掛け合い(❶)の札に「隠す」。設定にも「助手どうしの掛け合い 入/切」を足す
- 保存: ❹❷は今の `mh_assistant_bubble_mode_v1` をそのまま使う(値の意味は変えない)。❶だけ**新しいキーが1つ要る**(`mh_assistant_peer_show_v1` = 入/切。無い・壊れていれば「入」)
- よい所: HOME とそろう・どの画面でも1押しで消せる / 気になる所: 1か所で隠すと全部の画面で隠れる(設定の3択と同じ値のため)

### 案B「画面ごとにたたむ」 ― 止め絵 `plan-b-tate.png` / `plan-b-yoko.png`
- 今マーケット・神殿・編成だけにある右上の「▴(たたむ)」を、**全部の画面のひとこと**に広げる。たたむと小さな顔+「💬 ○○のひとこと ▾」。**画面ごとに覚える**
- ミッションの1日1行も同じ「▴」
- 掛け合いの札に「今日は出さない」(明日の朝4:00から戻る)
- 保存: 今の `mh_bubble_collapsed_v1` に画面の名前を足すだけ(新しいキーは要らない)。掛け合いの「今日は出さない」だけ**新しいキーが1つ要る**(`mh_assistant_peer_rest_v1` = その日の日付)
- よい所: 見たい画面だけ残せる / 気になる所: 消えるのではなく「たたむ」(札が1行残る)。HOME の形とは少し違う

### 案C「設定に1か所まとめる」 ― 止め絵 `plan-c-tate.png` / `plan-c-yoko.png`
- 画面には何も足さない。設定の「ホームの助手コメント」の下に「助手どうしの掛け合い」「ミッションの1日1行」の入/切を足す
- 保存: 掛け合い・1日1行で**新しいキーが2つ要る**(`mh_assistant_peer_show_v1`・`mh_mission_daily_line_show_v1`)
- よい所: 画面がいちばん変わらない / 気になる所: 画面の上で消せない(社長の「必要箇所に」から遠い)

### どの案でも足す(ビート部の画面なので案だけ・選ばれたら窓口経由でビート部へ)
- ❸ モンヒロビートの部屋: 部屋の設定に「呼んだ助手・マスモンの吹き出し 入/切」を足す。チャットの欄には残し、メンバー札の上の吹き出しだけ出さない。
  保存は今の `mh_rhythm_settings_v1` に項目を1つ足す(新しいキーは要らない)

## ③ 実装: 「💬▲▼を全画面に」(台帳 r1119-135・社長の選択)

モンヒロビートの曲えらびの「💬▲/▼」と同じ形のボタンを、助手のひとことが出る画面に付けた。

- **画面ごとのひとこと(❹)**: 吹き出しの右に「💬▲」。押すと畳んで「💬▼」だけ残る(押すと開く)。部品は `21-assistant.jsx` の `BubbleFoldButton`。
  画面の名前は場面から決める(`assistantBubbleFoldKey`)。同じ画面で場面が変わるもの(ミッション・ギフト・バトルのモード/難易度・結果・勇者/供モンを選ぶ・強化)は1つの名前にまとめた
- **ミッションの1日1行(❷)**: ミッションの画面のひとことと同じ名前(`screen:missions`)。どちらで畳んでも同じ
- **助手どうしの掛け合い(❶)**: 札の下の「閉じる」の左に「💬▲」。畳むと画面の右下に「💬▼」だけ出る(押すと続きから読める)。画面ごとに覚える(`peer:<画面>`)。見返しは畳まない
- **今の「▴」の画面**(マーケット・神殿・編成・カード売り場): 同じ名前のまま「💬▲▼」に替えた(覚えている値はそのまま)。
  **ヘルプ**: 見出しの右の「たたむ ▲ / 💬 ひとこと」を「💬▲ / 💬▼」の形に替えた(覚える名前 `help` はそのまま)
- **変えていない所**: HOME(「隠す」r1119-081)・設定「助手のひとこと」の3択(先に効く。「出さない」なら畳む前に隠れる)・はじめての案内/一度きりの案内・
  モンヒロビートの曲えらび(元から💬▲▼がある)・ビートの部屋のメンバー札(❸。ビート部へ回す)
- **保存**: 今の `mh_bubble_collapsed_v1`(畳んだ画面の名前だけを `true` で入れる)に `screen:<画面>` と `peer:<画面>` を足すだけ。新しいキーは作っていない。
  無い・壊れていれば今の見た目(開いている)。既存の名前(`market:*`・`temple *`・`roster *`・`help`)の意味は変えていない

止め絵(前 = main / 後 = 開いている / 後 = 💬▼ で畳んだ)は `node tools/assistant/bubble-fold-all-shoot.js` で撮った:
`fold-mb-dex-{tate,yoko}.png`・`fold-mission-{tate,yoko}.png`・`fold-market-{tate,yoko}.png`・`fold-settings-{tate,yoko}.png`。
掛け合いの札は出るかどうかが毎回の抽選なので止め絵に入れていない(動きは検査 `tools/assistant/bubble-fold-all-check.js` で見る範囲の外。窓口で実機を見てほしい所)。

検査: `node tools/assistant/bubble-fold-all-check.js`(HOME は変わらない・畳む/覚える/開く・3択が先に効く・ほかの mh_* は変わらない・場面のまとめ・壊れた値)
