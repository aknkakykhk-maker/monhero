# 裏クイックを、ゲームのどこにいても回す(方針)

2026-11-11 ビート部テンポ。社長の決めごと台帳 1094 行「クイックの裏周回を、ゲームを開いたら自動で始まり、どの画面でも裏で回る形にする。M/B管理と神殿では休む」。11/12 20時までのフル稼働の許可の中で進める。

## いまの作り(下調べ)

- 裏クイックは専用の部品ではなく、**ふつうのクイック∞周回(本物のバトル)を、画面を描かずに進めている**もの。
  段階は `runStage`(画面 gameState とは別)、進めてよいかは `runProgressAllowed`。
- 回してよい画面は `isBackgroundRunScreen`(60-app.jsx:22)と、`rhythmBackgroundRun` / `cardBackgroundRun` / `assistantLifeBackgroundRun`(60:4946〜)の3つで、
  モンヒロビート(演奏中を除く)・カード・助手ライフ(HOME/PROFILE/ITEM_INVENTORY の上)だけ。それ以外の画面では黙って止まる。
- `returnToHome` が `stopAllAuto` + `clearRunStage` を通るので、**HOME へ戻るとふつうは周回が終わる**。
- 自動で始める処理は3か所(ビート・カード・助手ライフに入った瞬間)、負けたら4秒後に始め直す処理も3か所。
- 「揺らさない・暗幕を出さない・負けの全面を出さない・効果音0・お祝いを貯める」は、画面ごとに
  `!rhythmScreenOpen&&!cardScreenOpen&&!assistantLifeScreenOpen` を並べて作ってある。
- 「動いているバトルは常に1つ」(QUICK_RHYTHM_LINK.md §13)。チャレンジ・プロ・種族・レイドなどを始めると、ランは作り直される。

## 方針

1. **判定を1つにまとめる**: 「いまバトル画面を見ていない」= `gameState !== runStage` を1つの値(`runOffscreen`)にし、
   画面ごとに並べた条件をこれに置き換える。新しい画面ができても揺れ・幕・音が出ない。
2. **休む画面**: M/B管理系と神殿系(BGM_STATE_MAP の 'management' / 'temple' の画面)では**進めないだけ**(止める=締めるではない)。
   出たら続きから。一覧の漏れ事故を防ぐため、BGM_STATE_MAP から作る。休む画面に入る瞬間、配っている途中の報酬(resultProcessing)が終わるのを待つ。
   演奏中(RHYTHM_PLAY)は今までどおり進めない(追いつきで後から入る)。
3. **HOME で終わらせない**: `returnToHome` を「ランを締めて HOME へ(今までの意味)」と「HOME を見るだけ」に分ける。
   ふつうに HOME へ戻るときは後者。裏クイックは回り続ける。
4. **ほかのバトルを始めるとき**: 裏クイックを**締めてから**(その周までの報酬を確定させて)新しいランを作る。いまの「常に1つ」の作りのまま。
   チャレンジ・プロなどが終わったら、裏クイックは自動で始め直す(AUTO設定の自動開始が入の人だけ)。
5. **自動で始める**: 起動時(AUTO設定・クリア記録・マスモンを読み込み終えてから)の1か所にまとめる。条件はいまと同じ
   (AUTO設定のクイックがそろっていて、自動開始が入、その難易度をクリア済み)。負けたら4秒後に始め直す処理も1か所に。
6. **帯**: どの画面からも見える共通の小さな帯を1つ(画面を揺らさない・高さを取らない)。いまの帯(ビート・カード・助手ライフ・バトル)はそのまま。
7. **保存・記録**: 新しい保存キーは作らない。報酬・クリア回数・周回数は今の関数(1ランに一度だけの錠つき)のまま。ランキングには送らない(今までどおり)。

## 決めてほしいこと(統括・社長へ)

- A. HOME に戻っても回り続けてよいか(社長の「どこにいても」はこの意味と読んだ)。
- B. ほかのバトル(チャレンジ・プロなど)を始めたら、裏クイックは**締めて報酬を確定**、終わったら**自動で始め直す**、でよいか
  (同時に2つ動かすのは「常に1つ」の作りを壊すのでやらない)。
- C. 休む画面は M/B管理系・神殿系に加えて、演奏中(RHYTHM_PLAY)・トレーニングの盤・ほかのバトルの最中。ほかに休ませたい画面があるか。

## 進め方

区切り1: 判定のまとめ(1)と見た目の条件の置き換え。今と同じ画面だけで回る状態で、検査がすべて通ることを確かめる(振る舞いは変えない)。
区切り2: 休む画面・HOME で終わらせない・ほかのバトルの前に締める・自動で始める1か所化。
区切り3: 共通の帯・ヘルプ・助手の案内・更新履歴の案と止め絵 → 社長の「この文で」 → ミハリ → 公開。
