## 2. 整理の案

1. **いちばん上に「よく使う」**(たたまない): 新モンスター確認 / 染色マスク編集 / MFバトルカード / モンヒロビート デバッグ / データを用意する / デバッグ戦
2. **名前で絞り込む欄**(上に1つ)。打った字を含む項目だけ残し、まとまりは自動で開く
3. まとまり(見出し＋短い説明・ふだんはたたむ。開いた状態は新しいキー `mh_debug_menu_open_v1` に覚える):
   - 🧬 モンスター(新モンスター確認・育成マーク)
   - 🖌️ 染色・絵(染色マスク・模様・プロフィールの見た目)
   - 🃏 MFバトルカード
   - 🎵 モンヒロビート(デバッグ・体験版)
   - 📖 お話・イベント(全ストーリー・イベントの再生)
   - ⚔️ バトル(モード・すべて解放・デバッグ戦・種族チャレンジ・RPG試作・チュートリアルと旧画面)
   - 💬 助手(会話・表情・親密度・通知・ワンポイント・おしゃべり・吹き出し) ※「みゅあデバッグ」を改名
   - 💾 保存データ(データを用意する・修行テスト・事前ダウンロード・初回状態へ戻す)
   - 🌐 ランキング・通信(ジャック確認)
   - 📐 表示の確認(性能計測・画面エラー・行動カードの絵)
   - 🧪 確認待ちの試作(7件) … たたんでいちばん下へ(件数と「NEW」は見出しに出す)
4. 見た目はほかの設定画面にそろえる(見出し・行の高さ・色)。書き換える物には「保存」の札を全部そろえて付ける
5. 320×568・390×844・横向きで、切れ・折れ・はみ出しを確かめる
