## あつの出し分け(今のお話の決まりどおり)

- `atsu:'with'` … あつを解放している人(または個人杯のお話であつに会った人)だけの行 / `atsu:'without'` … まだ会っていない人だけの行 / 印なし … 両方
- **会っていない人には、あつは一度も出ない**(顔の列にも出ない)。帳面を W.o.F の旗のそばに置いておくと、次の朝、あつの字で続きが書かれていた ―― という流れにする。
  あつの加入のお話(「旗が見えたから」「アシカからずっと見てたよ」「見てたなら、もっと早く顔出してよ」)の前ぶれになり、食い違わない
- 加入のお話より前に見た人が、あとで加入のお話を見ても矛盾しない(加入のお話の中でこの歌には触れていない)
