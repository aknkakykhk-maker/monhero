## 1. 区切りの時刻(日本時間)

| 時間帯 | 時刻 | 色 |
| --- | --- | --- |
| 朝 | 5:00〜9:59 | 少し青白い(上が淡い水色・下がほんのり暖色) |
| 昼 | 10:00〜15:59 | 今のまま(何も重ねない) |

## 2. 画面の一覧

背景に1枚絵を使っている画面と、絵のない画面に分けて調べた。

| 画面 | 背景 | 案 |
| --- | --- | --- |
| HOME(村の広場) | 絵(ホーム画面アレンジの絵) | **重ねる**(いちばんの対象。止め絵のとおり) |
| タイトル | 絵(ロゴが絵に描き込み) | 重ねる(夜は少し控えめ)/ または対象外 |
| お話(イベントストーリー) | 絵(場面ごとに朝・夕・夜の絵が別にある) | **重ねない**(絵がもう時間帯を持っている。二重になる) |
| モンヒロビート演奏中の後ろの絵(曲のジャケット) | 絵 | **重ねない**(道・ノーツの見やすさと、演奏中の重さを守る) |
| モンヒロビートのリザルト | ジャケットをぼかして薄く | 重ねない(ほとんど見えない) |
| カードバトルの場(全体カードがあるときだけ) | カードの絵をぼかしたもの | 重ねない(遊ぶ表示に近い) |
| マーケット・神殿・メニュー画面 | 絵なし(色の塗り) | 案A: 何もしない / 案B: 塗りの色をほんの少し時間帯に寄せる |
| モードえらび・曲えらび・バトルの入口 | 絵なし(グラデーション) | 同上 |
| バトル中(照明のグラデーション) | 絵なし | 何もしない(遊ぶ画面) |

## 3. 作り方

- いまの時間帯を返す関数を1つ(例 `timeOfDayAt(now)`)。1分ごとに見直し、変わったら `<html data-mh-tod="night">` のように印を付け替える
- 色は CSS の層だけ(背景の絵の要素の `::after` に半透明の色、夜は `::before` に星と灯り)。混ぜ方(blend)やぼかしは使わない → 古い端末でも重くならない
- 色の層は背景の絵の要素の中にあるので、ボタン・文字・カード・ノーツには乗らない。「🔄 横」で回しても絵と一緒に回る
- 切り替えは 2.4 秒かけてふわっと(端末の「動きを減らす」ではすぐ)
- 設定に「時間帯で雰囲気を変える(入/切)」。既定は入。保存は新しいキー `mh_time_of_day_v1`
- 助手ライフの家も同じ関数と同じ色の値を使う(ナカヨシ5とすり合わせ)

## 5. いまの時刻の表示(社長「ゲーム内にリアルタイム時間の表示も欲しいね。全ページはじゃまになるかもだから置けそうなとこに」)

止め絵は上の3枚に入れた(HOME の右上、「更新履歴」の下。横・🔄横では「更新履歴」の左)。

- 形: 小さな札に「時間帯の印＋時:分」。朝 🌅・昼 ☀️・夕 🌇・夜 🌙(例「🌙 21:34」)。押せない(下の操作を邪魔しない)
- 時刻はいつも日本時間(端末の時刻の設定がずれていても、ゲームの1日の区切りと同じ扱いで日本時間に直して出す)。1分ごとに書き換える
