## 案ごとの違い

| 案 | 一言 | 良い所 | 気になる所 |
| --- | --- | --- | --- |
| **A タブで分ける**(推奨) | 名刺は上に固定、下を「わたし・記録・助手・思い出」の4つのタブに。回想は「思い出」タブの中でジャンルの札を切り替え | 1画面に収まり、探す物の場所がタブ名で分かる。横は左に名刺、右にタブで空きが出ない | タブを押さないと記録や助手が見えない。開いたときのタブは毎回「わたし」(覚えさせるなら新しいキーが要る・下の表) |
| B 名刺＋扉 | 名刺を大きく、称号と「いちばんの記録」3つを並べ、下は6枚の扉(記録・助手・思い出・見た目・フレンド・アイテム)。押すとそれぞれの画面へ | 最初の画面がいちばん短く、名刺らしい。思い出はジャンルの扉4枚→中身で、ジャンルごとに見せ方を一番変えやすい | 何をするにも1押し増える。画面(ページ)が増えるので作る量が最も多い |
| C 1列のまま整理 | 今の1列を並べ替え、上に「名刺・思い出・記録・助手・持ちもの」のしおり(押すとそこへ飛ぶ)。回想は3番目に上げ、ジャンルの札4枚を置く | いまの手触りを残せて、作る量が一番少ない。回想が上がるので見つけやすい | 長い1列は変わらない(縦で約3画面)。横は2列になるが、しおりの分だけ縦が狭い |

3案とも共通:
- 名刺に称号の行(持っている称号があるときだけ)とひとことを入れる。性別は「わたし/見た目」の中へ
- はじめての人の「初めての設定」はいまのまま上に出す
- 回想のお話の一覧(押した後の画面)は、いまの「？？？(まだ見ていない)」の伏せ方と再生の仕組みをそのまま使う

## 保存データ・ランキング

| 項目 | 触るか | 内容 |
| --- | --- | --- |
| 既存の `mh_*`(名前・アイコン・フレーム・記録・仲良し度・回想を見た印 ほか) | 読むだけ | 名前も意味も変えない |
| ジャンル | 保存しない | 回想の各話に「どのジャンルか」をゲームの中の表として足すだけ(data/assistants.js の group から決める) |
| 開いていたタブ(案A)・扉(案B) | 保存しない(推奨) | 覚えさせたいときだけ新しいキー(例 `mh_profile_tab_v1`)を足す。既存キーは使わない |
| 案Bの「さいきん見たお話」 | 入れるなら新しいキー | 最後に見たお話の id を新しいキーに足す。要らなければ外す |
| ランキング・Supabase | 触らない | 送る中身も読む中身も今のまま |
