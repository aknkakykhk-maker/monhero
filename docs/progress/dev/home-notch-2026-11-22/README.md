# HOME まわり10場面の切り欠き点検(r1119-080 のやり直し・2026-11-22)

r1119-080(#7125〜#7162)の直しは、iPhone の切り欠きを入れて撮る決まりの前に終わっていた。HOME まわり10場面を、
切り欠きあり(縦 上47・下34 / 横 左右47・下21)で縦・横に撮り直し、押す物が切り欠きに入るかを測った
(`node tools/browser/visual-compare-check.js --head-only --only <場面> --sizes tate,yoko`。撮り比べの場面の一覧 `compare-scenes.js` にこの10場面を足した)。

- 縦: 10場面とも、切り欠き(上47・下34)に入る押す物は 0 件
- 横: 直す前は 6場面で 30 件(左右の切り欠きに 7〜45px 入っていた)→ 直したあとは 0 件
- 今の並べ方は変えていない。左右の余白に切り欠きの分を足しただけ(縦・PC・🔄横は余白 0 なので変わらない)
