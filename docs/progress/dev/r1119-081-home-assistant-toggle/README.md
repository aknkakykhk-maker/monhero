## 突き合わせ表

| 決めごと(窓口の依頼・台帳) | どこで満たすか | 結果 |
| --- | --- | --- |
| HOME の上でも出し入れできる | 入: 顔の下の「隠す」/ 切: 助手の顔の丸ボタン(💬の印つき)。3つの大きさの「入」「切」の絵 | 満たす(押して切→押して入に戻ることを3つの大きさで確かめた) |
| 設定と同じ値を使う・新しい保存キーを作らない(CLAUDE.md ⑦) | どちらも `HOME_ASSISTANT_COMMENT_STORE.setOn`(既存キー `mh_home_assistant_comment_v1`)。設定画面も同じ入れ物を見ている | 満たす(隠すと保存値が false になるのを確かめた) |
| 切のときも 1押しで出せる小さな押し所(押す所 44px) | 切の絵の左上の顔ボタン。測った大きさ 48×48px(「隠す」は 48×44px) | 満たす |
| 今の並べ方のまま | 吹き出しの位置・大きさは今と同じ。施設・右の丸ボタン・期間の帯は動かない | 満たす |
| HOME の助手コメントの押し所1つ(r1119-050)を壊さない | 吹き出しを押すとメニュー(💬 おしゃべり・📖 詳しく見る)は今のまま。「隠す」は吹き出しの外 | 満たす |
