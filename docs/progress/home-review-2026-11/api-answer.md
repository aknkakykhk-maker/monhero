## 3. 観点ごとの指摘

### ① 何が一番大事か一目で分かるか

- **【高】入口8枚が全部同じ大きさで、主と支えの差がありません。**

- **【中】ボスは中央でよく目立ちます(t2 tablet-tate-say)。**
  - ただし押せるのかどうかが見た目から分かりません。

  - 花の帯はまったく見えません。

## 4. すぐできる小さな直し(効き目の大きい順)

1. **会話窓を自動で開かない。** みゅあの顔丸に💬の印だけ出し、押したら開く。→ 入口・帯・ボスが隠れる問題がまとめて消えます。
2. **開くときは、窓の下端を入口の上端より8px 上に。横向きは右寄せで帯を避ける。** → 重なりが0になります。
3. **吹き出しは畳んだ状態(nosay)を初期にする。** 新しい一言があるときだけ💬に点を付けます。→ 上部が約70px 空きます。
4. **札を「左上・高さ18px・1種類の形」にそろえ、顔丸は右上に移す。** → ビートの札が隠れなくなります。
5. **入口の顔丸は1つ+「+n」までにする。** → 札とぶつからず、散らかりも減ります。
6. **phone-tate では支えの4つ(2段目)を高さ約80px に縮め、主の4つとの差を付ける。** → 毎日の遊び場がひと目で分かります。
7. **更新履歴は設定の中へ移して赤印も設定に付け、時計は外す。** → 右の列がミッション・ギフトの2つになります。
8. **横向きでも花の帯をクリスマス帯の下にそろえ、ボスの頭から外す。** → 縦と横で帯の場所が同じになります。
9. **いちばん小さい文字を11px にする(Lv・XP・丸の文字・共有HP・入口の小見出し)。** → 小学生も読めます。
10. **仲良し度の知らせを1枚の「仲良し度アップ(3人)」にまとめ、名前が切れない幅にする。** → 画面の端の散らかりが減ります。

## 5. 作り直しが要る大きな直し(3案)

### 案A「上を1本の帯にまとめる」

**考え方**
- 上にある帯2本・吹き出し・右列を、ヘッダーとイベント帯1本に集めます。
- 下は主の4つを大きく、支えの4つを小さくします。

**phone-tate の並び(上から下へ)**

| y の範囲(高さ) | 部品 |
|---|---|
| 0〜48(48) | ヘッダー:名前Lv/ダイヤ・P/設定(更新履歴の赤印は設定に付ける) |
| 56〜128(72) | イベント帯1本。数秒で切り替わり、点2つで「何枚目か」を示す |
| 128〜588(460) | 街:ボス+HP帯、みゅあの顔丸、右上にミッション・ギフトの丸2つ |
| 596〜726(130) | 主の4つ |
| 736〜824(88) | 支えの4つ(絵を小さく) |

**減らした物と行き先**
- 花の帯 → イベント帯の2枚目
- 時計 → 外す
- 更新履歴 → 設定の中
- 吹き出し → みゅあの顔丸
- 会話窓 → 顔丸の💬
- 仲良し度の知らせ → 1枚
- 入口の顔丸 → 1つ+数字

**横向きとタブレット**
- phone-yoko:ヘッダー44px。その下の左に帯(約360×56)、右にミッション・ギフト。中央が街。入口は y260〜385 に1列(主の4つは幅110、支えの4つは幅80)。
- タブレット:帯の幅は最大600px に抑えます。入口は1列8枚で、主の4つを大きくします。

**良い点と気になる点**
- 良い点:今の部品をほぼそのまま使えます。上部が約200px から約72px に減ります。
- 気になる点:切り替え式だと、2枚目のイベントが見落とされやすくなります。

**考え方**
- 遊ぶ所(入口)を画面の約4割まで大きくし、上はヘッダーと1行だけにします。
- イベントは「入口の札」と「街のボス」で伝えます。

**減らした物と行き先**
- クリスマス帯の大きな絵 → 押した先のイベント画面

  - ビートの「開催中」札は t2 で出て、t3 では花と一緒に消えていました。

  - クリスマスがどの入口につながるかは止め絵からは分からないので、確認が要ります。

## 6. どれを勧めるか

**案Aを勧めます。** 入口とイベントの両方がひと目で分かり、今の部品をほぼそのまま使えるからです。
案Bの「主の4つを大きく、支えの4つを小さく」も取り入れます。
まず4章の1〜3(会話窓・吹き出し・入口の札)を先に入れて社長に見せ、そのあと帯を1本にまとめる順で進めます。
