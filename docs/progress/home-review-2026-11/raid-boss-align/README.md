# HOME の期間中のボスの絵のずれ・共有HPの字(2026-11-28)

HOME の作り直しの点検で出た物(ボスの絵が共有HPの札より右にずれる・共有HPの字が小さい)。

- 原因: クリスマスのボスの絵を `left:50%` + `transform:translateX(-50%)` で真ん中に寄せていたが、跳ねる動き(`mhRaidJackHop`)が `transform` を丸ごと上書きするので寄せが効かず、絵の幅の半分だけ右へずれていた
- 直し方: 真ん中へは `left:0; right:0; margin:0 auto` で寄せる(transform を使わない)。共有HP(と「準備中」「…」)の字を 8px → 11px
- ジャック(ハロウィン)の絵は別の書き方なので変えていない
