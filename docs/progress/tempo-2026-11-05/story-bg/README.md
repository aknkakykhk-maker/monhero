# お話の背景絵(2026-11-05・レフェリーくん)

社長「背景絵がない」。えるびんの登場のお話の場面ごとに背景を出す。**ほかのお話でも使える。**

- 絵: `monster-hero/images/story-bg/<名前>.jpg`(1080×1080・1枚 38〜75KB)。表は `data/breeder.js` の `STORY_SCENE_IMAGES`(名前 → 絵の定数)
- 使い方: 台本の行に `scene:'<名前>'`。次に `scene` を書いた行まで続き、`scene:'none'` で消す。`fx:'fall'` の行は今までどおり背景が上へ流れて暗くなる
- 縦の画面は、会話の紙より上の範囲に絵を敷く(真ん中の家・宮殿が紙に隠れない)。横の低い画面は全面に敷く(紙の両脇に見える)
- お話を開いたとき、そのお話で使う絵を先に読む(場面が替わった瞬間に遅れて出ないように)

| 名前 | 絵 | えるびんのお話で使う所 |
| --- | --- | --- |
| desert_palace(desert も同じ) | 石油王の世界: 砂漠の夕方と白い宮殿・ラクダ | ① ピンチ〜穴に落ちる |
| desert_oilfield | 石油王の世界: 夕方の油田 | (案・ほかのお話用) |
| desert_hall | 石油王の世界: 宮殿の中 | (案・ほかのお話用) |
| monhero_plaza | モンヒロの世界: いつもの場所(昼の広場と家) | ② 着いた所〜③ / ⑤ 見守る人 |
| monhero_town | モンヒロの世界: 街(服の店とカフェ) | ④ コーディネート |
| monhero_night | モンヒロの世界: 夜(いつもの場所の月夜) | ⑥ 仲間になる |

止め絵: `背景の一覧.jpg`、`お話の画面_<番号>_<名前>_縦/横.jpg`(デバッグのお話一覧から流して、場面が替わるたびに撮った)
