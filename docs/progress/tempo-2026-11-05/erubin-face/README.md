# えるびんの表情の切り抜きの仕上げ直し(2026-11-05・レフェリーくん)

社長「透過の雑さが目立つ」。HOME などに出る胸から上の絵16枚(通常8・石油王8)と、そこから作る顔アイコン16枚を作り直した。立ち絵(ツナグくんの担当)は触っていない。

- 直したこと: くせ毛の外側のギザギザと背景のクリーム色の残り/髪のまわりの白いふち取り/頭布の白いにじみと欠け(縁をなめらかに)/肩の切れ目(マスの端でなじませる)。毛先は半透明を残し、背景の色かぶりを引いた
- 窓口の指摘で直し直した(同じ日): 頭布の外側の灰色〜白っぽい細い線 → 縁を内側へ2px削ってからなめらかにし、半透明の所は内側の色で塗り直した/頭の黒い輪の上に浮いていた輪郭の弧 → 丸ごと消した/肩のぼかしは4pxに(広いと明るい背景で灰色の帯に見えた)
- 道具: `tools/assistant/refine-assistant-cutout.py`(元の一覧の絵から作り直す。石油王は `--cloth`)。配信は前と同じ 256色・ディザあり
