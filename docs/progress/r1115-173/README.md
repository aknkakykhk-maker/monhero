# モンサクの育成バランス: 修行中心が突出する原因と調整案(r1115-173)

クラフト43。**数値は変えていない**(社長が選ぶ用の案)。発端は外部のAIの試験周回の指摘
「同じ種族・編成で各24周、修行中心の総合力中央値はトレーニング中心より ベースモン編成で約2〜11%・B相当の仲間入りで約26〜53%高い。B相当のライガーはファイナル戦勝率14%→63%」。

- 試算: `node tools/success/monsuc-balance-sim.js --matrix --runs 24 --variant now`(最新 main 7a480b78・30秒)
- 育てる子 5種(モッチー・ゴーレム・ライガー・キュウビ・ウンディーネ)× 編成4つ × 育て方2つ × 24周
- 育て方の重み: トレーニング中心 = トレ8・休む1・大会1 / 修行中心 = トレ2・修行6・休む1・大会1(どちらも「ほめる」・出来事は最初の選択肢)
- 編成: base = ベースモン / box-mid = 10周点検の箱の子(アシスト効果なし) / real-B・real-A = 育て終えた子らしい子(能力の合計 2,600・3,400・おまかせのアシスト効果つき)

## 1. 指摘の数字は出るか

| 指摘 | 最新 main の結果 | 判定 |
|---|---|---|
| ベースモン編成で +2〜11% | +2〜11%(ゴーレム +2.0%・ライガー +2.2%・キュウビ +3.8%・ウンディーネ +6.5%・モッチー +10.6%) | 合う |
| B相当の仲間入りで +26〜53% | 出るのは **box-mid(箱の子・アシスト効果なし)** の +26〜53%。道具の「B相当」= real-B では **+40〜67%** | 数字は合うが、編成の名前が違う。B相当ならもっと差が大きい |
| B相当のライガー ファイナル勝率 14%→63% | box-mid で 14%→63%。real-B では **30%→75%** | 同上 |
| (指摘に無い) real-A | **+47〜96%**。キュウビの修行中心は 21,166(評価 M が92%) | 強い編成ほど差が広がる |

## 2. 原因

1回ぶんの能力の上がり(ライガー・育成はじめの状態・能力6つの合計):

| 編成 | トレーニング1回(平均) | 修行1回(炎の谷) |
|---|---|---|
| base | 25.6 | 61 |
| box-mid | 27.7 | 130 |
| real-B | 28.0 | 138 |
| real-A | 28.6 | 171 |

1. **修行の「② 編成の得意」は、編成の子の能力の値そのものに比例する**(1位3%・2位1%・0.5%。重なりは 1/2 ずつ)。
   能力 560 の子なら1位の能力に +17。トレーニングの編成の補正は「能力 ÷40 の%」を元の上がり(1回 20台)にかけるだけなので、
   編成が強くなってもトレーニングは +12% しか伸びないのに、修行は 2.8倍になる
2. **② は行き先の4能力だけでなく6能力すべてに乗る**(行き先の基礎 +8 は4能力だけ)。修行1回で全部の能力が上がる
3. 修行には失敗・サボりが無く、技も覚える(技の分が総合力に足される)。トレーニング中心は技を覚えない
4. 強い編成ほど大会に勝ち、勝つとチケットが増えて修行に多く行ける(修行の回数 base 6〜9回 → real-A 7〜10回)

**初回育成(ベースモン編成)では ② が小さい**(1能力 +10 以下)ので差は +2〜11% に収まっている。突出するのは ① ではなく、強い子を連れたときの ②。

## 3. 調整案(試算は道具に案として足した。`--variant Sc10,Sc15,Scourse,Spct`・2分)

| 案 | base(初回育成) | box-mid | real-B | real-A | ライガー ファイナル勝率 box-mid / real-B | 初回育成(修行中心)の総合力 |
|---|---|---|---|---|---|---|
| いま | +2〜11% | +26〜53% | +40〜67% | +47〜96% | 14→63% / 30→75% | — |
| **案1 ② を1能力 +10 まで(おすすめ)** | **+2〜11%(変わらない)** | +5〜25% | +11〜31% | +8〜30% | 14→30% / 30→58% | **変わらない** |
| 案1b ② を1能力 +15 まで | +2〜11%(変わらない) | +17〜40% | +29〜42% | +23〜52% | 14→39% / 30→61% | 変わらない |
| 案2 ② は行き先の4能力だけ | −5〜+1% | +9〜25% | +11〜35% | +17〜46% | 14→17% / 30→42% | 5〜8% 下がる |
| 案3 割合を 2%/0.7%/0.3% に | −3〜+6% | +11〜29% | +17〜38% | +27〜53% | 14→32% / 30→75% | 3〜6% 下がる |

- **おすすめは案1**(② の合計に1能力あたりの上限 +10)。ベースモン編成では上限に届かないので**初回育成は1周も変わらない**。
  強い編成ほど抑えが効き、修行中心の上振れは +10〜30% 前後に収まる。修行のほうが強いという形は残る(技も覚えるので、それでよいと考える)
- 締めすぎと感じたら案1b(+15)。案2・案3は初回育成の修行も弱くなるので、おすすめしない
- 画面の「修行の上がりの内訳」(r1115-060)は同じ式から出しているので、入れるときは内訳の表示も上限で切る(芯の `shugyoGainOf` と `shugyoPartsOf` の両方)
- トレーニング側を強くする案(071 の案A系)とは別の数字なので、両方入れることもできる

## 4. 狙った技の習得条件を、育成の序盤から見やすくする案

いまは「覚えられる条件(能力の下限・前の技の熟練)」は修行の画面の🔒の札を押したときだけ見える。チケットが無い序盤は確かめにくい。

- 案A(おすすめ): 育成のホームに「ねらう技」を1つ置ける。置いた技の条件(例: 「ちから 300で」「〇〇 熟練40で」)と、いまの値をホームの帯に小さく出す。満たしたら「修行で覚えられる!」と知らせる
- 案B: 育成を始める前の画面(子を選ぶところ)に、その子の技の道すじ(どの技の熟練でどの技が開くか)を一覧で出す
- 案C: トレーニングの札に「この能力を上げると〇〇の条件に近づく」の印を付ける
