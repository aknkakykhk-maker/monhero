# MFバトルカードのランキングが横にも動く(r1119-157・追跡表 r1124-004)

社長の写真: [`shacho-rank-tate.png`](shacho-rank-tate.png)(iPhone 縦・ランクのタブ)。「ここのスライド横にも動く」「たまにこういうのある」

## 原因

ランクのタブだけ、中身(共通の `PlayerRankBoard`・43)を `-mx-3` で包んでいた。中身の左右の余白(px-3)を打ち消すつもりだったが、
包みが縦に流す一覧より 24px 広くなり、一覧が横にも 12px 動いた。指が少しでも横に流れると右へずれ、説明の頭が左で切れ、札の右が空いた。

## 直したこと(`monster-hero/src/parts/90-card-rank.jsx`)

- `-mx-3` をやめ、中身の左右の余白を消して一覧の幅にそのまま収めた(札の幅はほかのタブと同じ)
- 縦に流す一覧に `overflow-x-hidden` を付けた(中身が広がっても横へは動かない)
- ランキングの送信・中身・保存データは変えていない

## 測る検査(新規)

`node tools/card/card-hscroll-browser-check.js` — 本物のブラウザで、縦 390×844・320×568・横 844×390 の3つの大きさで、
カード部の画面(スターター・対戦の結果・トップ・ランキングの5つのタブと通算・図鑑とそのタブ・遊び方・記録とそのタブ・オプション・デッキ・
対戦を選ぶ・助手と対戦・デッキ登録・カップ・マルチ)を開き、縦に流す所(overflow-y が auto/scroll)の scrollLeft が動かないこと、
ページ全体が横に動かないことを見る。動いたら、scrollWidth と clientWidth の差と、はみ出している一番外の中身を出す。

- 直す前: ランクのタブが3つの大きさすべてで NG(横に 12px・はみ出し `data-card-ranking-rank .-mx-3`)
- 直したあと: 全部 OK
