# モンスター図鑑: 入手済み・未入手・未実装(2026-10-26)

社長「モンスターのデータめちゃくちゃ入れたから全部図鑑に入れて。ただ、入手済みと未入手と未実装と分ける。
未入手と未実装は、グラフィックと図鑑説明とメイン・サブしか見えない」。

- 一覧: 入手済み → 未入手 → 未実装 の区切りで並べ、見出しに「その区切りの数 / いま並んでいる全員」を出す
  (遊べる子28体＋案の子 UPCOMING_MONSTER_DRAFTS 36体 = 64体)。上の「図鑑登録数」は今までどおり解放数 / 28
- 未入手・未実装: 立ち絵(色つき)・名前・札・血統(主/副と区分)・図鑑説明だけ。能力・技・特性・タイプ・
  動き・攻撃アクション・色・染めてみるは出さない
- 案の子は `dexMonsterList` へは混ぜない(種族チャレンジ・絆ランキング・ヘルプの血統一覧も見ているため)。
  図鑑の画面だけが `dexScreenEntries` を使う。保存は読むだけ
