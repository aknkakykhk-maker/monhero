## 決まったこと(社長)

- 血統: イルミネ=イルミネ×イルミネ(純血) / ドリーミィ=イルミネ×ニャー(派生種)。血統 id は `illumine`・`nya`
- 能力値(ザンベース): イルミネ 330/120/130/50(ライフ/ガッツ/ちから/丈夫さ) / ドリーミィ 360/130/115/60
- 供モン加算(ライフ/ちから/丈夫さ/ガッツ): イルミネ 110/40/10/40 / ドリーミィ 120/35/15/40
- 間合い: イルミネ B・C・A・E / ドリーミィ B・D・D・A
- 勇者特性(2体共通)「影潜」: 楔(上限6)。1つごとに15%連撃と回避+15%。持ち主が回避で0
- 固有技: イルミネ ×2.3・消費46「セレーネチェイサー」 / ドリーミィ ×2.6・消費52「ドリームペイン」
- タイプ: イルミネ シャドウ/アタッカー / ドリーミィ サポーター/シャドウ
- モンビー: イルミネ血統=我慢、ドリーミィだけ必死(子ごとの上書き `RHYTHM_MONSTER_ABILITY_BY_MONSTER`)
- 顔アイコン: ドリーミィ B / イルミネ B の位置ちがいの「顔をもっと上へ」(`face-illumine-up.png` のいちばん左)
- 染色の部位分け(5部位ずつ)・ドリーミィの技名(作り直した表)も社長OK

## 開発部で決めたこと(報告済み)

- 楔は敵に付くので、WAVEが変わると0。既存5モードは勇者モンのとき(キー 'party')、タクティクスは持っている子それぞれ
- 楔の連撃は持ち主本人の攻撃だけ。セレーネチェイサーの連撃は技の出自がイルミネなら誰が使っても(楔はその枠のぶん)
- 固有技の効果の楔の数は、その攻撃で増える前の数
