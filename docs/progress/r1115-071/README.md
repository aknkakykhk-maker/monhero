クラフト30。**まだ入れていない**(社長の OK のあとで入れる)。数字は試算の台本 `tools/success/monsuc-balance-sim.js` の結果。

- 台本は10周点検の周の設計(`monsuc-play10.js` の LAPS: 子・育て方の重み・トレーニングの能力・ほめ/しかる・編成)をそのまま使い、
  計算の芯だけで **1周の設計を50回ずつ** 回した(ブラウザの10周は1周1回だけなので、運の差が大きい)。試合はオート相当
- 案の数字は芯の写しで試した(本物の芯は書き換えていない)。記録: `laps10.json`(10周の設計)・`matrix.json`(同じ子で育て方を比べた物)

## 分かったこと(先に)

1. **編成がベースモンのままだと、トレーニング中心と修行中心の差はほぼ無い**(同じ子で総合力の差 −500〜+600)。
   差が開くのは **育てた子を編成に入れたときだけ**。修行は「編成の子の得意な能力の 3%」をそのまま足すので編成が強いほど大きく伸びるのに、
   トレーニングの補正は「得意な能力 ÷ 40 %」(能力 400 の子で +10%)と小さい。編成の強さが修行にばかり効いている
2. 点検の周1(トレーニング中心)はベースモンの編成、周8 は弱い箱の子(能力の合計 800・アシスト効果なし)だったので、**アシストを強くしても周1・8 はほとんど変わらない**(下の①)
3. 能力ポイントは大会に勝ったときしか入らないので、**勝つ周(修行の周)ほどたまる**。ポイントを増やす・熟練に振れるようにすると、
   熟練の条件つき技は修行で覚えるため、**修行の周がさらに強くなる**(熟練 1点で +1 にすると修行の周が評価 M に届く)。そこで、トレーニングからもポイントが入り、熟練は「2点で +1」にした

## 読み方とおすすめ

- **案A3(アシスト強化)で、育てた子を入れたトレーニング中心は1〜2段上がる**(モッチー 育てたA: A3 → SS2・期末で負けた 76% → 26%)。
  ただし修行中心も少し上がるので、差は 4,300〜6,700 → 2,200〜5,000 に縮むところまで。キュウビ・ウンディーネ・ライガーは期末にまだ負けやすい
- 残る差のほとんどは **技の数**(トレーニング中心は技を覚えないので、総合力の技の分と試合の技が増えない)。数字の補正だけでは埋まらない
- **案P2 は単独では差を広げる**(勝つ周ほどポイントが入る・熟練の条件つき技は修行で覚える)。熟練の条件つき技を覚えた数は 0〜2.5 → 0〜4.4 に増える(頼みの r1115-072 の狙いはこちら)
- **別案S を足すと差が最も縮む**(モッチー 育てたB 差 1,932・ウンディーネ 差 94)。修行中心の評価は 1段ほど下がる

おすすめ: **案A3 + 案P2(熟練は2点で+1)**。差をもっと縮めたいなら 別案S も。
(さらに縮めるなら「トレーニングの大成功で技を覚えるくじ」など、トレーニングで技が増える道が要る。これは別の頼みとして窓口で)

## 能力ポイントの画面(熟練の行)の案

クラフト26 の仮振り → 決定の作り(#6391)に、能力6つの下へ「技の熟練」の行を足す。r1115-082 の熟練の表示(詳細の右の欄・升目のゲージ)と同じ言葉・同じゲージ。

```
能力ポイント 残り 86 点
 ライフ   412 → 415   [−] [＋]      (いまの行・そのまま)
 …
── 技の熟練(2点で +1) ──
 [技の絵] モッチ砲   熟練 12 → 25 /100 ▰▰▱▱▱  [−] [＋]
          あと 13 で「さくら吹雪」を覚えられる(修行で)
 [技の絵] ぽかぽか    熟練 40 /100 ▰▰▰▰▱    [−] [＋]
[元に戻す]  [おまかせ]  [決定]
```

- 覚えている技だけ並べる。熟練の条件になっている技(その先の技をまだ覚えていない物)を上に、「あと ◯ で ◯◯ を覚えられる」を添える
- ＋ は 2点で熟練 +1。熟練 100 の技・残りが 1点のときは押せない見た目
- おまかせは今までどおり能力だけに振る(熟練へは自分で振る)
- 保存: 熟練は今の `s.mastery`(たまった熟練)に足すだけで、新しい保存の項目は要らない。いくつ振ったかは新しい項目 `s.masteryBought`(既定 {})に足して持つ(古い途中の育成は {} として読む)
