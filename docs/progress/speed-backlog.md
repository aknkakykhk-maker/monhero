# 速さ部(ハヤテくん)の見つけた物と済んだ物

数字と測り方は [`speed/README.md`](speed/README.md)。

## 見つけた物(上から順に)

- [ ] 起動時に `data/rhythm-mode.js`(圧縮後 1.07MB)を読む。譜面を曲ごとに分けて、曲えらびで読む案 → 窓口へ
- [ ] タイトル曲を待ってからタイトルを出す(遅めの4G で 10 秒以上)。先にタイトルを出す案 → 窓口へ
- [ ] 起動時に更新履歴・ヘルプ・助手のデータ(圧縮後 739KB)を読む。開いたときに読む案 → 窓口へ
- [ ] HOME の裏の先読み(`imagePreloadQueue`)が、持っていないマーケットのアイコン・全モンスターの絵まで取る(2分で約19MB) → 窓口へ
- [ ] モンヒロビート Sheriruth MASTER 104〜112秒(CPU 3倍・縦)で 2.1 秒の止まりが1回 → テンポくんへ知らせる

## 済んだ物
