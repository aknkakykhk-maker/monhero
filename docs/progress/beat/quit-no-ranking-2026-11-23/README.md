# 途中でやめた演奏はランキングへ送らないか(r1119-152・2026-11-23 テンポくん)

社長「イベントランキングの曲ごとに回数表示あるけどそれが増えてる気がした(途中でやめても回数に加算されてない？)」

## 結果: 送っていなかった

検査 `tools/mode/rhythm-quit-no-ranking-check.js` で、本物のブラウザと偽の Supabase で確かめた。

| 動かしたこと | rankings への書き込み |
|---|---|
| ① 一時停止 → 曲選びへ戻る | 0件 |
| ② 一時停止 → リスタート → 一時停止 → 曲選びへ戻る | 0件 |
| ③ 画面を隠す(アプリを裏へ回した相当) → 戻る → 一時停止 → 曲選びへ戻る | 0件 |
| ④ 一時停止したまま画面を閉じる | 0件 |
| ⑤ 見本: 曲の時計を速めて最後まで流す | 1件(この検査が送信を見られていることの確かめ) |

- マルチライブ・レイドも同じ演奏画面(`rhythmPlay` の from:'multi' / 'raid')を通り、送る所は onComplete(曲の最後まで流れた時)の1か所だけ。やめる側(onExit)には無い。検査が作りの上でも見張る
- 回数に入るのは「曲の最後まで流れた演奏」。ライフが0になって未クリアのまま最後まで流れた演奏も1回に数える(前からの作り)。
  Android でアプリを裏へ回したまま曲が最後まで流れたときも、最後まで流れた演奏として数える(裏で自動で一時停止する設定 autoPauseOnHidden は既定で切)
- 既存のランキングの記録には触れていない
