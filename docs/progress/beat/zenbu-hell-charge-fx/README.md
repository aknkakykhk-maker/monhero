# 全部必殺技でつ HELL: ききのチャージノーツと必殺ノーツ(2026-11-23・ビート・台帳 r1119-141 と追記1〜4)

社長「必殺技って出るだけで安っぽい・文字は邪魔」「専用のききノーツ(ピンク系)…押したぶんだけたまって光の玉がでかくなって、最後に必殺ノーツみたいのがきて光が爆発」
「必殺！みたいのがノーツにくっついてきて」「3箇所か4箇所ぐらいあったイメージ」→ 選択「4か所それぞれで溜めて弾ける」「溜めた光が道を駆け下りる」。
追記5 社長「2と3は同じにしたら？」→ C の連打と続く B のスライドを1つの区間にした。**弾けるのは3回**。

## したこと

| 所 | 区間(譜面の時刻) | チャージノーツ | 必殺ノーツ |
| --- | --- | --- | --- |
| B 0:33〜(小節26〜29) | 33.45〜38.30秒 | 区間のタップ | 38.161秒のタップを sub1 → **真ん中(sub5)** へ |

- **譜面で変えたのは2つのノーツの横の位置だけ**(時刻・種類・幅は同じ)。ノーツ数 776・Lv.76・配点・判定の幅は変わらない。記録の版は今の `-r2` のまま
- 手の決まり(同じ手 90ms・押せない0・帯の中0)と押さえ中の交差0を確かめた(真ん中へ動かしたノーツは、反対の手のスライドの押さえ(右寄り)と重ならない)
- **チャージノーツ**: 区間のタップだけ、ききのピンク(濃いマゼンタ・金の縁)。スライド・フリックは今の色のまま(種類の見分けを崩さない)。
  上フリックの色が淡いピンク(#f472b6)なので、それと紛れないよう色を濃くし、金の縁を付けた
- **光の玉**: 道の奥(上の端)に出る。区間のノーツを取った数(取り逃しは数えない)÷区間のノーツの数で、大きく・明るくなる。各所ごとに空から溜め直す
- **必殺ノーツ**: 見た目だけ大きく(細いノーツは横2.6倍・縦1.9倍)。すぐ上に「必殺！」の印がくっついて一緒に流れ、叩くと消える
- **叩いた瞬間**: 玉が道を判定ラインまで約0.16秒で駆け下り、横に弾けて約0.3秒で消える(溜めた量で大きさが変わる)。取り逃したら、その場で小さくしぼむ
- **光はすべてノーツより下の層**に出すので、ノーツは隠れない
- 前の A の「道の色が変わる」「必殺技！の文字」はやめた
- 重さ: 動くのは玉と駆け下りる光の2つの要素の transform・opacity だけ(絵・動画は足していない)。「必殺！」の印は最初に1回だけ焼いた絵を貼る。軽量モード・演出の量が少なめでも出す
- 更新履歴・ヘルプには載せない(社長「こんなおしらせいらない」)
