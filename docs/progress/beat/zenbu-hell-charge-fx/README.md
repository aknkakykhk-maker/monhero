# 全部必殺技でつ HELL: ききのチャージノーツと必殺ノーツ(2026-11-23・ビート・台帳 r1119-141 と追記1〜4)

社長「必殺技って出るだけで安っぽい・文字は邪魔」「専用のききノーツ(ピンク系)…押したぶんだけたまって光の玉がでかくなって、最後に必殺ノーツみたいのがきて光が爆発」
「必殺！みたいのがノーツにくっついてきて」「3箇所か4箇所ぐらいあったイメージ」→ 選択「4か所それぞれで溜めて弾ける」「溜めた光が道を駆け下りる」。
社長(アプリから直接)「ききノーツをききのリボンがぴょこんとついたようなノーツに」「もうちょいピンク色に」「必殺ノーツは必殺よりピンクの剣をノーツの上に置いてききノーツを発光してる感じ」。
追記5 社長「2と3は同じにしたら？」→ C の連打と続く B のスライドを1つの区間にした。**弾けるのは3回**。

  (前は道の奥の光の玉だった → 社長「必殺ゲージ見にくいから。レーン端をどんどん光らせて必殺で真ん中にくるかんじ」で作り替えた)
- **必殺ノーツ**: 見た目だけ大きく(細いノーツは横2.6倍・縦1.9倍)。ノーツの上に**ピンクの剣**が乗って一緒に流れ、ノーツのまわりがピンクに脈打って光る(リボンは右上)。叩くと消える。
  剣は奥から来るノーツに大きくかぶらない大きさにした。画面の真ん中に文字は出さない
- **叩いた瞬間**: 両端の光が真ん中へ寄り(約0.2秒)、寄りきった所から光が道を判定ラインまで約0.16秒で駆け下り、横に弾けて約0.3秒で消える(溜めた量で大きさが変わる)。
  取り逃したら、両端の光がその場で消えるだけ。音は、触れた瞬間のタップ音に「少し強いタップ音」と「キン」を重ねる(社長「普段のタップ音より少し強調した音」・素材は足さない・タップ音の設定に従う)
- **光の色はききのピンク(桜色)だけ**(社長「ピンクだけ」・白や金は混ぜない)。両端の光も駆け下りる光も弾ける光も同じ色
- **光はすべてノーツより下の層**に出すので、ノーツは隠れない
- 前の A の「道の色が変わる」「必殺技！の文字」はやめた
- 重さ: 動くのは両端の光2つと駆け下りる光の3つの要素の transform・opacity だけ(絵・動画は足していない)。リボン・剣は最初に1回だけ焼いた絵を貼る(ノーツ1つにつき1〜2枚)。軽量モード・演出の量が少なめでも出す
- 更新履歴・ヘルプには載せない(社長「こんなおしらせいらない」)

## 曲の鑑賞でも出す(2026-11-23・社長「鑑賞でききの曲みたけど変わってないよ」)

鑑賞(`lineAdjust.listen`)は中で練習扱い(`tutorial`)になり、演出が切れていた。本物の練習(`tutorialProp`)でない鑑賞のときは、ふつうに遊ぶ時と同じに出す
(判定ラインの合わせ・オプションの見本・練習では今までどおり出さない)。鑑賞の「-10秒」で区間より前へ戻ったときは、玉を空から溜め直す。
止め絵 `4-listen.jpg`(鑑賞の自動の手で流したもの。スライドも取るので両端の光はいっぱいまで強くなる)。撮り方は `LISTEN=1` を足すだけ:

```
LISTEN=1 AUTO_TAP=1 STEP=20 PREFIX=b1 SHOT_AT=37.95,38.40 SONG='全部必殺技でつ( `･ω･)' SONG_ID=zenbu_hissatsuwaza DIFF=HELL FROM=33.3 OUT=<置き場> node tools/mode/rhythm-note-appear-scan.js
```

## 鑑賞で送った・戻したあとも出す(ミハリの指摘)

鑑賞の「+10秒」「-10秒」(`listenSeek`)はノーツを作り直すが、印(`rhythmMarkChargeNotes`)を付け直していなかったので、1回押すと以後ききノーツ・両端の光・必殺ノーツが出なかった。
作り直したあとに印を付け直し、溜めた数と弾けた印を移った先に合わせる(前に終わった区間は弾けたことに・移った先の区間はそこまで取れた数に・後の区間は空から)。
止め絵 `6-listen-after-seek.jpg`(「+10秒」を11回押してから 1:53〜 を実時間で撮った。止めた時計は送り戻しとかみ合わないので `REAL_SHOTS=1` を足した):

```
REAL_SHOTS=1 LISTEN=1 PRE_CLICK='+10秒:11' PREFIX=s SHOT_AT=114.5,117.3,117.7,117.85 SONG='全部必殺技でつ( `･ω･)' SONG_ID=zenbu_hissatsuwaza DIFF=HELL FROM=0 OUT=<置き場> node tools/mode/rhythm-note-appear-scan.js
```
