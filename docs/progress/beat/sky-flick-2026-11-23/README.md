# 空中フリックの見た目(r1119-148・社長「スカイフリックって…わかりづらすぎる」)

## 調べた結果
- 空中のタップ・フリックは、既定の見た目「案Z(ガラスの箱)」で描いている。10/10〜10/11 の空中ノーツの試作(e0c70c237・a48224399)からこの形のまま。
  11月の変更(空の上がり方 #7303・#7358、ききノーツ、ノーツの色の組)では変わっていない。**前の見た目に戻すものはない**
- 空中のフリックは「空中のタップと同じ赤い板」+「板の上の小さな白い三角」だけ。タップとの違いが三角しかなく、見分けにくい
- 三角は払う向きに関係なく、いつも上向きに描いていた(不具合)。PR #7389 で、左右のフリックは払う向きを指すように直した
- 空中のフリックがあるのは Beyond the Same Sky の HELL(左5・右3)と short ver. の HELL(左2・右2)だけ

## 絵
- `president-sky-flick.png` … 社長の写真(直す前・2:30 の空中の左フリック)
- `now-after-arrow-fix.png` … 同じ所を、矢印の向きを直した後で撮ったもの(横持ち 844×390)
- `compare-now-A-B-C.png` … 左上=今 / 右上=案A / 左下=案B / 右下=案C(実際の画面の上に案を重ねた見本)
  - 案A: 地上の横フリックと同じ山形の印(左=青・右=桃の手の色)を、板の上に大きく3つ重ねる。板は空中の赤のまま
  - 案B: 板をフリックの桃色に変え、払う向きへ白い大きな矢印を板から突き出す(桃の光付き)
  - 案C: 板そのものを払う向きに尖らせた矢じり形にし、縁を空色に光らせる。中に白い山形を2つ
- 見本の作り: `now-after-arrow-fix.png` は `node tools/mode/rhythm-listen-play-check.js --song beyond_the_same_sky --diff HELL --from 141000 --shot 150450 --out <png>`

## 社長の選択と作ったもの(2026-11-23・案A)
- 空中のフリック(ガラスの箱)に、地上の横フリックと同じ山形(<<< / >>>・地上と同じ色)を、箱の幅の 0.72 倍の大きさで箱の真ん中へ重ねる。上フリックは地上と同じ桃色の矢印(箱の幅の 0.34 倍)。板の赤はそのまま。下フリックという種類はゲームに無い
