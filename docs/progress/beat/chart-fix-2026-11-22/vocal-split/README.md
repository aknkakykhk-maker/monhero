# 歌い分け(ダブルボーカル)を声の高さで分けた試み — Beyond the Same Sky(2026-11-22・ビート)

台帳 r1119-096 の追記(社長「ダブルボーカルの曲だから、そこんとこうまく読み取って気持ちよくやれるようにしてほしい」)。
窓口経由の社長の答え「声の高さで分けてみる」で試した。**結論: 声の高さ(と声の色・左右の偏り)だけでは、2人をはっきり分けられなかった。**
譜面はまだ1つも変えていない。

## 分け方

1. 音源(`monster-hero/audio/bgm-beyond-the-same-sky.mp3`)の真ん中(左+右)から、繰り返す伴奏を「似たコマの中央値」で引いて声を浮かせる(REPET-SIM)
2. 浮かせた声の高さをコマ(約12ms)ごとに測る(pYIN・80〜1000Hz)。声らしさ0.35未満・小さすぎるコマは捨てる
3. 声のあるコマが0.25秒以上途切れたら区切って「区間」にする(0.4秒未満は捨てる)
4. 区間ごとに [高さの中央値・高さの上の方(80%点)・声の色(MFCC 2〜8)] を並べ、高さを2倍に重くして2つの組に分ける(k-means)。
   低い組を声A、高い組を声B。確かさ = 近い組と遠い組の中心までの距離の差(0〜1)
5. 確かめに、区間ごとの声の左右の偏り(声の倍音の所の右−左)も測った

道具: `tools/audio/vocal-split-pitch.py`(1〜2)・`tools/audio/vocal-split-phrases.py`(3〜4)。
既存の解析ファイル(`tools/mode/authoring/*-v3-audio.json`)は読んでも作り直してもいない。

## 結果

表: [`beyond_the_same_sky-table.md`](beyond_the_same_sky-table.md)(JSON は `beyond_the_same_sky-phrases.json`)

| 項目 | 値 |
| --- | --- |
| 拾えた歌の区間 | 76区間・計約52秒(歌っている時間の3割ほど。伴奏が厚く、声を浮かせきれない) |
| 声A(低め)/ 声B(高め) | 36 / 40 区間。高さの中央 F4(65)/ D#5(75) |
| 確かさ0.5以上 | **5区間だけ**(57.1・69.5・98.4・113.2・176.2秒) |
| 高さの分布 | 山が1つ(G3〜A#5 に切れ目なく広がる)。女声2人で音域が重なっている |
| 左右の偏り | ほぼ真ん中に1つの山(−0.2〜+0.25)。2人は左右に振り分けて録られていない |

**読み取り**: A と B の分かれ目は「誰が歌っているか」より「旋律の高い所か低い所か」(Aメロは低め・サビは高め)をなぞっている。
同じ区間の中で高さが行き来する所も多く、確かさの低い区間がほとんど。このまま譜面へ写すと「高い旋律は右手・低い旋律は左手」になり、
社長の言う「片方の声は片側の手」にはならない。2人が重なる所(ハモり)も、声を浮かせきれないので拾えていない。

## 写し方の案(区間が確かになったら)

| 歌い方 | 譜面 |
| --- | --- |
| 声Aのフレーズ | 左手側(レーンの左半分)。帯はAの区間の中で左に置く |
| 声Bのフレーズ | 右手側(右半分) |
| 2人が重なる(ハモり・ユニゾン) | 両手: 同時押し・左右の帯 |
| 掛け合い(A→B→A) | 句の切れ目で左右へ受け渡す(切れ目は150ms 以上空ける・手の決まり) |

直すのは横の位置(と帯の手の色)だけにし、時刻・種類・ノーツ数は変えない(記録はそのまま)。
押さえ中の交差は0件の決まり(手の決まりの検査の8番)を守る: 帯を押さえている手の側へ、反対の声のノーツを渡さない。

## 社長に聞くこと

高さだけでは分からなかったので、どれで区間を決めるか:

1. **社長(または歌詞カード)から「どこを誰が歌うか」をもらう**(秒でなくても、1番Aメロ=あつ・Bメロ=みゅあ・サビ=2人、のような段落でよい)。いちばん確か
2. 声だけを抜き出す分離器(demucs)を使えるようにする。重みの置き場(dl.fbaipublicfiles.com)がこの環境の通信設定で止められている。
   許せば、抜き出した声の高さ・声の色で分け直せる(女声2人なので、それでも確かになるかは試すまで分からない)
3. 今の高さの分け方のまま写す(「高い旋律は右・低い旋律は左」になる。歌い分けとは別物)
