# 歌い分けの手の割り当て(設計・2026-11-22)

窓口経由の社長の答え: HELL・MASTER(原曲・short)は位置の手直しではなく、音楽(歌の拍・言葉の頭・歌い分け・サビの盛り上がり)に合わせて組み直す。
交差を消すために位置をずらすのではなく、**歌い分けの手の割り当てで交差がそもそも出ない形**にする。区間は [parts-table.md](parts-table.md)。

## 決まり(全区間)

- 女声=右手(画面の右半分)・男声=左手(左半分)。歌っている側の手が言葉の頭(歌の拍)を取り、反対の手は小節の頭など伴奏の拍だけを自分の側で取る
- 帯(ホールド・スライド)は、歌っている側の手の側にだけ置く。反対の手のノーツはその帯の向こうへ置かない → 押さえ中の交差が出ない
- 掛け合い(1行ずつ交互)は、行の終わりで反対の手へ渡す。渡す所は同じ手の押し始め90ms・地上⇔空中150ms の手の決まりを守る
- 2人・ハモりは両手: 言葉の頭は左右の同時押し、伸ばしは左右対称のスライド(交差させない)
- サビの盛り上がり(サビ・最後のサビ・Beyond the Same Sky)は密度と同時押しを上げる。HELL の空中ノーツは、サビの伸ばし・ハモり・山場に寄せる
- MASTER は空中なし。同じ割り当てで、密度を HELL より下げる
- 記録の扱い(ノーツの時刻・数が変わる場合のランキング・自己ベスト)は**社長の答え待ち**
