# 譜面の直し: Beyond the Same Sky(原曲・short)MASTER・HELL / Desert Crown HELL(2026-11-22・ビート)

台帳 r1119-096・追跡表 r1122-012。社長「あつみゅあの曲はクロスが多すぎていやらしすぎる。片手ホールド・スライドで片手タップならいいけど、
それがクロス混じりでやりづらい」「えるびんの曲は HELL でホールドかスライドとスカイ中にさらにタップがある。親指2本じゃ押せない」。

## 何が起きていたか

どちらも同じ形: **片方の親指が帯(ホールド・スライド)を押さえて動けないまま、もう片方の親指がその帯の向こう側を叩く**。
押さえている指は離せないので、帯をまたぐか3本目の指が要る。データ上で「帯2本+タップ」のように3つが同時に重なる所は0件だった
(どれも帯の終わりから150ms後)。実際に押せなかったのは、例えば Desert Crown HELL の 2.99秒(真ん中のホールドの左)→3.29秒(右)、
17.70〜18.45秒(ホールドの右に3つ→左に1つ)、82.81秒(左手の空中スライドが右端へ振り切る最中に、左側の空中タップ)。

## 直し方(作り直しはしていない)

`tools/mode/rhythm-held-cross.js --fix` で、**交差しているタップ・フリックの横の位置だけ**を押さえていない手の側へ動かした。
時刻・種類・幅・高さ・ノーツ数は同じなので、ランキング・自己ベスト・フルコンボの記録はそのまま使える(2026-11-11 の決め「記録はそのまま残す」と同じ扱い)。
動かし先は、手の決まり(rhythm-chart-hand-rules.js の全部)・帯の中・空中の「指が同じ位置」「見分けにくい」が増えない所だけから選んだ。
Beyond の HELL の一部は、空中スライドの手の色(左手=青・右手=桃)を入れ替えた(桃色の帯が左端まで行き、右手で取る案内になっていた所。線の形は同じ)。
片手が帯を押さえている間は、空いている手が同じ側で続けて叩く形になるので、ノーツの密度は変わらない。

  手の決まりの検査の「指が同じ位置」の上限にこの曲の1件を名指しで足した(`--also 82808:9`)

  - スライドそのものがタップの左右をジグザグに行き来する所(スライドの形を変える大きな直しになる)
  - HELL で、外せる位置がどこも空中スライドの通り道の真上・真下になる所(HELL の Lv. ごとの上限がある)
- 1か所ずつは `<曲>-<難易度>.txt`(直し直しの後の中身に書き換えた)

## なぜ今の検査が見逃したか・強めたこと

- 親指2本のモデル(rhythm-ref-tiers.js の thumbCheck)は、この形を「指が交差」(注意・重み60)として数えるだけで「押せない」にしない。
  しかも帯を押さえていて動けない交差と、空いている指どうしの入れ替わり(どければ済む)を分けていなかった
- 手の決まり(rhythm-chart-hand-rules.js)は左右を「画面の半分」で決め打ちするので、帯の向こう側へ渡る形は「反対側のノーツ」に見えて引っかからない。
  交差を見るのは HELL の水平クロス(空中どうし)だけ。帯の中の検査は帯に重なるノーツだけを見る
- 強めたこと: `rhythm-held-cross.js`(thumbCheck の交差のうち、反対の手が帯を押さえている最中のものだけを数える)を作り、
  `rhythm-chart-hand-rules-check.js` の 8 番で、公開中の MASTER・HELL の件数を控え(`rhythm-held-cross-baseline.json`)より増やさない・
  控えに無い譜面(新しい曲・新しい HELL)は0、を見張るようにした。見つかったら同じ道具の `--fix --write` で位置だけ直せる
