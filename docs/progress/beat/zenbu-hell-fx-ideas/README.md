社長「ききの歌は必殺技って文字が出るだけでつまんない。ただ譜面の難易度はいいかんじだからそこの工夫がもっとほしいな」。
**譜面(ノーツの数・難しさ・判定)は変えない。** 変えるのはこの曲の HELL の演出だけ(今は 112.9〜118.0秒で道が赤くなり「必殺技！」の字が出るだけ・r1119-136 の D)。
**案を並べただけで、本体はまだ変えていない**(社長に選んでもらう・r1119-036)。更新履歴には載せない。

区間は今と同じ 112.9〜118.0秒(最後のサビの締め・譜面の「必殺技の決め」)。最後の一撃は 117.594秒の幅6の左右2つ(この曲の最後のノーツ)。

## 共通の決まり(どの案でも)

- 判定・点数・譜面・ノーツの色と形は変えない。見た目だけ
- 「演出の量: 少なめ(MINIMAL)」・軽量モードでは、揺れと閃光を出さない(今の D と同じ)。字・ききの絵は残すか消すかを選べる
- この曲の HELL だけ(`data/rhythm-mode.js` の `RHYTHM_CHART_SPECIAL_FX` の1行)。ほかの曲・難易度には出ない
- 演奏の途中で止めて戻る・やり直しでも、区間に入るたびに初めから出る

## 撮り方

`tools/mode/rhythm-note-appear-scan.js` に `MOCK_FX=<js>`(撮る前に `window.__mhMockFx(曲の時刻ms)` を呼ぶ)と `SHOT_AT=<秒>,…`(その時刻だけ撮る)を足した。本体は変えない。

```
cat docs/progress/beat/zenbu-hell-fx-ideas/mock-common.js docs/progress/beat/zenbu-hell-fx-ideas/mock-a.js > <置き場>/m-a.js
MOCK_FX=<置き場>/m-a.js PREFIX=a SHOT_AT=113.15,114.6,117.3,117.65,117.9 SONG='全部必殺技でつ( `･ω･)' SONG_ID=zenbu_hissatsuwaza DIFF=HELL FROM=112.5 OUT=<置き場> node tools/mode/rhythm-note-appear-scan.js
```

## 選ばれたら入れる所

- `data/rhythm-mode.js` の `RHYTHM_CHART_SPECIAL_FX`: 区間に「最後の一撃の時刻」と案の種類を足す
- `src/parts/30-rhythm-play.jsx`: 今の `specialFxRef` の所(tick で区間の出入りを見ている)。案1は満ち具合を CSS 変数で渡す、揺れは今ある画面の揺れの仕組みを使う。案2はききの絵(`images/assistant/kiki_*.PNG`)を出す
- `index.html` の `[data-rhythm-special-fx]` の CSS。案3の炎の縁は GPU の帯(`rhythm-gpu-band-check.js` で描き比べ)
