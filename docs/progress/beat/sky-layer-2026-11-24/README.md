# HELL の地上レーンを空中レーンの「裏」に見せる(r1119-165・相談・案だけ)

社長「ヘルで地上空中とあるけど、これみると空中レーンって薄いレーンが全体にある感じじゃん？ 地上レーンはこのレーン裏に出すような表示でできない？」

止め絵はすべて **Rebellion ～Beyond the Lock～ HELL 鑑賞 3:44(224秒)**。社長の写真と同じ場面。
縦 390×844・横 844×390・🔄横(縦の端末で絵だけ横にしたもの)。案は社長が選ぶまで本番に入れない(r1119-036)。判定・譜面・保存データは変えない。

## 1. 今の描き方(`now-yoko.jpg`・`now-tate.jpg`・`now-rot.jpg`)

重なり順(奥 → 手前):

| 層 | 中身 | 作り |
|---|---|---|
| 1 | 地上の道(6レーン・区切り) | SVG(z1) |
| 2 | 道の床 + **空中の薄い面**(地上の道を、奥から空中の判定線の高さまで丸ごと持ち上げた台形・塗り13%) + 空中の判定線 | SVG `RhythmSkyStage`(z2)・既定の見た目「案E はっきり」(2026-10-11) |
| 3 | **地上と空中のノーツを1枚の canvas に、時刻の順で混ぜて描く** | canvas(z5) |
| 4 | 地上の判定ライン・判定の文字・コンボ | DOM |

- 空中の面(層2)は**ノーツより奥**にある。だから空中の判定線より上(奥)を流れてくる**地上のノーツが、空中の面の上に乗って見える**。
  写真の「薄いレーンが全体にある」はこの面で、地上の HOLD がその面の上を走るので、空中の物か地上の物か一目で分かりにくい
- 空中と地上のノーツが重なった所は、時刻の早いほうが下になるだけで、どちらが上かは決まっていない

## 2. 案(どれも同じ瞬間を並べた比べ絵: `compare-yoko.jpg`・`compare-tate.jpg`・`compare-rot.jpg`)

3案とも共通: **地上のノーツを先に描き、空中のノーツをあとに描く**(重なったらいつも空中が上)。違いは、そのあいだに何を挟むか。

| 案 | 一言 | 横 | 縦 | 🔄横 |
|---|---|---|---|---|
| A ガラスの層 | 地上のノーツ → **すりガラスの空中の面**(手前ほど濃い・両端のレールと手前のふちが光る) → 空中のノーツ。空中の面と重なる所の地上のノーツは白く曇り、「ガラスの向こう」に見える | `an-A-yoko.jpg` | `an-A-tate.jpg` | `an-A-rot.jpg` |
| B 地上を沈める | 空中の面と重なる所だけ、**地上のノーツを暗く**(6〜8割暗く・背景や道は変えない)。空中の判定線より手前へ出た所から元の明るさ。空中の面は今のまま | `an-B-yoko.jpg` | `an-B-tate.jpg` | `an-B-rot.jpg` |

| | どちらのノーツか一目で分かるか | 演出量「最小」・軽量モード | 重さ |

## 2回目(社長「空中で濃すぎてみづらい」・案A〜Cはどれも選ばれず)

窓口から: 空中の面をもっと薄く(透明に近く)し、地上のノーツは見やすいまま「空中の裏」に見える案を出す。薄さの段が分かるように、今と並べる。
重なる所の地上は暗くしすぎない。演出量「最大」(見た目のおまかせ「全部のせ」)と初期設定(演出量「標準」)の両方で確かめる。

3案とも、空中のノーツを地上のあとに描く(重なったらいつも空中が上)。違いは空中の面の濃さと、地上をどれだけ沈めるか。

| 案 | 空中の面(今: 塗り13%・区切り32%・ふち60%) | 重なる所の地上 |
|---|---|---|
| D 半分 | 塗り6.5%・区切り16%・ふち30% | 3割暗く |
| E 3分の1 | 塗り4.3%・区切り11%・ふち20% | 3割暗く |
| F ふちだけ | 塗りと区切りなし・両端のふち35%だけ | 2割5分暗く |

比べ絵(どれも左上が今。Rebellion HELL 3:44):

| | 横 | 縦 | 🔄横 |
|---|---|---|---|
| 初期設定(演出量「標準」) | `compare2-yoko.jpg` | `compare2-tate.jpg` | `compare2-rot.jpg` |
| 全部のせ(演出量「最大」) | `compare2-yoko-max.jpg` | `compare2-tate-max.jpg` | `compare2-rot-max.jpg` |

1枚ずつの絵は `now-*`・`an-D-*`・`an-E-*`・`an-F-*`(`-max` 付きが全部のせ)。全部のせの回はライブ背景が出るのでコンボの数が違う。

### 見え方

- D: 面はまだ「層」として見える。今より軽いが、奥の左右の灰色の三角(道の外へはみ出した面)が少し残る
- E: 面はうっすら見える程度で、奥がすっきりする。地上の HOLD は空中の判定線より奥だけ少し沈み、線を越えると元の明るさ。地上のノーツの見やすさは今とほぼ同じ
- F: 面が消えるので一番すっきりするが、空中の段は判定線とふちの細い線だけになり、「空中のレーンがある」ことは分かりにくい
- 全部のせでも3案とも崩れない(ライブ背景の上でも面と地上の沈み方は同じ)。重さは今と変わらない(地上を沈める塗りが1コマに1回増えるだけ)

### おすすめ: 案E(面を今の3分の1 + 地上を3割暗く)

- 「濃すぎてみづらい」が一番はっきり減り、それでも空中の段があることはまだ分かる(F より空中のレーンが分かる)
- 地上は3割だけ沈めるので暗くなりすぎず、空中の判定線を越えた所から今と同じ明るさになる

### 撮り方の追加

- `shoot.js --max` … 見た目のおまかせ「全部のせ」の値(演出量 NORMAL・ライブ背景など)を入れて撮る
- `look.js` に案D・E・F(SVG の空中の面の濃さを CSS で下げる + 地上を軽く沈める)
- `compose.js D,E,F` … 2回目の比べ絵(`compare2-*`)を作る
- 1回目と同じく、撮影のときだけ `30-rhythm-play.jsx` に仮の2か所を入れてビルドし、撮ったあと元に戻した(コミットしていない)
