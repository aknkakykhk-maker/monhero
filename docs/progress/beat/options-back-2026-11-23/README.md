# モンヒロビートのオプションで「戻る」が押せない(再発)・台帳 r1119-147

## 何が起きていたか

- 直す前: `president-landscape.png`(社長の iPhone・🔄横)。画面全体が状態表示の高さ(47pt)ぶん上へずれ、
  左上の「戻る」が時計・電池の下に入って押せない。下端に黒い帯(ページの外)が出ている
- 黒い帯はアプリの紺ではなくページの外の色 → 器ではなく**ページ全体(見えている範囲)がずれた**と分かる

## 再発の原因

| これまでの直し | 防いだ道 | 今回すり抜けた理由 |
| --- | --- | --- |
| 2026-09-12 🔄横の器に安全域の余白 | 器の左(=端末の上)を状態表示の外へ寄せる | 器は正しい。ずれたのはページ全体 |
| 2026-11-02 / 11-11 ページのずれの見張り(10-core.jsx `MH_PAGE_OFFSET_GUARD`) | 回転・キーボード・拡大のあとのずれを0へ戻す | 「入力中は戻さない」が `INPUT` を全部入力中と数えていた |
| 2026-10-14 判定ラインのスライダー(横でも出す) | — | スライダー(`input type=range`)を触るとフォーカスが残り、見張りが止まったまま。保存を押しても戻らない |

## 直したこと

1. 見張りの「入力中」を、キーボードが出る欄だけにした(スライダー・チェック・ボタンは入れない)
2. オプションのスライダーは指を離したらフォーカスを外す。開いた時・タブを替えた時・保存した時にもずれを確かめる
3. 端末を回した横で、オプションの左右に安全域(切り欠き)の余白を取る(新しい検査で見つけた)
