# r1115-021 / r1115-106 観戦をプレイ画面と同じ見た目に: 止め絵と突き合わせ

左がプレイ画面(演奏している人)・右が観戦(同じ曲・同じ時刻・同じ撮影の瞬間)を並べた止め絵:
spectate-side-390.png(縦390)・spectate-side-320.png(縦320)・spectate-side-844.png(横844)。観戦だけの止め絵: spectate-road-390/320/844/rot.png(🔄横)。
前(旧): spectate-now-iphone.jpg

| 項目 | 同じになったか | どうやって |
| --- | --- | --- |
| レーン(奥行き・台形・格子・縁の白線) | 同じ | プレイ画面と同じ枠(data-rhythm-play-area)・同じ CSS・同じレーンの部品。道の幅の設定も同じ |
| ノーツの色・形 | 同じ(今回の直し) | プレイ画面を開くときと同じ順で、設定のノーツの色の組・形を描き手に当ててから作る(前は既定色のままだった)。同じ描き手(2D版)・同じ式の位置 |
| 長押し(HOLD)・スライド・フリック | 同じ | 同じ描き手 drawNote。押さえている間は判定ラインに乗り、終わりで弾ける。取れなかった帯は灰色で終わりまで流れる |
| モンスターノーツ | 金色の見た目は同じ・絵は未対応 | 金色のモンスターノーツの見た目は同じ。顔の絵は演奏する人のマスモンで、観る側の端末には無いため出ない(次の課題) |
| 判定ライン・判定の帯(GOOD/MARVELOUS の幅) | 同じ | 同じ要素・同じ式(rhythmJudgmentBandLayout)・同じ位置の設定 |
| 判定の文字(MISS など) | 同じ | プレイ画面と同じ要素(data-rhythm-judgment-text)と CSS |
| コンボ | 同じ | プレイ画面と同じ部品(RhythmHudCombo) |
| ライフ(♥・帯・数字・DOWN) | 同じ | プレイ画面と同じ部品(RhythmHudLife) |
| 叩いたときの光 | 同じ | プレイ画面と同じ部品(rhythmSpawnHitEffect) |
| 背景・ジャケット・スキン | 近い(控えめ段のジャケット背景) | 同じ背景の CSS・ジャケットの絵を同じ描き方で敷く。ライブの背景(サーチライト・光の粒・WebGL)は出さない。演奏する人の設定ではなく、観る人自身の設定の見た目 |
| 上の HUD(スコア・順位・曲名) | 違う(意図) | 観戦では「上に観戦の帯・下に参加者の札」。順位とスコアは札に出る |
| 1.5秒おくれ | 札で明示 | 道の右上に「1.5秒おくれ」 |
| 軽くする設定・省エネ | 今の2D描きへ戻る | rhythmWatchUseFlat |
