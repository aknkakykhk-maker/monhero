# r1115-021 / r1115-106 観戦をプレイ画面と同じ見た目に: 止め絵と突き合わせ

撮り方(撮り直し・窓口の3点に対応):
- 左がプレイ画面(演奏している人)・右が観戦。**同じ曲「トリコ」HARD・同じ時刻の1コマ**を並べた(spectate-side-390.png 縦390 / -320.png 縦320 / -844.png 横844)。
- ① 色: **ノーツの色の組は NEON(既定の STANDARD ではない組)** を、演奏する人・観る人の両方の設定にして撮った。縦390=TAP+FLICK(矢印のピンク)、縦320=SLIDE(紫の帯)+TAP、横844=HOLD(緑)+TAP+FLICK(ピンク)。
- ② 時刻と位置: 観戦は設計で1.5秒おくれ。同じ時刻の絵にするため、演奏側の絵を撮った曲の時刻 tA に、観戦側の曲の時刻が届いたところで、描画を止めて1コマ撮った(観戦側の時刻 − tA は約 +5〜10ms)。判定ラインの高さの比は 縦390: 0.798(プレイ) / 0.797(観戦)、縦320: 0.796 / 0.795、横844: 0.795 / 0.793。観戦の枠は上下の帯のぶん低いが、ラインの位置は枠の高さに対する比でそろえてあり、ノーツの高さの比(例: 縦390のタップ 0.28 / 0.285)も一致する。
- ③ 演奏側: ロボット(本物のタッチ)で演奏している状態(♥ライフ・コンボ・スコアあり。「0点・DOWN・赤い縁」ではない)。
- 観戦のゲージ・コンボの数字が左右で少し違うのは、観戦が1.5秒おくれの値を出すため(同じ時刻の1コマでも、数字は届いた最新の値)。

| 項目 | 同じか | どうやって・理由 |
| --- | --- | --- |
| レーン(奥行き・台形・格子・縁の白線) | 同じ | プレイ画面と同じ枠・同じ CSS・同じ道の幅 |
| ノーツの色・形(TAP/HOLD/SLIDE/FLICK) | 同じ(止め絵で確認) | プレイ画面を開くときと同じ順で、ノーツの色の組・形を描き手に当てる(前は既定色のままだった)。同じ描き手・同じ式の位置 |
| 長押し・スライド・フリック | 同じ | 同じ描き手。押さえている間は判定ラインに乗り、終わりで弾ける。取れなかった帯は終わりまで灰色 |
| MISS のノーツ | 直した | MISS の知らせは表示より1.5秒早く届くので、判定ラインに着く前に灰色になっていた → ラインを過ぎてから灰色にする |
| 金色のモンスターノーツ | 違う(意図) | 観戦では顔の絵は出さず、金色のノーツだけ(社長の決め)。止め絵の金色のタップがそれ。演奏側が顔のマスモンを持っていない試験の環境では、演奏側は青いタップのまま |
| 判定ライン・判定の帯(GOOD/MARVELOUS の幅) | 同じ | 同じ要素・同じ式・同じ位置の設定 |
| 判定の文字(MARVELOUS など)の部品・大きさ・位置 | 同じ | プレイ画面と同じ部品(RhythmHudJudgment)・同じ CSS |
| 判定の文字の「虹色」と「FAST / SLOW」 | 同じ(社長の決め「印を足して同じにする」で実装) | 演奏する人が、判定の番号 j(並びは変えない)とは別の配列 jx に「ぴったり=1・SLOW=2・FAST=4」の印をノーツ番号つきで足して送り(印のある判定だけ・上限つき)、観戦がプレイ画面と同じ部品に渡す。止め絵は縦390・横844で、左右とも虹色の MARVELOUS と SLOW。古い版の人から印が来ないときは、金色の MARVELOUS のまま(落ちない。検査あり) |
| コンボ | 同じ | プレイ画面と同じ部品(RhythmHudCombo) |
| 「+1 EXCELLENT」などの流れる字・「+1MARVELOUS」の残像 | 出さなくした(直した) | プレイ画面に無い、観戦だけの表示だったので外した(判定の数は下の枠で見える) |
| ライフ(♥・帯・数字) | 同じ | プレイ画面と同じ部品 |
| 叩いたときの光(光の柱・炎・粒) | 同じ(直した) | プレイ画面と同じ部品(rhythmSpawnHitEffect)に、プレイ画面と同じ引数(フリックの向き・長押しの終わり・モンスター)を渡す。止め絵の縦390・縦320で、左右とも同じレーンに同じ光の柱が立っている |
| 背景・ジャケット | 近い | 控えめ段のジャケット背景。ライブ背景(サーチライト・光の粒・WebGL)は出さない。観る人自身の設定の見た目 |
| 上の HUD(スコア・順位・曲名) | 違う(意図) | 観戦は「上に観戦の帯・下に参加者の札」 |
| 1.5秒おくれ | 札で明示 | 道の右上に「1.5秒おくれ」 |
| 軽くする設定・省エネ | 今の2D描きへ戻る | rhythmWatchUseFlat |
