# r1115-165 マルチの曲選びが、前に選んだ曲の位置から開く(2026-11-15 テンポくん4)

社長: マルチ(MULTI LIVE)の曲選びで、開くたびに(次の曲を選ぶたびに)いちばん上の曲に戻される。

## 原因と直し

- 原因: マルチの曲選びは、選んでいる曲を画面の中だけで持っていて、曲選びを開き直すと空(=いちばん上の曲)に戻っていた。一覧の位置も毎回まん中の先頭から始まっていた
- 直し:
  - 選んだ曲を新しいキー `mh_rhythm_multi_last_song_v1` に曲の id だけ覚える(既存のキーは触らない・おまかせは覚えない・壊れた値は使わない)。台帳 `docs/spec/SAVE_DATA.md` と錠 `tools/boot/saved-value-lock.json` に1行ずつ
  - 曲選びの部品 `RhythmSongSelect` に `scrollToSelected` を足し、開いたときに選んでいる曲の行が一覧のまん中に来るよう縦だけ寄せる(マルチだけが使う。ソロは今までどおり見ていた位置へ戻る)
  - 並べ替え・ジャンルでその曲が一覧に無いときは、いちばん上のまま
- 見張り: `tools/mode/rhythm-multi-select-keep-check.js`(本物の画面で部屋を作り、曲を選ぶ → 曲選びを開き直す → 前の曲が選ばれ、その行が見えているか)
