# r1115-161 モンヒロビートの観戦: 本番(iPhone)で2Dになる直し・入らずに観戦(2026-11-15 テンポくん4)

## ② 2Dになっていた原因と直し

- 原因: 観戦は、音ゲー設定に「軽くする」「演出量 最小」(見た目のおまかせ「軽い」も最小)「省電力」のどれかが入っていると、#6460 の前の2D描き(`RhythmWatchLaneFlat`)へ落としていた。プレイ画面はこの3つでも奥行きの道のまま(光・影を減らすだけ)なので、観戦だけ食い違っていた。社長の止め絵にある「1.5秒おくれ」の札は #6460 で入った物なので、本番は新しい版のままこの条件で2Dが選ばれていた
- 直し: 2Dへ落とすのは「描き手が作れないとき」だけ(`rhythmWatchUseFlat`)
- 見張り: `tools/mode/rhythm-multi-spectate-check.js`(設定で2Dへ落ちない)。撮るときだけ設定を重ねる `MH_WATCH_SETTINGS`

## ① 入らずに観戦だけ

- 「部屋に入る」の一覧(曲えらび中・人を待っている部屋)の各部屋に、「入る」と別に「観戦」
- 観戦は見るだけ(hb を送らない・次の曲にも入らない)。演奏していなければ「次の曲が始まるのを待っています」で待ち、始まるとそのまま見える
- 公開の一覧から観戦したときは、観戦の画面の上に「この部屋に入る」(押すと観戦をやめて、いつもの入る処理で部屋へ入る)
