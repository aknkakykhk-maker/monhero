# r1115-204 観戦でノーツが出ない・進みの棒が 0:00・判定の数が「-」・曲が待機のまま 突き合わせ表

止め絵は `MH_SHOT_DIR=docs/progress/beat/report-1115/r1115-204 node tools/mode/rhythm-multi-spectate-start-check.js` で撮った(偽の通信・本物の演奏画面・390×844 の縦と 844×390 の横)。
社長の本番の止め絵: `spectate-no-notes-president.png`。

## 原因

観戦の画面は、**見ている1人**から1秒ごとに届く細かい知らせ(曲の位置・判定の数・ライフ)で、譜面・進みの棒・判定の数を出し、観戦の曲もその位置で鳴らす。
この知らせは、観戦の人の「見ています」を聞いた演奏者だけが送る。点・コンボ・順位は別の知らせ(3秒ごと)で全員から届くので、そちらだけ動いていた。

1. **見ている人から細かい知らせが来ないと、ずっと止まったままだった(本番の主な原因)。** 見ている人の端末が古い版のアプリ(本番の端末は自動では新しい版に替わらない)や、観戦を許していない人だと、
   細かい知らせは来ない。観戦の画面はそれでも同じ人を見続け、ノーツ・進みの棒・判定の数・曲が止まったままだった。曲は位置が分からないと鳴らし始めないので、待機の曲が流れ続けた
2. 曲えらび中から観戦していると(本番の社長と同じ。部屋の一覧の「観戦」から入った)、始まりの合図で送る「見ています」が、まだ演奏に入っていない端末で捨てられることがあり、次に送るのは10秒後だった

人の部屋と助手を呼んだ部屋で、観戦に届く中身は同じ(助手は演奏中の点を持たないので観戦の行に入らない)。検査は助手(ソラシド)を呼んだ部屋で確かめた。

## 直したこと(観戦する人の端末だけ。演奏する人の端末・通信は変えない)

- 見ている人から細かい知らせが届かないあいだ、「見ています」を2秒ごとに送り直す(届いたら今までどおり10秒ごと)
- 8秒たっても届かなければ、自分で選んでいないときは、届く人へ自動で切り替える
- だれからも届かないときは、止まった画面のままにせず「この部屋の譜面は届いていません(アプリの版が古いときなど)。順位と点は見られます」と出す(自分で選んだ人なら「この人の譜面はまだ届いていません」)。また届くと消える
