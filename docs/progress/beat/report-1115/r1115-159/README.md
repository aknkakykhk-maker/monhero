# r1115-159 モンヒロビート: 曲の途中で速さが変わる所の洗い出しと案(2026-11-15 テンポくん4)

社長「モンビーで曲の速度が変わったりするやつがあると思うけど、速度の変化に滑らかさがなくて飛んだような描写に見えるやつがある。そのへんもっとわかりやすくしてほしい」

## 洗い出し(機械で全曲・全難易度を数えた)

流れる速さが曲の途中で変わるのは、速さの表(`scrollChanges`)を持つ **4曲だけ**。どれも 5難易度と HELL が同じ表を使う。
ほかの曲は速さが一定(BPM が変わっても、ノーツの流れる速さは変わらない)。4曲ともイベント対象ではない。

| 曲 | 変わり目 | 一瞬で速さが変わる所 | いちばん「飛んだ」に見える所 |
| --- | --- | --- | --- |
| Sheriruth | 6 | 6(82.06〜83.09秒 止まる⇔動くを3回) | 82秒台の止まる・動く |
| Grievous Lady | 23 | 2(ほかは「だんだん」) | 96.2〜96.9秒 戻る・飛ぶの往復(10〜15倍)・134秒(6〜9倍)・19.9秒(4倍) |
| Evans | 21 | 11(止まり → 1倍 など) | 84秒・89秒の行って戻る(約2.7倍) |
| LAMIA | 19 | 6 | 31.2秒の駆け込み(止まりのあと 7倍で0.3秒)・55.6秒 1倍→1.5倍 |

「飛んだように」見える原因は3つ:

1. **止まる⇔動くが一瞬で切り替わる**(Sheriruth・Evans・LAMIA)。全部のノーツが同時にガクッと止まり、ガクッと動き出す
2. **ごく短い間に道の大半を動く**(Grievous Lady 96秒・134秒、LAMIA 31秒)。1コマ(60fps)で道の1〜2割を動くので、間が抜けて瞬間移動に見える
3. **予告がない**。いつ変わるかが画面のどこにも出ないので、不意打ちになる

## 案(どれも譜面・判定の時刻・既存の解析は変えない。観戦の画面にも同じ物を出す)

比べ表: [proposals.png](proposals.png)

- **A 予告(推奨)**: 変わる約1秒前に判定線の上へ「SPEED UP / SLOW / STOP / BACK」の札、道の縁の色を変える。速さの表から自動で出す
- **D 残像(推奨)**: 1コマで大きく動くときだけ、前のコマの位置から今の位置へ薄い尾を引く
- B 切り替えを滑らかに: 段差の前後0.15秒をだんだんにする(「画面が止まって動く」のキレが弱まる)
- E ノーツに速さの印: 誤解されやすいのですすめない

おすすめは **A+D**(演出の止まる・飛ぶ・戻るはそのまま、「いつ来るか」と「どこへ動いたか」を見せる)。

## 撮り方

`tools/mode/rhythm-slowmo-shot.js`(playwright の読み込み先だけ `require('playwright')` にした写しで実行)
`ONLY=STANDARD SONG=LAMIA DIFF=HARD T=30.9 FRAMES=10 STEP=67 W=390 H=844`。速さは `rhythmScrollBuild` の表から計算した。
