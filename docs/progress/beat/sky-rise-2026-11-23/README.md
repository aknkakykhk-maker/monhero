## 見てわかったこと

- 違いが出るのは**道の奥(画面の上の方)だけ**。手前半分は案A〜C・前がそろって同じ動き、今も前より少し低いだけ。止め絵では差は小さく、動画の上の方で見える
- 案A・B は上端の近くで空中ノーツが「急に浮き上がる」ぶん、画面の上での下りが一時ゆっくりになる(横で地上の約0.3〜0.35倍。今は一定の約0.56倍)。そのあとは前の勢いで下りる
- 「遅く見える」のもう半分は、空中ノーツが画面にいる時間が前より約0.33秒長いこと(横)。見え始めを地上とそろえる限り、どの案でもこの長さは変わらない
- 参考 1/2 は道の奥で今より低く、上がり方を早める狙いに合わない(比べのためだけに載せた)
- 地上と空中が重なる・空中が道を突き抜ける絵は、どの案・どの向きでも見当たらない(下の止め絵)

## 撮り方

`tools/mode/rhythm-note-appear-scan.js` に `SKY_LIFT=old|now|rise:<割合>` を足した(配る `data/rhythm-mode.js` をそのブラウザの中でだけ差し替える。本体は変えない)。

```
SKY_LIFT=rise:0.25 SONG_ID=beyond_the_same_sky FROM=46.0 TO=49.0 STEP=33 SHOT_EVERY=1 OUT=<置き場> node tools/mode/rhythm-note-appear-scan.js
W=390 H=844 で縦
```

## 選ばれたら入れる所

`rhythmSkyLiftRatio`(`data/rhythm-mode.js`)の式、GPU の帯のシェーダー(`proj` の lift・上がり切る所の uniform を1つ足す・`skyK` の分母)。
演奏画面の空中の面(`30-rhythm-play.jsx` の3か所)は同じ関数を通るので、そのまま追従する。入れたら GPU と 2D の描き比べ(`rhythm-gpu-band-check.js`)も回す。
