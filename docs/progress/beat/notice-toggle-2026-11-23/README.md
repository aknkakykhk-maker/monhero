## 直し方(`monster-hero/src/parts/29-rhythm-screens.jsx`)

- ボタンに状態の字を足した: 横「💬 ひとこと 入▲ / 切▼」、縦「💬入▲ / 💬切▼」(縦は幅52pxのため「ひとこと」は省く)
- 「入」は明るい札、「切」は灰色の札。押したときの動き・保存(mh_rhythm_select_view_v1 の noticeOpen / noticeOpenShort)は変えていない
