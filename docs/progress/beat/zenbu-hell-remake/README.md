## 作り方

- `rhythm-hell-mix.js` の書く先を `zenbu-hissatsuwaza-v4` に移した(旧の `-v3-hell` は消さずに残し、使わない)
- `hellDensity:1.4`(拾う音を広げる)・曲の一覧の `sustainScale.HELL:0.6`(長押しを減らして、押さえている間に鳴っていた16分の刻みをタップへ戻す)・`phrases:['ground']`・precision 外し
- 書いたあと空のスライド12本・タップ3個を同じ時刻・位置の地上へ下ろした
- `rhythm-held-cross.js --fix` で押さえ中の交差 13→7。残りの6個は交差するタップを抜き、モンスターノーツ4番(90.60秒)は交差していたので抜いて 90.91秒のタップへ移した
- 長押しは減ったが(43→26・31→18)、その分が速い刻みのタップになり、密度の山が上がった

## 切り替えとスコア

- 新しい JS を読んだ時から新しい HELL(読み込み中に譜面が入れ替わることはない)
- ランキングの鍵: 新しい HELL は `Rhythm-zenbu_hissatsuwaza-HELL-r2`(`RHYTHM_CHART_RESETS`)。旧の行はそのまま
- 自己ベスト: `mh_rhythm_best_chart_reset_v1`(旧の v1・v2 は書き換えない)
- イベント・合算の集計は `docs/sql/rankings/RHYTHM_CHART_RESET_APPLY.sql`(窓口が流す。回数ボーナスは旧の回数も数える)

## 社長の追加「特別な感じ」(A＋B＋C＋D 全部・2026-11-23)

小節は 1.241秒(BPM 193.37・拍の頭 1236.1ms)。区間の中にあったノーツは抜いて置き直した(長押し・スライドは区間にかかる物ごと)。

- **C ききの連打**(小節66〜71・83.15〜90.52秒): 左右交互。最初の2小節は8分、あとの4小節は16分。真ん中(左4・右6)から1小節ごとに外へ広げて端(左0・右10)まで。同じ手は155ms おき(90ms の決まりの内側)。最後の右の1打は、次の B の頭と78ms で続くので抜いた
- **B 地上で描く大技**(小節26〜29・33.51秒〜 / 小節72〜75・90.60秒〜): 2小節ずつ、片手で「く」の字の大きなスライド(端→真ん中寄り→端)、反対の手は8分の刻み(左右を入れ替えて2回)。モンスターノーツ4番(90.91秒)は同じ時刻の右手の刻みへ付け直した
- **A 必殺技の決め**(小節90〜93・112.94〜117.90秒): 8分の同時押しを端から真ん中へ寄せる(左0→1→3→4・右10→9→7→6)を繰り返し、最後の拍(117.59秒)に左右半分ずつの幅6の同時押しで締める
- **D 演出**(ゲーム本体): A の区間(`RHYTHM_CHART_SPECIAL_FX`)に入ると道が赤金に染まり、「必殺技！」が一度だけ出る。見た目だけで判定・スコアは変わらない。演出「最小」では道の色は付けず文字だけ
