# スライドの形の種類を増やす案(台帳 r1119-129・追跡表 r1123-016)

社長「モンビーのスライドは曲線もあったからいまのままでもっとバリエーションを増やす案のほうが良さそうだ」。
全曲を自動で曲線にする作業(r1119-127)は取り消し済みで、作りかけの変更は入れていない。
**この資料は案だけ。ゲーム本体・譜面・譜面を作る道具はまだ変えていない**(足したのは止め絵を撮る道具 `tools/mode/rhythm-slide-shape-sheet.js` だけ)。

## いまのスライドの曲線の使われ方(配信中の全譜面・100曲・スライド 4,935本)

曲線(ease: in・out・inout)は約90曲で使われていて、全区間の約2割に付いている。
付け方は譜面を作る道具(`tools/mode/rhythm-chart-v3-generate.js` の `applySlideEase`)が決めていて、次の1通りだけ:

- 向きが変わる点(始点・終点・折り返し)の前後だけ、ゆっくり動かす(両端とも → inout の S 字、始まりだけ → in、終わりだけ → out)
- 同じ向きへ続く点は直線のまま。1秒に6レーンより速い区間も直線のまま

スライドの途中の点(26,957個)は、つなぎ方で分けると次のとおり。

| 途中の点のつなぎ方 | 数 | 割合 |
| --- | ---: | ---: |
| 横へ動かない区間とのつなぎ(幅が変わる点・まっすぐ伸びる所) | 20,848 | 77.3% |
| 同じ向き・曲線あり | 2,258 | 8.4% |
| 折り返し・曲線あり(S 字) | 1,196 | 4.4% |
| **同じ向きで速さが変わる・直線(点で折れる)** | 1,096 | 4.1% |
| **折り返し・直線(とがる)** | 1,010 | 3.7% |
| 同じ向き・同じ速さ(折れない) | 549 | 2.0% |

社長の言う「カクカク」は、太字の2つ(合わせて約8%)に当たる。

## 案

### 案A いまの曲線(in・out・inout)の組み合わせを増やす【ゲーム本体は変えない】

ゲーム本体はすでに3種類の曲線を描けるので、譜面を作る道具に「形の型」を足し、曲の流れで使い分ける。

- **弧**: 1区間だけ out。斜めに飛び出し、横へ寝る(歌の伸ばし・フレーズの終わり)
- **大きな S**: in → out。点で止まらず、大きく横切る(盛り上がりへの入り)
- **波**: inout を続ける(ゆれる歌・サビの長い音)
- **行って戻る**: out → in。丸く折り返す(呼びかけと返し)
- **ジグザグ → 曲線**: 速い折れのあとに S 字で落ち着く(山場の締め)

いまの「速い区間は直線」の上限(1秒6レーン)は守る。曲線は真ん中で平均の1.5倍の速さになるため。
押さえ中の交差・手の決まりの検査は、いまと同じ物を回す。

### 案B 新しい曲線の種類「通り抜け」を足す【ゲーム本体に1種類足す】

点に「通り抜け」の印を書いた所だけを、点を通る滑らかな曲線で結ぶ(行き過ぎない3次の曲線)。
同じ向きへ進み続ける点では止まらずに通り抜け、向きが変わる点では行き過ぎない。

- 「いま①」と同じ点でも折れ目が出ない(`through-compare-*.png`)
- 印を書いていない譜面(配信中の全譜面)は、見た目も判定も1点も変わらない
- 曲線の式は、取り消した r1119-127 の作りかけ(検査済み)を使い回せる

### どこから使うか(案A・案B 共通)

- **新曲と、作り直してよいと決まった譜面からだけ使う。** 譜面を作る道具の作り方の番号(`CHART_REVISION_CODE_LATEST`)を1つ上げる
- 配信中の曲の譜面・既存の解析は作り直さない(⑩-2)。公開中の譜面は `rhythm-released-chart-lock-check.js` が見張っているので変わらない
- **開催中のイベント3曲は触らない**(BRAND NEW SKY・全部必殺技でつ( `･ω･)・きみ待ち♡ループ)
- 空中スライドは横の位置だけが曲がり、高さの変わり方は今までどおり。空中の通り道の決まり(2026-10-22)は、いまの検査で見張る

### 判定の的(案A・案B 共通)

- 帯(2D・GPU)・追う位置・速さの上乗せは、どれも本体の `rhythmSlideExpectedLane`・`rhythmSlideLaneSpeedAt` を通る。見た目と追う位置はずれない
- 止め絵の桃色の点は、帯の真ん中を通っている
- 案B は、この2つの関数の中に「通り抜け」を足すだけ。描き方の側は変えない

## 社長に選んでもらうこと(選択式)

1. **案A+案B(推奨)**: いまの曲線の組み合わせを増やし、「通り抜け」も足す。新曲から使う。ゲーム本体が変わるので、ミハリの確認を通す
2. **案Aだけ**: ゲーム本体は変えず、譜面を作る道具だけ強化する。新曲から使う。点で折れる所(約4%)は新曲でも少し残る
3. **案Bだけ**: 「通り抜け」だけを足し、同じ向きで折れる所に使う。形の種類は増えない

案A では、譜面もゲーム本体も変わらないので、更新履歴とヘルプには書かない。新曲の告知に含める。
案B では、ゲーム本体が変わるが、プレイヤーに見えるのは新曲から。告知はその曲と一緒にする。
