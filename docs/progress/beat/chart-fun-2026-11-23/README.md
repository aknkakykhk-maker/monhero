# Beyond the Same Sky の MASTER・HELL を「遊んで楽しい」譜面に作り直した(2026-11-23・ビート・台帳 r1119-116・追跡表 r1123-004)

社長「ただ同じようなノーツが同じように流れてくるだけでつまんない譜面になってた。スライドやホールドもほとんどなし」「結構きあいいれてつくったから譜面も楽しめる譜面にしてほしい」。
前の組み直し(#7232・歌い分け)と #7261(幅を混ぜる・HELL の段変え)の上に、**曲の展開ごとの手触り**を足した(道具 `tools/mode/rhythm-vocal-split-chart.js` の `FUN`・`ROLE`・`funPass`)。
歌い分け(女声=右手・男声=左手・2人は両手)・押さえ中の交差0・親指2本の押せない0・手の決まり・段変えの上限はそのまま。ランキング・自己ベストは触っていない(r1119-105)。

## 何が楽しくなったか

| 展開 | 前 | 後 |
| --- | --- | --- |
| Aメロ | 歌う手のタップが1拍ずつ並ぶだけ | 歌のメロディの上下に沿って**歌う手がスライド**(3〜5音を1本に)。言葉が空く所は**伸ばしのホールド**。歌う手が帯を押さえている間、**反対の手が伴奏を刻む**(帯+刻み) |
| 掛け合い(1行ずつ) | 左右の受け渡しのタップ | 受け渡しと行末のフリックはそのまま。行の伸ばしにホールド・ときどきスライド |
| サビ | 歌う手のタップの連続 | MASTER: メロに沿う幅3のスライド+反対の手の8分の刻み。HELL: 空中のフレーズ(空中タップ)を主役に残し、3本に1本を**空中スライド**に |
| 2人・ハモり | 左右対称のホールド | 左右対称のホールドを**左右へ開く・閉じる鏡写しのスライド**に(交互)。区間の締めは**両手の外向きフリック**。両手の言葉の連なりは両手のスライド |
| 落ちサビ・静かな所 | ぽつぽつのタップ | 長めのホールドとゆっくりのスライド(帯の割合 9%→21%・原曲 MASTER) |
| 間奏 | 左右交互 | そのまま(息つぎ) |

## 足した検査

`tools/mode/rhythm-width-variety-check.js` に、公開中の MASTER・HELL で ①タップが9割を超える ②帯の割合が同じ曲の EXPERT より低い を NG にする見張りを足した。
前からある55譜面は控え(`tools/mode/rhythm-chart-mix-baseline.json`)で許す。新曲・組み直した譜面は控えに足さない。直す前の Beyond 4譜面はこの検査で NG になる形だった。
