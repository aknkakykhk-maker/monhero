# 曲鑑賞(オートプレイ)の案(r1119-112・2026-11-22 ビート)— 社長に選んでもらう

いちかさんの案「オートプレイで曲鑑賞。ノーツも見られる」。曲を選ぶと、譜面のノーツが自動で叩かれながら曲が最後まで流れる。
**まだゲームには入れていない。** 止め絵は main の本物の画面に見本の部品を差し込んで撮った(黄色の縁 = 案で足す所)。
iPhone の切り欠きの余白あり(縦 上47・下34 / 横 左右47・下21)。曲は「MF × ICHIKA MIX」の HARD(イベントの曲は使っていない)。

- 並べた1枚: 縦 [sheet-tate.png](sheet-tate.png) / 横 [sheet-yoko.png](sheet-yoko.png)(上の段 = 曲えらびの入口、下の段 = 鑑賞中。左から いま・案A・案B・案C)
- 1枚ずつ: `<tate|yoko>-<select|play>-<now|A|B|C>.png`
- 撮り直し: `node docs/progress/beat/auto-listen-plan/shoot.js`

## 案ごとの違い

| | 案A 難易度の横に🎧 | 案B 曲の詳細から | 案C 鑑賞の一覧 |
|---|---|---|---|
| 入口 | 「決定」の右に小さな「🎧 鑑賞」ボタン。選んでいる難易度をそのまま流す | 曲の行の「ⓘ 詳細」→ 詳細の窓で難易度を選んで「🎧 この譜面を鑑賞する」 | 一覧の上に「🎵 ライブ / 🎧 鑑賞」の切り替え。鑑賞側では決定が「🎧 鑑賞スタート」、ランダムが「🔁 連続」 |
| 鑑賞中の見せ方 | 今の演奏画面のまま。スコアの欄を「🎧 鑑賞中」に。判定の文字・コンボは出す。ライフ・運のポイントは隠す | 判定・スコア・コンボを消して、ノーツと曲だけ。下に再生の帯(-10秒 / 止める / +10秒・どこまで流れたか) | 上の欄をたたんでノーツを広く。上に難易度の切り替え(切り替えると最初から)、右下に「次の曲」(連続で流す) |
| 止める・送る | 今の Ⅱ(再開・最初から・やめる) | 送る・戻すができる(いちばん自由) | Ⅱ と「次の曲へ」 |
| 作る重さ | 軽い(ボタン1つと演奏の旗) | 中(詳細の窓と送る・戻す。送ったときのノーツの並べ直しが要る) | 重い(曲えらびに鑑賞の側を作る・連続再生。曲えらびのファイルを大きく触る) |
| ひとこと | いちばん早く出せる。遊ぶ流れのすぐ横 | 「聴く・見る」に寄せた形。練習で同じ所を何度も見られる | BGM のように流しっぱなしにできる。遊ぶ画面と分かれて迷いにくい |

どの案でも共通:
- ランキング・自己ベスト・ビートP・周回・ミッション・相棒の成長には載せない(結果の画面は出さず、終わったら曲えらびへ戻る)
- 流せる譜面は、その人が遊べる譜面だけ(鍵のついた EXPERT・MASTER・HELL は鍵のまま)。買っていない曲は流せない
- 保存するものは増やさない(増やすなら新しいキー。例: 連続の ON/OFF を `mh_rhythm_listen_loop_v1`)

## 日課に使うなら(社長が「あとで決める」。今回は作らない)

- **済ませられるもの**: 「1曲遊ぶ」系の日課(レイドの参加・デイリーミッションの曲数)だけに数える。高スコア・フルコンボ・ランク条件のミッションは対象外
- **スコア**: 手で遊んだときの 3割(上限は Sランクに届かない値)。レイドのダメージも 3割
- **報酬**: ビートP・経験値は 0 か 1割。1日に数えるのは 3回まで(手で遊ぶ人より得にならないように)。ランキング・自己ベストには引き続き載せない
- **ミッションへの響き**: 曲数のミッションは早く終わる。いまの「◯曲遊ぶ」の値を見直すか、オートは半分として数えるかを一緒に決める
