## どの行で出すか

第8話(`FLOWER3_EP8`)の **5〜7行目**(台詞は変えていない)。

| 行 | 台詞 | 一枚絵 |
| --- | --- | --- |
| 4 | パンドラ「……歌えた。外で、ちゃんと」 | 出さない(いつもの夜の広場とパンドラ) |
| **5** | もも「ぱんぷきん、ステップいくよ♡」(説明「最後は『きみ待ち♡ループ』。広場のみんなが跳ねる」・曲が きみ待ち♡ループ に替わる) | **出る** |

理由: 3曲目は5人(3人+パンドラ・ぱんぷきん)が最後にそろってステージに立つ所で、ライブのいちばん盛り上がる所。
1曲目(みゅあ)・2曲目(きき+パンドラ)はまだ全員がそろっていない。8行目からは観客({name})へのお礼と閉幕の案内に移るので、そこで絵を閉じる。
