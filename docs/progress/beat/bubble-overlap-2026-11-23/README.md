# 曲選び(横)の助手のひとことが「決定」に重なる(r1119-140・2026-11-23 テンポくん)

社長の写真: `president-landscape.png`(iPhone の🔄横・イベントで絞り込み・きみ待ち♡ループ)。

## 原因

横の右の欄は「決定」の段を欄の下に貼り付けている(sticky)。iPhone では HIGH SCORE の札などが検査の端末より高く、
欄が十数px あふれて、貼り付けた決定の段がすぐ上の一言にかぶさっていた。欄の高さの決め打ち(300px 以下なら一言を出さない)では
この差を見分けられなかった。

## 直し方(`monster-hero/src/parts/29-rhythm-screens.jsx`)

- 横のとき、右の欄があふれていないかを実際に測る(欄の大きさ・中身の高さが変わったら測り直す)
- あふれたら、上を詰める: HIGH SCORE の札の「MAX COMBO」の行を畳み、難易度の札を 48px → 44px
- それでも入らないときだけ、一言を出さない(前の「低い欄では出さない」と同じ扱い)。高さの決め打ちはやめた
- 縦画面は何も変えていない。💬▲▼ のたたみもそのまま
