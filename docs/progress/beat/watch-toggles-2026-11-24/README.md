# 曲鑑賞の画面: 判定とコンボを別々に入/切・操作を隠す(r1119-162)

社長の写真: [`shacho-watch-hell.png`](shacho-watch-hell.png)(縦・全部必殺技でつ(`･ω･) HELL 鑑賞中・下の操作欄に「判定・コンボ 入」が1つ)

## 何を変えたか

- 「判定・コンボ」の1つのボタンを、「判定」と「コンボ」の2つに分けた。判定を切ると MARVELOUS などの文字と FAST・SLOW が消え、コンボを切るとコンボ数が消える。
  覚え先は新しいキー `mh_rhythm_listen_judge_v1`・`mh_rhythm_listen_combo_v1`。値が無いときは前のまとめたキー `mh_rhythm_listen_hud_v1` を読む(前のキーは読むだけで書かない)。今の既定(どれも入)は変えていない。
- 「操作 隠す」ボタンを足した。押すと下の操作欄(-10秒・止める・+10秒・判定・コンボ・隠す)と右上の ✕・鑑賞の札が消え、上の表示がふつうに遊ぶ時と同じ形(スコア・ライフ・ポーズ)になる。動画を撮るとき用。
  画面のどこかを叩くと操作が戻る(戻すための見た目は何も出さない。動画に映らないように)。隠したかどうかは覚えない(鑑賞を開くたびに出た状態から)。
- 横は右の列の幅を 76px → 96px にし、-10秒・+10秒と判定・コンボをそれぞれ横に2つ並べた(列の高さは前とほぼ同じ)。縦は下の1行に6つ並べ、幅を分け合う(320幅でも1行)。
- ふつうに遊ぶ時のオプション(`mh_rhythm_settings_v1`)・判定・スコア・記録は変えていない。
