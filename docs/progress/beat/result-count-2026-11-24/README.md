## 1. 見えなかった理由(直した・PR #7458)

#7390(11/23 12:06 に main へ入った)の数え上げは、次のどれかのとき**初めから止まった形**で出していた。

| 止まる条件 | 社長の端末で当たりうるか |
| --- | --- |
| iPhone の「視差効果を減らす」(= 端末の動きを減らす `prefers-reduced-motion`) | **いちばん見込みが高い**。入っていると、演出の設定に関係なく数え上げも判定の行の入りも全部止まっていた |
| 演出量「最小」 | 入っていれば止まる |
| 軽量モード(重いときに自動で入るものを含む) | 入っていれば止まる |
| 練習 | 社長の回は本番なので当たらない |

横向き・FC でない回では止まらないことを確かめた(下の検査)。数え上げは 2.4 秒で終わり、タップでも飛ぶので、結果が出てから少し後に見ても動きは見えない(これは作りどおり)。

**直したこと**(社長の決定・r1119-156 追記)

- 数え上げと結果の出方は、演出量「最小」・軽量モード・動きを減らす・視差効果を減らすに**関係なくいつも動く**(練習は今のまま止まった形)
- 止めたい人向けに、演出のこまかい設定「コンボ」の組へ**「結果の画面の演出」**(おまかせ/出す/出さない)を足した。既定(おまかせ)は「出す」。
  保存は今の演出の設定(`mh_rhythm_settings_v1` の `fx`)へ項目 `resultCount` を足すだけ(既存の値の意味は変えない・無い/壊れた値はおまかせ)
- 演出量「最小」・軽量モードで動きを止める CSS は、数えているあいだ(`data-rhythm-count-anim="1"`)は効かないようにした。数え終わったあと(done)は今までどおり止まる
- 確かめ方: `node tools/mode/rhythm-record-fx-check.js`(横 844×390・FC でない回・演出量「最小」・軽量モード・動きを減らすを全部入れて、数え上がる・行とはんこが動く・done で止まるを見る)

## 2. 見ごたえを足す案(まだ本番に入れない・社長が選ぶ)

どれも「設定に関係なく強く出す」前提。数字の動きは今と同じく文字を書き換えるだけ、光は `transform` と `opacity` の箱で、重くしない。
タップでいつでも止まった形へ飛ぶ・ボタンは初めから押せるのは今のまま。保存データ・判定・スコア・ランキングは変えない。

| 案 | 主役 | 動き | 音(素材は足さず今の音から作る) | 長さ |
| --- | --- | --- | --- | --- |
| **A 判定が1行ずつ決まる** | 判定の内訳 | JUST MARVELOUS から MISS まで、1行ずつ順に数える。数えている行は大きく光り、決まると弾んで行の色の粒が散る。スコアは行が決まるたびに積み上がり、最後に MAX COMBO が数えられて輪が広がり、スコアが「じゃん！」と決まる → ランクのはんこ | 行が決まるたびに「カチッ」(行ごとに少しずつ音が上がる)、最後に決まる音 | 約2.5秒 |
| **B スロットの桁止め** | スコア | スコアの桁がスロットのように回り(水色)、左の桁から1つずつ「カチッ」と止まって金色に光る。全部止まると光が横切り、金と桃の輪が広がる。判定の行は数が決まる瞬間に数字が弾んで行が光る | 回っているあいだ細かく刻む音、桁が止まるたびに「カチッ」、最後に決まる音 | 約1.8秒 |
| **C 光のステージ** | 画面全体 | スコアの札の後ろで光の筋がゆっくり回り、判定の表を光の帯が上から下へなでる。スコアが決まる瞬間に画面が一瞬白く光り、衝撃の輪2重と金の粒が弾け、ランクのはんこで画面が小さく揺れる | 回っているあいだ上がっていく音、決まる瞬間に重い「ドン」+きらめき | 約1.8秒 |

おすすめ: **A**(社長の「判定のやつも数字が上がってく」に一番まっすぐ答え、FC でない回でも MISS の行まで1つずつ目に入る)。
B はスコアの決まる瞬間が一番気持ちいいが、判定の行は今とほぼ同じ。C は一番派手だが、数字そのものの動きは今と同じ。
**組み合わせもできる**(例: A の1行ずつ + C の決まる瞬間の光と揺れ)。

# 作ったもの(社長の選択「案A 判定が1行ずつ決まる」・台帳 r1119-156 追記2)

- 判定の行を上(JUST MARVELOUS)から1行ずつ数える(1行 260ms・数えるのは 200ms)。数えている行の後ろが光り、決まる瞬間に数字が弾んで行の色の粒が散る
- 音: 行が決まるたびに「カチッ」(行ごとに半音2つずつ高く)、スコアが決まる瞬間に決まる音。素材は足さず合成音(`RHYTHM_NOTE_SE_RUNTIME.playResultCount`)。
  ノーツの効果音の入/切・音量・全体ミュートに従う。タップで飛ばしたあとは鳴らさない。初めての記録は新記録の音と重ねない
- スコアは行の進みに合わせて積み上がり、全部の行のあとに MAX COMBO が数えられて弾み、輪が広がる → スコアが決まる(じゃん！)→ ランクのはんこ → 称号の札 → 下の物(約2.4秒・全部で3.3秒)
- 演出量・軽量モード・動きを減らすに関係なく動く(#7458)。止めるのは「結果の画面の演出」を「出さない」にしたときだけ
- 止め絵(本物のゲーム・各コマは結果が出てからのミリ秒): `an-a-game-yoko.jpg`(横 844×390)・`an-a-game-tate.jpg`(縦 390×844)。
  ロボットはクリアまで届かないので FAILED の回(MISS 59)。行の数が順に決まる・粒は決まる瞬間だけ・2500ms で MAX COMBO の輪
