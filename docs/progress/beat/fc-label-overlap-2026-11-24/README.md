# マルチの結果: 「FULL COMBO」などの札がスコアに重なる(r1119-169)

原因: 枠の札(`h-3.5` 固定の1行分)が、幅の足りない枠で2行に折れ、2行目がスコアの数字に重なった。
直し: `RhythmMultiFcLabel`(`77-screen-rhythm-multi.jsx`)。1行に置き、はみ出す分だけ横に詰める(高さは変えない)。
検査: `tools/ui/rhythm-multi-assist-result-check.js` に札の測り(1行・札の幅・枠の中・スコアと名前に重ならない)を足した。
`FC_KIND=am|ae`(省略はフルコン)で札の種類を変えられる。幅 430 と 小さい縦 320×568 も足した。

| 画面 | 直す前(before/) | 直した後(after/) |
| --- | --- | --- |
| 縦 390×844 | 2行に折れ、スコアに重なる | 1行・重ならない |
| 縦 430×932 | 同上 | 1行・重ならない |
| 小さい縦 320×568 | 枠で切れ、重なる | 1行・重ならない |
| 横 844×390 | 重ならない(そのまま) | 重ならない |
