社長「もんびーの曲終わりでフルコンボ以上のときの演出とそのあとのリザルトの画面がもうちょい作りこんでほしい。フルコンボって文字で出るだけだし次のリザルトは演出無しでそのまま結果だけ。経験値だけは動くけどスコアとか判定結果のほうをもっとメインに扱ってほしい」

社長の追記(同じ日): 「フルコンボとオールエクセレントとオールマーベラスがあるからね」「終わったあとのリザルトは数字が上がる演出でじゃん！みたいなかんじがほしいね。ハイスコアと比較して超えるかどうかとかそういうのとか」→ 終わりは3段で差を付け、結果はハイスコアと並べて数え上げる(下の「共通」)。

**案を並べただけで、ゲーム本体はまだ変えていない**(社長が選んでから作る・r1119-036)。

## 今の作り

- **曲の終わり**(`30-rhythm-play.jsx` の `view.status==='celebrate'`): 黒い全画面に「FULL COMBO!」「ALL EXCELLENT!!」「ALL MARVELOUS!!」の文字が弾んで入り、光の輪が2つ広がるだけ(1.3秒・効果音あり)。3つの称号は文字と色が違うだけで、演出の大きさは同じ
- **結果の画面**: 並びは r1119-108(曲の札 → スコア → 判定の内訳 → 経験値)。出る時の動きはなく、全部が最初から出ている。動くのは経験値の棒と、ランク S 以上の丸が光ること、新記録のときの「NEW RECORD!」の重ねだけ。称号の文字は判定の下に出る
- 止め絵: `now-tate.jpg`・`now-yoko.jpg`(試作で描いた比べ用)

## 共通: ハイスコアと並べて数え上げる(社長の追記・どの案にも入れた)

- スコアの数字の下に棒を出し、**ハイスコアの所に「BEST」の印**。数え上げに合わせて棒が伸び、下に「ハイスコア 951,200 まで あと ○○」が減っていく
- **越えた瞬間に「✨ NEW RECORD! +17,110」が弾んで出る**(越える時刻は数え上げの途中。越えなければ出ない)
- 数え上げが止まる瞬間に数字が一度大きくなって光り、ぴたっと決まる(「じゃん！」)。そのあとランクのはんこ → FC/AE/AM の札
- **届かなかったとき**は「ハイスコア ○○ まで あと 5,460」を赤みの字で残す(止め絵の「結果 AE 届かず」)
- 今ある「NEW RECORD!」の全画面の重ね(約3秒)は、この数え上げが同じ役をするので**結果の中へまとめる**(二重に出さない)。効果音は越えた瞬間に今の更新の音を鳴らす

## 共通の決まり(どの案でも)

- 絵・動画は足さない。動かすのは要素の `transform` と `opacity` だけ(光の柱・ライト・粒・帯はグラデーションの箱)。数え上げは今の新記録の演出と同じく文字を書き換えるだけ(毎フレーム描き直さない)
- **タップで飛ばせる**: 終わりの演出はタップで結果へ、結果の動きはタップで止まった形へ。ボタンは待たずに押せる
- **演出「最小」・軽量モード・端末の「動きを減らす」**: 曲の終わりの演出は出さず(今と同じ)、結果は止まった形でそのまま出す(数え上げもしない)。FC の札とランクの丸の色は出す
- **演出「少なめ」**: 粒・紙吹雪・光の筋を出さず、柱・ライト・帯と数え上げだけ
- 保存データ・判定・スコア・ランキングには触れない(見た目だけ)
