# 技の飛ぶ炎が黄緑になっていた不具合の直し(2026-11-04・レフェリーくん)

カード部が見つけたもの。社長「本編も直す」(ジン部長経由)。更新履歴なし。

## 原因

技の飛ぶもの「炎」(70-bootstrap の `.skfx-p--flame`)が、技の色を見ずに**黄緑で固定**されていた。
炎を飛ばす技は全部、技の色に関係なく黄緑の炎になっていた。
あわせて、固有技の着弾の炎の柱(24 の `UNIQUE_IMPACT_PALETTE.fire`)は橙で固定なので、青い炎の技でも柱が橙だった。

## 直したこと

- 飛ぶ炎は技の色(`--c1`・`--c2`)で塗る
- 火炎車 … 赤い炎の渦(技の色を赤に)
- 神狐蒼火 … 青い大きな炎(炎を1.6倍・着弾の柱も青)
- 神狐星火(オリヒメ) … 星空の色(紫)の炎と柱
- キュービの狐火・超狐火も、着弾の柱を技の青に(`tint:true`)

## 黄緑の炎が直った技(炎を飛ばす技すべて)

| 子 | 技 | 直した後の色 |
| --- | --- | --- |
| キュービ | 火炎車 | 赤 |
| キュービ | 神狐蒼火 | 青(柱も青) |
| キュービ | 煉獄九尾陣 | 深い赤 |
| オリヒメ | 神狐星火 | 星空の紫(柱も) |
| オリヒメ | 火炎車 | ピンク(オリヒメの通常技の色) |
| オリヒメ | 煉獄九尾陣 | 紫 |
| イルミネ | クリムゾンノヴァ | 深い赤 |
| ドリーミィ | クリムゾンノヴァ | 赤 |
| スプーキー | ドクロビーム | 橙 |
| スプーキー | グランドイリュージョン | 橙 |

ユグドラシル種のワンダーブレイズは、もともと技の色が黄緑なので見た目は変わらない。
ほかの色が決まっている飛ぶもの(星・葉・雷・氷など)は、形そのものが色を持つもので、技の色とずれている所は無かった。
