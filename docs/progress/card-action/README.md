## 案A「技の重さと属性で作り直す」

- 技のダメージで3段に分ける: 軽い(2以下)・ふつう(3〜5。全員に当たる技もここ以上)・大技(6以上)
  - 軽い … 今の動きのまま(テンポを落とさない)
  - ふつう … 着弾が二段・飛ぶものを増やす・**属性の締め**(炎の柱・氷柱・稲妻・水柱・光の柱・闇の渦・岩・斬撃・爪あと・花びら・魔法陣)
  - 大技 … ふつう + 使う子のオーラと残像(モンスターバトルの固有技と同じ飾り)
- 名前から当てる動きを増やした: 連打(コンビネーション・ラッシュ・マシンガン…)・ブレス・闇(デス・冥・ドクロ…)・ビーム(砲・キャノン・レーザー)・
  プレス(ボディプレス・ふみつけ・メテオ…)・ドリル(ニードル・針)・ハンマー(げんこつ・ハエたたき…)・剣・しっぽ
- 部品はモンスターバトルの技の動き(24 の SkillFxMotion・UniqueFxImpact)をそのまま使う。新しい絵は足していない
- 動きの長さは最長でも 1.2秒(今と同じ上限)。攻撃の順番(守りが決まってから攻撃の動き)・キラの光・待機モーションには触らない
- 技の動き「短め/出さない」・動きを減らす設定は今までどおり(残像は動きを減らす設定で出ない)
