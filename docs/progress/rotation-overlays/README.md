# 「🔄 横」で回らなかった窓口の4件の扱い(2026-11-07 レフェリー)

rotation-height-check の「回したとき用がまだ無い所」のうち、窓口の4件をバトル部で引き取った。
🔄横(縦の端末で絵を回す)は、モンヒロビートの中(gameState が RHYTHM_ で始まるあいだ)だけ。外へ出ると戻る。

| 窓 | 🔄横で出るか | 扱い |
| --- | --- | --- |
| 保存できない知らせ(data-storage-trouble) | 出る(どの画面でも30秒ごとの見回りで出す) | 直した: 回しているときは回した器へ出す(rotationAwarePortalTarget・41-screen-ui.jsx) |
| 新しい版の知らせ(data-update-notice) | 出る(どの画面でも出す) | 直した: 同上 |
| 「ゲームをやめる」の確認 | 出ない(バトルのメニュー data-battle-quit からだけ開く) | 例外: rotation-height-check に「outside」と理由つきで載せた |
| プロフィールの仲良し度のごほうびの一覧(58vh) | 出ない(gameState が PROFILE のときだけ) | 例外: 同上 |

クイックの案内(#4874)も、同じ出し先の部品 rotationAwarePortalTarget を使う形にそろえた。

## 止め絵
`後-保存できない知らせ-モードえらび-縦/横/🔄横.jpg`・`後-新しい版の知らせ-モードえらび-縦/横/🔄横.jpg`(モンヒロビートのモードえらびで出した)。
