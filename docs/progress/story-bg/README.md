# お話の背景(共通・どのお話からも使える)

社長「背景絵がない」「背景に関しては今後のイベントや今のパンドラのイベントにも使いたい」(2026-11-05)。
えるびんの登場のお話から作ったが、**名前も表もお話に寄せず、どのお話からも同じ書き方で呼べる**。一覧の絵: `背景の一覧.jpg`

## 使い方

- 台本の行に `bg:'<名前>'`。その行から背景が替わり、次に `bg` を書いた行まで続く。`bg:'none'` で消す。`fx:'fall'` の行は背景が上へ流れて暗くなる
- 絵は `monster-hero/images/story-bg/<名前>.jpg`(1080×1080 の正方形・大事なものは真ん中)。表は `data/breeder.js` の `STORY_SCENE_IMAGES`(名前 → 絵の定数)
- 縦の画面は会話の紙より上の範囲に敷き、横の低い画面は全面に敷く(紙の両脇に見える)。お話を開いたとき、そのお話で使う絵を先に読む
- **足すとき**: 絵を `images/story-bg/` に置き(1080×1080・JPEG・軽く。`monster-hero/images/CLAUDE.md`)、`data/breeder.js` に定数1行と `STORY_SCENE_IMAGES` に1行。`node tools/build.js` → `node tools/image-asset-check.js`
