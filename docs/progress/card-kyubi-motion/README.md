## 技カードの絵に寄せた(2026-11-04 社長「キュービの技アクションで技カードの見た目をも参考にして」)

本編の動きは変えず、バトルカードの側だけで色・形・飛ぶものを変えた(85-card-battle-motion.jsx の CARD_KYUBI_LOOK)。オリヒメは同じ形を星空の色で。

| 技 | カードの絵 | 前の動き | 寄せたあと |
| --- | --- | --- | --- |
| 提灯落とし | 大きな提灯が落ちる | 小さな金の玉 | 大きな橙の玉が降る |
| 陽炎 | 青い分身が爪で裂く | 炎色の影 | 青い爪・残像(大技の飾り) |
| 狐火 | 青い火の玉3つ | 赤い火がまわりを回る | 青い火の玉3つがまっすぐ |
| ひのこ | 提灯から火を吹く | 小さな火花 | 炎を吹きつける |
| 超狐火 | 青い炎がたくさん | 赤い炎 | 青い炎がたくさん+火柱 |
| なめろう | 黄色い提灯から大きな舌 | ピンクのハート | 金色の舌の一撃 |
| 火炎車 | 赤い炎の渦 | 黄緑の炎(部品の色が固定) | 赤い炎の渦 |
| 天河天翔 | 夜空から金の流れ星 | 星形 | 金の流れ星が降る |
| 神狐蒼火 | 青い大きな炎が落ちる | 黄緑の炎 | 青い大きな炎+火柱 |
| 炸裂気泡陣 | 燃える泡の爆発 | 水色の泡 | 燃える玉がはじける |
