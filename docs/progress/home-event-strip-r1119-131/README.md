# HOME 左上のイベントの札を横に伸ばして縦を詰める(r1119-131)

2026-11-23 開発部(クラフトくん)。直したのは `monster-hero/src/parts/69-screen-home.jsx` だけ(札の中の並びと CSS)。
押した時の動き(更新履歴を開く)・中身の文・`aria-label` は変えていない。

## 何を変えたか

- 1行目に「題」と「期間」を横に並べ、2行目に「副題」を置いた(前は 題 / 副題 / 期間 の3行)
- 札の幅の上限を、右の時計の手前(場面の幅 − 左の 9px − 88px)まで広げた
- 幅が足りない端末では、期間だけが題の下へ折り返す(題・期間の途中では折れない)
- 横の小さい端末(幅620以下・高さ340以下。568×320 など)では、左上の札が助手の吹き出しにかかっていた(main でも
  `home-layout-check.js` が「細バナー×吹き出し」で NG)。この大きさだけ、札を吹き出しの下の空き(施設の列の上)へ下ろした
