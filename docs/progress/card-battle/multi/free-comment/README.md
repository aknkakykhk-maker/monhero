## 作るときの形(メモ)

### 見える相手を「全員」にするための通り道

- 対戦の2人のコメント: 部屋の通信(`mhc-room-*`)の `chat` に文字(`x`)を足す。相手の画面は吹き出し4秒。
  ホスト(観戦の通り道を開いている側)が、観戦の通信(`mhc-watch-*`)へも流す(今の手と同じ流し方)
- 観戦者のコメント: 観戦の通信に新しく `say` を足す。ほかの観戦者は流れる+ログ。
  ホストが観戦の通信で受け取り、部屋の通信で相手へも渡す → 対戦の2人の画面にも出る
- 対戦の2人の画面での観戦者のコメントは、手の邪魔をしないよう **小さく流す**(まん中の空きだけ・1秒に1つまで)。対戦の人の吹き出しとは色を分ける(観戦は紫)
- 古い版の相手・観戦者は、知らない `chat` の文字・`say` を捨てる(今の `cardPvpCleanMessage` は知らない項目を落とす)ので壊れない

### 観戦の流れる+ログ

- 流れる: まん中の空きを右から左へ5秒、4段まで、1秒に2つまで(あふれた分は流さず、ログにだけ入れる)
- ログ: まん中の空きの上に一覧。いつもはたたんだ1行(「💬 コメント 12」)、押すと4行ひらく。新しいのが下。観戦が終わるまで最新50件
- 対戦の2人も、左上の「記録」の一覧の中で、コメントを振り返れる

### 守りの順番(送る前)

1. 見えない文字・改行を消す → 空白をつめる → 30字に切る
2. 全角英数字・空白をはさんだ数字を半角にそろえた写しで、連絡先を見る → 当たれば送らずに「URL・メール・電話番号・SNSのIDは送れません」
3. 言葉の表で「●●」に置き換え
4. 3秒あいていなければ送らない・回数の上限を超えたら「この試合ではもう送れません」

受ける側も 1 と 3 をもう一度通す(古い版・いじった端末から来ても出さない)。

### ミュート

- 吹き出し・流れるコメント・ログの行を長押し → 「🔇 ◯◯さんのコメントを消す」
- その試合(観戦ならその観戦)のあいだだけ。保存しない。消した人のコメントはログにも出さない

### 設定(`mh_card_chat_prefs_v1`)

- `{ free: true/false, flow: true/false }` … 自由文を出すか(切れば定型だけ)・観戦で流すか(切ればログだけ)
- 無い・壊れているときは `{ free: true, flow: true }`。今のキーの名前・意味は変えない
