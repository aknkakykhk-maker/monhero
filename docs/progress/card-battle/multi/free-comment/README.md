## 決めごとの案

### 1. だれに見えるか(おすすめ: 案1)

| 案 | 対戦の2人のコメント | 観戦者のコメント |
| --- | --- | --- |
| **案1(おすすめ)** | 2人と観戦者に見える | 観戦者どうしだけ(対戦の2人には見えない) |
| 案2 | 2人だけ | 観戦者どうしだけ |
| 案3 | 2人と観戦者に見える | 観戦者どうしと、対戦の2人にも見える |

- 案1の理由: 対戦の2人は持ち時間の中で考えているので、見ている人の声(答えの手を教えるなど)が届かないほうが公平。2人の会話は観戦の楽しみになる
- 対戦の2人は、相手のコメントを試合ごとに消せる(ミュート)。設定で「自由文を出さない(定型だけ)」も選べる

### 2. 長さと間隔

- 1回 **30字まで**(フレンドのひとことと同じ)。改行は入れられない
- 続けて送れるのは **3秒あけてから**(今の定型は1.5秒)。1試合に送れるのは対戦の人 **30回**・観戦の人 **20回** まで
- 持ち時間は止めない(打っているあいだも時計は進む)

### 3. 守り

- **悪い言葉の置き換え:** 今のゲームには言葉を置き換える仕組みが無い(フレンドのひとことは見えない文字を消して30字に切るだけ・`friendsCleanMessage`)。
  新しく **端末の中の言葉の表**(悪口・下品な言葉など)を作り、当たった所を「●●」に置き換えてから送る。受け取る側でも同じ表でもう一度置き換える(古い版・いじった端末から来ても出さない)
- **個人の情報を書かせない:** 送る前に弾く(送らずに「URL・メール・電話番号・SNSのIDは送れません」と出す)
  - URL(`http`・`www.`・`.com` など)・メール(`@` と `.`)・数字が7つ以上続くもの(電話番号)・「LINE」「ID」「インスタ」などのあとに英数字が続くもの
  - 全角の数字・英字・空白をはさんだもの(「0 9 0…」)も、半角にそろえてから見る
- **ミュート:** 吹き出しを長押し → 「🔇 ◯◯さんのコメントを消す」。その試合(観戦ならその観戦)のあいだ出さない。保存はしない
- **通報(要るか): いちどは入れない案をおすすめ。** 通報を受け取って見る人・仕組みがまだ無い。かわりに、フレンドならブロック(今ある)・相手のコメントは消せる、で始める。
  入れるなら、サーバに「だれが・どの試合の・どの言葉を」を足すだけの表で残す(下の4)
- 自由文は **公開後のふつうの入口から遊ぶ人だけ**。だれとでも(知らない人)の対戦では自由文を出さない、も選べる(社長に聞く)

### 4. 送り方

- **今のマルチの通信にのせるだけ(サーバには残さない)をおすすめ。** 対戦は部屋の通信(`mhc-room-*`)の `chat` に、文字を足す。観戦は観戦の通信(`mhc-watch-*`)に新しく `say` を足す
  - 対戦の2人のコメントを観戦に流すのは、ホストが今の観戦の通り道に流す(今の手と同じ)
- 会話の本文は、ログ(`console`・サーバの記録・マルチの履歴・過去の対戦の記録)に書かない
- 通報を入れるときだけ、サーバに **足すだけの表**(例 `card_chat_reports`: 通報した人・相手・試合の番号・その1文・時刻)。消す・書き換えるはしない。表を作る SQL は窓口へ本文で渡す

### 5. 保存データ

- 自由文そのものは保存しない
- 端末の設定だけ新しいキーで足す: `mh_card_chat_prefs_v1`(`{ free: true/false, watchStyle: 'bubble'|'flow'|'log' }`。無い・壊れているときは `{ free: true, watchStyle: 案で決まったもの }`)
- 今のキーの名前・意味は変えない

3. 通報: いちどは入れない(おすすめ)/入れる(表を足す)
