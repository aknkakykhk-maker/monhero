## 区切り2(2026-10-24): 時間切れ・切断・報酬・チャット ── できた

- 持ち時間: 自分の番60秒・守り15秒(`useCardPvpClock`)。使い切ったら番を終える(攻撃の番はガッツへ回さずターン終了)・守らない。3回続けたら負け(`timeout`)。
  相手の持ち時間が過ぎても手が来ないとき(電波はつながっている)は、20秒待って相手の負け
- 切断: こちらの電波が切れたら3秒おきにつなぎ直す。画面に戻ったらすぐつなぎ直す。届いていない手は送り直しで追いつく。相手から60秒何も届かなければ相手の負け。
  帯の下に「電波が途切れています」「相手の電波が途切れています(あと◯秒で相手の負け)」
- 抜けた人: 試合の途中で部屋を出た・アプリを閉じたら、3分は部屋に入れない(新しい保存キー `mh_card_pvp_penalty_v1`・SAVE_DATA.md に1行)
- 報酬(`cardPvpReward`): 勝ち 200・24周/負け 50・12周(自分の番10回で満額)/投了は倒した数/自分の番が3回より前に終わったら0/抜けた0。1日の上限なし(社長)。
  渡すのは、終わってからの確かめが「合っている」か「確かめられない(相手が抜けた)」のときだけ。無効の試合は渡さない
- 定型のチャット(上の帯の 💬・6つ)。相手の言葉は吹き出しに出る
- 対人戦の曲: `save.bgm.pvp`(既定はバトルテーマ by いちか)
- 写真: 04(チャットと電波の知らせ)・05(結果と報酬)
