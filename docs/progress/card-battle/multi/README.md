## 区切り2(2026-10-24): 時間切れ・切断・報酬・チャット ── できた

- 持ち時間: 自分の番60秒・守り15秒(`useCardPvpClock`)。使い切ったら番を終える(攻撃の番はガッツへ回さずターン終了)・守らない。3回続けたら負け(`timeout`)。
  相手の持ち時間が過ぎても手が来ないとき(電波はつながっている)は、20秒待って相手の負け
- 切断: こちらの電波が切れたら3秒おきにつなぎ直す。画面に戻ったらすぐつなぎ直す。届いていない手は送り直しで追いつく。相手から60秒何も届かなければ相手の負け。
  帯の下に「電波が途切れています」「相手の電波が途切れています(あと◯秒で相手の負け)」
- 抜けた人: 試合の途中で部屋を出た・アプリを閉じたら、3分は部屋に入れない(新しい保存キー `mh_card_pvp_penalty_v1`・SAVE_DATA.md に1行)
- 報酬(`cardPvpReward`): 勝ち 200・24周/負け 50・12周(自分の番10回で満額)/投了は倒した数/自分の番が3回より前に終わったら0/抜けた0。1日の上限なし(社長)。
  渡すのは、終わってからの確かめが「合っている」か「確かめられない(相手が抜けた)」のときだけ。無効の試合は渡さない
- 定型のチャット(上の帯の 💬・6つ)。相手の言葉は吹き出しに出る
- 対人戦の曲: `save.bgm.pvp`(既定はバトルテーマ by いちか)
- 写真: 04(チャットと電波の知らせ)・05(結果と報酬)

## 区切り3(2026-10-24): だれとでも・強さの点数 ── できた(SQL は窓口が流す)

- だれとでも: 受付 `realtime:mhc-lobby-free`。待っている人どうしが自分の部屋の合言葉を2秒ごとに知らせ合い、あとから来た人が先に待っている人の部屋へ入る(同じ時刻なら id の小さい人が待つ側)。
  入った部屋で8秒始まらなければ、自分の部屋へ戻ってさがし直す。「いま待っている人 ◯人」と残り秒。90秒だれも来なければ「もう一度さがす」「助手と対戦へ」
- 強さの点数: 確かめが済んだ試合だけ、2台がそれぞれ関数 `card_battle_pvp_report` へ届ける(`CARD_PVP.report`)。届けるのは公開後のふつうの入口だけ(84 の `rank.send && !debug`)。
  検査は `window.__mhCardPvpRankTest` で通し、Supabase を偽物にして届いた中身を見る。点数は3つの部屋どれでも動く・同じ相手でも小さくしない(社長)
- ランキングの「マルチ」の札: 90 の「準備中」の下に `CardPvpRankingList`(表が無いあいだは「強さの点数の表は、まだ準備中です」)
- 写真: 06(だれとでもでさがしている所)
- SQL: `docs/sql/card-battle-pvp/CARD_BATTLE_PVP_APPLY.sql`(足すだけ。最後に確かめの select)

## 区切り4(2026-10-24): フレンドから招待 ── できた(表は窓口が SQL を流してから使える)

- 部屋を作った人(合言葉)が「フレンドを招待する」→ 承認済みのフレンドの名簿(`sbFetchFriendRoster`)から選んで「招待する」。表 `card_battle_invites` へ合言葉を書く(`sbSendCardInvite`)
- 部屋に入っていないあいだ、8秒おきに自分あての3分以内の招待を読む(`sbFetchCardInvites`)。名簿にいるフレンドからのものだけ「◯◯さんから、マルチ対戦の招待が届いています [参加する]」
- ★表が無い環境でもフレンドの機能を止めない(friendsRequest を使わず、91 の中で別に数える)。フレンドがいない・表が無いときはボタンを出さない
- SQL: `docs/sql/card-battle-pvp/CARD_BATTLE_PVP_APPLY.sql` に招待の表の決まり(読む・足す・上書き。消すのは不可・時刻の更新・索引)を足した。何回流しても同じ
- 検査は `window.__mhCardPvpRosterTest`(名簿)と、Supabase を偽物に差し替えたうえでの `window.__mhSupabaseStubbed`(自動操作のブラウザは本物へ書かない仕組みがあるため)
- 写真: 07(招待を送る/届いた)
