# デッキ編成: カードの札の案(D5〜D8)

絵は1場面1枚。375 と 320 の幅で撮った。

## 今の困りごと

- D5 カードの字が小さく、ガッツ・ダメージは絵の中の小さな数字でしか分からない
- D6 −/＋ が同じ強さで、− が目立ちすぎる。i が名前の横で押しにくい
- D7 「3/3」が「入れた枚数 / 入れられる上限」だと分からない。持っている枚数が出ていない
- D8 どのモンスターが使えるカードかが、札を見ても分からない

## 案A 字で全部書く

- 絵の左下に「ガッツ3」「ダメージ5」の札
- 絵の左上に「ゴーレム専用」など使える子、右上に i
- 下の段は [− 灰] 「3枚 / 持3」 [＋ 金]

## 案B 点で枚数を見せる

- 絵の左上に使える子、右上に i、右下に「持3」
- 下の段は [− 灰] ●●○(入れた枚数・入れられる上限) [＋ 金]
- ガッツ・ダメージは今のまま(絵の中の数字)

## おすすめ

案A。D5〜D8 を全部字で答えられる。案Bは札がすっきりするが、ガッツ・ダメージは今のまま。
