社長「フレンドのデッキがもう少しわかるようにして。モンスターだけは画像で出すとか。見た目大事」(2026-10-30)。
絵は1案1枚・375×812。名前はすべて架空(ほしのリコ・こてつ・ミナト・さくらもち)。

- 今-ほかのブリーダー-375 … デッキ名とモンスター名が1行の字で切れる。同じ人(ほしのリコ・さくらもち)が「おすすめ」と「よく戦われているデッキ」に2回出る
- 案A-ほかのブリーダー-375 … 1件を大きな札に。3体の絵を名前つきで並べ、デッキ名を大きく。同じ人は1回だけ出して「おすすめ」「人気」「フレンド」の印で分かる(1画面に2件)
- 案B-ほかのブリーダー-375 … 並びはそのまま、縦長のデッキの札を横へ流す。3体の絵を重ねて、デッキ名・賢さ・戦うを札の中に。前の並びに出た人はうすく出す
- 案C-ほかのブリーダー-375 … 3つの並びを1つの一覧にまとめ、上の札(すべて/おすすめ/フレンド/人気)で絞り込む。行に3体の顔・デッキ名・モンスター名・賢さ・戦われた数・印(1画面に4件)
