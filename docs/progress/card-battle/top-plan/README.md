## 案A まとめ帯(1段・高さ固定) — top-A.jpg
左に「≡」と「💬」だけ。まんなかに番の札ひとつ(「あなたの番 ⏱60」/ 相手の番は灰色)。右に「T2」「👀3」。
電波が途切れたら、番の札そのものが「📶 ももすけの電波待ち あと114秒」に変わる(段は増えない)。
「≡」の中に ターンの記録・オプション・投了(赤)。投了の確かめの窓は今までどおり。難易度の札は上の帯から外す(助手の名前の下にある)。

## 案B ボタンは今の言葉のまま、投了を右端へ離す — top-B.jpg
左に「記録」「💬」、まんなかに番の札(「あなたの番 · 残り60秒」)、右端に赤い縁の「投了」。
帯のいちばん下に持ち時間の細い線(減っていく)。電波が途切れたら番の札と線が橙になる(段は増えない)。

## 案C 2段で、番の帯を横いっぱいに — top-C.jpg
1段目は今のボタン(投了・記録・💬)と右に👀・ターン数。2段目は横いっぱいの番の帯「▶ あなたの番 残り60秒」。
電波が途切れたら2段目がそのまま「電波が途切れています」に変わる。帯は今より26px ほど高い(盤が少し下がる)。

どの案も: 帯の高さはどの番でも同じ(盤が動かない)/ 持ち時間と番の表示を1つにまとめる / 観戦の数は「👀3」の札。
マルチの部品(持ち時間・💬・電波・観戦の数)はツナグくんの持ち場と重なるので、作るときはツナグくんとそろえる。
