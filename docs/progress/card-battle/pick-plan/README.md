# 組み合わせ系を自動で選ばない(見本4枚)

社長「組み合わせ系が自動で選択されるのなんとかして。自分で選ぶから、何かを選んだら候補として見えるようにして」(2026-10-29)。
場面: ドラゴンのコンビネーション(しっぽアタック・かみつきと同時に出す)＋急襲(ガッツ半分)。390 と 320。絵は1場面1枚。

1. 見本1-技を押した所 … 押した1枚だけが選ばれる。ほかの札は上がらない。「使う」はまだ押せない
2. 見本2-候補が光る … いっしょに出せる札は緑に光って「候補」。押すまで上がらない。組が1つしかなくても自動では選ばない
   (実際は1と2は同時。押したとたんに候補が光る)
3. 見本3-候補を足した … 候補を押すと加わる(もう1回押すと外れる)。出せる形がそろうと「使う」が押せる。上の帯に合計(全体に8ダメージ / ガッツ4)
4. 見本4-使う … 急襲も足した(ガッツ4→2)。「使う(全体に8・ガッツ2)」を押すと、4枚がいっしょに出る

- 付ける札(急襲など)から先に押してもよい。そのときは、付けられる技が候補で光る
- 今の「組み合わせの窓」(#4234)と、技を押すと付ける札が先に上がる動きはやめる
- 守りの番の組み合わせも同じ考え方にする: 1枚押す → いっしょに使える回避・防御が候補で光る → 押して足す → 「これで守る」。
  1枚で守れるときも勝手には足さない。マルチの守りの時間は今のまま
