# MFバトルカード: 立ち絵が無いモンスター(2026-10-26 調べ)

社長「カードではあるけど立ち絵がないモンスター作りたい。使えそうな画像出して」。

## 調べ方
- MFバトルカードのモンスターカード(純血・混血・すべての弾。キラ・別絵キラは元の番号の子として1つに数えた)
- ゲームのどこかに立ち絵があるか:
  - 純血24種族 … 本編の味方(ALL_PLAYER_MONSTERS)と、MF の種族の立ち絵(MF_*_IMG)で全部ある
  - 混血42体 … HYBRID_MONSTER_IMGS(混血の立ち絵)にある子が37体。無い5体のうち、ブルーマウンテン(C-011)は敵の立ち絵(BLUEMOUNTAIN_IMG)がある
  - 案の子(UPCOMING_MONSTER_DRAFTS)・敵の絵(enemy-monsters)も名前で突き合わせた

## 立ち絵が無い4体(どれも「図鑑だけ」= パックには入らない混血の子)
| 番号 | 名前 | メイン/サブ | タイプ・ライフ |
| --- | --- | --- | --- |
| C-014 | アンキロックス | ディノ/ゴーレム | 地上・7 |
| C-032 | マグナビートル | ゴーレム/ワーム | 地上・7 |
| C-037 | ソボロベント | モノリス/ワーム | 空中・9 |
| C-044 | ギンギライガー | ライガー/？？？ | 地上・6 |

- キラ・別絵キラは無いので、絵は1種類ずつ
- 参考: ブルーマウンテン(C-011・ゴーレム/ライガー)は、ゲームには敵の立ち絵があるが、カードの画面ではまだつないでいない

## ファイル
- `見本帳_立ち絵が無いモンスター.jpg` … 4体を1枚に並べた見本帳(名前・番号・メイン/サブ・タイプ・ライフ)
- `C-xxx_名前_切り出し.jpg` … カードの絵の窓の中(名前・番号の帯を除く)を2倍(1308×1640)にしたもの。ChatGPT などにそのまま渡せる
- `C-xxx_名前_カード全体.jpg` … 元のカードの絵(tools/art-sources/card-battle/hybrid の原本・742×1038)
