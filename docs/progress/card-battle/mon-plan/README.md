# ④ モンスターの欄(場の子) 2026-10-29

絵: mon-390.jpg / mon-320.jpg(左から 今・案A・案B・案C)

## 今の問題
1. 1体ごとに「小さいカードの絵」と「モンスターの立ち姿」の2つが並ぶ。同じ子の絵が2つで、カードの絵は小さくて読めない
2. 「地上」の札が全員にいつも付く。気をつけたい「空中」が目立たない
3. 長い名前(ストライクリパー)は字が小さくなる
4. ライフの数「8 / 8」が小さく、線はいつも緑(減っても色が変わらない)
5. 320 幅では立ち姿が 30px ほどしかなく、札と字がつまっている

## 案A 札の小さい絵をやめ、モンスターを大きく
立ち姿だけにして大きく。名前と、数の入ったライフの線(半分で黄、1/4 で赤)。「地上」は出さず、空中のときだけ「☁空中」。
## 案B 1体ずつ枠に入れる
立ち姿を枠に入れ、名前とライフの線は枠の下に重ねる。相手は桃、自分は金の縁。空中は枠の右上に札。
## 案C カードの絵を大きく、立ち姿はやめる
カードの絵を大きくし、横に名前とライフの線。立ち姿は出さない(カードゲームらしさ寄り)。

どの案も: 長押し・ダブルタップで詳しい画面 / 効果の札(技×2 など)/ ねらえる子の赤い輪・使う子の金の輪 / 倒れたときの裏返し は今のまま残す。
