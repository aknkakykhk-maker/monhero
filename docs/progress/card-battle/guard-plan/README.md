# MFバトルカード 守り・回避と相手の札の見せ方の案(ブレイブくん・2026-10-27)

社長の頼みは2つです。

- 「防御カードや回避カードを使ったあとの挙動が使ったか使ってないか分かりにくい。相手がカードを使ったときにカードがすぐ消えて効果がわからない」
- 「使ったあとの、いくつからいくつとか、わかりやすい表記が必要」

写真は 390×844 の本物の画面に、案の飾りを重ねて撮った見本です(まだ作っていません)。左が今、まんなかが守りを使ったあと、右が当たった瞬間です。
場面は、相手のゴーレムの「でこぴん」(5ダメージ)を、自分のモッチーが「まるまる」(防御 −3)で受けるところです。

## 今の何が分かりにくいか(各写真の左)

- 守りの札をタップすると、すぐ使われて大写しが出る。消えたあとも、まんなかの箱は「(ダメージ5)」のまま
- 下のボタンも「守らない」のまま。使ったのに、使っていないように読める
- 守った子に青い「−3」が少しの間出るが、すぐ消える。回避(転がる)は、ガッツが 9 → 8 と減るだけで、箱は「(ダメージ5)」のまま
- 当たったあとは記録に「モッチーに2ダメージ」と出るだけで、もとが5だったことは分からない
- 相手の技の札は2.2秒、大写しは約1.2秒で消える。横の画面では吹き出しと重なって、ほとんど見えなかった(フキダシくんの測り)

## どの案にも入れること

- **守りの番の箱を「前 → 後」で書く**: 「受けるダメージ 5 → 2」「まるまる(防御 −3)を使った」。回避なら「5 → 0(回避する)」。重ねて使えば、そのつど数え直す。数はルールと同じ計算(82 の cardAiFinalDamage)を使う
- **下のボタンを替える**: 守りを1枚でも使ったら「守らない」→「これで受ける(2ダメージ)」
- **守った子の上の印**: 「🛡 防御 −3」「💨 回避」。守りの番が終わるまで出しておく
- **当たった瞬間**: 子の上に「🛡 防御！ 5 → 2」「💨 回避！ 5 → 0」。記録も「モッチーに2ダメージ(まるまるで 5 → 2)」
- **使わなかったとき**: 「守らなかった 5ダメージ」/出せる札が無いときは「守れる札が無かった」を、同じ場所に小さく出す
- **自分も相手も同じ形**: 相手が守ったときも、相手の子の上に同じ印と「前 → 後」が出る
- **ルールは変えない**: 82 は当たりの出来事に「もとのダメージ」を1つ足すだけ(保存・数字・強さは変わらない)

## 分け方(社長が選んだあと)

1. 82: 当たりの出来事に、もとのダメージを足す(見た目は変わらない)
2. 守りの番: 箱の「前 → 後」、ボタンの文、守った子の印
3. 当たった瞬間の「防御！ 5 → 2」「回避！」と記録の書き方
4. 相手の札を残す・出し直す(吹き出しのあと・ダウンの帯のあと)
5. (案Bなら)この番の札の棚

前カード部長が 84 の札のタップの周りを触っているので、2 と 4 は先に場所を合わせる。更新履歴の文は、入れるときにソランドくん経由で社長の「この文で」をもらう。
