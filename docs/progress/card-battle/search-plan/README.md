# デッキ編成と図鑑: 並べ替えとさがす(D3・D4・Z4・K1)

絵は1場面1枚。375 と 320。両方の画面を同じ形にそろえる(K1)。

## 今の困りごと

- D3・Z4 名前でさがせない — 今-デッキ編成 / 今-図鑑
- D4 「並び: 種類順 ▾」は押すたびに替わるだけ(▾ なのに一覧が開かない)
- Z4 図鑑には並べ替えが無い
- K1 2つの画面で、札の並びと名前がそろっていない

## 案A さがす入れ物をいつも出す

- 札の列の上に「🔍 名前でさがす」と「並び: ◯◯ ▾」を1行で
- 「並び ▾」を押すと一覧が開き、えらぶと閉じる(案A-デッキ編成-並び / 案A-図鑑-並び)
  - デッキ編成: 種類順・ガッツの少ない順・ガッツの多い順・番号順
  - 図鑑: 番号順・ガッツの少ない順・持っている数の多い順
- 名前の一部を入れると、そのカードだけ出る(案A-デッキ編成-さがす)。✕で消す
- 1行ぶん高くなる(320 では一覧が少し下がる)

## 案B 🔍 は押したときだけ開く

- 札の列の先頭に 🔍。押すと入れ物が開き、「とじる」で札の列へ戻る(案B-デッキ編成-さがす)
- 並びは「種類|ガッツ|番号」(図鑑は「番号|ガッツ|枚数」)をその場で切り替え。一覧は開かない
- 高さは今のまま。ただし 320 の図鑑では切り替えが右で切れ、横へ送らないと見えない(案B-図鑑-320)

## おすすめ

案A。さがす入れ物が見えているので気づきやすく、並びの名前も一覧で分かる。高さは1行ふえるが、上のデッキ欄はたためるようにしてある。
