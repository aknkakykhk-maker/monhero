# デッキ編成: カードの並ぶ所を広く(D1・D2・D9・K2) 2026-10-29

絵は1場面1枚(頭が「今」「案A」など・幅 375 と 320)。
- 今-デッキ編成: 上のデッキの箱(名前・3体・50/50枚)が画面の約1/4。375 でカード2段、320 で1段半。絞り込みの札は横に流れ、「使える子だけ」「並び」は右はしで見えない
- 案A-デッキ編成: 上のデッキの箱を1行の帯に(名前・3体の小さい絵・50/50枚)。押すと今の箱が開いて、名前・3体を直せる。カードが半段ほど増える
- 案B-デッキ編成: 案A ＋ 「使える子だけ」「並び」を札の列の先頭へ(1列のまま)
- 案C-デッキ編成: 案A ＋ 絞り込みを1行4つに(「デッキの中」「技など全部▾」「使える子だけ」「並び▾」。▾ は押すと一覧が開く)。320 は字を短く(「種類▾」)
※札の列を2段に折り返す形も試したが、4段になってカードが減るので外した
