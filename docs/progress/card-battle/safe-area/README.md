# MFバトルカード: 画面いっぱいの窓が iPhone の時計の帯にかかる(2026-11-04 テスターさん)

報告: 戦術カードをえらぶ窓(「基本の型(メイン)をえらぶ」)の左上の「←戻る」が、iPhone の時計・電波・電池の帯と重なって押せない。
下の「決める(登録の確かめへ)」の帯も薄く暗く出ていた。

原因: 窓は fixed inset-0 で画面の端まで広がるので、body が取っているセーフエリアの余白が効かない。
背景が bg-slate-950/95(95%)なので、後ろの登録画面の「決める」の帯がうっすら透けていた。

直し:
- 84 に cardSafePad(元の余白とセーフエリアの大きいほう)を作り、82〜99 の画面いっぱいの窓・下から出る窓・まんなかの窓 27 か所に付けた
  (戦術カードのえらぶ窓・種族をえらぶ・足りないカード・組み合わせ・ためしに戦わせる・おすすめの組み方・詳しい画面・記録・選ぶ窓・
  デッキの確かめ・パックの見せ場・売り場・カタログ・コメントの板・登録デッキの詳しい画面・大会の記録 など)
- 画面いっぱいの窓の背景を不透明(bg-slate-950)にした
- 検査 tools/card/card-safe-area-browser-check.js を足した(書き方で全部の窓を見る+セーフエリア上47・下34px を付けて「戻る」の位置を測る)

写真: セーフエリア(上47px・下34px)を付けた 390×844。上の白っぽい帯が時計の帯、下がホームバーの場所(検査で重ねた目印)。
