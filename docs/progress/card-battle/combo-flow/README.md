# 組み合わせ系の流れ(攻撃の番) 2026-10-29

社長「攻撃はまず組み合わせ系の流れが非常に悪いから、まずそこをよくしてほしい」。例の場面: ドラゴンで
コンビネーション(しっぽアタック・かみつきを同時に出す)＋急襲(全体技のガッツ半分)。390×844。

## 今(#4196)の洗い出し — flow-now.jpg
- 迷う所
  1. 技を押しても、いっしょに出す札(しっぽ・かみつき)が手札で何も変わらない。何がいっしょに出るか分からない
  2. 手札の上に「＋しっぽアタック＋かみつき」「＋しっぽアタック＋かみつき＋急襲」と文字だけのボタン。違いは最後の「＋急襲」だけで、付けると何が変わるか(ガッツ4→2)が見えない
  3. 付ける札(急襲)を手札で押すと「足す」ではなく「選び直し」になる(手の動きと逆)
  4. 付ける札から先に押すと、何も選ばれず案内だけ
  5. 「使う」の前に、ダメージ・払うガッツの合計がどこにも出ない
- 押す回数: 技 → 組のボタン → 使う(3回。狙う相手がいる技は+1、使う子が2体以上なら+1 → 最大5回)
- ボタンの並び: 組のボタンは手札の上、使うは画面の下。目が上下に行き来する。組が増えると文字だけのボタンが横に並ぶ

## 案A 手札で足していく — flow-A.jpg
技を押すと、いっしょに出す札は自動で上がり「いっしょ」の札。付けられる札は手札で光り「＋付ける」。押すと足す/もう1回で外す。
手札の上の帯に合計(全体に8ダメージ / ガッツ4→2)。押す回数: 技 →(付ける札)→ 使う = 2〜3回。付ける札から押してもよい。

## 案B 組み合わせの窓 — flow-B.jpg
技を押すと、まんなかに窓。行ごとに札の絵の並び・ダメージ・ガッツ。行を押すと札が上がり、下に「使う(全体に8・ガッツ2)」「組を変える」。
押す回数: 技 → 行 → 使う = 3回(組が1つしかないときは窓を出さず2回)。

## 案C 付ける札はあとで1回だけ聞く — flow-C.jpg
技を押すと、いっしょに出す札は自動で上がり、そのまま「使う」。付けられる札があるときだけ「「急襲」も付けますか？ ガッツ4→2」[付けて使う][付けずに使う]。
押す回数: 技 → 使う → (付ける/付けない) = 2〜3回。考えることが1つずつ。

どの案も、出し終わり(4こま目)は今と同じ。狙う相手がいる技は「使う」の前に相手を押す(今と同じ)。
