# カード図鑑の見直し 2026-10-29

社長「カード図鑑がみにくい。血統別とかにしたときに、そのカードがどの弾に入っているかを見れるようにしたい」。
絵は1場面1枚(頭が「今」「案A」など。幅 375 と 320)。例: 血統別 → ゴーレム。

## 今の見にくい所
1. 血統別・種類別にすると、そのカードがどの弾(パック)に入っているかが、どこにも出ない — 今-図鑑-血統別-375 / -320
2. 詳しい画面にも、弾と持っている枚数が出ない — 今-図鑑-詳しい画面-375
3. 持っていないカードは暗い白黒で、名前も灰色。持っているカードとの見分けはつくが、どれも同じに見える
4. 持っている枚数(×3)は右上の小さい札だけ。持っていないカードには何も出ない
5. キラ・別絵キラは左上の小さい「キラ」の札だけ。名前の下の(キラ)(別絵キラ)で行がふえる
6. 上の部分(集めた種類・見方3つ・札・全部/持っている/まだ)が厚く、375 で約4割、320 はカードが1段半 — 今-図鑑-パック別-375 / -320
7. 札(ディノ・ハム…)が横に流れ、右はしで切れて見える

## 案(どれも「保存キー」と「カードの番号」は変えない。詳しい画面には「第◯弾パック・持っている◯枚」を足す)
- 案A-図鑑-血統別: 今の並びのまま、1枚ずつ左上に「第2弾」の札(弾ごとに色)、右上に「×3」(緑)/「まだ」。キラは金の縁と「★キラ」の札
- 案B-図鑑-血統別: 弾ごとの見出し(「第2弾パック 8/16」)でまとめて並べる。カードには枚数とキラの札だけ。混血は「混血(パックには入らない)」
- 案C-図鑑-血統別: 1行1枚の一覧(小さい絵・名前・弾の札・キラの札・持っている枚数)。弾ごとの見出し付き

おすすめは案B: 見出しで弾がひと目で分かり、カード1枚ずつの札が増えすぎない。案A は今の並びのまま札だけ足すので、作りがいちばん小さい。
