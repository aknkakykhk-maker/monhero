# MFバトルカード 対戦画面の改良の案(ブレイブくん・2026-10-26)

社長「バトルカードのバトル画面がまだ見にくい。ターン毎とかコメントとか勝ったときとかそのへんのアクセントも弱いし全体的に改良が必要」と、
社長「全体カードを使ったときは背景ごと変わるようにしたい」、カゲあつくんの10件への答え。
写真は 390×844 の今の画面に、案の飾りを重ねて撮ったもの(左が今・右が案)。

**決めごと(どの案も)**: 遊び方・数字・保存は変えない。テンポを遅くしない(どの演出も1秒前後・タップで飛ばせる)。
設定の「演出の速さ」(既定・速い)に合わせて短くする。手は 84(見た目)と 70-bootstrap(CSS の動き)だけ。

## A 番の替わり目(A-turn.jpg / カゲあつ 3・10)

| | 今 | 案 |
| --- | --- | --- |
| 知らせ | 真ん中に「あなたの番」の札(0.8秒) | 横いっぱいの帯が左から右へさっと通る(0.7秒)。「YOUR TURN / あなたのターン」 |
| 色 | 札は金色だけ | 自分=金→橙のあったかい色、相手=青→赤の冷たい色 |
| 画面のふち | 場のふちが光る(#3708) | 画面全体のふちも光る(自分=金・相手=青)。相手の番は全体を少し暗く |
| 音 | なし | 今ある効果音から「番が来た」の短い音を1つ(新しい音は足さない) |
| 場 | 境目があいまい | 自分の場=あったかい床・相手の場=冷たい床、まんなかにうすい「VS」 |

## B コメントと当たり(B-talk-hit.jpg / カゲあつ 4・5・7・9)

- **コメント**: ふだんの台詞は今の小さい吹き出しのまま。大事な場面(先に1体倒した・倒された・逆転・残り1体・勝ち負け)の台詞だけ、
  顔の大きいカットイン(右から入る・1.2秒・タップで消える)。吹き出しの出る時間はデッキくんの「吹き出しの時間」に合わせる
- **当たり**: 当たった子が白く一瞬光る+小さくゆれる+ダメージの数字を大きく(赤・白ふち)
- **倒れた**: 倒れた子は崩れて(少し傾いて暗く)、まんなかに赤い帯「ナーガ ダウン！ / 相手のモンスター 残り2体」。場のはしに「残り2体」
- **記録の帯**: ダメージ・ダウンの行だけ赤く大きく(いつも同じ見た目だったのを分ける)

## C 勝った・負けた瞬間と結果の画面(C-end.jpg / カゲあつ 1・2)

- **勝ち**: 決着の瞬間に一度止める → 画面を暗くして大きな「WIN!」・光の筋・紙ふぶき(1.5秒・タップで次へ)
- **負け**: 暗い青でやさしく「LOSE / おしかった！ もう一回いってみよう」。暗くしすぎない
- **結果の画面**: もらったビートPを0から数え上げる・勝ちは紙ふぶき・ビートPのコインが数字へ飛ぶ。
  「自分の番を3回やる前に終わったので…」の注意書き(クイック周回の説明)は、もらえなかった時だけ小さく1行に

## D 全体カード(D-field.jpg / 社長の指示)

1. 出した時: 真ん中に大きく「◯◯が出した 全体カード」・カードの絵・名前・効き目(1.2秒・タップで閉じる)。相手が出した時の今の大写しを使う
2. そのあと: 盤の背景を、そのカードの背景に変える。別の全体カードが出たら変わり、消えたら元の紫に戻る(場に1枚だけ・時間切れなし。デッキくん確認済み)
3. 字が読めるように、背景は暗く(明るさ半分以下)・模様はうすく

**やり方の比べ**

| | A カードの絵をぼかす | B カードごとの色と模様(すすめ) |
| --- | --- | --- |
| 見た目 | 絵の色がそのまま出る。にぎやかで、上に乗る字・モンスターが読みにくい | 色と模様だけなので字が読める。カードの気分は伝わる |
| 手間 | 0(どのカードにもそのまま効く) | 15枚に1行ずつ(下の表) |
| 新しいカード | そのまま効く | 表に無いカードは A で出す(取りこぼしなし) |

## E 全体(カゲあつ 8 ほか)

- 黄色の案内の帯は1行に短く(例「技をタップ → 相手をタップ」。運ぶ話はヘルプへ)
- 字の大きさ: 記録の帯 13→14px、場の名前・ライフは今のまま(切れの直しを壊さない)
- 番のまとめ(カゲあつ 6)はデッキくんの「1行の札」(card-turn-summary-chip)に任せる

## 分け方(社長の OK のあと)

1. A 番の替わり目+場の床
2. B 当たり・ダウン・残りの数・記録の帯
3. B コメントのカットイン(デッキくんの吹き出しの時間と合わせて)
4. C 勝ち負けの瞬間+結果の画面
5. D 全体カードの大写し+背景
6. E 案内の帯・字の大きさ

更新履歴は、入れるたびに文案をデッキくんへ送る。
