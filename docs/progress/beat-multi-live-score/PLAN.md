# モンヒロビートのマルチ: 演奏中にほかの人のスコアを見る(案)

2026-11-11 ナラビ(ビート部)。社長「モンビーマルチで演奏中もほかプレイヤーのスコア等みたい。ただし重くなるようならかんがえもの」

## いまの仕組み

- 通信は Supabase Realtime の Broadcast だけ(表・SQL・Edge Function なし。`docs/spec/RHYTHM_MULTI.md`)
- **演奏中は何も送らない・届いた知らせは溜めるだけ**(2026-10-03 の指示。判定と描画に割り込ませないため)。相手のスコアが分かるのは、曲が終わって結果(`res`)が届いたときだけ
- 演奏画面には、外から「読むだけ」の窓(`RHYTHM_PLAY_WATCH`。スコア・コンボ・判定の数)がすでにある(助手とのセッションの顔が使っている)

## 案

どの案も Supabase の設定・表は変えない(今の Broadcast に小さい知らせを1種類足すだけ)。判定・音の同期・譜面・ランキングの送信・保存データには触らない。

| | A 順位とスコアの札(推奨) | B 自分の順位だけ | C なめらかに動かす |
| --- | --- | --- | --- |
| 見た目 | 左上(道の外)に全員の順位・名前・スコア。自分の行に色 | 左上に「2位 / 5人・1位まで あと 14,760」の1枚 | A の数字が毎フレーム増えていく |
| 止め絵 | `A-port.jpg` `A-land.jpg` | `B-port.jpg` `B-land.jpg` | (A と同じ形) |
| 送る量 | 1人が3秒に1回・約70バイト | A と同じ | A と同じ |
| 描き直し | 3秒に1回、数字の文字だけ。順位が入れ替わったときだけ行を動かす | 3秒に1回、文字2か所 | 毎フレーム |
| 重さ(下の表) | 今と変わらない | A より軽い(測っていない。A が変わらないので同じかそれ以下) | 1フレームの JS が約1.5倍・レイアウトが約4倍 → **推奨しない** |

- 通信の量: 5人の部屋で受け取りが1秒に約1.7件。**待合室でいま流れている定期の知らせ(2秒に1回・1秒に約2.5件)より少ない**
- 「コンボの節目ごとに送る」形も考えたが、うまい人ほど送る回数が増えて量が読めないので、時間で決める形(3秒)にした
- 呼んだマスモン(CPU)は演奏中のスコアを持たない(結果を曲の終わりに決めている)ので、札には出さない。人が自分だけの部屋では札は出ない
- 古い版のままの人がいても部屋は壊れない(知らない知らせは捨てる作り)。その人の行は出ない
- 設定で消せるようにする(「演奏中にほかの人のスコアを出す」。はじめは入)

## 重さを測った結果

本番の画面を開いて実際に曲を流し、CPU を 1/4 に絞って15秒 × 3回の中央値(`tools/mode/rhythm-live-frame-report.js` に、4人ぶんの知らせを受けて札を書き換えるまねを差し込んだ)。

| 条件 | 33.3ms を超えたフレーム | 長いタスク | 1フレームの JS | スタイル再計算 | レイアウト |
| --- | --- | --- | --- | --- | --- |
| 札なし(今)1回目 / 2回目 | 5 / 12 | 0 / 0 | 1.11 / 1.19ms | 0.40 / 0.43ms | 0.04 / 0.05ms |
| A 3秒ごと 1回目 / 2回目 | 5 / 6 | 0 / 0 | 1.06 / 1.21ms | 0.39 / 0.43ms | 0.04 / 0.05ms |
| C なめらか(毎フレーム) | 6 | 0 | 1.65ms | 0.43ms | 0.17ms |
| わるい作り(届くたびに画面全体を更新・1秒ごと) | 20 | 4(最大124ms) | 1.29ms | 0.82ms | 0.09ms |

- A は、札なしを2回測ったときのばらつきの中に収まる(差が見えない)
- ヘッドレスのブラウザなので、絶対値は実機と違う。同じ条件での比べ
- 作ったあとは、まねではなく本物の作りで同じ測り方をもう一度回し、札なしと並べて確かめる。実機(社長の iPhone)での見え方は公開の前に止め絵で

## 作るときの形(A)

- 送る側: 演奏のループの外で3秒に1回、読むだけの窓からスコアとコンボを読んで送る。ポーズ中・結果が出たあとは送らない
- 受ける側: 演奏中に溜める仕組みはそのまま。新しい知らせだけ、溜めずに小さい表へ入れて札の文字を書き換える(演奏画面は作り直さない)
- 置き場所: 縦は時間の行の下・横は曲名の行の下(どちらも道の外)。**助手とのセッションの顔(呼んだ助手がいるとき)と同じ場所**なので、両方出る部屋では札を顔の下へずらす。縦で助手4人+人5人だと道にかかるので、そのときは札を「1位・自分・すぐ上」の3行に縮める(作るときに止め絵で確かめる)
- 触るファイル: `77-screen-rhythm-multi.jsx`(知らせの出し入れ・札の部品)、`60-app.jsx`(演奏画面の外から札を重ねる1か所)、設定の1項目、仕様書・検査
