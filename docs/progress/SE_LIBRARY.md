### なぜ `monster-hero/audio/` に置かないか

`tools/build-asset-manifest.js` が `monster-hero/audio/` の下を**フォルダの奥まで全部**事前ダウンロードの一覧に入れる。
そこへ置くと、まだ鳴らない音を遊ぶ人の端末に落とさせてしまう。だから使うと決まるまでは配信しない `tools/art-sources/` に置く。

### 音量と音質(docs/rules/ASSETS.md・r1115-143)

- かける倍率は曲と同じ「`min(目標LUFS - いまのLUFS, -1 - いまの真のピーク)` の1つだけ」。圧縮はしない
- 目標は効果音の既定 **-18 LUFS**(曲の -14 より少し下)。下敷きに長く鳴らす物(地の底のうなり -22・恋の余韻 -20)は小さめ。0.4 秒より短い音は LUFS が測れないので、真のピーク -1 dBTP にだけ合わせる
- 書き出しは **44.1kHz ステレオ mp3 192kbps**(元の曲は 128kbps。加工のあと同じ 128kbps で書くと、もう一段こもるため上げた)。タグは落とす
- 合成の部品は、どれも -1dBFS を超えない大きさにしてある。場面の音量は出口の手前の音量(ゲームなら効果音の音量 seBus)で決める

### ゲームで使うとき

1. 曲から作った音: そのファイルだけを `monster-hero/audio/se-<id>.mp3` へコピー → `node tools/build.js`(キャッシュキーと事前ダウンロードの一覧が付く) → `Audio_.playSeFile` で鳴らす。素材庫の方は消さない
2. 合成の音: `se-synth.js` の関数を `monster-hero/src/parts/14-audio.jsx` へ移し、出口に `seBus` を渡す(`ctx` は `getAudioCtx()`)。事件簿の音量設定(r1126-116)の「効果音」「環境音」「時計の音」の出口を選ぶ
3. 足したら ⑤ の更新履歴・ヘルプ(`changelog-help-update` スキル)

### 作り直す・足すとき

- 足す: `se-library.json` に1件足す → `python3 -I tools/audio/se-library-build.py --only <id>` → `node tools/audio/se-library-page.js`
- 素材の曲は `monster-hero/audio/` の配信中の曲と、`tools/art-sources/song-audio/` の声だけの音源。曲はどれも流用してよい(社長が権限を持っている・r1126-121)
- 同じ一覧からは同じ音ができる(残響の雑音は id ごとに決まった種から作る)
