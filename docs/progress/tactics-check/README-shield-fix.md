# 直した: ドリーミィのミルフィーシールドの数字が枠の中で重なる(2026-11-01・レフェリーくん)

セコンドくんが点検で見つけた崩れ(ドリーミィのEX「ミルフィーシールド」のあと、枠の中で 🛡️の数字・ライフ・GUTS の数字が重なって読めない)。
原因: 🛡️の数字をライフの数字の前に足していたので、狭い枠(375幅など)で行に入り切らず折り返し、下の GUTS の行にかぶっていた。
直し方(71-screen-battle.jsx): 🛡️の数字を「ライフ」の文字の代わりに出す(盾があるときは「🛡️360」、無いときは「ライフ」)。横向きは、盾がある間だけ「/最大」を隠す(ライフの棒で割合は分かる)。

| 直した_ドリーミィ_シールドの数字_横 | 844×390。「🛡️360 720」「GUTS 70/140」 |
