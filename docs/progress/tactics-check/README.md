# タクティクスの点検(見た目)— きゅうこのアシカ・イルミネを中心に(2026-11-01・レフェリーくん)

社長「タクティクスバトルで、見た目やシステム面の不具合・改良したい所を確認して。特に、きゅうこのアシカやイルミネが出て以降の確認作業をあまりしていないので、よく見てほしい」(ジン部長経由)。見た目の担当。

撮るときの箱の中だけ、イルミネの解放と教えカードの候補(きゅうこ)を入れた。
