## 確かめて問題なかったもの

- 楔は枠ごとに数える(イルミネとドリーミィを並べても混ざらない)。持ち主が回避すると0へ戻る。ジエンドのあいだは1回で2つ・上限12
- きゅうこの譜面の引き受けは、単体攻撃だけ・使ったターンだけ(ターンの始めと敵の番のあとで消す)。全体攻撃は引き受けない。EX「みんなをかばう」があればそちらが勝つ
- AIコピーは元の子の山札からカードを使う。ソラシドの自動化そのものは使わない(重ねて出ない)。きゅうこの譜面は使うことがあり、そのときは元の子が引き受ける
