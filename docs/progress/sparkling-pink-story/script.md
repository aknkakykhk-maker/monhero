## 場面の流れ(要点)

1. **夜の広場**: ドラとももすけが、夜中に小さなピアノの音を聞く。行ってみると、ききがひとりで鍵盤に向かっていた。
   ききは「{name}がモンヒロビートで遊ぶのを横で見ていて、いつか私の曲でも遊んでもらいたい」と打ち明ける。まだ1曲もできていない。2人が手伝うと言う
2. **次の日の広場(みんな)**: ききの1曲目の試し弾きは、強い音だけを全部入れた「火力全開」の曲。
   あつ「叩きごたえはすごい笑」/きゅうこ「ずっと全力だと聞かせどころが分からない」/ソラシドが速さと強い音の置き場所を計算/
   えるびん「聞いた人にどんな気持ちになってほしい？」→ きき「明るい気持ち。春にみんなで桜を見に行けたら、その日みたいな」→ ももすけ「キラキラのピンク！」
3. **何日かあとの夕方**: ききは何日も鍵盤に向かう。きゅうこのお茶、ドラの夜食(具が2倍)。
   「やさしい音でかけ上がって、いちばん大事なところだけ思いきり押し切る」—— ききの音が見つかる
4. **曲の名前**: ももすけの「キラキラのピンク」から「Sparkling Pink」、はじめての曲なので「始まりの曲」の「Overture」
5. **お披露目(広場)**: みんなの前で弾く(明るいピアノが桜色の舞台に広がる)。みんなの感想。
   最後にききが{name}へ「モンヒロビートに入れてもらいまちた。難しめなので気をつけて。遊んでもらえたらうれしい」→ 締めの札 → 曲えらび
