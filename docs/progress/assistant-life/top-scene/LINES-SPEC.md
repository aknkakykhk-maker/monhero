# 助手ライフ「できごと」と「家の場面」の台詞の頼み方(ナカヨシ20・2026-11-11)

社長の決め: できごとは案A 小さな場面(いま一緒にいる2人の掛け合い → 2択 → 返事で台詞が変わる・ときどき珍しいできごと)。
口調の要点と検査は [PLAN.md](PLAN.md) の「すり合わせ」。台詞はこの2つのテキストに書く(取り込みの道具 `tools/assistant/life-daily-import.js` が data へ入れる)。

助手id: mua(みゅあ) kiki momosuke(もも) dra atsu kyuko sorashido erubin
時間帯: late(深夜) morning(朝) noon(昼) afternoon(午後) evening(夕方) night(夜)
表情: normal happy excited wink surprise troubled angry crying
`{name}` = プレイヤーの呼び方(仲良し度で変わる。きき「◯◯さん/◯◯ちー」など)。`{c}` は相手の助手の呼び方(back の中だけで使ってよい・open では使わない)

## 1. daily-lines.txt(家の場面で顔を押したときの一言)— 8人×6時間帯×2本 = 96本

```
mua evening happy 夕焼けまぢきれい〜 写真とっとこ📸
```
1行 = `助手id 時間帯 表情 台詞`。その時間帯にひとりでいるときの独り言(ソラシドの独り言はタメ口でよい)。

## 2. daily-scenes.txt(できごとの場面)— 時間帯ごとに2場面 = 12場面

場面ごとに、まず頭の1行(場面id・題・2択の文)。2択はプレイヤーの返事なので、助手の口調ではなくふつうの言葉で短く(12字くらいまで)。

```
scene evening-1 夕日を見る | 📸 一緒に写真を撮る | 🌇 ふたりを撮ってあげる
```

続けて、8人ぶん × 4役の台詞(1場面 32本・全部で 384本)。

```
evening-1 open atsu happy 夕日やば笑 空ぜんぶオレンジなんだけど
evening-1 back atsu happy それな笑 今日いっぱい動いたし！
evening-1 r1 atsu excited いい顔〜笑 これ待ち受けにしよ
evening-1 r2 atsu wink え、オレらだけ？ じゃあ次は{name}も入って笑
```

| 役 | いつ言う | 気をつけること |
| --- | --- | --- |
| open | 場面のはじめ(2人のうち先に話す人。ひとりのときもこれ) | 時間帯と場面が分かる一言。相手の名前は入れない(誰と組むか決まっていない) |
| back | 相手の open を受けて(2人のときだけ) | どの助手の open にもつながる、ゆるい受け方 |
| r1 / r2 | プレイヤーが2択の1つめ/2つめを選んだあと(2人なら open の人が言う) | プレイヤーへ向けて言う(ソラシドは仲良し度の口調で) |

## 3. 珍しいできごと(daily-scenes.txt の続き)— 6つ × 8人 × 2役 = 96本

ときどき(だいたい数日に1回)出る。2択はなし。見ると思い出アルバムに1枚残る。

```
rare shootingstar night 流れ星
shootingstar open kyuko surprise あ、いまの見た？ 流れ星…！
shootingstar back sorashido excited 見た見た！ 願いごと間に合わなかったー
```

題の案(時間帯): 流れ星(夜・深夜)/虹(午後)/夕立で雨宿り(午後・夕方)/朝焼け(朝)/まんまるの月(深夜)/ねこが遊びに来た(昼)。変えてよい。

## 本数のまとめ
- 1. ひとこと 96本 / 2. 場面 12場面×32本 = 384本 / 3. 珍しい 6×16本 = 96本
- 一度に全部が重ければ、2. を「時間帯ごとに1場面(192本)」から始めてよい(2場面めは後から足しても動く)
