# 助手の行き先を決める・1日の予定を組む(設計案 ナカヨシ11 2026-11-11)

社長「助手を次の移動のときにどこにいかすか提案したりスケジュールを組めるようにしたい」。
選んだ答え: ①提案は「たいてい行く」(仲良し度が高いほど聞いてくれる。ときどき「今日は◯◯の気分」と断る) ②組めるのは1日ぶん(今日の移動の回ごとに行き先を決める・空けた所は助手にまかせる)。
**まだ作っていない。この設計と止め絵・画面の文に社長の OK をもらってから作る。**

## 1. 動き(1人・1回の移動)

1. プレイヤーが「次の移動(◯時)で、◯◯をここへ行かせる」と決める(場所は 12 か所のうち、助手が行ける所。寝る時間帯の助手・フレンドの家は決められない)
2. その時間帯が来て助手の様子を決めるとき(`assistantLifeNow`)に、予定を読む。**聞いてくれる確率** = 0.65 + 仲良し度の段 × 0.03(最大 0.93)。ふだんの行き先の重みはそのまま残し、予定の場所を選んだときは、その場所でできる「していること」を助手の好みの重みで選ぶ
3. 断る・従うは時間帯の乱数(salt・abs)で決める。**開き直しても結果は変わらない**(押し直しで当たりを引く遊びにしない)
4. 結果は「助手の一言」で出す。従う: 「いいね、{place}行ってくる！」/断る: 「今日は◯◯の気分なんだ」(◯◯ = 実際に行った場所)。8人ぶん × 従う・断る 各2本 = 32本(ココロ2に頼む。口調は VOICE.md・SPEECH-STYLE.md)
5. 断っても「聞いてくれなかった」とは出さない。助手の気分として出す(生活している感じを残す)

## 2. 置き場所(3か所に1つずつ。重ならない分担)

| どこで | 何をする | 他との分担 |
| --- | --- | --- |
| **町の地図の「場所の窓」**(推奨の入口) | 場所を押すと、いる助手の下に「📍 次の移動でここへ」の行(助手ごとに選ぶ・44px 行)。「得」の印がある場所は、行に「得」も出す | 地図は居場所の画面。ここで「場所から助手を選ぶ」 |
| **助手の部屋の「できること」** | 「📅 次の行き先を決める」の1行 → 12 か所の一覧(得の印つき) | 部屋は「助手から場所を選ぶ」(ナカヨシ13) |
| **📅 今日の予定表**(新しい小さな窓。部屋・地図の上の帯の「📅」から) | 今日の残りの移動の回(朝・昼・午後・夕方・夜)× 8人の表。決めた所に 📍、空けた所は「おまかせ」 | 「1日ぶん」を組む画面はここだけ |

- **家の上の帯には出さない**(ナカヨシ16の「得」3行・ナカヨシ17の毎日来る理由と重ならないため)。帯に出すなら、予定表の「📅 あと◯回の移動が空いています」の小さな1行だけ(得の行の下)
- 「いま行くと得」の判定は `assistantLifePerkAt(place)`(ナカヨシ10)を使う。場所の一覧・地図の札に「得」の印、選ぶ窓の先頭に「得のある場所」を並べる

## 3. 他の仕組みとの関わり

- **修行(シュギョウ)**: 「モンヒロバトル」に行かせる = その回に助手のマスモンが修行する。予定表の 📍 に「修行」の小さな印(1日2回まで、は修行側の決まりのまま)
- **M/B管理のチケット(ナカヨシ10)**: 行き先が ranch の回は「育成の得」の行がそのまま出る。この仕組みは行き先を変えるだけ
- **フレンドの家**: 助手が「家にいる/出かけている(行き先)」はいまの様子(life)から出している。**予定は様子を決めるときにだけ効き、保存した様子が正本**なので、フレンドに見える行き先と食い違わない。フレンドの家への行き先は予定に入れられない(フレンド側の仕組み)
- 声かけ(`nudges.invite`)・引き合わせ(`introduce`)は今のまま。同じ回に両方あれば、**声かけ・引き合わせが先**で、予定は別の助手にだけ効く

## 4. 保存(新しいキーだけ)

`mh_assistant_life_plan_v1` = `{ day: 'YYYY-MM-DD'(朝4時区切りの日), plan: { [abs(時間帯の通し番号)]: { [助手 id]: 場所 id } }, result: { [abs]: { [助手 id]: 'ok'|'no' } } }`

- 読むときは `normalizeAssistantLifePlan`(型を確かめ、壊れていれば空)。日が替わったら捨てる。今日より前の回は読まない
- 既存の `mh_assistant_life_v1`・`mh_assistant_life_play_v1` は変えない(CLAUDE.md ⑦)。公開の印は `assistantLife` の後ろ
- 予定の変更は「その回の2つ前の時間帯の終わりまで」はなく、**今の回が終わるまで何度でも直せる**(次の回の行き先を決めるだけなので、悪用の余地がない)

## 6. 社長に決めてほしいこと(選択式)

1. 入口は地図の窓・部屋・予定表の3つでよいか(推奨: 3つ。減らすなら予定表だけ)

## 8. 移動12回での組み直し(ナカヨシ19 2026-11-11・止め絵 `schedule/mock-*.png`・見本 `schedule/mock.html`)

移動は2時間ごと・1日12回(SLOT12-AUDIT.md)。1日に組める回が倍になるので、表の形だけを変える(動き・保存・確率は上の1〜4のまま。社長の決め #5301)。

- **回の数え方**: 予定の1マス = 12区切りの1回(`abs` = 日×12+j)。保存 `mh_assistant_life_plan_v1` の `plan` のキーは新しい abs。名前は6つの時間帯(朝・昼・午後…)を添える(「16〜18時 午後」)
- **今日の範囲**: いまの次の回から、その日の 0時(22〜24時の回)まで。深夜(0〜4時)は寝ている助手が多いので出さない
- **縦(390×844)**: 上に8人の顔(押して1人を選ぶ)→ その助手の今日の回が縦に並ぶ(1行44px・終わった回は薄く「✓ 行った」・いまの回は黄色の枠・先の回は「📍 決める」/「変える」)。下に「◯◯を ぜんぶおまかせに」と、いまの聞いてくれる割合(💗 約◯%)
