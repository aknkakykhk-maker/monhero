- `hair-3bg/<表情>.png` … 9枚それぞれ、髪まわり4か所(アホ毛・ポニーテールの付け根・左の毛先・右の毛先)を3倍に拡大。
  上の段が前(いまの公開版)、下の段が後。各か所を 暗(#111)/中間の灰(#808080)/明るい(#f2f2f2)の3つの背景で

直したこと
- 半透明の縁の幅を詰めた(暗い背景で明るい輪・灰色のもやに見えない)
- 縁の色を内側の髪・体の色で置き換えた(マゼンタの滲み・白いにじみの線を取る。アホ毛のピンクも)
- 薄くて体から浮いたかけら(細い線・点)を捨てた
- 羽・マント・手袋のフチも同じ作りで直した(フチの検査 life-fullbody-edge-check で9枚とも OK)
- wink も作り直し版にそろえた
- 土台の髪の外側に残る細いピンクの線は、final で描き直された線画そのもの(不透明の描き込み)なので残している

## 1回目
- 8表情は raw(マゼンタ背景)から抜き、final と違う所(angry の顔・troubled の耳飾りを消した所など)は final の絵を使う
- 土台は final が描き直された別の絵(raw と画素がそろわない)なので final から抜き直す(金の円盤なし・右耳の下パネルは縞模様)
- 編み目の四角(`decor-mask.json`)は、同じ髪の帯の少し右上を写して埋める(髪の輪郭は変えない)
- 大きさは差し替え前の公開版の「画像の高さ・体の上端・体の高さ」(`body-height.json`)にそろえる。減色しない

作り方: `python3 tools/assistant/life-card-master-recut.py`(素材は `tools/art-sources/assistant-fullbody/mua-card-master-2026-11-23/`)

残り: 立ち絵 stand-card-master(全身が決まったら作り直す。道具の hold・wink の場面で顔がずれる注意は差し替え前の絵でも出る)
