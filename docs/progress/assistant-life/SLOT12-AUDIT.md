# 助手ライフの移動を 1日6回 → 12回にする: 洗い出し表(ナカヨシ11 2026-11-11)

社長の決めごと(台帳 #5303・#5304): 区切りは2時間ずつ均等/いまの6つの時間帯の傾向(`ASSISTANT_LIFE_SLOT_MOD`)は変えない/時間帯ごとに戻る得は1回ごとの量を約75%(1日の合計は約1.5倍)/保存の abs(= 日×6+i)を壊さず読み替える。
**まだ作っていない。この表に窓口の OK をもらってから作る。ミハリ3の確認対象。**

## 1. 作り方(案): 6つの名前は残し、数え方だけ12にする

- `ASSISTANT_LIFE_SLOTS`(深夜・朝・昼・午後・夕方・夜 の6つ)と、そのキー `id`・`label` は **そのまま**。傾向の表(SLOT_MOD・PREFS の slot・RHYTHM の slot)・時間帯の見た目(朝昼夕夜)・フレンドの `life.slot === 'late'/'night'` は変えなくてよい
- 新しく **12個の区切り**(0-2・2-4・…・22-24 時)を持つ。各区切りの傾向は、**区切りの真ん中の時刻がどの6つに入るか**で決める(0-2・2-4=深夜 / 4-6・6-8・8-10=朝 / 10-12・12-14=昼 / 14-16・16-18=午後 / 18-20=夕方 / 20-22・22-24=夜)。4-6 時は真ん中が5時なので朝になる(いまの「朝 5:00〜」と同じ)
- `assistantLifeSlotAt()` は `{ abs, i, id, label }` に **`abs`(新: 日×12+j)・`j`(0〜11)・`absV1`(旧: 日×6+i)** を足して返す。**`i`・`id`・`label` は6つのまま**なので、`slot.i`・`slot.id` を使っている所は変わらない
- 保存の印: `mh_assistant_life_v1` に `v: 2` を足す(既存の項目は消さない)。`v` が無い・1 のものは旧データとして読む
