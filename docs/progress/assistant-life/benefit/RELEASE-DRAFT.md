## 何を作ったか(新UIだけ・旧UIは触らない)
- B 家のいちばん上の「✨ 助手ライフの得」3行: ⏰ いま(いる助手の場所の得。STEP2 の帯をそのまま1行目に・ほかは「ほか◯件」)/📅 今日(見守る 今◯組・贈る あと◯回 → 🤝 友情Lv・💗 仲良し度が上がる。押すと見守る/贈る)/🌱 次のごほうび(いちばん近い助手の「💗 仲良し度 Lv◯ まで あと◯」と開くもの。押すと「きずな」へ)。「❓ 見かた」で1枚をいつでも開ける
- C 「きずな」の先頭の「🎁 ごほうびの道のり」: 💗 仲良し度(あと◯の小さい順)・🐾 次に迎えるマスモン・🤝 友情Lv(助手どうし)。近い所だけ出し、「ぜんぶ見る」で全部。助手の行を押すとその部屋へ
- 案1 初めて開いた人に1回だけ1枚(下の3行)。見守る札が光って「👆 まずはここ」。「見守ってみる」「わかった」で消える
- 新しい保存は「見た」の印 `mh_assistant_life_guide_seen_v1`(boolean・新しいキー1つ。SAVE_DATA.md に追記済み)。新しい報酬の数字は作っていない(いまある決まりを読むだけ)

## 案1 の3行(この文で?)
- 見守る・贈る・おしゃべり で、助手たちと過ごす
- 仲良くなるとごほうび が届く(ダイヤ・飾り枠・話し方・マスモン)
- ほかの遊びも得に なる(モンヒロビートは券なし・カードはごほうび1.5倍)
- 「まずは 光っている「👀 見守る」を押してみよう」
