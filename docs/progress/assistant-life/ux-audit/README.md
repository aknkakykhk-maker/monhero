## そのほか気づいたこと(小さいもの・重い順)

11. 部屋を下へ送ると、上に残る「← 家へ」が「仲良し度 Lv1」の字にかぶる(`shots/extra-tate-room-ranch-acts.jpg`)
12. マスモンの行の言い方: 部屋の行は「ももすけのマスモン 1体」と「ドラのマスモン」(数あり・なし)、くわしくは「ゆめっち ほか0体」。「ほか0体」は出さない
13. 部屋の「仲良し度 Lv2 で: 話し方・飾り枠・ダイヤ×10,000・虹のプシュケー×10」が家の帯・きずな・部屋の3か所で同じ長文。家の帯は「Lv2まであと38」だけにし、中身は部屋ときずなで
14. 「にぎやか ×1.5 ⓘ」「お祭りまで 48」: 何が1.5倍かは ⓘ を押さないと分からない。横に「(仲良し度・友情Lvのたまり方)」の短い字
15. 📖紹介の一覧の「選ぶと、その助手のことが分かります」が空色の上で薄くて読めない(`shots/extra-tate-profile-list.jpg`)
16. 家の部屋の札: 昼は8部屋のうち7部屋が「留守」。名札・行き先の字が 9px、「ドラ ほか2人」「みゅあ・きき」が自分の部屋でない人の名も並ぶ。横は「おやつ屋さんへ…」と切れる(ナカヨシ20 の断面図で直る見込み)
17. 町の地図だけタブが上・ほかの画面は下(縦)。場所が変わって迷う
18. 出かけている助手の部屋が空っぽの絵なのに「おしゃべりする」が押せる(遠くにいてもできるなら「メッセージを送る」など言い方を)
