## 1枚の中身と、使い回すデータ(新しく作る文はほぼ無い)

| 段 | 出すもの | 元のデータ |
| --- | --- | --- |
| 上 | 立ち絵(表情 happy)・名前・一言紹介・ひとこと | `ASSISTANTS` の `name`・`tagline`・`greeting`・立ち絵 |
| 人となり | 性格・生活・いまの話し方 | `intro`(助手えらびの「くわしく」と同じ文)・`ASSISTANT_LIFE_RHYTHM` の `label` と寝る/起きる時刻・`ASSISTANT_BOND_STYLES[id].tones[Lv-1]` |
| 好き・苦手 | 道具(2人・1人)・家具・モンスター | `ASSISTANT_LIFE_GIFT_LIKES`・`_SOLO_LIKES`・`_FURN_LIKES`・マスモンの表の `likeMon`/`dislikeMon`。分かったかどうかは保存 `mh_assistant_life_likes_v1`(読むだけ)。ヒントは `ASSISTANT_LIFE_GIFT_HINT_LINES` |
| きずな | 仲良し度・称号・次のLvまで・呼び方・推し・マスモン(勇者モン先頭に3体+「くわしく」) | 仲良し度の保存(読むだけ)・`titles`・`call`・`assistantLifeCardMaterial(id).core`・マスモンの保存(読むだけ) |
| 台詞 | 表情つきの吹き出し・種類のタブ・「もう1つ聞く」 | あいさつ(`greeting` ほか既存のホーム台詞)・おしゃべり・贈ったとき(`ASSISTANT_LIFE_GIFT_LINES` ほか)・寝言(`ASSISTANT_LIFE_SLEEP_TALKS`)。`bond:N` 付きの台詞はそのLvから |

- **保存は増やさない・書かない**(読むだけの画面)。ミハリの確認は「新機能」で要るはず(公開前に gate)
- 新しく要る文は、見出しと説明の数行だけ(「？は贈ると分かります」など)。口調の要る文は作らない
- 公開前の助手: 画面に並べるのは `assistantUnlockedBy` を通した助手だけ(`unreleased-assistant-hidden-check` の①に合う書き方)
- ファイル: 新しい部品 `56-assistant-life-profile.jsx` に画面を1つ足し、入口は部屋(`56-assistant-life-house.jsx` の部屋の見出し)に1か所だけ足す。ナカヨシ11(移動12回・予定表)と同じファイルを触るのは入口の数行だけ。触る前に知らせる

## 決めてほしいこと(案と推奨)

### Q1 入口をどこに置くか
- **A(推奨) 部屋の右上に「📖 ◯◯のこと」の札**。部屋を開いた人が必ず目にする・いまの押す所とかぶらない
- B 部屋の「仲良し度」の札を押すと開く(見た目は変わらないので気づかれにくい)
- C 家の名札を押す(いまは部屋が開く所。押し分けが分かりづらくなる)
- (Aと一緒に「友情」タブの助手の顔からも開けるようにはできる。まずはAだけで出す案)

### Q2 好き・苦手を最初から全部見せるか
- **A(推奨) 分かったものだけ出し、まだのは「？」**。いまも贈ると好みが分かる仕組み(`mh_assistant_life_likes_v1`)があるので、それを並べるだけ。「？」の下に助手のヒント台詞を1つ出す。モンスターの好き・苦手は贈る仕組みが無いので、最初から出す案(隠すなら仲良し度で出す)
- B 仲良し度で少しずつ分かる(Lv3で1つ…)。贈って分かる仕組みと二重になる
- C 最初から全部見せる。分かりやすいが、贈って当てる楽しみが消える

### Q3 ボイスが無い助手は
- いま、助手のボイスの音はどの助手にもありません
- **A(推奨) 台詞の文字+表情が変わる吹き出しで「試し聞き」**。ボイスが届いたら同じ吹き出しで音も鳴らせる形にしておく
- B 端末の読み上げで声を出す(機械の声になり、キャラの声と違う)
- C ボイスが届くまで台詞の欄を出さない

### Q4 まだ会っていない・公開前の助手
- 公開前の助手(公開の印が立っていない)は、どの案でも名前も絵も出さない(決まり)
- **A(推奨) 会っていない助手は紹介ページ自体が開かない**(部屋も家に出ていないので、入口が無い)
- B 「？？？」の影で並べ、加入のお話の後に開く(ネタバレの心配と、一覧の画面が別に要る)

### Q5 台詞の量
- **A(推奨) 仲良し度で増える**。いまのLvまでの台詞だけ聞け、先は「🔒 Lv10 から」と数だけ見せる(また来る理由になる)
- B 全部いつでも聞ける
