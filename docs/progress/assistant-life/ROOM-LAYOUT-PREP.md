## 2. おまかせの型(8人のくせ)

置き方がどの形になっても使えるよう、「どの家具を先に」「どこへ寄せるか」「どうそろえるか」の言葉で決めておく。
好きな家具から先に置き、苦手な家具は押し入れへ。置ける数を超えた分も押し入れへ。

| 助手 | 主役(いちばん良い所へ) | 寄せ方 | そろえ方 |
| --- | --- | --- | --- |
| みゅあ | くまのぬいぐるみ | 真ん中に集める | 左右をそろえる(鏡の左右に同じ数) |
| キキ | 小さな本棚 | 壁ぎわ・植物は窓辺 | 等間隔にきっちり |
| ももすけ | レコードプレーヤー | 音の出る物をひとかたまりに・ミラーボールは真ん中の上 | にぎやかに・間をつめる |
| ドラ | ふかふかソファ | ぜんぶ床の低い所へ・ソファのとなりにクッション | ゆるく・かたまりで |
| あつ | トロフィー棚 | トロフィーは壁の真ん中・ソファは手前 | 主役のまわりを空ける |
| きゅうこ | 星空の絵 | 絵は目の高さ・クッションは窓の下 | 余白を多めに |
| ソラシド | 星のランタン | 星の物を上に集める・トロフィーは目立つ所 | 上から順に高さをそろえる |
| えるびん | 観葉植物 | 植物と風鈴は窓のそば | すっきり・床は広く空ける |

ひとこと(コトバ・ツムギへ頼む分・1人3行): ①並べ終わったとき ②好きな家具が主役になったとき ③置く家具が少ないとき(「もっとあったらうれしい」の気持ち。ねだりすぎない)。
口調は `VOICE.md`・`SPEECH-STYLE.md` のとおり。試作に入れた4人ぶんは仮の文。

## 3. 保存の形(作るときの決めごと)

- 新しいキー `mh_assistant_life_room_layout_v1`: `{ [助手]: { items: [{ k 家具, x, y(部屋に対する割合 0〜1), f 向き, z 前後 }] } }`。
  読むときは正規化を通す(知らない家具・持っていない家具・数でない値は捨てる。同じ家具は1つだけ)
- 一度きりの写し: フラグ `mh_assistant_life_room_layout_migrated_v1`。今の天井・壁・床の3つを、今と同じ見た目の位置へ写す
- 今の `mh_assistant_life_room_v1` は消さない・書き換えの意味を変えない。持っている家具(got)・贈った日は今のキーが正本のまま。
  「部屋に出ているか」は新しいキーが正本になり、今のキーの put / kept も合わせて書き続ける(古い版へ戻しても部屋が空にならないように)
- フレンドの家へ送る控えは、今の3つの項目(c・w・f)を残したまま「並び」を足す

**まだ入れていないわけ**: 保存の形(とくに x・y の意味と写し先)は置き方で決まる。社長の別案が来る前に本番へ入れると、
形が変わったときに二度目の写しが要り、保存データを二重に動かすことになる。小さな部屋で家具を顔の後ろに描く直しも、
今の3つのままだと顔に隠れて見えにくくなるだけなので、新しい並びと一緒に入れる(カルクが直した測り直しはそのとき外す)。
