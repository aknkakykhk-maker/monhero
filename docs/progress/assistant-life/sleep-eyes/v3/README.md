# 寝顔 3回目: A'(道具の手直し)の前後 — 2026-11-11 ネガオ

行はどれも上から みゅあ・きき・ももすけ・あつ・きゅうこ。

- `house-*` 家の部屋の顔 / `map-*` 地図の全身 / `bed-*` ベッド: 列は [目を開いた元 | 前(SVG) | 案A | A']
- `scene-*` 場面の立ち絵(ようすを見る): 列は [前(SVG) | 案A | A'](A' だけ切り出しの高さが少しちがう)
- `*-actual.jpg` スマホの実際の大きさ(2倍の細かさ)/ `*-3x.jpg` その3倍
- `source-full.jpg` / `source-face.jpg` 元の絵の大きさで [元 | 案A | A'](全身・顔アイコン)

A' で変えたこと(原因の3つをつぶす):
1. 埋める範囲を目の形(上まぶたの線〜下まつげ・目頭〜目じり)に絞り、まわりの肌を「明るく・暗くしただけの色」だけを手本に埋める → 目のくぼみ・前髪の影の濃淡が残る。ごく弱い肌の粒も足す
2. 閉じた線は、元の絵の上まぶたの線から太さと色を測り、目頭は細く・目じりは太く跳ねる形を、絵の細かさのまま描く(色は目頭が薄く目じりが濃い)。線の少し上にまぶたの影をぼかしてのせる
3. まつげは、根元が太く先が細い束を3本
前髪: あつ(赤)・きゅうこ(ばら色)・きき(桃色。上まぶたより上だけ)は、目にかかる髪を消さずに前に残す

残る所: あつは線が薄めで、前髪の間の肌が少し濁る。ききは目の上の前髪の際が少し明るい
