# 助手ライフの寝顔(閉じた目)の直し方の案 — 2026-11-11 ネガオ

社長「寝顔で目を瞑ってるやつが変な感じ。ききとかももすけとかが特に気になる」

## 何が変だったか(本物の画面を4倍で撮って確かめた)

いまは目を開いた絵の上に、SVG で「肌色の楕円1色 + まぶたの線 + まつげ3本」を描いている(`AssistantLifeSleepEyes`)。

1. **線が太すぎる**: 線の太さが画面の画素で最低 1.1px なので、顔アイコン(約40px)や地図の小さな全身では絵の線の何倍も太く、まつげと混ざって「骨」「なめくじ」のような塊になる(きき・ももすけ・きゅうこが特にひどい)
2. **塗りの色むら**: 楕円1色なので、まわりの肌のグラデーション(頬の赤み・前髪の影)と合わず、目の所だけ平たい色の楕円が浮く(ももすけの左目は赤黒く、ききは桃色に)
3. **塗り残し**: ききの顔アイコンの左目は、楕円が小さく瞳の下が覗いている
4. **前髪にかかる**: 目にかかる前髪の毛筋を楕円が消している(あつ・きき)

止め絵: `zoom-now-kiki-momosuke.jpg`(左: 目を開いた元・右: いま)

## 案

- **A(推奨)道具で「閉じ目の重ね絵」を助手ごとに作る**: 目の範囲を、まわりの**肌の画素だけ**から滑らかに埋め(髪や線の色は混ぜない)、
  その絵の線の色(目のいちばん暗い所)で、**絵の解像度で**細いまぶたと短いまつげ2本を描いた透明PNG(5人 × 全身・顔 = 10枚、1枚 4〜37KB)。
  画面ではもとの絵と同じ大きさで重ねるだけなので、小さく出しても線が太らない。目の位置の表はいまのものを使い回す
- **B** いまの SVG のまま、線の太さを絵の大きさに比べて決め直し・まつげを減らし・色を1人ずつ合わせ直す。軽いが、単色の楕円の色むらと前髪の消えは残る
- **C** 社長に閉じ目の絵を描いてもらう(届くまでは目を描かず 💤 だけ)
