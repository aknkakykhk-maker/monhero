# 寝顔 4回目: 「消し方が雑」の見直し — 2026-11-11 ネガオ

閉じた線を描かずに「目を消して肌で埋めた所」だけを、元の絵の大きさの2倍で見たもの。左が元、右が消したあと。行はみゅあ(左目・右目)・きき・ももすけ・あつ・きゅうこ。

- `erase-Aprime-eyes.jpg`: A' の消し方(目の形の楕円をまるごと埋める)
  - 目にかかる髪の毛筋まで消え、髪の縁が楕円の線で段々に切れる(きき・きゅうこ・あつ)
  - きき: 前髪を残す判定が色の閾値だけなので、桃色の切れ端がちぎれたように残る
  - みゅあ: 埋めた色が灰色に濁り、右目は瞳の青い縁が少し残る
  - あつ: 前髪の間の埋めた所が、まわりより明るい四角い塊になる
- `erase-try-color-hair.jpg`: 試したが悪くなったもの(目の上の髪から色を集め、近い色を髪として残す)
  → 髪の明るい所と白目・光・瞳の色を区別できず、白目や瞳が残った。きき は髪ごと消えた
