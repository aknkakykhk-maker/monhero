それぞれ全身の立ち絵と顔アイコンの2枚、計14枚。重ねるのは目のまわりだけ(元の開いた目がまるごと隠れる芯の外側をぼかす)。ももすけ と、絵の無い着せ替えは、いままでの寝顔のまま。

本物の画面(縦・行は みゅあ・きき・ももすけ・あつ・きゅうこ):
- `house-*` 家の部屋の顔 / `map-*` 地図の全身 / `bed-*` ベッド: [元の目を開いた絵 | 社長の絵を入れたもの]
- `scene-*` 場面の立ち絵(ようすを見る): [いままでの寝顔 | 社長の絵を入れたもの]
- `*-actual.jpg` スマホの実際の大きさ / `*-zoom.jpg` その3倍
- `face-*.jpg`: 元の絵の大きさで目のまわりを [元 | 重ねた後](着せ替え3つを含む14枚)

合わない所:
- みゅあ(3着とも): 目のすぐ上の前髪の毛先が、うっすら二重に見える(社長の絵と元の絵で前髪の毛先の位置が少しちがう)
- 社長の絵は元の立ち絵より小さく描かれているので、約2倍に広げて重ねた所(きき・ききハロウィン・みゅあの着せ替え)は、元の絵より少しやわらかい(画面の大きさではほぼ分からない)
- 着せ替え3つは本物の画面では撮っていない(着替えさせる手順が要る)。`face-halloween_*` `face-card-master_*` で元の絵の大きさを確かめた
