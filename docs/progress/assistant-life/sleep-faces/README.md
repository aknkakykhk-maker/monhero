# 社長の寝顔の絵をそのまま使った止め絵 — 2026-11-11 ネガオ

社長「絵をそのまま使う」: 寝ているあいだは、社長が描いた上半身の寝顔の絵をまるごと出す(ふちのごみは取った)。
受け取った絵: `tools/art-sources/sleep-faces/`(加工せずに残す)。作る道具: `tools/assistant/life-sleep-faces-make.js`

- 絵は、元の立ち絵と同じ大きさ・同じ顔の位置に合わせて ◯◯_sleep.PNG として置く(全身と顔アイコン)。だから、どの場所でも今までの顔の大きさ・位置のまま収まる
- 全身を出していた所(地図・場面の立ち絵・ベッド)も、寝ているあいだは上半身の絵になる。腰の下の切れ目は少しぼかして消した
- 絵の無い助手(ドラ・えるびん・ソラシド)と、絵の無い着せ替えは、今までの寝顔のまま

本物の画面(縦・スマホの実際の大きさ。行は みゅあ・きき・ももすけ・あつ・きゅうこ。列は [今まで | 社長の絵そのまま]):
- `house-actual.jpg` 家の部屋の顔 / `map-actual.jpg` 地図 / `bed-actual.jpg` ベッド / `scene-actual.jpg` 場面の立ち絵(ようすを見る)
- `all-9-outfits.jpg`: 9着ぶん [元の立ち絵 | 寝ているときの絵](着せ替えは本物の画面では撮っていない)

社長の絵 → 入れた先: 赤い髪の男の子→あつ / ピンクの髪・赤いパーカー→きき / そのハロウィン→きき(ハロウィン) / 茶色の髪→きゅうこ / 金髪 天使→みゅあ / 青いマント→みゅあ(カードマスター) / 魔女→みゅあ(ハロウィン) / ももすけ ふだん・小悪魔→ももすけ(ふだん・ハロウィン)
