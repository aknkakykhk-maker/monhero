## 2 盛り上がりに合わせて量を配る(R6)は、既定にしていない

いちど作った譜面の実際の密度を区切りごとに測り、盛り上がりの順になっていない所を配り直して作り直す。強さ2つを7曲35譜面で比べた(前=R6 なしの Rev.38。動機の写しの条件を締める前の同じ時点の道具どうしなので、上の表と合計が少し違う)。

| --- | ---: | ---: | ---: |
| ノーツ数の合計 | 11,716 | 11,569 | 11,397 |
| 盛り上がりとの合い方(平均) | 0.62 | 0.61 | 0.60 |
| 静かなのに重い区切り | 63 | 71 | 71 |

| Lv. が2以上動いた譜面 | — | 2 | 6(どれも下がる) |

- 点検の数字は良くならず、ノーツが減る。濃い譜面(ヒューマノイド MASTER など)は鳴っている音をほぼ拾い切っていて、静かな区切りを軽くしてもサビへ回す音が残っていない
- ヒューマノイド MASTER(`'strong'`): 594 → 532ノーツ。入り 5.3 → 3.9/秒・間の静かな区切り 5.2 → 4.6/秒・サビ 6.3 → 5.9/秒。谷ははっきりするが、山は高くならない
- 盛り上がりに合わせる効き目は、上の「1 サビ」で先に出ている(静かなのに重い 76 → 63・いちばん低い合い方 −0.03 → 0.01)
- **社長の決定(2026-11-11・A): 既定にしない。曲ごとに使う。** 「この曲は入りと間奏をもっと軽く」と言われた曲にだけ、曲の一覧へ `energySpread:'strong'` を書く

## 公開中の譜面へ当てたら何が変わるか(読むだけ)

```
node tools/mode/rhythm-chart-compare.js --make <場所> --tracks <曲,曲>      いまの道具で作り直す(書き出すだけ)
node tools/mode/rhythm-chart-compare.js --released --after <場所> --tracks <曲,曲>   公開中の譜面(前)と比べる
```

合計と、譜面ごとの行(ノーツ / Lv. / 交差 / 届きにくい / 跳び / 盛り上がりとの合い方)が出る。公開中の譜面は人の手直しと公開時のつまみも入っているので、
差は道具の強化だけのものではない。例(Evans の EXPERT・MASTER): 交差 52 → 31・届きにくい 82 → 57・跳び 37 → 22・押せない 5 → 0・ノーツ 972 → 980・Lv. は同じ。
譜面を直す仕事(社長「譜面直しはツール強化がおわったあと」)は、この数字と止め絵を曲ごとに出してから決める。

## フメンの第1版との関係

連絡の行き違いで、フメンも同じ 1→2→3 の第1版をブランチ `claude/chart-engine-rev38` に作っていた(曲の一覧の `musicShape:true` で切り替え・既定は切・main 未マージ)。
窓口の「良い方を残す判断は任せる」で、7曲で測ってあるこちらの版を土台に残し、フメンの版からは「形ごとずらして写す」を取り込んだ。
フメンの版の「盛り上がりに合わせた配り」(持ち上げ幅を [.45,1.35] → [.35,1.5] に広げ、サビらしさを混ぜる)は入れていない(交差 145 → 161・跳び 221 → 239 と増える数字だったため。
量の配りは上の R6 と合わせて、社長が既定を決めるときにもう一度比べる)。そのブランチはマージしない。
