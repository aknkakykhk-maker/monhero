# Rev.38 は HELL でどう効くか(2026-11-11・フメン2・読むだけ)

社長の質問「新譜面制作ツールはヘルも考慮して考えられてるよね？」への答えの材料。
HELL の決まり(水平クロス0・帯の中0・上下の交差・空中と地上の入り乱れ)が崩れないかを、7曲で比べた。ゲームのデータ・authoring は変えていない。

## 比べ方

- 前 = Rev.37(main `afaa7385`)、後 = Rev.38(`claude/beat-chart-rev38` に main を取り込んだもの)
- どちらも `node tools/mode/rhythm-hell-mix.js --song <曲>`(書かない実行。`source:'audio'` の曲は、生成器 `--difficulty HELL` で骨組みを作ってから空中を付ける)
- 切り分けは作業用の写しだけで、hell-mix から生成器へ `--no-motifs` / `--no-chorus` を渡して作った(道具そのものは変えていない)

## Rev.38 の3つは HELL に効くか

| こと | HELL に効くか |
| --- | --- |
| サビを見つける(見せ場をサビへ・サビ前の溜め) | **効く**。生成器の `--difficulty HELL` も同じ通り道を通る |
| 短い動機の写し | **効く**(骨組みの段で写す)。ただし下のとおり HELL では悪い方へ出る |
| 量の配り直し R6 | 既定は切(社長の決定 A)。曲の一覧で `energySpread:'strong'` を書いた曲だけ |

## 切り分け(後の作りから1つずつ切る)

| 曲 | Rev.38 | 動機を切る(`--no-motifs`) | サビを切る(`--no-chorus`) |
| --- | --- | --- | --- |
| Rebellion short | 押せない2・交差2・届き4 | 押せない0・交差2・届き3 | 押せない0・交差3・届き4 |
| Altar short | 両手で押せない1・交差76・届き85 | **0**・72・85 | 0・65・77 |
| Toward short | 両手で押せない1・交差36・届き69 | **0**・23・47 | 1・36・69 |
| Evans | 交差32・届き61 | 25・49 | 32・61 |

→ 押せない所と交差の増え方の元は**短い動機の写し**。動機を切ると4曲とも押せない0になり、交差・届きにくいは Rev.37 と同じか少なくなる。
サビ(見せ場の位置)は HELL でも悪さをしていない。

**なぜ**: 地上の5難易度は生成のあと「手の仕上げ」(`rhythm-chart-flow-fix.js`)を通るので、写しで生まれた無理な形が直る。
HELL の骨組みは手の仕上げを通らずに `rhythm-hell-mix.js` で空中を付けるので、写した手の形(左右反転・最大2レーンずらし)がそのまま残る。
さらに空中を付けると左右の手の分け方が変わり、「同じ手の動き」の前提が HELL では成り立ちにくい。

## HELL ではどうするかの案(ジゴクの Rev.39 で)

- **A(推奨)**: HELL の骨組みは**短い動機の写しを既定で切る**(サビはそのまま使う)。7曲で押せない0・交差は Rev.37 並み。小さな変更で、既にある HELL の決まりと重ならない
- B: 動機の写しは残し、HELL の骨組みにも手の仕上げ(`must`=押せない・帯の中だけ)を通してから空中を付ける。押せないは消えるが、交差・届きにくいの増え(1〜3割)は残る
- C: そのまま(押せない所が出る曲がある)

数字の元(書かない実行の出力): 作業用の写しで作ったもの。作り直すときは上の「比べ方」の2本を同じ曲で回す。
