# 出来事の体力回復と説明の無い効き目

## 1. 結論(3行)
- 出来事の回復は1回あたり 24.6 で、休み(61.3)の半分以下です。1回の育成ではおおよそ休みの2〜3割にあたり、いちばん大きいのは記念日(31.9/育成)です。
- 社長案の +10 にそろえる試算(hp10)では、休む回数 +0.3・総合力 −108±26(−0.7%)と小さな悪化で済みます。けがはほぼ動きません。
- 説明の無い効き目のうち、ひらめき(noHira)は差があるとは言えず、一喝(noIssa)もごく小さいです。40以上の効き目は無くした方が総合力が上がります(+52±14)。

## 2. 表から読める偏り(大きい順)
1. **記念日が回復の中心**: ev.self.anniv は 31.9/育成で、event+ 合計 80.4 のうち最大です。出た育成の割合は 79.6%、1回あたり 40.1 です。2位の peakout(13.7)以下は、どれも 5 未満です。
2. **出来事の回復は休みより小さい**: 1回あたり出来事 24.6 に対し、休みは 61.3 です。育て方ごとの「出来事÷休み%」は 17.2(balance)〜27.1(train・tag)です。
3. **40以上の効き目は差し引きでマイナス**: no40 で総合力 +52±14(0.3%)、サボり −0.289、失敗の差は 0 です。
4. **一喝 ±5% は効きがごく小さい**: noIssa で −14±5(−0.1%)です。幅の外なので差はありますが、ほかの指標の差はすべて 0 です。
5. **ひらめき +15% はほぼ意味が無い**: noHira で −1±6 となり、差があるとは言えません。技の数も −0.012 です。

## 3. 原因の見立て
- **記念日**: +50 で、13〜15ターン目に選択肢なしで必ず起きます。そのため1件だけ飛び抜けています。1回あたりが 40.1 と +50 より小さいのは、体力上限で頭打ちになっているのかもしれません。
- **出来事 vs 休み**: 休みは上限の 50/70/90% 回復するのに対し、出来事は +10/+20/+30 です。削れる量(hp10 で −24.5)は休み1回分に届かず、休む回数が +0.3 で収まっているのはこのためかもしれません。
- **40以上**: 甘え40以上ではサボりが ×1.2 になります。一方、恐れ40以上の効果は失敗 ×0.9 ですが、「体力が上限の半分以上なら失敗率0%」なので、ほとんど効く場面が無いのかもしれません(失敗の差 0)。さらに基準で甘い側に終わる育成が 66.4% あり、マイナス側だけが効いている形かもしれません。
- **一喝**: イッサ博士は1ターン約3%・1育成3回までで、出る回数そのものが少ないためかもしれません。
- **ひらめき**: 修行は 1.6回/育成と少なく、+15% がかかる機会がわずかなのかもしれません。

## 4. 直し方の候補(決めるのは人です)
**候補A: hp10(出来事の +20・+30 → +10、記念日 +50 は据え置き)**
- 良くなる: ルールが単純になり、社長の言葉どおり「基本は10」になります。出来事の回復 −24.5 で、休みとの役割分担がはっきりします。
- 悪くなる: 総合力 −108±26(−0.7%)、休む +0.3、勝率 −0.2pt です。けが −0.003 は幅が出ていないので、差があるとは言えません。

**候補B: hp10a(候補Aに加えて記念日を +30)**
- 良くなる: 偏りの1位である記念日の比重が下がります(出来事の回復 −33.3)。
- 悪くなる: 総合力 −131±27(−0.9%)、休む +0.4、勝率 −0.3pt です。なお hp10 との差(−108±26 と −131±27)は幅が重なっており、差があるとは言えません。

**候補C: 説明の無い効き目の整理**
- ひらめき +15% は 0 にしても差が出ません。説明を書くか、外す候補です。
- 一喝 ±5% は −14±5 とごく小さいです。説明を足すか、0 にする候補です。
- 40以上は、サボり ×1.2 を 1 に近づけるか無くす方向です。no40 で総合力 +52±14、サボり −0.289 になります。
- 悪くなりそうなのは「甘やかしすぎの罰」が消えることです。甘い側で終わる割合が +0.8pt 増えます。
