## 甘え度・恐れ度
- はじめ 甘え10・恐れ10。各50まで。下がらない(負の値は0扱い)。忠誠度 = 甘え + 恐れ
- 方針 = 甘え − 恐れ の差。差の大きさ 5/11/16 以上で 1/2/3 段(甘い側: 甘い・溺愛・超溺愛 / 厳しい側: 厳しい・スパルタ・超スパルタ)
- 方針の段で増え方に倍率(addLoyal): 甘え POL_AMA = [1.5, 1.35, 1.2, 1, 0.8, 0.65, 0.5](超溺愛→超スパルタの順)、恐れ POL_FEAR = [0.5, 0.65, 0.8, 1, 1.2, 1.35, 1.5]
- ターンの終わり: 体力が上限の50%以上なら 甘え +1、未満なら 恐れ +1(倍率あり)
- ほめる: 良い結果 甘え+4・悪い結果 甘え+2 / しかる: 良い結果 恐れ+1・悪い結果 恐れ+4(倍率あり)。体力が上限の半分以上なら失敗率は0%なので、結果はほとんど「良い」
- 試合に勝つ 甘え+2 / 遊ぶ 甘え+5 / ごはん 甘え・恐れ +2〜5 / ごはん抜き 恐れ+1 / 出来事の loy は半分ずつ・fear は恐れだけ(倍率なし)
- 効き目: 甘い側の段でサボり 4/8/12%、甘え40以上でサボり ×1.2。恐れ40以上で失敗 ×0.9。厳しい側ではサボりなし
## 体力
- 休む: 上限の 50/70/90%(10/70/20%の確率)。遊ぶ 50%。通院 30%
- 出来事の回復: +10・+20・+30、記念日(13〜15ターン目・選択肢なし)+50

## アシスト
- 型: with(その子が来たトレーニングだけ・編成で重なる・上限あり)/ self / stay(編成でいちばん大きい1つだけ)/ battle(試合で効く・1つだけ)
- ポイント = 総合力 ÷ 100(B 10,000→100・A 12,500→125・S 14,500→145)。おまかせは7種を各目盛り5まで
- 上限の例: トレ効果アップ系 合計100%・能力別アップ 120%・失敗率ダウン 50%
## 試しの条件
- 子(種)× 育て方7 × 編成6 × 助手 を回す。育て方は機械の決まった打ち方。試合はゲーム本体の試合の式と同じ(全部オート相当)
- 出来事は、体力が上限の7割未満なら体力が増える選択肢、ほかは最初に選べる物。見るだけの出来事も効き目をかける
- 一喝は毎回「ステータスアップ」を選ぶ
- 編成 base=ベースモン6体 / memo1-X=育てた子1体(ランクXのおまかせアシスト)+ベースモン5 / memo3-S=3体 / real-X=6体 / bare-X=real-X と同じ能力でアシストなし / battle-S=real-S の能力に試合型アシスト5種を最大 / probe-<id>=bare-S の6体全員にその1種だけ最大
