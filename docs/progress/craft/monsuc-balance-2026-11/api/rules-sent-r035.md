# 前提(社長の向き r1119-035 と、芯の決まり)
- 甘えの境: ターンの終わりに体力が上限の「境」以上なら甘え +1、未満なら恐れ +1(いまは境5割)。方針の段の倍率(いま 甘え [1.5,1.35,1.2,1,0.8,0.65,0.5]・恐れはその逆順)。「倍率を弱める」は [1.25,1.17,1.1,1,0.9,0.83,0.75]
- 甘い側の段ではサボり 4/8/12%・甘え40以上でサボり ×1.2。厳しい側ではサボりなし(だから厳しい側ほど総合力が上がる)
- 体力回復は社長が決定: 基本のイベント +20・+30 → +10、記念日 +50 → +30
- アシスト: 芯は試合型を「6体ぶん足し合わせ」(r1115-107)。値は芯の第1版の表(3段・見立て最大 −8%)で、画面の表(5目盛り・最大 −10%)と違う(芯の注記「ひらめきは社長の保留中」)。試合の上乗せの上限 eva 0.5・missCut 1.0 など
- ライバル魂は「足し合わせ・上限なし」(r1115-107)。ライバルに勝つと全能力 +12 × (1 + 合計%)
- 超修行は技を2つ選ぶ修行で、チケット2枚が要る。超修行アップは回数だけ増やす
- 助手・継承は、助手が来た札にその子が来ていないとき、その子のいっしょ型を足す
- 編成の記号: bare-S=育てた子6体S・アシストなし / real-S=同じ6体におまかせのアシスト / battle-S=6体全員に試合型5種最大 / battle1-S=real-S の1体だけが試合型5種最大(ふだんありそうな形) / probe-X=6体全員に X だけ最大 / one-X=1体だけに X 最大 / R:=ライバルあり・大会重視 / X:=超修行を使う打ち方
