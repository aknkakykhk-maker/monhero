# r1119-035 試算の読み取り

## 結論
- 甘えの境は **7割(倍率はいまのまま)** を候補にします(担当と同じ)。8割にすると「何もしないと厳しい側」になり、倍率を弱めると普通に寄りすぎます。
- 体力回復の決定値に問題は見当たりません。総合力は −0.9%、勝率は −0.4pt 下がりますが小さく、けがと途中終了は変わりません。
- アシストは、試合型を **案b(種類ごとに1体ぶんだけ効く)** にするのが候補です。ライバル魂も同じ「足し合わせ」の形なので、直す必要がありそうです。

## (1) 甘えの境(全体)
| 案 | 甘い/普通/厳しい% | 総合力の差 | サボり |
|---|---|---|---|
| 5割(いま) | 66.4/33.5/0.1 | — | 2.26 |

**7割**
- 甘い/厳しい側の割合は、いつもほめる 33.2/1.7、いつもしかる 10.9/20.6、なにもしない 22.2/17.4 です。
- ほめ方によって終わりの方針が分かれ、どの打ち方でも普通は6〜8割に収まります。

**8割**
- なにもしないで厳しい側 33.3%(スパルタ以上 19.4%)、いつもしかるで厳しい側 37.9% になります。
- 全体の甘え/恐れの平均が 46.9/47.8 と逆転し、「放っておくと厳しく育つ」形になります。

**倍率を弱める**
- 普通が 76.8%(7割)・78.2%(8割)に集まり、方針の意味が薄くなります。
- 総合力への上乗せは小さく、差があるとは言えません。
  - いつもしかる: 1010±65 と 1047±64
  - なにもしない: 1396±72 と 1425±72
  - 全体の8割どうし: 1411±37 と 1465±37

**反対の意見(数字で)**
- 7割でも総合力は +1111±34 上がります。
- 上がり幅を抑えるなら 6割(+588±27)ですが、甘い側がいつもほめるで 60.3%、なにもしないで 45.7% と偏りが残ります。
- 7割でも、いつもほめる 15799 に対していつもしかる 16924 で、ほめる側が不利なままです。

**原因の見立て**
- 厳しい側にはサボりがなく、甘い側はサボり 4/8/12% です。
- 甘えの平均が約49なので、「甘え40以上 ×1.2」がほぼいつも掛かっているかもしれません。
- そのため、境を上げるほど総合力が上がり続けます。

## (2) 体力回復の最終の確かめ

- けがは 0±0.01、途中で終わった割合は 0 で、変わりません。
- 総合力 −143±17、勝率 −0.4±0.2pt は差があると言えますが小さく、問題はないと見ます。
- ただし、これは境5割での確かめです。

## (3) アシスト
**① 強める**
- 効いたのは忠誠度だけです(probe-kizuna +1288±167、勝率 58.8→60.4)。
- しつけ(5±89)と落ち着き(23±40)は差があるとは言えず、元気(64±46)も小さいです。
- 値を倍にしても効かないので、原因は値ではなく「効く場面の条件」かもしれません。

**③ 効き目0の3種**
- ライバル魂: 1体で +11.3%、6体で +8878±695(+77.9%)と強すぎます。「足し合わせ・上限なし」から来ています。
- 超修行アップ: 残りの回数が 1.52→2.5/7.5 と余るだけで、総合力は 15±18 で差があるとは言えません。チケット2枚が詰まりどころかもしれません。
- 助手・継承: −17±85 で差があるとは言えません。条件が満たされることが少ないのかもしれません。

- **表のずれ**

  - どちらの案でも、表をそろえる決定(ひらめきの保留)が先に要ります。

## 直し方の候補
1. **甘えの境を 5割→7割にする**
   - 良くなる: 甘い側 66.4→21.9%、サボり 2.26→0.96
   - 悪くなりそう: 総合力 +1111±34、厳しい側 0.1→10.4%
2. **試合型を案bにする**
   - 良くなる: battle-S の勝率 96.3→71.8
   - 悪くなりそう: ガッツと見せ場の1体ぶんの意味が薄れる(値を上げる試算が要ります)
3. **ライバル魂に上限を付けるか、1体ぶんだけ効くようにする**(値は試算が要ります)
   - 良くなる: 6体で +77.9% の強さを抑えられる
   - 悪くなりそう: 何体も集める意味が減る
