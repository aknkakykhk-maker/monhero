# アシストの数値の分析(試し約20万回より)

## 1. 結論(3行)
- 試合型アシストを最大にした battle-S は、勝率 96.3% です(real-S は 60.3%)。試合への効き目が強すぎます。
- 1ポイントあたりの効き目は、追加トレボーナスの 75.3 から 0 まで大きく開いています。季節のトレ効果アップ4種(値段10)も 65.5〜73.7 で、値段に対して割安すぎます。
- 13種は差が ±95% の幅に収まっています。うち超修行アップ・ライバル魂・助手・継承の3種は 0±0 で、試しで再現できていない可能性があります。

## 2. 表から読める偏り(多い順)

## 3. 原因の見立て
- **失敗率ダウン・元気のお守り**
  - 決まりでは「体力が上限の半分以上なら失敗率0%」で、試しでは病気の平均が 0 です。
  - 機械の打ち方(休む平均 6.4回)が体力を半分以上に保つため、効く場面がほぼ無いのかもしれません。通院の付き添い 110±55 も同じ理由かもしれません。
- **0の3種**
  - 超修行・ライバル・継承は試しの条件に入っていない仕組みかもしれません。弱いのではなく、測れていない可能性があります。
  - トレーニングチャンス・上限アップブーストも同じかもしれません。
- **遊び上手・ぐっすり**
  - 機械が「遊ぶ」をほぼ選ばないのかもしれません。休むの回復(50/70/90%)で足りていることも関係しているかもしれません。
- **A≈S**
  - 「おまかせは7種を各目盛り5まで」の制限や、各上限(トレ効果アップ系 合計100%・能力別 120%・失敗率ダウン 50%)で、S で増えたポイントが使われていないか切られているのかもしれません。
- **メモモンの重みの減り方**
  - with 型の重なりに上限があり、stay 型は「いちばん大きい1つだけ」なので、体数が増えるほど足し分が減るのかもしれません。
- **battle-S**
  - 「1つだけ」が種類ごとの決まりなら、5種が同時に効いて負けにくさが重なっているのかもしれません。
  - トレ系アシストが無い分、上10% が下がっているのかもしれません。

## 4. 直し方の候補
アシストの数値を変えた試算の表は無いため、動かす向きだけを書きます。

- **候補A:** 追加トレボーナスの確率+20% を下げる、または値段40を上げる。季節4種の値段10を上げる。
  - 良くなる指標: 1ポイントあたりの開き(75.3〜0)が縮む。
  - 悪くなりそうな指標: おまかせに入っていれば、real-B/A/S の総合力が下がる。
- **候補B:** 見立ての確率−10% を小さくする、または試合型を編成全体で1つだけ効くようにする。
  - 良くなる指標: battle-S の勝率 96.3% が real-S の 60.3% に近づく。
  - 悪くなりそうな指標: 試合型全体の効き目がさらに薄くなる(見せ場 6.8・見守り 8.6)。
- **候補C:** 失敗率ダウン(70)・しつけ上手(75)の値段を下げる、または効き目を変える。
  - 良くなる指標: 値段に見合った効き目になる。
  - 悪くなりそうな指標: 体力を削って育てる人の遊び方では強すぎになる恐れがあります。0の3種は再現の確認を先に済ませてください。
