# 甘え度・恐れ度の分析(main 100,000回+仮の数値 各8,000対)

## 1. 結論
- 甘えは**どの条件でも中央値50(上限)**に達します。厳しい側で終わるのは最大1.4%(train×scold)、超スパルタは全条件で0%です。社長の言う「厳しい方向にできない」は数字でも確認できます。
- 主な原因は**ターン終わりの甘え+1(体力50%以上)**です。これが甘えの増えた分の48.7%を占め、甘い側の倍率がさらに後押ししています。しかっても届きません。
- 候補は turnNoAma(厳しい側で終わる +28.4pt)か polFlatTurn(+24.2pt)です。ただし総合力も上がるため、厳しい側が「正解」になりすぎないか確かめる必要があります。

## 2. 表から読める偏り(多い順)
1. **甘えが必ず上限に届く**: 甘え40到達は全条件で97.9〜98.9%です。praise では T24 時点で甘えの中央値がもう50です。一方、恐れの中央値は praise 35・none 36 にとどまります。
2. **ターン終わりの甘えが最大の要因**: all で turnHp は甘え+19.2(48.7%)です。scold では57.2%、none では58.4%と、ほめない遊び方ほど比率が上がります。
3. **しかるが効かない**: scold 条件で、しかる7.1回から得た恐れは+9.6(1回あたり約1.35)だけです。同じ条件の turnHp は甘え+22.5、win は甘え+6.3 です。しかるのは、全体の結果では厳しい側0.4%・普通60.6%に寄せる程度です。
4. **甘い側から抜けにくい**: 甘い側のターン%は praise 90.7、balance 93.3 です。いつもしかっても56.2あります。厳しい側のターン%は、最も高い shugyo×scold でも14.4で、終わりは普通が97.4%です。
5. **40以上の効き目は意味が薄い**: ほぼ全員が甘え40に届くため、差がつきません。no40 の総合力は +52±14(0.3%)、サボりは −0.289 です。失敗の差は0で、恐れ40の×0.9は効いていません。甘い側で終わる +0.8pt には幅がなく、差があるとは言えません。

## 3. 原因の見立て
- **ターン終わり甘え+1**: 体力が上限の50%以上なら毎ターン甘えが入ります。休む(50/70/90%)・遊ぶ(50%)と出来事の回復がこれを支えるため、turnHp の回数は16.3と turnLow の12.6より多くなっています。普通にケアするほど甘くなる作りかもしれません。
- **しかるの値**: 体力が半分以上なら失敗率は0%なので、結果はほとんど「良い」になり、しかっても恐れは+1です。一方、ほめると良い結果で甘え+4です。対称になっていないのが原因かもしれません。
- **方針の倍率の自己強化**: 甘い側では甘えが×1.2〜1.5、恐れが×0.8〜0.5 になります。turnHp は16.3回で甘え19.2なので、平均で1倍を超えています。一度甘くなると戻りにくいかもしれません。
- **プレイヤーが厳しい側へ寄せる手**: 体力を50%未満に保つ(turnLow で恐れ+1)、ごはん抜き(恐れ+1)、しかり続ける、の3つです。ただし、最も効いた shugyo×scold でも厳しい側で終わるのは0.6%です。今の数値では、事実上ほぼ手が無いと言えます。

## 4. 直し方の候補(決めるのは人です)
| 候補 | 動かす数値 | 良くなる指標 | 悪くなりそうな指標 |
|---|---|---|---|
| A: turnNoAma | ターン終わりの甘え+1 → 0 | 甘え −7.3、甘い側で終わる −22.1pt、厳しい側で終わる +28.4pt、総合力 +438±37(2.9%)、サボり −1.227 | 病気 +0.07(幅なし・要確認)。ケアしても甘えが入らず、甘い側の遊びが減るかもしれません |
| B: polFlatTurn | Aに加え、方針の倍率を全部1 | 甘い側で終わる −30.3pt、厳しい側で終わる +24.2pt、総合力 +552±38(3.6%)、サボり −1.394 | 病気 +0.064・けが +0.009(幅なし)。段ごとの手ごたえが消えます。厳しい側への寄りはAより小さく、厳しい側の恐れ倍率も消えるためかもしれません |
| C: しかる(良い結果)の恐れ+1を上げる | +1 → 大きく | プレイヤーが選んで厳しい側へ寄せられる | **試算なし**。数値は出せません |

- 補足として、polFlat 単独では厳しい側で終わる差が0ptです(総合力 +204±20、甘い側で終わる −15pt)。倍率だけでは厳しい側に届きません。
- どの案も総合力が上がります。抜き書きでは、厳しい側はサボりが無く、恐れ40で失敗×0.9という得しかありません。直した後は厳しい側が強すぎる(甘い側を選ぶ理由が無い)おそれがあります。

## 5. 追加で確かめたい所
