# 紹介動画 第3弾 (a) 戦術カードの場面(ブレイブくん)

縦 390×844・deviceScaleFactor 2(780×1688)・音なし。main の公開済みの画面だけで撮った。相手のデッキ・戦術カード・カードランクは偽のデータ(相手は「ブリーダーA」、デッキ名は「仮のデッキ」「わたしのデッキ」)。
