# 紹介動画 第3弾 FEATURE 05「戦術カード」の撮り直し(ブレイブくん)

縦 390×844・deviceScaleFactor 3(1170×2532)・30fps・音なし。main の公開済みの画面だけで撮った。名前は架空(組む人=モンヒロ太郎、遊ぶ人=ブリーダーA)。デッキは仮の「わたしのデッキ」(グジラ・デュラハン・アーマードラゴン)。

筋立て: モンヒロ太郎が自分の登録デッキに作戦を組む(t1)→ ほかのブリーダー(ブリーダーA)がそのデッキと戦うと、モンヒロ太郎の作戦どおりに動く(t2〜t4。帯の頭は「📜 モンヒロ太郎の戦術カード」)。t1 で組む作戦と t2 で出る作戦は同じ文。

対戦はオートなので、撮り直すたびに、どのモンスターが・何ターン目に作戦を使うかは変わる(文は同じ)。

## 字幕に使う言い方(いまの遊び方どおり)

1. **戦術カードとは**: 「条件(〜のとき)と行動(〜する)を組み合わせて、登録したデッキの戦い方を決めるカード」
2. **作戦の文**(画面の文そのまま)
   - t2: いまの手札とガッツで倒せる相手がいるとき → いちばん良い技で攻撃する
   - t3: 3ダメージ以上の攻撃を受けたとき → いちばん良い守り方で守る
   - t4: (ブリーダーの作戦・いつでも)→ 使えないカードから先にガッツにする
3. **自動か、自分で選ぶか**: 自動。試合中に自分で選ぶものではない。組んでおいた作戦を、条件がそろったときにモンスター(ブリーダー)が自動で使う。1体ごとに上から順に見て、最初に当てはまった1つを使う。登録デッキがほかのブリーダーと戦うとき(と、自分がオートで戦うとき)に働く
