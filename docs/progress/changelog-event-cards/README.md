## タブの「！」がどこから来ていたか

クリスマスの開催予告の項目。開幕の前倒し(r1126-063)で本文の日付を直したとき、既読の印(題と本文から作るID)が
`event-138cicc` → `event-1edc1lc` に変わり、前に読んだ人にも未読として戻っていた。一覧の札には未読の印が無かったので、どれか分からなかった。

## 直したこと

1. 札ごとに「NEW」。札を開いたらその札だけ既読(保存は今までどおり `mh_changelog_seen_ids_update` / `_issue` へIDを足す。キーは増やしていない)。
   タブの印はまだ開いていない札の数で、札の「NEW」と同じ集合から作るので必ず合う
2. 札の上にイベントの絵の横長の帯、その下に短い題を1行(絵が無い項目は色の札のまま)。帯の位置は項目の `bannerPos`
3. 期間「11/28(土) 10:00 〜 12/31(木) 3:59」と残り「あと◯日 / ◯時間 / ◯分」「開幕まであと◯…」。期間は `eventStartAt` / `eventEndAt` / 助手の告知の期間 / `pinTop.until` から
4. 開催中(終わりが近い順)→開催予定(開幕が近い順)。題は項目の `listTitle`(無ければ `pinTitle`、それも無ければ題から【…】と「がはじまりました」等を落とす)
