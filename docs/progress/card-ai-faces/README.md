## 決まったこと
- Q1 A: 推し=推しの種が主役/好き=好きなモンスターのもう1体が主役/素顔=仲良し度で よそいき(無難)⇔本音(ほんとはやってみたい)。カードに無い種は同じ系統か近い種
- Q2 A: 名前は主役(愛称か種)か遊び方を入れる。攻め・守り・ふつうと「・〇〇」は付けない。3つで同じことばを使わない(素顔は よそいき・本音 の両方で見る)。見張りに落ちたら既定の名前
- Q3 A: 2つのデッキのカードの重なりは4割まで・主役3体は2体以上ちがう(組み直すたびに見る)。強さは今の水準に収め、測って残す
