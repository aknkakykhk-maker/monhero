## 2. お知らせ(更新履歴)の形

- 公開の日に出るのは **1本の大きなお知らせ「モンヒロサクセス(β版)が始まりました」**(助手の告知 `update_notice_monsaku_v1`・一覧の上に2週間固定する帯 `pinTop:{ days:14 }`)
- β公開の前の直し(2026-11-13〜15 に `releaseFlag:'monheroSuccess'` で溜めていた39件と「紹介」)は、公開の日に初めて遊ぶ人には「変わったこと」ではないので、大きいお知らせへまとめて `dev:true`(どのタブにも出ない)にした
- 予告の4件(`unreleasedFlag:'monheroSuccess'`)は印が立つと自動で消える
- 日時は公開の印の PR で実時刻に直す(帯の2週間もそこから数える)

## 4. 公開の日の手順(窓口)

1. ミハリ12 の2周目で重大・高が0件、社長の最後の確認 OK(窓口が知らせる)
2. 第2話(助手部)が main に入っていること。入らないまま出すなら、大きいお知らせの3行目(第2話の行)を消す
3. 公開の印の PR を main に合わせ直し、`TZ=Asia/Tokyo date '+%Y-%m-%d %H:%M'` で大きいお知らせの `date` を実時刻に直してビルド・検査 → マージ
4. 本番 URL で「5. 社長が最後に見る所」を見る

## 5. 社長が最後に見る所(本番 https://aknkakykhk-maker.github.io/monhero/)

1. HOME: 「🌱 モンヒロサクセス β」の入口とリボン「β版 開幕！」(縦長の画面では一言も)
2. HOME に戻ったとき: 第2話のお話が1回流れ、終わりの「🌱 モンヒロサクセスへ」で開く
3. 更新履歴: いちばん上に帯「🌱 新しい遊び「モンヒロサクセス」β版がはじまりました!」、開くと大きいお知らせ1本。予告(近日公開・開発中 第1〜3弾)が消えている
4. みゅあの告知が1回出る(「聞いて聞いて！ モンサクのβ版が始まったよ〜！」)
