# MFバトルカード 個人杯(案)

2026-10-30 ルールくん。社長の言葉:「大会システムを利用してプレイヤーでも個人杯を開けるようにしたい。リアルタイムでエントリーから操作するモードと、
エントリーして時間を決めてオートで結果を出せる大会と同じ仕様みたいな」。**まだ作らない(案)。**

公式杯(`docs/progress/card-tournament/plan/README.md`・`docs/spec/CARD_TOURNAMENT.md`)の表と計算を使い回し、
プレイヤーが自分で杯を開けるようにする。モードは2つ。

| | A. リアルタイム杯 | B. オート杯 |
| --- | --- | --- |
| 対戦 | 決まった時刻に集まって、1試合ずつ自分で操作(マルチ対戦の仕組み) | 公式杯と同じく、登録デッキと戦術カードでサーバが自動で回す |
| 形式 | **総当たり** か **トーナメント** を主催が選ぶ(おすすめはトーナメント。早く終わる) | **総当たり** か **トーナメント** を主催が選ぶ(おすすめは総当たり。試合が多いほど楽しめる) |
| 人数 | 4〜8人 | 4〜8人(総当たりで足りない席は助手) |
| かかる時間 | 30分〜1時間ほど(8人で3回戦) | 主催が決めた時刻に、全部の試合を一度に回して発表 |
| 結果の見せ方 | 総当たり: 公式杯と同じ「大会結果」の演出(空の表 → ○×が押される → 上位3人が光る)<br>トーナメント: 山の表で、勝った側の線が光って上へ伸び、最後に真ん中の優勝カップへ。どちらも「演出リプレイ」あり | 同じ |
| 見返し・実況 | 見返しあり・観戦あり・実況なし | 見返しあり・実況は優勝決定の1試合だけ(回数を抑える) |
| サーバの負担 | ほぼ無い(対戦は端末どうし。表に書くのは結果だけ) | 1杯で最大28試合(8人の総当たり)。下の見積もり |

## 決めてほしい所(おすすめを先に)

### 1. 誰が開けるか
- **おすすめ: デッキ登録をしていて、カードランク5以上の人**(すぐ作って捨てる杯を減らす。公式杯と同じ持ち主の鍵で見分ける)
- ほか: だれでも / 公式杯に1回出た人

### 2. 参加の募り方
- **おすすめ: 合言葉(6けたの数字)を知っている人だけ + フレンドに知らせる**。主催が合言葉をフレンドへ送れる
- ほか: 公開の一覧に出す(知らない人も入れる。荒らし・すっぽかしの対策が要るので、あとから)

### 3. 人数と回数
- 人数: **4〜8人**(トーナメントで5〜7人のときは、1回戦に「不戦勝」の枠ができる)
- 1人が同時に開ける杯: **1つ**。1日に開ける数: **1つ**。同時に出られる杯: **3つまで**
- 全体の上限: 同時に開かれている杯 **200まで**(超えたら「いまは開けません」)

### 4. 主催が決められる項目
- 名前(20字まで・ことばの見張りは名前と同じ)・モード(A/B)・人数の上限(4/6/8)
- A: 始まる時刻(15分きざみ・1〜72時間後まで)。1試合の持ち時間はマルチ対戦と同じ(自分の番60秒・守り15秒)
- B: エントリーの締め切りと、結果の発表の時刻(どちらも1時間きざみ・最長3日後まで)
- 決められないもの: ルール(公式と同じ)・ごほうび(下)

### 5. 形式(社長の見本の動画 2本から)
- **総当たり**: 全員と1回ずつ。順位は公式杯と同じ(勝ち数 → 倒した数 → 2人の対戦 → エントリーの早さ)。8人で28試合
- **トーナメント**: 負けたら終わり。8人で7試合・3回戦。人数が 5〜7人のときは、1回戦に「不戦勝」の枠ができる(組み合わせは種で混ぜる)。3位決定戦はしない(3位は準決勝で負けた2人)
- どちらも、主催が開くときに選ぶ。公式杯の計算(82-card-tournament-core)に、トーナメントの組み合わせと勝ち上がりを足す

### 6. A. リアルタイム杯の進め方
- 始まる時刻の10分前から「集合」。時刻に集まっていない人は**不戦敗**(相手は不戦勝)。全員そろったら時刻を待たずに始めてよい
- 1回戦の組み合わせは、そろった人を種で混ぜて決める(エントリー順にしない)
- 各試合は、マルチ対戦の合言葉の部屋をサーバが割り当て、2人が入って戦う。終わったら2台が結果を表に送り、**2台の答えが合ったら確定**
  (合わない・片方しか送らないときは、マルチ対戦の「なぞり直し(cardPvpVerify)」の結果で決める)
- 途中で抜けた・時間切れ3回は、マルチ対戦と同じく負け
- ほかの人の試合は**観戦**できる(マルチ対戦の観戦 94 の作り)。主催も観戦できる
- 決勝まで終わったら結果。見返しは自分の試合だけ端末に残る(マルチ対戦の記録と同じ)

### 7. B. オート杯の進め方
- 公式杯とほぼ同じ。ちがいは「毎日1試合」ではなく「**発表の時刻に、全部の試合を一度に回す**」こと(トーナメントも、1回戦から決勝まで続けて回す)
- 締め切りで登録デッキの写しを取り、組み合わせと種を決める(公式杯の表に `kind='personal'` の行として足す)
- 発表の時刻の1時間前までにサーバが回し、時刻になったら見せる(公式杯の「見せてよい時刻」と同じ)
- 実況・解説は、**優勝が決まった1試合だけ** AI で書く(ほかの試合は用意した台詞)

### 8. ごほうび
- **おすすめ: なし**(名誉だけ。順位は結果の画面と、出た人の記録に残る)
- ほか: 主催が自分のビートPを出して、優勝した人へ渡す(主催の端末のビートPを減らす仕組みが要る・やり取りの見張りが要るので、あとから)

### 9. ランキング・戦績への入り方
- **ランキング・カードランク・強さの点数(マルチ対戦のレート)には入れない**(知り合いどうしで勝ち負けを回して点を上げられるため)
- 「記録」に「個人杯」の欄を足し、出た数・優勝の数だけ数える(新しい保存キー。今のキーは触らない)

## 公式杯への使い道(トーナメント)

- いまの公式杯は、10人以上なら5人ずつの組 → 各組の上から2人で「頂上決戦」の**総当たり**。40人だと16人の総当たりで15日かかる
- 組が5つ以上(21人以上)の日は、頂上決戦を**トーナメント**にする案: 各組の1位でトーナメント(8組なら8人で3日。組の数が2のべき乗でないときは不戦勝の枠)
- 毎日 4:00 に1回戦ずつ発表し、勝ち上がりの線が伸びる演出で見せる(`案A-7`)
- 想定は多くて8人(1つの総当たり)なので、すぐには要らない。人数が増えてきたら入れる

## サーバの負担と見積もり

- 1試合を回すのにかかる時間: **およそ 80ms(重い試合で 145ms)**。2026-10-30 に手元で30試合を測った
- サーバの関数は、**1回の呼び出しで CPU を 2秒まで**しか使えない(Supabase の決まり)。1回で回せるのは **20試合ほど**
- B. オート杯は、8人の総当たりで28試合 = **1杯で2回ぶん**の呼び出し。発表の時刻の前の1時間に、10分おきに呼んで少しずつ回す(6回 × 20試合 = 1時間に120試合 ≒ 4杯)
  - 同じ時刻に発表する杯が多いと間に合わない → **発表の時刻ごとに受け付ける杯の数に上限**(1時間に4杯まで・それ以上は「この時刻はいっぱい」と出して別の時刻を選んでもらう)
  - 1日にできるのは 24時間 × 4杯 = **96杯まで**(全部8人なら 2,700試合ほど)
- AI の実況: 1杯1試合だけ → **1日96回まで**。助手のおしゃべりと同じ全体の上限(1日2,000回)の中に収まる
- A. リアルタイム杯: 試合は端末どうしでサーバは回さない。表に書くのは組み合わせと結果だけ(1杯で十数回の書き込み)
- 表の大きさ: 杯の行は終わって30日で一覧から外す(消さない。読むときに見せないだけ)

## サーバに足す物(足すだけ。今の表は変えない)

| 足す物 | 中身 |
| --- | --- |
| 表 `card_cups` | 個人杯(主催・名前・モード・合言葉の指紋・人数の上限・時刻・状態)。公式杯の表とは分ける(一覧・上限・見張りがちがうため) |
| 表 `card_cup_entries` / `card_cup_matches` | 公式杯と同じ形(B はデッキの写し・手の並び。A は結果と2台の答え) |
| 関数 | `card_cup_create`・`card_cup_join`(合言葉)・`card_cup_leave`・`card_cup_view`・`card_cup_report`(A の結果)・`card_cup_checkin`(A の集合) |
| サーバの関数 | B は `card-tournament-run` に個人杯の分を足す(呼ぶ間隔を10分おきにする) |
