## ① 日程(決まり)

開催日を D とする。

| いつ | すること |
| --- | --- |
| D 0:00 〜 D+1 の終わり | エントリー受付。受付中はデッキと戦術カードを何度でも変えられる・取り消せる |
| D+2 0:00 | 締め切り。デッキと戦術カードの**写し**を取り、組分けと総当たりの日程を作る(組み合わせだけを発表する日は作らない) |
| D+2 4:00 | 1試合目の結果を発表 |
| 毎日 4:00 | その日の試合の結果を発表。試合を回す時刻はサーバに任せる(4:00 までに結果がそろえばよい。0:30 に回し、失敗したら 1:30・2:30 にやり直す) |
| 最後の試合の結果の日 4:00 | 最終順位とごほうび |

- 途中でアプリやデッキを消しても、写しで最後まで戦う(不戦敗にしない)。ごほうびは本人が受け取りに来たときに渡す
- 順位: 勝ち数 → 倒したモンスターの数 → 2人の対戦の勝ち負け(ちょうど2人が並んだときだけ) → エントリーが早い人

## ② 組分け(決まり。ランクは使わない)

想定は多くて8人。

- **9人まで**: 全員で1つの総当たり。4人に足りないときは、足りない席に助手が入る
- **10人以上**: 5人ずつの組に分ける(組の数 = 人数 ÷ 5 の切り上げ。人数がそろうように 4〜5人ずつ。組への振り分けはエントリー順ではなく、締め切りの種で混ぜる)。
  各組の総当たりが終わったら、各組の**優勝・準優勝だけ**で「頂上決戦」(新しい総当たり)。頂上決戦の順位が大会の順位
- **人数が奇数**の総当たりは、毎日1人がお休み(試合の数は人数−1、奇数なら人数ぶんの日)
- 助手の席: 助手と対戦と同じデッキと打ち方(強さは EXPERT)。助手はごほうびを受け取らない(順位には入る)

## ③ エントリー(決まり)

- 参加の条件はなし。ルールどおりのデッキ(3体・50枚)なら出られる。1人1デッキ
- 自分の登録デッキ(デッキ・戦術カード・切り札)を選ぶ。締め切りで deck・tactics・version を大会の表へ写す
- 持ち主の見分けは、みんなのデッキと同じ owner_id(ブリーダーID)+ 端末の鍵(md5 で確かめる)。新しい保存キーは足さない

## ④ 自動の対戦(決まり: サーバで回す)

- カードの対戦は、同じデッキ・同じ戦術カード・同じ乱数の種なら、どこで回しても同じ結果になる
- 種は締め切りで「大会の番号+試合の番号」から決めて表に残す
- サーバの上の関数(Edge Function `card-tournament-run`)が、ゲームと同じルール本体(82-card-battle-core・82-card-tactics-core)で試合を最後まで回し、
  勝ち負け・倒した数・手の並び・ルールの版を表に書く。打ち方はみんなのデッキと同じ(cardSharePolicy)
- ルール本体は、ビルドのときに Edge Function へ写す(手で写さない。写しが古いと検査で落ちる)
- 結果を書いても、画面に出すのは 4:00 から(表の「見せてよい時刻」)

## ⑤ 実況・解説(決まり: AI で書かせる)

- 試合を回したあと、試合の記録(手と出来事の要約)を読ませ、その日の担当の助手らしく、実況と解説を作って表に残す
- 鍵は助手とのおしゃべり(card-assistant-talk)と同じ Secrets の ANTHROPIC_API_KEY。新しい鍵は作らない
- モデル・回数の上限・ログに本文を書かない、は card-assistant-talk にそろえる。失敗したら、用意した台詞を使う
- 担当の助手は、日ごとに順番(公開ずみの助手から)

## ⑥ ごほうび(決まり: 大会ごとの設定)

- 大会の表の1行に、ごほうびの表を持たせる: 順位ごと・参加賞・1勝ごとの**ビートPだけ**(2026-10-30 社長「ビートPだけ」。称号・プロフィール枠は出さない)
- 開く前に社長が1位のごほうびを決め、そこから順に下げる。第1回の数字は統括部長が社長に聞く
- 頂上決戦がある大会は、頂上決戦の順位で順位のごほうび、出られなかった人は参加賞。1勝ごとは全部の試合で数える
- 受け取りは1回だけ(サーバで受け取り済みを記録)

## ⑧ サーバに足す物(足すだけ・今の表は触らない)

| 足す物 | 中身 |
| --- | --- |
| 表 `card_tournaments` | 大会(名前・開催日・受付の終わり・状態・ごほうびの表・組の人数) |
| 表 `card_tournament_entries` | エントリー(大会・owner_id・鍵の md5・名前・アイコン・デッキと戦術カードの写し・登録デッキの version・助手の席か・組・席) |
| 表 `card_tournament_matches` | 試合(大会・段(組/頂上)・組・日・2人の席・種・先攻・勝った方・倒した数・手の並び・ルールの版・実況と解説・見せてよい時刻) |
| 表 `card_tournament_rewards` | ごほうびの受け取り済み |
| 関数 | `card_tournament_enter` / `card_tournament_withdraw`(受付中だけ)/ `card_tournament_view`(見せてよい時刻を過ぎた結果だけ返す)/ `card_tournament_claim` |
| Edge Function | `card-tournament-run`: ①締め切りで写し・組分け・日程・種 ②その日の試合を回す ③頂上決戦の組み合わせ ④実況と解説 |
| 決まった時刻の仕組み(pg_cron + pg_net) | 毎日 0:30(やり直し 1:30・2:30)に `card-tournament-run` を呼ぶ。合言葉はサーバの中で作り、どこにも書かない |

窓口に流してもらう物(SQL・Edge Function の置き場・合言葉・pg_cron)は、要る段階で1回にまとめて本文をソランド部長へ送る。
