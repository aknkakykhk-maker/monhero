# 速さ部(ハヤテくん)の計測

ゲームの読み込みと動きの速さを、iPhone に近い条件で測った記録。直す前と後の数字はここに足していく。

## 測り方

```
node tools/build.js                                   本番と同じ作りにする
node tools/speed/speed-measure.js                     ①②③④⑤ をまとめて(CPU 4倍遅く・遅めの4G)
node tools/speed/speed-measure.js --only boot --runs 3            はじめの読み込みだけ・3回の中央値
node tools/speed/speed-measure.js --only boot --net wifi --runs 3 回線を Wi-Fi 相当にする
node tools/speed/speed-measure.js --only boot --net wifi --settle 120   HOME に2分いるあいだに裏で読む量
node tools/speed/speed-measure.js --only images        表示より大きすぎる画像
node tools/playbot/rhythm-frame-perf.js --song sheriruth --diff MASTER --cpu 3 --landscape 0   モンヒロビートの演奏中
```

- 条件: 画面 390×844(iPhone 13)・CPU 4倍遅く・回線は「遅めの4G」(往復150ms・下り1.6Mbps)と「Wi-Fi」(往復20ms・下り30Mbps)
- 手元のサーバーは GitHub Pages と同じく文字のファイルを gzip で返す。大きさは**圧縮後**(実際に通信する量)
- Supabase を含め、手元以外への通信はすべて止めている(名前を引けなくする)。本番へは1件も送らない
- ★Playwright の `route` を使うとブラウザのキャッシュが切れ、同じファイルを2回取ったように見える。計測では使わない
- 手元のブラウザには GPU が無いので、CSS アニメーションの描き直しは実機より重く出る。待機中の数字は参考

### ⑤ HOME で何もしない10秒(Wi-Fi・CPU 4倍)

動いた時間 2.1秒(うち JS 0.1秒・配置と見た目 0.4秒)。動くのはジャックのオーラ(CSS 11本。transform / opacity だけ)と
タイマー4本(500ms・1.5秒・15秒×2)。GPU の無い手元の水増しが大きく、実機では軽いと見ている。
