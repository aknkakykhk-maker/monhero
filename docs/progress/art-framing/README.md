開発部(クラフトくん)が調べた。コードを読み、全部の子の顔アイコンを丸に入れて十字を引いて並べて確かめた。

## 1. 絵の種類と、いまの決め方

| 絵 | どこにあるか | 位置と大きさを決めているもの |
| --- | --- | --- |
| 全身絵(立ち絵) `imgUrl` | `images/monsters/*.png` | 取り込むときに余白を切り、高さをそろえる(`trim-art-margin.js`)。縦長の子だけ、表示のときに `MONSTER_ART_CONTAIN_IDS`(15-dye-and-art.jsx)で contain にする |
| 一覧の小さい絵 `iconUrl` | ほぼ全員が全身絵と同じファイル | 場面ごとの `object-contain` / `object-cover` と枠の形 |
| 顔アイコン `faceIconUrl` | `images/monster-icons/face/*.png`(256px) | 作るとき: `tools/image/make-face-icons.js` の `FACE_BOXES`(顔の範囲)。表示のとき: マーケット・プロフィールだけ `MARKET_PROFILE_ICON_STYLES` で拡大・移動 |
| 円盤石 | `images/disc-icons/*` | `MARKET_PROFILE_ICON_STYLES` の円盤石の行(`tools/image/disc-icon-values.js` で計算) |
| 混血(MFバトルカード) | `images/monsters/cNNN.png`・`face/cNNN.png` | `HYBRID_MONSTER_IMGS`・`HYBRID_MONSTER_FACE_ICONS`(images-ally.js)。顔は同じく `FACE_BOXES` |
| 助手の顔 | 表情ごとの `face/*.PNG` | 絵そのもの(切り出し済み)。お話のゲスト(イルミネ・ドリーミィ)は全身絵を `imageFit:'contain'` |
| アシストカードのアイコン | 助手の顔アイコンなど | `ASSIST_CARD_ICON_STYLES`(15-dye-and-art.jsx。いまは きき だけ) |

## 3. ずれの元になっていた所

1. **顔アイコンの作り方**: `make-face-icons.js` は、`FACE_BOXES` の範囲の中で「絵がある所」のまんなかを顔のまんなかとみなす。羽・髪・尾が片側にあると、そのぶん顔がずれる。**アーク**はこれで顔が右へずれていた(範囲が左 28%〜右 65% で、左の羽を含んでいた)
2. **顔アイコンが全身絵そのもの**: ライガー・ミーア・パンドラ・モノリス・オボロゲソウ・プラントの6体は、`*_FACE_ICON = *_IMG`(全身絵)だった。顔アイコンを使う所(モンヒロビートの顔の列・MFバトルカードのパンドラの顔・はじめの子のアイコンなど)で、小さな全身が出ていた
3. **2画面だけの手書きの寄せ**: 1と2を、マーケットとプロフィールの `MARKET_PROFILE_ICON_STYLES` だけで手で直していた(アーク・ライガー・ミーア・パンドラ・プラントなど)。ほかの場面には効かないので、場面によって見え方が違っていた。きき(`KIKI_FACE_ICON_ADJUSTMENT`)も同じで、マーケットとアシストカードにだけ効く
4. **全身絵の収め方の例外の表**: 縦長の子は `MONSTER_ART_CONTAIN_IDS` に名前を足さないと頭が切れる(足し忘れが実際に起きた。ドリーミィ・イルミネ)
5. **MFバトルカードの手書きの位置**: 84・83 の中に、助手やモンスターの絵の位置の手書きの値がある

## 5. 仕組み(2026-10-26 社長「この案で進める」。入れた物)

**1つの子につき、顔のまんなかを1か所に持つ。** `data/images/images-ally.js` の `ART_ANCHORS`。

```
ARK: Object.freeze({ face: Object.freeze([0.5, 0.393]) }),
```

- `face` … 全身絵(`◯◯_IMG`)の中で、顔アイコンの丸のまんなかに来る点(0〜1)。顔(目のあいだ・鼻)のまんなか
- `make-face-icons.js` は、この点を丸のまんなかに置いて顔アイコンを作る。`FACE_BOXES` は大きさ(寄り・引き)だけを決める。
  範囲を左右対称に取らなくても、顔はずれない
- はじめの値(73体)は、`tools/image/art-anchors.js` で「いまの顔アイコンの丸のまんなかに来ている点」を書き出した。
  全員を並べて目で見て、顔がまんなかに来ていることを確かめてある(アークは直した)。
  この基準で作り直しても、いまの顔アイコンとの差は色を減らした誤差くらい(128px にして平均 3 以下)で、見た目は変わらない
- 顔アイコンを作らず全身絵のまま使う子は `ART_FACE_FULL_BODY`(モノリス・オボロゲソウ・プラント。ライガー・ミーア・パンドラは案を選ぶまで)

## 6. 見張り(検査)と、目で見る一覧

- `tools/image/art-anchor-check.js`(run-checks に入る)
  - ① 顔アイコンを持つ子(モンスター・混血・案の子)は、全員が基準と顔の範囲を持つ。**書いていない子が来たら止まる**
  - ② 顔アイコンが全身絵そのものの子は、`ART_FACE_FULL_BODY` に書いてある
  - ③ 基準の点が顔の範囲の中にある
  - ④ 顔アイコンの画像が、基準どおりに作られている(作り直した絵とくらべる。手で直した・基準だけ変えた、を止める)
  - ⑤ マーケット・プロフィール・アシストカードの手書きの寄せが、いまある分(11件)から増えていない
  - 壊して確かめた: アークの基準を消すと①が、基準を 5% 動かすと④が止まる
- `tools/image/art-anchor-sheet.js` … 全員を丸に入れて十字を引いた一覧の画像(モンスター・混血の顔アイコン、マーケット・プロフィールのアイコン、
  アシストカードのアイコン。寄せがある物は、寄せをかけた見え方で並べる)

## 7. 手順への書き足し

- `monster-add` スキル: 顔アイコンの注記に「`ART_ANCHORS` を書く・寄せを足さない・`art-anchor-check` を通す」を足した
- `docs/rules/ASSETS.md`: 「顔のまんなかは1か所で決める(モンスター・助手・アシストカード)」の節を足した
