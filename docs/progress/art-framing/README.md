## 3. ずれの元になっていた所

1. **顔アイコンの作り方**: `make-face-icons.js` は、`FACE_BOXES` の範囲の中で「絵がある所」のまんなかを顔のまんなかとみなす。羽・髪・尾が片側にあると、そのぶん顔がずれる。**アーク**はこれで顔が右へずれていた(範囲が左 28%〜右 65% で、左の羽を含んでいた)
2. **顔アイコンが全身絵そのもの**: ライガー・ミーア・パンドラ・モノリス・オボロゲソウ・プラントの6体は、`*_FACE_ICON = *_IMG`(全身絵)だった。顔アイコンを使う所(モンヒロビートの顔の列・MFバトルカードのパンドラの顔・はじめの子のアイコンなど)で、小さな全身が出ていた
3. **2画面だけの手書きの寄せ**: 1と2を、マーケットとプロフィールの `MARKET_PROFILE_ICON_STYLES` だけで手で直していた(アーク・ライガー・ミーア・パンドラ・プラントなど)。ほかの場面には効かないので、場面によって見え方が違っていた。きき(`KIKI_FACE_ICON_ADJUSTMENT`)も同じで、マーケットとアシストカードにだけ効く
4. **全身絵の収め方の例外の表**: 縦長の子は `MONSTER_ART_CONTAIN_IDS` に名前を足さないと頭が切れる(足し忘れが実際に起きた。ドリーミィ・イルミネ)
5. **MFバトルカードの手書きの位置**: 84・83 の中に、助手やモンスターの絵の位置の手書きの値がある

## 5. 仕組みの案(社長に見てもらう)

**1つの子につき、基準を1か所に持つ。** 表の名前は仮に `ART_ANCHORS` とする(data に置く)。

```
Ark: { face: { cx: 0.50, cy: 0.38, size: 0.36 }, body: { top: 0.20, bottom: 0.80 } }
```

- `face.cx / cy` … 全身絵の中の顔のまんなか(目のあいだ・鼻)。0〜1
- `face.size` … 顔(頭)の大きさ。顔アイコンでどれだけ大きく写すかを決める
- `body.top / bottom` … 頭の上(冠・角を含む)と足もと。全身を出す場面の収め方を決める(縦長かどうかもここから分かるので、`MONSTER_ART_CONTAIN_IDS` は要らなくなる)

この表から、次をすべて作る。

1. **顔アイコン**: `make-face-icons.js` は「絵がある所のまんなか」ではなく `face.cx/cy` を真ん中に置く(1と同じずれが起きなくなる)
2. **全身の場面**: 共通の部品(仮に `MonsterArt mode="full|bust|face"`)が `body` から収め方を決める。場面ごとの contain / cover の書き分けをやめる
3. **場面ごとの例外**: どうしても要る物(MFバトルカードの VS で大きく出すなど)は、この表の中に `scenes: { cardVs: {...} }` として書く。パーツの中に手書きの値を置かない
4. **マーケット・プロフィールの寄せ**(`MARKET_PROFILE_ICON_STYLES` の顔の行): 顔アイコンが正しくなれば要らない。円盤石の行だけ残す
5. **助手・アシストカード・混血**も同じ表に入れる(助手は表情の顔の絵が切り出し済みなので、`face` の中心だけ確かめる)

## 6. 見張り(検査)

- `tools/image/art-anchor-check.js`(新しく作る・run-checks に入る)
  - 全部の子(モンスター・混血・助手・アシストカード)に `ART_ANCHORS` があるか。無ければ止まる(新しい子を足して書き忘れたら公開できない)
  - 顔アイコンの絵を読んで、`face.cx/cy` が丸のまんなかから 4% 以内か(数字で見る)
  - 全身の場面を実際に描き、頭の上・足もとが枠の外へ出ていないか
- `tools/image/art-anchor-sheet.js` … 全部の子 × おもな場面を1枚に並べた画像を出す(社長・窓口が目で見る用)

## 7. 手順への書き足し(仕組みを入れるとき)

- `monster-add` スキル: 「`ART_ANCHORS` に顔の中心・大きさ・頭の上・足もとを書く」「`art-anchor-check` を通す」を足す
- 助手・アシストカードを足す手順にも同じことを書く
