# 見回りの続き: MFバトルカードの VS 画面と、混血の札(2026-10-26)

[README.md](README.md) の続き。開発部クラフトの依頼 ③(VS 画面で、モンスター・助手・アシストカードの顔がどう切られているか)と ①(混血の札の絵)。
本物の画面を 390・320 で開いて撮った(デバッグの MFバトルカード → 助手と対戦 → VS)。直すのは、クラフトと相談してから。

## ③ VS 画面(`data-card-vs`)

写真: `vs-assistants-w390.jpg`・`vs-assistants-w320.jpg`(相手の助手5人ぶん。みゅあ・きき・ももすけ・ドラ・きゅうこ)。

### 仕組み(測った値・390 幅)

| 絵 | 枠 | 収め方 |
| --- | --- | --- |
| 相手の助手の立ち絵 | **133×177(縦長)** | `object-contain` |
| 双方のモンスター | **118×118(正方形)**(札は 118×135) | `object-contain` |
| 自分のアイコン | 32×32 の丸 | `BreederIcon`(顔アイコン) |

### 見えたこと(ずれの大きい順)

1. **【大】相手の助手の大きさが、助手ごとに大きく違う(顔の位置ではなく、見た目の大きさ)**。
   枠は縦長の 133×177 に `contain` だが、立ち絵の画像の形が助手ごとに違うため、枠に入る大きさが変わる。

   | 助手 | 画像の大きさ | 枠に入った見た目の高さ | 備考 |
   | --- | --- | --- | --- |
   | みゅあ | 1536×1024(横長・人物は幅の59%) | **約89px** | 人物の幅は約78px。いちばん小さく見える |
   | きき | 1536×1024(横長・人物は幅の89%) | **約89px** | 同じ画像の形 |
   | ドラ | 384×384(丸い顔の絵) | 約109px | 顔のアップ |
   | ももすけ | 512×512 | 約133px | 上半身 |
   | きゅうこ | 384×512(縦長) | **約177px** | 枠いっぱい。いちばん大きい |

   みゅあ(全身)・きき(横長)は、ももすけ・きゅうこ(上半身のアップ)より**ずっと小さく**写る。
   同じ画面で並べると 2 倍近く違う(`vs-assistants-w390.jpg`)。顔の位置の問題ではなく、**絵の縦横比と枠の形が合っていない**ことが原因。
2. **【中】混血・モンスターは、横長の子ほど小さく写る**(枠が 118×118 の正方形に `contain`)。
   縦横比が 1 より大きい子は、幅いっぱいで高さが縮む。見た目の高さ(118px が満点):

   | 小さく写る順 | 縦横比 | 見た目の高さ |
   | --- | --- | --- |
   | C-041 コロネ | 1.24 | 95px |
   | C-062 ムラサキチュウ | 1.23 | 95px |
   | C-061 ベニヒメソウ | 1.21 | 97px |
   | C-040 ヒネクレソウ | 1.14 | 103px |
   | C-038 ダークヘンガー | 1.11 | 105px |
   | C-063 アーマードラゴン | 1.10 | 107px |
   | (純血) ワーム | 1.26 | 93px |
   | (純血) ヘンガー | 1.17 | 100px |

   縦に細い子は高さは満点(118px)だが、幅が狭い(C-060 ミミニャー 57px・C-015 ヴァージアハピ 72px・C-055 ダークハム 73px・C-058 ワカクサケンザイ 76px)。
   高さの中央値は 118px で、半数は満点。**いちばん小さい子と大きい子の差は約 20%**。
3. **【小】自分のアイコンは 32px の丸**。顔アイコンの寄りがそのまま出る(補正なし)。テスト(モッチー)は問題なし。
4. **アシストカード(札)は VS 画面には出ない**(札は対戦中の画面だけ)。VS に出るのは、助手の立ち絵・モンスター・自分のアイコンの3種。

## ① 混血の札(`hybrid-cards-all.jpg`)

混血は 41 枚(C-010〜C-067、特別版 S・V を含む)。札の画像は `images/card-battle/s/Cxxx.jpg`、対戦で出す全身絵は `images/monsters/cNNN.png`(35体。C-066・C-067 の全身絵はまだ無い)。

- **札の画像は絵がはめ込み済み**(絵の位置・大きさは作った絵の中で決まっていて、画面側の補正はない)。41 枚を並べて見た結果:
  - **顔・頭が欠けている札は見つからなかった**。
  - 絵が札の上の枠にかかる札: **C-016 エンジェル(翼が上へ)・C-019 バズラ(頭が上枠にくっつく)・C-043 ベスピオス・C-045 ムー・C-063 アーマードラゴン**(翼・頭が上の枠に触れる)。ほかの札より絵が大きめ(寄り気味)。いずれも欠けてはいない。
  - 特別版の C-066S・V、C-067S・V は、光の演出で絵が大きく見える(別の作りなので比べない)。
- **全身絵(`cNNN.png`)は、余白を切って高さ 916px にそろえてある**(幅は 444〜1134px)。切ってあるので、絵の「顔のまんなか」を示す基準が無く、
  純血の `ART_ANCHORS` のような点は混血にはまだ無い。VS 画面では上の ③ 2 のとおり、縦横比の差がそのまま大きさの差になる。

## クラフトへ(相談したい点)

1. VS の助手の立ち絵: 枠を「助手ごとの絵の形」に合わせるか、画像を同じ縦横比にそろえるか(いまはみゅあ・ききが小さい)。
2. VS の混血・モンスター: 枠 118×118 を、高さそろえ(横長の子は幅がはみ出す)にするか、そのままにするか。
3. 混血の全身絵に `ART_ANCHORS` の点を足すか(顔のまんなかを持たせる)。
