## 2. 見つけたこと(ずれの大きい順)

すべて、いまの画面を撮った結果。**直す案ではなく、見えた事実と、それが起きる仕組み**。

1. **【形・デザインの違い。2026-10-26 クラフト「いまは直さなくてよい」】初期8体のアイコン選択だけ、丸ではなく「角丸の札+名前」になる**(`profile-icon-picker-w390.jpg`、`faces-vs-body-vs-disc-w390-p1/p2.jpg` のゴーレム・ハム・ピクシー・スエゾー)。
   同じ子がホーム・ランキングでは丸の顔アイコンなので、丸に切ったときの寄りは、この札では確かめられない(場面6)。
2. **【中・寄り】顔アイコンの寄りの強さが、子ごとに大きく違う**。ドリーミィ(顔のアップで髪が丸の外へ出る)・メルホイップ(ほぼ模様になる)・イルミネ・エイキは顔のアップ、
   ゴースト・スプーキー・クロミー・メロディー・ミタラシ・アークは上半身まで入る(`faces-vs-body-vs-disc-w390-p1/p2.jpg` の中の列)。
   ART_ANCHORS は「顔のまんなか」をそろえるが、**寄り(大きさ)は `FACE_BOXES` の子ごとの手書き**のまま。
3. **【中・場面の差】同じ子が「図鑑=全身が小さい / アイコン=顔のアップ / 円盤石=全身がリングいっぱい」で、場面ごとに見え方が大きく違う**(`faces-vs-body-vs-disc-*`)。
   意図した違い(全身か顔か)だが、円盤石の中の子の位置は子ごとに `scale 0.95〜1.52・y 0〜2.3` の手書きがあり、
   スネグーラチカ・ウンディーネ・ヤオビクニだけ 1.49〜1.52倍に寄せている。ミーア・パンドラは円盤の中で下へ寄る(`y 0.8〜1.6`)。
4. **【小〜中・全身の丸】縦に細い子は、全身絵を丸に `contain` で入れると、丸の高さの約6割・幅は3割ほどしか使わず、顔が小さく見える**(図鑑: ピクシー・ミーア・c013・c033・c016 など)。
   `MONSTER_ART_CONTAIN_IDS` の13体は手書きの表で、足し忘れると頭が切れる(過去に起きた)。
5. **【小】助手の顔は場面が違っても位置はそろっている**(アイコン選択・マーケットのアシスト札・円盤石の画面・カード対戦。`assistants-by-scene.jpg`)。
   丸・角丸(みゅあは桃色の角丸)の枠の形だけが場面で違う。アシスト札の手書きの寄せは きき だけ(`ASSIST_CARD_ICON_STYLES`)で、ほかの助手は絵のまま出ている。
6. **【撮影の限界】カード対戦の1画面では、対戦の札の中の混血の絵・助手の欄は、顔が欠けたり丸の中心から大きくずれたりしてはいなかった**(`card-battle-w390.jpg`)。
   ただし1画面しか見ていない(混血は50体近くいる)。

## 3. 撮れていない所(理由と、次にやること)

| 場面 | 理由 | 次にやること |
| --- | --- | --- |
| モンスター編成・マスモン一覧・放牧の丸 | マスモンを持っていないと出ない | 保存データの代わりに、確認用の仮の保存を作って開く(本物のセーブには触れない) |
| ランキング・フレンドのプロフィールの丸 | サーバーのデータが要る | `BreederIcon` と同じ部品なので、アイコン選択・マーケットで代表(構図は同じ) |
| モンヒロビートの選曲・顔の列 | 顔の列は演奏の中・選曲の丸の入口を特定できていない | 場所を特定してから撮る |
| 320 幅の全場面 | 390 と同じ部品で、構図は同じ(`*-w320-*.jpg` は並べてある) | 気になる子だけ個別に見る |
