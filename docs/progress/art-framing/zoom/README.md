# 顔アイコンの「寄りの強さ」を測った表(2026-10-26)

開発部クラフトの依頼。顔アイコンの寄りの強さをそろえる案(クラフトが社長へ出す)の材料。
`monster-hero/images/monster-icons/face/*.png` の**全員(78体)**について、256px の丸の中で「顔の幅」が何px かを**目で測った**。

## 測り方

- 丸(256px・画面と同じく丸で切る)に、32px ごとの目盛りの線を重ねて見て、顔の左端と右端を読んだ(**±10px くらいの目測**)。ミタラシだけ元が 512px なので 256px に縮めて測った。
- **「顔の幅」= 頭(顔)の横いっぱいの幅**。耳・翼・角・飾り・帽子のつば・髪の外側は含めない(髪が顔の一部の子は、顔の肌の幅)。両目が見える子は「両目の外側〜外側」より少し広く、頬の幅くらい。
- **顔がはっきりしない子**(箱・卵・板・ドーム型・ロボットなど: c037・c038・c040・c057・c058・c059・henger・arrowhead)は、頭の見える部分の幅を読んだが、表に「顔がはっきりしない」と印を付け、上位5体の順位からは外した。

## 結果(顔があるはっきりした子 70体)

| | 値 |
| --- | --- |
| 中央値 | **187px(丸の73%)** |
| 平均 | 172px(67%) |
| 最小〜最大 | 70px(27%)〜250px(98%) |

最小と最大は 3.5 倍違う。**半数の子は 160〜230px(63〜90%)**に入るが、両端がかなり外れている。

## 気づいたこと

1. **同じ丸の中で、顔の大きさが 27%〜98% とばらつく**。クラフトが見つけた「寄りの強さがまちまち」(`FACE_BOXES` の子ごとの手書き)が、数でもはっきり出た。
2. **引きすぎの子は、顔のまわりの飾り・髪・花・帽子で丸を埋めている**(ベニヒメソウ・ガリ・ジョーカー・ユグドラシル・ベスピオス)。顔だけを見せるなら、いまの2.5倍ほど寄れる。
3. **寄りすぎの子は、顔が丸いっぱいで頭の輪郭が欠ける**(プラムラー・ザン・メロンボ・ヨロイモッチー・マミニャー)。
4. 顔の幅を丸の約70〜85%(180〜220px)にそろえると、両端の子以外はほとんど動かさずに済む(中央値が 187px なので)。この値はクラフトの案に使える目安として書いた(決めてはいない)。
5. 値は目測なので、**順位の近い子は入れ替わることがある**。そろえた後に、測り直す(自動で顔の幅を出す道具を作る)のがよい。
