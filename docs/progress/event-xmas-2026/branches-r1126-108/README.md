## 矛盾しないための決まり(全部の案に通す)

1. **真相は1つのまま**: 犯人はきゅうこ・動機は「12年前、母を閉め出した人たちに同じ寒さを」・ドラはかばっている。これを変える「別の真相」は作らない。そのかわり、**真グッドのあとだけ開く「もしも」**(本筋の答えを知った人が選ぶ、起きなかった方の夜)として作る(下の第4弾)
2. **真グッド以外では答えを明かさない**(r1126-022 追記6): 動機の正解・決め手・ドラがかばった理由。黒いサンタは影か「？？？」の声だけ。もしもの道は真グッドのあとだけなので明かしてよい
3. **殺される理由の決まり**(r1126-043 追記2・3): ねらわれるのは箱を持ち12年前に関わった人(黒羽・白瀬・えるびん・ももすけ)。ほかの人が亡くなるのは「見てしまった・近づきすぎた」(やむを得ず)か、雪の山(人の手でない)だけ
4. **後半の死ぬ順**(えるびん → ももすけ → もちまる)と、狙われる人が尽きたら黒いサンタはもう殺さない、をそのまま使う(迷宮入りのエンドの理由になる)
5. 途中の推理の問い(突きつけ)のまちがいは、今までどおり分かれ道にしない(r1126-099)。足すのは**行動の選択**と**名指しのあとの選択**だけ
6. 決め台詞・口調・呼び方・「文章はしっかり、絵は演出で」・きゅうこは男の子、は今の決まりのまま

## 既に読んだ人の保存を壊さない作り

- 保存のキー・形は変えない(`mh_xmas_novel_v1`・`mh_xmas_novel_route_v1`)。見たエンドは `endings` に id が増えるだけ
- **今ある場面の行の途中には差しこまない**。続きの場所(`cur.idx`)と見取り図の読み直しの点(`route.at`)は「場面の何行目か」で残っているので、途中に行を足すと一つずれる。選択は「新しい場面を場面と場面のあいだに挟む」か「今ある選択の選択肢を1つ足す」(行の数が変わらない)か「場面の最後に足す」だけにする
- 名指し・動機のあとの選択は、行き先(`route` の `*`)を新しい場面へ向けるだけ。今そこにいる人の続きはそのまま
- `endings` は50件まで残す作り(`xmasNovelNormalize` の `strs(r.endings, 50)`)。33なので足りるが、50を超えるほど増やすときは上限を上げる(読み込みの数を増やすだけ・壊さない)
- 新しいエンドの id は今の決まり(`END-` + 英大文字 + 数字)に合わせる(見たエンドの日時の読み込み `/^END-[A-Z]+\d*$/` に合う)
- ランキング(r1126-107)は、弾を出すときにサーバーの「数えてよいエンドの一覧」へ行を足すだけで、見たエンドの数がそのまま増える
