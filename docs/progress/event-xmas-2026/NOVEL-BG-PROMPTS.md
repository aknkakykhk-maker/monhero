# 事件簿『十三番目の鐘』の背景 プロンプト集(チャッピー用)

台帳 r1126-029。台本 SCRIPT.md の「背景:」を、まとめて16枚にした。届くまでは色のグラデーションで代わりにしている(`79-screen-xmas-novel.jsx` の `XMAS_NOVEL_BG`)。
朝・夜・ろうそくなどの時間の違いは、ゲーム側で明るさと色をかぶせて作るので、ホール以外は1枚ずつでよい。

**同じ会話で1枚ずつ続けて作る**(絵の雰囲気をそろえるため)。最初に「共通の決まり」を送り、そのあと「1枚目」から順に送る。


## 届いたら(窓口・開発部へ)

- `79-screen-xmas-novel.jsx` の `XMAS_NOVEL_BG` に、台本の背景の名前→絵を足す(例: ホール+夜/ろうそく/停電 → `hall_night`、ホール → `hall_day`、裏口 → `backdoor`、客室・ドラの部屋・きゅうこの部屋・えるびんの部屋 → `guest_room`、朝の鏡の廊下 → `mirror_hall` に朝の色を重ねる)
