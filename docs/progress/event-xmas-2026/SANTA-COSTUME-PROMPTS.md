# クリスマスイベント 助手のサンタきせかえ プロンプト集(チャッピー用)

台帳 r1119-172(追記5・12・13)。社長「全助手のサンタきせかえを作りたいから、イメージカラーとかイメージを助手ごとに決めて、チャッピーに投げれるプロンプトを作りたい」(2026-11-25)。

## 使い方

1. チャッピーの新しい会話を開く(**1人ずつ別の会話**。同じ会話で続けると、前の助手の顔が混ざりやすい)
2. 下の「助手ごとのまとめのプロンプト」から、その助手の枠を**そのまま全部コピーして貼る**。これ1つで、参考の絵・衣装・作る順番(全身 → 表情8種 → 寝顔)・書き出すファイル名まで全部入っている
3. 1つできるごとに見せてくれるので、よければ「次へ」と送る
4. 最後に、チャッピーが**GitHubの「できた絵の保存先」へ直接置いてコミットする**(加工なし)。置けたら担当の会話に「◯◯の絵を置いた」と知らせる

- チャッピーが参考の絵のリンクを開けないと言ったときだけ、その助手の絵を添付する
- ボスが「贈り物を奪う黒いサンタ」なので、**助手のサンタは黒を主役にしない**(あつは黒が持ち色なので、赤を主役にして黒は差し色まで)

## できた絵の保存先(GitHub)

チャッピーが作った絵は、チャッピーが**加工せずに**下の場所へ直接置く(受け取った物はそのまま残す決まり)。ゲームで使う大きさへの切り出し・顔アイコン作りはバトル部(または窓口)がここから作る。

置き場所: `tools/art-sources/assistants/<フォルダ>/santa/received/`
GitHub で見る: https://github.com/aknkakykhk-maker/monhero/tree/main/tools/art-sources/assistants

例: みゅあの全身の絵は `tools/art-sources/assistants/mua/santa/received/mua_santa_fullbody.png`

- 置き方は、担当の会話に ZIP を渡せば置いてもらえる。自分で GitHub に上げるときは、`tools/art-sources/assistants/<フォルダ>/` で「Add file → Upload files」を開き、名前の頭に `santa/received/` を付けてから上げる
- 作り直した絵は、前の絵を消さずに `_v2` を付ける(例 `mua_santa_fullbody_v2.png`)。どちらを使うかは渡すときに言う
- ゲームに入れたあとの置き場所(参考): 全身 `monster-hero/images/assistant/fullbody/<名前>_santa.png`、表情 `monster-hero/images/assistant/santa/`(ハロウィンの衣装と同じ並び)
- みゅあの表情8枚は、先に作ったぶんを「表情ごとの8枚」で書き出した(`mua_santa_faces.zip`)。名前の形はこの表と同じ

## 助手ごとのまとめのプロンプト

### みゅあ

```
ゲーム「モンスターヒーロー」の助手「みゅあ」の、クリスマスのサンタきせかえの絵を作ってください。

■参考の絵(よく見て、同じ人物で作る)
https://github.com/aknkakykhk-maker/monhero/blob/main/monster-hero/images/assistant/fullbody/mua.png

■みゅあの衣装
キャラクター: みゅあ。明るく元気なムードメーカーの女の子。
イメージカラー: ピンク・白。金色は使わない(いまの絵の金の飾りも、白いレースかピンクの刺しゅうに置きかえる)。
衣装: 「天使のサンタ」。ピンクのサンタドレス(ふんわり広がる段のスカート)、裾と袖と胸元に白いふわふわのファー、白いレースの縁取り。
残すもの: 金髪のふわふわのツインテール、青い目、白い天使の羽。頭の帽子は、いまの垂れたうさ耳の帽子の形のまま、サンタ帽の赤と白のファーと白いぽんぽんを足す。
小物: 銀の鈴のついたピンクのリボン、白いニーハイ、ピンクと白のブーツにピンクのハート。
表情: 元気な笑顔。

■作る順番(1つできるごとに見せてください。私が「次へ」と言ったら次へ)
★作る絵は10枚すべて「全身の絵」(頭のてっぺんから足の先まで)。胸から上・顔だけ・バストアップの絵は1枚も作らない(顔の切り出しはゲーム側でする)
1. 全身の絵(正面・頭の上から足の先まで全部・縦長・参考の絵に近い自然な立ちポーズ)
2. 表情8種(8枚とも全身の絵・同じ服。表情ごとにポーズも変える: その気持ちに合う立ち方・手の動き・体の向きにする。8枚が同じポーズにならないように): ふつうの微笑み/笑顔/ウインク/驚き/困り顔/むくれ顔(怒り)/泣き顔(照れ泣き)/わくわく(したり顔)
3. 寝顔(全身の絵・1枚・目を閉じてすやすや。立ったままこっくりうとうと、またはプレゼント箱に座って眠るなど、全身が入る眠りのポーズ・小さな「Zzz」1つまで)
4. 最後に、全部をGitHubへ置く(下の「GitHubへ置く」)

■守ること
- 参考の絵と同じ人物にする。顔立ち・目の色と形・髪型・髪色・体型・年齢感は変えない
- 画風・線の太さ・塗り方・色の淡さも参考の絵に合わせる(別の絵柄にしない)
- 変えるのは服と小物だけ
- 背景は透過(できなければ真っ白の単色)。床の影・背景の模様・文字・ロゴ・サインは入れない(寝顔の「Zzz」1つだけは可)
- 手と指の数・形を正しく

■GitHubへ置く(全部できたら)
作った絵を描き直さず・縮めず、PNG(背景は透過のまま)で、GitHub のリポジトリ aknkakykhk-maker/monhero の main ブランチへ、次の場所に追加してコミットしてください。
置き場所: tools/art-sources/assistants/mua/santa/received/
- 全身の絵 → mua_santa_fullbody.png
- ふつうの微笑み → mua_santa_normal.png
- 笑顔 → mua_santa_happy.png
- ウインク → mua_santa_wink.png
- 驚き → mua_santa_surprise.png
- 困り顔 → mua_santa_troubled.png
- むくれ顔(怒り) → mua_santa_angry.png
- 泣き顔(照れ泣き) → mua_santa_crying.png
- わくわく(したり顔) → mua_santa_excited.png
- 寝顔 → mua_santa_sleep.png
コミットメッセージ: 素材: mua のサンタきせかえの元絵(チャッピーで作成・加工なし)
- この場所以外のファイルは、追加・変更・削除しない
- 同じ名前のファイルがもうあるときは上書きせず、名前の最後に _v2 を付ける
- 終わったら、コミットのリンクと追加したファイルの一覧を見せる
- GitHubへ置けないときだけ、同じファイル名で1つのZIP「mua_santa.zip」にまとめてダウンロードできるようにする
```
