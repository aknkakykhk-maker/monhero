# クリスマスイベント 助手のサンタきせかえ プロンプト集(チャッピー用)

台帳 r1119-172(追記5)。社長「全助手のサンタきせかえを作りたいから、イメージカラーとかイメージを助手ごとに決めて、チャッピーに投げれるプロンプトを作りたい」(2026-11-25)。

## 使い方

1. チャッピーの新しい会話に、**その助手のいまの絵を1枚添付**する(下の表の「添付する絵」)
2. 「共通の前置き」+「その助手のプロンプト」を**続けて1つに貼って**送る
3. 全身の1枚ができたら、同じ会話で「表情8種のプロンプト」を送る
4. できた絵は**加工せずに**窓口へ(受け取った物はそのまま入れない決まり。切り分け・顔アイコン作りはこちらでやる)

- ハロウィンの衣装と同じく、ゲームの中では「全身の絵+表情8種」を使う
- ボスが「贈り物を奪う黒いサンタ」なので、**助手のサンタは黒を主役にしない**(あつは黒が持ち色なので、赤を主役にして黒は差し色まで)

## 共通の前置き(毎回これを先に貼る)

```
添付した絵のキャラクターに、クリスマスのサンタ衣装を着せた「着せ替え」の絵を作ってください。

必ず守ること:
- 添付の絵と同じ人物にする。顔立ち・目の色と形・髪型・髪色・体型・年齢感は変えない
- 画風・線の太さ・塗り方・色の淡さも添付の絵に合わせる(別の絵柄にしない)
- 変えるのは服と小物だけ
- 全身、正面向き、頭の上から足の先まで全部入れる。縦長の絵
- ポーズは添付の絵に近い、自然な立ちポーズ
- 背景は透過(できなければ真っ白の単色)。床の影・背景の模様・文字・ロゴ・サインは入れない
- 手と指の数・形を正しく
```

## 助手ごとのプロンプト

### みゅあ(ピンク×白)

```
キャラクター: みゅあ。明るく元気なムードメーカーの女の子。
イメージカラー: ピンク・白。金色は使わない(いまの絵の金の飾りも、白いレースかピンクの刺しゅうに置きかえる)。
衣装: 「天使のサンタ」。ピンクのサンタドレス(ふんわり広がる段のスカート)、裾と袖と胸元に白いふわふわのファー、白いレースの縁取り。
残すもの: 金髪のふわふわのツインテール、青い目、白い天使の羽。頭の帽子は、いまの垂れたうさ耳の帽子の形のまま、サンタ帽の赤と白のファーと白いぽんぽんを足す。
小物: 銀の鈴のついたピンクのリボン、白いニーハイ、ピンクと白のブーツにピンクのハート。
表情: 元気な笑顔。
```

### きき(真紅×深緑×金)

```
キャラクター: きき。おとなしい口調だけど、戦い方は火力で押し切るお姉さん。
イメージカラー: 真紅・深い緑・金。
衣装: 「王道のサンタ」。白いファーの縁の、真紅のフードつきサンタケープ(前を金のボタンで留める)。スカートは深緑のチェックのプリーツで、裾に金のライン。
残すもの: ピンクのボブヘア、ピンクの目、頭の上のピンクのうさ耳リボン(サンタ帽をかぶせず、リボンに白いファーと小さな柊の飾りを足す)。
小物: 白いハイソックス、赤と白のハートのスニーカーブーツ、小さなプレゼント箱を片手に。
表情: 落ち着いた、やわらかい微笑み。
```

### ももすけ(桜ピンク×白×いちごの赤)

```
キャラクター: ももすけ。ちょっぴり生意気な、小悪魔系アイドルの女の子。一人称は「もも」。
イメージカラー: 桜のピンク・白・いちごの赤。
衣装: 「小悪魔アイドルのミニスカサンタ」。フリルたっぷりのピンクのミニスカのサンタワンピース、白いファーの縁、胸に大きないちご色のリボン。腰から小さなピンクの小悪魔のしっぽを少しだけのぞかせる。
残すもの: 金からピンクへのグラデーションの髪、緑の目、白いふわふわの垂れ耳、桜の花とリボンの髪飾り。
小物: 赤と白のしま模様のキャンディケインを持つ、白いニーハイ、ピンクのストラップの靴。
表情: いたずらっぽいウインクか、口を開けた明るい笑顔。
```

### ドラ(もみの木の緑×白)

ドラは全身絵がなく、落書き風の丸い顔の絵(胸から上)だけ。**この画風を崩さないのが一番大事**なので、前置きの「全身」は使わず、下の文だけで送る。

```
添付した絵のキャラクター(ドラ)に、クリスマスの格好をさせた絵を作ってください。

必ず守ること:
- 添付の絵と同じ、手描きの落書き風の画風のまま(太い茶色の線・塗りは肌色だけの、ゆるい絵)。リアルにしない・アニメ絵にしない
- 丸い顔、丸いめがね、ツンツンの短い毛、への字の口はそのまま
- 絵の大きさ・顔の位置・余白は添付の絵とそろえる(正方形、顔は真ん中)
- 背景は透過(できなければ真っ白)。文字は入れない

衣装: もみの木の緑のサンタ帽(白いファーの縁と白いぽんぽん)を斜めにかぶり、あごに白いもこもこのつけひげ(少しずれている)。
雰囲気: 下ネタまじりの冗談ばかり言う、ゆるいおじさん。ちょっと照れてごまかしている感じ。
```

### えるびん(白×サンタの赤×金)

石油王の衣装(`erubin_sekiyuou.png`)をサンタにする形。顔を合わせるため、ふだんの絵(`erubin.png`)も一緒に添付する。

```
キャラクター: えるびん。みんなを見守る穏やかな大人の男性。砂漠から来たので、まわりから「石油王」といじられている(本人はいたって普通)。
イメージカラー: 白・サンタの赤・金。
衣装: 「砂漠のサンタ」。添付した石油王の衣装(頭布と、ゆったりした民族衣装)の形のまま、サンタの色にする。頭布は赤で、ふちに白いファー、頭の輪は金。衣は白で、前の合わせと裾に赤と金の刺しゅう、白いファーの縁。
残すもの: 茶色の巻き毛、口ひげとあごひげ、茶色の目、腕時計。顔はふだんの絵(2枚目の添付)に合わせる。
小物: 片手に、赤い鞍と金の鈴をつけた小さなラクダのぬいぐるみ。もう片方の手に、赤と金のリボンのプレゼント箱。
表情: 穏やかでやさしい微笑み。
```

## 表情8種のプロンプト(全身ができたあと、同じ会話で送る)

```
いま作ったサンタ衣装のキャラクターで、表情違いを8つ作ってください。
- 1枚の絵に、4列×2段で8つ並べる。どれも同じ大きさ・同じ画角(胸から上)・同じ服
- 顔・髪・服・画風は、さっきの絵と完全に同じ。変えるのは表情だけ
- 並び順(左上から右へ): ふつうの微笑み / 笑顔 / ウインク / 驚き / 困り顔 / むくれ顔(怒り) / 泣き顔(照れ泣き) / わくわく(したり顔)
- 背景は透過(できなければ真っ白)。文字・番号・枠線は入れない
```

ドラは表情も落書き風のまま、正方形の顔だけで8つ(並び順は同じ)。
