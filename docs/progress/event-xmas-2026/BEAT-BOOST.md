## 決めごととの突き合わせ(止め絵の代わりに検査の結果)

HOME の札を時計を進めて撮ろうとしたが、起動の窓を抜けられず3回で打ち切った(札は本オープン記念と同じ部品で、出し入れは定義の時刻だけで決まる)。

| 決めごと | どこで満たすか |
| --- | --- |
| 期間 11/30 10:00〜12/31 4:00 | `rhythm-xmas-campaign-check` ①②(9:59:59 は無し・10:00 から・12/31 3:59:59 まで・4:00 で終わり) |

| 11/30 の境目で倍率が落ちる・重なる | 同 ④(前のイベントの公開曲と同じ量・同じ周回の倍率。イベント曲だけの7倍は持ち越さない)。**11/30 0:00〜9:59 は5倍なし**(前のイベントが 0:00 で終わるため。11/9 の 4:00〜9:59 と同じ) |
