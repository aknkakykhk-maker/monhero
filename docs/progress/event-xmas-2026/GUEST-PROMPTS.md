# クリスマスのお話 謎の客2人の立ち絵 プロンプト集(チャッピー用)

台帳 r1126-022。見た目は台本 SCRIPT.md「E. 謎の客2人」のとおり。
**1人ずつ別の会話で**作る(同じ会話で続けると顔が混ざる)。
できた絵は、チャッピーが加工せずに `tools/art-sources/promo/xmas-2026/received/guests/` へ置く。

## 黒羽 宗一郎(くろば そういちろう)

```
スマホのカードバトルゲーム「モンスターヒーロー」のミステリーのお話に出る、登場人物の立ち絵を2枚作ってください。1枚できるごとに見せてください。私が「次へ」と言ったら次へ。

■絵の雰囲気の手本(同じ塗り・同じ線・同じ頭身にする)
- https://github.com/aknkakykhk-maker/monhero/blob/main/monster-hero/images/assistant/fullbody/sorashido_santa.png
- https://github.com/aknkakykhk-maker/monhero/blob/main/monster-hero/images/assistant/fullbody/atsu_santa.png
やわらかい線のアニメ調。手本の2人と並べても同じゲームの絵に見えること。

■人物: 黒羽 宗一郎(58歳の男)
- 都会の大きな音楽事務所の社長。横柄で、人を見下した態度。いつも懐中時計を見ている
- 背が高く、やせて肩が角ばっている。白髪まじりの髪をうしろへなでつけたオールバック
- 細い銀縁のめがね、眉間に深いしわ、口ひげは無し
- チャコールグレーの長いウールのコート、黒いタートルネックのセーター、えんじ色のスカーフ
- 片手に金色の鎖の懐中時計、もう片方の手に黒い革の手袋。黒い杖(握りは銀)
- こわい顔にしすぎない(悪役っぽさは目つきと口もとで出す)

■1枚目: 全身の立ち絵
- 正面からやや斜め。立ったまま懐中時計を見ている
- 背景は透明(PNG・透過)。影・地面・文字は入れない
- 縦長(1:2くらい)。頭から足まで全部入れ、上下左右に少し余白

■2枚目: 顔(胸から上)
- 1枚目と同じ人物・同じ服。口をへの字にした、人を見下ろす目つき
- 背景は透明(PNG・透過)。正方形

■絶対に守ること(1つでも外れたら作り直す)
- 2枚とも同じ人物・同じ顔・同じ服
- 文字・ロゴ・サインを入れない。背景は透明
- 血・けが・武器は描かない
- 見せる前に「手本と同じ絵の雰囲気か」「背景が透明か」を自分で確かめて一言そえる

■GitHubへ置く(2枚ともできたら)
描き直さず・縮めず、PNG で、リポジトリ aknkakykhk-maker/monhero の main ブランチへ追加してコミットしてください。
置き場所: tools/art-sources/promo/xmas-2026/received/guests/
- 全身 → kuroba_fullbody.png
- 顔 → kuroba_face.png
(同じ名前があれば上書きせず _v2 を付ける。この場所以外のファイルは、追加・変更・削除しない)
コミットメッセージ: 素材: クリスマスのお話の黒羽の立ち絵(チャッピーで作成・加工なし)
終わったら、コミットのリンクを見せる。

■クロードへの引き継ぎ(最後に、そのままコピーできる文を1つ書く)
---
クロードへ。黒羽の立ち絵(全身・顔)を置きました。
置き場所: tools/art-sources/promo/xmas-2026/received/guests/
コミット: (コミットのリンク)
お願い: クリスマスのお話(ノベルゲーム)の立ち絵として、影の仮の絵と差し替えてください。
---
```
