# 「Kissからはじまるミステリー」のジャケット プロンプト(チャッピー用)

台帳 r1126-015。社長「このジャケットをあつとソラシド探偵版にうまく作り直させるプロンプトつくって」(2026-11-26)。
手本は社長が持っている元のアルバムのジャケット(白地に青い円の線・左下と右上の2人・真ん中の大きな黄緑の文字・黄色に赤い縁の太い文字)。
**手本の画像は、チャッピーの会話に社長が直接添付する**(リポジトリには入れない)。

使い道: モンヒロビートの曲えらびのジャケット(512×512 にこちらで縮める)と、イベントページの曲の表示。

```
スマホのカードバトルゲーム「モンスターヒーロー」の音楽ゲームで使う、曲のジャケット(正方形 1:1)を1枚作ってください。

■手本(添付した画像)
添付したCDジャケットの「構図・色・勢い」をまねて、人物を下のゲームのキャラクター2人に置き換えます。
写っている実在の人物の顔・姿は描かないでください。元のグループ名・ロゴの文字も入れないでください。
まねするのは次のところだけです。
- 白い背景に、青い細い線の円や弧がいくつも走り、白と水色のスピード感のある残像がかかっている
- 2人をカメラが上から見下ろす角度で描き、こちらを見上げている
  - 左下に1人。少し小さめで、体を傾けている
  - 右上にもう1人。大きめで、体を乗り出している
- 真ん中に大きな黄緑の太い文字が1つあり、その横に小さな文字が段で並ぶ
- 下の方に、黄色に赤と黒の縁取りをした太い斜めの文字がある
- 90年代のCDジャケットのような明るくポップな写真風の雰囲気。ここだけはゲームのアニメ調の塗りにする

■出すキャラクター(参考の絵と同じ人物・同じ髪・同じ衣装で描く)
- あつ(右上・大きめ): https://github.com/aknkakykhk-maker/monhero/blob/main/monster-hero/images/assistant/fullbody/atsu_santa.png
  赤い髪・銀の王冠・青い目・黒のジャケットに赤いシャツの探偵の衣装。自信たっぷりのにやりとした顔
- ソラシド(左下・少し小さめ): https://github.com/aknkakykhk-maker/monhero/blob/main/monster-hero/images/assistant/fullbody/sorashido_santa.png
  黒髪に青い毛先・丸眼鏡・紺のブレザーに赤い蝶ネクタイの少年探偵の衣装。落ち着いた、見抜くような目
- 2人は探偵のライバル。あつは虫めがねを片手に、ソラシドは眼鏡を指で押し上げる、など探偵らしい小物を1つずつ持たせる
- 2人とも参考の絵の顔立ちのまま。年齢・髪型・色は変えない

■文字(この2つだけ・つづりを正しく)
- 真ん中の大きな黄緑の文字: 「K」1文字。手本の大きな文字と同じ太さ・同じ影の付き方にする。
  横の小さな段の文字はやめて、代わりに小さな虫めがね・ハートの形の鍵穴・雪の結晶をあしらう
- 下の太い斜めの文字: 「Kissからはじまるミステリー」。手本の下の文字と同じ黄色の文字に、赤と黒の太い縁取りをして、少し斜めに置く。
  日本語が正しく読めることを最優先にする(字が欠けたり、ちがう字になったりしたら作り直す)
- これ以外の文字・英語・日付・ロゴは入れない

■クリスマスのひと工夫(控えめに)
- 白い背景の残像に、雪のつぶを少しだけ混ぜる
- 青い円の線の1本だけを、赤いリボンのように見せる

■絶対に守ること(1つでも外れたら作り直す)
- 実在の人物の顔・元のグループ名・元のロゴは描かない(構図と色づかいだけをまねる)
- あつとソラシドは参考の絵と同じ人物・同じ衣装
- 文字は「K」と「Kissからはじまるミステリー」だけ。つづりを正しく
- 正方形。顔と文字は端から 6% 以上内側に置く(あとで角を丸く切っても欠けない)
- 見せる前に「2人が参考と同じか」「文字が正しく読めるか」「実在の人物やロゴが入っていないか」を自分で確かめて一言そえる
```
