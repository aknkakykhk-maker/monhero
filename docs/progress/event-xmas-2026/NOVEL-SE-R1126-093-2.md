## 音の素材

音源ファイルは足していない。ゲームの効果音と同じく、その場で合成する音(Tone.js)を `monster-hero/src/parts/14-audio.jsx` の
表の口 `fgSe` に事件簿用として9つ足した(権利の心配なし)。どれも小さく低い音で、効果音の音量の設定(seBus)に従う。

| 音の名前 | どんな音 |
| --- | --- |
| `nvTick` | 柱時計のチク(高め)/タク(低め)。金属の短い粒と、ごく小さな低音 |
| `nvCreak` | 扉・床のきしむ「ギィ」(低いのこぎり波がゆっくり下がる) |
| `nvThud` | 遠くで重い物が落ちる・ぶつかる「ゴッ」 |
| `nvWind` | 吹雪の風「ゴォォ……」(2.5秒でふくらんで消える) |
| `nvFire` | 暖炉の薪がはぜる「パチ……パチ」 |
| `nvRustle` | 紙・封・空気の「カサ」 |
| `nvGlass` | 低めのガラスの「カシャ」 |
| `nvDread` | 不穏な一音(低い3音の半音のぶつかりが、ゆっくり消える) |
| `nvMusicBox` | 小さなオルゴールの短調の4音 |

## 1. 選択肢を待つ間のチクタク

行動の選択・推理の問い・人を名指しする窓が開いている間、柱時計のチク・タクを 0.64 秒ごとに交互に、小さく鳴らす。
選ぶ・「話をもう一度見る」で窓を閉じる・事件簿を閉じると止まる(窓を開けている間だけ動く仕組みなので、オート・早送りと重ならない)。
