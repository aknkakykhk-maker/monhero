## 2. 案(3通り)

### 案A 減らす(推理の問いを章に1つ程度へ)

- 推理の問いを Q2a(第2章)・Q4a(第4章)・Q6a(第6章)・Q10a(後半)の4つに減らす。Q3a・Q5a・Q6b は、主役が自分で手がかりを突きつける場面(今の `-ok` の行)をそのまま見せて進む(会話で自然に進める)
- 行動の選択は5つとも残す(バッドエンド5つは見たエンドの記録の「集める物」なので、消すとエンドの到達が壊れる)。ただし第2章の A2b と A2 の間に場面を1つはさむだけで連続感は減らせる(任意)
- 成績(score)は7問 → 4問(Q2a・Q4a・Q6a+1回目の推理)。結びの一言の区切り(7問 / 4〜6問 / 3問以下)を(4問 / 2〜3問 / 1問以下)へ替える
- **数: 先に進めない所 12 → 9**(推理の問い 7 → 4)。まちがいの数の合計 86 → 52
- 気になる所: 一番むずかしい Q6a(16個から)が残る。成績の数え方が変わる(すでに読み終えた人の記録の見え方に注意)

### 案B まちがえても進む(推理の問いを行き止まりにしない)

- 推理の問い7つは、まちがえたら「違う場面の返し」が出て、そのまま先へ進む。返しは今の行を使う: まちがい1回目なら `-x1`(または近い手がかりなら `-near`)のあとに、主役か相手が**正しい手がかりを自分で突きつける**一言(今の `-ok` の行)を出して進む。=「助手がまちがえ、探偵が拾う」形
- まちがいは成績(一発で当てた数)にそのまま効く。結びの一言(7問 / 4〜6問 / 3問以下)は今のまま使える。さらにエンドの札に「推理のまちがい ◯回」を出してもよい(任意)
- 行動の選択5つは今のまま(エンドの集める物)。工夫として、一度見た強制バッドの選択肢には「見たエンド」の小さな印を付ける(2周目からは迷わない)
- **数: 先に進めない所 12 → 5**(推理の問い 7 → 0。残る5つはエンド集めの分かれ道)。まちがいの数の合計 86 → 0(空振りなし)
- 気になる所: 「当てる手ごたえ」は一発目だけになる(当てた/外したは成績と結びの一言で返る)

### 案C 段階のヒントで、2回まちがえたら答えを選ばせる

- 推理の問い7つは残すが、①手がかり帳の候補を「この問いに関係しそうな物」だけ(今の章で手に入った物+正解+近い手がかり・3〜5個)に絞って出す ②1回まちがえるとヒント(今の `-x1`/`-near`)、③2回まちがえると候補が正解と罠の2つに減る、④3回目は `-x3` の返しのあと、正解だけを選べる形で進む
- 行動の選択は案Bと同じ(今のまま+見たエンドの印)
- **数: 先に進めない所 12 → 12**(場所は減らない)。ただし1か所で空振りできるのは最大2回 → **まちがいの数の合計 86 → 14**(7問×2)
- 気になる所: 候補の絞り方を問いごとに決める作業が要る。「手がかり帳から突きつける」楽しさは一番残る

## 3. 推し

**案B**(+ 案C の①「候補を絞る」を Q6a・Q6b・Q10a の3問だけに足す)。

- 行き止まりが推理の問いから全部なくなり、社長の「先に進めないのが多すぎる」に一番まっすぐ効く(12 → 5。残る5つは強制バッドで、エンドの集める物)
- 今の返しの行(`-x1`・`-near`・`-ok`)と成績(score)・結びの一言をそのまま使えるので、書き足す台詞が少なく、保存の形も変わらない
- 一番詰まる Q6a・Q6b・Q10a(17〜23個から探す)は、候補を絞ると一発目で当てる手ごたえも残る
