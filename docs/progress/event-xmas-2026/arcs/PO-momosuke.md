# 視点の編 ももすけの編「窓の外の影」(本筋・r1126-115・ALLOCATION の 10)

真グッドを見たあと、第3章 C3-1(雪の上の影)の最後に新しい選択が出る。停電の夜、ホールの窓の外に見た影と、黒羽の倒れた影を最初に見つけた朝を、ももすけの目で。
本筋の場面は CANON の区間に合わせる(見出しの `時刻:`)。ももすけは12年前のことを何も覚えていない(CANON「誰が何をいつ知ったか」・知るのは真ルート C8-3)。この編でも思い出しきらせず、体の奥に残った声と手の感じだけにする(過去編 C12-5 を裏側から見せる)。
窓の外の影が誰だったかは、帯で決めない(停電の直後、外には黒羽ときゅうこのどちらもいた)。ドラはきゅうこを見ているが、この編でも口にしない(本編 3-4-8 と同じ「何も見てない」)。

選択を足す: C3-1 / | APO0[end_G=1] | 選択 | | 【行動の選択】雪原に、灰色のコートの影。ももすけの指先が、まだ震えている—— / ①足あとを調べる(→C3-2 へ) / ②【二周目】ゆうべ、ももすけは、あの窓から何かを見ていた——(ももすけの目で)(→PO-1 へ。視点の編) |
