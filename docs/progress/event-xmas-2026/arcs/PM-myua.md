# 視点の編 みゅあの編「編みかけの夜」(本筋・r1126-115・ALLOCATION の 7)

真グッドを見たあと、第2章 C2-2(夜の台所)の最後に新しい選択が出る。夜中の台所でマフラーを編んでいた理由と、黒い毛糸を疑われた夜を、みゅあの目で。
本筋の場面は CANON の区間に合わせる(見出しの `時刻:`)。みゅあは犯人も動機も知らない(CANON「誰が何をいつ知ったか」)。鐘の時、みゅあは自分の部屋に戻っていた(本編 3-4-5)。
マフラーはみんなへの贈り物(真グッド G-11「あつくんのは、黒」)。恋の贈り物にはしない。
台所でドラにマフラーを見せる道は、本編(2-2-3「何でもない！」)と食い違うので「もしも」にした。
