# 視点の編 ドラの編「何も見てない」(本筋・r1126-115・ALLOCATION の 6)

真グッドを見たあと、第2章 A2(停電の暗闇)に③が出る。停電の夜、台所の奥の食料庫から出た所ですれ違った一瞬から、かばうと決めるまでを、ドラの目で。
本筋の場面は CANON の区間に合わせる(見出しの `時刻:`)。ドラが知っているのは「黒い服の人がきゅうこだった・泣いていた」まで(CANON「誰が何をいつ知ったか」)。動機の細部はドラの口から言わない。
あの夜にきゅうこへ声をかける道は、本編と食い違う(きゅうこはドラに見られたと知らない)ので「もしも」にした。

選択肢を足す: A2 / ③【二周目】そのころ、台所の奥の食料庫で——(ドラの目で)[end_G=1](→PD-1 へ。視点の編)
