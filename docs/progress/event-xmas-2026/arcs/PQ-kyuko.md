# 視点の編 きゅうこの編「十三分」(本筋・犯人の側・r1126-115・ALLOCATION の 11)

真グッドと、ほかの5つの視点の編(PD1・PM1・PK1・PE1・PO1)を全部見たあと、終章 A9(吹雪へ走るきゅうこ)に④が出る。印は付けない(わざと気づかせない)。
吹雪の中を走るきゅうこが、計画の夜を思い返す形。最初の夜(D1N)から、本当の0時の鐘(D8)まで。本筋の場面は CANON の区間に合わせる(見出しの `時刻:`)。
きゅうこは全部を知っている(CANON「誰が何をいつ知ったか」)。ただし思い返す場面の中では、その時に知らなかったこと(ドラに見られたこと・写真がワトソンくんに送ってあったこと・白瀬の手紙の中身)は書かない。ドラとすれ違った台所は「涙で何も見えなかった」とだけ書く。
真グッドで明かした事より先の新しい真相は足さない。本編の答え(犯人・動機・決め手・ドラがかばった理由)は変えない。2人が亡くなった重さは、最後まで軽くしない。

- ほかの編を裏から見せる所: 鍵のかかっていない扉と「もう、止まらないよ」(1-M)/ 窓辺で吹雪を見ていた(PM-1-3)/ 廊下の床のきしみと「誰だ！ 白瀬か？」(2-M-10・2-M-11)/ 扉の下の紙(2-M-19)/ 雪原の長靴の跡(3-2-1・3-2-4)/ 裏口の扉の真下の懐中時計(3-1-14)/ 扉が開く音・かんぬき・しゃくりあげる息(PD-1-7〜PD-1-13)/ 階段の上のゴトンと下のガタン(PM-4)/ 「何も見てない」(PD-2-6・PO-4-8)/ 鏡の前の夜通しの見張り(PK-5)/ はしごの上で息をのむ気配(PE-5-3)/ 吹雪の向こうの叫び声(PE-6-3・6-7-4b)/ 「……おで、は……」(PD-4-5)/ 屋根裏のかんぬき(8-2-3)/ 針を13分戻す(9-1-2)/ 子守歌(9-2)
- 新しく足した物は、本編の答えを変えない物だけ(きゅうこの気持ち・暗闇でつないだももすけの手(声は出さない)・階段の途中で聞こえた気がした音)
- もしもの道(かんぬきを下ろせない)は本編と食い違うので、見出しに「もしも」と書いた
