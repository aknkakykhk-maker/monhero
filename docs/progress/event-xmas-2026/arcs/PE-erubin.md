# 視点の編 えるびんの編「写真の影」(本筋・r1126-115・ALLOCATION の 9)

真グッドを見たあと、第6章 C6-4(うしろの人)の最後に新しい選択が出る。①は今までどおり C6-5 へ。②から、写真の影を確かめに1人で通り道へ入った昼を、えるびんの目で。はしごの上で押されるまで(と、その夜)。
本筋の場面は CANON の区間に合わせる(見出しの `時刻:`)。えるびんが知っているのは「写真の奥に黒いフードの影があった・白瀬が12年前に何かをしたと言いかけた」まで(CANON「誰が何をいつ知ったか」: 12年前のことは覚えていない)。押した人の顔は見ない(フードの影まで)。声の主も、えるびんには分からない。
カメラを自分から差し出す道は、本編と食い違う(本編ではカメラを取られ、押されて足をくじく)ので「もしも」にした。

- 本編の伏線を裏から見せる所: 「後ろにいるのが得意」(1-5-7・5-2-4・6-4-3)/ 白瀬の「取り返しのつかないこと」(3-5-4)/ ほこりのない鏡のふち(5-2-9)/ 行き止まりのはしごの上の板(6-1-4b → 屋根裏・8-1)/ 写真はソラシドにも送ってある(6-5-8b)/ 「押すつもりなんて、なかった」(8-3-22)
- 新しく足した物は、本編の答えを変えない物だけ(板の隙間の風・落ちる前に息をのむ気配・震える手)

選択を足す: C6-4 / | APE0[end_G=1] | 選択 | | 【行動の選択】えるびんの背中が、通り道の暗がりに消えた—— / ①今は、追いかける(→C6-5 へ) / ②【二周目】その少し前から、えるびんの目で——(→PE-1 へ。視点の編) |
