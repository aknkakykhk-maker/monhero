# 視点の編 ききの編「見張りのノート」(本筋・r1126-115・ALLOCATION の 8)

真グッドを見たあと、第5章 C5-1(言いかけた言葉)の最後に新しい選択が出る。白瀬に「12年前、わたしは扉を……」と言いかけられた昼から、白瀬が鏡の向こうで見つかる朝までを、ききの目で。見張りのノートの頁を順にめくる形。
本筋の場面は CANON の区間に合わせる(見出しの `時刻:`)。ききが知っているのは、自分で見た・聞いた・ノートに書いたことと、イチーカから聞いた「次の朝、白瀬が裏口の前で泣いていた」まで。白瀬の手紙の中身は読まない(見つかるのは C5-4)。
白瀬が消えた頃、ききはホールでノートを書いていた(本編 7-1-10 で、名探偵がこのノートで居場所を確かめる)。1人で鏡の廊下へ上がる道は、本編と食い違う(誰も鏡の向こうの音を聞いていない・5-4-11)ので「もしも」にした。

選択を足す: C5-1 / | APK0[end_G=1] | 選択 | | 【行動の選択】白瀬が口をつぐんだ書斎。ききの手もとで、当番表の下の見張りのノートが開いたままになっている—— / ①ノートを閉じる(→C5-2 へ) / ②【二周目】ききの見張りのノートを、停電の夜の頁から読む(→PK-1 へ。視点の編) |
