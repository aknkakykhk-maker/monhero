## 決めごととの突き合わせ

| 決めごと | どこで満たすか |
| --- | --- |
| r1119-172 追記1「レイド画面からボスのデッキ(コンピューター)と専用の1戦・与えたダメージを換算してレイドへ・ふだんの対戦の結果は足さない」 | 対戦は `raidChallenge` から始まる専用の1戦だけ(raid-board.png の「レイドバトル」)。ふだんの助手と対戦の終わりの処理は通らない(記録に数えない・ブラウザ検査⑤)。換算は raid-result.png の「レイドへ与えたダメージ」 |
| r1119-172 追記4「回数はバトルと同じ(どの入口でも共通)」 | 回数は使わず、始める直前に `onStart`(=バトル部の `raidXmasUseTry`)を呼ぶだけ。false なら始めない。カード側で別の回数は持たない |
| r1119-172 追記4「レイドバトル(協力)だけ・グランドスラムには入れない」 | 送るのは `kind:'a'` だけ(`CARD_RAID_XMAS.md`「つなぐ口」)。グランドスラムの入口は作らない |
| r1119-172 作り始め「仮のボス(仮の名前と絵)・開始時刻までは外に出さない」 | 名前は `CARD_RAID_BOSS.name`(仮)とレイド側から渡す `bossName`。入口はデバッグの試しだけ(ふつうのプレイヤーには出ない)。レイド画面のボタンはバトル部の `RELEASE_FLAGS.raidXmas` の中 |
| ⑦ 既存の保存・ランキングを壊さない | 新しいキーも足さない(カード側は何も保存しない)。`mh_card_*` 以外を書き換えない(ブラウザ検査⑤)。サーバーへはカードから直接送らない(バトル部の `raidXmasAddDamage` だけ) |
| 数字は案を表にして社長へ | `CARD_RAID_XMAS.md`「数字の案」(仮の値で作り進め) |

## レイド画面とつないだあと(App の startRaidXmasCard)

| 止め絵 | 何が写っているか |
| --- | --- |
| [`xmas-raid-ways.png`](xmas-raid-ways.png) | クリスマスのレイド画面(デバッグの強制表示)。段階の下に「バトルで」「バトルカードで」の挑み方 |

| 決めごと | どこで満たすか |
| --- | --- |
| r1119-172 追記4 回数はバトルと同じ | デッキを選んで始める直前に `raidXmasUseTry('a')`(バトル部の口)。残りが無ければ始めずレイド画面へ |

| 結果はレイドの結果画面 | カードの結果を閉じると `openRaidXmasResult`(バトル部の画面) |
