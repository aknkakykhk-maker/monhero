## 推理の筋(笑えて、筋は通す)

1. ドラはつまみ食いの名人(第2章 2-2-4 で夜中にもちまるのクッキー・みゅあが見ている)。帽子を振ると、クッキーのくずが落ちる(その場で見せる・もちまるが「ドラさんが通った後は、くずで分かる」)
2. ワトソンくんが撮った、かばんの黒い服(第6章 6-2-5 で写真に残した)と通り道の写真には、くずが **0個**
3. 黒いサンタはその服を着て、毎晩通り道を歩いていた。ドラが着ていたなら、ポケットも通り道もくずだらけのはず → **その服を着ていたのは、ドラではない**
4. 「本当の黒いサンタは——」で電池切れ。ソラシドがとっさにいびきの声まねでごまかし、正体は分からないまま終わる

- 真グッドの決め手(毛くずが全部約2センチ・12月20日の写真)・犯人・動機・ドラがかばった理由は出さない(r1126-022 追記6)。真相(犯人はきゅうこで、服を着ていたのもドラではない)とも食い違わない
- 本編の時系列: 第7章の時点で、黒羽・白瀬は亡くなり、えるびんはけが、きゅうこは崖で消えた後。ルートに出るのは、その時ホールにいられる人だけ(あつ・ソラシド・みゅあ・きき・ももすけ・ドラ・えるびん・イチーカ・もちまる・ワトソンくん)
