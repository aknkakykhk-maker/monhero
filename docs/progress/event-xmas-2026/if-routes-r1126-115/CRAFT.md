# 事件簿の書き方の作法(サウンドノベル型のホラーミステリー・r1126-115 追記4)

社長「この手のホラーミステリーノベルをちゃんと学習した上で、ストーリーとの辻褄もおかしくならないように。ネタルートやネタエンドはあるとしても」。
もしもの話・助手の視点の編を書く会話は、**書く前にこれと [`CANON.md`](CANON.md) を読む**。よその作品の文・話・名前は写さない(ここに書いたのは、このジャンルでよく使われる作り方を自分の言葉にした物)。

## 1. 推理の公平さ

- **答えに要る手がかりは、答えを問う前に、読者にも見せる。** 主役だけが見て読者に伏せた物で解かない。手がかり帳に入る物は、本文でも必ず一度は書く
- 手がかりは「見た物」と「意味」を分けて出す。見た物は早めにそのまま書き、意味(何を示すか)は推理の場面で初めて言う
- 名探偵が言う理屈は、読者が手がかり帳だけで同じ所まで行けるようにする。最後の一手(決め手)だけ少し跳んでよい
- 偶然・新しい人物・その場で出た秘密の通路で解かない(通り道は第6章で先に見つかっている。新しい編で新しい隠し部屋を出すときは、「もしも」の話だけ)

## 2. 伏線と回収

- 伏線は「その時は別の意味に読める」形で置く。例: きゅうこの鼻歌(第4章)=ただの癖に見えて、母の子守歌
- 1つの伏線は、2回以上ふれてから回収する(1回だけだと、読み返しても気づけない)
- 視点の編は、本編の伏線を**裏側から見せる**のが役目。新しい伏線を足すときは、本編の答えを変えない物に限る

## 3. ミスリード(疑いの向け方)

- 疑われる人には、**本当の理由のある、ほかの秘密**を持たせる(ドラ=かばっている・みゅあ=マフラーを編んでいた・イチーカ=部屋を守ってきた)。理由のない怪しさは置かない
- ミスリードの手がかりにも、本当の説明を必ず用意して、あとで回収する(黒い毛糸=マフラー)
- 読者をだますのは「並べ方」と「言い方」だけ。地の文(帯)でうそを書かない。うそを言うのは人物の台詞だけ

## 4. 視点の制限

- **その人物が知らないことは、その人物の視点では書かない。** 何をいつ知ったかは CANON の「誰が何をいつ知ったか」に従う
- 視点の編の帯は、その人物が見た・聞いた・思ったことだけ。ほかの部屋で起きたことは「物音」「あとで聞いた話」として書く
- 犯人の視点(きゅうこの編)でも、真グッドで明かした事より先(本編に無い新しい真相)は書かない

## 5. 怖さの溜めと外し

- 怖い一瞬の前に、静かな行を2〜3行置く(時計の音・灯りが揺れる・誰かが黙る)。溜めずに出すと驚きだけで怖くならない
- 本当の怖さは「見せない」所に置く。音・影・残された物・止まった時計。遺体は文章ではっきり、絵は演出だけ(今の決まり)
- 外し(何も起きない)を時々入れる。毎回なにか起きると読者が慣れる。外したあとの1回が一番効く
- 明るい場面のあとに急に落とす(夕ごはん → 最初の夜)。落差で怖くする

## 6. ネタルート・ネタエンドの置き方

- **入口**: 本筋の緊張が切れない所に置く。山場の直前・人が亡くなった直後には置かない。行動の選択の「ありえないほう」の選択肢として出し、選ばなければ本筋は何も変わらない
- **中身**: 「もしも」と分かる始まり方にする(帯の1行目で、起きなかった夜だと分かる)。本編の答え(犯人・動機・決め手・ドラがかばった理由)はネタの中でも書き換えない
- **出口**: ネタのあとは、外側(OUT-*)の場面で助手たち本人が笑って閉じる。本筋へは戻さない(戻すと本筋の緊張が壊れる)
- 真グッドの前に開くネタは、答えに触れない(眠りのドラ・助手の名推理と同じ)

## 7. 恋の駆け引き(全年齢・r1126-115)

- 線は「意味深な台詞・嫉妬・秘密の関係・目くばせ・手を取る」まで。体に触れる描写の先・寝室の場面は書かない
- 助手どうし・助手とプレイヤーの恋は書かない(決まり「恋愛なし」)。恋をするのは大人のゲームの中の人(白瀬・黒羽・イチーカと、絵の無い新しい大人の客)
- 大人の会話は「言わないこと」で色っぽくする。言いかけてやめる・返事の代わりにグラスを置く・名前だけ呼ぶ
