# 事件簿の「特別なしおり」と別ジャンルのもしもの話 案(r1126-115・2026-11-28 バトル部)

社長「いろんなルートがあるから、ちょっと大人な感じとか、いろんなルートに展開するような感じにしたい」への**案**。まだ文は書かない・ゲームに入れない(社長が下の「聞きたい事」を選んでから作る)。

社長の方針(窓口から):
- エンドを集めると**特別なしおり**が手に入り、本編と全然違う**もしもの話(別ジャンルのルート)**が開く
- 「大人」の線は**恋の駆け引き・色っぽい雰囲気まで**(意味深な台詞・嫉妬・秘密の関係)。直接的な性の描写はしない。全年齢で大丈夫な範囲
- よその作品の話・設定・しおりの色の意味は写さない。考え方だけ使う

## 先に決めておきたい2つ(ぶつかる決まり)

2. **「別の真相は作らない・もしもは真グッドのあとだけ」**(第3弾までの決まり・`branches-r1126-108/README.md` の1)。別ジャンルの話は事件の答えに触れる場面が多いので、**どのしおりも真グッド(END-G)を見たあとに開く**ことを推す。真グッドを見た人だけが読むので、本編の答えを前提にしてよい

## 本編の真相とぶつからないか・ネタバレの扱い

- どのしおりも真グッドのあとなので、読む人は答え(犯人・動機・決め手・ドラがかばった理由)を知っている。**本編の答えは変えない**(「別の真相」にはしない)。もしもの夜の中で、事件が起きない・起きる前に終わる・違う形の怖さ、のどれかにする
- ①: 黒羽と白瀬が生きている夜。12年前の出来事は「二人とも言えないことがある」までで、新しい事実は足さない(カノンの話は本編のまま)
- ②: 人の手でない怪異。本編の「殺される理由の決まり」とは別の世界の話として、冒頭の1行で「これは、起きなかった夜」と分ける
- ③: 通り道は「カノンと息子の二人だけのないしょ」(F の決まり)。宝さがしはそれに合う形(カノンが息子のために残した遊び)
- ④: きゅうこは犯人のまま。くり返しの中で止めようとする話にして、本編の動機を書き換えない
- 更新履歴・ヘルプには、ルートの中身・しおりの条件を書かない(「エンドを集めると、何かが起きるかもしれません」程度まで)

## 起動画面での見せ方(r1126-112 追記5「静かな言葉+物で見せる」に合わせる)

- 起動画面は1冊の本。手に入れたしおりは、**本の上から垂れる細いリボン**として1本ずつ増える。持っていないしおりは何も出さない(「？？？」も数も出さない)
- 手に入れた瞬間は、エンドの札のあとに静かな1行だけ: 「頁のあいだに、紅いリボンが挟まっていた」
- リボンを押すと、その話の扉(題と1行)。「この夜を読む」で、分かれる所の直前から始まる
- 条件は書かない。ヒントは「綴じた結末」の棚の隅に、まだ綴じられていない背表紙が薄く見えるだけ
- 起動画面にはもう「しおりから」(章から読み直す)がある。**名前がかぶる**ので、画面の言葉では特別なしおりを「リボン」と呼ぶのを推す(聞きたい事3)
- 見た目は開発部のホラー案(#8082)と起動画面の言葉の直し(r1126-112 追記5)の上に乗せる。組み込むときは開発部と順番を合わせる

## 土台(このPRで入れた物)

- **しおり**: `79-xmas-novel-engine.jsx` の `XMAS_NOVEL_BOOKMARKS`(紅・灰・緑・銀・白紙)。持っているかは見たエンドから毎回数える(保存のキー・形は増やさない)。選択肢の条件は `[bm_red=1]`
- **真グッドのあとだけの選択肢**: 今ある `[end_G=1]` をそのまま使う
- **画面**: 起動画面の「一発で当てた数」の下に、持っているしおりだけ細いリボンで並ぶ(数・条件は出さない)。エンドの札で新しく手に入った時だけ「頁のあいだに、紅いリボンが挟まっていた」
- **編の台本の置き場**: `docs/progress/event-xmas-2026/arcs/<頭文字>-<名前>.md`(1編1ファイル。並行で書いてもぶつからない)。組み立て道具が本編の台本のうしろ(「# 旧案」の手前)へつなぐ
- **本編への入口**: 編のファイルに `選択肢を足す: A1b / ③…[bm_red=1](→RW-1 へ。もしも)` と1行書くと、本編のその選択の行の末尾へ選択肢が足される(SCRIPT.md を触らない・行の数が変わらないので続きの場所はずれない)
- **節の見出し**: `## もしも ～題～` か `## 視点の編 ～題～`(エンディングの章として読まれる)。最初の場面と分かれ先の場面には `条件: A1b で③` のような文の条件を付ける(本編から流れこまない)
- **エンドの種類**: もしも(`ifroute`)・視点の編(`pov`)。id の頭文字ごとに `xmas-novel-build.js` の `ENDING_KIND` に入れてある(下の表の頭文字だけ使う)
- **名前だけの話し手**(絵なし)は `xmas-novel-build.js` の `PAST_SPEAKERS` に足す(灰谷を足した)
- **ランキング**: エンドを足したら `xmas_novel_end_ids` に id と種類を1行ずつ(窓口が流す)
- 見取り図: 入口の選択肢の先のエンドは、本編の分かれ道の札として出る。編の中の分かれ道の段は、まだ出していない(編が増えたら段を足す)
