# クリスマスイベント「聖夜の名探偵」ポスター(キービジュアル)プロンプト集(チャッピー用)

台帳 r1119-172(追記8・r1125-043)。社長「イベントの構成が出来たらイベントポスター作りたい。キービジュアルみたいの? 告知用と本番用と」(2026-11-25)。
2026-11-25 社長「チャッピーにイベント告知用のキービジュアルというかポスターみたいの作らせるプロンプトちょうだい」で、決まったお話の筋に合わせて書き直した(前の下書きの「王さまサンタ・エンジニアのサンタ・クリスマスの街」は使わない)。

## 決まったこと

| 項目 | 決定 |
| --- | --- |
| イベント名 | **聖夜の名探偵**(副題 〜十三番目の鐘が鳴る夜〜) |
| お話の筋 | 雪山のペンションに招かれた助手たち。もみの木の下のプレゼントと助手が1人ずつ消えていく。探偵役のあつとソラシドがライバルとして謎に挑む(`STORY.md`・`SCRIPT.md`) |
| 中心の助手 | **あつとソラシド**(どちらも探偵の衣装) |
| オーナー | **イチーカ**(スネグーラチカ・ペンションのオーナー)。絵はモンスターのスネグーラチカ |
| モンスター | モッチー・ハム(サンタ帽)。スネグーラチカはイチーカとして出す |
| ボス | 覚醒サンタ(赤いサンタが黒く変わった姿・目つきを直した絵)。**告知用は黒い影だけ**、本番用で姿を出す。名前は未定 |
| 枚数 | 告知用と本番用。どちらも**正方形**(お知らせ・起動時の告知)と**横長 2:1**(イベントタブ)= 4枚 |
| 期間 | 2026/11/30(月)10:00 〜 12/31(木)3:59 |
| 目玉 | レイド(バトル・モンヒロビート・MFバトルカードで挑める)/助手のクリスマスきせかえ/ひとりで進める物語「聖夜の名探偵」/期間中のボーナス(モンヒロビート5倍・MFバトルカード1.5倍) |

## まだ決まっていない所

- ボスの名前・新曲の曲名(決まるまでポスターに書かない)
- 本番用はボスの名前が決まってから

## 使い方

1. チャッピーの新しい会話に、下の「告知用」の文をそのまま送る(正方形→横長の順に作る)
2. できた絵は**加工せずに** `tools/art-sources/promo/xmas-2026/received/` へ置く(880px の正方形と 1000×500 の横長に切りそろえるのはこちらでやる)

## 告知用(正方形と横長)

```
スマホのカードバトルゲーム「モンスターヒーロー」の、クリスマスイベント「聖夜の名探偵」の告知用ポスター(キービジュアル)を2枚作ってください。1枚できるごとに見せてください。私が「次へ」と言ったら次へ。

■参考の絵(よく見て、同じ人物・同じ姿で描く)
- あつ(探偵の衣装): https://github.com/aknkakykhk-maker/monhero/blob/main/tools/art-sources/assistants/atsu/santa/received/atsu_santa_fullbody_v2.png
- ソラシド(探偵の衣装): https://github.com/aknkakykhk-maker/monhero/blob/main/monster-hero/images/assistant/fullbody/sorashido_santa.png
- イチーカ(ペンションのオーナー・スネグーラチカ): https://github.com/aknkakykhk-maker/monhero/blob/main/monster-hero/images/monsters/snegurochka.png
- モッチー: https://github.com/aknkakykhk-maker/monhero/blob/main/monster-hero/images/monsters/mocchi.png
- ハム: https://github.com/aknkakykhk-maker/monhero/blob/main/monster-hero/images/monsters/ham.png
- 黒い影の形の見本(このボスの輪郭だけを使う。顔や服は描かない): https://github.com/aknkakykhk-maker/monhero/blob/main/tools/art-sources/raid-xmas-2026/received/santa_black_kakusei_glare.png
- ポスターの手本(文字の太さ・縁取り・枠の飾り・情報の並べ方): https://github.com/aknkakykhk-maker/monhero/blob/main/monster-hero/images/events/halloween-night-2026.jpg と https://github.com/aknkakykhk-maker/monhero/blob/main/monster-hero/images/events/pandora-wings-2026.jpg 、横長は https://github.com/aknkakykhk-maker/monhero/blob/main/monster-hero/images/events/flower3-2026-wide.jpg

■お話(絵の雰囲気のもと)
雪山のペンションに招かれた助手たち。もみの木の下に置いたプレゼントが、夜ごとに消えていく……。探偵の格好をしたあつとソラシドが、ライバルどうしで謎に挑むクリスマスの推理もの。怖すぎず、わくわくするミステリーの雰囲気にする(血・けが・武器は描かない)。

■絵の中身
- 中心: あつとソラシドを大きく、2人並べて。ライバルらしく背中合わせ、またはそれぞれ別の方を指さす決めポーズ
  - あつ: 赤髪(7:3でかき上げ)・青い目・金の小さな王冠・黒のジャケット・赤いシャツ・グレーのチェックのマフラー・柊のピン・銀縁の虫めがね。自信のある不敵な笑み
  - ソラシド: 参考の絵のとおり(紺のブレザー・赤い蝶ネクタイ・丸い眼鏡・ノートパソコン・サンタ帽の猫のキーホルダー)。落ち着いた知的な笑み
  - 2人とも参考の絵と同じ顔・髪型・髪色・目の色・服。変えない
- 2人の少し後ろに、イチーカ(スネグーラチカ)が参考の絵の姿でやさしく微笑む。モッチーとハムはサンタ帽をかぶって足もとに小さめに(1匹は虫めがねをのぞいている、など楽しい仕草)
- 背景: 雪の降る夜の雪山。明かりのともった木造のペンション、窓の向こうに大きなもみの木とプレゼントの山。手前の雪にはなぞの足あと
- 夜空の奥に、大きな黒い影(見本の絵の輪郭: うさぎのような長い耳・サンタ帽・袋)。全身まっ黒のシルエットで、赤く光る目だけが見える。顔・服の模様・色は描かない(正体は告知では見せない)
- 色: 夜空の紺と雪の白を土台に、赤・緑・金の光(イルミネーション・ペンションの灯り)。明るく華やかなゲームのイベント告知の絵

■入れる文字(日本語・この文だけを正確に。ほかの文字・英語の飾り文字・ロゴは入れない)
- 小さな帯: 「クリスマスイベント 開催予告」
- 大きなタイトル: 「聖夜の名探偵」
- サブタイトル: 「〜十三番目の鐘が鳴る夜〜」
- 期間の枠: 「開催期間 2026/11/30(月)10:00 〜 12/31(木)3:59」
- 目玉の札を4つ(小さめの文字で):
  1. 「レイド開催! バトル・モンヒロビート・MFバトルカードで挑める」
  2. 「助手のクリスマスきせかえ登場」
  3. 「ひとりで進める物語」
  4. 「期間中ボーナス モンヒロビート5倍・MFバトルカード1.5倍」

■1枚目: 正方形(1:1)
- 上: 帯 → タイトル → サブタイトル
- 真ん中: あつとソラシド、後ろにイチーカ、足もとにモッチー・ハム。奥の夜空に黒い影
- 下: 期間の枠。いちばん下に目玉の札4つ(2つずつ2段でもよい)

■2枚目: 横長(2:1。作れなければ3:2にして、上下を切っても文字が欠けない余白をとる)
- 左上: 帯・タイトル・サブタイトル。左下: 期間の枠
- 真ん中から右: あつとソラシド、後ろにイチーカ、足もとにモッチー・ハム。右奥の夜空に黒い影
- 右下: 目玉の札4つ(横長の手本のように小さな札で並べる)

■絶対に守ること(1つでも外れたら作り直す)
- あつ・ソラシド・イチーカ・モッチー・ハムは参考の絵と同じ姿(顔・髪・目の色・服・体の色)
- 黒い影は輪郭と赤い目だけ。顔や服を描かない
- 文字は上の文だけ・誤字なし。文字が人物の顔にかからない
- 手と指の数・形を正しく
- 見せる前に「2人の顔と服が参考の絵と同じか」「文字が上の文のとおりか」「影が黒いシルエットだけか」を自分で確かめて一言そえる

- 終わったら、コミットのリンクと追加したファイルの一覧を見せる
```

## 本番用(正方形と横長)

ボスの名前が決まってから。告知用の文をもとに、次を替えて使う。

- 帯を「クリスマスイベント 開催中」に
- 黒い影を、ボスの姿(参考の絵 `tools/art-sources/raid-xmas-2026/received/santa_black_kakusei_glare.png` のとおり・赤く光る目・プレゼントの袋)に替え、2人はボスに立ち向かう構えに
- ボスの名前を入れる場所を足す
- ファイル名は `xmas-2026-square.png`・`xmas-2026-wide.png`
