# クリスマスイベント ポスター(キービジュアル)プロンプト集(チャッピー用)

台帳 r1119-172(追記8)。社長「イベントの構成が出来たらイベントポスター作りたい。キービジュアルみたいの? 告知用と本番用と」(2026-11-25)。

> **作るのは、お話(ストーリー)の筋が決まってから**(社長 2026-11-25「ポスター絵とかはストーリー決まってからのほうがいいんじゃないの?」)。
> 筋が決まったら、ポスターの場面・2人のポーズ・サブタイトルを筋に合わせて書き直してから使う。下の文は、いま決まっている所までの下書き。

## 決まったこと(社長 2026-11-25)

| 項目 | 決定 |
| --- | --- |
| 枚数 | **告知用**と**本番用**。どちらも**正方形**(お知らせ・起動時の告知)と**横長 2:1**(イベントタブ)の2つの形 = 4枚 |
| 告知と本番の分け方 | **告知も情報を多めに**(期間と目玉も載せる)。違いは、告知=ボスは**黒い影**・「11/30 開幕」/本番=ボスの**姿を出す**・「開催中」 |
| 中心の助手 | **ソラシドとあつ**(サンタきせかえの姿)。お話の筋もこの2人に合わせる |
| モンスター | **モッチー・スネグーラチカ・ハム** |
| ボス | 告知は影だけ(贈り物を奪う黒いサンタ)。本番はボスの絵が決まってから |
| 目玉の枠(4つ) | レイド開催(3つの遊びで挑める)/助手のサンタきせかえ/イベントBGMの新曲/ひとりで進める物語 |
| 手本にした最近の絵 | `halloween-night-2026.jpg`(タイトル・期間・目玉の枠)・`pandora-wings-2026.jpg`(2人を大きく・期間の枠)・`flower3-2026-wide.jpg`(横長の並べ方)・`kyubi-orihime-notice.jpg`(予告の見せ方) |

## まだ決まっていない所(決まったら下の文の【】を埋める)

- 【イベント名】・【ボスの名前】(社長が追って決める)
- 【新曲の曲名】
- ソラシドとあつのサンタ姿の絵(`SANTA-COSTUME-PROMPTS.md` で作る)。**できてから**ポスターを作ると顔と服がそろう
- 本番用はボスの絵ができてから

## 使い方

1. 先にソラシドとあつのサンタきせかえの絵を作る(できていれば、その絵も添付する)
2. チャッピーの新しい会話で、下の「チャッピーへ送る文」を送る(告知用・本番用は別の会話)
3. できた絵は**加工せずに** `tools/art-sources/promo/xmas-2026/received/` へ置く(880px の正方形と 1000×500 の横長に切りそろえるのはこちらでやる)
   - ファイル名: `xmas-2026-notice-square.png`(告知・正方形)/`xmas-2026-notice-wide.png`(告知・横長)/`xmas-2026-square.png`(本番・正方形)/`xmas-2026-wide.png`(本番・横長)。作り直しは `_v2` を付ける

### チャッピーへ送る文

```
次のページに、ゲームのクリスマスイベントのポスターを作るための指示がまとめてあります。
https://github.com/aknkakykhk-maker/monhero/blob/main/docs/progress/event-xmas-2026/POSTER-PROMPTS.md

このページの「共通の前置き」と「告知用(正方形)」の指示を読み、指示の中にある「参考の絵」のリンクの絵をよく見てから、ポスターを作ってください。
```

「告知用(正方形)」の所を「告知用(横長)」「本番用(正方形)」「本番用(横長)」に替えて使う。

## 共通の前置き(どの1枚でも先に読む)

```
スマホのカードバトルゲーム「モンスターヒーロー」の、クリスマスのレイドイベントのポスター(キービジュアル)を作ってください。

絵の決まり:
- 手本のポスター(ハロウィン・パンドラ・花の3人)と同じ、明るく華やかなアニメ調のゲームのイベント告知の絵にする。文字の太さ・縁取り・枠の飾りの雰囲気も手本に合わせる
- 中心はソラシドとあつの2人。参考の絵と同じ人物にする(顔立ち・髪型・髪色・目の色は変えない)。服は「2人のサンタ衣装の中身」のページの「あつ」「ソラシド」の衣装
  - あつ: 王さまサンタ。深紅の長いコートに白いファー、裏地は黒。銀の王冠と銀の鎖。金色は使わない
  - ソラシド: エンジニアのサンタ。白いファーの赤いパーカーにサンタ帽、ノートパソコン、首に青緑のヘッドホン、腰のキーホルダー2匹にもサンタ帽
- モンスター3体(モッチー・スネグーラチカ・ハム)を参考の絵のとおりの姿で、2人のまわりに小さめに。モッチーとハムにはサンタ帽をかぶせる。スネグーラチカは参考の絵のサンタ姿のまま
- 背景: 雪の降る夜のクリスマスの街。大きなもみの木、イルミネーション、プレゼントの箱
- 色: 赤・白・緑・夜空の紺を中心に、雪の白と光の金
- 文字は日本語で、下の指示の文だけを正確に入れる。指示にない文字・ロゴ・英語の飾り文字は入れない
- 人物の手と指の数・形を正しく
```

## 告知用(正方形)

```
形: 正方形(1:1)。
雰囲気: これから始まるわくわく感。ボスはまだ正体を見せない。

並べ方:
- 上: 小さな帯「レイドイベント 開催予告」。その下に大きなタイトル「【イベント名】」と、小さなサブタイトル「〜【ボスの名前】から贈り物を取り戻せ!〜」
- 真ん中: ソラシドとあつが並んで、こちらへ手を伸ばす・指さすなど元気なポーズ。足もとにモッチー・スネグーラチカ・ハム
- 2人の後ろの夜空に、大きな「黒いサンタ」の影。黒いシルエットで、赤く光る目だけ見える。贈り物の袋をかついでいる。顔や服の細かい所は描かない
- 下: 期間の枠「開催期間 2026/11/30(月)10:00 〜 12/31(木)3:59」
- いちばん下: 目玉の枠を4つ横に並べる(小さめの文字で)
  1. 「レイド開催! バトル・モンヒロビート・MFバトルカードで挑める」
  2. 「助手のサンタきせかえ登場」
  3. 「イベントBGM 新曲【新曲の曲名】」
  4. 「ひとりで進める物語」
```

## 告知用(横長)

```
形: 横長(2:1。作れなければ3:2にして、上下を切っても文字が欠けない余白をとる)。
中身は「告知用(正方形)」と同じ。並べ方だけ横長に合わせる:
- 左上: 帯「レイドイベント 開催予告」とタイトル「【イベント名】」、サブタイトル「〜【ボスの名前】から贈り物を取り戻せ!〜」
- 真ん中から右: ソラシドとあつ。足もとにモッチー・スネグーラチカ・ハム。右奥の夜空に黒いサンタの影(赤く光る目)
- 左下: 期間の枠「開催期間 2026/11/30(月)10:00 〜 12/31(木)3:59」
- 右下: 目玉の枠を4つ(花の3人の横長の手本のように、小さな札で並べる)
  1. 「レイド開催! バトル・モンヒロビート・MFバトルカードで挑める」
  2. 「助手のサンタきせかえ登場」
  3. 「イベントBGM 新曲【新曲の曲名】」
  4. 「ひとりで進める物語」
```

## 本番用(正方形)

ボスの絵ができてから。ボスの参考の絵のリンクを、この節に足してから使う。

```
形: 正方形(1:1)。
雰囲気: いよいよ決戦。告知用と同じ並べ方で、ボスが姿を現した絵にする。

並べ方:
- 上: 小さな帯「レイドイベント 開催中」。大きなタイトル「【イベント名】」とサブタイトル「〜【ボスの名前】から贈り物を取り戻せ!〜」
- 真ん中: ソラシドとあつがボスに立ち向かう構え(背中合わせ・身構えるなど)。足もとにモッチー・スネグーラチカ・ハム
- 後ろ: ボス「【ボスの名前】」(参考の絵のとおり)が、奪った贈り物の袋をかついで夜空に大きく。告知用の影と同じ位置・同じ大きさ
- 下: 期間の枠「開催期間 2026/11/30(月)10:00 〜 12/31(木)3:59」
- いちばん下: 目玉の枠を4つ
  1. 「レイド開催! バトル・モンヒロビート・MFバトルカードで挑める」
  2. 「助手のサンタきせかえ登場」
  3. 「イベントBGM 新曲【新曲の曲名】」
  4. 「ひとりで進める物語」
```

## 本番用(横長)

```
形: 横長(2:1。作れなければ3:2にして、上下を切っても文字が欠けない余白をとる)。
中身は「本番用(正方形)」と同じ。並べ方は「告知用(横長)」と同じで、右奥の影をボスの姿に替える。
```
