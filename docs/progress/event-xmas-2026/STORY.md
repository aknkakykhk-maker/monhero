## 骨組みの案(ここから選んでもらう)

### 筋

1. **招待**: ペンションのオーナーのスネグーラチカが「クリスマス会をしませんか」と、助手たちとプレイヤーを雪山の**ペンション・シュプール**へ招く。みんな、それぞれプレゼントを1つ用意して持ってくる
2. **閉じ込め**: その夜から吹雪。道がふさがり、ペンションから出られなくなる
3. **消える**: 夜ごとに、助手が1人ずつ、自分のプレゼントといっしょに消える。残るのは、赤い帽子のぽんぽんと雪の足あと
4. **黒いサンタ**: 消える夜に、窓の外や廊下の奥に黒いサンタの影が見える(=レイドのボス)
5. **推理**: あつ(勘と人を見る目)とソラシド(計算・記録・まとめ)が、ライバルとして張り合いながら手がかりを集めていく
6. **あつの推理(外れ)**: あつが「謎はすべて解けた!」と言い切って犯人を名指しするが、実は違う。名指しするのは**ドラ**(社長 11/25)。**ドラは消えずにペンションに残り、犯人に仕立てられる**(社長 11/25)。残った者の中で、手がかりがすべてドラを指すように見え、あつはドラを犯人と見立てるが、外れる。**あつの推理は、かなり論理的にトリックを解いて見せる演出にする**(社長 11/25)。手がかりを1つずつ並べて筋道を立て、読む人も「これで決まりだ」と思える出来にする。外れるのは、**犯人(きゅうこ)の罠**のため。きゅうこはドラが犯人に見えるように手がかりを仕込んでおり、あつはその手がかりを論理的に正しくつないだからこそ罠にはまる(社長 11/25)。**ソラシドは、手がかりが「きれいにそろいすぎている」ことに計算・記録から気づき、罠だと見抜いて**本当の答えに至る。あつの推理の筋道そのものはあなどらない
7. **きゅうこが消える**: 途中で、きゅうこ自身も消えたように見せる(推理ものの定番。疑いの外へ出る)
8. **解決**: ソラシドが最後の手がかりを計算でつなぎ、「真実はいつもひとつ!」と言って、黒いサンタの正体がきゅうこだと解く。消えた助手たちは、ペンションのどこかで無事に見つかる
9. **結末**: 動機(下で選ぶ)が明かされ、みんなでクリスマス会をやり直す

### 2つのお話への割り振り

| お話 | 中身 |
| --- | --- |
| **ひとりで進める物語**(毎日1話開く・25話前後・イベントページから選んで読む) | 1話=1日の夜。招待 → 閉じ込め → 1人ずつ消える → 推理。戦う話は「黒いサンタの影を追う」「手がかりを守る」などで、バトル/モンヒロビート/MFバトルカードの好きな遊びで勝てば進む(やさしめ) |
| **みんなで進む話**(レイドの段階を倒すたび・5話+終章2種) | 黒いサンタとの対決。段階を倒すたびに、黒いサンタの仮面・衣装が少しずつはがれ、正体の手がかり(音符の飾り・ローズ色の髪など)が1つずつ見える。終章は「大王まで倒せたか」で2つ |

- 2つのお話の時間の合わせ方: ひとりで進める物語が「謎」、みんなで進む話が「追い詰める」。どちらを先に読んでも分かるように、犯人の名前は**最後の話まで出さない**
