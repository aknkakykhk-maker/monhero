## 骨組みの案(ここから選んでもらう)

### 筋

1. **招待**: スネグーラチカが「クリスマス会をしませんか」と、助手たちとプレイヤーを雪山のペンション(名前は仮)へ招く。みんな、それぞれプレゼントを1つ用意して持ってくる
2. **閉じ込め**: その夜から吹雪。道がふさがり、ペンションから出られなくなる
3. **消える**: 夜ごとに、助手が1人ずつ、自分のプレゼントといっしょに消える。残るのは、赤い帽子のぽんぽんと雪の足あと
4. **黒いサンタ**: 消える夜に、窓の外や廊下の奥に黒いサンタの影が見える(=レイドのボス)
5. **推理**: あつ(勘と人を見る目)とソラシド(計算・記録・まとめ)が、残った手がかりを集めていく
6. **きゅうこが消える**: 途中で、きゅうこ自身も消えたように見せる(推理ものの定番。疑いの外へ出る)
7. **解決**: 最後の手がかりで、黒いサンタの正体がきゅうこだと分かる。消えた助手たちは、ペンションのどこかで無事に見つかる
8. **結末**: 動機(下で選ぶ)が明かされ、みんなでクリスマス会をやり直す

### 2つのお話への割り振り

| お話 | 中身 |
| --- | --- |
| **ひとりで進める物語**(日付で開く・約10〜14話) | 1話=1日の夜。招待 → 閉じ込め → 1人ずつ消える → 推理。戦う話は「黒いサンタの影を追う」「手がかりを守る」などで、バトル/モンヒロビート/MFバトルカードの好きな遊びで勝てば進む(やさしめ) |
| **みんなで進む話**(レイドの段階を倒すたび・5話+終章2種) | 黒いサンタとの対決。段階を倒すたびに、黒いサンタの仮面・衣装が少しずつはがれ、正体の手がかり(音符の飾り・ローズ色の髪など)が1つずつ見える。終章は「大王まで倒せたか」で2つ |

- 2つのお話の時間の合わせ方: ひとりで進める物語が「謎」、みんなで進む話が「追い詰める」。どちらを先に読んでも分かるように、犯人の名前は**最後の話まで出さない**
