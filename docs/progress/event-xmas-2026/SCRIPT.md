## 書き方の約束

- 台本は「番号・話し手・表情・台詞」の並び。表情は助手の8種(`normal` ふつう / `happy` 笑顔 / `wink` ウインク / `surprise` 驚き / `troubled` 困り顔 / `angry` むくれ顔 / `crying` 泣き顔 / `excited` わくわく)
- 衣装は全員**クリスマスのきせかえ**(サンタ服。あつとソラシドは探偵の衣装)。台本の行の衣装は `santa`(台帳 r1119-172 追記)
- **イチーカ**(スネグーラチカ・ペンションのオーナー)は表情の絵が1枚なので、表情の欄は「—」
- 「帯」の行は、話し手のいない地の文(画面の帯 `fxText` や効果音)。「並び」の行は毎話の終わりの**のこった人の並び**(下の §3)
- ゲームに入れるときの形は、バトル部の別の会話が `BUILD.md` に書く。出たら列の名前を合わせる(この稿を書いた時点ではまだ無い)
- 口調: みゅあ=「あたし」・「〜ぢゃん」「まぢ」/ きき=「私」・敬語で「でつ」「まつ」/ ももすけ=「もも」・「♡」「w」/ ドラ=「おで」・「〜だ」「〜だな」/ あつ=「俺」・短く、文の終わりに「笑」か記号 / きゅうこ=「俺」・ゆるいタメ口、「ほい！」「〜だよぉ」/ ソラシド=「自分」・丁寧語に「笑」、記録と計算 / えるびん=「俺」・おだやか、「〜かな」「〜だね」/ イチーカ=ちょっと元気、おしとやかで優しいお姉さん(「〜ですよ」「ふふっ」「〜しましょうね」)
- 怖がらせ方は、停電・足音・影・閉じ込め・時計の音まで。血・死・けがは出さない
- 手本にした作品の名前・人物・場面・見せ方は使わない。例外は決め台詞「謎はすべて解けた!」(あつ)・「真実はいつもひとつ!」(ソラシド)の2つだけで、この言葉のまま使う

## 3. 毎話の終わりの「のこった人の並び」

手本の作品の見せ方はまねせず、自分たちの形でやる。

- 画面の下に、8人の助手の顔アイコン(クリスマスの衣装)と、その前にそれぞれのプレゼントの箱を並べる
- のこった人は明るく、いなくなった人は**顔が暗くなり、箱のふたが開いて空になる**。その回に消えた人だけ、明るい顔から暗くなる動きを見せる
- 右はしにイチーカの顔(オーナーはいつも並びに入る)
- 帯に「のこった人 ◯人 / 空になった箱 ◯つ」
- きゅうこが消えた(ふりの)回も、ほかの人と同じように暗くする(読む人にも、ふりだと分からないように)

## 4. 裏の真相メモ(社長の確認用・お話の本文には出さない)

全話がこの真相に合うように手がかりを置く。

- **きゅうこのはじめの計画**: 24日の夜に、黒いサンタに変装してプレゼントを「盗み」、手がかりを追う宝さがしの末に、屋根裏に飾りつけた秘密の会場でみんなで開ける——という小さなサプライズ。大きいケース(第1話)の中身は楽器ではなく黒いサンタの服と飾り。夜中の2階の足音は、屋根裏を飾りに通うきゅうこ
- **大ごとになったきっかけ(第7話)**: 停電は吹雪による本物。ブレーカーは外の物置小屋にあり、イチーカは裏口から外へ出た(森へ向かう足あとはイチーカの物。イチーカは「外へ出た」と言わなかった→アリバイのすき)。窓は古い留め金が風で開いた(第1話で仕込む)。ぽんぽんは窓ぎわに置いたきゅうこのケースから落ちた物。森の影は、きゅうこが宝さがしの目印に物置の裏へ立てておいた黒いサンタのかかし
- **みゅあが消えたわけ**: 暗がりで、もみの木の裏の暖炉わきにある古い隠し通路の扉に寄りかかって転がりこみ、扉が閉まった(内からは開かない)。プレゼントは抱えたままだった。通路の先の屋根裏で、きゅうこの会場を見つける。その夜きゅうこが見つけて計画を話すと、みゅあ「まぢ最高ぢゃん、あたしも手伝う！」。でも下はもう大さわぎで出ていきにくくなり、2人は「どうせなら24日に全部まとめて驚かそう」と決める
- **2人目から**: きき・ももすけ・えるびんは、それぞれ通路へ「招待」されて、サプライズの仲間になった(消える演出はきゅうこの仕込み。本人たちは屋根裏で会場作りと曲の練習をしている)
- **きゅうこが消えたふり(第9話・2番目)**: みゅあの件のすぐあと。自分も消えれば疑われずに動けて、屋根裏のみゅあのそばにもいられる。2番目に消えるので「最後に消えた人」として疑われもしない。ここから会場の仕上げと、ほかの子の「招待」
- **ドラへの罠**: 24日の前に探偵2人に屋根裏を見つけられないよう、目をドラへ向けさせた。ドラの部屋の暖炉にも通路の出口があることを使い、緑の毛くず・大きな長靴の足あと・黒いサンタの服を順に置いた。「ドラなら笑って許してくれる」と思っていて、会場にはドラへのおわびのプレゼントも用意してある(終わりに渡す)
- **ドラを怪しく見せる場面(社長「もっと怪しく」)**: 置かれた手がかり(緑の毛くず・大きい長靴・黒いサンタの服・暖炉の出口・0時のアリバイ)に加えて、ドラ自身の言動でも怪しく見せる。どれも**本当はただの食いしんぼう・照れ・ふざけ**で、真相が分かると「疑ってごめん」と笑える種明かしがつく
