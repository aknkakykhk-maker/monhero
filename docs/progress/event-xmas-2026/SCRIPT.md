### もちまるが消えたわけ(犯人の誤算)

- 12/15 の夜、きゅうこは通路の口(ホールの暖炉わき)から出て、**柱時計の針を13分進めていた**(ドラへの罠のため)。そこへ見回りのもちまるがランタンを持って通りかかり、黒いサンタの姿のきゅうこを見て、追いかけて通路へ入ってしまう
- 屋根裏の会場まで来てしまったもちまるは、計画を聞いて「すてきだっちー！」と喜ぶ。でも、もちまるは**うそがつけない**ので、下に戻すと全部話してしまう。きゅうこは「24日まで、ここにいて」と頼むしかなかった
- 柱時計の前には、もちまるのランタンと、開いたままの帳面(最後の行「0時5分 ホール。柱時計の前に、だれか」)が残る。ほかの3人と違って、**箱も、ぽんぽんも、窓の外の影もない**
- **箱のちがい(社長 2026-11-26「おかしいと思うきっかけにする」)**: もちまるも第1話で、みんなへの小さな箱(手作りのクッキーの箱・水色のリボン)をもみの木の下に置いている(木の下の箱は9つ)。助手が消えた夜は、いつも**その人の箱も同時に空になって**いた。なのに、もちまるが消えた朝、**もちまるの箱だけ、リボンも結んだまま木の下に残っている**。第16話でソラシドが「いつもと違う」と書き留め、第22話で「黒いサンタは、もちまるさんを連れていくつもりがなかった。……計画の外だったんです」と、**誤算**を見抜く入口にする(箱は最後まで開かず、第25話でもちまるが自分で開けて配る)
- **ほころび①**: もちまるは仕事をやめられない。毎朝こっそり通路から台所へ下りて、スープを作り、パンを焼いて、書き置きを残して戻る。のこった人は「だれも作っていないのに、朝、温かいスープがある」(イチーカ「わたしじゃありません」)・「この味は、もちまるの味」と気づく → 消えた人は、ペンションの**中**で元気にしている

## 3. 毎話の終わりの「のこった人の並び」(推理ドラマの登場人物パネル風・社長 2026-11-25)

手本の作品の見せ方はまねせず、自分たちの形でやる。

- 10人(助手8人+イチーカ+もちまる)を、**同じ形の四角いパネル**で**5人ずつ2段**に並べる。パネルの顔はクリスマスの衣装(イチーカはスネグーラチカ、もちまるはふだんのモッチーの顔 `monster-hero/images/monster-icons/face/mocchi.png`)
- 並び順(仮): 上の段 あつ・ソラシド・みゅあ・きき・ももすけ / 下の段 ドラ・きゅうこ・えるびん・イチーカ・もちまる
- パネルの下に**名前の札**(「あつ」「イチーカ」「もちまる」など)
- いなくなった人は、パネルが**白黒**になり、「**行方不明**」の**はんこ**が押される。**その回に消えた人だけ**、色が抜けて、はんこが押される動きを見せる(ほかの白黒の人は、はじめから白黒)
- **出すのは、はじめてだれかがいなくなった回(第7話)から**(社長 2026-11-26)。それより前の、全員そろっている回(第1〜6話)の終わりには出さない。はじめて出す回は、消えた人のパネルの色が抜けて「行方不明」のはんこが押される動きを見せ、そのあとの回は毎話の終わりに出す
- 帯に「のこった人 ◯人 / 空になった箱 ◯つ」。**10人みんなを数える**(はじめは10人)。プレゼントの箱は帯の数だけで、パネルの前には置かない
- きゅうこが消えた(ふりの)回も、ほかの人と同じように白黒とはんこにする(読む人にも、ふりだと分からないように)
- 見つかった回(第24話のきゅうこ・第25話の全員)は、はんこがはがれて色が戻る
