## チャッピーに送る文(1つにまとめた版・社長 2026-11-27「ひとつにまとめて」)

```
添付した3枚を参考に、スマホゲーム「モンスターヒーロー」のクリスマスイベントのポスターを4枚、新しく作り直してください(1枚目・2枚目=今のポスター、3枚目=黒いサンタ)。人物の見た目・絵柄・豪華な金と赤の枠と文字の飾りは今のポスターと同じにし、雰囲気と文字を下のとおりに変えます。1枚できるごとに見せ、私が「次へ」と言ったら次を作ってください。

■作る順番(4枚)
1. 告知用・正方形(1:1)
2. 告知用・横長(2:1)… 1と同じ絵を左右に広げて組み直す
3. 本番用・正方形(1:1)
4. 本番用・横長(2:1)… 3と同じ絵を左右に広げて組み直す

■雰囲気(ここを一番変える)
楽しいクリスマスから、ミステリーの空気へ。雪山の古い木造ペンションの夜。吹雪、窓のあたたかい灯り、その奥で真夜中を指す大きな柱時計(十三番目の鐘が鳴る前の静けさ)。深い青と冷たい影の中に、クリスマスの赤と金がぽつりと光る。怖すぎず、でも「何かが起きる夜」だと分かる絵。血や死体は描かない。
本番用(3・4)は、もう一段冷たく: 柱時計の針が真夜中を少し過ぎ、吹雪が強まり、窓の灯りが一つ消えている。

■人物(今のポスターと同じ見た目のまま)
- 真ん中に探偵の2人。左: 赤い髪に小さな王冠、虫めがね、チェックのマフラーの「あつ」(勘で動く名探偵・不敵な笑み)。右: 黒髪に青のメッシュ、眼鏡、ノートパソコンの「ソラシド」(記録で真実をつなぐ名探偵・冷静な顔)。2人とも、今より少し引き締まった真剣な表情に
- 左奥: サンタ服の人魚のオーナー「イチーカ」(少し不安そう)
- 右奥の黒いサンタ:
  告知用(1・2)は、吹雪の中に赤い目だけが光る大きな影(シルエットだけ・姿は見せない)
  本番用(3・4)は、添付3枚目の「黒いサンタ」の姿をはっきり見せる(黒い服・赤く光る目。見た目はそのまま、迫力のある構図で)
- 手前に、ピンクのアヒルのモンスターと茶色のうさぎのモンスター(サンタ帽)は小さく残してよい

■文字(この通りに。1文字も変えない・崩さない)
- 上の赤いリボン: 告知用は「クリスマスイベント 開催予告」/本番用は「クリスマスイベント 開催中」
- 題字(大きく金): 聖夜の名探偵
- 題字の下の副題: 〜十三番目の鐘が鳴る夜〜
- 下の帯: 開催期間 2026/11/30(月)10:00 〜 12/31(木)3:59
- 下の4つの枠:
  ・レイド開催!(小さく: バトル・モンヒロビート・MFバトルカードで挑める)
  ・ミステリーノベル『モンヒロ事件簿』
  ・助手のクリスマスきせかえ登場
  ・期間中ボーナス(小さく: モンヒロビート5倍・MFバトルカード1.5倍)

■毎回、見せる前に自分で確かめて一言そえる
「文字が上のとおり一字一句合っているか」「人物の見た目が今のポスターと同じか」「告知用か本番用かでリボンの文字と黒いサンタの見せ方が合っているか」
```
