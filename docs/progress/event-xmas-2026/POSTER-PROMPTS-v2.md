# 聖夜の名探偵 ポスター作り直し プロンプト(チャッピー用・第2版)

台帳 r1126-051。副題を「〜十三番目の鐘が鳴る夜〜」に替え、今の重いミステリー(呪いのセーブデータ・十三番目の鐘)に合わせて全部作り直す。
参考に添付するもの: 今の告知ポスター `tools/art-sources/promo/xmas-2026/received/xmas-2026-notice-square.png` と `-wide.png`(本番用はさらに `monster-hero/images/enemies/santa-black.png`)。
できた絵は加工せずに `tools/art-sources/promo/xmas-2026/received/` へ。名前は `xmas-2026-notice-v2-square.png` / `-v2-wide.png` / `xmas-2026-open-square.png` / `xmas-2026-open-wide.png`。

## 1通目(告知用・正方形→横長)

```
添付したポスターを参考に、スマホゲーム「モンスターヒーロー」のクリスマスイベントのポスターを新しく作り直してください。人物の見た目・絵柄・豪華な金と赤の枠と文字の飾りは参考のポスターと同じにし、雰囲気と文字を下のとおりに変えます。

■雰囲気(ここを一番変える)
楽しいクリスマスから、ミステリーの空気へ。雪山の古い木造ペンションの夜。吹雪、窓のあたたかい灯り、その奥で真夜中を指す大きな柱時計(十三番目の鐘が鳴る前の静けさ)。深い青と冷たい影の中に、クリスマスの赤と金がぽつりと光る。怖すぎず、でも「何かが起きる夜」だと分かる絵。血や死体は描かない。

■人物(参考のポスターと同じ見た目のまま)
- 真ん中に探偵の2人。左: 赤い髪に小さな王冠、虫めがね、チェックのマフラーの「あつ」(勘で動く名探偵・不敵な笑み)。右: 黒髪に青のメッシュ、眼鏡、ノートパソコンの「ソラシド」(記録で真実をつなぐ名探偵・冷静な顔)。2人とも、参考より少し引き締まった真剣な表情に
- 左奥: サンタ服の人魚のオーナー「イチーカ」(少し不安そう)
- 右奥: 吹雪の中に、赤い目だけが光る黒いサンタの大きな影(姿ははっきり見せない。シルエットだけ)
- 足元の手前に、ピンクのアヒルのモンスターと茶色のうさぎのモンスター(サンタ帽)は小さく残してよい

■文字(この通りに。1文字も変えない・崩さない)
- 上の赤いリボン: クリスマスイベント 開催予告
- 題字(大きく金): 聖夜の名探偵
- 題字の下の副題: 〜十三番目の鐘が鳴る夜〜
- 下の帯: 開催期間 2026/11/30(月)10:00 〜 12/31(木)3:59
- 下の4つの枠:
  ・レイド開催!(小さく: バトル・モンヒロビート・MFバトルカードで挑める)
  ・ミステリーノベル『モンヒロ事件簿』
  ・助手のクリスマスきせかえ登場
  ・期間中ボーナス(小さく: モンヒロビート5倍・MFバトルカード1.5倍)

■形
まず正方形(1:1)で1枚。見せて「次へ」と言ったら、同じ絵を横長(2:1)に組み直した1枚(人物と題字が左右に広がる配置。文字は同じ)。
見せる前に「文字が上のとおり一字一句合っているか」「人物の見た目が参考と同じか」を自分で確かめて一言そえてください。
```

## 2通目(本番用・正方形→横長。1通目の会話の続きで送る)

```
同じ絵柄で、イベント開催中に出す本番用のポスターを作ってください(正方形→横長の順)。1枚目からの変更は次の3つだけです。

1. 上の赤いリボン: クリスマスイベント 開催中
2. 右奥の黒い影を、添付した「黒いサンタ」の姿で、はっきり見せる(黒い服・赤く光る目。参考の絵の見た目のまま、迫力のある構図で)
3. 空気をもう一段冷たく: 柱時計の針が真夜中を少し過ぎ、吹雪が強まり、窓の灯りが一つ消えている

文字(題字・副題・開催期間・4つの枠)は1枚目と一字一句同じにしてください。
```
