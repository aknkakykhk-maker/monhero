## 1. 見た目

館の見取り図に、クリスマスの飾りを下げた形にする(ほかの作品の見た目は使わない)。

- **背景**: 夜の紺に、見取り図の方眼を薄く重ね、雪を少し降らせる
- **幹の線**: 金のリボン。読んだ所まで光る。その先は暗い点線
- **章**: 木の扉の札(「第二章」)と、章の題。読むまで「第？章 ？？？」(r1126-094 追記3: 題は読むまで伏せる)
- **分かれ道**(形で見分ける。色だけに頼らない)
  - 行動の選択: 赤いひし形
  - 推理の問い: 緑の丸に番号(①〜⑦)
  - 名指し(派を選ぶ A1・1回目と2回目の推理): 紫の角丸の四角
  - 下の小さな字は、読んだあとだけ出す(場面の短い呼び名・「一発で正解」「外して仲間が拾った」「あつ派を選んだ」など)
- **エンド**: 枝の先に下がったオーナメントの札。見た物だけ名前を出し、まだの物は「？？？ 未見のエンド」。上の段に「エンド ◯/16」
- **いまここ**: 今の「続き」の場所の印を赤い札で出し、その分かれ道を白く光らせる
- **派の切り替え**: 上の段に「あつ派 / ソラシド派」。派ごとに台詞と強制バッドの中身が違うので、地図も派ごとに出す。まだ選んでいない派は全部伏せる
- **過去編**: 一番下に鍵の札。真グッドを見たあとに開く(今の決まりのまま)
- **読み直しの印「↺」**: 通った分かれ道の右に付く。押すと下から札が出る(右の止め絵)

## 2. 地図の作り方(新しく保存する物は無い)

- 地図の形は、台本 `XMAS_NOVEL_SCRIPT` から機械で作る。章 → 問いの行(`t:'q'`)→ 行き先(`options[].to`・`route`)→ その先のエンド(`xmasNovelEndingAhead`・r1126-099 で足した関数)。台本を書き換えても地図は自動で合う
- **読んだかどうか**: 今の保存 `mh_xmas_novel_v1` の `read`(読んだ行のID)と `endings`(見たエンド)を使う。地図のためだけの保存は足さない
- 分かれ道の下の小さな字(一発で正解など)は、`first`(一番はじめの答え)と `cur.ans` から出す

## 3. 「ここから読み直す」の保存の持ち方(新しいキーを1つ足す)

### キー

`mh_xmas_novel_route_v1`(新しいキー。今の `mh_xmas_novel_v1` は形も中身も変えない・⑦)

```
{
  v: 1,
  at: {                       // 分かれ道ごとの、その問いの行に止まった時の状態
    "A2|1":  { scene, idx, flags, clues, ans, panel },   // 「<問いのID>|<派 0〜2>」
    "Q2a|1": { ... },
    ...
  },
  back: { scene, idx, ... } | null   // 読み直しを始める前の「続き」(地図の「いまここ」から戻るため)
}
```

- 中身の形は今の「続き」(`cur`)と同じ。読み込みは今の `xmasNovelNormalizeCur` を通す(壊れた物・台本に無い場面は捨てる)
- **書く時**: 問いの行に着いたら、その分かれ道の状態を上書きする(一番新しく通った時の状態が残る)
- **大きさ**: 分かれ道は両方の派で最大32か所。全部通って約4万4千字(1か所あたり最大約2,400字)。今の `mh_xmas_novel_v1` の `read`(最大6000件)より小さい

### 読み直す時

1. 「ここから読み直す」を押す
2. 今の `cur` を `back` に写す
3. `at[キー]` を `cur` にして、その問いの行から始める(手がかり帳・登場人物パネル・フラグ・派は、その時の状態に戻る)
4. `first`(一番はじめの答え)・`endings`(見たエンド)・`endAt`・`read` は**変えない**。記録が消えたり、二重に付いたりはしない
5. 地図の「いまここ」の札か、札の中の「さっきの続きへ戻る」で `back` に戻れる(`back` は戻ったら空にする)

### 二重に効かないこと

- 付与・補償・数を足す処理は無い。上書きと読み出しだけなので、何度読み直しても同じ結果になる
- 一度きりの移行は要らない(新しいキーは空から始まり、通った分かれ道から埋まる)

### 前から遊んでいる人

更新より前に通った分かれ道は、状態が残っていない。どちらかにする(**聞きたい事 ②**)。

- **案ア**(推し): 今ある章ごとの状態(`snaps`・章の頭の状態)から、機械で分かれ道まで進めて作る。安全な方・正解で進めるので、その時の手がかり帳と同じになる。読み込んだ時に1回だけ動かし、`mh_xmas_novel_route_v1` に `seeded: 1` を書いて二度は動かさない
- **案イ**: 作らない。「↺」の代わりに「もう一度通ると選べる」と出す(今の「章から」はそのまま使える)

## 4. 入口

事件簿の上の段(人物・一覧・オート・スキップ・メニュー)に「地図」を1つ足す。読んでいる途中でいつでも開ける。タイトルの「章から」の横にも置くか(**聞きたい事 ③**)。

## 5. 守ること(作り込む時)

- 今の「続き」(`mh_xmas_novel_v1.cur`)の位置を壊さない。読み直しは `back` に逃がしてから替える
- エンドの到達(`xmas-novel-check`)を壊さない。台本は触らない
- 保存データに触るので、作り込んだあとは gate のとおりミハリの確認を通す
- 演出の会話(同じ事件簿の画面)とぶつかりやすいので、地図は新しい部品(`79-screen-xmas-novel-map.jsx` など)に分け、今の画面には入口のボタンと呼び出しだけを足す

## 7. 決まったこと(r1126-102 追記1)と、作った物

社長の答えは4点とも推しどおり(①まだ読んでいない先は暗い「？？？」で形だけ ②地図より前に通った分かれ道は今の保存から機械で作る・1回だけ ③入口は上の段の「地図」だけ ④名前は「聖夜の見取り図」)。

- 地図の部品: `monster-hero/src/parts/79-xmas-novel-map.jsx`(新しいファイル。台本から章・分かれ道・エンドを並べる `xmasNovelMapModel` と画面 `XmasNovelMap`)
- 保存: `79-xmas-novel-engine.jsx` の `xmasNovelRouteNormalize` / `xmasNovelRouteRecord` / `xmasNovelRouteSeed`(キー `mh_xmas_novel_route_v1`)

- 検査: `tools/novel/xmas-novel-route-check.js`(機械で作った状態が通しの状態と中身まで同じ・1回だけ・正規化・大きさ)。`xmas-novel-browser-check.js` は書いてよいキーに `mh_xmas_novel_route_v1` を足した
