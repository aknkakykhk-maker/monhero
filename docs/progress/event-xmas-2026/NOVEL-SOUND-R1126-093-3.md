# 事件簿の音を「曲は静か・様子は効果音で」に作り直す(台帳 r1126-093 追記3・追跡表 r1128-053)

2026-11-28 社長「事件簿だけどBGMを明るいとこ以外は極力静かなやつか音無しにいれてSEで表現するつくりしたい。風の音とか足音とかノックの音とか殴られる音とか時計の音とか」。
前の一覧: 曲 [`NOVEL-BGM-R1126-093.md`](NOVEL-BGM-R1126-093.md) / 効果音 [`NOVEL-SE-R1126-093-2.md`](NOVEL-SE-R1126-093-2.md)(この版で上書きした所は下に書く)。

## 決め方

- **曲**: 明るい場面(ほっとする・笑い)の「Close To Your Heart -BGM-」と、静かな曲(Erfolg ピアノ ver.・プロフィールテーマ・ゲームオーバーテーマ)だけ残した。
  不穏・怖い・推理で鳴らしていた5曲(呪われた騎士の時計仕掛け・同 -Another-・鋼鉄の亡霊・同 -Another-・魔窟の旋律・デュラハンテーマ)は全部音無しにした。
  開いた所(題の画面)も音無し(柱時計の環境音だけ)
- **環境音**(ずっと小さく鳴る): 外の風・吹雪・暖炉・柱時計のチク・タク・部屋のかすかなすきま風の5つ。背景の名前で決め、場面や背景が替わると 1.2 秒で前の音を小さくし、1.5 秒で次の音を大きくする(つなぎ目なく替わる)。
  外側(助手たちの前)とエンドの札では鳴らさない。仕組みは `14-audio.jsx` の `nvAmbient`、場所の決め方は `79-screen-xmas-novel.jsx` の `xmasNovelAmbientOf`
- **1回の音**: 帯の文に合わせて1回鳴る。#8038 の9種に、足音・駆ける足音・殴られる・倒れる・悲鳴の手前の息・扉・吹きこむ風の7種を足した(どれもその場で合成する音・音源ファイルなし)

## 重ならない・残らないための決まり

- 音量は効果音の音量の設定(環境音と1回の音)・BGM の音量の設定(曲)に従う。音を切ると環境音も止まる
- 既読飛ばしの間は、帯の1回の音を鳴らさない。環境音は場面が 0.35 秒落ち着いてから替える(飛ばしても次々には重ならない)
- オートで次の行へ進むと、まだ鳴っていない残りの回数(叩く音の2回目など)は鳴らさない
- 選択肢を待つ間のチクタク(#8038)と柱時計の環境音は重ねない(待つ間だけ環境音の柱時計を止める)
- 事件簿を閉じると環境音を止める

## 音無しにして効果音で表す主な所(例)

- 第2章「十二の鐘」: 柱時計のホールの環境音の中で鐘 → 停電(ゴッ+不穏な一音)→ 2階の物音
- 第2章「吹雪の向こう」: 吹雪の環境音・扉が開いて風が吹きこむ・かすかな声の手前の息
- 第3章「雪の上の影」: 外の風だけ
- 第5章「鏡の向こう」: 叩いても開かない鏡の扉(2回)・きしみ
- 2回目の推理の外れ「灯りを消した部屋」(C2-Y): 足音 → 殴られて倒れる → 階段の下に倒れる音

## 追記4(2026-11-28 社長「事件簿っていま無音になってる？」)

### 原因

1. **小さすぎ・低すぎ**: 環境音は -74〜-89 dB(ボタンの音の最大 -45 dB よりずっと小さい)で、しかも音の大半が、スマホのスピーカーでほとんど出ない 300Hz より下だった。
   足音・殴る・倒れる・柱時計のチクタクも低い音だけでできていた。曲を音無しにした場面では、ほぼ無音に聞こえていた
2. **鳴らし始められないことがあった**: 音がまだ使えない(解錠前・音を切っている)うちに頼まれた環境音を「鳴っている」と覚えてしまい、
   あとで音が使えるようになっても、場面が替わるまで鳴らし直さなかった
3. (変えていない)超省エネで周回を回している間は、決まりで効果音の口ごと 0 になる(60-app.jsx の ultraEcoSession)。そのあいだは事件簿の効果音も鳴らない

### 直したこと

- 環境音を大きくし、音の帯を 400〜2000Hz 寄りへ移した(雑音を帯域で絞り、ゆっくり揺らす)。暖炉のはぜる音・柱時計のチク・タクも高く大きく
- 1回の音(nv*)も大きくし、低い音だけの物(足音・駆ける・殴る・倒れる・きしみ・扉)に、スピーカーで聞こえる高さの「こすれ」「打つ音」を重ねた
- 頼まれた環境音を覚えておき、音の解錠(unlock)・音を戻す(setEnabled)・再開(resumeIfNeeded)のときに鳴らし直す。音を切ると止まり、戻すとまた鳴る
