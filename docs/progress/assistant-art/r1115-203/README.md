# 助手の表情の全身画が荒い(r1115-203)

担当: 助手部ココロ3。社長「渡した画像をちゃんと処理すればあんなに荒れないと思う」。

## どこで荒れていたか(数で)

原画(`tools/art-sources/assistant-fullbody/received-v1/`)の同じ表情の所を、原画の画素のまま切り出した物と、ゲームに入っていた絵を画素ごとに突き合わせた。

| 疑った所 | 結果 |
| --- | --- |
| 切り出しの範囲・縮み | **縮みなし。** 体の中の画素は全員、原画と同じ(色の差 0.00〜0.9・細かさの比 0.98〜1.00)。体の高さも原画のまま(あつ 751・みゅあ 569・カードマスター 507 など) |
| 色の数 | **減色なし**(1枚 4万〜25万色) |
| **縁の処理** | **ここで荒れていた。** `life-fullbody-art.py` の `clean()` が ①体の芯から約3画素より外の透けを消す ②透けを 1〜1.2 画素ぼかす ③ふちの画素の色を内側の平均の色で塗り直す、をしていた。毛先・輪郭の細い線が消え、ふちがにじむ。ふちの色を変えた画素は 1人 約8,000〜16,000(あつ 8,230・ももすけ 16,236) |
| 表示の引き伸ばし | 紹介「◯◯のこと」: 枠 242×300。端末3倍で 0.6〜1.7倍(みゅあ3種だけ 1.5〜1.7倍)。MFバトルカードのトップ(胸から上の大写し): 端末3倍で **あつ 4.5倍・えるびん 3.4〜3.7倍・みゅあ/ソラシド 3.2倍・キュウコ 3.1倍・みゅあハロウィン 3.0倍・カードマスター 2.7倍・ききハロウィン 2.6倍・ももすけ 2.2倍・きき 1.3倍** |
| 紹介で表情を変えたとき | 絵ごとに枠へ収めていたので、腕を上げた絵などで体が縮んだ(えるびん 7%・ききハロウィン 8%) |

並べ比べ: [`edge-compare-3x.jpg`](edge-compare-3x.jpg)(原画・直す前・直した後の頭のまわり、9人ぶん)

## 直したこと

- 表情の絵(`fullbody/<名前>__<表情>.png` 96枚と、そこから切る立ち絵)を、**原画のふちの透けと色のまま**作り直した(`clean(raw=True)`)。消すのは、となりの絵のかけら・ごみと、はっきりした線(不透明度64以上)から2画素より外の薄いもやだけ。縮めない・減色しない・補間で引き伸ばさない
  - ふちの色を変えた画素: 約8,000〜16,000 → 0〜117(残りは縫い目で切った、となりの体のすそ)
  - 変えなかった物: カードマスター(市松を抜いたシートで、ふちが2値のため今までどおり)・表情なしの絵・顔アイコン・寝顔・ソラシド『補正』の立ち絵
- 紹介「◯◯のこと」の全身画: 8表情でいちばん背の高い絵が枠の 96% になる倍率を全部の表情に使い、足元をそろえる → 表情を変えても体の大きさが変わらない(表は `ASSISTANT_LIFE_PROFILE_FULL_MAX_H`。`life-profile-faces-check.js` ③ が絵と食い違うと止める)
- 顔の表(`ASSISTANT_LIFE_STAND_FACE_OUTFIT` の stand-normal・stand-sekiyuou)を、作り直した立ち絵の数字に合わせた(差は 1% 未満)
