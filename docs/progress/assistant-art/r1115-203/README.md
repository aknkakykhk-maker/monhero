## 原画そのものが足りない所

あつの表情の原画は 1024×1536 の1枚に8体並んでいて、1体の高さが約750画素・顔は一辺約140画素しかない。
加工をやめても、**MFバトルカードのトップの大写し(約4.5倍)と、大きめの顔アイコン(約1.9倍)では、原画の細かさが足りず荒く見える**。
表情ごとに1枚の絵(1024×1536 に1体。ききのいつもの服と同じ形)があれば、1体の高さが約1500画素になり、大写しでも約2.2倍・顔アイコンは1倍未満になる。
