# 助手の絵の大きさ・重さの調べ(2026-11-28・台帳 r1126-119)

社長「助手画像は基本サイズでかめだから確認してみてほしい」。`monster-hero/images/assistant/` 以下の助手の絵 **806枚・515MB** を道具で全部測った。**ゲームの絵はまだ差し替えていない**(調べるだけ)。

- 道具: `python3 tools/assistant/assistant-art-size-audit.py [--json 出力] [--no-webp]`(全部で約20分。WebP の見込みを出さないなら数分)
- 1枚ずつの数字: `audit.json`(場所・縦横・中身の縦横・余白の割合・重さ・可逆WebP・画質90・要る画素に対する倍率・組の中の世代の差・原本の有無)

## まとめ(要点)

| | 重さ | 今からの減り |

| 今 | **515.4 MB** | — |

- 重さの半分以上が **全身画(283MB)**。助手ごとでは、みゅあの3着(ふだん・ハロウィン・カードマスター)が全種類で 128MB(うち全身画 67MB)
- 顔アイコンは全部で 25MB と小さい。クリスマスの決めに合わせて PNG のままでも、全体はほぼ変わらない(画質90にしても約19MB減るだけ)
- 「大きすぎ」より **「粗い」ほうが目立つ**: あつ・ももすけ・えるびんのふだんの立ち絵、あつの全身画などが、iPhone の細かさに対して2〜5分の1しかない

## 測り方

- 画面で要る画素(縦)= iPhone の倍率3 × 画面でいちばん大きく出るときの高さ(CSS px のめやす)。立ち絵 460(モード選びの縦の枠・r1119-153 の測り)/ 全身 600 / 胸像 400 / 顔 96
  - 立ち絵の 460 は測った値。全身・胸像・顔はめやす(画面ごとに測ってはいない)ので、倍率は「傾向」として読む
- 中身の高さ = 透明でない所の高さ(透明の余白は数えない)
- **大きすぎ** = 中身の高さが要る画素の2倍を超える / 透明の余白が絵の6割を超える
- **粗い** = 中身の高さが要る画素の6割に届かない / 256色に減らしてある / 同じ組の表情どうしで中身の高さが1.5倍より違う(世代の混ざり)
- WebP は Pillow の WebP(method 4)。画質90 は透明の縁も含めて今日のクリスマスの絵と同じ設定
- 原本 = `tools/image/assistant-art-catalog.json` の目録で、ゲームの絵とは別に元の絵が残っているか

## 直す案と手間

| 案 | 中身 | 減る重さ・良くなる所 | 手間 | 気をつける所 |
|---|---|---|---|---|
| **A. PNG を WebP 画質90 にそろえる**(推奨) | クリスマスと同じ仕様。全身・胸像・立ち絵を WebP 画質90、顔は PNG のまま | **約330MB 減**(顔を除く) | 中(道筋 `assistantArtFile` はクリスマスで WebP を受けるようにしてあるので、絵の書き出し・置き場の切り替え・検査。めやす1〜2日)| 絵の置き場と拡張子が変わるので、絵の道筋と事前ダウンロードの一覧(build.js)を合わせて作り直す。保存データには触れない |
| B. 可逆 WebP にそろえる | 見た目を1画素も変えない | 約145MB 減 | Aと同じ | 減りが半分以下 |
| **C. 粗い物を元の絵から作り直す** | あつ・ももすけのふだんの全身画と立ち絵、ドラ・えるびんの胸像、あつの顔。元の絵がある | 見た目が良くなる(重さは少し増える) | 中〜大(1組ずつ PR。全身画を替えると立ち絵の切り直し・顔の位置合わせが続く) | 顔アイコンは承認済みの組が多い(r1119-153 追記5)。触るなら1枚ずつ確かめる |
| D. 元の絵の無い粗い物を拡大の道具で上げる | ソラシド・ももすけ・ソラシド補正の256色の胸像など | 見た目が良くなる | 中(拡大は1枚5〜20分) | 256色の段を拡大すると段も残る。描き直すかは社長 |
| E. 大きすぎる物を縮める | ききのツインテールの胸像・クリスマスの胸像など | 数MB しか減らない | 小 | すでに WebP の物が多く効果が小さい。後回しでよい |
| F. 立ち絵の長い辺の上限を見直す | 横長の立ち絵(えるびん・みゅあカードマスター・ソラシド補正)の縦を増やす | 縦の枠で細かくなる | 小〜中(切り出しの数字 `life-stand-cut.json` と場面の確かめ) | 重さは少し増える |

- 先に A をすると、C・D で作り直す物も最初から WebP で入れられる。C の中では **あつのふだん(立ち絵0.20倍・全身0.41倍)** がいちばん効く
- どれもゲームの絵を差し替えるので、公開の前に場面の撮り比べ(`tools/browser/visual-compare-check.js`)を通す
