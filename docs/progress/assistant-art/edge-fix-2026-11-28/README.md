# 助手の絵の縁の荒れを、絵を入れる手順から直す(2026-11-28・r1126-095 追記2)

社長「やっぱまだ助手の画質悪い気がする。ソラシド探偵の顔周りとか」「全体的に際が荒い」
「最近こういうぼやけ加工になってるのが多くて助手全部直したんだけど、新着替えでまた同じ現象だから実装の仕方が悪いよね」

## 原因(1段ずつ止めて確かめた)

`cause-stages-face.png`・`cause-stages-hair.png`(ソラシドのクリスマス衣装・ふつう。左から順に道具の段)

| 段 | 縁 |
| --- | --- |
| 原本(Lanczos で2倍) | 外に黒い線・内側に白いつや(描き込み)。くっきり |
| AI 拡大の中間(#8044) | 黒い線がそのまま残る。くっきり |
| 3) 体から離れた所を消す | 変わらない |
| 4) 透けをぼかす(1.2) | 縁が甘くなる(ぼやけ) |
| **5) 縁の色を内側の色で塗り直す** | **外の黒い線が肌色・髪の色で塗りつぶされ、頬〜あごに白っぽい縁取り。髪の外の線が消え、塗りの塊が出る** |
| WebP 画質90 | 縁の数はほぼ変わらない(4:2:0 でも線は残る) |

窓口の見立て(AI 拡大した絵に今までの縁の掃除が合わない)のとおりで、決め手は 5) の塗り直しと 4) のぼかし。
AI 拡大そのもの・縮める補間・WebP は原因ではない。前からの検査(`life-fullbody-edge-check.js`)は
「縁に半透明が5割以上あるか」を見ていたので、ぼかすほど通っていた。

## 直したこと(道具)

- `tools/assistant/art_edge.py` … 新しい口。透けは原本の物を Lanczos で広げて使い、色だけ AI 拡大の絵から取る。
  縁は削らない・ぼかさない・塗り直さない。消すのは体から離れたごみと、線から原本の2画素より外の薄いもやだけ
- `tools/assistant/life-fullbody-art.py` … `LEGACY_CLEAN`(2026-11-28 より前に作って社長が見た絵)に無いキーは全部この口を通る。
  新しい服はここへ足さないので、必ず縁を削らない作り方になる。表情シートは `EDGE_SHEETS` に入れた子だけこの口へ(今は空。下の判断待ちを見る)
- `tools/image/upscale-anime/upscale.py` … 拡大するのは色だけ。透明な所の色を縁の色で埋めてから模型に通す(黒のにじみ止め)
- `tools/assistant/life-stand-from-fullbody.py` … 全身が WebP になった服でも、目印を測った時の全身を履歴から探せるように

- `tools/assistant/life-fullbody-edge-check.js`(前からの検査)は、縁を削らない口で作った絵(クリスマス衣装・冬服・ももすけの8表情)を見ない。
  「縁に半透明5割」「縁の白は取る」が、ぼかし・塗り直しの方へ道具を押していたため。これらは原本と比べる新しい検査が見る

## 二度と戻らないための検査

`node tools/assistant/art-edge-check.js`(本体 `art-edge-check.py`・物差し `art_edge_metrics.py`)。
原本と出来上がりを同じ物差しで測り、原本より悪ければ落ちる。助手の絵・原本・絵を作る道具を触ると `run-checks.js --changed` が選ぶ。

| 測る物 | 落ちる線 | 原本の Lanczos 2倍 | AI 拡大の中間 | #8044 の配信の絵(ソラシドのふつう) |
| --- | --- | --- | --- | --- |
| 白い縁取り(縁の帯の明るさの浮き) | +10 | −0.5 | −5.4 | **+66** |
| 外の線の消え(縁の帯の暗い画素の減り) | 0.06 | −0.006 | −0.011 | **0.31** |
| ギザギザ(輪郭の長さの比) | ×1.10 | ×1.00 | ×1.00 | ×0.99 |
| ぼやけ(縁の半透明の幅の比。幅の増えが 0.4 画素以下は落とさない) | ×1.20 | ×1.03 | ×1.02 | **×1.53** |

## 比べ絵

`compare-<名前>.png` … 顔周りを「原本(同じ大きさに広げた物)・今(直す前)・直した後」で、暗い背景と明るい背景の2段に並べた物
(`tools/assistant/art-edge-compare.py` で作った)。


## 作り直した絵

- クリスマス衣装 7人 × 10枚(全身・半身の置き場)、きゅうこの冬服 9枚(全身)。立ち絵・顔アイコン・顔の表(56-assistant-life-house.jsx)は道具で作り直し
- 大きさ・置き場所・ファイル名は前と同じ(体の箱の取り方で1画素ほど違う物がある)
