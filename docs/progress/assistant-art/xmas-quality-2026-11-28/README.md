## 何をしたか

1. 受け取った原本(1表情1枚)を、拡大の道具(Real-ESRGAN アニメ用・線や色は描き変えない)で2倍に(`tools/art-sources/assistants/<キャラ>/santa/upscaled-2026-11-28/received/`・冬服は `kyuko/winter/upscaled-2026-11-28/fullbody/`)
2. そこから全身 → 半身の置き場 → 立ち絵・顔アイコンを作り直し(`tools/assistant/life-xmas-art-remake.py`)。背景の縁の掃除は今までの道具のまま
3. 顔アイコンの切り方・顔の表は今までの数字のまま(目印は全身の倍率 2.00倍で自動で移った)。表情を替えても頭は動かない
4. 256色に減らさない。全身・半身・立ち絵は WebP 画質90(PNG だと1枚 3〜4MB になるため)。顔アイコンは今までどおり PNG 256×256
5. ドラは原本が 1254×1254 あるので拡大せず、384×384 だった顔の絵を原本の大きさのまま(`tools/assistant/life-dra-santa-art.py`)
6. きゅうこの冬服は全身と立ち絵だけ作り直し(顔アイコンは #7943 で直した物のまま)
