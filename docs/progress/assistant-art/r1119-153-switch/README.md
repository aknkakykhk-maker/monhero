# 助手の絵を最新の全身絵からの切り出しへ切り替える — 一覧と前後(r1119-153・2026-11-23 ナカヨシ)

社長「古いやつは画質が悪いから、助手絵は最新の全身絵に切り替えて場面場面の切り出しで出してほしい」。
この段階では**ゲームの絵は替えていない**。社長に前後を見てもらってから切り替える。

## 画面に出る助手の絵は4種類

| 種類 | どこに出るか | 絵を決める所 | 元の絵 |

## 前後の止め絵(このフォルダ)

- `face-<助手>[_<服>].png` … 顔アイコン8表情。上がいま、下が最新の全身絵から切った案(丸く切って表示する形)
- `stand-<助手>[_<服>].png` … 立ち絵8表情(みゅあ ふだん・ハロウィン、ソラシド ふだん・補正)
- えるびん・ききの立ち絵の前後(公開済み): `../erubin-stand-recut-2026-11-23/`

## 切り方(案)

- 顔アイコン: 一辺 = 頭のてっぺんから顎までの1.5倍、上はてっぺんより1割上。横は目の高さの頭の幅の真ん中。
  表情ごとの全身絵の大きさ・位置の違いは重ね合わせてそろえる。**一辺256へ縮める**(吹き出しは48〜72pxで出るため)
- 立ち絵: 表情ごとの大きさをいちばん小さい表情に合わせて縮めてそろえ、場面はどの表情も normal の範囲で置く(えるびん・ききと同じ)。
  **長い辺1000へ縮める案**(バトルの入口の絵の枠が最大で幅約360px × 画面の細かさ3倍)
- 色は減らさない。引き伸ばさない。古い絵は消さない(使う所だけ替える)

## 判断が要る所

1. 顔アイコンの寄せ方(上の案でよいか)と大きさ(256か192か)
2. 立ち絵を長い辺1000へ縮めてよいか(えるびん・きき 公開済みの物は縮めていない)
3. ソラシド 補正の立ち絵も全身絵から切り替えるか(前は作り直しを相談中だった)
4. 仲良し度UPの演出(`44-growth-fx.jsx`)は着替えを見ずに、ふだんの服の立ち絵を出している。着ている服の立ち絵にするか
5. MFバトルカードの立ち絵の範囲の表(`CARD_ART_KNOWN_BOX`)は前から今の絵と合っていない(合わない値は使わずその場で測るので崩れはしない)。カード部の `node tools/card/card-art-box-build.js` で書き直せる
