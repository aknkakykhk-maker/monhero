# 顔アイコンの位置合わせ(r1119-153 追記5・追跡 r1125-023)

社長(11/25)「顔アイコンの位置合わせも随時進めよう」「今回はこっちの部署で」→ 助手部ナカヨシが1組ずつ直して公開する。

基準: **目の大きい絵柄と男性陣でも、丸の中の顔の大きさと目の高さがそろって見える**こと。
物差しは Muse の承認済み6組(★: ももすけ・きゅうこ・えるびん・えるびん石油王・ソラシド補正・きき ツインテール)。
★の組は、目の高さが丸の 0.48〜0.55、顔の幅(頬から頬)が丸の約半分。

★の組は上書きしない。道具の `--write` は顔の表の m(場面の大きさ)と立ち絵まで書き換えるので、
`life-stand-cut.json` に組の数字を足し、`--only <キー>` を **--write なし**で回して、顔アイコン(`*/face/*.PNG`)だけを入れる(立ち絵と `life-stand-made.json` は戻す)。

## 道具

```
python3 tools/assistant/life-face-sheet.py <出力.png>                       # 全組の normal を丸く並べる
python3 tools/assistant/life-face-pair.py <出力.png> halloween/face/momosuke "名前" face/momosuke "基準★"   # 8表情の前(origin/main)・後・基準
python3 tools/assistant/life-face-zoom.py <出力.png> 前 origin/main:monster-hero/images/assistant/<置き場>_normal.PNG 後 <置き場>_normal.PNG   # normal を大きく・5%ごとの線
```
