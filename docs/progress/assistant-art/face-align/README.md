## 新しい着替えの点検(公開の前に必ず・r1119-172 追記・追跡 r1125-040)

社長(11/25・きゅうこのクリスマスの寝顔・わくわくが大きい)「根本的にずれとサイズ感が悪い。新着替えは全部顔アイコンチェックが必要」。
新しい着替えの顔アイコン(8表情+寝顔)は、公開の前にどの部もこの点検を通す。

1. 一覧を作る: `python3 tools/assistant/life-face-outfit-sheet.py <出力.png> <服>`(助手ごとに1行・9表情・右端に基準=ふだんの normal)。止め絵は `--compare` で前(origin/main)・後を上下に
2. 見る所(合格の目安)。どれも**右端の基準(承認済みのふだん)と比べる**
   - 目の高さ: 丸の 0.48〜0.58 で、基準との差が 0.05 以内(赤線=0.5・青線=0.4/0.6)
   - 顔の大きさ: 目と目の間(または頬から頬)が基準の 0.85〜1.15 倍
   - 中心: 顔の横の真ん中が 0.42〜0.58(横を向いた絵は目と目の真ん中で見る)
   - **表情ごとにそろっている**こと(全身画は表情ごとに大きさ・ポーズが違う。泣き・わくわく・寝顔がずれやすい)
   - 決めごとで形を選んだ組は、その形が正(あつ=案C「王冠まで入れて顔を大きめ」)
3. 外れたら数字で直す: `tools/assistant/life-stand-cut.json` の `<助手>:<服>` の `face`
   - 全表情そろって外れる → `head`(大きいほど引く)・`up`・`dx`・`dy`
   - 1つの表情だけ外れる → `face.expr.<表情>` に `zoom`(1より大きいほど引く)・`dx`・`dy`(一辺の何割・+は右・下)。寝顔は `sleep`
   - 目と目の間で測った倍率 k の表情は `zoom: k`。目が (ex, ey) にあり (tx, ty) へ動かしたいとき `dx = ex − 0.5 − k(tx − 0.5)`・`dy` も同じ
4. 作り直す: `python3 tools/assistant/life-stand-from-fullbody.py --only <助手>:<服> --face-only`(顔アイコンだけ書く。立ち絵・顔の表は動かさない)
5. 1. の一覧を `--ref origin/main` 付きでも作り、前後を並べて止め絵にする

## 道具

```
python3 tools/assistant/life-face-outfit-sheet.py <出力.png> <服> [--ref origin/main]   # 着替え1着: 助手ごとに9表情+基準
python3 tools/assistant/life-stand-from-fullbody.py --only <キー> --face-only            # 顔アイコンだけ作り直す
python3 tools/assistant/life-face-sheet.py <出力.png>                       # 全組の normal を丸く並べる
python3 tools/assistant/life-face-pair.py <出力.png> halloween/face/momosuke "名前" face/momosuke "基準★"   # 8表情の前(origin/main)・後・基準

```

## クリスマスの着替え: やり直し(r1125-040 追記・社長「全然位置合わせる気ない出来だね」)

社長の答え: そろえるのは**新しいきせかえ(クリスマスの8着)だけ**。既存の服(ハロウィン・カードマスター・補正など)は触らない。
基準は**各助手のふだんの顔アイコン(`images/assistant/face/<助手>_<表情>.PNG`)と、同じ表情どうしで**目の高さ・顔の幅・中心をそろえる。
あつは案C(王冠まで入る)のふだんに、ドラはふだんのドラの顔に合わせる。

上の「目と目の間が基準の0.85〜1.15倍なら合格」という目安は甘すぎた(並べると寄りすぎ・あふれる)。**同じ表情のふだんと上下に並べて、見え方が同じこと**を合格にする。

### 進め方

1. 測って数字を入れる: `python3 -I tools/assistant/life-face-measure.py <助手>:<服> --apply` → `python3 tools/assistant/life-stand-from-fullbody.py --only <助手>:<服> --face-only`(2回くり返す)
   - ふだんの顔(目のあたり)を型にして、着替えの顔の中を大きさを変えながら探す。似ている度 0.6 未満の表情(手で顔を隠す・絵柄が違う)は数字を書かない
2. 上下2段で見る: `python3 tools/assistant/life-face-vs-normal.py <出力.png> <服> <接頭辞...>`(9表情・十字線)
3. 測れなかった表情は、測れた normal の数字を使う(表情どうしの重ね合わせは切り出し道具が済ませている)。全体が大きい・小さい助手は、全表情の zoom で直す
4. 全員を並べた絵で、もう一度目で見る。そろっていない物が残っていたら直す
