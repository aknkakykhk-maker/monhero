# ソラシドの口調の見直し(案・2026-11-11)

依頼: 社長「ソラシドの口調の見直し。敬語は親密度によって。あつのも参考にして」(窓口 → 助手部ココロ)。
**これは案。社長の OK が出るまで、台詞も人柄の指示も直していない。**
手本の話し方からは言い回しの癖だけを取り、中身・人・出来事は台詞に入れない。

- 人柄の指示(`ASSISTANTS` の `speech`): 「ため口のくだけた男性口調」「です・ますは少し丁寧に話すときだけ」。一人称はふだん「俺」

- つまり、いまは**仲良し度に関係なく最初からタメ口**。丁寧語はほぼ無い(499行に7行)
- 仲良し度で変わるのは、HOME の17行(`bond:` の付いた行)の「中身」だけ。口調は変わらない
- おしゃべり(assistant-chat)へ渡す「この段階の話し方」は、ソラシドの分が無く、みゅあと同じ文(「呼び捨てになって、雑談も増える」など)が渡っている

## 2. あつの親密度の仕組み(同じやり方にそろえる所)

あつも、ソラシドも、同じ2つの仕組みに乗っている。新しい仕組みは作らない。

| 仕組み | 置き場所 | 何をするか |
| --- | --- | --- |
| 段階の行 | 台詞の束の各行の `bond:[下,上]`(`bond:21` は「21以上」) | その仲良し度のときだけ出る行。あつは HOME に16行(Lv1〜2 / 3〜5 / 4〜8 / 6〜12 / 11〜20 / 16〜20 / 21〜30 は1段ずつ) |
| 段階の話し方 | `ASSISTANT_BOND_STYLES.<助手>.tones`(30段ぶん) | おしゃべりへ「この段階の話し方」として毎回渡る(きき・ももすけが持つ。あつ・ソラシドは未記入でみゅあの文) |
| 段階の呼び方 | `ASSISTANT_BOND_STYLES.<助手>.call` | Lv でプレイヤーの呼び方を変える(あつはずっと呼び捨て) |

- あつは「口調は最初から最後までタメ口」で、段階の行で**距離の近さ(中身)**を変えている
- ソラシドは、この同じ3か所を使って**敬語の度合い(口調)**を変える。足りない所(`tones` と、HOME 以外の場面の段階の行)を足す

## 3. 段階ごとの口調の決まり(案)

| 段階 | 仲良し度 | 敬語の度合い | 語尾・言い回し | 「笑」・絵文字 | 一人称 |
| --- | --- | --- | --- | --- | --- |
| ① 丁寧 | Lv1〜3 | 丁寧語だけ。硬くはしない | 「〜ですね」「〜と思います」「〜って感じです」「なるほど了解です！」 | 「笑」はよく付ける(「〜ですか？笑」)。絵文字は付けない | 自分 |
| ② のびる丁寧 | Lv4〜8 | 丁寧語のまま、語尾がのびる | 「〜ですねー」「〜ますねー！」「ほほー！」「そうか◯◯・・・！」 | 「笑」+ 🤔 👀 💦 をときどき(3〜4行に1つ) | 自分(ときどき俺) |
| ③ っす | Lv9〜15 | 丁寧語に「っす」とタメ口の独り言が混ざる | 「了解っす！」「〜しかないや」「〜だ笑」「つい！」 | 「笑」+ 絵文字が少し増える | 俺 |
| ④ 混ざる | Lv16〜30 | 丁寧語とタメ口が半々。相手に向ける文は丁寧語、独り言と気持ちはタメ口 | 「そうだ、〜」「〜しなきゃ！」「〜かな👀」「〜ちゃいますねー！」 | 「笑」+ 絵文字(2行に1つまで・1行に1つ) | 俺 |

どの段階でも変えないもの:

- ゲームの話は、理由を並べて長めに分析する(「〜なので〜ですね」「〜だと思います」)。結論は軽く(「〜かどうか、という感じです」)。**分析の文は④でも丁寧語のまま**
- 感嘆は短く。三点は「・・・」(中黒3つ)
- 攻略班のエンジニア・すぐ計算したがる・推しはキュービとオリヒメ・勝ち負けに本気・自分の失敗を笑いにする(人柄はそのまま)
- 笑いは全角の「笑」(「w」は使わない)

## 5. 直し方(OK が出たあと)

1. 人柄の指示(`speech`・`speechQuirks`・`speechMarkers`・`firstPerson`・あいさつ・おしゃべりの見本6つ)を丁寧語の土台に書き直す
2. `ASSISTANT_BOND_STYLES.sorashido.tones` に30段ぶんの「この段階の話し方」を足す(おしゃべりはこれで段階が効く)
3. 固定の台詞: どの仲良し度でも出る行(`bond` なし)は①〜②の丁寧語に書き直す。そのうえで、よく開く場面に③④の段階の行(`bond:[9,15]` / `bond:16`)を足す。あつと同じ `bond:` の仕組み
4. assistant-chat の「助手ごとに必ず守ること」のソラシドの行と、口調の見張り(「〜ぜ」で言い切ってよい助手)を合わせる → main に入れたら窓口へ配り直しを頼む
5. 更新履歴は短く1行

## 6. 社長に決めてほしいこと

1. **段階の区切り**: 4段階(Lv1〜3 / 4〜8 / 9〜15 / 16〜30)でよいか
2. **これまでのくせ**(「うぉぉぉ！」「〜ぜ・・・！」・沖縄の言葉): 残すか、やめるか
3. **プレイヤーの呼び方**: いまは Lv1〜2「さん」→ Lv3〜4 呼び捨て → Lv5〜「ちん」(性別を選んだ人は くん/ちゃん)。丁寧語と合うように変えるか
4. **直す範囲**: 見終わるお話(加入のお話・イベントのお話)の中のソラシドの台詞も直すか
