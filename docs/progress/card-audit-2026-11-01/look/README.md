# MFバトルカード 見た目の点検(2026-11-01・ツナグ)

社長「バトルカードの見た目やシステム面の不具合・改良したい所を確認して。特に、きゅうこ(のアシカ)やイルミネが出て以降の確認作業をあまりしていない」「きゅうこ以降をチェックしてね。ソラシドやキュービとかも」。
カード部3人で分けたうちの【見た目】。**main へは入れない**(このブランチに置くだけ)。

## やり方

- 本物のゲームを開いて、MFバトルカードの画面(デバッグの形)を順にめぐる道具 `audit.js` で写真を撮り、機械でも数えた(文字の切れ・画面の外へのはみ出し・9px未満の字・読めない絵)
- 画面の大きさ: 縦 320×640 / 390×844 / 430×932、背の低い画面 390×600、横 844×390
- めぐった画面: トップ・対戦えらび・フリー対戦(きゅうこ・ソラシドを選ぶ)・デッキをえらぶ・VS(対戦開始)・対戦画面・手札と場のモンスターの詳しい画面・図鑑(一覧・カードの詳しい画面・キラ/レアキラ)・デッキ編成・デッキを組む・ランキング・記録・ルール・オプション・パックの絵・パックを開ける演出(キラ・レアキラ)
- 読めない絵(img の読み込み失敗)は、どの大きさ・どの画面でも 0。実行時エラーも 0

## きゅうこ以降のキャラの見え方

- **きゅうこ・ソラシド**(助手): 対戦えらびの顔の並び、フリー対戦の顔(7人の並び)、VS の立ち絵と台詞、対戦画面の顔と吹き出しのどこにも欠け・はみ出しは無かった(背の低い画面の VS だけ崩れていたので直した。下の②)
- **イルミネ・ドリーミィ・キュービ・オリヒメ**: MFバトルカードのカードはMFのモンスター(27種)なので、この子たちのカード・立ち絵はバトルカードには出ない(カードのデータ・バトルカードの部品のどこにも名前が無い)
- あつは加入のお話を見るまで、対戦えらびの顔にもフリー対戦にも出ない(写真のフリー対戦にあつがいるのは、デバッグの形で撮ったため)
