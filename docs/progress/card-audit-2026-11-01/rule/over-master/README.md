# 戦術カードで組んだデッキの打ち方の直し(ア+イ+ウ+倒れるのに守る)

2026-11-02 社長の決定「ア+イ+ウ 全部」+「倒れるのに守る」。ブランチ claude/card-over-master。社長の「この文で」までマージしない。

## 直したこと

| | 中身 |
| --- | --- |
| ア | 基本カードを、くせ(メインの基本カードの型。助手と同じ強さごとの調整ずみ)の上に足す。くせと同じ型の基本カードは二重に足さない(くせ みゅあ に攻め型を入れると「守るのは倒れるときだけ」が重なり、MASTER 50→36% に下がっていた) |
| イ | 行に当たっても、MASTER の点で、出せるいちばん良い手より2点以上低い手は出さずに、次の行・基本カードの型へ(登録デッキだけ。助手の打ち方は変えない) |
| 倒れるのに守る | 守っても倒れるのが変わらず、はね返し・まとめて回避などの得も無い守りは出さない(「守る」「倒れるときだけ守る」などで必ず守るときも。助手も同じ) |
| ウ | GRAND MASTER 以上の先読み: 先の場の良さに、その手の MASTER の点(×2)を足して比べる。持久型のくせは、山札の残りの差も見る |

### 更新履歴(1件・group cardBattle)

**戦術カードで組んだデッキが、より賢く戦うようになりました**

- 戦術カードに当てはまっても、その手が、いちばん良い手よりはっきり損なときは出さずに、次の戦術カードへ進むようになりました
- 「守る」などの戦術カードで、守っても倒れるのが変わらないときは、守らずに受けるようになりました
- 基本カードは、メインの型のくせの上に足されるようになりました。助手と同じ戦術カードを組めば、助手と同じくらいの強さで戦います
- GRAND MASTER から上の賢さで、先を試して手を決めるときの見方を良くしました
