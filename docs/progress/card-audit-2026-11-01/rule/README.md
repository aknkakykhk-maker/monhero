## 道具

- `audit-watch.js <port> <出力>` … 助手どうしの試合を3つの画面の大きさで流し、エラー・undefined・はみ出しを拾って止め絵を残す(`ONLY=new-mons` で1つだけ)
- `audit-cpu.js <port> <出力> <助手> <強さ> <幅x高さ>` … 人が押すように助手と対戦し、セリフを集める(`DEBUG=1 MAX=40` で押した物を表示)
