# 冥界チャレンジの見た目(タブ・背景・カードの枠・解放の演出)の止め絵と動画(2026-11-01・レフェリーくん)

社長の決め(ジン部長経由): 案1(タブ3つ: 通常 / 極限 / 冥界)・名前は「冥界チャレンジ」(UNDERWORLD)・解放は ETERNAL クリア・
一新は背景(炎と氷+シールドのひび)・カードの枠(INFERNO 橙 / COCYTUS 水色+🛡×3〜5)・解放の演出(タブがひび割れて開く+NEW)。専用BGMは入れない。
タブ・解放の判定・見出しの文字・記録の分け方はセコンドくん(60・19)、見た目の CSS は私(70-bootstrap.jsx)。
撮るときは、ETERNAL・INFERNO をクリアした記録だけ入れた(撮影用の箱の中だけ)。
