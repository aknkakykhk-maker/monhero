## 突き合わせ表

| 決めごと(台帳 r1115-002) | 止め絵のどこで満たすか |
| --- | --- |
| 指を札の列に置いたまま左右になぞると、指の下の札がその場で浮いて選ばれる(ほかは下がる) | T3 は「命中」が浮いて大きく光り、ほかの札は少し下がって小さい |
| 浮いた札の上に失敗率の吹き出し・下に「決定」 | T1・T3・T4 とも、選ばれた札の上に白い「失敗率 8%」・下に黄色の「決定」(T3 では命中の上に出ている) |
| 上の能力の上がり幅も、なぞっている札の物へすぐ替わる | T3 は能力の欄の「命中 +31」(T1 は「回避 +34」)と、場面の「命中のトレーニング」・効果の札も命中の物 |
| 指の通った跡に白い細い線が少し残る | T3 の札の列の上に白い線。離すと T4 では 0.5 秒で消える |
| 離した所の札が選ばれたまま | T4 は離した「回避」が選ばれている(検査 `T4: scrubup` が選びを確かめる) |
| 決め方(もう一度タップで決定)は変えない | 下の「〜をする」と、選ばれている札をもう一度タップで決定。なぞったあとの指離しでは決まらない(クリックを止める) |
| 札が替わるたびにタップ音(既存の効果音・SE の音量に従う) | 既存の `tap`(`Audio_.fgSe.tap`)。撮影の道具の検査で、3つ越えたら3回以上鳴ることを確かめている |

## 窓口の追加依頼(2点)の直し
- トレーニング名: 5字以下(大丸太割り・落ち葉よけ・木の実よけ など)は札の中で1行にして、途中で折れないようにした。6字以上(絵合わせパズル・遠くの的当て など)は1行に入らないので、これまでどおり語の区切り(パズル・的当て などの終わりの語の前)だけで折る。幅320の「札の最後だけ落ちた」の見張りは0件になった。
- 「← もどる」は main 取り込みで既に「← 戻る」になっている(止め絵も撮り直し済み)。
- 「絵合わせパズル」(7字)は幅390でも2行になる。1行に収めるには名前を短くするしかない(名前の決めは窓口・社長)。
