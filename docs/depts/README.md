# 部署別の手引き

<!-- このファイルは tools/team/depts.json から作っている。作り直し: node tools/team/dept-guide.js --write -->

新しい会話は、CLAUDE.md のあと**自分の部の1枚だけ**を読んで始める。ほかの部の手引きは読まない。
どの部のファイルか分からないとき: `node tools/ctx.js dept --of <ファイル>`

| 部 | 部長 | 受け持ち | 手引き |
| --- | --- | --- | --- |
| 本社(窓口) | 統括部長モンヒロくん | 社長の頼みを受けて部へ振る・台帳・Supabase の操作(SQL・配り直し)・新しい会話を作る。自分では改修しない | [`hq.md`](hq.md) |
| ビート部(モンヒロビート) | テンポくん | モンヒロビート(曲えらび・演奏・判定・マルチ・ランキング・相棒・助手とのセッション)、譜面生成ツール、曲の音源 | [`beat.md`](beat.md) |
| カード部(MFバトルカード) | ソランドくん | MFバトルカード(対戦・デッキ・パック・マルチ・リプレイ・観戦・大会・カップ・ランキング・助手の台詞) | [`card.md`](card.md) |
| バトル部(モンヒロバトル) | ジンくん | モンヒロバトル(難易度とルール・敵・戦闘画面・演出・タクティクス・レイドのジャック・編成・結果) | [`battle.md`](battle.md) |
| モンスター部(図鑑・絵・染色・新モンスター) | ズカンくん | モンスターの絵と染色マスク・図鑑・新しい味方モンスターの追加 | [`monster.md`](monster.md) |
| 開発部(HOME・マーケット・育成・設定・ヘルプ・土台) | クラフトくん | HOME・マーケット・マスモンの育成・ミッション・プロフィール・設定・ヘルプと更新履歴の仕組み・保存と通信の土台・デバッグ・検査の道具・速さ | [`dev.md`](dev.md) |
| 助手部ココロ(助手の AI・おしゃべり) | ココロ | 助手の人柄と台詞の土台・おしゃべり・ミッションのひとこと・Edge Function assistant-chat(中継役) | [`assistant-ai.md`](assistant-ai.md) |
| 助手部ナカヨシ(助手ライフ・地図・助手どうし) | ナカヨシ | 助手ライフ本体(家・部屋・時間帯・仲良し度・けんかと仲直り)・地図・助手どうしの掛け合い | [`assistant-life.md`](assistant-life.md) |
| 助手部オクリモノ(贈り物・道具・家具) | オクリモノ | 助手ライフの贈り物(買って贈る)・道具・家具 | [`gift.md`](gift.md) |
| 助手部オトズレ(フレンドの家・フレンド) | オトズレ | フレンドの家(助手の行き来・場面)とフレンド機能(一覧・申請・通信) | [`friend.md`](friend.md) |
| 助手部キズナ(育つ助手・助手のマスモン・提案) | キズナ | 助手のマスモン(名前・染め方・育て方)・育つ助手・「助手に提案する」 | [`masmon.md`](masmon.md) |
| 検査部(ミハリ) | ミハリ | 作った人と別の目での通し確認。新機能・保存データ・ランキングに関わる変更だけを見る(小さな直しは見ない) | [`kensa.md`](kensa.md) |

部を足す・受け持ちを変えるとき: `tools/team/depts.json` を直して `node tools/team/dept-guide.js --write`。
