# iPhoneでの「いまの見た目をランキングに出す」実行順

> 🟢 **`PROFILE_FRAME_BOND_APPLY.sql`（絆Lv・総合力のフレーム）もまだなら、2本を1つにまとめた
> [`PROFILE_LOOK_ALL_IPHONE_STEPS.md`](PROFILE_LOOK_ALL_IPHONE_STEPS.md) のほうが1回で済みます。**
> 中身は同じです。こちらは個別に当てたいときの手順です。

ランキングに出る**名前・アイコン・プロフィールフレーム**を、記録した当時のものではなく**いま設定しているもの**にするための作業です。新しいテーブル `public.breeder_profiles` を1つ作ります。

**既存のテーブル（`rankings` / `bond_levels`）には一切触りません。** 記録も順位もスコアも変わりません。

## なぜ必要か

ランキングは「1プレイ＝1行」で、その瞬間の名前・アイコン・フレームを記録へ写しています。そのため、あとから見た目を変えても**過去に出した行は古いまま**でした。

記録を書き換えるのは危ないので、**表示に使う見た目だけ**を別の小さな表から引くようにします。

- `breeder_profiles` は**1人1行**です。プレイ回数が増えても行は増えません
- 見た目を変えたとき（と、遊んだとき）に、その1行を上書きします

## 先に必要なSQL

`BREEDER_ID_APPLY.sql`（端末ごとのブリーダーIDを送るようになっていること）。無ければ先頭の点検でその場で止まります。

## 手順

1. **Safari で Supabase Dashboard を開く**
   SQL Editor → New query。
2. **いまの `rankings` の件数を控える**
   `select count(*) from public.rankings;` を Run して数字を残します。
3. **`BREEDER_PROFILE_APPLY_TEST.sql` を実行**（末尾が `rollback;`）
   予行演習です。本番には何も残りません。**エラーが出たらここで止めて共有**してください。
4. **`BREEDER_PROFILE_APPLY.sql` を実行**（末尾が `commit;`）
   まとめの表に、テーブル「あり」・RLS「有効」・権限に **DELETE が無い**・`rankings の件数`が手順2と同じ、と出れば成功です。
5. **⚠️ ゲームを開き直す（いちばん忘れやすい）**
   **SQLを当てただけでは、いま開いているアプリには反映されません。**
   アプリは「その表はまだ無い」と一度気づくと、**そのページを閉じるまでずっと**使いません。
   Safariならタブを閉じて開き直す／ホーム画面のアプリならタスクを切って起動し直してください。
   **更新のお知らせ（バナー）は出ないこともあります**（本体のファイルが変わっていない場合）。
6. **見た目を変えて、ランキングを開く**
   プロフィールでフレームやアイコンを変えてから、ランキングを開きます。
   **過去に出した自分の行も、新しい見た目に変わっていれば成功です。**
7. **`BREEDER_PROFILE_VERIFY.sql` を実行**（読み取りだけ）
   登録されているブリーダー数と、選ばれているフレームの内訳が見られます。

## 覚えておくこと

- **ブリーダーIDが付く前の古い記録**（2026-09-11より前）には、誰のものか分かる印がありません。
  その行は**名前で結びつけ**ます。ただし**同じ名前の人が2人以上いる名前は結びつけません**
  （他人の見た目を出さないため）。その場合は今までどおり記録に写した見た目で出ます。
  誰が当てはまるかは手順7の「同じ名前が2人以上いる名前」で分かります。
- **順位・スコア・集計・記録は何も変わりません。** 変わるのは見た目だけです。
- 削除の権限は与えていないので、間違って書き始めても行が消えることはありません。

## うまくいかないとき

- **「rankings.breeder_id がありません」**
  先に `BREEDER_ID_APPLY.sql` を適用してください。このSQLは何も変えずに止まっています。
- **適用したのに古い見た目のまま**
  まず手順5（**ゲームを開き直す**）をやったか確認してください。
  それでも直らなければ、ファイル末尾の `notify pgrst, 'reload schema';` まで実行できているか見てください。
