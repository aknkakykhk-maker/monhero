# ジャックのSQLを流す順番

イベント・レイドボス「ジャック」の与ダメージを貯める、**新しい表を1つとビューを3つ**作る作業です。
**既存の表・列・ビュー・関数・RLS・ポリシー・権限には触りません**(DROP・DELETE・UPDATE・ALTER をしません)。
設計は [`docs/spec/RAID_BOSS_JACK.md`](../../spec/RAID_BOSS_JACK.md)。

> **Supabase の SQL Editor は、ファイル全体を実行すると「最後の1文」の結果しか表示しません。**
> 3本とも**最後の1文が「まとめ」**になっています。1回 Run して出てきた表をスクリーンショットするだけで大丈夫です。

> **「Run and enable RLS」ではなく「Run without RLS」を選んでください。**
> 表のRLSはSQLの中で有効にして、ポリシーも作ります。Supabase側に追加のRLS設定を差し込ませる必要はありません。

## 何ができるか

- `raid_jack_hits` … 「1戦の与ダメージ = 1行」。同じ送信が2回届いても1行しか入りません(再送しても二重に数えません)
- `raid_jack_tier_totals` … 段階ごとの合計(A の共有HPを数える)
- `raid_jack_contributions` … 人ごとの貢献(A の貢献ランキング)
- `raid_jack_b_ranking` … B の累計ダメージ(5段階を合算)

誰でも追加と読み出しはできますが、**書き換え・削除はできません**(そのポリシーを作りません)。

## 順番

1. `RAID_JACK_APPLY_TEST.sql` を Run(**予行演習**。末尾で rollback するので何も残りません)。
   エラーが出ずに「まとめ」の表が出れば OK(列の数 9 / RLS true / ビューの数 3)
2. `RAID_JACK_APPLY.sql` を Run(本番。最後に commit します)
3. `RAID_JACK_VERIFY.sql` を Run(読み取りだけ。形の確認)
4. 画面で確かめてから、`RAID_JACK_PUBLIC_RELEASE` を `true` にして公開する
   (SQLを当てる前に公開フラグを立てても、画面は「準備中」になるだけで壊れません)

## あとから足す: 大王を倒したあとの「累計ダメージ」ビュー(2026-10-04)

大王を倒したあとにレイドバトルの累計ダメージを競うために、**ビューを1つだけ**足します(`raid_jack_a_ranking`)。
表・既存のビュー・権限には触りません。上の1〜2を済ませたあとに、同じ要領で流します。

1. `RAID_JACK_A_RANKING_TEST.sql` を Run(予行演習。最後に rollback。「列の数(4)」「ビューの数(4)」が出れば OK)
2. `RAID_JACK_A_RANKING.sql` を Run(本番。最後に commit)

流す前に公開しても、「累計ダメージ」の一覧が「準備中」になるだけで壊れません。

## あとから足す: 「1戦あたりの最大ダメージ」ビュー(2026-10-05)

レイドバトル・グランドスラムの「1戦で出したいちばん大きいダメージ」を競うために、**ビューを1つだけ**足します(`raid_jack_max_hit_ranking`)。
表・既存のビュー・権限には触りません。順位報酬は付きません。

1. `RAID_JACK_MAX_HIT_RANKING_TEST.sql` を Run(予行演習。最後に rollback。「列の数(5)」が出れば OK)
2. `RAID_JACK_MAX_HIT_RANKING.sql` を Run(本番。最後に commit)

流す前に公開しても、「1戦の最大ダメージ」の一覧が「準備中」になるだけで壊れません。

## うまくいかないとき

| 出たもの | 意味と対処 |
| --- | --- |
| `public.raid_jack_hits が別の形で既にあります` | 同じ名前の別の表があります。何も変えずに止まったので、中身を確かめて相談してください |
| `列が○個です` / `ビューが○個です` | 想定と違う形になったので全部取り消しました。画面を共有してください |
| 予行演習が通らない | 本番には何も入っていません。エラーの文章を共有してください |

## 元に戻すには

表は新しいので、使うのをやめるだけで既存のものには影響しません。公開フラグを `false` に戻せば画面から消えます。
