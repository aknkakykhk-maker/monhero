# 社長の決めごと台帳

社長(あつ)が会話の中で決めたことを、会話をまたいで引き継ぐための台帳。
**新しい会話(部署・子の会話を含む)は、作業を始める前にこれを読む。** 会話を新しく作る側は、
依頼文に「最初に docs/rules/PRESIDENT_DECISIONS.md を読む」と必ず書く。
社長が新しく決めたら、その場でここに1行足す(日付・社長のことば・何をするか)。

## 進め方

- **2026-10-22 SQL は社長にリクエスト(許可・確認)を出さずに流す。** 社長「リクエストはしないにすればいいんだよ」「今後SQLは全部リクエストなしですすめて」。新しい表の権限を絞る `revoke` なども聞かない。
- **2026-10-22 社長に SQL を流させない(基本なし)。** 社長「こっちに流させるのも基本なしだからな」。こちらで流し切る。
- **2026-10-22 会話を変えるときは決めごとを引き継ぐ。** 社長「頻繁に変えるんならそこもちゃんと引き継げよ」。この台帳がその受け皿。
- **未済(社長に次に SQL が要るとき、または手が空いたときに案内する)**: Supabase の許可の画面は、リポジトリの設定ではなく claude.ai のコネクタの設定で決まる。社長に https://claude.ai/customize/connectors → Supabase → `execute_sql`・`apply_migration` を「常に許可」にしてもらう。2026-10-22 社長「今は無理だからまた今度教えて」。済んだらこの行を消す。
- 改修はコミット → プッシュ → PR → マージ → 同期まで聞かずに進める(CLAUDE.md ②③)。
- 社長の判断が要るときは選択式で聞く。おすすめを先頭に「(推奨)」(CLAUDE.md)。
- 社長が寝る・離れるときは、相当重要なこと以外は窓口(モンヒロくん)の判断で進める。
- 表は画像(PNG)で見せる。送る前に拡大して、文字の切れ・単語の途中の改行がないか確かめる。
- 質問には答えるだけ。調査を広げない(CLAUDE.md ⑩)。
- 部署はサブエージェントを使わない。
- 仕上がりは、社長に報告する前にカゲあつくん(社長代理)に見てもらう。カゲあつくんは見るだけで、決めない・コミットしない。
