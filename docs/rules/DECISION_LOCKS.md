# 決めごとの錠(決めたことを、道具の側で止める)

2026-11-12 社長「決めたことを無視しないでちゃんと決めごととしての仕組み作ってね」(台帳 #5553)。

## なぜあるか

2026-11-12 に2回、台帳には書いてあるのに道具が古いままで食い違った。

1. 台帳は「要約は窓口だけ」なのに、部署向けのフックが要約を勧める文を出し続け、部署が社長に要約を頼んだ(#5524 で直した)
2. 社長は窓口の要約をトークン数で管理するつもりなのに、フックは回数で数えていた(#5552 で直した)

それまでの検査は「道具が自分の説明どおりに動くか」だけを見ていて、「台帳の決めごとと合っているか」を見るものが無かった。
窓口(モデル)が台帳を読み落としても、検査で止まる形にする。**人が覚えて守るだけの決めごとを増やさない。**

## 仕組み

| もの | 役目 |
| --- | --- |
| [`tools/team/decision-locks.json`](../../tools/team/decision-locks.json) | 錠の表(正本)。「進め方」の決めごと1つごとに、台帳のことば・守らせ方・検査・逆のことばを書く |
| `node tools/team/decision-lock-check.js` | 錠の検査。`run-checks-always.json` に入っているので、`run-checks.js --changed` と CI で毎回回る |
| `node tools/team/decision-lock-check.js --list` / `--people` | 錠の一覧 / 「人が守る」の一覧と理由 |

検査が止めること:

- **A 錠の無い決めごと** … 台帳の「## 進め方」の節の行と、本文の「`- <日付> 進め方:`」「`- <日付> 窓口の進め方:`」で始まる行が、どの錠にも載っていない
- **B 古い錠** … 錠に書いた台帳のことばが、台帳にもう無い
- **C 守らせ方の無い錠** … フック・道具・手引きの錠に、検査・動き・要ることばが1つも無い。検査のファイルが無い・決めごとのことばを確かめていない。「人が守る」に理由が無い
- **D 動き** … 道具とフックを実際に動かして、決めごとどおりの答えが出ない(例: 窓口が50万トークンの前に回数で問いを出す)
- **E 要ることば** … 手引き・依頼文・フックの知らせから、決めごとのことばが消えた
- **F 逆のことば** … 手引き(CLAUDE.md・AGENTS.md・docs/rules・docs/depts・tools/hooks・tools/team)・newsession の依頼文・フックの知らせ・台帳の「進め方」に、
  決めごとと逆のことばが残っている。逆のことばの形は、直す前に実際にあった文(例)に当たることも確かめる(見張りの空振りを止める)

## 守らせ方(強い順。なるべく上を選ぶ)

| 守らせ方 | 中身 |
| --- | --- |
| フック | 会話の中で機械が知らせる・止める(例: 部署がサブエージェントを呼ぶと `tools/hooks/no-subagent-in-dept.js` が止める) |
| 道具 | 道具の出力が決めごとどおりになっている(例: newsession の依頼文・モデルの表) |
| 手引き | 毎回読まれる CLAUDE.md に書いてあり、ことばが消えないことを検査する |
| 人が守る | 機械で確かめられない。**理由を書く。** 窓口の手引き(docs/depts/hq.md)に書き、ことばが消えないことだけ検査する |
| 対象外 | 決めごとではない行(未済のメモなど)。理由を書く |

## 台帳に「進め方」の決めごとを足すとき(窓口)

1. 台帳に1行足す。本文に足すなら、行の頭を「`- <日付> 進め方: …`」にする(この形の行を検査が拾う)
2. **同じ PR で** `tools/team/decision-locks.json` に錠を1つ足す
   - 守らせ方を決める。道具・フックで守れるなら、その道具の直しも同じ PR に入れるか、開発部(シクミ)へ頼む
   - 前の決めごとを改めるなら、古い言い方を「逆」に書く(形・例)。古い決めごとの錠は直すか消す
3. `node tools/team/decision-lock-check.js` が OK になるまで直す。NG のまま公開しない
4. 道具・フック・手引きの文を変えるときも同じ検査が回る。逆のことばに当たったら、決めごとのほうを確かめる(台帳が正)

錠を足さずに台帳だけ足すと、A で NG になり公開できない。

## 「人が守る」を減らす

`node tools/team/decision-lock-check.js --people` で一覧が出る。機械で確かめる手だてが見つかったら、道具かフックにして守らせ方を書き換える。
