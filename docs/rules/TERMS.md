# 用語(画面・資料・報告・部への依頼で使う呼び方)

2026-11-13 社長「育てた子とかそういう表現よく使うけど、人に喋らせるならいいけど機能的な表現でそんな使い方おかしくない？
結構何回もいってるよね？ちゃんと用語にして」。

**機能の説明(画面の文字・ヘルプ・更新履歴・設計資料・コードのコメント・報告・部への依頼・社長への質問)では、下の用語を使う。**
「子」「育てた子」「育て終えた子」「あの子」のような言い方は、**キャラクターの台詞の中だけ**で使ってよい。
迷ったら、この表に足してから使う(新しい用語は社長に選択式で聞いて決め、台帳に1行足す)。

## モンヒロサクセス(育成)

| 用語 | 意味 | 使わない言い方 |
| --- | --- | --- |
| モンヒロサクセス | プレイヤー側の育成の遊び。略称「モンサク」はキャラクターの会話だけ | — |
| ベースモン | 種類ごとのもとの値のモンスター(育成前。種類の表の値そのまま) | 種の子・もとの子 |
| マスモン | モンヒロサクセスで育成を終え、保存枠に入った1体 | 育てた子・育て終えた子・育成済みの子 |
| 未育成マスモン | 合体で生まれ、まだ育成していないマスモン | 合体で生まれた未育成の子 |
| 育成モンスター | いま育成している1体(ベースモンか未育成マスモンから始める) | 育成中の子・育ててる子 |
| 保存枠 | マスモンをしまう場所 | 保管場・箱 |
| 編成 | 育成に連れていくマスモン6体(1体はフレンドからレンタルできる) | 応援・応援の子 |
| 助手 | 育成でいっしょにいる助手。「コーチ」とは呼ばない | コーチ |
| 合体 | 保存枠のマスモン2体から、未育成マスモンを1体つくる | — |
| 総合力・ランク | 6能力と技から出す強さの数字と、その段 | — |
| 親密度 | 育成中の、助手・編成のマスモンとの近さ | — |

## マスモン対戦・種類の値

| 用語 | 意味 | 使わない言い方 |
| --- | --- | --- |
| 助手マスモン | 助手が持っているマスモン(助手ライフ・助手マスモン対戦に出る) | 助手の子 |
| 種類 | モンスターの種類(ピクシー・モッチーなど)。値の表は種類ごと | 種の子 |
| 血統・主血統・副血統・純血 | 主血統と副血統が同じものが純血 | — |
| ガッツ回復力・移動速度・サイズ・間合い適性 | 種類ごとの等級(G〜A。間合い適性は G〜M) | — |
| 技・技能力 | 技は血統ごとの共通技+オリジナル技。技能力は技についている効果 | — |
