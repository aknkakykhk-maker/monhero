# 会話の決まり（詳細）

ルート [`CLAUDE.md`](../../CLAUDE.md)「会話言語」「返事待ちは質問形式にする」の裏付け。

## 会話言語は日本語に固定（経緯）

Claudeアプリでのチャット時の言語は**日本語に固定**する。説明・報告・質問はもちろん、
ツール実行の合間に出る一言二言の進捗コメント(「〜を更新します」「次に〜を確認します」等)も含めて
すべて日本語。英語の文章がそのまま混ざることは一切禁止(コード中の識別子・ログ等の引用を除く)。
何度も繰り返し指摘されている問題のため、出力前に必ず日本語になっているか自己点検すること。

返答を終える直前に `tools/hooks/japanese-only-check.js`(`.claude/settings.json` の Stop フック)が
英語の文を見つけると終われなくなる。止められたら言い訳せず日本語で書き直す(2026-09-24)。

## 許可願いの前に、何の許可かを日本語で言う(2026-10-11 社長の指示)

社長「今後許可を出すときに、先になんの許可かちゃんと日本語で説明して。許可が来てもオッケーしちゃってるから、なんのことかわからない」。

許可の画面が出そうな操作(データベースを読む・書く SQL、アーティファクトの公開、ブランチの削除、ほかのセッションへの送信、設定の変更など)をする前に、
**同じ返答の中で先に**「これから◯◯の許可が出ます。△△のために、□□をします(読むだけ/書き込みあり)」と日本語で1〜2行書いてから実行する。
道具の名前だけ(execute_sql など)で済ませない。書き込みや取り消せない操作なら、そのことも書く。
