# 呼び方の決まり(助手・マスモン)

2026-11-07 ナカヨシ4。社長「ブリーダーとか呼び方がおかしい。こういうのもちゃんと整理が必要だね」。表は実データ(`monster-hero/data/assistants.js` ほか)から作った。プレイヤーの名前は例として「テスト」。

## 0. 台本の書き方(全部の台詞の決まり)

| 書くもの | 意味 | ゲームが置きかえるもの |
| --- | --- | --- |
| `{name}` | プレイヤー | 話している助手の、いまの呼び方(下の1。仲良し度の段・性別・Lv6から選んだ呼び方) |
| `{c}` | 相手の助手(2人のとき) | 話している助手が相手を呼ぶ呼び方(下の2) |
| `{c:kiki}` など | 3人のときの相手 | 同じく下の2 |

- 助手の台詞で、プレイヤーを「ブリーダー」「ブリーダーさん」と直に書かない。必ず `{name}`(`tools/assistant/player-call-check.js` が止める)
- 「ブリーダーLv」「ブリーダーP」「ブリーダー経験値」「ブリーダーの教え」「ほかのブリーダー」のような、役目・物の名前はそのまま
- AI 版の掛け合い(`supabase/functions/assistant-chat/core.js` の PEER_RULES_TEXT)も `{name}` で書かせる。「ブリーダー(さん)」と書いてきたら `{name}` に直す

## 3. マスモン → プレイヤー(モンヒロビートの相棒)

- 性格ごとの候補から1つ(`src/parts/33-rhythm-buddy-persona.jsx` の RHYTHM_BUDDY_CALLS・性格ごとの候補)。「◯◯さん」「◯◯くん」「◯◯ちゃん」「◯◯っち」「呼び捨て」「マスター」「相棒」「ボス」「ご主人」「◯◯さま」など
- 性別: 男の子なら「ちゃん」→「くん」、女の子なら「くん」→「ちゃん」に持ち替える(その性格の候補に両方あるときだけ)。答えないなら変えない
- `tools/assistant/breeder-gender-call-check.js` が見る

## 4. 見張る検査

- `node tools/assistant/player-call-check.js` … 助手どうし・助手ライフ・書き直しの表・台本のテキストに、プレイヤーへの「ブリーダー」が直に無いか/`{name}` が呼び方に置きかわるか
- `node tools/assistant/breeder-gender-call-check.js` … 性別ごとの呼び方
- `node tools/assistant/assistant-call-honorific-check.js` … 助手どうしの呼び方に「さん」「ちゃん」が重ならないか
