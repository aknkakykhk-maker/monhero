## 守ること(引き出しを使っても変わらない)

- 参考の**数**(1秒10ノーツ・指10本)は写さない。写すのは形(比・置き方・順番)だけ
- 空にするスライドは、重なる反対の手のスライドと左右が入れ替わるなら空にしない(両方空だと水平クロス。HELL では作らない)
- 同じ親指で詰まって続く鎖の中に、段の違う固定のノーツ(ホールド・モンスター・交差の形)があるスライドも空にしない(段を変える間 1.5拍を守れず、直しが収まらなくなった。10/16 の Sheriruth で R3 が12件の違反を出したのを直した)
- 手の決まり(同じ側の地上⇔空中 150ms・空中は地上から250ms など)は、引き出しのあとも今までの直しが最後に通る

## 前からある HELL

Sheriruth・風がそよぐ場所・Against My Own Shadow の HELL は `rhythm-hell-mix.js` の `SONGS` に `drawers:false`(作り直しても今の形)。
試すときは `--drawers`(書かない・数字だけ)。
**2026-10-16 社長の決定: 3曲とも今のまま。**「あくまでもツールの強化として学習してほしいだけで、基本的にいま実装されてる曲を変えることはしない」。
引き出しは、これから作る曲・譜面だけに使う。配信中の曲の譜面は今後も作り直さない(⑩-2)。

```
node tools/mode/rhythm-density-shape.js [--difficulty HELL|ALL] [--chart <譜面のJSON>]   R1
node tools/mode/rhythm-hell-mix.js --song <曲> --drawers                          前からある HELL で試す
node tools/mode/rhythm-hell-mix.js --song <SONGS に無い曲>                          解析ファイルから試しに作る(書けない)
node tools/mode/rhythm-chart-v3-generate.js --track <曲> --no-drawers              R2 を使わずに作る
```
