# 行動カードの名札(2026-10-15)

社長が ChatGPT で作った、カードの名前を載せる名札の原本。配信しない(組み込むときは縮めて軽くしてから monster-hero/images/ へ)。
社長「まだ文字に馴染みがないようにみえる。ただ乗っけてるだけというか」を受けて、枠と同じ金の飾りでできた台の上に名前を置くために作った。

- plate-red / blue / green / purple / gold.png … 枠の色(攻撃=赤・距離撃=青・守り=緑・支援=紫・固有技=金)と同じ。約1281×172・本物の透過
- 横長(約7.4:1)で、2行の名前には高さが足りない。左右の宝石の飾りは縮めず、真ん中の面だけを縦に伸ばして(9分割の伸ばし方)使う
- 金の名札の上の字は、金の字だと読みにくい(固有技)。濃い色の字に明るい縁取りなど、読める見せ方にする
