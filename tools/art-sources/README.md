# 配信しない画像の置き場

ここには**ゲームから読み込まない画像**だけを置く。`monster-hero/` の外にあるので、
GitHub Pages では配信されない。

| フォルダ | 中身 | 使うところ |
| --- | --- | --- |
| `monsters/` | 顔アイコンを切り出すための、立ち絵より高解像度な原本 | `node tools/make-face-icons.js` |
| `dye-masks/` | 染色の部位分けが正しいかを比べるための正解見本 | `node tools/undine-dye-mask-check.js` など |

## なぜここに置くか

- **配信フォルダを汚さないため。** `monster-hero/images/` に入れると、ゲームが一度も読まない
  画像がサイトに並ぶ。`tools/image-asset-check.js` は「`images/` に使われていない画像が残っていない」
  を検査するので、検査専用の画像をそこへ置くと例外リストが必要になり、本当の消し忘れを
  見逃す原因になる。
- **失わないため。** 過去に原本を一時ディレクトリにしか置かず、セッションが変わって
  失われたことがあった。

## 置くときの決まり

- **配信中の画像と同じ中身のものは置かない。** 同じバイト列を2か所で持つと、片方だけ
  差し替わったときにどちらが正しいのか分からなくなる。原本と配信画像が同じなら、
  `monster-hero/images/` にある1枚だけを正本とする。
- ファイル名はモンスター ID を大文字にして統一する(例: `MOCCHI.PNG`、`IBLIS.PNG`)。
