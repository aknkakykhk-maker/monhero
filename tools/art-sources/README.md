# 顔アイコンの元画像

`tools/make-face-icons.js` が顔アイコンを作るときに使う、高解像度の元画像を置く場所。

ファイル名は `FACE_BOXES` のキーと同じ大文字(例: `ZAN.png`)。ここにファイルがあれば、
`data/images/images-ally.js` に埋め込まれている立ち絵より優先して使う。

## なぜここに置くか

立ち絵として埋め込んでいる画像は表示に必要な解像度まで落としてあるため、そこから顔を
切り出すと拡大で粗くなる。顔アイコン用にもらった高解像度の元画像をそのまま残しておけば、
切り出し範囲を調整したくなったときにいつでも作り直せる。

過去に元画像を一時ディレクトリにしか置いておらず、セッションが変わって失われたことがあった
ため、リポジトリで管理する。ここに置いた画像は配信されない(`monster-hero/` の外にある)。
