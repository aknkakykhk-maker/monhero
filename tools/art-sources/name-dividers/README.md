# 行動カードの名前の飾り線(2026-10-15)

社長が ChatGPT で作った、カードの名前の下(または上下)に入れる細い金の飾り線の原本。配信しない(縮めて軽くしてから monster-hero/images/ へ)。
社長「この乗っかった感じをもっとよくできない?」を受けて、名札の代わりに、枠とつながって見える飾り線を名前に添えるために作った。

- divider-red / blue / green / purple / gold.png … 真ん中の宝石の色が枠の色(攻撃=赤・距離撃=青・守り=緑・支援=紫・固有技=金)。約2085×105(約20:1)・本物の透過
- 横に縮めすぎると真ん中の飾りがつぶれるので、名前の幅ではなく、文字の置き場の幅に合わせて置く
