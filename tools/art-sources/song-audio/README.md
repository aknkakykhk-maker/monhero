# モンヒロビートの曲の元の音源(配信しない)

曲を入れるときに受け取った音源(動画・mp3・m4a など)を、**加工する前のまま**ここへ残す。
2026-11-02 社長「元の音源が無くて直せないことを防ぐ」。全曲を 44.1kHz / 128kbps へ上げたとき、
元の音源が残っていない曲は作り直せなかった(32kHz のファイルから上げ直しても音は良くならない)。

- 置き場所: `tools/art-sources/song-audio/<songId>/`(short ver. は全編と同じ曲のフォルダへ。ファイル名で分かるように)
- 配信されない(GitHub Pages が配るのは `index.html` と `monster-hero/` だけ)。起動時にも読まない
- 届いたファイルをそのまま置く(音量そろえ・切り出し・無音足しは `monster-hero/audio/` の側でする)
- 作り直しのやり方は `docs/rules/ASSETS.md`「44.1kHz / 128kbps への作り直し」
