# 技のマーク(試作・2026-10-14)

社長が ChatGPT で作った、行動カードの上の真ん中に入る技のマークの原本。配信しない(ゲームに入れるときは軽くしてから monster-hero/images/ へ)。
今の絵文字(data/skills.js の BASE_ATK_EVOLUTION・GUARD_EVOLUTION の icon、距離撃は RANGE_LABELS の漢字)を置き換える予定。

- atk-1〜9.png … 攻撃の9段階(小さな衝撃の火花・三本の爪あと・地面を割る亀裂・燃える隕石・光の爆発・燃えさかる炎の渦・天から落ちる稲妻・砕ける大地と溶岩・星を砕く光の大爆発)。512×512、本物の透過。3×3の1枚を窓口が切り分けた
  - 最初の版は拳・剣・戦槌・三叉の槍など武器の絵だった。攻撃の名前はモンスターごとに違う(「ぞうさん頭突き」など)ので、どの技にも合う衝撃・力の絵で9個とも作り直した(2026-10-14 社長の決定)。最初の版は git の履歴にだけ残る
- guard-1〜9.png … 守りの9段階(丸い盾・紋章の盾・城壁・ダイヤの盾・星空の結界・聖堂・六角形の障壁・無限の印の盾・光る鳥居)。作り方は攻撃と同じ
- range-0-zero / 1-near / 2-mid / 3-far.png … 距離撃の間合いごとのメダル(赤・金・緑・青。盤面の零・近・中・遠の枠の色に合わせた)。中に絵はなく、真ん中に「零・近・中・遠」の字をゲーム側で金の字で重ねる(2026-10-14 社長「今までの距離のマークをしゃれた感じに」「距離にあった色」)

## 決めたこと

- 段階の数字は絵に描かせず、ゲーム側でマークの下に**ローマ数字の札(I〜IX)**を重ねる(2026-10-14 社長が選択。丸い数字・星の数と見比べて)
- 組み込みはリセット(10/15 20:00)後に部署へ回す。枠(tools/art-sources/card-frames/)と一緒に試作を作り、社長が見比べて決める
