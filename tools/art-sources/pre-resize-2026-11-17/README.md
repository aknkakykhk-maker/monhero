# 画像サイズ見直し前の原本置き場(2026-11-17)

2026-11-17 社長指示「画像サイズの見直し。ホームのアイコンとかは結構小さめのサイズだから
それに合わせた画像サイズに下げたほうが良さそう。ダウンロードサイズがでかくなりすぎた」
にもとづき、`monster-hero/images/` の画像を表示サイズに合わせて縮小した。
ここには、縮小前の原本のうち、ほかに原本の置き場所が無いものを、元のパスそのままに残す。

- 画質(圧縮品質・色数)は落としていない。ピクセル寸法だけを表示サイズ(高DPIで2〜3倍)に合わせた
- 元がパレットPNGのものは、パレットのまま縮小した(トゥルカラー化すると逆に重くなるため)
- 助手の全身画(`images/assistant/fullbody/` と `images/assistant/winter/` のキュウコ冬服)は、
  原本が `tools/art-sources/assistant-fullbody/received-v1/` にあるので、ここには入れていない
- 戻したいときは、ここのファイルを同じパスへ上書きし、`node tools/build.js` で
  キャッシュキー(`?v=`)を付け直す
