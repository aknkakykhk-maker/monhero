# 染色マスクの正解見本

染色(部位ごとの塗り分け)が崩れていないかを画素単位で比べるための、**検査専用**の見本 PNG。
ゲームからは一切読み込まない。

| ファイル | 使うところ |
| --- | --- |
| `undine-dye-mask.PNG` | `node tools/image/undine-dye-mask-check.js` の正解見本(1024x1536・立ち絵と同じ原寸) |
| `yaobikuni-dye-mask.PNG` | ヤオビクニの差し替え前の原本。今の検査は配信中の `yaobikuni-dye-mask2.PNG` を使うため、比較・巻き戻し用に保管しているだけ |
| `pandora-dye-mask.PNG` | パンドラの部位分けの原本。ゲーム本体は埋め込みの部位マップ(`PANDORA_EXACT_REGION_2BIT`)を使うので、このPNGは配信していない。部位を描き直したくなったときの元データとして保管している |
| `kenshi-mocchi-dye-mask.PNG` | 剣士モッチー(5部位)の原本。届いたときのまま(背景が不透明な黒・境目にアンチエイリアスあり)。配信中の `monster-hero/images/monsters/kenshi-mocchi-dye-mask.PNG` は、これを本番と同じ判定で読み直して純色へそろえたもの(`node tools/image/convert-dye-mask.js … --snap`)で、どの画素がどの染色になるかは同じ。953KB→37KB になるので配信側だけ差し替えている |
| `yggdrasil-dye-mask-aligned.png` / `mel-whip-dye-mask-aligned.png` | 配信中の染色マスクの**出発点**(2026-09-28)。いただいた3色マスクを立ち絵と同じ座標・大きさへ合わせ、色だけリポジトリの約束(赤=① / 緑=② / 青=③)へそろえたもので、形には手を入れていない。配信中のマスクは、これを `node tools/image/finish-dye-mask.js <名前>` で仕上げたもの(塗り残しの輪郭線・胸元・スポンジとの境目・ブルーベリー・ケーキの目と口)。`node tools/image/upcoming-dye-mask-check.js` が「仕上げ直すと配信中と1画素も違わない」ことを見る |
| `yggdrasil-dye-mask-aligned.png` / `mel-whip-dye-mask-aligned.png` | 配信中の染色マスクの**出発点**(2026-09-28)。いただいた3色マスクを立ち絵と同じ座標・大きさへ合わせ、色だけリポジトリの約束(赤=① / 緑=② / 青=③)へそろえたもの。配信中のマスクは、これを `node tools/image/finish-dye-mask.js <名前>` で仕上げたもの(輪郭線の塗り残し・暗い線・胸元・スポンジとの境目・ブルーベリー・ケーキの目と口)。`node tools/image/upcoming-dye-mask-check.js` が「仕上げ直すと配信中と1画素も違わない」ことを見る。**メルホイップは2枚の組み合わせ**: 3回目(`-received-v3.png`)で塗ってある画素はそれを使い、3回目が白く抜いていた画素だけ2回目(`-received-v2.png`)で補った。3回目は髪・葉・果物・ドレスの緑の境目が正確だが、ケーキ上面のふち・傘の白いストライプ・胸当てのような、元の絵でいちばん白い所を背景と同じ扱いで抜いていたため |
| `mel-whip-dye-mask-received-v3.png` | メルホイップの3色マスク(2026-09-28・3回目・白背景)。色の付け方は2回目と同じ(緑=緑系 / 赤=赤系 / 青=白・クリーム)。上の説明のとおり、2回目と組み合わせて使っている |
| `mel-whip-dye-mask-received-v2.png` | メルホイップの3色マスクの**いま使っている原本**(2026-09-28・2回目)。元の絵そのものの上で塗ってもらったもので、目・口・イチゴの位置が2〜6px以内で合っている。色の付け方は 緑=緑系 / 赤=赤系 / 青=白・クリーム で、取り込むときに リポジトリの 赤=①緑系 / 緑=②赤系 / 青=③ へ入れ替えた(`convert-dye-mask.js --map`)。1回目(下の `mel-whip-dye-mask-received.png`)は描き直された別の絵から作られていて、果物やドレスの形が合わなかったため差し替えた |
| `yggdrasil-dye-mask-received.png` / `mel-whip-dye-mask-received.png` | 近日公開予定の2体(2026-09-28)の3色マスク。届いたときのまま(市松模様の背景・メルホイップは右に凡例入り)。立ち絵とは大きさ・位置が少し違っていたので、重なりがいちばん大きくなる倍率と位置を測って立ち絵へ合わせ、純色へそろえたものを配信している(ユグドラシル 横0.976倍・右へ22px / メルホイップ 横0.969倍・縦0.994倍・右へ81px)。メルホイップは顔が別の表情で描かれていたため、縁の塗り残しを色のつながりで埋め、①に入った肌色・金属色と③に入った肌色、ごく暗い画素(目・口・蹄)を外している |

モッチー・プラントの正式マスクはここではなく配信フォルダ(`monster-hero/images/monsters/`)にある。
ゲームが実際に読み込んで染め分けに使っているためで、検査もその配信中のPNGを正本として比べる
(`mocchi-dye-mask-check.js` / `plant-dye-mask-check.js`)。

見本はデバッグ画面の「染色マスクエディタ」から書き出した PNG を、そのままここへ置く。
配信フォルダ(`monster-hero/images/`)には置かないこと — 理由は `../README.md` を参照。
