# 実装依頼: 新しい血統「キュービ」をカードバトルに追加する

このフォルダ(zip)を受け取った Claude へ。これは MFバトルカード(monhero のカードバトル)に、
新しい血統「キュービ」を足すための素材一式と依頼書です。まず `README.md` でファイルの場所を、
`kyubi.md` で血統の考え方と効果の意図を読んでください。

## やること
1. **ゲーム側のつくりを調べる**: 既存の血統(例: ピクシー、ヒノトリ)がどう登録されているかを、アプリのコードで確かめる。
   カードのデータ、カード画像の置き場所、効果の処理、図鑑、デッキ編成を見る。そのやり方にそろえる。
2. **カード画像を入れる**: `cards/` の画像を既存のカード画像と同じ場所・同じ名前の決まりで置く。
   表示用の `.l.jpg`(大)と `.s.jpg`(小)がある。既存に合わせて置く。原寸 png が必要なら依頼者にたずねる。
3. **カードのデータを入れる**: `kyubi.cards.json` が正。既存のデータの形に書き換えて登録する。
   - モンスター: `monster`(番号 C-K01、空中 `air`、ライフ7)
   - 技: `cards[]`(K01〜K13)。画面に出る番号は `noBase` 901 からの連番(◆001〜◆013)
   - `kind`: pow=ちから / int=かしこさ / spe=特殊 / dge=回避 / blk=防御
   - `star: true` は必殺技の印
   - K01 提灯落としは効果なし(`text` が空なのはわざと)
4. **効果を動かす**: `effects[].t` のうち、既存にないものは新しく作る。下の表を見る。
5. **混血モンスター「オリヒメ」を入れる**: `orihime/` にある。下の「混血 オリヒメ」を見る。
6. **確かめる**: 各カードの効果が文どおりに動くことをテストで確かめる。下の「確かめること」を見る。

## 効果の一覧
既存にあるかどうかは、アプリのコードで確かめてください(下は企画側の見立て)。

| `t` | 動き | カード |
|---|---|---|
| `noEvade` | この技は回避されない | 狐火・超狐火・神狐蒼火 |
| `area` (`who: enemies`) | 相手モンスター全員にダメージ | 炸裂気泡陣 |
| `evade` (`kinds`) | 指定の種類の技を回避する | 神域移動 |
| `reduce` (`kinds`, `n`) | 指定の種類の技のダメージを−n | 九重神眼 |
| `gutsLossOnHit` (`n`) | ダメージを与えたら、相手のガッツ−n | なめろう |
| `safeOnHit` | ダメージを与えたら、このモンスターは次の自分のターンまでダメージを受けない | 陽炎 |
| `toGutsOnHit` 【新】 | ダメージを与えたら、このカードは捨て札でなく自分のガッツ置き場へ(裏向き)。既存の `returnOnHit`(手札に戻る)の行き先違い | ひのこ・火炎車 |
| `toGutsAfterUse` 【新】 | 使ったあと、条件なしでこのカードはガッツ置き場へ。戻ったガッツは同じ相手ターン中の次の守りに使える | 九重神眼 |
| `gutsFromDiscard` (`n`) 【新】 | (`gutsLossOnHit` の後で)自分の捨て札からランダムに n 枚をガッツ置き場へ。相手が減少を無効にしても、こちらの回収は行う。捨て札が足りなければある分だけ | なめろう |
| `gutsFromDiscardNow` (`n`) 【新】 | 使ったとき、自分の捨て札からランダムに n 枚をガッツ置き場へ(条件なし)。足りなければある分だけ。ガッツにしたカードは普通のガッツと同じ扱い(山札に戻す効果などで戻れば、そのカードはまた使える) | 霊魂操作 |
| `nextOwnCost` (`n`, `kinds`) 【新】 | ダメージを与えたら、技を使ったモンスター自身が次に使う、指定の種類の技の消費ガッツを−n(0未満にしない)。期限なし。重ねがけしない。KOで消える。ほかの味方には効かない | 天河天翔 |

細かいルールの判断は `kyubi.md` の「4. 新しい効果の部品」と「5. バランス確認」に書いてあります。

## 混血 オリヒメ
- キュービ種の混血。メイン キュービ、サブ unknown(カードの表記は「？？？」。元のゲームのジェントル C-020 と同じ扱い)
- データ: `orihime/orihime.cards.json`(番号 C-K02、空中 `air`、ライフ7)。画像: `orihime/cards/C-K02.*`(画面の番号は C-◆04)
- 専用技は持たない。`cards` が空なのはわざと。**サブが unknown の混血は、技をすべてメイン(キュービ)の専用技 K01〜K13 から使う**
- 既存に混血モンスターの登録方法があれば、それに合わせる。なければ依頼者にたずねる

## 確かめること
- 15枚すべて(キュービ14枚+オリヒメ)が図鑑・デッキ編成・対戦で、正しい画像・名前・数値で出る
- 新しい効果それぞれについて、当たった場合と回避・防がれた場合の両方
- なめろう: 相手がガッツ減少を無効にしても、自分の捨て札からの回収は行われる。捨て札0枚でも止まらない
- 天河天翔: 2回当てても−2のまま。そのモンスターがKOされたら消える。ほかの味方には効かない
- オリヒメのデッキに、キュービの専用技が入れられる
- 九重神眼: 使ったカードがガッツ置き場に行き、同じ相手ターン中にまた使える

## 決まりごと
- 画像は描き直さない・作り直さない(企画側で確定済み)
- データの数値・効果文は変えない。おかしいと思ったら、変える前に依頼者にたずねる
- 分からないところ(ルールの判断、既存のつくりと合わない所)は、勝手に決めずに依頼者にたずねる
