# キュービ(新しい血統)実装用パッケージ

> Claude に渡すときは、zip ごと渡して「CLAUDE.md を読んで実装して」と頼めば伝わります。

2026-11-03 作成。キュービのモンスターカード 1枚 + 専用技カード 13枚 + 混血オリヒメのモンスターカード 1枚。

## 中身
| 場所 | 内容 |
|---|---|
| `cards/C-K01.*` | モンスターカード(番号 C-◆01、ライフ7、空中) |
| `cards/901-K01.*` 〜 `913-K13.*` | 専用技カード(◆001〜◆013) |
| `cards/*.l.jpg` / `*.s.jpg` | 大きい表示用 / 小さい表示用(元のカードと同じ大きさの並び) |
| `kyubi.cards.json` | カードのデータ(技名・種類・ダメージ・ガッツ・効果文・効果の中身 `effects`) |
| `kyubi.summary.json` | 数値のまとめ |
| `kyubi.md` | 血統のコンセプトと、各技の意図・バランスの説明 |
| `orihime/` | 混血オリヒメ(メイン キュービ・サブ ？？？)。`cards/C-K02.*` 画像、`orihime.cards.json` データ |
| `一覧.jpg` | 全カードの一覧(下の段が混血) |

## 対応表
ファイル名の数字(901〜913)がカード番号、K01〜K13 が `kyubi.cards.json` の `cards[].id` です。
モンスターは `monster.no` = `C-K01`。オリヒメは `C-K02`(画面の番号 C-◆04)。オリヒメは専用技を持たず、キュービの技を使います。

## メモ
- 効果文はカードの絵に入っています。データ側は `kyubi.cards.json` の `text` と `effects` が正です。
- 新しい効果(`effects` の `t`)が既存のゲームにない場合は、`kyubi.md` の説明を見てください。

- 軽い版です。原寸 png と枠に入れる前の絵は省きました(表示用の jpg だけ)。必要なら依頼者に原寸版をもらってください。
