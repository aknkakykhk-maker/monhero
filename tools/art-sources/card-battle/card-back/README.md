# MFバトルカードの裏面

- `received.png`: 社長から 2026-10-26 に届いた絵(1073×1466)。四隅に黒い背景が写っている(カード本体は x16・y10 から 1043×1428)
- 配信用: `monster-hero/images/card-battle/s/back.jpg`(240×336)・`l/back.jpg`(480×672)。表のカードと同じ大きさ・JPEG(quality 78・mozjpeg)
- 作り方: 本体を切り出し、両わきのクリーム色のふちを 11px ずつ削って比を 0.715 にそろえる(ゲームのカードは 0.714)。
  ロゴと空の絵には手を付けない。角は幅の 4.5% で丸め、外は白(表のカードと同じ。画面ではどこも角を丸めて切り抜いて出す)
- 使う所(84・87): 相手の手札・倒れたモンスターの裏返し・ガッツへ飛ぶ裏向きのカード・パックのめくる前のカード。
  山札とガッツの山は、いまは数字の札なので絵は無い
