# プレイボット(遊んでくれるロボット)

実ブラウザ(Chromium)でゲームを開き、ボタンを押して回りながら「おかしなこと」を記録する道具。
検査(`run-checks.js`)と違って**合否は出さない**。見つけたものをスクリーンショット付きで報告し、
直すかどうかは人(とClaude)が決める。2026-10-06 に試作した。

```
node tools/playbot/playbot.js                 ふつうに1回(約4分)
node tools/playbot/playbot.js --steps 300     探索の手数を変える(既定160)
node tools/playbot/playbot.js --seed 12345    同じ押し方を再現する(報告に種が出る)
node tools/playbot/playbot.js --auto-ms 60000 クイックモードのAUTOを見張る長さ(既定45秒)
node tools/playbot/playbot.js --headed        画面つきで動かす
```

結果は `tools/out/playbot/<日時>/` に出る(`report.md` / `report.json` / 画像)。`tools/out` は git に入らない。

## やること

1. **起動**: TAP TO START → タイトル → HOME まで止まらずに着くか(かかった秒数も出す)
2. **クイックモード**: 勇者モンを毎回ちがう子で選び、AUTOで回す。20秒以上WAVE/ターンが動かなければ「進行停止」
3. **探索**: 見えているボタンを、まだ押していないものを優先して押す(モンキーテスト)。
   同じ画面に長くいたら戻る/HOMEへ戻す

## 見張っているもの

| 分類 | 種類 | 中身 |
| --- | --- | --- |
| 不具合候補 | JSエラー / コンソールエラー | `pageerror` と `console.error`(通信を止めたことで出るものは除く) |
| 不具合候補 | 真っ白 | `#root` が空、または本文が空 |
| 不具合候補 | 横はみ出し | ページ全体が画面幅(390px)より広い |
| 不具合候補 | 行き止まり / 進めない | 押せるものが無い、決まった手順で先へ進めない |
| 不具合候補 | 進行停止 | AUTO中にWAVE/ターンが動かない |
| 改善のヒント | 反応なし | 同じボタンを3回押しても画面の文字が1つも変わらない |
| 既知 | — | 調べて意図どおりだと分かったもの(`playbot.js` の `KNOWN`) |

意図どおりだと分かった挙動は、`KNOWN` へ**理由と根拠の場所**を書いて足す。消さずに「既知」として
報告の下へ回るので、毎回同じものを調べ直さずに済む。

## 守っていること(CLAUDE.md ⑦)

- 毎回まっさらなブラウザで動かす。手元・本番のセーブデータには触れない
- Supabase(全国ランキング)への通信は横取りし、読みは空・書きは成功を返す。**本物へは1件も届かない**
  (報告の「全国ランキングへの送信」は横取りした件数)
- 手元(localhost)以外への通信はすべて止める。よその作品へのリンク・削除・初期化・デバッグ系のボタンは押さない

## 苦手なこと

- 「楽しいか」「手ざわりが良いか」は判断できない。モンヒロビートの判定のずれも測れない
- 画面の名前は `gameState` を外から読めないので、テーマの分類と見出しの文字で呼び分けている
  (`battle:クイックモード` など)。見出しの無い画面は `(見出しなし)` になる
- 乱数で押すので、毎回見る画面は少しずつちがう。気になる結果は `--seed` で再現する
